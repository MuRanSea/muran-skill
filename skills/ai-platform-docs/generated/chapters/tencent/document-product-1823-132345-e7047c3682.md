# 查询 API 密钥详情

官方来源：https://cloud.tencent.com/document/product/1823/132345
最近更新时间：2026-06-18 01:59:49

## 1. 接口描述

接口请求域名： tokenhub.tencentcloudapi.com 。

根据 API 密钥 ID 或密钥值查询 API 密钥详情，返回明文密钥。ApiKeyId 和 ApiKey 至少需传入其一，优先使用 ApiKeyId。

默认接口请求频率限制：20次/秒。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](/document/api/1823/132283)。

| 参数名称 | 必选 | 类型 | 描述 |
|---------|---------|---------|---------|
| Action | 是 | String | [公共参数](/document/api/1823/132283)，本接口取值：DescribeApiKey。 |
| Version | 是 | String | [公共参数](/document/api/1823/132283)，本接口取值：2026-03-22。 |
| Region | 是 | String | [公共参数](/document/api/1823/132283)，详见产品支持的 [地域列表](/document/api/1823/132283#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| Platform | 是 | String | 平台类型。当前支持填值：maas<br/>示例值：maas |
| ApiKeyId | 否 | String | API 密钥 ID，与 ApiKey 至少需传入其一，优先使用 ApiKeyId。<br/>示例值：ak-20260320-a1b2c3d4 |
| ApiKey | 否 | String | API 密钥明文，与 ApiKeyId 至少需传入其一。<br/>示例值：sk-xxx |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
|---------|---------|---------|
| ApiKeyId | String | API 密钥 ID。<br/>示例值：ak-20260320-a1b2c3d4|
| Name | String | 名称。<br/>示例值：my-api-key|
| ApiKey | String | API 密钥值（明文）。<br/>示例值：<API_KEY>|
| Remark | String | 备注。<br/>示例值：test api key|
| Platform | String | 平台类型。枚举：maas<br/>示例值：maas|
| Uin | String | 主账号。<br/>示例值：100000000001|
| SubUin | String | 子账号。<br/>示例值：100000000002|
| Status | String | 状态。取值：enable（启用）、disable（禁用）。<br/>示例值：enable|
| BindType | String | 绑定类型。取值：all（全部模型和接入点）、model_all_endpoint_custom（全部模型+自定义接入点）、model_custom_endpoint_all（自定义模型+全部接入点）、model_custom_endpoint_custom（自定义模型+自定义接入点）。<br/>示例值：all|
| CreateTime | String | 创建时间。格式：YYYY-MM-DD HH:mm:ss。<br/>示例值：2026-03-01 00:00:00|
| UpdateTime | String | 更新时间。格式：YYYY-MM-DD HH:mm:ss。<br/>示例值：2026-03-01 00:00:00|
| AppId | String | 应用 ID。<br/>示例值：1300000001|
| Editable | Boolean | 是否可编辑。true 表示可编辑，false 表示不可编辑。<br/>示例值：true|
| BindingItems | Array of [BindingItem](/document/api/1823/132279#BindingItem) | 绑定资源列表，区分 endpoint 和 model 类型。|
| IpWhitelist | Array of String | IP 白名单列表。支持 IPv4和 CIDR 格式。空数组表示不限制 IP。<br/>示例值：["1.1.1.1"]|
| Creator | String | 当Platform为maas时该字段为空<br/>示例值：张三|
| QuotaSet | Array of [QuotaInfo](/document/api/1823/132279#QuotaInfo) | Token 限额多维度信息。未配置限额时不返回该字段。|
| QuotaStatus | String | Token 限额状态。空字符串表示未配置任何限额包；active 表示已配置且当前可用；inactive 表示已配置但额度耗尽<br/>示例值：active|
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。|

## 4. 示例

### 示例1 DescribeApiKey

#### 输入示例

```
POST / HTTP/1.1
Host: tokenhub.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: DescribeApiKey
<公共请求参数>

{
    "Platform": "maas",
    "ApiKeyId": "ak-20260609-f294a4aa4e2a7412780914226ad3ffd8"
}
```
