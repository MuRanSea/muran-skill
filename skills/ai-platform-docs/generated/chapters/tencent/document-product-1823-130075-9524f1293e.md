# Kilo Code

官方来源：https://cloud.tencent.com/document/product/1823/130075
最近更新时间：2026-10-22 10:29:00

Kilo Code 是一款开源 AI 编程助手，全场景适配您的开发工作流，无论在 IDE、终端、浏览器中，还是移动办公场景均可使用。借助深度理解代码库的 AI 能力，高效生成代码、自动化代码评审、调试问题，加速研发交付。本文介绍如何在 Kilo Code 中配置与使用腾讯云大模型 Token Plan。

## 前置条件

在开始配置前，请确保您已完成以下准备工作：

1. [订阅 Token Plan 套餐](https://cloud.tencent.com/document/product/1823/130119#bdc49d9b-f68d-4b79-bb5a-0aa694f2624a)。

2. [获取 API Key](https://cloud.tencent.com/document/product/1823/130119#ac6f544e-6de6-46b7-8709-36d777248b34)。

## 安装 Kilo Code 并使用 Token Plan

在 IDE 中搜索安装 Kilo Code 插件，下面分别以 JetBrains 和 VS Code 为例展示安装配置过程。

VSCode

JetBrains

1. 打开 VSCode，在扩展市场中搜索 Kilo Code 并安装。

![](https://qcloudimg.tencent-cloud.cn/image/document/c19c0fad114f86c9d8e72f4134a53fba.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/c19c0fad114f86c9d8e72f4134a53fba.png)

2. 单击 Kilo Code 右上角的**设置**按钮，选择 **Use your own API key**，并配置以下信息：

API Provider：**OpenAI Compatible**（Token Plan 接口兼容 OpenAI 标准）。

Base URL：`https://tokenhub.tencentmaas.com/plan/v3`。

API Key：Token Plan 专属的 API Key。

Model：根据您购买的套餐，填入 [套餐支持的模型 ID](https://cloud.tencent.com/document/product/1823/130119)。

如果您购买通用 Token Plan 套餐：请参见 [可用模型](https://cloud.tencent.com/document/product/1823/130060#b6fdbed0-897c-475d-a9a1-f9af922027c4)，选择具体的 **Model ID** 配置。

如果您购买 Hy Token Plan 套餐：请参见 [可用模型](https://cloud.tencent.com/document/product/1823/130060#b145766a-c747-42eb-89c2-a04463d20cc5)，选择具体的 **Model ID** 配置。

3. 配置完成后，单击 **Use custom**。您可以在输入框中输入需求，与模型进行交互。

![](https://qcloudimg.tencent-cloud.cn/image/document/002df8fe82c176eb31c8dd8fb0f875c9.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/002df8fe82c176eb31c8dd8fb0f875c9.png)

4. **模型切换：**您可以通过单击右上角的**设置**，在 **Model** 输入框搜索模型，选择 **Use custom** 进行切换。

1. 打开 JetBrains ，在扩展市场中搜索 Kilo Code 并安装，安装完成后重启 IDE 生效。

![](https://qcloudimg.tencent-cloud.cn/image/document/952113c3c2d7b8240e37ceac25a5baa3.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/952113c3c2d7b8240e37ceac25a5baa3.png)

2. 安装成功后，单击 Kilo Code 右侧图标，选择 **Bring my own Key** ，并配置以下信息，配置完成后，单击 **Use custom**。

API Provider：**OpenAI Compatible**（Token Plan 接口兼容 OpenAI 标准）。

Base URL：`https://tokenhub.tencentmaas.com/plan/v3`。

API Key：Token Plan 专属的 API Key。

Model：根据您购买的套餐，填入 [套餐支持的模型 ID](https://cloud.tencent.com/document/product/1823/130119)。

3. 在 Kilo Code 中使用，单击右上角的**设置**按钮，修改 Model 即可切换模型。
