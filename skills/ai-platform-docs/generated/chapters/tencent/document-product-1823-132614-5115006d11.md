# 查询模型列表

## 1. 接口描述

接口请求域名： tokenhub.tencentcloudapi.com 。

查询模型列表。

支持按模型 ID、模型名称、模型能力等条件筛选，支持分页和排序。

默认接口请求频率限制：20次/秒。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](/document/api/1823/132283)。

| 参数名称 | 必选 | 类型 | 描述 |
|---------|---------|---------|---------|
| Action | 是 | String | [公共参数](/document/api/1823/132283)，本接口取值：DescribeModelList。 |
| Version | 是 | String | [公共参数](/document/api/1823/132283)，本接口取值：2026-03-22。 |
| Region | 是 | String | [公共参数](/document/api/1823/132283)，详见产品支持的 [地域列表](/document/api/1823/132283#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| ModelIds.N | 否 | Array of String | <p>模型 ID 列表。最多支持 10 个，不支持重复。</p><br/>示例值：["hy3"] |
| ModelNames.N | 否 | Array of String | <p>模型名称列表。最多支持 10 个，不支持重复。</p><br/>示例值：["Hy3"] |
| ModelTypes.N | 否 | Array of String | <p>模型类型列表，筛选指定类型的模型。最多支持 10 个，不支持重复。取值：Text（文本）、Vision（视觉）、Multimodal（多模态）、Speech（语音）、Embedding（向量）。</p><br/>示例值：["Text"] |
| Tags.N | 否 | Array of String | <p>模型标签</p><br/>示例值：["深度思考"] |
| Limit | 否 | Integer | <p>返回数量，默认为 20，最大值为 100。</p><br/>示例值：20 |
| Offset | 否 | Integer | <p>偏移量，默认为 0。</p><br/>示例值：0 |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
|---------|---------|---------|
| ModelSet | Array of [Model](/document/api/1823/132279#Model) | <p>模型列表。</p>|
| TotalCount | Integer | <p>符合条件的模型总数。</p><br/>示例值：20|
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。|

## 4. 示例

### 示例1 DescribeModelList

查询模型列表，支持按模型 ID、模型名称、模型能力等条件筛选，支持分页和排序。

#### 输入示例

```
POST / HTTP/1.1
Host: tokenhub.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: DescribeModelList
<公共请求参数>

{
    "ModelIds": [
        "deepseek-v3.2"
    ]
}
```
