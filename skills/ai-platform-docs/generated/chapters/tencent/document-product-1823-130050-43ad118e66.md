# 产品简介

## 什么是大模型服务平台 TokenHub？

大模型服务平台 TokenHub 是一站式 AI 大模型服务平台，面向企业和开发者提供统一的模型接入能力。平台聚合了腾讯混元、DeepSeek、MiniMax、Kimi、智谱 GLM、通义千问等多家行业领先的大模型，覆盖文本生成、图片生成、视频生成、3D 生成等多种 AI 能力场景。

无论您是希望快速集成 AI 能力的应用开发者，还是需要稳定可靠的模型推理服务的企业用户，大模型服务平台 TokenHub 都为您提供了一站式解决方案：**统一的 API 接口**、**灵活的计费模式**、**完善的监控体系**以及**便捷的在线体验**，帮助您以较低的接入成本获得优质的大模型服务。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| [模型广场](https://cloud.tencent.com/document/product/1823/130084) | 汇聚多家厂商的主力大模型，提供多维度筛选（类型、服务商、体验状态）、模型对比和详细信息查看，帮助您快速选择合适的模型使用。平台提供了部分模型的免费体验包，供用户免费试用平台部分模型。 |
| [体验中心](https://cloud.tencent.com/document/product/1823/130085) | 在线体验大模型能力，支持文本对话（深度思考、流式输出）、图片生成（多风格、多尺寸）、视频生成以及 3D 生成，便于您在接入 API 之前充分评估模型效果。 |
| [在线推理](https://cloud.tencent.com/document/product/1823/130087) | 创建和管理模型的推理服务实例，获取专属 API Endpoint。支持按需选择计费方式——免费体验、按 Token 计费，满足从测试验证到生产部署的全阶段需求。 |
| [模型监控](https://cloud.tencent.com/document/product/1823/130089) | 展示模型、服务性能相关指标，如：TTFT (Time To First Token)、TPOT (Time Per Output Token)、RPM (Request Per Minute) 。 |
| [用量统计](https://cloud.tencent.com/document/product/1823/130088) | 展示模型、服务性能计费用量指标，如：输入 Token、输出 Token、TPM (Tokens Per Minute) 、插件调用次数。 |
| [API Key 管理](https://cloud.tencent.com/document/product/1823/130090) | 集中管理 API 访问密钥，支持精细化的权限控制（全部模型及服务或限定范围），便捷地启停切换和调用统计，保障接口调用的安全性与可控性。 |
| [Token Plan](https://cloud.tencent.com/document/product/1823/130059) | 是面向龙虾和编程场景设计的专属订阅套餐，覆盖腾讯混元、MiniMax、GLM、Kimi 等国产主流模型，兼容热门龙虾工具和主流编程工具，内设更多套餐档位可供选择。 |
| [Coding Plan](https://cloud.tencent.com/document/product/1823/130091) | 面向开发者的 AI 编程工具套餐，提供 Lite 和 Pro 两档选择，支持 OpenClaw、Cursor 等常见 AI 工具集成，提升开发效率。 |
