# 首页

官方来源：https://cloud.tencent.com/document/product/1823/140865
最近更新时间：2026-11-12 21:51:30

## 功能概述

首页汇聚了快速接入引导、核心资源概览与高频功能入口，帮助您完成从接入到调用的快速闭环：

通过“获取 API Key → 选择模型 → 获取接入代码”三步完成模型接入。

集中查看账户余额、订阅套餐、免费额度及 Token 消耗情况。

快速访问 API Key 管理、模型广场、开通管理、在线推理和帮助文档等高频功能。

## 页面结构

页面包含以下板块：

| 板块 | 说明 |
| --- | --- |
| 快速接入 | 选择 API Key、模型与接入方式，自动生成示例代码。支持按量付费接入与 Token Plan 接入。 |
| 用量看板 | 展示 Token 消耗走势及模型消耗 Top5。 |
| 资源概览 | 页面右侧展示账户余额、订阅套餐和免费额度。 |
| 功能入口 | 提供高频功能的快捷入口。 |
| 帮助文档 | 汇集高频查看的文档指南。 |

## 快速接入

在快速接入区域顶部，可切换**按量付费接入** / **Token Plan 接入**两种方式。单击右上角的收起按钮，可折叠快速接入区域。

### 按量付费接入

按以下三步完成接入：

| 步骤 | 说明 |
| --- | --- |
| 步骤1：获取 API Key | 调用推理服务时，需要使用 API Key 进行身份鉴权。  1. 从下拉列表中选择已有 API Key，或创建新的 API Key。  2. 选择 API Key 后，系统会自动执行以下操作：  2.1 在步骤2中筛选并展示该 API Key 可访问的模型。  2.2 将该 API Key 写入步骤3生成的示例代码。 |
| 步骤2：选择模型 | 模型列表仅展示步骤1所选 API Key 可访问的模型。  将鼠标悬停在模型上，可查看模型上下文长度、价格、免费额度余量及按量付费状态等信息。  **支持领取免费额度或开启按量付费**。  选择模型后，系统会将模型 ID 自动写入步骤3生成的示例代码。 |
| 步骤3：选择接入方式 | 支持 **API 接入**或 **AI 工具接入**。  **API 接入：**选择 API 接入后，右侧将根据步骤1和步骤2的选择自动生成示例代码：  支持切换 API 协议，例如 Chat Completions API。  支持切换代码语言，包括 cURL、Python 和 Node.js。  支持一键复制示例代码并发起调用。  **AI 工具接入：**选择 AI 工具接入后，可在右侧选择目标 AI 工具，并跳转至对应的接入指南。 |

### Token Plan 接入

未订阅套餐时，页面将展示个人版 / 企业版 Token Plan 的选购入口。单击对应套餐，可前往套餐页面查看并购买。

已订阅套餐时，页面展示最新订阅的套餐信息，并支持切换套餐。您可以按照以下步骤获取接入配置。

| 步骤 | 说明 |
| --- | --- |
| 步骤1：获取接入配置信息 | 1. **API Key**：展示当前所选套餐对应的 API Key，支持一键复制。企业版套餐仅展示 API Key 数量，可跳转至该套餐的 API Key 管理页面。  2. **Base URL / 完整 URL**：提供 OpenAI 和 Anthropic 协议格式，支持一键复制。  3. **可用模型 ID**：单击**速查列表**，查看当前套餐支持的模型。  4. **查看套餐详情**：单击后跳转至对应的套餐详情页。  5. **Token Plan 快速入门**：单击后跳转至个人版或企业版 Token Plan 快速入门文档。 |
| 步骤2：选择要接入的 AI 工具 | 在侧边窗口中选择目标 AI 工具，系统将跳转至对应的接入指南。 |

## 用量看板

| 板块 | 说明 |
| --- | --- |
| Token 消耗走势 | 默认展示近7日语言模型 Token 消耗趋势与当前总消耗量，支持切换时间范围。单击“查看更多”，可跳转至“用量统计”页面。 |
| 模型消耗 Top5 | 展示 Token 消耗量最高的5个模型及其 Token 总消耗量。 |

## 资源概览

页面右侧展示当前账户的核心资源信息：

| 板块 | 说明 |
| --- | --- |
| 账户余额 | 账户余额默认脱敏展示，单击显示图标可查看具体金额。  单击“充值”，可跳转至费用中心进行充值。 |
| 我的订阅 | 展示最新订阅套餐的套餐类型、剩余天数、可用模型与剩余额度。  支持切换套餐、查看详情（跳转至对应套餐页）。  套餐到期后，自动按个人版、企业版的顺序切换展示其他已购套餐；若无其他套餐，将重新展示开通引导。 |
| 免费额度 | 展示已领资源数 / 总数。单击后可领取免费资源包。  展示当前额度可用与即将到期的模型数量。单击后跳转至“开通管理”页面，并自动筛选对应模型。  “额度可用” = 模型状态：已上线、待下线、停止新购；领取状态：已领取；免费额度余量：有余量  “即将到期” = 模型状态：已上线、待下线、停止新购；领取状态：已领取；免费额度到期时间：即将到期  展示免费额度即将耗尽的模型。 |

## 功能入口

| 入口 | 说明 |
| --- | --- |
| API Key 管理 | 获取调用模型的身份凭证。 |
| 模型广场 | 查看平台最新、热门的模型。 |
| 开通管理 | 对平台全部模型及插件开启按量付费。 |
| 在线推理 | 支持更灵活的计费方式、分团队管理资源配额。 |
