# CC Switch

官方来源：https://cloud.tencent.com/document/product/1823/136605
最近更新时间：2026-08-21 17:56:52

CC Switch 是 Claude Code、Claude Desktop、Codex、Gemini CLI、Grok Build、OpenCode、OpenClaw 和 Hermes Agent 的全方位桌面管理工具，提供可视化界面来统一管理多个 AI 编程工具的供应商配置、API 密钥、MCP 服务器和 Skills，支持一键切换供应商。本文介绍如何在 CC Switch 中配置与使用腾讯云大模型 Token Plan 企业版。

## 前置条件

在开始配置前，确保您已完成以下准备工作：

1. [订阅 Token Plan 企业版套餐](https://cloud.tencent.com/document/product/1823/130660#9bad146b-59b9-463a-b9d9-4c21a823f8a5)。

2. 获取模型配置：

2.1 [专业套餐模型配置](https://cloud.tencent.com/document/product/1823/130659#cde5404a-a7bb-4d53-acba-6e3b1b6b8264)。

2.2 [轻享套餐模型配置](https://cloud.tencent.com/document/product/1823/131173#b18f9f4d-fad3-49a9-a38e-2ef38854fa19)。

3. [获取 API Key](https://cloud.tencent.com/document/product/1823/130660#c517dcb2-4a6d-4fbc-9793-a6fc05467143)。

4. 下载并安装 CC Switch，请参见 [CC Switch](https://ccswitch.io/download)。

## 配置 Token Plan 企业版

CC Switch 通过**自定义供应商**方式接入腾讯云 Token Plan。Token Plan 企业版同时提供 OpenAI 兼容和 Anthropic 兼容两种 API 协议，可根据目标工具选择对应协议配置。

### 方式一：Claude Code / Claude Desktop

1. 打开 CC Switch，在顶部工具栏选择 **Claude Code** 或 **Claude Desktop** 应用标签。

2. 单击右上角 **+** 按钮，打开**添加新供应商**面板。

3. 在**预设供应商**下拉框中选择**自定义**。

4. 填写以下信息：

| 配置项 | 填写说明 |
| --- | --- |
| 供应商名称 | 自定义设置，后续如需重命名则需要添加新的提供方，并删除旧的提供方。 |
| API Key | 填写您在腾讯云控制台获取的 API Key。 |
| API 格式、请求地址 | Anthropic messages（原生）：https://tokenhub.tencentmaas.com/plan/anthropic |
| 模型映射 | 展开**高级选项**，在模型映射中按需手动添加套餐支持的模型 （暂不支持**获取模型列表**功能），并配置**默认兜底模型**，支持模型请参见：  [专业套餐模型配置](https://cloud.tencent.com/document/product/1823/130659#cde5404a-a7bb-4d53-acba-6e3b1b6b8264)  [轻享套餐模型配置](https://cloud.tencent.com/document/product/1823/131173#b18f9f4d-fad3-49a9-a38e-2ef38854fa19) |

5. 请配置完成以上内容后，单击右下角**+ 添加**保存。

## 切换与生效

1. 在主界面或系统托盘中选择刚添加的供应商。

2. 单击**启用**或直接点击托盘菜单中的供应商名称。

3. **生效方式**：

**Claude Code**：支持热切换，无需重启终端。

**Codex / Gemini CLI / OpenCode / OpenClaw / Hermes**：需重启对应的终端或 CLI 工具。

4. 切换后，在对应工具中即可使用腾讯云 Token Plan 的模型。

## 使用 CC Switch

1. **启动 CC Switch**：安装后从应用列表启动，首次运行可导入现有 CLI 工具配置作为默认供应商。

2. **切换供应商**：在应用界面或系统托盘菜单中一键切换供应商，当前激活的供应商会高亮显示。

3. **管理 MCP 与 Skills**：通过左侧导航栏的 **MCP、Prompts、Skills** 面板统一管理所有工具的扩展配置。

4. **用量追踪**：在**用量**面板中查看跨供应商的 Token 消耗和费用趋势。

5. **代理与故障转移**：在**代理**面板中配置本地代理，实现格式转换、自动故障转移和健康监控。
