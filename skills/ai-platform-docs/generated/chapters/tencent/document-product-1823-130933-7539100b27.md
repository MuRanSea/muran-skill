# Cursor

官方来源：https://cloud.tencent.com/document/product/1823/130933
最近更新时间：2026-08-31 15:26:53

Cursor 是一款基于 VS Code 打造的以 AI 为核心的代码编辑器，它能够让您通过自然语言直接与代码库进行对话，从而实现代码的自动生成、智能重构和快速理解。本文以 Hy3 模型为例演示如何将模型接入到 Cursor 中使用。

## 安装 Cursor

官网下载安装包：通过 [Cursor 官网](https://cursor.com/) 下载并安装 Cursor。

**注意：**

由于 Cursor 的限制，只有订阅了 Cursor Pro 及以上版本套餐的用户才支持自定义配置模型。

## 获取 API Key

1. 进入[API Key 管理](https://console.cloud.tencent.com/tokenhub/apikey) 页面，单击**创建 API Key**。操作详情请参见 [创建 API Key](https://cloud.tencent.com/document/product/1823/130090#40882178-aaf2-48c9-8559-dffc083a79bc)。

**注意：**

在设置**可访问范围**时，如果选择“限定范围”，则需要确保勾选 **Hy3**。

2. 创建完成后，请您务必**复制并妥善保管 API Key**，在后续配置到工具的流程中将会使用该信息。

![](https://qcloudimg.tencent-cloud.cn/image/document/654b883e1243be9e2757c4eaebaaba29.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/654b883e1243be9e2757c4eaebaaba29.png)

## 配置 Cursor

1. 以 macOS 为例，Cursor 安装完成后，在 Cursor 中，单击右上角的 **Cursor Settings**；或键盘按下快捷键 `Cmd/Ctrl + Shift + P` ，输入 Cursor Settings 并按下回车。

![](https://qcloudimg.tencent-cloud.cn/image/document/fbfe834343b810584313b0d633b6ab87.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/fbfe834343b810584313b0d633b6ab87.png)

2. 在 Cursor Settings 左侧菜单栏，选择 **Models** 模块并进行配置。

![](https://qcloudimg.tencent-cloud.cn/image/document/9ea780e0e42b3e2b349b13ebe5565c43.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/9ea780e0e42b3e2b349b13ebe5565c43.png)

**Models** 模块的具体配置如下：

**OpenAI API Key**：填入您的 API Key。

**Override OpenAI Base URL**：`https://tokenhub.tencentmaas.com/v1`

![](https://qcloudimg.tencent-cloud.cn/image/document/88897e8f2656256981b1a8919ff46da9.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/88897e8f2656256981b1a8919ff46da9.png)

**Add Custom model**：手动输入模型 ID `hy3`。

**说明：**

需先点击 **View All Models**，才可看到 **Add Custom model 选项。**

![](https://qcloudimg.tencent-cloud.cn/image/document/849f87788ac0e907b9c3aca449476ba2.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/849f87788ac0e907b9c3aca449476ba2.png)

## 使用 Cursor

完成配置后，在 Cursor 的对话窗口找到 hy3 模型，即可对话使用。

![](https://qcloudimg.tencent-cloud.cn/image/document/4f57285c053b01f8feed7d339dd972c0.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/4f57285c053b01f8feed7d339dd972c0.png)

**注意：**

Hy3 默认为极速响应（no\_think）模式，受 Cursor 当前适配限制，暂不支持切换思考模式。
