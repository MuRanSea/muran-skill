# OpenCode

官方来源：https://cloud.tencent.com/document/product/1823/130664
最近更新时间：2026-09-14 10:35:05

OpenCode 是一款开源的 AI 编程代理工具，可以在终端、桌面客户端或 IDE 扩展中接入多种大模型使用，可帮助开发者进行代码分析、智能编码等多种任务。本文介绍如何在 OpenCode 中配置与使用腾讯云大模型 Token Plan 企业版。

## 前置条件

在开始配置前，确保您已完成以下准备工作：

1. [订阅 Token Plan 企业版套餐](https://cloud.tencent.com/document/product/1823/130660#9bad146b-59b9-463a-b9d9-4c21a823f8a5)。

2. 获取模型配置：

2.1 [专业套餐模型配置](https://cloud.tencent.com/document/product/1823/130659#cde5404a-a7bb-4d53-acba-6e3b1b6b8264)。

2.2 [轻享套餐模型配置](https://cloud.tencent.com/document/product/1823/131173#b18f9f4d-fad3-49a9-a38e-2ef38854fa19)。

3. [获取 API Key](https://cloud.tencent.com/document/product/1823/130660#c517dcb2-4a6d-4fbc-9793-a6fc05467143)。

4. 安装 OpenCode：请参见 [OpenCode 安装指南](https://opencode.ai/)，您可以选择桌面应用版下载；也可以在命令行中执行以下命令安装：

```bash
npm install -g opencode-ai
```

安装完成后，执行以下命令检查，输出版本号则表示安装成功：

```bash
opencode -v
```

## 配置模型

OpenCode 支持通过**桌面客户端**或**命令行配置文件**接入腾讯云 Token Plan 企业版，两种方式任选其一即可。

### 方式一：桌面客户端配置

1. 打开 OpenCode，在对话界面，单击**管理模型**打开模型设置界面。

![](https://qcloudimg.tencent-cloud.cn/image/document/a90a2f1c26339c745ac8c905c350d0b5.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/a90a2f1c26339c745ac8c905c350d0b5.png)

2. 在打开的弹窗中，单击**+ 连接提供商**，选择**自定义 OpenAI 兼容提供商**。

![](https://qcloudimg.tencent-cloud.cn/image/document/4b40605d2e3fa2f6e995c610a10251a9.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/4b40605d2e3fa2f6e995c610a10251a9.png)

3. 在打开的弹窗中，点击填写信息并提交：

提供商 ID：tencent

显示名称：Tencent TokenPlan

基础 URL：https://tokenhub.tencentmaas.com/plan/v3

API 密钥：填写您的 API Key。

model-id 和模型：根据您购买的套餐，填入套餐支持的模型 ID。

[专业套餐模型配置](https://cloud.tencent.com/document/product/1823/130659#cde5404a-a7bb-4d53-acba-6e3b1b6b8264)

[轻享套餐模型配置](https://cloud.tencent.com/document/product/1823/131173#b18f9f4d-fad3-49a9-a38e-2ef38854fa19)

4. 在对话窗口的模型列表中，找到并选定新配置的模型，即可进行对话使用。

![](https://qcloudimg.tencent-cloud.cn/image/document/effb0369cc73c4f2eec27ecb0cfb697c.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/effb0369cc73c4f2eec27ecb0cfb697c.png)
