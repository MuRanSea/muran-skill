# 常见问题

官方来源：https://cloud.tencent.com/document/product/1823/130104
最近更新时间：2026-09-03 17:58:00

### 大模型服务平台 TokenHub 支持哪些模型以及如何收费？

平台支持腾讯混元、优图及热门第三方模型，具体请参见 [模型列表](https://cloud.tencent.com/document/product/1823/130051)；模型的计费方式请参见 [计费方式](https://cloud.tencent.com/document/product/1823/130054)。

### 在哪里查看我的用量和费用账单？

您可在大模型服务平台 TokenHub 控制台的 [用量统计](https://cloud.tencent.com/document/product/1823/130088) 页面，按照模型、服务、API key 维度查看用量，也可在腾讯云 [费用中心](https://console.cloud.tencent.com/expense/bill/view?tab=overview) 查看账单明细。

### 什么是在线推理服务，为什么我要通过服务来调用模型？

在线推理服务用于管理模型的使用方式，包括计费方式、限流方式等。同一个模型可以创建多个在线推理服务，以区分不同业务场景的使用，因此即使是同一个模型也可能有多个服务，访问时需要通过服务 ID 来明确访问对象。

### TokenHub 会用我的数据来训练模型吗？

不会，我们非常重视您的隐私保护，不会将您的数据用于为您提供服务以外的场景，更不会用于训练。详情请参见 [TokenHub 隐私政策：个人信息的收集和使用](https://privacy.qq.com/document/preview/91d5fd3c98ce4468ae462ac59233bba2)。

### 如何访问模型服务？

平台支持 OpenAI API 协议的调用，您可以在每个模型的详情页参考示例代码完成调用。

### 访问模型服务有限流吗？

有，每个模型的限流阈值可能不同，您可以在模型的详情页查看每个模型的限流规则。

### 同一个模型创建的多个服务，计费是相互独立的吗？

是的，服务之间计费开启或关闭、计费方式相互不影响。
