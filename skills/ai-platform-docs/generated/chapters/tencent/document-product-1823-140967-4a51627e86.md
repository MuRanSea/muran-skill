# 查询 TokenPlan 个人版套餐详情

官方来源：https://cloud.tencent.com/document/product/1823/140967
最近更新时间：2026-11-17 03:04:26

## 1. 接口描述

接口请求域名： tokenhub.tencentcloudapi.com 。

查询个人版套餐详情。

查询指定产品类型的个人版 Token Plan 套餐状态、额度及续费信息。

默认接口请求频率限制：20次/秒。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](/document/api/1823/132283)。

| 参数名称 | 必选 | 类型 | 描述 |
|---------|---------|---------|---------|
| Action | 是 | String | [公共参数](/document/api/1823/132283)，本接口取值：DescribeTokenPlanPersonalPackage。 |
| Version | 是 | String | [公共参数](/document/api/1823/132283)，本接口取值：2026-03-22。 |
| Region | 是 | String | [公共参数](/document/api/1823/132283)，详见产品支持的 [地域列表](/document/api/1823/132283#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| ProductType | 是 | String | <p>产品类型。取值：personal（个人版）、personal-hunyuan（个人版混元）。</p><br/>示例值：personal |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
|---------|---------|---------|
| ProductType | String | <p>产品类型。</p><br/>示例值：personal|
| PackageStatus | String | <p>套餐状态。取值：active（生效中）、processing（处理中）、failed（创建失败）、isolated（隔离/欠费）、destroyed（已销毁）、used_up（额度用尽）、stopped（已停止）、unpurchased（未购买）。</p><br/>示例值：active|
| ResourceId | String | <p>计费资源ID</p><br/>示例值：pre-tp-gz-personal-202611020090241********|
| TotalCredits | String | <p>总额度。</p><br/>示例值：780|
| TotalUsed | String | <p>已使用额度。</p><br/>示例值：32.613264|
| CycleCredits | String | <p>单周期额度。</p><br/>示例值：780|
| TotalCycles | Integer | <p>总周期数。</p><br/>示例值：12|
| CurrentCycle | Integer | <p>当前周期序号。</p><br/>示例值：3|
| RemainCycles | Integer | <p>剩余周期数。</p><br/>示例值：9|
| StartTime | String | <p>套餐生效时间，ISO 8601 格式。</p><br/>示例值：2026-11-02 17:02:19|
| ExpireTime | String | <p>套餐过期时间，ISO 8601 格式。</p><br/>示例值：2027-03-15 10:30:00|
| PeriodEndDate | String | <p>当前周期到期日，ISO 8601 格式。</p><br/>示例值：2026-07-15|
| AutoRenewFlag | Integer | <p>自动续费标识。取值：0（未开启）、1（已开启）。</p><br/>示例值：0|
| OutputToken | Integer | <p>输出token数</p><p>单位：tokens</p><br/>示例值：123|
| InputToken | Integer | <p>输入token数</p><p>单位：token</p><br/>示例值：123|
| CacheToken | Integer | <p>缓存命中token数</p><p>单位：token</p><br/>示例值：12345|
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。|

```

Host: tokenhub.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: DescribeTokenPlanPersonalPackage
<公共请求参数>

{
    "ProductType": "personal"
}
```
