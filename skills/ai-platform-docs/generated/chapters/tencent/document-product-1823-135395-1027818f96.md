# TRAE

官方来源：https://cloud.tencent.com/document/product/1823/135395
最近更新时间：2026-08-04 10:37:03

TRAE IDE 是一款深度融合 AI 能力的开发工具，提供从代码编写、项目理解、调试运行到变更管理的完整开发体验。本文介绍如何在 TRAE 中配置与使用腾讯云大模型 Token Plan。

## 前置条件

在开始配置前，请确保您已完成以下准备工作：

1. [订阅 Token Plan 企业版套餐](https://cloud.tencent.com/document/product/1823/130660#9bad146b-59b9-463a-b9d9-4c21a823f8a5)。

2. 获取模型配置：

2.1 [专业套餐模型配置](https://cloud.tencent.com/document/product/1823/130659#cde5404a-a7bb-4d53-acba-6e3b1b6b8264)。

2.2 [轻享套餐模型配置](https://cloud.tencent.com/document/product/1823/131173#b18f9f4d-fad3-49a9-a38e-2ef38854fa19)。

3. [获取 API Key](https://cloud.tencent.com/document/product/1823/130660#c517dcb2-4a6d-4fbc-9793-a6fc05467143)。

## 操作步骤

### 步骤一：进入设置中心添加模型

1. 选择个人用户入口登录后，点击界面右上角的设置图标，进入设置中心。

2. 在左侧导航栏中，选择**模型**，进入模型管理页面。

3. 点击 **+ 添加模型**，打开添加模型窗口。

4. 在添加模型窗口，选择**自定义配置**。

![](https://qcloudimg.tencent-cloud.cn/image/document/3075ddce4b56efec4fbcba27167c63bc.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/3075ddce4b56efec4fbcba27167c63bc.png)

### 步骤三：使用 TRAE

1. 在 AI 对话输入框的右下角，单击当前模型名称；若显示为 **Auto**，点击**关闭**。

![](https://qcloudimg.tencent-cloud.cn/image/document/a0f04ea4d0a8e291e068b948d0847c96.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/a0f04ea4d0a8e291e068b948d0847c96.png)

2. 在模型列表中，找到自定义模型，并选择已经配置好的模型。

![](https://qcloudimg.tencent-cloud.cn/image/document/9089a3198afcc7bf56df8dd85b317416.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/9089a3198afcc7bf56df8dd85b317416.png)

3. 选定模型后，即可使用 TRAE 进行开发任务。

## 常见问题

### 提示模型无访问权限

错误示例：

```text
The current API Key is not authorized to access model <MODEL_ID>.
Model Provider Error Code: 403002
HTTP Status: 403
```

该错误表示请求已到达模型服务，但当前请求携带的 API Key 没有目标模型的访问权限。

请检查：

1. API Key 是否在正确的企业版套餐下创建。

2. API Key 的模型权限中是否包含报错信息里的模型 ID。

3. TRAE 中保存的 API Key 是否为完成授权的 Key。

4. TRAE 中的模型 ID 是否与控制台中的授权模型 ID 完全一致。

5. 当前对话是否仍在使用旧的自定义模型配置。

若修改了 API Key 权限或 TRAE 模型配置，建议重新选择模型并新建对话后再次尝试。

### 提示额度不足或请求频率受限

请进入对应企业版套餐的 API Key 管理页面，检查套餐剩余额度、Key 的总额度上限及 TPM 限制。专业套餐和轻享套餐的额度计算方式不同，请以对应套餐页面展示为准。
