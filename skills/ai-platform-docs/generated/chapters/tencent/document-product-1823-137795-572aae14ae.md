# 启用管理

官方来源：https://cloud.tencent.com/document/product/1823/137795
最近更新时间：2026-09-16 17:40:30

## 功能概述

启用管理用于集中查看和管理平台上所有需要**启用**后才能使用的模型与工具。支持以下操作：

查看当前账号可领取的免费体验模型、已领取的免费额度余量及到期时间。

支持单个领取或批量领取模型的免费体验包。

开启/关闭模型或工具的**按量付费**，支持单个操作或批量操作。

查看每个模型的限流配额。

## 页面结构

**说明：**

启用管理页的操作仅对**“在线推理”中的“默认”服务**生效——该服务在您领取免费体验包后由平台自动创建，与模型同名。它**不影响您在“在线推理”中手动创建的“自定义”推理服务**。如需为自定义服务配置计费、限流等策略，请前往 [在线推理](https://console.cloud.tencent.com/tokenhub/inference) 页面操作。

启用管理页包含两个 Tab：

| Tab | 管理对象 |
| --- | --- |
| **模型** | 平台支持的各类大模型（语言、视觉、多模态理解、向量、语音模型），管理其免费体验包与默认模型服务的按量付费。 |
| **工具** | 平台提供的各类工具能力，管理其启用状态与按量付费。 |

## 模型 Tab

顶部以卡片形式汇总当前账号的整体启用情况，分为两部分：

**免费体验包**

展示“可领取免费模型数量 / 全部数量”与“即将到期”数量。

提供**领取免费资源**按钮，点击后弹出批量领取弹窗，详情请参见 [新人免费体验包](https://cloud.tencent.com/document/product/1823/130053)。

**按量付费**

展示“已开启 / 未开启”按量付费的模型数量。

提供**一键开启、一键关闭**按钮，点击后弹出批量操作弹窗。

### 模型列表

列表支持按**语言模型 / 视觉模型 / 多模态理解模型 / 向量模型 / 语音模型**进行 Tab 筛选，分为“模型信息”、“免费体验”、“按量付费”三个板块。

**免费体验**

| 列 | 说明 |
| --- | --- |
| 领取状态 | **未领取**：可单击按钮领取该模型的免费体验包。  **已领取**：按钮置灰，不可重复领取。  **不支持**：该模型不支持免费体验，若要使用需开启按量计费。 |
| 免费额度余量 | 以**剩余百分比 + 进度条**展示已领取模型的免费额度剩余情况。  悬停进度条可查看明细：免费额度 tokens、已消耗 tokens、剩余 tokens、剩余比例 %。未领取 / 不支持的模型不显示。 |
| 免费额度到期时间 | 显示免费额度的到期时间。未领取 / 不支持的模型不显示。 |

**说明：**

**余量告警：**

· 当免费额度**剩余比例 < 20%** 时，余量进度条变为红色。

· 当有效期**剩余不足 7 天**时，到期时间列以红字提示“剩余 7 天”。

**按量付费**

| 列 | 说明 |
| --- | --- |
| 启用状态 | **未启用**：可单击按钮开启该模型的按量付费。  **已启用**：可单击按钮关闭该模型的按量付费。  开启或关闭均会弹出二次确认弹窗。 |
| 计费方式 | 当前支持**按 Token 计费**，对于未启用按量付费的模型，此列不显示信息。 |

**说明：**

若某模型**未领取**免费体验包，而您直接对其**开启按量付费**，平台会自动为您领取该模型的免费体验包，“领取状态”随之变为“已领取”。在调用时，平台会**优先消耗免费额度**，额度用尽后再按 Token 计费。

## 工具 Tab

用于管理平台各类工具的启用与计费：启用后即可调用，开启按量付费后按实际用量从账户余额扣费。

## 与在线推理的关系

启用管理页与 [在线推理](https://cloud.tencent.com/document/product/1823/130087) 页面协同工作，分工如下：

| 页面 | 职责 |
| --- | --- |
| **启用管理** | 模型维度的总览入口——看模型列表、领免费额度、开/关按量付费，帮助用户做轻量开通。 |
| **在线推理** | 服务维度的管理入口—— 一个模型下可以有多个推理服务(1 个同名默认服务 + n 个自定义服务)，可根据需要，创建自定义服务、配置限流、计费、API 调用。 |
