## 二、积分抵扣说明

### 1. 积分定义

积分是 Token Plan 个人版用于计量模型调用消耗的用量单位，购买价格为每 20 积分人民币 1 元。购买后按本页积分抵扣规则扣减相应模型调用用量。

### 2. 抵扣规则

单次请求的积分消耗 = `（未命中缓存输入 Token 数 × 未命中缓存输入价 + 输出 Token 数 × 输出价 + 缓存命中 Token 数 × 命中缓存输入价）÷ 1,000,000`

### 3. 两种计价方式

| 计价方式 | 适用模型 | 规则 |
| --- | --- | --- |
| 分 token 类型差异积分计价 | 2026 年 8 月 31 日及以后上架的模型 | 输入、输出、缓存命中分别计价；Lite / Standard / Pro / Max 各档位价格相同 |
| 按档位统一计价 | 2026 年 8 月 31 日前上架的模型（Auto、DeepSeek-V4-Flash 正式版 原厂直供、DeepSeek-V4-Pro 正式版 原厂直供、MiniMax-M2.7、GLM-5.2、Hy3 的 hy3 / hy3-preview） | 不区分输入、输出、缓存命中，所有 token 按同一价格计 |

### 4. 套餐抵扣顺序

通用 Token Plan 与 Hy Token Plan 共用相同的 API Key 及调用地址。平台将根据您请求中指定的 Model ID，自动匹配并扣减对应套餐包内的积分。

若同一 Model ID 同时被两个套餐支持，系统将优先从本计费周期内较早到期的套餐包中进行抵扣。

## 四、抵扣示例

### 示例 1：调用 hy3（按档位统一计价）

假设用户购买 Hy Token Plan Lite 套餐，某次调用 `hy3` 时产生：

未命中缓存输入：180,000 tokens

输出：10,000 tokens

缓存命中输入：820,000 tokens

Hy Token Plan Lite 档 hy3 不区分 token 类型，统一 16 积分/百万 tokens，因此：

积分消耗 = `（180,000 + 10,000 + 820,000）× 16 ÷ 1,000,000 = 16.16 积分`（约 0.81 元）

### 示例 2：调用 minimax-m3（输入长度 > 512k）

假设用户调用 `minimax-m3` 时，未命中缓存输入与缓存命中输入合计 1,000,000 tokens，超过 512k：

未命中缓存输入：100,000 tokens

输出：10,000 tokens

缓存命中输入：900,000 tokens

应按“输入 > 512k”档积分价抵扣：

积分消耗 = `（100,000 × 84 + 10,000 × 336 + 900,000 × 16.8）÷ 1,000,000 = 26.88 积分`（约 1.34 元）
