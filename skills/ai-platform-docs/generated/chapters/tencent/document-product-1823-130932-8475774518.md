# Cline

官方来源：https://cloud.tencent.com/document/product/1823/130932
最近更新时间：2026-09-03 17:58:00

Cline 是一款用于智能编程的 VSCode 插件，您可以集成腾讯 Hy3 模型，完成复杂的编程任务。本文以 Hy3 模型为例演示如何将模型接入到 Cline 中使用。

## 安装 Cline

打开 VSCode，在扩展市场搜索并安装 Cline，详情可参考 [Cline 官方安装指引](https://docs.cline.bot/getting-started/installing-cline)。

![](https://qcloudimg.tencent-cloud.cn/image/document/4a0807fa32c7b7416444e67a7c8bd405.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/4a0807fa32c7b7416444e67a7c8bd405.png)

## 获取 API Key

1. 进入[API Key 管理](https://console.cloud.tencent.com/tokenhub/apikey) 页面，单击**创建 API Key**。操作详情请参见 [创建 API Key](https://cloud.tencent.com/document/product/1823/130090#40882178-aaf2-48c9-8559-dffc083a79bc)。

**注意：**

在设置**可访问范围**时，如果选择“限定范围”，则需要确保勾选 **Hy3**。

2. 创建完成后，请您务必**复制并妥善保管 API Key**，在后续配置到工具的流程中将会使用该信息。

![](https://qcloudimg.tencent-cloud.cn/image/document/654b883e1243be9e2757c4eaebaaba29.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/654b883e1243be9e2757c4eaebaaba29.png)

## 配置 Cline

Cline 插件安装完成后，选择 **Bring my own API key**，并点击 **Continue** 以打开配置界面。如果您之前使用过 Cline，可单击主界面右上角的设置按钮进行配置。

![](https://qcloudimg.tencent-cloud.cn/image/document/6f3ed58a5b267bfa1918f0ea7834ee43.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/6f3ed58a5b267bfa1918f0ea7834ee43.png)

在配置界面中，配置以下信息：

**API Provider**：选择 `OpenAI Compatible`。

**Base URL**：`https://tokenhub.tencentmaas.com/v1`

**OpenAI Compatible API Key**：填写您的 API Key。

**Model ID**：填写 `hy3`

![](https://qcloudimg.tencent-cloud.cn/image/document/51f197b08dd1429cd0f2f1ad3d6c7c31.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/51f197b08dd1429cd0f2f1ad3d6c7c31.png)

## 使用 Cline

完成填写后，点击 **Continue** 即可完成配置。您可以在 Cline 中使用 Hy3 进行对话使用。

![](https://qcloudimg.tencent-cloud.cn/image/document/f04b060f8f7ecaf1afdbe9fafc1ae3c6.png)
