官方来源：https://cloud.tencent.com/document/product/1823/136110

## 1. 接口描述

接口请求域名： tokenhub.tencentcloudapi.com 。

查询指定模型的 TPM 和 QPM 配额上限。

默认接口请求频率限制：20次/秒。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](/document/api/1823/132283)。

| 参数名称 | 必选 | 类型 | 描述 |
|---------|---------|---------|---------|
| Action | 是 | String | [公共参数](/document/api/1823/132283)，本接口取值：DescribeModelQuota。 |
| Version | 是 | String | [公共参数](/document/api/1823/132283)，本接口取值：2026-03-22。 |
| Region | 是 | String | [公共参数](/document/api/1823/132283)，详见产品支持的 [地域列表](/document/api/1823/132283#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| ModelId | 是 | String | <p>模型 ID。可通过 DescribeModelList 获取。</p><br/>示例值：deepseek-v3.2 |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
|---------|---------|---------|
| ModelId | String | <p>模型 ID。</p><br/>示例值：deepseek-v3.2|
| TPMLimit | Integer | <p>TPM 限制（Tokens Per Minute）。模型无配额配置时不返回此字段。</p><br/>示例值：5000000|
| RPMLimit | Integer | <p>RPM 限制（Request Per Minute）。模型无配额配置时不返回此字段。</p><br/>示例值：601|
| TPMInputQuotaLimit | Integer | <p>TPM 保障包 input 配额</p><br/>示例值：20000000|
| TPMOutputQuotaLimit | Integer | <p>TPM 保障包 output 配额</p><br/>示例值：2000000|
| TPMInputReserveLimit | Integer | <p>TPM 预留 input 配额</p><br/>示例值：10000000|
| TPMOutputReserveLimit | Integer | <p>TPM 预留 output 配额</p><br/>示例值：1000000|
| TPMInputReservePostPaidLimit | Integer | <p>TPM 预留后付费 input 配额</p><br/>示例值：1000000|
| TPMOutputReservePostPaidLimit | Integer | <p>TPM 预留后付费 output 配额</p><br/>示例值：1000000|
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。|

## 4. 示例

### 示例1 正常请求

#### 输入示例

```
POST / HTTP/1.1
Host: tokenhub.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: DescribeModelQuota
<公共请求参数>

{
    "ModelId": "glm-5.2"
}
```

#### 输出示例

```json
{
    "Response": {
        "ModelId": "glm-5.2",
        "RPMLimit": 601,
        "RequestId": "cfa39e4e-d23a-409b-9488-1a4de77a16e2",
        "TPMInputQuotaLimit": 20000000,
        "TPMInputReserveLimit": 10000000,
        "TPMLimit": 5000000,
        "TPMOutputQuotaLimit": 2000000,
        "TPMOutputReserveLimit": 1000000
    }
}
```
