# 操作指南

官方来源：https://cloud.tencent.com/document/product/1823/130661
最近更新时间：2026-09-21 14:35:30

本文面向 Token Plan 企业版用户，介绍控制台的核心操作流程及限制，帮助您高效完成企业版的配置、管理与使用。

## API Key 管理

每个套餐具备独立的额度池、API Key 管理与用量统计。各套餐之间互不干扰，适合企业按部门、项目或业务线进行独立管理。核心能力包括：

按套餐额度规模创建多个 API Key 。

支持单个创建和批量创建 API Key，批量创建时可复用已有 Key 配置。

支持为每个 Key 设置独占配额（仅该 Key 可用的专属积分）和配额上限（该 Key 最多可使用的积分总量，含独占 + 共享部分），未设置独占配额的部分为共享池，各 Key 先到先得。

### 创建 API Key

1. 在 [我的套餐](https://console.cloud.tencent.com/tokenhub/tokenplan-e) 列表中，选择套餐，单击**管理 API Key**，进入 API Key 管理页面。

2. 单击**创建 API Key**，进入创建 API Key 页面。

3. 填写 API Key 配置，单击**确认**即可完成单个或者批量创建 API Key。

| **字段** | **是否必填** | **说明** | **举例** |
| --- | --- | --- | --- |
| 复用已有 Key | 否 | 下拉选择当前套餐下已创建的 Key，选中后自动回填该 Key 的配置（模型选择、独占额度、总额度上限、TPM 限制）到下方表单，便于快速创建同配置的新 Key。Key 名称不回填，需重新输入。  选择“不复用”则从空白开始配置。 | 不复用 |
| Key 名称 | 是 | 为 Key 自定义命名，便于识别用途和归属（如“员工001”、“客服 Bot”）。  命名规则：**只能包含中文、字母、数字、下划线、连字符，以中文或字母开头，以中文或字母或数字结尾，长度 2~50 个字符**。 | 员工001 |
| 创建数量 | 是 | 本次创建的 Key 数量，范围 1~10。系统会自动在 Key 名称后追加序号（如“员工001-1”、“员工001-2”）。批量创建时，所有 Key 共享相同的配置参数。 | 1 |
| 模型选择 | 是 | 选择该 Key 可以调用的模型，支持多选。可选模型包括 Auto 智能路由、GLM-5、Kimi-K2.5、MiniMax-M2.5。  未勾选的模型，该 Key 调用时将返回无权限错误。 | Auto 智能路由 |
| 独占额度 | 是 | 为该 Key 预留的专属额度（专业套餐单位：积分；轻享套餐单位：tokens），仅该 Key 可使用，其他 Key 无法占用。设为 0 表示不预留专属额度，该 Key 仅使用共享池。输入值不得超过当前可分配的独占额度（页面会提示“当前最大可配置 X 积分/tokens”）。 | 0 |
| 总额度上限 | 是 | 该 Key 在本计费周期内最多可使用的额度总量（独占 + 共享部分之和）。提供两种模式：  同套餐包上限（默认）：上限等于套餐包的总额度，即该 Key 理论上可使用整个额度池（实际受共享池竞争限制）。  自定义上限：手动输入一个具体数值，限制该 Key 的最大可用额度，适合需要严格控制单 Key 成本的场景。 | 同套餐包上限 |
| TPM 限制 | 是 | 该 Key 每分钟可处理的最大 Token 数（Tokens Per Minute），用于控制调用速率，防止单个 Key 过度占用带宽。提供两种模式：  同套餐包上限（默认）：TPM 上限与套餐包级别一致。  自定义上限：手动输入值，不可超过套餐包级 TPM 上限。 | 同套餐包上限 |

### **复制 API Key**

1. 在 [我的套餐](https://console.cloud.tencent.com/tokenhub/tokenplan-e) 列表中，选择套餐，单击**管理 API Key**，进入 API Key 管理页面。

2. 选择目标 API Key，选择**复制**即可获得 API Key。

### **编辑 API Key**

**编辑规则**

编辑次数配额：每个 API Key 的配置每日最多可修改 10 次。

编辑不影响密钥值：编辑操作仅修改 Key 的配置参数，API Key 密钥值不变，已集成的业务无需更换 Key。

修改立即生效：所有配置修改保存后即时生效，无需重启服务或重新分发 Key。

套餐失效时不可编辑：套餐处于“已失效”状态时，Key 配置不可编辑，需先续费恢复套餐后再操作。

**操作步骤**

1. 在[我的套餐](https://console.cloud.tencent.com/tokenhub/tokenplan-e)列表中，选择套餐，单击**管理 API Key**，进入 API Key 管理页面。

2. 单击**编辑**，进入编辑页面。

3. 您可以修改 API Key 的可用模型和配额限制。

**可配置字段说明：**

| **字段** | **说明** |
| --- | --- |
| 启用状态 | 控制该 Key 是否可用于 API 调用。  停用该 Key 后，所有使用该 Key 的请求将立即失效，返回 “API key is disabled by user” 错误；  重新开启后立即可重新调用。 |
| 模型选择 | 调整该 Key 可调用的模型范围。  新增模型后立即生效；  移除模型后，该 Key 调用被移除的模型将返回 “Model xxx is not authorized for this API key” 错误。 |
| 独占额度 | 调整该 Key 的专属预留额度。  调大：从共享池中划出更多额度锁定给该 Key；  调小：释放部分独占额度回共享池，供其他 Key 使用。  **说明：**  输入值不得超过当前可分配的独占额度。  独占额度不能调低至小于该 Key 已使用的独占部分。例如，Key 当前独占额度为 300 积分、已使用独占 200 积分，则最低只能调至 200 积分。 |
| 总额度上限 | 调整该 Key 的最大可用额度总量。可切换“同套餐包上限”或“自定义上限”。  自定义规则：  总额度上限必须高于该 Key 当前已用额度、独占额度。 |
| TPM 限制 | 调整该 Key 的每分钟 Token 处理上限。可切换“同套餐包上限”或“自定义上限”。自定义时，不可超过套餐包级 TPM 上限。 |

4. 单击**确定**完成修改**。**

### **重置 API Key**

1. 在 [我的套餐](https://console.cloud.tencent.com/tokenhub/tokenplan-e) 列表中，选择套餐，单击**管理 API Key**，进入 API Key 管理页面。

2. 单击**重置**，系统重新生成 API Key。

**注意：**

此操作将立即生成新的 API Key，旧 API Key 预计 5 分钟内失效并且无法恢复，请谨慎操作。

旧 API Key 失效后，所有使用旧 API Key 的工具/应用/服务将立即无法调用 API，请确保更新对应的配置。

### **删除 API Key**

1. 在 [我的套餐](https://console.cloud.tencent.com/tokenhub/tokenplan-e) 列表中，选择套餐，单击**管理 API Key**，进入 API Key 管理页面。

2. 单击**删除**，删除 API Key。

**注意：**

删除后旧 API Key 将失效并且无法恢复，所有使用旧 API Key 的工具/应用/服务将立即无法调用 API，请谨慎操作。

### 用量告警

套餐支持默认告警和自定义告警。

#### 系统默认用量告警

在套餐包余额达到 30%，15%，5% 时，会通过短信/邮件/站内信自动发送告警到主账号。

#### 自定义用量告警

您可通过[腾讯云可观测平台](https://console.cloud.tencent.com/monitor/alarm/config/policy?monitorType=MT_QCE)配置定义用量告警。

1. 在**告警管理 > 告警配置**中，选择**告警策略**页签。

2. 单击 [新建策略](https://console.cloud.tencent.com/monitor/alarm/config/policy/create?monitorType=MT_QCE)，选择**自定义告警策略**。

3.1 **策略类型**：选择**大模型服务平台 TokenHub** > **Token Plan 企业版**，选择**套餐**/**API Key** > 用量指标，即可配置某个套餐或者 API Key 的用量告警。

## 套餐管理

### 套餐续费

#### 1. 续费规则

**警告：**

请您在套餐到期前完成续费操作，**套餐到期后将无法进行续费**，套餐将失效，**API Key 也会失效**。

套餐续费是指续订下一订阅月的套餐，续费完成后，新的额度将在下个订阅月生效：

若本订阅月额度未用尽：剩余额度可继续使用至本订阅月结束，下个订阅月自动重置为新的额度。

若本订阅月额度已用尽：**续费操作不会重置本订阅月的额度**，新的额度需等待下个订阅月生效。

#### 2. 续费示例

**示例如下：**用户本订阅月（2026-03-23～2026-04-23）积分总额度 1 亿。用户为下个订阅月（2026-04-23～2026-05-23）续费，不同场景可用额度说明如下：

| **场景** | **本月额度消耗情况** | **可用额度说明** |
| --- | --- | --- |
| 本订阅月额度未用尽 | 假如本订阅月（2026-03-23～2026-04-23）已用 0.5 亿。 | 本订阅月（2026-03-23～2026-04-23）剩余可用额度 0.5 亿。  下个订阅月（2026-04-23～2026-05-23）可用额度 1 亿。 |
| 若本订阅月额度已用尽 | 假如本订阅月（2026-03-23～2026-04-23）已用 1 亿。 | 本订阅月（2026-03-23～2026-04-23）剩余可用额度 0。  下个订阅月（2026-04-23～2026-05-23）可用额度 1 亿。 |

#### 3. 续费方式

Token Plan 企业版支持**手动续费**和**自动续费**两种方式。具体说明如下：

**手动续费**：套餐自购买到到期前，您可以在任意时间为套餐手动续费，以延长套餐的使用时间。

在 [Token Plan 企业版](https://console.cloud.tencent.com/tokenhub/tokenplan-e) 页面，选择您的套餐，进入套餐详情页面，单击**续费。**

确认续费周期（1 个月），单击**续费**，即可完成操作。

**自动续费**：套餐开启自动续费后，在账户余额充足的情况下，套餐到期前一天会自动执行续费。

在 [Token Plan 企业版](https://console.cloud.tencent.com/tokenhub/tokenplan-e) 页面，选择您的套餐，进入套餐详情页面，单击**开启**自动续费**。**

### 套餐升配

**说明：**

Token Plan 企业版套餐仅支持套餐升级，**不支持套餐降级操作**。

#### **升配规则**

升级套餐的费用 = 新套餐费用 − 原套餐费用（补差价）。

升级后套餐额度剩余量 = 新套餐总额度 - 原套餐额度使用量。

套餐升级成功后：

套餐的 API Key 与原套餐保持一致。

套餐到期时间跟原套餐保持一样，例如：原套餐（50 万积分）是 2026-05-23 到期，升级到（100 万积分）也是 2026-05-23 到期。

#### 操作步骤

在 [Token Plan 企业版](https://console.cloud.tencent.com/tokenhub/tokenplan-e) 页面，选择您的套餐，进入套餐详情页面，单击**升配**，选择目标规格，进行套餐升级。

### 套餐重新开通

过期套餐支持重新开通，重新开通时，套餐规格保持不变。套餐恢复后，套餐内已创建的 API Key 均可正常使用，无需重新创建。

**操作步骤：**

1. 在 [我的套餐](https://console.cloud.tencent.com/tokenhub/tokenplan-e) 列表中，选择套餐，单击**重新开通**。

2. 进入重新开通套餐弹窗，点击**重新开通**按钮进行支付，即可开通套餐。

## 性能监控

套餐支持查看模型调用性能监控和告警。

1. 查看监控：在 [我的套餐](https://console.cloud.tencent.com/tokenhub/tokenplan-e) 列表中，选择套餐 > 单击套餐名称，进入套餐详情页面 > 单击**监控**，查看各模型的请求并发、Token 吞吐、响应延迟等核心指标。

2. 配置告警：通过 [腾讯云可观测平台](https://console.cloud.tencent.com/monitor/alarm/config/policy?monitorType=MT_QCE) 配置定义用量告警。

2.1 在**告警管理 > 告警配置**中，选择**告警策略**页签。

2.2 单击 [新建策略](https://console.cloud.tencent.com/monitor/alarm/config/policy/create?monitorType=MT_QCE)，选择**自定义告警策略**。

2.3 **新建告警策略 > 配置告警规则。**

2.3.1 **策略类型**：选择**大模型服务平台 TokenHub** > **Token Plan 企业版**，选择**套餐**/**API Key** > 性能指标，即可配置某个套餐或者 API Key 的性能告警。

2.3.2 **告警对象**：根据套餐/API Key 维度，选择需要告警具体的套餐/API Key。

2.3.3 **触发条件：**选择手动配置，配置告警指标和触发逻辑。

2.4 **配置告警通知**：可以选择已用通知模板，或者新建通知模板，配置通知对象、周期、时段、渠道等。
