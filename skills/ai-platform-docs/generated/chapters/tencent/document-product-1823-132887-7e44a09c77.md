# 创建术语库

官方来源：https://cloud.tencent.com/document/product/1823/132887
最近更新时间：2026-07-31 03:02:56

## 1. 接口描述

接口请求域名： tokenhub.tencentcloudapi.com 。

创建术语库。(单个用户默认最多可以创建50个术语库)

在当前应用下创建一个新的翻译术语库，用于自定义源语言到目标语言的术语映射。创建成功后返回术语库 ID，可通过该 ID 进一步管理术语条目。

默认接口请求频率限制：20次/秒。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](/document/api/1823/132283)。

| 参数名称 | 必选 | 类型 | 描述 |
|---------|---------|---------|---------|
| Action | 是 | String | [公共参数](/document/api/1823/132283)，本接口取值：CreateGlossary。 |
| Version | 是 | String | [公共参数](/document/api/1823/132283)，本接口取值：2026-03-22。 |
| Region | 是 | String | [公共参数](/document/api/1823/132283)，详见产品支持的 [地域列表](/document/api/1823/132283#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| Name | 是 | String | 术语库名称。最大 50 字符。<br/>示例值：my-glossary |
| Source | 是 | String | 源语言代码。最大 16 字符。例如：zh（中文）、en（英文）。<br/>示例值：zh |
| Target | 是 | String | 目标语言代码。最大 16 字符。例如：zh（中文）、en（英文）。<br/>示例值：en |
| Description | 否 | String | 术语库描述。最大 255 字符。<br/>示例值：test glossary |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
|---------|---------|---------|
| GlossaryId | String | 术语库 ID。<br/>示例值：glossary-a1b2c3d4|
| Name | String | 术语库名称。<br/>示例值：my-glossary|
| CreatedAt | Integer | 创建时间。Unix 时间戳（毫秒）。<br/>示例值：1717000000000|
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。|

## 4. 示例

### 示例1 CreateGlossary

#### 输入示例

```
POST / HTTP/1.1
Host: tokenhub.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: CreateGlossary
<公共请求参数>

{
    "Name": "my-glossary",
    "Source": "zh",
    "Target": "en",
    "Description": "test glossary"
}
```

#### 输出示例

```json
{
    "Response": {
        "CreatedAt": 1779967663,
        "GlossaryId": "14cf0f58e4f165ee414cbf43217650f2",
        "Name": "my-glossary",
        "RequestId": "46a9c46b-698b-42e8-9cc6-8a5604eeed01"
    }
}
```
