# Kilo CLI

官方来源：https://cloud.tencent.com/document/product/1823/130669
最近更新时间：2026-09-29 14:11:34

Kilo CLI 是 Kilo Code 全栈式 AI 编程代理平台的命令行形态。本文介绍如何在 Kilo CLI 中配置与使用腾讯云大模型 Token Plan 企业版。

## 前置条件

在开始配置前，确保您已完成以下准备工作：

[订阅 Token Plan 企业版套餐](https://cloud.tencent.com/document/product/1823/130660#9bad146b-59b9-463a-b9d9-4c21a823f8a5)。

获取模型配置：

[专业套餐模型配置](https://cloud.tencent.com/document/product/1823/130659#cde5404a-a7bb-4d53-acba-6e3b1b6b8264)；

[轻享套餐模型配置](https://cloud.tencent.com/document/product/1823/131173#b18f9f4d-fad3-49a9-a38e-2ef38854fa19)。

[获取 API Key](https://cloud.tencent.com/document/product/1823/130660#c517dcb2-4a6d-4fbc-9793-a6fc05467143)。

## 安装 Kilo CLI

在终端执行如下命令安装 Kilo CLI。

**说明：**

Kilo CLI 通过 npm 安装，需先安装 Node.js（建议 ≥ 18）。如未安装，请访问 [Node.js 官网](https://nodejs.org/) 下载 LTS 版本。

```bash
npm install -g @kilocode/cli
```

安装完成后，您可以执行如下命令检查，输出版本号则表示安装成功。

```bash
kilo --version
```

macOS/Linux：`~/.config/kilo/config.json`。

## 使用 Kilo CLI

配置完成后执行如下命令启动 Kilo CLI。

```bash
kilo
```

输入`/models`，选择 **Tencent Token Plan Enterprise** 分组下的模型。
