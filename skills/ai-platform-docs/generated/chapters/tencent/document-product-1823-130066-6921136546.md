# Lighthouse OpenClaw

官方来源：https://cloud.tencent.com/document/product/1823/130066
最近更新时间：2026-08-07 17:32:30

腾讯云轻量应用服务器（Lighthouse）上部署的 OpenClaw（Clawdbot）官方一键部署镜像。本文介绍如何在 Lighthouse OpenClaw 中配置与使用腾讯云大模型 Token Plan。

## 前置条件

在开始配置前，请确保您已完成以下准备工作：

1. [订阅 Token Plan 套餐](https://cloud.tencent.com/document/product/1823/130119#bdc49d9b-f68d-4b79-bb5a-0aa694f2624a)。

2. [获取 API Key](https://cloud.tencent.com/document/product/1823/130119#ac6f544e-6de6-46b7-8709-36d777248b34)。

## 操作步骤

参考 [腾讯云轻量应用服务器 OpenClaw 部署](https://cloud.tencent.com/developer/article/2624003) 指引，完成服务器的购买、通道和技能的配置。其中模型配置可以参考下文指引，选用**腾讯云 Token Plan** 的模型服务：

### 步骤一：进入应用管理

登录 [腾讯云轻量应用服务器控制台](https://console.cloud.tencent.com/lighthouse)，找到已部署 OpenClaw 的实例，单击实例名称进入实例详情页面后，选择**应用管理**页签。

### 步骤二：配置模型

请根据账号情况选择对应的配置方式：

#### 场景一：您的账号同时购买 Token Plan 套餐和腾讯云轻量应用服务器

在**应用管理**界面中找到**模型（Models）**配置区域，参考下文配置 Token Plan 模型：

1. 根据已购买的套餐类型，选择**通用 Token Plan** 或 **Hy Token Plan**。

![](https://qcloudimg.tencent-cloud.cn/image/document/ccda947815b26cd58463a80267cc01ad.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/ccda947815b26cd58463a80267cc01ad.png)

2. 选择具体的模型后，单击**一键添加为默认**。

![](https://qcloudimg.tencent-cloud.cn/image/document/ae3e946b31a1271e6a522ebbfc66e77b.png)

![](https://qcloudimg.tencent-cloud.cn/image/document/ae3e946b31a1271e6a522ebbfc66e77b.png)

#### **场景二：您的 Token Plan 套餐和腾讯云轻量应用服务器不在同一个账号**

需通过自定义模型方式配置 Token Plan 模型。在**应用管理**界面中找到**模型（Models）**配置区域，按以下步骤操作：

1. 在**模型供应商**列表选择**自定义模型**。

2. 在 **JSON 输入**区域填入对应模型的配置信息。JSON 配置信息详情请参见 [各模型 JSON 配置信息](https://cloud.tencent.com/document/product/1823/130066#6d654dbd-79cb-46e9-8f62-b2e0cf15e21a)。

![](https://qcloudimg.tencent-cloud.cn/image/document/ae792c76237ab268e56f500dc12535f5.png)

## **各模型 JSON 配置信息**

**注意：**

请您将 `$your-api-key` 字段替换为您购买 Token Plan 后获取的专属 API Key。每个模型需单独添加一次。

通用 Token Plan

Hy Token Plan

### **配置 Auto**

```json
{
  "provider": "tencent-token-plan",
  "base_url": "https://api.lkeap.cloud.tencent.com/plan/v3",
  "api": "openai-completions",
  "api_key": "$your-api-key",
  "model": {
    "id": "tc-code-latest",
    "name": "Auto"
  }
}
```
