# 查询 Token Plan 套餐详情

官方来源：https://cloud.tencent.com/document/product/1823/132270
最近更新时间：2026-05-29 10:58:19

## 1. 接口描述

接口请求域名： tokenhub.tencentcloudapi.com 。

查询 TokenPlan 套餐详情。

返回套餐基本信息及额度中心主额度包余量。

默认接口请求频率限制：20次/秒。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](/document/api/1823/132283)。

| 参数名称 | 必选 | 类型 | 描述 |
|---------|---------|---------|---------|
| Action | 是 | String | [公共参数](/document/api/1823/132283)，本接口取值：DescribeTokenPlan。 |
| Version | 是 | String | [公共参数](/document/api/1823/132283)，本接口取值：2026-03-22。 |
| Region | 是 | String | [公共参数](/document/api/1823/132283)，详见产品支持的 [地域列表](/document/api/1823/132283#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| TeamId | 是 | String | 套餐 ID。可通过 DescribeTokenPlanList 接口获取。<br/>示例值：tp-ent-abcdefgh |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
|---------|---------|---------|
| TeamId | String | 套餐 ID。<br/>示例值：tp-ent-abcdefgh|
| Name | String | 套餐名称。<br/>示例值：生产环境套餐|
| AppId | String | 主账号 APP ID。<br/>示例值：1300000001|
| Uin | String | 主账号 UIN。<br/>示例值：100000000001|
| Status | String | 状态。取值：enable（启用）、disable（停用）。<br/>示例值：enable|
| StopReason | String | 关停原因。取值：取值：NORMAL（套餐正常）、ISOLATED（隔离/欠费）、FROZEN（冻结）、EXHAUSTED（额度耗尽）、DESTROYED（已销毁）。<br/>示例值：none|
| ApiKeyMax | Integer | 可创建APIKey 上限。<br/>示例值：1000|
| PrepayResourceID | String | 云计费预付费资源包 ID。<br/>示例值：pre-abc12345|
| Creator | String | 创建人，子账号创建的套餐将展示子账号UIN。<br/>示例值：100000000002|
| CreatedAt | [Timestamp ISO8601](/document/api/1823/132287) | 创建时间。<br/>示例值：2026-04-01T00:00:00Z|
| UpdatedAt | [Timestamp ISO8601](/document/api/1823/132287) | 更新时间。<br/>示例值：2026-04-01T00:00:00Z|
| PackageInfo | [TokenPlanPackageInfo](/document/api/1823/132279#TokenPlanPackageInfo) | 套餐包基本信息|
| AutoRenewFlag | Integer | 自动续费标识。取值：0（手动续费）、1（自动续费）、2（明确不自动续费）。未绑定预付费资源时不返回。<br/>示例值：1|
| ApiKeyCount | Integer | 当前已创建的 API Key 数量<br/>示例值：5|
| TokenSummary | [TokenSummary](/document/api/1823/132279#TokenSummary) | 当前周期 Token 用量明细|
| ProductType | String | 套餐类型。取值：enterprise（企业版专业套餐）、enterprise-auto（企业版轻享套餐）<br/>示例值：enterprise|
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。|

## 4. 示例

### 示例1 DescribeTokenPlan

测试查询 TokenPlan 套餐详情

#### 输入示例

```
POST / HTTP/1.1
Host: tokenhub.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: DescribeTokenPlan
<公共请求参数>

{
    "TeamId": "team-1a2b3c4d"
}
```

