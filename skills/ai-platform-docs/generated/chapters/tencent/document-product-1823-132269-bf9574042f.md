# 查询 Token Plan 套餐列表

官方来源：https://cloud.tencent.com/document/product/1823/132269
最近更新时间：2026-05-29 10:58:18

## 1. 接口描述

接口请求域名： tokenhub.tencentcloudapi.com 。

查询 TokenPlan 套餐列表。

支持分页、过滤和排序。主账号可查看全部，子账号仅可查看自己创建的。返回结果包含每个套餐关联的额度中心主额度包详情。

默认接口请求频率限制：20次/秒。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](/document/api/1823/132283)。

| 参数名称 | 必选 | 类型 | 描述 |
|---------|---------|---------|---------|
| Action | 是 | String | [公共参数](/document/api/1823/132283)，本接口取值：DescribeTokenPlanList。 |
| Version | 是 | String | [公共参数](/document/api/1823/132283)，本接口取值：2026-03-22。 |
| Region | 是 | String | [公共参数](/document/api/1823/132283)，详见产品支持的 [地域列表](/document/api/1823/132283#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| Offset | 否 | Integer | 分页查询偏移量，默认为 0。<br/>示例值：0 |
| Limit | 否 | Integer | 分页查询返回数量，默认为 20，最大值为 100。<br/>示例值：20 |
| Filters.N | 否 | Array of [RequestFilter](/document/api/1823/132279#RequestFilter) | 分页查询过滤条件列表。支持的过滤字段：TeamId（套餐 ID）、Name（套餐名称）、StopReason（关停原因）、ProductType（套餐类型）。 |
| Sorts.N | 否 | Array of [RequestSort](/document/api/1823/132279#RequestSort) | 排序条件列表。支持的排序字段：CreatedAt（创建时间）、UpdatedAt（更新时间）。默认按 CreatedAt 降序。 |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
|---------|---------|---------|
| TokenPlanSet | Array of [TokenPlanListItem](/document/api/1823/132279#TokenPlanListItem) | 套餐列表。|
| TotalCount | Integer | 套餐总数量。<br/>示例值：1|
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。|
