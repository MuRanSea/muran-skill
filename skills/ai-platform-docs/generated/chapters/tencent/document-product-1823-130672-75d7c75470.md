# AutoClaw

官方来源：https://cloud.tencent.com/document/product/1823/130672
最近更新时间：2026-06-26 18:12:01

AutoClaw 是智谱 AI 推出的零门槛本地 AI 智能体，支持 OpenClaw 核心执行能力，主打普通用户轻松上手。本文介绍如何在 AutoClaw 中配置与使用腾讯云大模型 Token Plan 企业版。

AutoClaw 支持通过“**自定义模型**”功能接入任何兼容 OpenAI 协议的第三方模型服务。通过以下配置，可将腾讯云 Token Plan 企业版的模型接入 AutoClaw。

## 前置条件

在开始配置前，确保您已完成以下准备工作：

1. [订阅 Token Plan 企业版套餐](https://cloud.tencent.com/document/product/1823/130660#9bad146b-59b9-463a-b9d9-4c21a823f8a5)。

2. [获取模型配置](https://cloud.tencent.com/document/product/1823/130660#e1afdc13-96a1-46ac-b648-fa94ce3a3e7f)。

3. [获取 API Key](https://cloud.tencent.com/document/product/1823/130660#c517dcb2-4a6d-4fbc-9793-a6fc05467143)。

## 操作步骤

### 步骤一：打开 AutoClaw 应用

启动 AutoClaw 应用，进入主界面。

![](https://qcloudimg.tencent-cloud.cn/image/document/4f923a822d34c3935345f74e978ca4f6.png)

### 步骤二：进入设置界面

单击左下角**反馈**按钮旁的**设置**，进入设置界面。

![](https://qcloudimg.tencent-cloud.cn/image/document/512f0799c4257710daf01f4116da4811.png)

### 步骤三：进入模型配置页面

在设置界面的左侧导航栏中，单击**模型与 API**，进入模型配置页面。页面会显示**内置模型**和**自定义模型**两个区域。

### 步骤四：添加自定义模型

单击右侧**添加自定义模型**，在弹出的**添加模型**对话框中，选择**服务商**为**自定义**，依次填写模型 ID、API Key、Base URL 等信息：

![](https://qcloudimg.tencent-cloud.cn/image/document/73a7a80f3d1f39c0dd5ba2e616486abe.png)

#### **配置 Auto**

| 参数 | 值 |
| --- | --- |
| **服务商** | 选择**自定义** |
| **模型 ID** | `auto` |
| **显示名称** | Auto |
| **API Key** | 参见 [获取 API Key](https://cloud.tencent.com/document/product/1823/130660#c517dcb2-4a6d-4fbc-9793-a6fc05467143) |
| **API 协议** | 选择 **OpenAI** |
| **Base URL** | `https://tokenhub.tencentmaas.com/plan/v3` |

### 步骤五：连通测试

填写完成后，单击**连通测试**，系统会按当前配置真实发起一次请求，验证接口是否可用。当状态显示为**测试成功**时，说明配置正确。

![image_1774007166635.png](https://qcloudimg.tencent-cloud.cn/image/document/4f2c1bbac9d7efcda739c9b3084ba572.png)

### 步骤六：添加模型

连通测试成功后，单击**添加**，完成模型的添加。重复第四步至第六步，逐一添加其余模型。

### 步骤七：设为默认模型

返回**模型与 API** 页面，在**自定义模型**列表中找到刚添加的模型，单击**设为默认**，即可将该模型设为默认使用的模型。

![image_1774007288519.png](https://qcloudimg.tencent-cloud.cn/image/document/af10f27f25e3908af6287da5c4754384.png)
