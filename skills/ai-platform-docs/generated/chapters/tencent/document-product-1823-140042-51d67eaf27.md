# Token Plan 个人版限时优惠活动

官方来源：https://cloud.tencent.com/document/product/1823/140042
最近更新时间：2026-10-30 14:25:30

本文介绍 Token Plan 个人版当前及往期的限时优惠活动。活动期间调用指定模型，按活动积分价抵扣，到点自动生效，无需申请。

**活动对象**：所有 Token Plan 个人版用户

**说明：**

1 元可兑换 20 积分，括号内金额为按此比例折算的参考值。

活动仅调整所列模型在活动期间的积分抵扣价，不改变其他模型、套餐额度刷新规则与使用限制。

活动结束后，恢复 [Token Plan 个人版积分用量抵扣规则](https://cloud.tencent.com/document/product/1823/133811) 中 [积分抵扣价](https://cloud.tencent.com/document/product/1823/133811#1cfc0817-0e3b-4f79-95f8-ce7ee5eb976c) 所列原价。跨活动周期的请求，按请求发起时间对应的积分价抵扣。

除另有说明外，活动优惠不与其他优惠叠加。

腾讯云可以根据运营情况对活动进行变更或调整，包括但不限于活动规则、活动有效期等，请以页面最新内容为准。
