# Claude Code

官方来源：https://cloud.tencent.com/document/product/1823/130070
最近更新时间：2026-09-29 14:11:34

Claude Code 是一款 AI 编程助手，支持通过 Anthropic API 接入模型，帮助开发者快速编写、调试和管理代码。

Token Plan 中的模型支持 Anthropic API 兼容接口，可以通过 Claude Code 调用。

## 前置条件

在开始配置前，请确保您已完成以下准备工作：

1. [订阅 Token Plan 套餐](https://cloud.tencent.com/document/product/1823/130119#bdc49d9b-f68d-4b79-bb5a-0aa694f2624a)。

2. [获取 API Key](https://cloud.tencent.com/document/product/1823/130119#ac6f544e-6de6-46b7-8709-36d777248b34)。

## 安装 Claude Code

**注意：**

在 Windows 上使用 Claude Code，需要提前安装 [WSL](https://learn.microsoft.com/en-us/windows/wsl/install) 或 [Git for Windows](https://git-scm.com/install/windows)。

执行如下命令安装 Claude Code，更多操作可参考 [Claude Code 安装指引](https://code.claude.com/docs/zh-CN/quickstart#%E6%AD%A5%E9%AA%A4-1%EF%BC%9A%E5%AE%89%E8%A3%85-claude-code)。

```bash
npm install -g @anthropic-ai/claude-code
```

安装结束后，执行以下命令查看安装结果，若显示版本号则安装成功。

```bash
claude --version
```

## 配置 Token Plan

在 Claude Code 中接入 Token Plan，需要配置以下信息：

ANTHROPIC\_BASE\_URL：设置为 `https://api.lkeap.cloud.tencent.com/plan/anthropic`。

ANTHROPIC\_AUTH\_TOKEN：设置为 Token Plan 专属 API Key。

ANTHROPIC\_MODEL：设置为 Token Plan 支持的模型。

### 配置文件路径

编辑或新增 settings.json 文件。不同系统配置文件路径不同，具体如下：

MacOS / Linux：`~/.claude/settings.json`。

Windows：`C:\\Users\\<用户名>\\.claude\\settings.json`。

若 settings.json 文件不存在，可使用文本编辑器（如 VSCode、记事本等）手动创建，或在终端中执行以下命令创建：

```bash

# MacOS/Linux
mkdir -p ~/.claude && touch ~/.claude/settings.json
﻿
# Windows（PowerShell）
New-Item -ItemType Directory -Force -Path "$HOME\\.claude" | Out-Null; New-Item -ItemType File -Force -Path "$HOME\\.claude\\settings.json" | Out-Null
```

### 方式一：配置单个模型

在 settings.json 文件上修改或添加的配置信息如下：

```json
{
    "env": {
        "ANTHROPIC_AUTH_TOKEN": "<USER_API_KEY>",
        "ANTHROPIC_BASE_URL": "https://api.lkeap.cloud.tencent.com/plan/anthropic",
        "ANTHROPIC_MODEL": "<Model_ID>"
    }
}
```

<USER\_API\_KEY>：替换为您 Token Plan 套餐的 API Key。

<Model\_ID>：根据您购买的套餐，填入 [套餐支持的模型 ID](https://cloud.tencent.com/document/product/1823/130119)。

如果您购买通用 Token Plan 套餐：请参见 [可用模型](https://cloud.tencent.com/document/product/1823/130060#b6fdbed0-897c-475d-a9a1-f9af922027c4)，选择具体的 **Model ID** 配置。

如果您购买 Hy Token Plan 套餐：请参见 [可用模型](https://cloud.tencent.com/document/product/1823/130060#b145766a-c747-42eb-89c2-a04463d20cc5)，选择具体的 **Model ID** 配置。

### 方式二：配置多个模型

如需在 Claude Code 中切换多个模型，可配置 `haiku`、`sonnet` 和 `opus` 对应的模型 ID：

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "<USER_API_KEY>",
    "ANTHROPIC_BASE_URL": "https://api.lkeap.cloud.tencent.com/plan/anthropic",
    "ANTHROPIC_MODEL": "kimi-k2.7-code",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "glm-5.3-flash",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "kimi-k2.7-code",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "deepseek-v4-pro-202606"
  }
}
```

配置说明：

`ANTHROPIC_MODEL`：Claude Code 启动时默认使用的模型。

`ANTHROPIC_DEFAULT_HAIKU_MODEL`：`haiku` 别名对应的模型。

`ANTHROPIC_DEFAULT_SONNET_MODEL`：`sonnet` 别名对应的模型。

`ANTHROPIC_DEFAULT_OPUS_MODEL`：`opus` 别名对应的模型。

**说明：**

示例模型仅用于说明配置方式，实际支持的模型及 Model ID 以 Token Plan [可用模型](https://cloud.tencent.com/document/product/1823/130060) 页面为准。

### 完成初始化配置

编辑或新建 `.claude.json` 文件：

macOS / Linux：`~/.claude.json`

Windows：`C:\\Users\\<用户名>\\.claude.json`

写入以下内容：

```json
{
  "hasCompletedOnboarding": true
}
```

保存后重新打开终端，使配置生效。

## （可选）配置 Claude Code 子代理模型

Claude Code 在代码检索、任务规划等部分场景中，可能自动调用 Explore、Plan 等内置子代理。一般对话和基础代码任务无需额外配置。

若您需要使用子代理，或执行任务时出现以下错误，可在 settings.json 的 env 中补充 CLAUDE\_CODE\_SUBAGENT\_MODEL：

```json
Model <模型名称> is not supported by TokenPlan
API Error: 403
API Error: 500
```

**配置示例：**

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "<USER_API_KEY>",
    "ANTHROPIC_BASE_URL": "https://api.lkeap.cloud.tencent.com/plan/anthropic",
    "ANTHROPIC_MODEL": "<Model_ID>",
    "CLAUDE_CODE_SUBAGENT_MODEL": "<Model_ID>"
  }
}
```

CLAUDE\_CODE\_SUBAGENT\_MODEL 请填写当前 Token Plan 套餐支持的模型 ID，建议与 ANTHROPIC\_MODEL 保持一致。修改配置后，请重新打开终端或重启 Claude Code，使配置生效。配置完成后，Claude Code 不会单独显示子代理模型配置成功提示。可通过触发 Explore、Plan 等子代理任务进行验证；若子代理能够正常完成任务，说明配置已生效。
