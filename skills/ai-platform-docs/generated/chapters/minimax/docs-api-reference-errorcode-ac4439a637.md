# 错误码查询

> 本文档汇总 MiniMax 接口常见错误码及对应解决方案，帮助开发者快速排查并解决调用问题。

> [!NOTE]
>
> 如需反馈问题，请提供 Header 中的 trace\_id，以便我们为您排查。

| 错误码 | 含义 | 解决方法 |
| :- | :- | :- |
| 1000 | 未知错误/系统默认错误 | 请稍后再试 |
| 1001 | 请求超时 | 请稍后再试 |
| 1002 | 请求频率超限 | 请稍后再试 |
| 1004 | 未授权/Token 不匹配/Cookie 缺失 | 请检查 API Key |
| 1008 | 余额不足 | 请检查您的账户余额 |
| 1024 | 内部错误 | 请稍后再试 |
| 1026 | 输入内容涉敏 | 请调整输入内容 |
| 1027 | 输出内容涉敏 | 请调整输入内容 |
| 1033 | 系统错误/下游服务错误 | 请稍后再试 |
| 1039 | Token 限制 | 请调整 max\_tokens |
| 1040 | 输入音频内容涉敏 | 请调整输入音频 |
| 1041 | 连接数限制 | 请联系我们 |
| 1042 | 不可见字符比例超限/非法字符超过 10% | 请检查输入内容，是否包含不可见字符或非法字符 |
| 1043 | ASR 相似度检查失败 | 请检查 file\_id 与 text\_validation 匹配度 |
| 1044 | 克隆提示词相似度检查失败 | 请检查克隆提示音频和提示词 |
| 1045 | 任务并发数超限 | 请等待进行中的任务完成后再提交 |
| 1046 | 提示词因身份声明被拒绝 | 请移除提示词中的身份声明后重试 |
| 2013 | 参数错误 | 请检查请求参数 |
| 20132 | 语音克隆样本或 voice\_id 参数错误 | 请检查 Voice Cloning 接口下的 file\_id 和 T2A v2，T2A Large v2 接口下的 voice\_id 参数 |
| 2014 | 输入内容为空 | 请检查输入内容 |
| 2022 | 模型不存在或无权使用 | 请检查 model 参数，或确认是否已开通该模型 |
| 2037 | 语音时长不符合要求(太长或太短) | 请检查 voice\_clone file\_id 文件时长，最少应不低于 10 秒，最长应不超过 5 分钟 |
| 2038 | 用户语音克隆功能被禁用 | 使用语音克隆功能需要完成账户身份认证，请根据您的使用需求在账户系管理》账户信息中进行个人或企业认证 |
| 2039 | 语音克隆 voice\_id 重复 | 请修改 voice\_id，确保未和已有 voice\_id 重复 |
| 2042 | 无权访问该 voice\_id | 请确认是否为该 voice\_id 创建者 |
| 2043 | 该模型不支持此 voice\_id | 请更换 voice\_id 或模型 |
| 2045 | 请求频率增长超限 | 请避免请求骤增骤减情况 |
| 2046 | Token 用量增长超限 | 请避免 Token 用量骤增骤减 |
| 2047 | 连接数增长超限 | 请避免连接数骤增骤减 |
| 2048 | 语音克隆提示音频太长 | 请调整 prompt\_audio 音频文件时长（＜ 8s） |
| 2049 | 无效的 API Key | 请检查 API Key |
| 2051 | 克隆音频质量检测未通过 | 请更换清晰、无明显噪音的音频后重试 |
| 2052 | 音色槽位不足 | 请升级套餐，或删除已有的克隆音色以释放槽位 |
| 2053 | 积分不足 | 请购买积分或升级套餐 |
| 2054 | voice\_id 不存在 | 请检查 voice\_id 是否正确 |
| 2056 | 超出M Plan资源限制 | 请等待下一个时间段资源释放后，再次尝试 |
| 2057 | 非 M Plan 订阅 Key | 请使用 M Plan 订阅 Key 调用该接口 |
| 2061 | 当前套餐不支持该模型 | 请更换模型或升级套餐 |
| 2062 | 超出 M Plan 速率限制；查询用量时也可能表示未订阅 M Plan | 请降低请求频率和并发后重试，或升级套餐、改用按量付费 API；查询用量时请确认已订阅 M Plan |
| 2064 | 服务集群负载较高 | 请稍后重试 |
| 2066 | 请求处理超时 | 请稍后重试 |
| 2067 | 套餐额度已用完，且未开启积分自动消耗 | 请升级套餐，或购买积分并开启积分自动消耗 |
| 2068 | 当前套餐等级不支持该模型 | 请升级套餐后使用 |
| 2069 | 模型已下线 | 请更换为在售模型，详见[模型发布](https://platform.minimaxi.com/docs/release-notes/models.md) |
| 2160 | 语音识别服务暂时不可用 | 请稍后重试 |

如有其他疑问，请联系我们 [api@minimax.io](mailto:api@minimax.io)。
