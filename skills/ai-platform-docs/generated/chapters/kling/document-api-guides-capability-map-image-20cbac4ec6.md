| --- | --- | --- | --- | --- | --- | --- |
| 文生图 | - | 支持: 生成相互关联的一组图片；提示词必填。 | - | - | - | - |
| 图生图 | - | 支持: 2–10 张或 auto，默认 4 张；提示词必填。组图为内容关联的一组图片。 | - | 支持 | - | - |
| 提示词容量 | - | 50,000 / 21,000 字符: 如为纯英文，内容长度不超过50,000个字符；如为纯非英文，内容长度不能超过21,000个字符；如为英文&非英文混合输入，需保持英文字符数÷50,000+非英文字符数÷21,000≤1。 | - | 2,500 字符: 不区分中英文，提示词统一上限为 2,500 个字符。 | - | - |
| 参考素材上限 | - | 10 个: 参考图与主体合计最多10个。图片格式支持 .jpg/.jpeg/.png。单张图片文件不超过 30 MB，宽、高均不小于 300 px，宽高比为 2:5–5:2。 | - | 10 个: 图片与主体合计最多 10 个。参考图支持 JPG、JPEG、PNG，单张 ≤10 MB，宽高均不小于 300px，宽高比 2:5–5:2。 | - | - |
| 主体库引用 | - | 支持: 仅多图主体 | - | 支持: 仅多图主体 | - | - |

## 长图生成

一次生成完整长图，支持电商详情页和网页设计。

| 能力 | 说明 | Kling Image 4.0 | Kling Image 3.0 | Kling Image 3.0 Omni | Kling Image O1 | Kling Image 2.1 |
| --- | --- | --- | --- | --- | --- | --- |
| 电商详情页 · 图生图 | - | 支持: 电商详情页仅支持图生图，不支持文生图。输入商品参考图及提示词，输出 1 张完整长图。 | - | - | - | - |
| 网页设计 · 文生图 | - | 支持: 通过提示词生成 1 张完整网页设计长图。 | - | - | - | - |
| 网页设计 · 图生图 | - | 支持: 通过风格参考图和主体参考图及提示词生成1张完整网页设计长图。 | - | - | - | - |
| 提示词容量 | - | 166,000 / 71,000 字符: 如为纯英文，内容长度不超过166,000个字符；如为纯非英文，内容长度不能超过71,000个字符；如为英文&非英文混合输入，需保持英文字符数 ÷ 166,000 + 非英文字符数 ÷ 71,000 ≤ 1。 | - | - | - | - |
| 参考图片上限 | - | 电商详情页：3 张<br>网页设计：2 张: 电商详情页：必须提供 1-3 张商品参考图。网页设计：可仅输入提示词，也可提供风格参考图和主体参考图，每种最多 1 张，合计最多 2 张。 | - | - | - | - |
| 主体库引用 | - | 不支持: 长图不支持从主体库选择素材。 | - | - | - | - |
| 分辨率 | - | 1K, 2K | - | - | - | - |
| 画面比例 | - | 不支持选择: 长图不提供画面比例选项，不套用普通单图、组图的比例枚举。 | - | - | - | - |
| 输出张数 | - | 1 张: 最终输出 1 张完整长图。 | - | - | - | - |
| 电商详情页长度 | - | 长 / 中 / 短: 仅电商详情页可选择长、中、短；网页设计不提供此选项。 | - | - | - | - |
