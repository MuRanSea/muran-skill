3.3.2.9 音量调节与淡入淡出
AI MediaKit 的音量调节与淡入淡出工具，可以帮助您轻松调整视频或音频文件的音量大小，或为其添加平滑的淡入、淡出效果。无论是需要将背景音乐无缝融入视频，还是希望统一不同来源素材的音量，都可以通过简单的 API 调用实现。
工具说明
AI MediaKit 为音量调节和淡入淡出功能提供了独立的 API，但它们都遵循相同的异步任务流程，即“提交任务 -> 查询结果”。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备视频文件：准备一个需要处理的视频或音频文件，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
场景一：全局音量调整
本节将演示如何调用 API 将一个视频的整体音量放大至原来的 2 倍。
音量调节是一个异步任务，完整的调用流程如下：
成功调用 POST /api/v1/tools/adjust-video-volume 提交任务后，系统将返回一个唯一的 task_id 。您可以通过轮询 GET /api/v1/tasks/{task_id} 接口来查询任务状态，直到状态（ status ）变为 completed ；或者使用事件回调 自动接收任务状态变化。
任务完成后，解析响应中的 result 字段，即可在 video_url 字段中获取处理后视频的下载地址。第 1 步：提交任务
您需要调用提交调整视频音量任务 API 。您可以直接复制以下 cURL 命令提交任务。

场景二：为视频添加声音淡入淡出效果
本节将演示一个常见的场景：如何为一个视频的开头添加 3 秒的声音淡入，并在结尾添加 5 秒的声音淡出，以使听感更加自然。
声音淡入淡出是一个异步任务，完整的调用流程如下：
成功调用 POST /api/v1/tools/fade-video-audio 提交任务后，系统将返回一个唯一的 task_id 。您可以通过轮询 GET /api/v1/tasks/{task_id} 接口来查询任务状态，直到状态 status 变为 completed ；或者使用事件回调 自动接收任务状态变化。
任务完成后，解析响应中的 result 字段，即可在 video_url 字段中获取处理后视频的下载地址。第 1 步：提交任务
调用提交视频声音淡入淡出任务 API ，您可以直接复制以下 cURL 命令发起请求。
