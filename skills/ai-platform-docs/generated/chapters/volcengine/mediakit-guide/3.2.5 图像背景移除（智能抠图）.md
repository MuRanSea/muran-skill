3.2.5 图像背景移除（智能抠图）
AI MediaKit 图像背景移除（智能抠图）工具，能够精准识别图像中的主体（如人物、商品、物体等），自动移除背景并生成透明底的图片，适用于电商主图制作、证件照换背景、营销海报合成等多种场景。本篇开发指南将引导您：
快速体验通过一次 API 调用完成图像背景移除。
了解通用、人像、商品等不同抠图场景的差异与效果。
学习如何使用描边、自动裁剪等进阶功能，为主体添加视觉特效。
效果展示
快速体验：一键移除图像背景
图像背景移除是一个同步任务，您发起的请求会直接在响应中返回处理结果，无需轮询。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备图像文件：准备一张待处理的图片，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程
您只需调用提交图像背景移除任务 API ，即可在 API 的响应体中直接获取抠图后的图片地址。步骤 1：提交任务并获取结果
可直接复制以下 cURL 命令，使用 general （通用）场景对一张图片进行背景移除。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/remove-image-background'\
--header 'Content-Type: application/json' \
说明
将 {Your_API_Key} 替换为您的有效 API Key。
将 image_url 替换为您真实的图片地址。
步骤 2：查看响应
由于是同步接口，请求成功后，您会立即收到包含最终结果的响应。您可以直接从 result.image_url 字段获取抠图后图片的下载地址（默认输出 PNG 格式，有效期为 24 小时）。
参考信息
应用场景
弹幕穿人：在优酷、爱奇艺、哔哩哔哩等视频应用中，实现弹幕穿透人物的效果，避免弹幕遮挡视频主体，从而提升用户的观看体验。
背景替换：在在线会议、直播、在线图片编辑或证件照制作等场景中，自动移除人物或物体的背景，并替换为自定义背景。
素材生成：从图片中精准分离出主体，方便您将其用于制作新的广告或宣传素材。

限制项 说明
输入图像限制
图像来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、火山引擎对象存储
( tos:// ) 三种输入协议。关于各协议的具体
说明和使用示例，请参阅多源媒体输入与本
地上传。
支持格式：支持
.png 、 .jpg 、 .jpeg 、 .webp 、 .tiff 、 .bmp
和 .heic 。
文件大小：单张图片不得超过 30 MB。
图像输入分辨率： 
当 scene 为 general ： 
输入图像分辨率的长边不得超过 10240
px、短边不得超过 6000 px。
输入图像的总像素数量（长边 × 短
边）不得超过 40 MP。
当 scene 为 human 或 product ：图像
输入分辨率的长边不得超过 7680 px、短边
不得超过4320px。
