3.1.29 视频横转竖
AI MediaKit 的视频横转竖工具，可将横版视频智能转换为竖版（默认 9:16）成片，输出可直接分发到竖屏平台。工具内部由 AI 完成逐帧主体检测、发言主体识别、主体跟踪与智能裁剪，并对多人场景自动进行布局决策，无需人工编辑即可获得竖屏结果。
本篇开发指南将引导您：
快速体验如何将一段横版视频转换为竖版成片。
掌握在竖屏成片中叠加烧录外部字幕的用法。
效果预览
快速入门：将横版视频转换为竖版
本节演示如何提交一个视频横转竖任务，将一段 16:9 的横版视频智能转换为 9:16 的竖版成片。准备工作
获取访问凭证：在开始之前，请访问 AI MediaKit 控制台的 API Key 管理页面 ，创建并获取 MediaKitAPI Key。
准备视频文件：准备一个待处理的横版视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。输入应为横屏比例（ 16:9 、 4:3 、 21:9 ），时长不超过 4 小时，单文件不超过 20 GB。
操作流程
输入的横屏视频 输出的竖屏视频
视频横转竖是一个异步任务，其标准流程如下：
成功调用 POST /api/v1/tools/reframe-video-to-vertical 提交任务后，您将获得一个任务 ID。您可以轮询 GET /api/v1/tasks/{task_id} 接口，直到任务状态 status 变为 completed ；或者使用事件回调 自动接收任务状态变化。
任务完成后，解析响应中的 result 字段，即可在 video_url 中获取横转竖后视频的下载地址。第 1 步：提交视频横转竖任务
您需要调用提交视频横转竖任务 API 。可直接复制以下 cURL 命令，提交一个将横版视频转换为竖版成片的任务。

进阶使用：为竖屏成片烧录外部字幕
如果您希望在竖屏成片中烧录一份外部字幕，可通过 subtitle_url 参数传入一个字幕文件。该字幕仅用于成片阶段烧录字幕，不参与主体识别、跟踪、裁剪等内部处理。字幕文件支持 SRT 、 ASS 等格式。参考信息

限制项 说明
输入视频限制
视频来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、来源于火山引擎视频点
播 ( vod:// ) 和火山引擎对象存储 ( tos:// ) 四
种输入协议。关于各协议的具体说明和使用
示例，请参阅多源媒体输入与本地上传。
支持格式： MP4 、 MOV 、 MKV 、
AVI 、 FLV 。
画面比例：输入应为横屏比例，支持 
16:9 、 4:3 、 21:9 。
视频时长：不超过 4 小时。
文件大小：单文件不超过 20 GB。
字幕文件限制
字幕来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、来源于火山引擎视频点
播 ( vod:// ) 和火山引擎对象存储 ( tos:// ) 四
种输入协议。关于各协议的具体说明和使用
示例，请参阅多源媒体输入与本地上传。
支持格式： SRT 、 ASS 等字幕文件。
数量限制：最多传入一个字幕文件。
