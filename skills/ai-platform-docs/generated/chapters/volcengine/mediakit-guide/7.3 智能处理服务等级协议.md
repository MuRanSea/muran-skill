7.3 智能处理服务等级协议
发布日期：2021年11月23日
生效日期：2021年11月23日
本服务等级协议（Service Level Agreement，简称 “SLA”）规定了乙方及乙方运营的火山引擎平台（“平台”）向甲方（“客户”或“您”）提供的智能处理服务的服务可用性等级指标及赔偿方案。具体服务内容请参考本《服务目录》的服务价格和计费。
除非您已充分阅读、完全理解并接受本SLA所有条款，否则，请您不要购买本服务。您单击“同意”、“下一步”或您的购买、使用等行为或者您以其他任何明示或者默示方式表示接受本SLA的，即视为您已阅读并同意受本SLA的约束。本SLA即在您与火山引擎之间产生法律效力，成为对双方均具有约束力的法律文件。
1. 定义
1.1 服务周期 ：一个服务周期为一个自然月，如不满一个月按一个月计算。
1.2 错误请求 ：HTTP状态码为5XX，或因智能处理服务故障导致的用户正常请求未能到达智能处理服务器端的请求视为错误请求，但不包括以下类型的请求：
（1）由智能处理服务发起的合理升级、变更、停机而导致的错误请求或服务不可用情况；
（2）由于客户业务受到攻击而导致被智能处理限制的请求；
（3）内容违规或其他原因而导致域名被封禁而产生的错误；
（4）由于客户业务突增（业务突发增长大于等于上月计费的30%）且未通知火山引擎而导致的错误；1.3 请求数 ：用户在单位时间内全部请求数。
1.4 每5分钟错误率：每5分钟错误率 = （每5分钟错误请求数 / 每5分钟请求总数）× 100%1.5 月度服务费用 ：一个服务周期内，客户某一火山引擎账号下就智能处理服务产生的服务费用总额。不包含已经购买尚未消费的部分，如果客户一次性支付了多个月份的服务费用，则将按照所购买的月数或使用量比例分摊计算月度服务费用。
2. 服务可用性
2.1 服务可用性计算方式
服务可用性=(1-服务周期内∑每5分钟错误率/服务周期内5分钟个数) * 100%
2.2 服务可用性/服务指标标准
火山引擎提供的本服务可用性不低于99.9%， 如智能处理未达到上述可用性标准，客户可以根据本SLA第3条约定获得补偿。但由以下原因导致的服务不可用，相应服务不可用时间不属于服务不可用的计算范畴的补偿范畴，本服务无需向您承担责任：
（1）智能处理发起的合理升级、变更、停机、维护而导致的错误请求或服务不可用情况；；（2）内容违规、不符合平台商业转播/视频播放规则和目的限制或其它原因而导致直播被封禁而产生的错误；
（3）由于客户端异常导致的播放错误；
任何火山引擎所属设备以外的网络、设备故障或配置调整引起的；
（4）用户的应用程序或数据信息受到黑客攻击而引起的；
（5）用户维护不当或保密不当致使数据、口令、密码等丢失或泄漏所引起的；
（6）智能处理页面收到攻击或其他不当行为引起的；
（7）大规模流量突增（业务突发增长大于等于上月计费的30%），客户需至少提前3个工作日书面告知火山引擎，否则因此造成的可用性影响，火山引擎不承担责任；
（8）用户自行升级操作系统所引起的；
用户未遵循本服务产品使用文档或使用建议引起的；
（9）用户的应用程序或安装活动所引起的；
（10）用户的疏忽或由用户授权的操作所引起的；
（11）其他用户原因导致的服务不可用；
（12）不可抗力以及意外事件引起的；
（13）其他非火山引擎原因所造成的不可用；
（14）属于相关法律法规、相关协议、相关规则或单独发布的相关规则、说明等中所述的可以免责、免除补偿责任等的情况。
3. 补偿方案
3.1 补偿标准
火山引擎故障原因导致用户的智能处理服务在服务周期内未达到可用性标准，用户可申请要求针对事故或故障进行补偿。根据客户某一火山引擎账号下智能处理的月度服务可用性，按照下表中的标准计算补偿金额。补偿金额仅限于抵扣发生故障当月智能处理产品的月度服务费用，该赔偿是我们针对服务不满足服务可用性承诺向您提供的全部及唯一赔偿，且补偿总额不超过未达到服务可用性承诺的当月客户就该账号下智能处理支付的月度服务费用（此处的月度服务费应扣除使用代金券、优惠券、折扣优惠及服务费减免等方式而抵扣/减免的金额）的25%。
3.2 补偿申请时限
客户可以在每月第5个工作日后对上个月没有达到可用性的服务提出补偿申请。 补偿申请必须限于在智能处理没有达到可用性的相关月份结束后60个自然日内提出。超出申请时限的补偿申请将不被受理。
