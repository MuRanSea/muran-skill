3.3.1 智能剪辑
3.3.1.1 智能剪辑 Vibe Editing
AI MediaKit 智能剪辑是面向企业客户提供的视频理解剪辑工具集，致力于将复杂的视频剪辑能力封装为可组合、可调用、可对话的智能服务。结合火山方舟视觉大模型，用户无需理解底层复杂的剪辑参数，只需通过自然语言描述剪辑目标，系统即可自动完成意图理解、参数转换、多轨道剪辑、云端渲染与成片导出。
AI MediaKit 智能剪辑适用于 AI 剧粗剪、视频二创、视频剪辑 Agent 等业务场景，并支持 API、Web SDK等多种交付形态，能够灵活适配您的 SaaS 平台、Agent 工具及自建业务系统。
为什么需要智能剪辑？
随着大模型在视频生成与理解上的能力持续增强，企业可以更轻松地生产和解析媒体素材。然而，在 AI生成内容（AIGC）的后期制作，或基于视频理解结果进行二次创作时，传统剪辑工具暴露了以下问题：参数复杂：传统剪辑涉及大量参数，学习成本高。
AI 协同不畅：AI 模型直接控制底层剪辑参数时，容易因理解偏差导致结果不理想。
智能剪辑旨在解决这一问题，它为 AI 和业务提供了一套足够友好且易用的剪辑基础设施，将复杂的底层能力封装为简单的自然语言接口，显著降低了视频创作的门槛。
方案架构
方案优势
对话即剪辑，零门槛上手：自然语言直接驱动多轨道剪辑，无需掌握专业剪辑软件，复杂操作一句话完成，大幅降低使用门槛。
场景覆盖广，一套能力多用：从 AI 剧创的片段拼接，到视频二创的精彩剪辑，再到个人助手的自由创作，一套产品能力覆盖多类核心场景。
所见即所得，人机协同：Web SDK 支持实时预览与手动微调，Agent 自动生成草稿后用户可直接在线精调，兼顾效率与可控性。
多形态交付，灵活集成：API、Web SDK 多种交付形态全覆盖，无论是 AI SaaS 平台、Agent 工具还是传统业务系统，均可低成本快速接入。
云端渲染，稳定高效：云端合成导出，弹性资源支撑高并发，无需客户自备算力，开箱即用、交付稳定。

使用模式
智能剪辑提供两种使用模式，您可以根据业务需求选择合适的方案。
模式 1：直接生成
该模式以 API 调用为核心，实现全自动化的视频生成。您只需提供媒体素材和描述剪辑目标的自然语言指令 (Prompt)，系统即可异步完成从意图理解、剪辑参数转换到云端合成的全过程，并直接返回最终的视频文件。
适用场景：后端服务驱动的自动化出片、批量化内容生产、集成至 AI Agent 或工作流引擎等无需人工干预的场景。
使用方式：通过调用提交智能剪辑任务 API 实现。未来将支持通过 Skill 接入对话式应用。准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 MediaKit APIKey（用于媒体处理功能鉴权）。
准备素材文件：确保您剪辑所需的所有媒体文件（视频、音频、图片）均已上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
进行跨服务授权：智能剪辑工具会在剪辑过程中根据自然语言意图调用其他 AI MediaKit 工具以及剪辑合成工具完成最终成片。因此在首次调用本 API 前，您必须先在 AI MediaKit 控制台基础配置 > 授权管理 页面，为 AI MediaKit 授予访问您 IMP 智能处理资源的权限。否则，任务将因无权限访问而失败。同一账号下只需授权一次，后续调用无需重复操作。
（可选）当您的剪辑指令包含需要理解视频内容的意图时（例如，识别特定物体、场景或行为并进行剪辑），智能剪辑工具可以依赖火山方舟视觉大模型进行内容分析。为确保任务正常执行，请在使用前完成以下准备工作： 
开通火山方舟大模型服务：请前往火山方舟控制台 ，确保您计划使用的模型服务已开通并可正常调用。
进行跨服务授权：首次使用涉及视频理解的智能剪辑功能前，您需要为 AI MediaKit 授予访问您火山方舟资源的权限。请前往 AI MediaKit 控制台基础配置 > 授权管理 页面，为 AI MediaKit 授予访问您 AMK 火山方舟资源的权限。

预览与微调：您通过自然语言在聊天框下达指令后，系统会进行智能剪辑。您可以单击剪辑产物，系统会自动在右侧展示剪辑轨道。用户可以通过以下步骤对成片效果进行预览、微调和导出。实时预览剪辑效果：右侧上方的播放器区域支持所见即所得的实时预览。单击播放器下方的 ▶ 按钮，即可实时播放当前时间轴上的音视频与字幕组合效果。

修改出现时间：在时间轴上，左键按住字幕块（紫色条）或视频块，左右拖拽即可改变它们在视频中出现的先后顺序。
调整时长：鼠标悬停在轨道元素（如文字轨道）的左右边缘，出现双向箭头时拖拽，即可精准调整该文字或视频的显示时长。
选中时间轴上的任意片段（如特定视频帧或字幕块），单击轨道上方快捷工具栏中的按钮进行分割/复制/粘贴/删除等操作。

编辑文字与样式：在时间轴上双击紫色文字轨道，或在预览画面中直接双击文字框，即可修改文本内容。您也可以在上方切换到文字面板调整字体大小和颜色。

计费说明
智能剪辑方案包含两个核心工具。整体计费基于底层合成工具的实际使用量。
智能剪辑 vibe-editing ：通过大语言模型（LLM）进行意图识别，将您的自然语言剪辑意图转换为精确的剪辑参数，然后调用“智能剪辑合成”工具来提交具体的合成任务。该工具本身及其依赖的 LLM 服务，目前不计费。
智能剪辑合成 vibe-editing-common ：作为底层的多轨道剪辑合成服务，负责执行视频、音频、图像、文字、转场、特效等所有元素的云端渲染与合成工作。该工具由“智能剪辑”工具自动调用，不支持您单独调用，按最终成功合成的产物时长收费，计费单元为 “剪辑工具-基础剪辑-计费时长” 。详细的计费规则，请参阅剪辑工具计费。
