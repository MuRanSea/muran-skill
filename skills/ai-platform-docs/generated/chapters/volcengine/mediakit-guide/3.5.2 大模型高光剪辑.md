3.5.2 大模型高光剪辑
AI MediaKit 的大模型高光剪辑工具，能够从一个或多个输入视频中，按场景预设、评分标准或故事目标智能识别精彩片段，自动挑选、裁剪并拼接成一个或多个指定时长的高光成片。该工具依托大模型的视频理解与文本推理能力，适用于新品发布、体育赛事、内容营销、知识科普、品牌宣传等多种场景的高光提取与混剪。
快速体验：从一个新品发布会视频生成一条高光成片
本节将演示如何针对一个新品发布会视频，快速生成一条 60 秒的宣发高光短片。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备视频文件：准备待处理的视频，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
开通火山方舟大模型服务：大模型高光剪辑工具依赖火山方舟大模型。请前往火山方舟控制台开通管理页面 ，确保您已开通以下模型： 
视觉理解模型： doubao-seed-2-0-lite-260428
文本推理模型：请至少开通以下任一模型。当您未在请求中通过 customer_ark_config 参数指定Endpoint 时，系统将按场景复杂度，自动查找并使用您账号下已开通的模型服务。 
doubao-seed-2-0-pro-260215
doubao-seed-2-1-turbo-260628
doubao-seed-2-1-pro-260628
此外，您还需开启 Cache 功能，用于启用模型的上下文缓存 API，若不开启，任务虽不会失败，但可能会影响最终的效果。
进行跨服务授权：首次使用大模型高光剪辑工具前，请前往 AI MediaKit 控制台基础配置 > 授权管理页面，为 AI MediaKit 授予访问您 ARK 火山方舟资源的权限。否则，任务将因无权限访问而失败。操作流程

您可以轮询查询任务信息 API ，直到任务状态 status 变为 completed ；或者使用事件回调 自动接收任务状态变化。

进阶使用
使用场景预设
如果您不确定如何描述评分标准，可以通过 preset 参数直接选用内置场景预设，系统会自动采用针对该场景优化的分析策略和评分标准。当前支持的预设包括： football （足球）、 basketball （篮球）、automotive （汽车）、 finance （金融财经）、 product_launch （产品发布）、 ecommerce （电商）、knowledge_share （知识分享）。
使用自定义评分标准

仅输出结构化高光数据
如果您只需要高光片段的结构化数据（片段来源、时间范围、标题、摘要等）而不需要生成成片视频，可将 skip_video_output 设置为 true 。此时响应中的 outputs 仅包含 segments 等结构化信息，不再返回 video_url 。
限定分析时间范围
当仅输入一个视频时，您可以通过 time_range 指定待分析的时间范围（左闭右开，单位为毫秒），工具将只在该范围内分析并选取高光片段。
使用火山方舟 Endpoint
您可以通过 customer_ark_config 指定您自己火山引擎账号下的方舟（Ark）Endpoint，用于承载底层的视频理解与文本推理大模型调用。

参考信息
计费说明
大模型高光剪辑工具的总费用由两部分组成：
AI MediaKit 任务费用：由 AI MediaKit 收取，按输入视频的总时长计费。关于详细的计费规则与价格，请参阅大模型高光剪辑（按输入时长计费）。
火山方舟大模型调用费用：功能运行依赖的底层大模型由火山方舟提供。您通过跨服务授权使用这些模型所产生的费用，将由火山方舟根据其自身定价直接向您收取。关于详细的计费规则与价格，请参阅火山方舟计费说明 。您可以在任务完成后的 API 响应中，通过 result.token_usage 字段查看本次任务的详细大模型用量，包括输入/输出/缓存/音频/思考 Token 总数，以及按方舟 Endpoint 聚合的细分用量（ endpoint_token_usages ）。

限制项 说明
输入视频来源
支持公网 HTTP/HTTPS URL、本地上传
( mediakit:// )、来源于火山引擎视频点播
( vod:// ) 和火山引擎对象存储 ( tos:// ) 四种输
入协议。关于各协议的具体说明和使用示例，请
参阅多源媒体输入与本地上传。
支持格式 mp4 、 flv 、 ts 、 avi 、 mov 、 wmv 、
mkv 等主流视频格式。
输入时长 单个视频时长不超过 3 小时，全部输入视频累计
时长不超过 15 小时。
输出条数 单次任务最多生成 5 条高光成片。
