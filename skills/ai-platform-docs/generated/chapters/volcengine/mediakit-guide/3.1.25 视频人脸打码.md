3.1.25 视频人脸打码
AI MediaKit 的视频人脸打码工具，能够自动并精准地识别视频画面中的人脸区域，并对所有人脸进行模糊或马赛克处理。此功能适用于需要保护人物五官隐私的场景，例如短剧内容脱敏、保护未成年人、新闻素材处理、生成式视频的参考素材预处理等。
本篇开发指南将引导您：
快速体验为一个视频中的所有人脸打上马赛克。
了解如何通过各项参数，精细化地控制打码的方式、强度与范围。
效果预览
通过视频人脸打码工具，您可以将一个包含人脸的视频作为输入，快速生成一个人脸均被精确地打上马赛克或高斯模糊的视频。
快速体验：为人脸打上马赛克
本节将演示如何为一个视频，快速生成一个人脸区域被马赛克处理的视频。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备视频文件：准备一个待处理的视频，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。为方便您快速测试，本文后续步骤的示例代码中提供了两个可直接使用的演示视频 URL。
操作流程
视频人脸打码是一个异步任务，完整流程如下：
成功调用 POST /api/v1/tools/face-blur-video 提交任务后，您将获得一个任务 ID。
您可以轮询 GET /api/v1/tasks/{task_id} 接口，直到任务状态 status 变为 completed ；或者使用事件回调 自动接收任务状态变化。
任务完成后，解析响应中的 result 字段，即可在 video_url 字段获取最终生成的视频文件下载地址。第 1 步：提交任务

进阶使用
在快速入门的基础上，您可以通过在提交任务时配置不同的参数，实现更精细的打码效果。选择打码方式：高斯模糊或马赛克
通过 mask_mode 选择对人脸区域应用马赛克还是高斯模糊效果。
mosaic ：（默认）马赛克。
blur ：高斯模糊。
示例：使用高斯模糊方式打码
调整打码强度
通过 mask_strength 控制打码的强度，以适应不同场景下的隐私保护级别。
low ：低强度。
medium ：（默认）中强度。
high ：高强度。
示例：使用高强度打码

扩大打码范围
为了更彻底地覆盖人脸轮廓，您可以通过 face_box_expand 设置一个扩展比例，在系统检测到的人脸边界框基础上向外扩大打码范围。例如， 0.2 表示在原边界框的每条边上向外扩展 20%。
示例：将打码范围向外扩展 20%
调整人脸识别灵敏度
通过 face_confidence 调整人脸检测的置信度阈值，您可以控制人脸识别的严格程度。该值越高，检测结果越保守（即要求更高的人脸相似度），可能会漏掉一些模糊或非正面的脸；值越低，则可能将一些非人脸的物体误识别为人脸。取值范围为 [0.1, 1.0] ，默认值为 0.35 。
示例：设置更高的识别置信度
