3.3.2.6 音频提取
AI MediaKit 的音频提取工具能够快速从视频文件中分离音轨，并保存为纯音频文件（支持 MP3 或 M4A 格式）。该工具适用于制作播客素材、视频转文字前置处理、以及从影视素材中提取背景音乐等场景。本篇开发指南将引导您：
理解音频提取的核心能力与应用场景。
快速从一段视频中提取出音频文件。
学习如何指定输出音频的格式。
应用场景
播客与有声内容制作：将视频访谈、在线课程、会议录像等直接转换为音频节目，方便听众随时收听。
音乐与音效提取：从 MV、影视片段或游戏录屏中分离出背景音乐或特定音效，用于素材积累或二次创作。
多语言配音处理：从包含多音轨的视频中提取目标语言的音轨，用于后续的翻译、校对或存档。快速体验：从视频中提取完整音频
本场景演示如何从一段视频中提取其完整的音频。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备视频文件：准备一个待处理的视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。
操作流程
音频提取是一个异步任务：
成功调用 POST /api/v1/tools/extract-audio 后，API 将返回一个任务 ID。
您可以轮询 GET /api/v1/tasks/{task_id} ，直到任务状态 status 变为 completed ；或者使用事件回调自动接收任务状态变化。
任务完成后，解析 result 字段，即可在 audio_url 字段处获取最终音频文件的下载地址。第 1 步：提交任务
您需要调用提交音频提取任务 API 。可直接复制以下 cURL 命令提交。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/extract-audio' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {Your_API_Key}' \
--data '{

将 {Your_API_Key} 替换为您的有效 API Key。
将 video_url 替换为您真实的视频文件地址。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。

限制项 说明
输入文件限制
视频来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、来源于火山引擎视频点
播 ( vod:// ) 和火山引擎对象存储 ( tos:// ) 四
种输入协议。关于各协议的具体说明和使用
示例，请参阅多源媒体输入与本地上传。
视频格式：支持 mp4 , flv , ts , avi , 
mov , wmv , mkv 等主流视频容器。
文件大小：建议单个视频文件不超过 10 GB。
