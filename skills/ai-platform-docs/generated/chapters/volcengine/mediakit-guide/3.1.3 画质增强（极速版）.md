3.1.3 画质增强（极速版）
AI MediaKit 的画质增强（极速版）工具，集成了轻量级超分与智能画质增强能力。它采用速度优先的算法策略，在保证画质有效提升的同时，提供更快的处理速度，尤其适用于直播、短视频处理等对时延敏感的业务场景。
本篇开发指南将引导您：
快速体验将一段低清晰度视频提升至 720p。
理解并使用画质增强（极速版）工具的核心参数。
效果预览
通过画质增强（极速版），您可以显著改善视频的清晰度和观感。
快速体验：将低清视频提升至 720p
本节演示如何将一段低分辨率视频，通过画质增强（极速版）工具快速提升至 720p 高清画质。准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 MediaKit APIKey（用于媒体处理功能鉴权）。
准备视频文件：准备一个待增强的视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。若您尚未生成视频，请参考火山方舟视频生成文档 完成视频生成并获取视频地址。
输入视频（480p） 增强后视频（720p）
操作流程
画质增强是一个异步任务：
成功调用 POST /api/v1/tools/enhance-video-fast 后，API 将返回一个任务 ID。
您可以轮询 GET /api/v1/tasks/{task_id} ，直到任务状态 status 变为 completed ；或者使用事件回调自动接收任务状态变化。
任务完成后，您可解析 result 字段，在 video_url 字段处获取最终生成的视频文件下载地址。第 1 步：提交任务
您需要调用提交画质增强（极速版）任务 API 提交任务。可直接复制以下 cURL 命令提交。说明
需替换参数：
将 {Your_API_Key} 替换为您的有效 API Key。
将 video_url 替换为您真实的视频文件地址。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。
第 2 步：获取结果
画质增强需要一定的处理时间。您需要轮询查询任务信息 API ，直到任务状态 status 变为 completed 。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/enhance-video-fast' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {Your_API_Key}' \
--data '{
 "video_url": "https://example.com/source_video.mp4",
 "resolution": "720p"
}'

配置输出帧率
通过 fps 参数可以调整视频的目标帧率（单位 fps），取值范围为 [15, 120] 。若不指定，将尽量保持与原片一致。为保证画面流畅自然，建议设置的目标帧率不要超过原视频帧率的 4 倍。

参考信息
费用说明
画质增强（极速版）工具采用“按量计费”模式，基于输出文件时长，并结合任务的输出分辨率和输出帧率的计费换算系数进行计算。关于详细的计费规则、换算系数和计费示例，请参阅画质增强（按输出时长计费）。
任务耗时预估
任务处理时长与视频的原始时长相关。您可根据 RTF (Real-Time Factor) 系数预估任务耗时，即处理耗时与原片时长的比值。画质增强（极速版）工具的平均 RTF 约为 3。例如，一个 1 分钟的视频，处理耗时约3 分钟。
