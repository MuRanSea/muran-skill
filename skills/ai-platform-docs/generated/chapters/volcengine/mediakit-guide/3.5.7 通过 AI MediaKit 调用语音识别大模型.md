3.5.7 通过 AI MediaKit 调用语音识别大模型
您可以通过 AI MediaKit 调用已在豆包语音 开通的豆包语音识别（标准版），将录音文件转写为文本，无需再单独对接豆包语音接口。
本篇开发指南将引导您快速体验如何通过 AI MediaKit 调用语音识别大模型，将一段录音文件转写为文本。
快速入门
本节以将一个 mp3 录音文件转写为文本为例，演示通过 AI MediaKit 调用语音识别大模型的完整流程。准备工作
开通模型：在豆包语音控制台 开通豆包语音识别（标准版），并记录可用的模型标识。
进行跨服务授权：前往 AI MediaKit 控制台授权管理页面 ，为 AI MediaKit 授予访问您豆包语音资源的权限。
获取访问凭证：访问 AI MediaKit 控制台的 API Key 管理页面 ，创建并获取 MediaKit API Key。准备音频文件：准备一个待识别的录音文件，并将其上传至公网可访问的地址，以获取可供调用的URL。
操作流程
通过 AI MediaKit 调用语音识别大模型以异步任务方式进行，其标准流程如下：
调用 POST /api/v1/tools/call-maas-proxy 提交任务， api 设为 doubao.asr ，即可获得一个任务 ID。轮询 GET /api/v1/tasks/{task_id} 接口，直到任务状态 status 变为 completed ；或使用事件回调 自动接收任务状态变化。
任务完成后，从响应 result.maas_result 中读取豆包语音识别接口的原始结果（如识别文本），并从 result.duration 获取识别音频的总时长（秒）。
第 1 步：提交语音识别任务
调用MaaS 模型代理 API 。可直接复制以下 cURL 命令，为一个录音文件提交语音识别任务。curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/call-maas-proxy' \-H 'Authorization: Bearer {Your_API_Key}' \
-H 'Content-Type: application/json' \
-d '{
 "api": "doubao.asr",
 "maas_params": {
 "audio": {
 "url": "https://example.com/your-audio.mp3",
 "format": "mp3"
 },
 "request": {
 "model_name": "bigmodel",
 "enable_itn": true,
说明
将 {Your_API_Key} 替换为您的有效 MediaKit API Key。
maas_params 内为豆包语音识别接口的原始业务参数，以豆包语音 - 录音文件识别 API 为准。其中 audio.url 替换为您自己的录音文件地址， request.model_name 请按您已开通的模型填写。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。
