3.1.29 大模型高光剪辑
AI MediaKit 的大模型高光剪辑工具，能够从一个或多个输入视频中，按场景预设、评分标准或故事目标智能识别精彩片段，自动挑选、裁剪并拼接成一个或多个指定时长的高光成片。该工具依托大模型的视频理解与文本推理能力，适用于新品发布、体育赛事、内容营销、知识科普、品牌宣传等多种场景的高光提取与混剪。
快速体验：从一个新品发布会视频生成一条高光成片
本节将演示如何针对一个新品发布会视频，快速生成一条 60 秒的宣发高光短片。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备视频文件：准备待处理的视频，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
开通火山方舟大模型服务：大模型高光剪辑工具依赖火山方舟大模型。请前往火山方舟控制台开通管理页面 ，确保您已开通以下模型： 
视觉理解模型： doubao-seed-2-0-lite-260428
文本推理模型：请至少开通以下任一模型。当您未在请求中通过 customer_ark_config 参数指定Endpoint 时，系统将按场景复杂度，自动查找并使用您账号下已开通的模型服务。 
doubao-seed-2-0-pro-260215
doubao-seed-2-1-turbo-260628

进行跨服务授权：首次使用大模型高光剪辑工具前，请前往 AI MediaKit 控制台基础配置 > 授权管理页面，为 AI MediaKit 授予访问您 ARK 火山方舟资源的权限。否则，任务将因无权限访问而失败。操作流程

仅输出结构化高光数据
如果您只需要高光片段的结构化数据（片段来源、时间范围、标题、摘要等）而不需要生成成片视频，可将 skip_video_output 设置为 true 。此时响应中的 outputs 仅包含 segments 等结构化信息，outputs[].video_url 不提供可下载的视频地址，可能为空字符串或 null 。
使用火山方舟 Endpoint
您可以通过 customer_ark_config 指定您自己火山引擎账号下的方舟（Ark）Endpoint，用于承载底层的视频理解与文本推理大模型调用。两个 Endpoint 列表均须包含 1～3 个不重复、属于当前客户且处于运行状态的 Endpoint ID，按数组顺序确定调用优先级。视频理解 Endpoint 必须支持视频、音频及结构化输出；文本推理 Endpoint 必须支持思考及结构化输出。

场景方案：短剧“一口气看完”系列
针对短剧营销场景，常见的做法是提取前几集的精彩高光作为“钩子”吸引观众，随后拼接全集正片内容形成一个超长视频（如“一口气看完”系列）。您可以组合以下参数实现该效果：
提取高光钩子：通过 analysis_video_count 指定仅分析前 N 个视频（如前 10 集）。系统将仅从这些视频中筛选精彩片段，作为成片的开场。
无缝拼接全集：将 append_source_video 设为 true ，系统会在高光结束后，按顺序追加全部输入视频（如 100 集）。
去除冗余内容：开启 analyze_intro_outro_info （片头片尾检测）。系统会自动识别并剔除每集的片头、片尾以及重复的“前情提要”，确保长视频观看体验丝滑。
确保视频生成：请确保 skip_video_output 为 false （默认值），以生成最终的合成视频。请求示例： 分析前 2 集高光，检测并拼接全部 3 集正片。

大模型高光剪辑工具的总费用由两部分组成：
AI MediaKit 任务费用：由 AI MediaKit 收取，以任务结果中的 result.duration 作为处理计量时长。该值由高光有效输入分析时长、实际生成的高光部分时长之和及片头片尾分析计量时长按需累加而成。关于不同参数组合下的计费场景和计量时长，请参阅大模型高光剪辑计费说明。
火山方舟大模型调用费用：功能运行依赖的底层大模型由火山方舟提供。您通过跨服务授权使用这些模型所产生的费用，将由火山方舟根据其自身定价直接向您收取。 
用量查询：您可以在任务完成后的 API 响应中，通过 result.token_usage 字段查看本次任务的详细大模型用量，包括输入/输出/缓存/音频/思考 Token 总数。
价格参考：关于详细的计费规则与价格，请参阅火山方舟计费说明 。这些字段采用不同统计维度，请勿直接相加。

限制项 说明
输入视频来源
单次请求支持 1～100 个视频。支持公网 HTTP/
HTTPS URL、本地上传 ( mediakit:// )、来源于火
山引擎视频点播 ( vod:// ) 和火山引擎对象存储
( tos:// ) 四种输入协议。关于各协议的具体说明
和使用示例，请参阅多源媒体输入与本地上传。
支持格式 mp4 、 flv 、 ts 、 avi 、 mov 、 wmv 、
mkv 等主流视频格式。
输入时长 单个视频时长不超过 3 小时，全部输入视频累计
时长不超过 15 小时。
输入语言
指定输入视频中的语音语言（供 ASR 分析时使
用）。
默认行为：不指定时，系统会自动检测语言
（支持中文、英文及部分方言）。
指定语种：支持 zh-CN （中文）、 en-US
（英文）、 ja-JP （日语）等二十余种语
言。详细列表请参阅提交大模型高光剪辑任
务 API 。
输出语言
用于指定输出的结构化信息（如标题、摘要、理
由）的语言。支持 zh-CN （中文）和 en-US
（英语）；不传或传空字符串时默认为 zhCN 。
输出条数 单次任务最多生成 5 条高光成片。
