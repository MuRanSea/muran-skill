5.2 剪辑工具计费
本文向您介绍 AI MediaKit 中剪辑工具的计费规则、折算系数及具体计费示例。
计费模式总览
按输出时长计费
除“添加 AIGC 元数据标识”外，其余所有剪辑工具均采用本计费模式。
计费规则
说明
分辨率判定规则：输出视频的分辨率规格是根据其短边的像素值来判定的。系统会将输出视频的短边与各规格的阈值进行比较，以确定其所属的计费档位。例如，一个分辨率为 1920x800的视频，其短边为 800 像素。因为该值大于 720P 规格的短边（720），但小于等于 1080P 规格的短边（1080），所以该视频将被归入 1080P 档位进行计费。
计费时长说明：AI MediaKit 以“元/分钟”为单位报价，但底层会精确到毫秒来记录实际使用时长。最终生成账单时，系统会将毫秒级的累计时长换算成分钟进行计费。例如，一个处理后时长为 90 秒的任务，其计费时长为 1.5 分钟。

输出媒体文件（视频/音频）的
时长和分辨率。

项目 说明
计费规则
采用“基准单价 + 系数折算”的计费模式，基于
输出文件时长，并结合任务的输出分辨率的计费
换算系数进行计算。
计费项 剪辑工具-基础剪辑-计费时长
基准单价 0.01 元/分钟
计费公式 剪辑工具费用 = 输出文件时长（分钟） × 计费
换算系数 × 0.01 元/分钟
付费方式
按量计费（后付费） ：任务完成后，系统将
根据实际用量从您的账户余额中扣除相应费
用。
资源包（预付费） ：支持使用 “多媒体处理
资源包” 进行抵扣。关于资源包的购买与使
用细则，请参考资源包。

计费示例
以下通过几个典型业务场景，为您演示剪辑工具的具体费用计算过程。
示例 1：视频拼接
场景：您调用提交视频拼接任务 API ，将两段短片合并为一个完整视频。输出视频的分辨率为1920x1080（1080P），总时长为 5 分 30 秒（即 5.5 分钟）。
费用：5.5 分钟 × 6 × 0.01 元/分钟 = 0.33 元
示例 2：音频提取
场景：您调用提交音频提取任务 API ，从一段长视频中剥离出背景音乐，最终输出时长为 8 分 15 秒（即 8.25 分钟）的纯音频文件。
费用：8.25 分钟 × 1 × 0.01 元/分钟 = 0.0825 元
示例 3：图片转视频
场景：您调用提交图片转视频任务 API ，传入 10 张高清商品图（分辨率为 1080P），设置每张停留3 秒，最终输出一段时长 30 秒（0.5 分钟）、分辨率为 1080 的动态营销视频。
费用：0.5 分钟 × 6 × 0.01 元/分钟 = 0.03 元
示例 4：智能剪辑
场景：您调用提交智能剪辑任务 API ，指令为“将视频 A 和 B 拼在一起，加上我提供的背景音乐”，系统理解意图后，最终生成了一个时长为 2 分钟、分辨率为 1920x1080（1080P） 的视频。费用：2 分钟 × 6 × 0.01 元/分钟 = 0.12 元

计费示例
场景：您调用提交添加 AIGC 元数据标识任务 API 成功处理了 15,000 个图片文件和 2,000 个视频文件。
计费总次数：15,000 + 2,000 = 17,000 次
费用：(17,000 次 / 1000) × 1.00 元/千次 = 17.00 元
项目 说明
计费规则 基于成功处理次数进行计算，每成功处理 1 个媒
体文件（不区分视频、音频、图片）计为 1 次。
计费项 剪辑工具 - 添加 AIGC 元数据标识 - 计费次数
单价 1.00 元/千次
计费公式 费用 = (成功处理总次数 / 1000) × 1.00 元/千次
付费方式

根据实际用量从您的账户余额中扣除相应费
用。
资源包（预付费） ：支持使用 “多媒体处理
资源包” 进行抵扣。关于资源包的购买与使
