3.2.10 图像翻译
AI MediaKit 图像翻译工具能够自动识别图像中的文字内容，并将其翻译为指定的目标语言，最终生成保留原图布局和视觉风格的新图像。该功能适用于跨境电商商品图、漫画、游戏、行业文献、路牌菜单等多语言本地化场景。
本篇开发指南将引导您：
快速体验通过一次 API 调用将图片中的文字翻译成另一种语言。
理解不同翻译模型的效果差异与适用场景。
效果示例
快速体验：一键翻译图片文字
图像翻译是一个同步任务，您发起的请求会直接在响应中返回处理结果。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备图像文件：准备一张待翻译的图片，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程
您只需调用提交图像翻译任务 API ，即可在 API 的响应体中直接获取翻译后的图片地址。步骤 1：提交任务并获取结果
可直接复制以下 cURL 命令，替换其中的参数后执行。该示例将图片中的英文翻译为中文。说明
将 {Your_API_Key} 替换为您的有效 API Key。
将 image_url 替换为您真实的图片地址。
此示例未指定源语言，系统会自动检测。
步骤 2：查看响应
由于是同步接口，请求成功后，您会在几秒内收到包含最终结果的响应。您可以直接从 result.image_url字段获取翻译后图片的下载地址（有效期为 24 小时）。
进阶使用

--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {Your_API_Key}' \
--data '{
 "image_url": "https://example.com/image_in_english.jpg",
 "target_lang": "zh"
}'

切换模型版本
图像翻译工具提供了多种模型版本以适应不同场景的需求，您可以通过 tool_version 参数进行选择。指定源语言与目标语言
您可以通过 source_lang 和 target_lang 参数来指定源语言和目标语言。不同模型版本支持的语种有所不同，详情请参考附录：支持的语种。
示例：将日语图片翻译为英语
参考信息
性能与限制
模型版本 (tool_version) 描述与适用场景
seed-translation (默认)
大模型版擦除模型。使用 doubao-seedtranslation 模型 翻译图片，先擦除翻译区
域，再将翻译后的文本放置在翻译区域中。效果
最佳。
erase 擦除翻译区域模型。在翻译图片时，先擦除翻译
区域，再将翻译后的文本放置在翻译区域中。
overlay-translation 直接叠加译文，不擦除原文。适合保留原图布
局、强调译文叠加效果的场景。
dense-text-translation
密集文本非擦除模型。适用于漫画等文字密集型
翻译场景。翻译后的文本会直接叠加在原始文本
上。
logo-retain-erase-translation 带品牌识别的擦除模型。在翻译图片时，能够识
别并保持品牌 Logo/名称不被翻译。

输入图像限制
图像来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、火山引擎对象存储
( tos:// ) 三种输入协议。关于各协议的具体
说明和使用示例，请参阅多源媒体输入与本
地上传。
