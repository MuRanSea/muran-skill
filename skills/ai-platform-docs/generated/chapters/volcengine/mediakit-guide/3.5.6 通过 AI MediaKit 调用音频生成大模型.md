3.5.6 通过 AI MediaKit 调用音频生成大模型
您可以通过 AI MediaKit 调用已在豆包语音 开通的音频生成大模型，用一句文本提示词生成音频，无需再单独对接豆包语音接口。
本篇开发指南将引导您快速体验如何通过 AI MediaKit 调用音频生成大模型，用一段文本提示词生成音频。
快速入门：合成一段音频
本节以将一段文本合成为 mp3 音频为例，演示通过 AI MediaKit 调用音频生成大模型的完整流程。准备工作
开通模型：在豆包语音 控制台开通所需的音频生成模型，并记录可用的模型标识。
进行跨服务授权：前往 AI MediaKit 控制台授权管理页面 ，为 AI MediaKit 授予访问您豆包语音资源的权限。
获取访问凭证：访问 AI MediaKit 控制台的 API Key 管理页面 ，创建并获取 MediaKit API Key。操作流程
通过 AI MediaKit 调用音频生成大模型以异步任务方式进行，其标准流程如下：
调用 POST /api/v1/tools/call-maas-proxy 提交任务， api 设为 doubao.audio_generation ，即可获得一个任务 ID。
轮询 GET /api/v1/tasks/{task_id} 接口，直到任务状态 status 变为 completed ；或使用事件回调 自动接收任务状态变化。
任务完成后，从响应 result.maas_result 中读取豆包音频生成接口返回的原始结果（如音频地址），并从 result.duration 获取合成音频的总时长（秒）。
第 1 步：提交音频生成任务
调用MaaS 模型代理 API 。可直接复制以下 cURL 命令，将一段文本提交音频生成任务。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/call-maas-proxy' \-H 'Authorization: Bearer {Your_API_Key}' \
-H 'Content-Type: application/json' \
-d '{
 "api": "doubao.audio_generation",
 "maas_params": {
 "model": "seed-audio-1.0",
 "text_prompt": "欢迎使用 AI MediaKit，这是一段音频生成示例。",
 "audio_config": {
 "format": "mp3",
 "sample_rate": 48000,
 "pitch_rate": 0,
 "speech_rate": 0,
 "loudness_rate": 0
说明
将 {Your_API_Key} 替换为您的有效 MediaKit API Key。
maas_params 内为豆包音频生成接口所需的业务参数，请以豆包语音 - 音频生成 API 为准；其中 model 、音色等字段请按您已开通的模型填写。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。
第 2 步：获取合成结果
您需要轮询查询任务信息 API ，直到任务状态 status 变为 completed 。
