3.2.6 图像文字识别（OCR）
AI MediaKit 图像文字识别（OCR）工具，能够快速、准确地识别图片中的印刷体文字（中英文），并返回每个文本块的可编辑内容、位置坐标及置信度，适用于从文档扫描件、屏幕截图、海报或自然场景图片中提取文本信息等多种场景。本工具提供两个版本：
标准版：支持简体中文和英文印刷体的通用文字识别，返回每个文本块的内容、坐标及置信度。加强版：相比于标准版，识别精准度更高，且适用范围更为广泛。
本篇开发指南将引导您快速体验通过一次 API 调用完成图像文字识别。
快速体验：一键识别图中文字
图像文字识别是一个同步任务，您发起的请求会直接在响应中返回识别结果，无需轮询。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备图像文件：准备一张包含文字的图片，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程

应用场景
资质审查：在银行、信贷、零售和电商等行业中，识别并核验营业执照、商标注册证等证件。这有助于节省人力成本、提高审核效率，并有效降低业务风险。
内容审核与管理：在社交、电商等平台，识别图片中的违规文字，例如不文明用语、涉黄、涉暴等内容。这有助于快速定位问题图片并进行审核，从而有效规避业务风险。
纸质文件内容电子化：将书本、论文、档案、PPT 等印刷文件内容快速电子化。识别并整理纸质文件中的文本，可方便学校、图书馆、企事业单位等进行资料录入，进而提高内容整理的效率。使用限制

限制项 说明
图像大小 单张图片不得超过 10 MB。
图像输入分辨率
短边不得超过 2160 px
长边不得超过 3840 px
图像质量建议
为保证最佳识别效果和性能，请注意：
图像方向：避免使用旋转角度超过 30 度的图
片，以防识别效果不佳或处理超时。
文字密度：对于文字密度过高的图片（例如
整页密排的文档），建议将其切分后再提交
识别，以规避因处理内容过多而导致超时。
