3.1.22 视频抽帧
AI MediaKit 的视频抽帧工具，可以从视频中截取一张或多张静态图片。您可以根据不同的业务场景，选择按时间间隔、按指定时间点、按指定帧（首/尾帧）或按场景变化四种策略进行抽帧。截取的图片可用于生成视频封面、预览图、雪碧图，或作为其他视频理解任务的输入。
本篇开发指南将引导您：
快速体验如何按固定时间间隔从视频中抽帧。
掌握使用不同策略进行抽帧的核心参数。
快速入门：按时间间隔均匀抽帧
本节以“按时间间隔抽帧”为例，演示如何从一段视频中每隔 10 秒截取一帧。
准备工作
获取访问凭证：在开始之前，请访问 AI MediaKit 控制台的 API Key 管理页面 ，创建并获取 MediaKitAPI Key。
准备视频文件：准备一个待处理的视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。为方便您快速测试，本文后续步骤的示例代码中提供了一个可直接使用的演示视频 URL。
操作流程
视频抽帧是一个异步任务，其标准流程如下：
成功调用 POST /api/v1/tools/extract-frames 提交任务后，您将获得一个任务 ID。
您可以轮询 GET /api/v1/tasks/{task_id} 接口，直到任务状态 status 变为 completed ；或者使用事件回调 自动接收任务状态变化。
任务完成后，解析响应中的 result 字段，即可在 snapshots.image_url 中获取截图的下载地址。第 1 步：提交抽帧任务
您需要调用提交视频抽帧任务 API 。可直接复制以下 cURL 命令，提交一个从视频中每 10 秒截取一帧的任务。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/extract-frames' \-H 'Authorization: Bearer {Your_API_Key}' \
-H 'Content-Type: application/json' \

 "video_url": "https://vod-ai-test.tos-cn-beijing.volces.com/demo/dragon.mp4",
 "snapshot_type": "TimeInterval",
 "time_interval": 10

生成雪碧图
雪碧图是由多张截图按一定行列顺序拼接而成的一张大图。在播放器中，它常用于实现进度条预览功能，允许用户在拖动进度条时快速查看视频缩略图，具有以下优势：
减少网络请求：将多张小图合并为一张大图，客户端只需请求一次即可获取所有预览帧，显著降低了服务器压力并提升加载速度。
优化存储与压缩：单张大图相比于海量小图，更易于管理和存储，且通常能获得更好的压缩效果。以下示例展示了如何从视频中每 10 秒截取一帧，并将这些截图合成为一个 5x5 的雪碧图。curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/extract-frames' \-H 'Authorization: Bearer {Your_API_Key}' \

限制项 说明
输入视频限制
视频来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、来源于火山引擎视频点
播 ( vod:// ) 和火山引擎对象存储 ( tos:// ) 四
种输入协议。关于各协议的具体说明和使用
示例，请参阅多源媒体输入与本地上传。
支持格式：mp4, mov, mkv, flv, ts, avi, wmv 等
主流视频格式。
截图数量限制
通过 snapshot_limit 参数可限制 TimeInterval
和 SceneChange 策略生成的截图最大数量，上
限为 1000。 SpecifiedTime 策略最多支持 1000
个时间点。
雪碧图限制
当 enable_sprite 设为 true 时，系统会生成雪
碧图。建议雪碧图的最终尺寸（宽或高）不要超
过 16384 像素，否则可能导致任务失败。您可
以通过调整 sprite_rows 、 sprite_cols 以及缩放
参数（ scale_long / scale_short ）来控制最终尺
寸。
