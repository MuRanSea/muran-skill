3.3.2.2 Web 剪辑 SDK 集成指南
本文面向需要在 Web 页面中集成剪辑能力的前端开发者。通过 AI MediaKit Web 剪辑 SDK，你可以在业务页面中嵌入完整的剪辑编辑器，包括素材管理、轨道编辑、特效渲染和视频导出，无需自行拼装底层编辑器组件。
SDK 概述
AI MediaKit 提供一款一站式 Web 剪辑 SDK @volcengine/amk-editor ，将编辑器界面、素材管理、轨道编辑、特效渲染和视频导出封装在一个包中，你只需提供剪辑工程标识和业务代理地址，即可在页面中快速嵌入完整的剪辑能力。
能力 说明
主题与布局
SDK 内置了一套开箱即用的专业剪辑界面，你可
以轻松将编辑器切换为亮色或暗色主题，以适配
你的业务页面风格。同时，SDK 内置了素材面板
的收起/展开等布局管理能力，无需额外开发。
剪辑工程管理
你可以将一个剪辑工程理解为一个独立的剪辑任
务或草稿，包含了本次剪辑所用到的所有素材
（视频、音频、图片）以及它们在时间轴上的排
列、应用的特效和字幕等所有编辑信息。SDK 通
过唯一的工程 ID projectId 来自动加载和保存你
的所有工作。
素材库管理
SDK 提供了完整的素材管理面板。你可以通过它
上传本地文件、通过 URL 添加网络资源，或从
你自己的业务资产库导入素材（这需要你实现对
应的回调函数），SDK 会自动为素材发起抽帧任
务生成预览图。所有素材都属于当前剪辑工程，
并显示在素材面板中，方便你随时拖拽到轨道上
使用。
架构与核心概念
在开始集成之前，你需要了解 AI MediaKit Web 剪辑 SDK 的一个核心设计原则：为保障密钥（API Key）安全，浏览器不能直接请求 AI MediaKit 服务，必须通过你自己的业务代理服务来中转。这个代理服务需要由你自己在服务端实现，主要负责两件事：
安全地附加密钥：将存储在你自己服务器上的 AI MediaKit API Key 添加到请求中。
转发请求：将来自 SDK 的请求安全地转发给 AI MediaKit 服务端。

能力 说明
预设资源
SDK 自带了丰富的预设资源库，包括字体、花
字、文字动画、转场、滤镜和特效等。你可以通
过配置项决定开启哪些资源面板，为用户提供多
样的创作能力。
视频导出
SDK 内置了导出弹窗和相应的参数配置（如分辨
率、帧率、格式等）。用户完成配置后，SDK 会
将整个剪辑工程提交到服务端进行异步渲染合
成，最终输出一个完整的视频文件。用户可在右
上角任务列表查看和下载。
ASR 字幕
用户可以在编辑器中一键为视频或音频素材发起
语音转字幕（ASR）任务。任务完成后，SDK 会
自动将生成的字幕文本和时间戳添加到时间轴的
字幕轨道上。
概念 说明
projectId
剪辑工程的唯一标识。SDK 使用此 ID 关联工程
的素材库和编辑数据。你需要在初始化 SDK 前
通过服务端 API 创建剪辑工程并获取此 ID。
endpoint（业务代理）
业务代理的基础地址，负责注入 AI MediaKit API
Key、校验用户权限，并将请求安全地转发到 AI
MediaKit 上游。例如，若传入 xxx.xxx.com/api/
amk-proxy ，SDK 的实际请求路径将是 
xxx.xxx.com/api/amk-proxy/{targetPath}/... 。
准备工作
在正式开始集成编码前，请确保已完成以下一次性的前置准备，为你后续创建工程、实现代理服务提供必要的权限和凭证。
开通 AI MediaKit 服务： 确保你的火山引擎账号已开通 AI MediaKit 服务 。
获取并妥善保管 API Key： API Key 是你在服务端调用 AI MediaKit API 进行身份认证的唯一凭证。它与你的账号绑定，具有高权限，必须妥善保管。你可以前往 AI MediaKit 控制台的 API Key 管理页面 创建并获取专用 API Key。获取后，可将其配置为你服务端（即业务代理）的环境变量。
API Key 是高权限凭证，必须严格保管在服务端。严禁将其硬编码在前端代码中或通过任何方式传递到浏览器。浏览器端的所有请求都应只访问你自己的业务代理地址。

最佳实践：为了数据安全，建议将存储桶访问权限设为“私有”。在你的数据库和剪辑工程中，始终使用固定的 tos://bucket/key 地址保存素材位置。仅在前端页面需要播放或展示时，才通过 STS 服务动态生成临时的签名 URL。
