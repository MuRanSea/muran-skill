3.3.2.17 视频高斯模糊
AI MediaKit 的视频高斯模糊工具，允许您对视频画面中的一个或多个指定矩形区域应用高斯模糊效果。此功能常用于保护隐私信息（如人脸、证件号码）、遮挡固定的水印或角标等场景。输出的视频为 MP4格式。
本篇开发指南将引导您了解如何通过 API 调用，为您的视频精准添加模糊效果。
效果预览
通过视频高斯模糊工具，您可以对视频中的特定区域进行动态模糊处理，以达到遮挡信息的目的。快速体验：为视频中的指定区域添加模糊
本节将通过一个具体的示例，演示如何调用 API 为一段视频的第 5 秒到第 10.5 秒的指定矩形区域添加高斯模糊效果。
准备工作
获取访问凭证：在开始之前，请访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取您的 AIMediaKit API Key。
准备视频文件：准备一个需要添加模糊效果的视频文件，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程
视频高斯模糊是一个异步任务，调用 API 的整体流程如下：
成功调用 POST /api/v1/tools/gaussian-blur-video 提交任务后，您将获得一个唯一的 task_id 。原视频 添加高斯模糊后
您可以通过轮询 GET /api/v1/tasks/{task_id} 接口来查询任务状态，直到状态（ status ）变为 completed 。或者，配置事件回调 自动接收任务状态变化。
任务完成后，解析响应中的 result 字段，即可在 video_url 字段中获取处理后视频的下载地址。第 1 步：提交任务
您需要调用提交视频高斯模糊任务 API 。可直接复制以下 cURL 命令提交。该示例将为视频的指定时间段和坐标区域添加模糊效果。
说明
需替换参数：
请将 {Your_API_Key} 替换为您的有效 API Key。
请将 video_url 的值替换为您自己准备的视频文件 URL。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。

进阶使用
定义模糊区域
您可以通过 blur_regions 参数手动指定一个或多个矩形区域进行模糊。 blur_regions 是一个数组，最多支持 3 组配置，每组配置（一个 JSON 对象）定义一个模糊区域及其生效的时间段。
每个区域的位置通过其左上角和右下角的坐标来定义，所有坐标值均以像素（pixel）为单位，原点 (0, 0) 为视频画面的左上角。
top_left_x : 矩形左上角的 X 坐标（图中 b1）。
top_left_y : 矩形左上角的 Y 坐标（图中 a1）。
bottom_right_x : 矩形右下角的 X 坐标（图中 b2）。
bottom_right_y : 矩形右下角的 Y 坐标（图中 a2）。
