3.1.6 极智超清
AI MediaKit 的极智超清工具基于人眼视觉系统特性，在转码过程中针对视频中的场景、动作、内容、纹理等进行智能分析，选择最优的编码参数。这使得您可以用相对更低的码率，输出主观画质更优的视频，从而在降低存储和带宽成本的同时，为用户带来更好的视觉体验。
本篇开发指南将引导您快速体验如何通过极智超清工具，将一个视频转换为压缩效率更高的编码格式（如 H.265），以在保证主观画质的同时，有效降低文件体积。
快速入门：基础极智超清任务
本节演示如何通过极智超清工具将一个采用 H.264 编码的视频转码为 H.265 编码格式。
准备工作
获取访问凭证：在开始之前，请访问 AI MediaKit 控制台的 API Key 管理页面 ，创建并获取 MediaKitAPI Key。
准备视频文件：准备一个待处理的视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。为方便您快速测试，本文后续步骤的示例代码中提供了一个可直接使用的 H.264 编码的演示视频 URL。
操作流程
极智超清是一个异步任务，其标准调用流程如下：
调用 POST /api/v1/tools/martencode-video 提交任务，获得一个用于查询的 task_id。
轮询 GET /api/v1/tasks/{task_id} 直至任务完成，然后从 result.video_url 字段中获取优化后视频的下载地址。
第 1 步：提交极智超清任务
您需要调用提交极智超清任务 API 。可直接复制以下 cURL 命令，提交一个将 H.264 视频转为 H.265 编码、并保持原始分辨率的任务。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/martencode-video' \-H 'Authorization: Bearer {Your_MediaKit_API_Key}' \
-H 'Content-Type: application/json' \
-d '{
 "video_url": "https://vod-ai-test.tos-cn-beijing.volces.com/demo/demo_480p.mp4",
 "container_format": "MP4",
 "video": {
 "codec": "h265",
 "scale_type": 0,
 "bitrate_mode": "crf",
 "bitrate_crf": 25,
 "bitrate_kbps": 2000
 }
}'
Plain
说明
将 {Your_MediaKit_API_Key} 替换为您的有效 API Key。
video_url ：示例中已提供可直接用于测试的演示视频 URL。您也可以将其替换为您自己的视频地址。
这个示例展示了极智超清的核心用法： 
"codec": "h265" ：指定输出压缩效率更高的 H.265 编码。
"scale_type": 0 ：表示不进行任何缩放，保持视频的原始分辨率。
"bitrate_mode": "crf" 与 "bitrate_kbps": 2000 ：联合使用。既确保日常场景下通过 CRF 25 智能省流，又给复杂、高运动的场景加一层“码率天花板（不超过 2000 Kbps）”，防止因瞬间
码率飙升导致用户播放卡顿。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。
第 2 步：获取转码结果
极智超清任务需要一定的处理时间。您需要轮询查询任务信息 API ，直到任务状态 status 变为 completed 。
当任务成功完成后，您将收到如下响应。您可以在 result.video_url 字段中找到最终生成的视频文件下载地址（默认有效期为 24 小时）。
