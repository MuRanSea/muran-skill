3.1.23 视频转封装
视频转封装（Remuxing）是指在不重新编码音视频码流的前提下，仅改变文件容器格式的过程。由于不涉及复杂的编解码计算，转封装具有处理速度极快、无画质和音质损失、成本极低的优点。AI MediaKit的视频转封装工具支持在 MP4、FLV、MPEG-TS 等主流格式间进行快速转换，广泛适用于点播分发适配、流媒体切片打包与多端兼容等场景。
本篇开发指南将引导您快速掌握如何通过 API 调用，实现视频格式的秒级转换。
快速入门：基础转封装任务
本节演示如何将一个 MP4 格式的视频文件快速转换为 FLV 格式。
准备工作
获取访问凭证：在开始之前，请访问 AI MediaKit 控制台的 API Key 管理页面 ，创建并获取您的 AIMediaKit API Key。
准备视频文件：准备一个待处理的视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。
操作流程
视频转封装是一个异步任务，其标准流程如下：
调用 POST /api/v1/tools/remux-video 提交任务，API 将返回一个任务 ID。
轮询 GET /api/v1/tasks/{task_id} 直至任务状态 status 变为 completed ；或者使用事件回调 自动接收任务状态变化。
任务完成后，您可解析 result 字段，在 video_url 字段处获取转封装后视频的下载地址。第 1 步：提交转封装任务
您需要调用提交视频转封装任务 API 。可直接复制以下 cURL 命令，提交一个将视频从 MP4 封装为 FLV的任务。
说明
将 {Your_MediaKit_API_Key} 替换为您的有效 API Key。
video_url ：示例中请替换为您自己的视频地址。
container_format ：指定目标封装格式。支持 MP4（默认）, FLV, MPEGTS。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/remux-video' \-H 'Authorization: Bearer {Your_MediaKit_API_Key}' \
-H 'Content-Type: application/json' \
-d '{
 "video_url": "https://vod-ai-test.tos-cn-beijing.volces.com/demo/demo-480p.mp4",
 "container_format": "FLV"
}'
Bash
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。
第 2 步：获取转封装结果
轮询查询任务信息 API ，直到任务状态 status 变为 completed。
当任务成功完成后，您将收到如下响应。您可以在 result.video_url 字段中找到最终生成的 FLV 格式视频的下载地址（默认有效期为 24 小时）。
