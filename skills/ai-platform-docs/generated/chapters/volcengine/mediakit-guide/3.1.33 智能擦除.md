3.1.33 智能擦除
智能擦除结合音频语义和视频画面，自动识别视频中的字幕、水印等后期叠加文字，定位其出现的时间和区域，并对目标区域进行无痕擦除。您既可以只提供源视频，让系统自动检测并擦除，也可以通过时间段和矩形区域手动指定擦除范围。
支持的擦除目标
通过 presets 指定擦除目标类别，可组合使用，默认值为 ["all"] ：
如需同时处理多类目标，可传入多个类别，例如 ["watermark", "subtitle"] 。
与字幕擦除（精细化版）的区别
如需按算法版本、字幕特征（文字高度、水平居中）精细控制，请使用字幕擦除（精细化版）。快速体验：自动擦除字幕
准备工作
完成 IMP 智能处理跨服务授权：首次使用智能擦除工具前，请前往 AI MediaKit 控制台基础配置 > 授权管理 页面，为 AI MediaKit 授予访问您 IMP 智能处理资源的权限。未完成授权时，任务将因无权限访问而失败。同一账号下只需授权一次，后续调用无需重复操作。
获取访问凭证：前往 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 API Key。

操作流程
智能擦除是一个异步任务，整体流程如下：
调用 POST /api/v1/tools/erase-video-vlm 提交任务，获取 task_id 。
使用 task_id 轮询 GET /api/v1/tasks/{task_id} ，直到 status 变为 completed 或 failed ；您也可以通过事件回调 接收任务状态变化。
任务完成后，从 result.video_url 获取处理后的视频地址。
第 1 步：提交任务
调用提交智能擦除任务 API ，传入源视频地址，并将 presets 设置为 subtitle 。

mode 控制擦除范围的确定方式，默认值为 auto ：
auto ：系统自动检测并擦除 presets 指定类别对应的文字与水印。同时传入 erase_hint_rules 时，提示规则会与自动检测结果合并使用，可用于补充系统漏检的区域。
manual ：系统按 erase_hint_rules 中指定的时间段和矩形区域执行擦除，适用于位置固定、需要精确控制擦除范围的水印、台标等元素。
指定时间段与擦除区域
通过 erase_hint_rules 指定擦除范围，一次请求最多包含 400 项规则。每项规则由可选的时间段和可选的矩形区域组成：
只指定时间段：擦除该时间段内的全画面。
只指定矩形区域：擦除完整视频内的该区域。
同时指定时间段和矩形区域：擦除该时间段内的该区域。
同一时间段如需擦除多个不相邻的区域，可通过多项分别指定同一时间段的不同矩形区域。时间段以秒为单位，须同时提供 start_time 和 end_time ，且 0 ≤ start_time < end_time 。矩形区域使用归一化坐标（画面左上角为原点 (0, 0) 、右下角为 (1, 1) ），须同时提供四个坐标，且 top_left_x <bottom_right_x 、 top_left_y < bottom_right_y 。
以下示例使用 manual 模式，仅擦除 0–15 秒内画面右下角的水印：
{
"video_url": "https://example.com/source_video.mp4",
"presets": ["watermark"],
"mode": "manual",
"erase_hint_rules": [
{
"start_time": 0,
"end_time": 15,
"top_left_x": 0.62,
"top_left_y": 0.86,
"bottom_right_x": 0.97,
"bottom_right_y": 0.96
}
]
}
JSON

选择输出封装格式
output_format 控制输出视频的封装格式，默认值为 mp4 ：

参考信息
使用限制
presets 至少包含 1 个类别，默认为 ["all"] ，即擦除水印和字幕；仅需处理特定类别时请显式传入。erase_hint_rules 单次请求最多 400 项；每项至少指定时间段或矩形区域，时间段须成对提供且 start_time 小于 end_time ，矩形区域的四个坐标须同时提供且取值均在 [0, 1] 内。
识别效果受音频清晰度、字幕与水印的可见性、画面复杂度及字幕与语音匹配程度影响。复杂背景、动画文字、遮挡或音画不同步时，可能出现漏擦或误擦。
输入视频最高支持 2K 分辨率，输出视频最高为 1080P。
使用 Quality 模式时，输出文件码率和体积可能明显高于源文件；对文件体积敏感时建议使用 Size模式。
计费说明
智能擦除按任务结果中的视频时长计量，沿用字幕擦除（精细化版）的计费项，不因擦除目标类别或模式变化新增计费项。具体计费信息请参阅视频工具计费。
