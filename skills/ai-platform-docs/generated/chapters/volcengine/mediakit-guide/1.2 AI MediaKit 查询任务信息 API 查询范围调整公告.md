1.2 AI MediaKit 查询任务信息 API 查询范围调整公告
为提升 AI MediaKit 整体服务的稳定性与查询性能，为您提供更优质、高效的体验，我们计划于 2026 年 8月 20 日，对查询任务信息 API 的数据查询时效性进行调整。
变更详情如下： 
涉及接口：查询任务信息 API
调整内容：数据查询范围由不限时长调整为仅支持查询最近 30 天内创建的任务。
对您的影响：自 2026 年 8 月 20 日起，调用该 API 查询 30 天前创建的任务时，系统将返回任务不存在或查询失败的提示。
您需要采取的措施：如果您的业务需要依赖、存储或回溯 30 天以上的任务信息，我们强烈建议您检查并调整您的业务逻辑： 
及时转存任务数据：在任务完成后，通过查询任务信息 API 获取详情，并立即将所需信息（如任务状态、处理结果等）保存到您自己的业务数据库或存储服务中，以便长期归档。
（推荐）配置事件回调：为确保实时、可靠地接收任务结果，避免数据遗漏，我们推荐您配置事件回调 。配置后，AI MediaKit 会在任务完成时主动将结果推送到您的服务器。
请您在此日期前完成相关业务逻辑的检查与调整，以确保业务平稳运行。
如果您对此调整有任何疑问，您可以提交工单 或联系客户经理咨询。
感谢您对 AI MediaKit 的支持与理解！
