3.1.14 高光智剪-小游戏
AI MediaKit 的“高光智剪 - 小游戏”工具，基于多模态视频理解，深度理解消除、闯关、竞技等各类小游戏玩法，自动从原始录屏中精准捕捉“全屏连击、BOSS 通关、极限操作”等高光瞬间，快速生成适用于买量推广、社区分享等场景的视频素材。您可以通过提供游戏名称、玩法描述、高光定义等信息，来辅助模型更精准地识别和剪辑精彩内容。
本篇开发指南将引导您：
快速体验从一个游戏录屏视频中，自动生成高光集锦。
学习如何通过提供游戏描述信息，来提升剪辑的精准度和效果。
了解该功能的工作原理与使用限制。
效果预览
通过“高光智剪 - 小游戏”工具，您可以将一段原始的游戏录屏视频作为输入，快速生成一段剪辑好的高光集锦。
快速体验：生成一个基础的小游戏高光视频
本节将演示如何从一个游戏录屏文件中，快速生成一个高光集锦。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备视频文件：准备好一个小游戏录屏视频，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。

操作流程
小游戏高光智剪是一个异步任务，完整流程如下：
成功调用 POST /api/v1/tools/generate-highlights-minigame 提交任务后，您将获得一个任务 ID。您可以轮询 GET /api/v1/tasks/{task_id} 接口，直到任务状态 status 变为 completed ；或者使用事件回调 自动接收任务状态变化。
任务完成后，解析响应中的 result 字段，即可在 video_urls 数组中获取最终生成的视频文件下载地址。

限制项 说明
输入视频限制
视频来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、来源于火山引擎视频点
播 ( vod:// ) 和火山引擎对象存储 ( tos:// ) 四
种输入协议。关于各协议的具体说明和使用
示例，请参阅多源媒体输入与本地上传。
支持格式： mp4 , flv , ts , avi , mov , 
wmv , mkv 等主流视频格式。
数量限制：单次任务仅支持输入 1 个视频文
件。
时长限制：输入文件时长不得超过 10 分钟。
分辨率限制：最高支持 1080p。
并发限制
默认情况下，每个账户的并发处理任务数上限为
20。超出并发限制的新任务将自动进入队列等
待。
单视频处理耗时
处理耗时和输入视频时长正相关。视频时长越
长，处理耗时越长。平均 RTF（处理耗时/原片
时长）为 1.5～2。
