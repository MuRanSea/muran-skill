3.4.2 语音端点识别
AI MediaKit 的语音端点识别工具，能够自动定位您输入的音频或视频文件中有效语音的起止时间，将人声和静音、背景噪声等无效片段区分开来，返回一个包含所有有效人声片段起止时间戳的列表，为后续识别、分析、剪辑和训练提供更干净的音频输入。
本篇开发指南将引导您：
理解语音端点识别的核心能力与应用场景。
快速从一段媒体文件中检测出所有有效人声片段的时间戳。
效果预览
通过语音端点识别工具，您可以实现以下效果：
快速体验：从音频中识别语音片段
本场景演示如何从一段包含人声、静音和背景音的音频文件中，识别出所有包含有效人声的片段及其起止时间。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备媒体文件：准备一个待处理的视频或音频文件，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。为方便您快速测试，本文后续步骤的示例代码中提供了一个可直接使用的演示音频 URL。
