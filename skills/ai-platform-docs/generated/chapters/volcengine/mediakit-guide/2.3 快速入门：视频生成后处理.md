2.3 快速入门：视频生成后处理
AI MediaKit 的画质增强（大模型版）工具，专为 Seedance 2.0 等 AIGC 视频生成场景打造。它基于先进的Diffusion 扩散大模型技术，提供生成式视频修复与增强能力，不仅能修复视频在压缩或低清生成过程中损失的细节，更能通过深度语义理解，智能地补全和生成符合视频内容的真实细节，最终产出媲美模型直出的高保真、高分辨率视频。
本篇快速入门将引导您在几分钟内，将一段 AI 生成的 480p 低清视频提升至 1080p。
效果预览
通过画质增强（大模型版）的深度语义理解与像素级修复，视频的清晰度、色彩及细节保真度均得到全面提升。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备视频文件：准备由 AI 生成的原始视频 URL。 
若您尚未生成视频，可参考火山方舟视频生成文档 完成视频生成并获取视频地址。请确保该视频URL 处于公网可访问状态（支持 HTTP/HTTPS 协议）。
为方便您快速测试，本文后续步骤的示例代码中提供了一个可直接使用的演示视频 URL。
注意
输入视频（480p） 增强至 1080p
◦
◦
画质增强（大模型版）工具对输入视频有以下要求：
分辨率：最高支持 1080p。具体规格要求： 
短边范围：[360,1080]
长边范围：[360,1920]
色彩空间：仅支持 SDR 视频。
文件大小：建议不超过 10 GB。
操作流程
画质增强是一个异步任务：
调用 POST /api/v1/tools/enhance-video-generative API，API 将返回一个任务 ID。
轮询 GET /api/v1/tasks/{task_id} API，直到任务状态 status 变为 completed 。
任务完成后，解析 result 字段，在 video_url 字段处获取最终生成的视频文件下载地址。说明
成本提示：画质增强（大模型版）是付费工具。为节约成本，建议您预先购买多媒体处理资源包。以本快速入门演示的将视频增强至 1080p、50 fps 规格为例，每处理 1 分钟视频，将从资源包中抵扣 10 分钟额度。您可以先购买一份售价 9 元的 10 分钟资源包，处理约 1 分钟此类规格的视频，相比按量付费可节省 10% 费用。详细的计费规则与资源包抵扣关系，请分别参考视频工具计费和资源包。
第 1 步：提交任务
您可直接复制以下 cURL 命令提交画质增强任务。
说明
需替换参数：
将 {Your_API_Key} 替换为您的有效 API Key。

◦
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/enhance-video-generative' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {Your_API_Key}' \
--data '{
 "video_url": "https://vod-ai-test.tos-cn-beijing.volces.com/demo/demo_video_480p.mp4",
 "resolution": "1080p",
 "fps": 50
}'
Bash
--data 部分是 JSON 请求体，您可以直接修改其中的关键参数来自定义您的视频： 
video_url ：示例中已提供可直接用于测试的演示视频 URL。您也可以将其替换为您自己的视频地址。
将目标分辨率 resolution 设为 1080p ，同时指定 fps 为 50 。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。
第 2 步：获取结果
画质增强属于高计算量任务，需要一定处理时间。您需要轮询查询任务信息 API 接口，直到任务状态 status 变为 completed 。
说明
需替换参数：将 URL 末尾的 {task_id} 替换为第 1 步返回的任务 ID。
