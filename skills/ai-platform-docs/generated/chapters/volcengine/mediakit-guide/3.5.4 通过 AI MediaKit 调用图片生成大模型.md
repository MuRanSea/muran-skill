3.5.4 通过 AI MediaKit 调用图片生成大模型
您可以通过 AI MediaKit 调用已在火山方舟 开通的图片生成大模型（Seedream 系列），用一句文本提示词生成图片，无需再单独对接火山方舟接口。
本篇开发指南将引导您快速体验如何通过 AI MediaKit 调用图片生成大模型，用一句文本提示词生成图片。
快速入门
本节以用一句文本提示词生成一张 1024×1024 图片为例，演示通过 AI MediaKit 调用图片生成大模型的完整流程。
准备工作
开通模型：在火山方舟 控制台开通所需的图片生成模型（如 Seedream 系列），并记录可用的模型ID 或推理接入点 ID。
进行跨服务授权：前往 AI MediaKit 控制台授权管理页面 ，为 AI MediaKit 授予访问您 ARK 火山方舟资源的权限。
获取访问凭证：访问 AI MediaKit 控制台的 API Key 管理页面 ，创建并获取 MediaKit API Key。操作流程
通过 AI MediaKit 调用图片生成大模型以异步任务方式进行，其标准流程如下：
调用 POST /api/v1/tools/call-maas-proxy 提交任务， api 设为 ark.image_generation 。成功调用后您会获得一个任务 ID。
轮询 GET /api/v1/tasks/{task_id} 接口，直到任务状态 status 变为 completed ；或使用事件回调 自动接收任务状态变化。
任务完成后，从响应 result.maas_result 中读取火山方舟图片生成接口返回的原始结果（如生成图片地址）。
第 1 步：提交图片生成任务
调用MaaS 模型代理 API 。可直接复制以下 cURL 命令，用一句提示词提交一个图片生成任务。curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/call-maas-proxy' \-H 'Authorization: Bearer {Your_API_Key}' \
-H 'Content-Type: application/json' \
-d '{
 "api": "ark.image_generation",
 "maas_params": {
 "model": "doubao-seedream-5-0-pro-260628",
 "prompt": "一张赛博朋克风格的城市夜景海报，霓虹灯，电影质感",
 "size": "1024x1024"
 }
}'
Bash
说明
将 {Your_API_Key} 替换为您的有效 MediaKit API Key。
maas_params 内为火山方舟图片生成接口所需的业务参数，请以火山方舟 - 图片生成 API 为准；其中 model 请替换为您已开通的模型 ID 或推理接入点， size 请按所选模型支持的尺寸填写。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。
第 2 步：获取生成结果
您需要轮询查询任务信息 API ，直到任务状态 status 变为 completed 。
说明
将 URL 末尾的 {task_id} 替换为第 1 步返回的任务 ID。
任务成功完成后，您将收到如下响应。 result.maas_result 为火山方舟图片生成接口返回的原始结果，其结构以火山方舟 - 图片生成 API 为准。

"success": true,
"task_id": "amk-tool-call-maas-proxy-123456789",
"request_id": "20240523100000ABCDEFG12345"
}

参考信息
计费说明
图片生成大模型的用量由火山方舟按其定价计费，请在火山方舟中查看用量与账单；AI MediaKit 不对该调用额外收费。具体价格请参考火山方舟价格说明 。
已知限制
通过 MaaS 模型代理 API 进行图生图时，仅支持通过 URL ( image_url ) 方式提供参考图，暂不支持通过Base64 编码 ( image_base64 ) 方式提供。
