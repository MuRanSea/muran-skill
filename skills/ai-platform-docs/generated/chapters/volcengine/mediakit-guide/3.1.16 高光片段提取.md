3.1.16 高光片段提取
AI MediaKit 的高光片段提取工具，并非直接剪辑视频，而是作为一个智能分析引擎，深度理解您的视频内容。它能精准捕捉视频中的“情绪高潮”、“关键动作”或“高能瞬间”，并以结构化数据（JSON）的形式，输出包含精确时间戳、高光分数、OCR 文本和画面描述的详细元数据。
本篇开发指南将引导您：
快速体验从视频中提取一份完整的高光元数据。
了解如何针对“短剧”和“小游戏”两种不同场景，使用对应的分析模型。
学习如何通过提供辅助信息，提升小游戏场景的分析精准度。

快速体验：提取短剧视频的高光数据
本节将以“短剧”场景为例，演示如何从多个视频片段中，快速提取出包含剧情高光的元数据。准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
输入 3 集短剧视频 输出的高光片段信息示例
准备视频文件：准备好多个短剧视频片段，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程
高光片段提取是一个异步任务，完整流程如下：
成功调用 POST /api/v1/tools/analyze-video-highlights 提交分析任务后，您将获得一个任务 ID。您可以轮询 GET /api/v1/tasks/{task_id} 接口，直到任务状态 status 变为 completed ；或者使用事件回调 自动接收任务状态变化。
任务完成后，解析响应中的 result 字段，即可获取完整的高光分析元数据。
第 1 步：提交任务
您需要调用提交高光片段提取任务 API 。可直接复制以下 cURL 命令，提交一个针对短剧视频的分析任务。
说明
将 {Your_API_Key} 替换为您的有效 API Key。
将 video_urls 列表中的 URL 替换为您真实的短剧视频地址。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。

限制项 说明
通用限制
视频来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、来源于火山引擎视频点
播 ( vod:// ) 和火山引擎对象存储 ( tos:// ) 四
种输入协议。关于各协议的具体说明和使用
示例，请参阅多源媒体输入与本地上传。
支持格式： mp4 , flv , ts , avi , mov , 
wmv , mkv 等主流视频格式。
输入分辨率限制：最高支持 1080p。
短剧模型限制 ( model: "Miniseries" )
输入配额：单次任务最多支持输入 30 个视频
文件，累计总时长建议不超过 45 分钟。
输入素材要求：必须同时包含视频流和音频
流。 
视频画面要求：视频画面下半部分（垂直
位置 0.5-1.0 范围内）必须包含清晰居中的
中文字幕。
音频流要求：视频的音频轨道中必须包含
清晰可识别的中文对话文本。仅包含 BGM
（含歌词）、纯音乐、语气词或无有效语
义的声音，将无法准确识别剧情逻辑。
