3.3.2.12 视频添加运镜
AI MediaKit 视频添加运镜工具能够为静态或平稳拍摄的视频素材一键添加专业的镜头动态效果，如缩放、平移缩放、旋转等，显著提升视频的视觉冲击力和节奏感。此功能常用于素材二次创作、营销片头、短剧动效等场景。
本篇开发指南将引导您了解如何通过 API 调用，轻松为您的视频添加运镜效果。
效果预览
通过视频加运镜工具，您可以将一段静态的镜头变得充满动感。例如，为一个固定机位的宠物视频添加“缩放”运镜后，画面会平滑地移动和放大，仿佛由专业摄影师进行了运镜操作。
运镜名称 效果展示 描述
视频缩放运镜（ zoom ）
模拟镜头向前推进（Zoom
In）或向后拉远（Zoom Out）
的单一缩放效果。突出主体、
强调细节、展示开阔环境。
平移缩放运镜（ pan-zoom ）
使画面在移动的同时进行放大
或缩小，效果更具动感。制作
Ken Burns 特效、让静态图片
或视频动起来。
运镜名称 效果展示 描述
360 度旋转运镜
（ orbit-360 ）
模拟镜头围绕一个中心点进行
360 度旋转，创造出强烈的空
间感和视觉焦点。强调中心物
体、营造眩晕或梦幻感。
镜头弹跳运镜（ bounce ）
为画面添加富有节奏感的弹跳
或轻微震动效果。匹配音乐节
拍、制作卡点视频、增加活泼
动感。
快速体验：添加缩放运镜
本节将通过一个具体的示例，演示如何调用 API 为一段视频添加缩放（ zoom ）效果。
准备工作
获取访问凭证：在开始之前，请访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取您的 AIMediaKit API Key。
准备视频文件：准备一个需要添加运镜效果的视频文件，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程
视频加运镜是一个异步任务，调用 API 的整体流程如下：
成功调用 POST /api/v1/tools/apply-camera-motion 提交任务后，您将获得一个唯一的 task_id 。您可以通过轮询 GET /api/v1/tasks/{task_id} 接口来查询任务状态，直到状态（ status ）变为 completed 。或者，您也可以配置事件回调 自动接收任务状态变化。
任务完成后，解析响应中的 result 字段，即可在 video_url 字段中获取添加运镜后视频的下载地址。第 1 步：提交任务
您需要调用提交视频添加运镜任务 API 。可直接复制以下 cURL 命令提交。该示例将为视频添加“缩放运镜”效果。
