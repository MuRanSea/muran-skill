3.1.24 视频画质检测 VQScore
AI MediaKit 视频画质检测工具集成了火山引擎自研的 VQScore（Video Quality Score）无参考视频质量评价算法，无需原始参考视频，能够直接对视频的视觉质量进行客观打分，模拟人眼主观感受，输出贴近真实观感的质量分数。您可以利用此工具在视频生产、分发、消费等环节对画质进行量化评估与监控。本篇开发指南将引导您：
快速体验检测一段视频的 VQScore 画质分数。
通过轮询或事件回调两种方式获取处理结果。
理解 VQScore 分数的含义及其应用场景。
快速体验：获取一段视频的画质分数
本节演示如何为一个指定的视频 URL 快速获取其 VQScore 画质分数。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备视频文件：准备一个待检测的视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。
操作流程
视频画质检测是一个异步任务：
成功调用 POST /api/v1/tools/assess-video-quality 后，API 将返回一个任务 ID 。
您可以轮询 GET /api/v1/tasks/{task_id} ，直到任务状态 status 变为 completed ；或者使用事件回调接收任务状态变化。
任务完成后，您可解析 result 字段，在 vq_score 字段处获取最终的画质分数。
第 1 步：提交任务
您需要调用提交视频画质检测 VQScore 任务 API 。可直接复制以下 cURL 命令提交。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/assess-video-quality' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {Your_MediaKit_API_Key}' \
--data '{
 "video_url": "https://example.com/your_video.mp4"
}'
Bash
第 2 步：获取结果
画质检测任务需要一定时间。您需要轮询查询任务信息 API ，直到任务状态 status 变为 completed 。当任务成功完成后，您将收到如下响应。 result 字段是一个 JSON 对象，您可以直接从其下的 vq_score字段获取画质分数。
VQScore 的评分范围为 [0, 100] ，分数越高代表画质越好。您可以参考下表来理解不同分数区间的画质水平：

"request_id": "20240523110000ABCDEFG98765"
}

限制项 说明
输入视频限制
视频来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、来源于火山引擎视频点
播 ( vod:// ) 和火山引擎对象存储 ( tos:// ) 四
种输入协议。关于各协议的具体说明和使用
示例，请参阅多源媒体输入与本地上传。
支持格式： mp4 , flv , ts , avi , mov , 
wmv , mkv 等主流视频格式。
分辨率限制：输入视频最高支持 4K
(3840×2160) 分辨率。
