3.1.12 视频识别字幕（OCR）
AI MediaKit 的视频识别字幕工具，利用先进的视频光学字符识别（OCR）技术，能够精准地从视频画面中提取硬字幕（即固化在视频画面中、无法访问的文字），输出一份带时间戳的结构化文本数据，有助于实现字幕提取、视频内容合规审核以及构建视频内容搜索引擎等功能。
本篇开发指南将引导您：
理解视频识别字幕的核心能力与工作流程。
快速从一个视频文件中提取出内嵌的字幕文本。
学习如何使用不同的识别模式以适应不同场景。
效果预览
通过视频识别字幕工具，您可以将一个包含硬字幕的视频文件作为输入，最终得到结构化的 JSON 字幕数据，其中包含了每一句字幕的文本内容和精准的起止时间。

快速体验：从视频中提取硬字幕
本场景演示如何从一段视频中，提取出所有内嵌字幕对应的文本及时间轴。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 MediaKit APIKey（用于媒体处理功能鉴权）。
准备视频文件：准备一个待处理的视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。为方便您快速测试，本文后续步骤的示例代码中提供了一个可直接使用的演示视频 URL。
操作流程
视频识别字幕是一个异步任务，完整流程如下：
成功调用 POST /api/v1/tools/video-ocr 后，API 将返回一个任务 ID。
您可以轮询查询任务信息 API ，直到任务状态 status 变为 completed ；或者使用事件回调 自动接收任务状态变化。
任务完成后，解析 result 字段，即可在 subtitles 数组中获取所有字幕信息。

进阶使用
调整识别范围（默认仅字幕）
默认情况下，视频识别字幕工具仅识别位于视频画面常规字幕位置的文本，适用于绝大多数硬字幕提取场景。除了默认的字幕识别模式（ Subtitle ）外，该工具还提供详细模式（ Detailed ），用于识别画面中所有可见的文本信息，包括但不限于字幕、标题、注释等。
示例：使用详细模式识别视频中的所有文本
详细模式下，返回结果中的每个 subtitle 对象会额外包含两个字段：
text_label ：文本类别标签。 Subtitle 表示字幕； Others 表示画面中的其他文字（如水印、台标、贴片等非字幕内容）。
text_location ：文本在画面中的像素坐标矩形（ top_left_x / top_left_y / bottom_right_x / bottom_right_y ），可用于精确定位文本所在位置。

限制项 说明
输入文件限制
文件来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、来源于火山引擎视频点
播 ( vod:// ) 和火山引擎对象存储 ( tos:// ) 四
种输入协议。关于各协议的具体说明和使用
示例，请参阅多源媒体输入与本地上传。
支持格式： mp4 , flv , ts , avi , mov , 
wmv , mkv 等主流视频格式。
视频时长：单文件时长不得超过 10 分钟。
视频分辨率：支持 240p～4k。
语种支持：当前版本仅支持识别简体中文和
英语。
