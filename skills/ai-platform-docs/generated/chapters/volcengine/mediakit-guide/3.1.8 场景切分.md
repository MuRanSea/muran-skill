3.1.8 场景切分
AI MediaKit 的场景切分工具能够智能分析视频内容，依据镜头切换、转场效果和画面内容的变化，自动将一个长视频精准地切分为多个有意义的场景片段。该工具会输出每个片段的起止时间轴信息，并提供对应独立视频文件的下载地址，从而帮助您轻松实现视频拆条、集锦制作、关键帧提取等下游应用。本篇开发指南将引导您：
理解场景切分的工作方式。
快速从一个视频中获取场景切分的时间码和独立视频文件。
学习如何调整切分粒度并获取独立的切片文件。

准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 MediaKit APIKey（用于媒体处理功能鉴权）。
准备视频文件：准备一个待处理的视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。

进阶使用
调整切分粒度
您可以通过 segment_threshold 、 min_duration 、 max_duration 和 enable_clip_fade 等参数，来精细化地控制场景切分的效果。
segment_threshold ：场景切分的敏感度阈值，范围为 [0, 100]。推荐的经验值为 10 。 值越低，切分得越细碎：算法对画面的变化更敏感，可能将细微的变化也识别为切分点。
值越高，切分得越粗略：算法会忽略一些不那么显著的场景变化。
min_duration ：单个切片的最小时长（秒）。任何小于此时长的片段都将被自动合并到相邻的片段中。
max_duration ：单个切片的最大时长（秒）。任何大于此时长的片段都将被强制切分。
enable_clip_fade ：是否将检测到的淡入/淡出片段作为独立的切片输出。默认为 false 。以下是一个示例请求，展示了如何使用这些参数来定制您的场景切分任务：

限制项 说明
输入文件限制
文件来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、来源于火山引擎视频点
播 ( vod:// ) 和火山引擎对象存储 ( tos:// ) 四
种输入协议。关于各协议的具体说明和使用
示例，请参阅多源媒体输入与本地上传。
支持格式： mp4 , flv , ts , avi , mov , 
wmv , mkv 等主流视频格式。
视频时长：单个视频时长不超过 2 小时。
