3.7 按项目或 API Key 分账
AI MediaKit 支持按项目和 API Key 归集工具调用产生的用量与费用。您可以根据业务隔离粒度选择分账方式，也可以先通过项目隔离业务，再在同一项目内通过 API Key 进一步区分应用、环境或开发者的成本。核心概念
选择分账方式
如果您既需要跨业务隔离资源，又需要核算同一业务内部的成本，可以组合使用两种方式。例如，先为生产业务和测试业务分别创建项目，再在生产项目内为不同应用分配独立的 API Key。
按项目分账
按项目分账适用于需要同时隔离资源管理范围和费用的场景。例如，SaaS 平台可以为每个客户创建项目；企业也可以为不同业务线或生产、测试环境创建项目。
概念 描述
账号 Account
火山引擎账号（主账号）是火山引擎资源归属、
资源使用计量计费的基本主体。火山引擎账号为
其名下所拥有的资源付费，并对其名下所有资源
拥有完全控制权限。
项目 Project
项目是火山引擎提供的资源归属与计费分账的基
本单位。您可以为不同的业务线、产品或环境
（开发、测试、生产）创建不同的项目。这是实
现成本分摊、资源分组和权限管理的核心。
队列 Queue
队列是 AI MediaKit 中用于接收任务的实体，它
将任务与项目进行绑定，从而将任务产生的费用
正确地归属到对应的项目账单下。
API Key
API Key 是调用 AI MediaKit 服务时用于身份认证
的唯一凭证。仅 IAM 通用 API Key 支持作为费用
中心的分拆项，AI MediaKit 专用 API Key 不支
持。

步骤 1：为每个成本归属对象创建项目
登录火山引擎控制台，进入项目管理 页面。
单击新建项目。
输入能够标识成本归属对象的项目名称。例如，按客户分账时可以使用 customer-[您系统中的客户 ID] ；按环境分账时可以使用 production 或 testing 。
创建项目后，当您在 AI MediaKit 控制台顶部通过项目选择器切换项目后，整个控制台的视图和操作范围都将被限定在该项目内。您所看到的用量统计、任务管理、队列管理、基础配置（包含 AI MediaKit 专用API Key 及回调配置）都将是该项目专属的，从而确保不同客户或业务之间的资源和配置是完全隔离的。步骤 2：在项目中创建队列并获取 queue_id
每个项目会自动创建一个名为 default 的默认队列。您可以直接使用默认队列，也可以根据业务需要创建其他队列。
说明
每个账号下最多可创建 10 个队列（含默认队列）。
队列名称创建后不支持修改。
登录 AI MediaKit 控制台 。
在控制台顶部的项目选择器中，选择目标项目。
单击左侧导航栏的队列管理。
单击新建队列并输入队列名称。
创建成功后，在队列列表中复制队列 ID，例如 q00a9731598092652e4a95292434198 。
说明
建议在业务系统中保存成本归属对象与 queue_id 的对应关系，提交任务时根据当前客户、业务或环境读取正确的队列 ID。

完成以上设置后，您就可以按项目查看用量和费用：
查看项目用量：进入 AI MediaKit 控制台用量统计页面 ，通过顶部的项目选择器切换项目。页面上展示的所有用量数据，都仅属于该项目。

常见问题
是否支持将队列从一个项目转移到另一个项目？如何操作？
支持。您可以更改队列所属的项目。操作步骤如下：
登录火山引擎控制台，进入项目管理 页面。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/enhance-video' \-H 'Authorization: Bearer {IAM_API_Key}' \
-H 'Content-Type: application/json' \
-d '{
 "video_url": "https://example.com/video.mp4",
 "tool_version": "professional",
 "resolution": "1080p"
}'
Bash
找到您的目标项目（即您希望将队列转入的新项目，如 Project B），单击该项目的管理资源按钮。单击资源转入按钮，选择需要转移的队列资源，即可将其从原项目（Project A）转移至当前的新项目（Project B）下。
将队列转移到新项目后，用量统计和账单会如何展示？
当您将一个队列从原项目（例如 Project A ）转入新项目（例如 Project B ）后，账单出账规则与控制台用量统计规则分别如下：
账单页面的展示情况：费用的归集以系统最终出账时刻队列当前所属的项目为准。若任务产生费用并在出账时，该队列已转移至 Project B ，则这部分账单费用会记录在 Project B 之下。
AI MediaKit 控制台用量统计页面的展示情况：用量数据是以用户提交任务时队列所绑定的项目为准进行统计的。因此，在队列转移前（属于 Project A 时）提交的任务，其用量统计数据仍会留在 Project A 的统计视图中；队列转移后提交的新任务，用量才会统计到 Project B 中。
由于上述统计维度的差异，在队列跨项目转移后，有可能会出现 AI MediaKit 控制台特定项目下的统计用量与最终账单费用无法完全对应的情况，属于正常现象。
更换或删除 API Key 后，如何查看费用？
每个 API Key ID 是独立的分拆项。更换 API Key 后，新调用产生的费用归属到新的 API Key ID，历史费用仍归属到原 API Key ID。建议保留 API Key ID 与应用、环境或开发者的对应记录，以便后续核对账单。
