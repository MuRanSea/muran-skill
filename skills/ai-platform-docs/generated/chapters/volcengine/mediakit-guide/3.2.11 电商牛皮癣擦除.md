3.2.11 电商牛皮癣擦除
AI MediaKit 的电商图片牛皮癣擦除工具，能自动检测并擦除商品图中的平台水印、品牌 Logo、促销贴纸、价格标签和干扰性文字，输出更干净、更适合二次流转和再创作的商品图。整个过程无需人工框选即可完成，适用于电商搬家、商品图净化、素材二次创作等场景。
效果示例
牛皮癣擦除工具能在保持主体内容不变的前提下，精准移除干扰元素，提升图片质量。
快速体验：一键擦除商品图牛皮癣
电商牛皮癣擦除是一个同步任务，您发起的请求会直接在响应中返回处理结果。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备图像文件：准备一张待处理的图片，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程
您只需调用提交电商牛皮癣擦除任务 API ，即可在 API 的响应体中直接获取处理后的图片地址。步骤 1：提交任务并获取结果
您可以直接复制以下 cURL 命令，替换其中的参数后在您的终端执行。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/remove-image-elements' \-H 'Authorization: Bearer {Your_MediaKit_API_Key}' \
说明
将 {Your_MediaKit_API_Key} 替换为您的有效 API Key。
将 image_url 替换为您真实的图片地址。
步骤 2：查看响应
请求成功后，您将直接收到如下所示的 JSON 响应。 result 对象中的 image_url 即是擦除处理后图片的下载地址。该地址的有效期为 24 小时，请务必及时下载保存。
