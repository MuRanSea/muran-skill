3.4.3 音频内容编辑
AI MediaKit 的音频内容编辑工具，能够基于用户使用自然语言描述的修改诉求，自动定位目标语句，生成与上下文自然连贯的新语音并无缝替换，同时保持音色、情绪、韵律和时序基本一致。该工具适用于短视频、播客、有声内容、课程及广告等场景的口误修正、文案更新与局部改词。当前仅支持中文。快速体验：对一段音频执行改词
本节将演示如何对一段音频执行一处改词。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key。
准备媒体文件：准备一段待编辑的音频（或包含有效音频流的视频）文件，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程
音频内容编辑是一个异步任务，完整的调用流程如下：
成功调用 POST /api/v1/tools/edit-speech 提交任务后，API 将返回一个任务 ID（ task_id ）。您可以轮询 GET /api/v1/tasks/{task_id} 接口查询任务状态，直到状态 status 变为 completed ；或者使用事件回调 自动接收任务状态变化。
任务完成后，从响应的 result 字段中获取编辑后的媒体下载地址（音频输入返回 audio_url ，视频输入返回 video_url ）。
第 1 步：提交音频内容编辑任务
您需要调用提交音频内容编辑任务 API 。可直接复制以下 cURL 命令，提交一个对音频执行改词的任务。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/edit-speech' \-H 'Authorization: Bearer {Your_API_Key}' \
-H 'Content-Type: application/json' \
-d '{
 "audio_url": "https://vod-ai-test.tos-cn-beijing.volces.com/demo/audio_edit_before.mp4",
 "edits": [
 {
 "instruction": "把三九十九替换成二百九十九",
 "search_range": {
 "start_time": 7,
 "end_time": 10
 }
 }
 ]
}'
Bash
说明
将 {Your_API_Key} 替换为您的有效 API Key。
audio_url ：替换为您自己的音频地址。如需编辑视频中的语音，请将 audio_url 替换为 video_url （视频须包含有效音频流）。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。
第 2 步：获取任务结果
音频内容编辑需要一定处理时间，您需要通过轮询查询任务信息 API 来获取最终结果，直到任务状态变为 completed 。
说明

最佳实践
编写清晰的编辑指令：请在 instruction 字段中使用完整、明确的替换指令，例如：“把‘这款产品’改成‘这款面霜’”。 
原文部分：指令中待替换的原文应尽量贴近音频中的实际发音。
新内容部分：指令中替换后的新内容应直接填写目标文本，不要使用谐音或近音词。对于数字和单位，建议使用规范、无歧义的写法（如 960ml 或“九百六十毫升”），以确保生成效果的准确性。指令顺序：当一次提交多条指令时，建议按照它们在音频中出现的先后顺序在 edits 数组中填写，以获得最佳处理效果。
使用 ** search_range ** 精准定位：当同一词语在音频中多次出现，或您希望在特定片段内执行修改时，强烈建议为该指令提供 search_range （包含 start_time 和 end_time ），将搜索范围限定在特定时间区间。这能有效避免误改，显著提升编辑的准确性。
