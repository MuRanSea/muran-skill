3.3.2.3 音视频拼接
AI MediaKit 的音视频拼接工具，可以将多个视频片段或音频片段按指定顺序拼接成一个新文件。无论是将日常拍摄的多个短视频汇集成一个 Vlog，还是将多段录音合并成一期完整的播客，都可以通过简单的API 调用完成。
工具说明
AI MediaKit 为视频和音频的拼接分别提供了独立的 API，但它们遵循完全相同的异步任务流程，并使用同一个 API 查询任务结果。

准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备视频文件：准备多个待拼接的视频文件，并将它们上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。
操作流程
音视频拼接是一个异步任务：
成功调用视频拼接 API POST /api/v1/tools/concat-video 后，API 将返回一个任务 ID。您可以轮询 GET /api/v1/tasks/{task_id} API，直到任务状态 status 变为 completed ；或者使用事件回调自动接收任务状态变化。
任务完成后，您可解析 result 字段，在 video_url 字段处获取最终生成的视频文件下载地址。第 1 步：提交视频拼接任务
您需要调用提交视频拼接任务 API 。可直接复制以下 cURL 命令提交。请确保 video_urls 数组中文件的顺序就是您期望的拼接顺序。

规格说明
为获得最佳的拼接效果，建议您在拼接前，尽量确保所有输入片段的规格（如分辨率、帧率、采样率等）保持一致。
输出分辨率（视频） ：视频拼接任务的输出分辨率，默认以您在 video_urls 数组中传入的第一个视频片段的分辨率为基准。后续其他片段若分辨率不一致，将被自动缩放以对齐第一个片段，这可能会导致画面出现黑边或拉伸。
输出格式（音频） ：音频拼接任务默认输出的音频格式为 m4a。
