3.1.11 语音转字幕（ASR）
AI MediaKit 的语音转字幕工具利用先进的自动语音识别（ASR）技术，能够将视频或音频文件中的语音内容精准地转换成带时间戳的字幕文本。该工具支持多种语言，并能选择性地识别不同说话人，为视频后期制作、内容分析、无障碍访问等场景提供强大支持。
本篇开发指南将引导您：
理解语音转字幕的核心能力与工作流程。
快速从一个媒体文件中生成带时间戳的字幕。
学习如何使用高级功能，如说话人识别和语种指定。
效果预览
通过语音转字幕工具，您可以将一段包含语音的视频或音频文件作为输入，最终得到结构化的 JSON 字幕数据，其中包含了每一句字幕的文本内容、起止时间，以及可选的说话人信息。

快速体验：从视频生成中文字幕
本场景演示如何从一段中文视频中，提取出所有语音对应的字幕文本及时间轴。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 MediaKit APIKey（用于媒体处理功能鉴权）。
准备视频文件：准备一个待处理的视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。为方便您快速测试，本文后续步骤的示例代码中提供了一个可直接使用的演示视频 URL。
操作流程
语音转字幕是一个异步任务，完整流程如下：
成功调用 POST /api/v1/tools/asr-subtitles 后，API 将返回一个任务 ID。
您可以轮询查询任务信息 API ，直到任务状态 status 变为 completed ；或者使用事件回调 自动接收任务状态变化。
任务完成后，解析 result 字段，即可在 subtitles 数组中获取所有字幕信息。
第 1 步：提交任务
您需要调用提交语音转字幕（ASR）任务 API 。可直接复制以下 cURL 命令提交一个基础任务。输入的视频文件 输出的字幕数据

参考信息
应用场景
视频字幕自动生成：支持自动将视频中的语音识别转换为字幕，为短视频、长视频、直播回放等内容自动生成字幕文件，免去人工听写的繁琐流程。
会议与访谈转写：将会议录音、访谈视频自动转为文字记录，支持说话人区分，方便后续整理和归档。
播客与音频内容提取：将播客节目、有声读物等音频内容转写为文本，便于内容检索、摘要生成和二次创作。

限制项 说明
输入文件限制
文件来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、来源于火山引擎视频点
播 ( vod:// ) 和火山引擎对象存储 ( tos:// ) 四
种输入协议。关于各协议的具体说明和使用
示例，请参阅多源媒体输入与本地上传。
支持格式： 
mp4 , flv , ts , avi , mov , wmv , 
mkv 等主流视频格式。
mp3 , m4a , wav 等主流音频格式。
文件时长：单个文件不超过 3 小时。
语种支持：支持简体中文（ cmn-HansCN ）、英语（ eng-US ）、西班牙语
（ spa-ES ）、印尼语（ ind-ID ）。可通过 
language 参数指定。
