8.5 服务端 SDK
8.5.1 使用说明
您可以通过服务端 SDK 调用智能处理的 OpenAPI，实现快速对接智能处理服务。智能处理服务提供了多种主流语言的 SDK，让您不用复杂编程，即可快捷访问。
功能介绍
服务端 SDK 封装了 OpenAPI 的调用和响应，避免需要繁琐计算 API 签名。
服务端 SDK 封装了智能处理常用 OpenAPI 接口，并提供了对应的示例代码。
服务端 SDK 封装了常用的操作流程，比如服务端提交媒体处理。
支持开发语言，包括：Python、Go、PHP、Java等。
准备工作
开始使用智能处理服务端 SDK 前，您需要完成以下准备工作。
开通服务
确认您已经开通了智能处理服务，并完成相关基础配置。详情请参考 快速入门 。
准备账号
您需要提前准备好调用智能处理 OpenAPI 的 AK/SK，支持主账号、子账号。
子账号（推荐）：在访问控制中创建一个子账号，并授权智能处理权限后，创建子账号下的 AK/SK。主账号：在访问控制中创建主账号的 AK/SK。
注意
主账号拥有账号下全部权限，如果泄漏可能给您的服务带来很大风险，不推荐直接使用主账号AK/SK 调用服务。
