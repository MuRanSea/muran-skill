3.5.8 AIGC 视频生成质量评估
AI MediaKit 的 AIGC 视频生成质量评估工具，面向 AIGC 视频生产场景，对视频检查参考信息一致性、世界合理性、内容持续性、视觉保真度等质量问题，自动定位异常时间区间、问题类型与证据帧，帮助您快速完成采用、复核或重新生成的决策。也可将它接入创作 Agent，形成「视频生成 — 质量评估 — 复核或自动重新生成」的生产闭环。
本篇开发指南将引导您：
了解 AIGC 视频质量评估的检测模块与问题类型。
快速体验如何对一段 AIGC 视频进行多维度质量评估。
掌握按场景组合检查模块，以及结合参考图检查参考信息一致性的用法。
检测模块与问题类型
AIGC 视频质量评估工具通过 modules 参数提供 11 个检测子维度，覆盖 AIGC 视频生产中常见的参考一致性、内容持续性、结构、物理、运动和口播发音问题。您可以按业务场景自由组合，每个子维度检出的问题会在结果中标注所属 module 与具体问题类型 type 。
检测模块 module 字段 说明
结构保真度 structural_fidelity
检查视频中的人体结构、物体
结构和文字结构是否合理、自
然。
人物身份参考一致性 character_identity_adherence 检查视频中的人物身份与参考
图是否一致。
人物服装参考一致性 character_appearance_adherence 检查视频中的人物服装与参考
图是否一致。
商品外观参考一致性 product_adherence
检查视频中的商品外观
（Logo、形状、包装文字、颜
色、花纹等）与参考图是否一
致。
场景参考一致性 scene_adherence
检查视频中的场景（元素、布
局、风格等）与参考图是否一
致。
口播发音一致性 pronunciation_mismatch
检查口播发音与字幕信息是否
一致，是否有错读、漏读、发
音不一致等问题。
人物身份持续性 character_identity_consistency 检查人物面部特征在视频时序
内是否保持一致。
人物服装持续性 character_appearance_consistency 检查人物的服装与外观在视频
时序内是否保持一致。
商品外观持续性 product_consistency
检查商品外观（Logo、形状、
颜色、花纹等）在视频时序内
是否保持一致。
应用场景
AIGC 短剧：检查人物面部特征、服装、道具与场景的一致性，以及动作连贯性、物理合理性等问题，识别角色变脸、物体突变、剧情穿帮等问题，支持漫剧风格、真人风格、3D 风格等多种风格。电商广告素材：结合参考图，检查商品外观、颜色、Logo、包装文字、品牌元素等是否保持一致，识别商品变形、画面时序和物理表现等问题。
创作 Agent 生产闭环：视频生成后自动触发质量检查，合格视频进入编辑环节，问题视频转人工复核，严重问题视频自动重新生成。
快速入门：对 AIGC 视频进行质量评估
本节演示如何提交一个 AIGC 视频质量评估任务，并组合多个不依赖参考图的检测子维度。准备工作
获取访问凭证：在开始之前，请访问 AI MediaKit 控制台的 API Key 管理页面 ，创建并获取 MediaKitAPI Key。
开通火山方舟大模型服务：AIGC 视频生成质量评估工具依赖火山方舟（Ark）视觉大模型完成评估。请前往火山方舟控制台 ，确认本工具所需的大模型（如 Doubao 系列）已开通且可用。模型能力会影响检测效果，推荐使用 doubao-seed 系列中最新的 pro 模型，例如 doubao-seed-2-1-pro-260628 。完成跨服务授权：首次使用 AIGC 视频质量评估工具前，请前往 AI MediaKit 控制台的授权管理页面，授权 AI MediaKit 访问您的 ARK 火山方舟资源，否则任务将因权限不足而失败。
准备视频文件：准备一个待评估的视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。
操作流程
AIGC 视频质量评估是一个异步任务，其标准流程如下：
成功调用 POST /api/v1/tools/evaluate-aigc-video-quality 提交任务后，您将获得一个任务 ID。您可以轮询 GET /api/v1/tasks/{task_id} 接口，直到任务状态 status 变为 completed ；或者使用事件回调 自动接收任务状态变化。
任务完成后，解析响应中的 result 字段，即可在 issues 中获取检出的问题明细。未检查到问题时 issues 为空数组。
