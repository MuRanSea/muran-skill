3.3.2.13 视频加字幕
AI MediaKit 视频加字幕工具支持将外部字幕文件（如 SRT、ASS）或直接提供的文本内容，以丰富的自定义样式，压制（或称“烧录”）到视频画面中，生成带内嵌字幕的新视频。
本指南将带您了解如何通过 API 调用，为您的视频添加专业的内嵌字幕。

快速体验：为 Vlog 视频添加内嵌字幕
本节将通过一个具体的示例，演示如何直接在 API 请求中提供字幕文本和时间戳，为一段 Vlog 视频添加两句对话字幕。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key。
准备视频文件：准备一个需要添加字幕的视频文件，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程
视频加字幕是一个异步任务，整体流程如下：
成功调用 POST /api/v1/tools/add-subtitle-to-video 提交任务后，您将获得一个唯一的 task_id 。输入视频 输出视频（添加字幕后）
您可以通过轮询 GET /api/v1/tasks/{task_id} 接口来查询任务状态，直到状态（ status ）变为 completed 。或者，您也可以配置事件回调 来自动接收任务完成的通知。
任务完成后，解析响应中的 result 字段，即可在 video_url 字段中获取添加字幕后视频的下载地址。第 1 步：提交任务

自定义字幕样式
AI MediaKit 允许您通过丰富的 API 参数来定制字幕的视觉样式，使其与您的视频内容和品牌风格完美契合。您可以自定义字幕的位置、字体、大小、颜色，甚至应用复杂的花字效果。以下是主要的样式控制参数：
字幕位置 ( subtitle_pos_preset )：通过预设值快速将字幕放置在画面中的常用位置。 
bottom_center : 底部居中（默认）
top_center : 顶部居中
center : 画面正中央
lower_third : 偏下三分之一处
字体类型 ( subtitle_font_type )：选择不同的字体以适应视频的氛围。 
sy_black : 思源黑体（端正百搭，正文首选）
pm_zhengdao : 庞门正道标题体（粗壮有力，大标题神器）
zhanku_kuaile : 站酷快乐体（圆润活泼，适合 Vlog 氛围）
字体大小 ( subtitle_font_size )：设置字幕的像素大小，默认为 50 。
字体颜色 ( subtitle_font_color )：使用 RGBA 十六进制格式（如 #RRGGBBAA ）设置颜色和不透明度。默认值为 #FFFFFFFF （不透明白色）。
花字效果 ( subtitle_text_effect )：指定一个花字效果资源 ID，为字幕应用描边、渐变、阴影等预设的视觉样式。设置后， subtitle_font_color 参数将不生效。具体效果请见支持的花字 。
示例：应用自定义样式
