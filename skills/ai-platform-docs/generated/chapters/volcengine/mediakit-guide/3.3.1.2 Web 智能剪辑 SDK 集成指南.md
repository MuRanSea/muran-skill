3.3.1.2 Web 智能剪辑 SDK 集成指南
本文档面向需要在 Web 应用中集成 AI 智能剪辑能力的前端及服务端开发者。通过 AI MediaKit Web 智能剪辑 SDK（@volcengine/amk-editor-assistant），您可以在业务页面中嵌入一套 AI 驱动的视频创作工具，实现从素材管理、智能编排、特效渲染到高清导出的全链路剪辑流程，而无需自行拼装复杂的底层组件和 AI 算法。
SDK 概述
@volcengine/amk-editor-assistant 是一款面向浏览器环境的、一站式的智能视频剪辑SDK，将强大的 AI助手与专业的剪辑器无缝整合，为用户提供自然语言驱动的全新视频创作体验。
核心能力 说明
AI 助手
用户可通过自然语言对话完成复杂编辑操作，
如“理解视频内容，剪辑出高光片段，并添加字
幕”、“把我提供的素材混剪成片，理解素材内
容，生成一条结构完整的混剪 Vlog”，AI 助手
会自动理解意图并调用相应工具执行。
Web 剪辑器
内置功能完备的剪辑器，支持多轨道编辑、精确
裁剪、实时预览、文本与字幕添加、特效、转
场、滤镜等专业能力，满足精细化调整需求。
丰富的云端 AI 原子能力
内置多种 AI MediaKit 原子能力，如 ASR 字幕识
别、视频抽帧、视频理解、高光识别等，可被
AI 助手自动编排调用。
场景化智能剪辑工具
提供多种开箱即用的场景化方案，如高光剪辑
（通用/短剧）、AI 短漫剧粗剪、多素材智能混
编和 Vlog 视频混剪，能自动完成从素材筛选、
架构与核心概念
集成 Web 智能剪辑 SDK 时，您的应用前端（浏览器）将与您的业务后端（代理服务）以及 AI MediaKit 服务端进行交互。

核心设计：业务代理
为保障密钥（API Key）安全，浏览器不能直接请求 AI MediaKit 服务。所有请求都必须通过您自己实现的业务代理服务进行中转。该服务主要负责：
安全地附加密钥：将安全存储在您服务器上的 AI MediaKit API Key 添加到请求头中。
校验业务权限：验证当前登录用户是否有权访问其正在操作的 projectId，防止数据越权。转发请求：将来自 SDK 的请求安全地转发给对应的 AI MediaKit 上游服务。
费用说明
使用 Web 智能剪辑 SDK 会涉及三部分费用，分别由 AI MediaKit 和火山方舟进行计费。费用遵循日结后付费模式，次日 6:00 生成前一日的账单并进行结算。
火山方舟大模型调用费
AI 助手在进行自然语言对话（推理模型）和多模态内容理解（多模态理解模型）时，会调用您在 SDK 中配置的火山方舟大模型。此部分费用由火山方舟根据模型调用过程中实际消耗的 Token 数量（包括输入和输出 Token）进行计费。 关于不同模型的 Token 计费标准，请查阅火山方舟最新官方定价说明 。AI MediaKit 原子能力费用
在 AI 助手自动编排或用户手动编辑过程中，可能会调用 AI MediaKit 的多种原子能力。这些能力将按照各自的计费规则进行计费，主要包括以下两类：
视频工具：当 AI 助手需要理解视频内容或执行特定处理时，会触发视频工具的调用，包含字幕识别、视频抽帧、视频理解、高光识别等。这些能力将按照各自的计费规则进行计费，详细规则请参阅视频工具计费。
剪辑工具：当您或您的用户最终执行“导出视频”操作时，会产生剪辑费用。该费用基于最终输出的视频时长和分辨率进行计费。详细规则请参阅剪辑工具计费。

// 适用于 Node.js 18+
import express from 'express';
import { Readable } from 'node:stream';
import { pipeline } from 'node:stream/promises';
const app = express();
app.use(express.json({ limit: '10mb' }));
// --- 需要您配置的部分 ---
const PROXY_PREFIX = '/api/amk-proxy';
const UPSTREAM_BASE_URL = 'https://mediakit.cn-beijing.volces.com';
const API_KEY = process.env.AMK_API_KEY; // 从环境变量读取您的 API Key
if (!API_KEY) {
throw new Error('AMK_API_KEY is not set in environment variables.');
}
// 剪辑器 API 路径白名单
const ALLOWED_EDITOR_PATHS = [
/^\/api\/v1\/editing\//,
/^\/api\/v1\/tools\//,
/^\/api\/v1\/tools-sync\//,
/^\/api\/v1\/tasks\/[^/]+\/?$/,
];
// AI 助手 Runtime 的 API 路径白名单
const ALLOWED_ASSISTANT_PATHS = [
 ['GET', /^\/api\/v1\/studio\/agents\/copilotkit\/?$/],
 ['POST', /^\/api\/v1\/studio\/agents\/copilotkit\/?$/],
 ['GET', /^\/api\/v1\/studio\/agents\/threads(?:\/|$)/],
 ['GET', /^\/api\/v1\/studio\/agents\/agents(?:\/|$)/],
];
// --- 配置结束 ---
app.use(PROXY_PREFIX, async (req, res) => {
// SDK 已在请求中包含完整的 /api/v1/... 上游路径；
// 代理只移除本地前缀，不要再次拼接 /api/v1/editing。
const upstreamPath = req.originalUrl.slice(PROXY_PREFIX.length);
const pathname = upstreamPath.split('?')[0];
const assistantRequest = pathname.startsWith('/api/v1/studio/agents/');
if (assistantRequest) {
// 1. 【安全】AI 助手路径白名单校验
const allowed = ALLOWED_ASSISTANT_PATHS.some(
([method, pattern]) => req.method === method && pattern.test(pathname)
 );
if (!allowed) {
return res.status(403).json({ error: 'Assistant Runtime path is not allowed' });
 }
 } else {
// 1. 【安全】剪辑器路径白名单校验
const allowed = ALLOWED_EDITOR_PATHS.some(pattern => pattern.test(pathname));
if (!allowed) {
return res.status(403).json({ error: 'Editing API path is not allowed' });
 }
 }
// 2. 【安全-需要您自行实现】业务权限校验
// 在这里校验当前登录用户是否有权访问其请求的 projectId，防止数据越权。
const controller = new AbortController();
const timeoutMs = assistantRequest ? 30 * 60_000 : 60_000;
const timeoutId = setTimeout(() => controller.abort(), timeoutMs);
const onClose = () => {
if (!res.writableFinished) controller.abort();
 };
 res.on('close', onClose);
try {
const headers = {
'Authorization': `Bearer ${API_KEY}`,
'Accept': assistantRequest
 ? req.headers.accept ?? 'application/json'
 : 'application/json',
 };
if (!['GET', 'HEAD'].includes(req.method)) {
 headers['Content-Type'] = 'application/json';
 }
if (assistantRequest && typeof req.headers['x-endpoint-id'] === 'string') {
 headers['X-Endpoint-Id'] = req.headers['x-endpoint-id'];
 }
const upstreamResponse = await fetch(`${UPSTREAM_BASE_URL}${upstreamPath}`, {
method: req.method,
 headers,
body: ['GET', 'HEAD'].includes(req.method)
 ? undefined
 : JSON.stringify(req.body ?? {}),
signal: controller.signal,
redirect: 'manual',
 });
// 3. 原样透传响应头和状态码
 res.status(upstreamResponse.status);
 res.setHeader(
'Content-Type',
 upstreamResponse.headers.get('content-type') ?? 'application/json'
 );
 res.setHeader('Cache-Control', 'no-cache');
 res.setHeader('X-Accel-Buffering', 'no'); // Nginx 禁用缓冲
// 4. 流式透传响应体（关键）
if (upstreamResponse.body) {
await pipeline(Readable.fromWeb(upstreamResponse.body), res);
 } else {
 res.end();
 }
 } catch (error) {
if (res.destroyed) return;
if (!res.headersSent) {
 res.status(502).json({ error: 'AI MediaKit request failed' });
 } else {
 res.destroy(); // 如果流已开始，只能异常关闭
 }
 } finally {
clearTimeout(timeoutId);
 res.off('close', onClose);
 }
});

服务端 API 参考
您的业务代理服务（BFF）通过同一个代理入口，将前端 SDK 的调用转发到 AI MediaKit 同一 Host 下的两组路径：剪辑器 API 和 AI 助手 API。
剪辑器 API (Editing API)
这套 API 负责管理剪辑项目的核心数据，如工程、素材库、时间轴和异步任务。
基础信息

项目 说明
Host https://mediakit.cn-beijing.volces.com
Base Path /api/v1/editing
鉴权方式 Authorization: Bearer <YOUR_AMK_API_KEY>
响应约定
所有接口在 HTTP 层面统一返回 200 OK，具体的业务成功与失败通过响应体内容来区分。
常用接口
创建工程
POST /projects
创建一个新的剪辑工程，并返回其唯一标识 project_id。
请求参数
批量创建/更新素材
POST /projects/{projectId}/materials（创建）
PUT /projects/{projectId}/materials（更新或插入）
向指定工程中批量添加或更新素材。PUT 操作会根据 source_material_id 判断是更新现有素材还是插入新素材。此操作具有原子性，任一素材校验失败，整批操作都将回滚。

AI 助手 API (Assistant Runtime API)
这套 API 负责处理所有与大模型交互的逻辑，包括自然语言理解、对话管理和 Agent 工具调用。基础信息

error 字段 表示请求失败。error.code 字段标明了具体的错
误类型。
