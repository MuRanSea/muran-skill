3.3.1.2 Web 智能剪辑 SDK 集成指南
本文档面向需要在 Web 应用中集成 AI 智能剪辑能力的前端及服务端开发者。通过 AI MediaKit Web 智能剪辑 SDK（ @volcengine/amk-editor-assistant ），您可以在业务页面中嵌入一套 AI 驱动的视频创作工具，实现从素材管理、智能编排、特效渲染到高清导出的完整剪辑流程，而无需自行集成多个剪辑组件和 AI模型。
SDK 概述
@volcengine/amk-editor-assistant 是一款面向浏览器环境的一站式智能视频剪辑 SDK，将 AI 助手与剪辑器集成在同一界面中，用户可以通过自然语言完成视频创作。
核心能力 说明
AI 助手
用户可通过自然语言对话完成复杂编辑操作，
如“理解视频内容，剪辑出高光片段，并添加字
幕”、“使用我提供的素材生成一条结构完整的
混剪 vlog”，AI 助手会自动理解意图并调用相
应工具执行。
Web 剪辑器
内置功能完备的剪辑器，支持多轨道编辑、精确
裁剪、实时预览、文本与字幕添加、特效、转
场、滤镜等专业能力，满足精细化调整需求。
丰富的云端 AI 工具
内置多种 AI MediaKit 工具，如语音识别
（ASR）、视频抽帧、视频理解、高光识别等，
AI 助手可根据用户指令自动选择并调用。
场景化智能剪辑工具
提供多种可直接使用的场景方案，如高光剪辑

业务代理
为保障密钥（API Key）安全，浏览器不能直接请求 AI MediaKit 服务。所有请求都必须通过您自己实现的业务代理服务进行中转。该服务主要负责：
安全地附加密钥：将安全存储在您服务器上的 AI MediaKit API Key 添加到请求头中。
校验业务权限：验证当前登录用户是否有权访问其正在操作的 projectId ，防止用户访问不属于自己的数据。
转发请求：将来自 SDK 的请求安全地转发给对应的 AI MediaKit 服务。
费用说明
使用 Web 智能剪辑 SDK 可能产生三类费用：火山方舟大模型调用费、AI MediaKit 视频工具费和 AIMediaKit 剪辑工具费。费用遵循日结后付费模式，次日 6:00 生成前一日的账单并进行结算。火山方舟大模型调用费
AI 助手在进行自然语言对话（推理模型）和多模态内容理解（多模态理解模型）时，会调用您在 SDK 中配置的火山方舟大模型。此部分费用由火山方舟根据模型调用过程中实际消耗的 Token 数量（包括输入和输出 Token）进行计费。 关于不同模型的 Token 计费标准，请查阅火山方舟最新官方定价说明 。AI MediaKit 工具费用
在 AI 助手自动执行任务或用户手动编辑的过程中，可能会调用多种 AI MediaKit 工具。这些工具将按照各自的计费规则进行计费，主要包括以下两类：
视频工具：当 AI 助手需要理解视频内容或执行特定处理时，会调用字幕识别、视频抽帧、视频理解、高光识别等视频工具。这些工具将按照各自的计费规则进行计费，详细规则请参阅视频工具计费 。剪辑工具：当您或您的用户执行“导出视频”操作时，会产生剪辑费用。该费用基于最终输出的视频时长和分辨率进行计费。详细规则请参阅剪辑工具计费 。

素材导入与存储
本节先帮助您选择素材上传方式，再说明 SDK 内置 TOS/VOD 存储的配置方法。
选择接入方式
用户从本地导入素材时，您可以选择以下任一方式将文件上传到存储服务：
自定义上传：通过 material.onUploadFile 将文件上传到您的存储服务。适用于已经具备素材上传服务，或需要自行控制上传流程的业务。
SDK 内置上传：通过 storage 配置 TOS 存储桶或 VOD 点播空间。SDK 负责上传文件并获取编辑器预览所需的播放地址，适用于希望直接使用火山引擎存储服务的业务。具体操作请参见 配置 SDK 内置TOS 素材存储或 配置 SDK 内置 VOD 素材存储。

工作流程
