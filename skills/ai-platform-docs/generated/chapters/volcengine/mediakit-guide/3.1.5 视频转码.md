3.1.5 视频转码
视频转码是将一个视频码流转换成另一个视频码流的过程。这通常涉及对编码格式（如 H.264、H.265）、编码参数（如分辨率、码率、帧率）、封装格式（如 MP4、FLV）等的转换，以适应不同的业务场景、播放终端和网络环境。
本篇开发指南将引导您快速体验如何通过转码改变一个视频的画幅比例。
快速入门：基础转码任务
本节演示如何将一个竖屏视频转为 720x720 分辨率，并自动补齐黑边。
准备工作
获取访问凭证：在开始之前，请访问 AI MediaKit 控制台的 API Key 管理页面 ，创建并获取 MediaKitAPI Key。
准备视频文件：准备一个待处理的视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。为方便您快速测试，本文后续步骤的示例代码中提供了一个可直接使用的演示视频 URL（原始分辨率为 496x864）。
操作流程
视频转码是一个异步任务，其标准流程如下：
调用 POST /api/v1/tools/transcode-video ，获得一个用于查询的 task_id 。
轮询 GET /api/v1/tasks/{task_id} 直至任务完成，然后从 result.video_url 字段中获取转码后视频的下载地址。
第 1 步：提交转码任务
您需要调用提交视频转码任务 API 。可直接复制以下 cURL 命令，提交一个将竖屏视频转为 720x720 分辨率、并自动补齐黑边的任务。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/transcode-video' \-H 'Authorization: Bearer {Your_MediaKit_API_Key}' \
-H 'Content-Type: application/json' \
-d '{
 "video_url": "https://vod-ai-test.tos-cn-beijing.volces.com/demo/demo_480p.mp4",
 "video": {
 "scale_type": 2,
 "scale_width": 720,
 "scale_height": 720,
 "scale_mode": 2
 }
}'
Bash
说明
将 {Your_MediaKit_API_Key} 替换为您的有效 API Key。
video_url ：示例中已提供可直接用于测试的演示视频 URL。您也可以将其替换为您自己的视频地址。
这个示例能直观地展示如何改变视频的画幅比例。我们将一个竖屏视频转为 1:1 的方形视频，通过设置 "scale_mode": 2 ，系统会自动在视频两侧添加黑边，以在不拉伸、不裁剪画面的前提下适应新的分辨率。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。
第 2 步：获取转码结果
转码任务需要一定的处理时间。您需要轮询查询任务信息 API ，直到任务状态 status 变为 completed 。
当任务成功完成后，您将收到如下响应。您可以在 result.video_url 字段中找到最终生成的视频文件下载地址（默认有效期为 24 小时）。

"task_id": "amk-tool-transcode-video-123456789",

}
