3.3.2.16 视频截取动图
AI MediaKit 的视频截取动图工具能够从视频文件中按指定时间段截取片段，并生成高品质的动态图片（支持 GIF 或 WebP 格式）。该工具适用于制作精彩片段预览、社交媒体分享素材、产品功能演示动图等场景。
本篇开发指南将引导您：
理解视频截取动图的核心能力与应用场景。
快速从一段视频中截取指定时长的动图。
学习如何指定输出动图的格式。
快速体验：从视频中截取动图
本场景演示如何从一段视频的第 10.5 秒截取到第 15 秒，并生成一个 GIF 格式的动图。
准备工作
获取访问凭证：在开始之前，请访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备视频文件：准备一个待处理的视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。
操作流程
视频截取动图是一个异步任务：
成功调用 POST /api/v1/tools/extract-animated-image 后，API 将返回一个任务 ID。
您可以轮询 GET /api/v1/tasks/{task_id} ，直到任务状态 status 变为 completed ；或者，配置事件回调自动接收任务状态变化。
任务完成后，解析 result 字段，即可在 image_url 字段处获取最终动图文件的下载地址。第 1 步：提交任务
您需要调用提交视频截取动图任务 API 。可直接复制以下 cURL 命令提交。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/extract-animated-image' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {Your_API_Key}' \
--data '{
 "video_url": "https://example.com/source_video.mp4",
 "start_time": 10.5,
 "end_time": 15.0
}'
Bash
说明

将 video_url 替换为您真实的视频文件地址。

进阶使用
指定输出动图格式
默认情况下，生成的动图为 gif 格式。您可以通过 output_format 参数将其指定为 webp 格式，以获得更好的压缩率和画质。

限制项 说明
输入文件限制
视频来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、来源于火山引擎视频点
播 ( vod:// ) 和火山引擎对象存储 ( tos:// ) 四
种输入协议。关于各协议的具体说明和使用
示例，请参阅多源媒体输入与本地上传。
视频格式：支持 mp4 , flv , ts , avi , 
mov , wmv , mkv 等主流视频格式。
分辨率：输入视频最高支持 4K (3840×2160)
分辨率。
输出动图限制
时长：输出动图时长（ end_time - 
start_time ）不能超过 60 秒。
分辨率：输出动图分辨率最大为 480p。若输
入视频分辨率低于 480p，则输出分辨率与输
入保持一致。
帧率：输出动图的帧率固定为 15 fps。
