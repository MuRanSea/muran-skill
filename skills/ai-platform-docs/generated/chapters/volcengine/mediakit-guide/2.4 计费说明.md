大模型处理工具计费
AI MediaKit 支持按量计费（后付费）和资源包（预付费）两种付费方式。
按量计费（后付费） ：按照各计费项的实际用量结算费用。这是一种“先使用，后付费”的模式，灵活度高，适用于业务用量经常有变化的场景。所有用户默认采用此方式。
资源包（预付费） ：您可以针对特定的计费项预先购买有一定优惠折扣的资源包。在费用结算时，系统会优先从资源包中抵扣用量。这是一种“先购买，后使用”的模式，性价比更高，适用于业务用量相对稳定的场景。资源包到期或额度用尽后，超出的用量将自动转为按量计费。关于资源包的购买方式、价格和抵扣规则，请参见资源包。
结算周期
AI MediaKit 支持以下两种结算周期：
按日结算：系统在次日下午 6 点对您前一天产生的费用进行结算、出具账单并从您的账户余额中扣费。
按月结算：系统在次月 2 号对您上一个自然月产生的费用进行结算、出具账单并从您的账户余额中扣费。
欠费说明与关停策略
为确保您的业务持续稳定运行，请关注账户余额。AI MediaKit 遵循火山引擎统一的欠费处理流程。欠费关停与资源回收规则

欠费后的功能限制
当账号处于欠费关停状态时，您的使用体验将受到以下限制：
控制台提示：管理页面将出现全局告警提示。您可以通过点击提示框中的“充值”按钮快速跳转至费用中心。
API Key 限制：不支持创建新的 API Key。
API 调用限制：通过现有的 API Key 调用接口时将返回鉴权失败或欠费相关的错误码，无法发起新的处理任务。
充值恢复策略
从欠费关停状态恢复：在资源被回收前，您只需补足欠款，确保账户余额为正值。充值成功后，APIKey 创建、任务提交等功能将自动恢复正常。
从回收状态恢复：一旦进入资源回收阶段，原计费实例已销毁。如需继续使用，您必须在控制台重新开通 AI MediaKit 服务。
