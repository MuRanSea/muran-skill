3.2.12 电商万创（商品场景图生成）
AI MediaKit 电商万创（商品场景图生成）工具，能够基于您提供的商品图，通过 AI 技术智能生成高质量的背景与营销场景。该工具支持多种模式，满足不同业务需求：
标准版：使用预设模板快速出图。
专业版：通过创意描述（Prompt）、参考图等方式进行自定义创作。
行业版：专为汽车行业设计，支持棚拍风格的汽车场景图生成。
本篇开发指南将引导您：
通过一次 API 调用，快速体验为商品图生成一个全新的背景。
理解标准版、专业版与行业版的效果差异与适用场景。
效果示例
输入图 生成示例结果
快速体验：一键生成商品场景图
电商万创是一个同步任务，您发起的请求会直接在响应中返回处理结果。
准备工作
获取访问凭证： 在开始之前，请访问 AI MediaKit 控制台的 API Key 管理页面，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备图像文件： 准备一张背景清晰、主体明确的商品图，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程
输入图 生成示例结果

费用说明
电商万创（商品场景图生成）工具的费用根据成功生成的图片张数计算。系统会根据您任务中指定的模型版本（标准版、专业版、行业版），应用不同的计费系数。关于详细的计费规则、换算系数和计费示例，请参阅图像工具计费。
