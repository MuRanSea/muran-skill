8.6.5 回调事件
8.6.5.1 媒体处理完成事件
本节为您介绍媒体处理完成事件、事件内容和回调示例。
事件类型
MediaProcessComplete
事件说明
若您在系统配置中进行回调事件的设置，媒体处理完成后您将收到事件回调记录。
智能处理服务端接收完媒体处理完成的文件后，会产生 MediaProcessComplete 事件。
事件内容
MediaProcessComplete
回调示例
参数 类型 描述
RequestId String 请求 ID
EventTime String 事件时间，格式 rfc3339
EventType String 事件类型：
MediaProcessComplete
Data MediaProcessComplete 回调内容
参数 类型 描述
JobId String 请求 ID
AccountId String 帐号 ID
InputPath InputPath 输入路径
Output Array of JobOutput 输出信息
CallbackArgs String 回调参数
CreatedAt String 创建时间，格式：rfc3339
FinishedAt String 完成时间，格式：rfc3339
