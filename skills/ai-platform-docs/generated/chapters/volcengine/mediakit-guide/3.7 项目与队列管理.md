3.7 项目与队列管理
AI MediaKit 通过项目（Project）和队列（Queue）为您提供强大的资源管理与成本分摊能力。您可以将不同业务、不同环境的媒体处理任务划分到不同的项目中，实现资源的逻辑分组与成本的独立核算。核心概念
说明
三者关系：一个账号下可以创建多个项目，一个项目下可以创建多个队列。
并发限制：此限制针对异步任务，指您账号下可同时处理的异步任务数量上限。该限制为账号维度，所有项目和队列共享同一个并发上限，默认为 20。如需提升并发上限，请提交工单
联系技术支持。同步任务（如图像工具）不受此并发数限制，而是遵循独立的 API QPS 限制，详见 API QPS 限制说明 。
如何使用：为您的客户实现独立计量与分账
本节将以一个真实的场景为例介绍如何使用项目和队列。
场景说明
痛点：您运营一个 SaaS 平台，利用 AI MediaKit 为众多终端客户提供多媒体智能处理服务。如果没有隔离机制，所有客户产生的费用都会混在您的主账号账单里，您无法知道客户 A 和客户 B 各自消耗了多少资源，因此难以进行精确的成本核算与合理的收费。
解决方案：通过结合使用“项目”和“队列”，您可以为每个客户建立一个独立的资源和成本单元。 为您的每一位终端客户创建一个专属的项目，例如 customer-a 、 customer-b 。
在每个客户的项目下创建一个或多个队列。
在提交客户 A 的任务时，使用 customer-a 项目下队列的 queue_id 。
效果：所有任务的费用都会被精确地归属到对应的项目上。在火山引擎的费用中心，账单会自动按项目维度进行分拆，您可以清晰地看到每个客户的独立消费金额，从而实现精准的成本归因和自动化分账。
以下是具体的操作步骤。
概念 描述
账号 Account
火山引擎账号（主账号）是火山引擎资源归属、
资源使用计量计费的基本主体。火山引擎账号为
其名下所拥有的资源付费，并对其名下所有资源
拥有完全控制权限。
项目 Project
项目是火山引擎提供的资源归属与计费分账的基
本单位。您可以为不同的业务线、产品或环境
（开发、测试、生产）创建不同的项目。这是实
现成本分摊、资源分组和权限管理的核心。
队列 Queue
队列是 AI MediaKit 中用于接收任务的实体，它
将任务与项目进行绑定，从而将任务产生的费用
正确地归属到对应的项目账单下。
操作步骤
第 1 步：为每个终端客户创建项目
首先，您需要为您平台上的每一位客户创建一个专属的项目。项目是 AI MediaKit 中资源归属和计费分账的基本单位，将一个项目与您的一个客户进行一对一绑定，是实现客户独立计费的基础。
登录火山引擎控制台，进入项目管理 页面。
单击新建项目。
在弹出的窗口中，为您的客户创建一个项目。建议采用统一且易于识别的命名规范，例如 customer-[您系统中的客户ID] 。
完成此步后，您就为每个客户都建立了一个独立的“账本”。
说明
创建项目后，当您在 AI MediaKit 控制台顶部通过项目选择器切换项目后，整个控制台的视图和操作范围都将被限定在该项目内。您所看到的用量统计、任务管理、队列管理、基础配置（包含API Key 及回调配置）都将是该项目专属的，从而确保不同客户或业务之间的资源和配置是完全隔离的。
第 2 步：在项目中创建队列并获取 queue_id
接下来，您需要在每个客户专属的项目下，为其创建一个或多个任务队列。API 任务通过与队列绑定，才能将其资源消耗计入正确的项目中。
说明
系统会为每个项目自动创建一个名为 default 的默认队列。您可以直接使用此队列，也可以根据业务需要创建新的队列。
每个账号下最多可创建 10 个队列（含默认队列）。
队列名称创建后不支持修改。
登录 AI MediaKit 控制台 。
在控制台顶部的项目选择器中，选择您在第一步为某个客户创建的项目（例如， customer-a ）。单击左侧导航栏的队列管理。
单击新建队列，为该客户创建一个队列，例如命名为 customer-a-queue 。
创建成功后，在队列列表中找到该队列，并复制其队列 ID。这个 ID 是全局唯一的，例如 q00a9731598092652e4a95292434198 。
说明
您需要在您的后端数据库中，将这个 queue_id 与您的客户实体进行关联并持久化存储。例如，在您的用户表（ customers ）中，为客户 A 的记录关联 q00a9731598092652e4a95292434198 。对您的每一位客户重复此操作，确保每个客户都有一个专属的、已记录的 queue_id 。
第 3 步：在提交任务时使用队列
当您的客户在您的 SaaS 平台上发起一个媒体处理请求时（例如，进行视频画质增强），您的后端服务在调用 AI MediaKit API 时，需要将该客户专属的 queue_id 传入请求中。以提交画质增强（标准版和专业版）任务 API 为例：
您的终端客户 A 在您的平台上上传了一个视频，点击“画质增强”。
您的后端服务接收到请求，从数据库中查询到客户 A 对应的 queue_id 为 
q00a9731598092652e4a95292434198 。
您的服务在构造 API 请求时，在请求体（Body）中加入 queue_id 字段。请求示例：
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/enhance-video' \-H 'Authorization: Bearer {Your_MediaKit_API_Key}' \
-H 'Content-Type: application/json' \
-d '{
 "video_url": "https://customer-a.volces.com/video.mp4",
 "tool_version": "professional",
 "resolution": "1080p",
 "queue_id": "q00a9731598092652e4a95292434198"
}'
Bash
通过在请求中明确指定 queue_id ，这个画质增强任务及其产生的所有费用，就会被精确地记录在 q00a9731598092652e4a95292434198 队列关联的 customer-a 项目下。
第 4 步：查看用量与账单
完成以上设置后，您就可以按客户维度查看用量和进行成本核算了。
按客户查看用量：在 AI MediaKit 控制台的用量统计页面 ，您可以通过顶部的项目选择器，切换到您为特定客户创建的项目（如 customer-a ）。页面上展示的所有用量数据，都仅属于该客户。按客户进行分账：在火山引擎费用中心的账单明细中，消费数据会按“项目”维度进行分拆。您可以看到名为 customer-a 、 customer-b 等项目的独立消费金额。
常见问题
是否支持将队列从一个项目转移到另一个项目？如何操作？
支持。您可以更改队列所属的项目。操作步骤如下：
登录火山引擎控制台，进入项目管理 页面。
找到您的目标项目（即您希望将队列转入的新项目，如 Project B），单击该项目的管理资源按钮。单击资源转入按钮，选择需要转移的队列资源，即可将其从原项目（Project A）转移至当前的新项目（Project B）下。
将队列转移到新项目后，用例统计和账单会如何展示？
当您将一个队列从原项目（例如 Project A ）转入新项目（例如 Project B ）后，账单出账规则与控制台用量统计规则分别如下：
账单页面的展示情况：费用的归集以系统最终出账时刻队列当前所属的项目为准。若任务产生费用并在出账时，该队列已转移至 Project B ，则这部分账单费用会记录在 Project B 之下。
AI MediaKit 控制台用量统计页面的展示情况：用量数据是以用户提交任务时队列所绑定的项目为准进行统计的。因此，在队列转移前（属于 Project A 时）提交的任务，其用量统计数据仍会留在 Project A 的统计视图中；队列转移后提交的新任务，用量才会统计到 Project B 中。
由于上述统计维度的差异，在队列跨项目转移后，有可能会出现 AI MediaKit 控制台特定项目下的统计用量与最终账单费用无法完全对应的情况，属于正常现象。
