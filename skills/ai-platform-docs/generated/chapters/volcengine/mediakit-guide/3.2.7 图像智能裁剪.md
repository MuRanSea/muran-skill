3.2.7 图像智能裁剪
AI MediaKit 的图像智能裁剪工具，能够自动识别图像中的人脸主体区域，并根据您指定的目标尺寸进行智能、美观的裁剪。支持普通人脸裁剪和动漫人脸裁剪两种场景模型。当图像中未检测到人脸时，该工具还支持多种降级策略，如居中裁剪或毛玻璃填充，以确保输出结果的可用性。适用于封面制作、社交媒体图片适配、动漫游戏素材处理等需要快速批量调整图片构图的场景。
效果示例
快速体验：将图片裁剪为 200x200 的头像
本节将通过一个具体的示例，演示如何调用 API 将一张包含人脸的图片，智能裁剪为一张 200x200 像素的头像。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key。
准备图像文件：准备一张待处理的图片，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程
图像智能裁剪是一个同步任务。您只需调用提交图像智能裁剪任务 API ，即可在 API 的响应体中直接获取处理后的图片地址。
提交请求并获取结果
可直接复制以下 cURL 命令，提交一个智能裁剪任务。
输入图片 输出图片
（尺寸为 200x200）
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/smart-crop-image' \-H 'Authorization: Bearer {Your_API_Key}' \
说明
需替换参数：
请将 {Your_API_Key} 替换为您的有效 API Key。
请将 image_url 的值替换为您自己准备的图片文件 URL。
请求成功后，您会直接收到如下响应。 result 字段中的 image_url 即是裁剪后图片的下载地址。该地址的有效期为 24 小时，请务必及时下载保存。
进阶使用
识别动漫人脸
除了普通人脸，图像智能裁剪工具还支持对动漫、卡通角色的人脸进行识别和裁剪。您只需将 scene 参数设置为 cartoon_face 即可。
-H 'Content-Type: application/json' \
-d '{
 "image_url": "https://example.com/human-image.png", 
 "target_width": 200, 
 "target_height": 200, 
 "scene": "person_face" 
}'

限制项 说明
输入图像限制
图像来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、火山引擎对象存储
( tos:// ) 三种输入协议。关于各协议的具体
说明和使用示例，请参阅多源媒体输入与本
地上传。
文件大小：单张图片不得超过 10 MB。
支持格式：支持
.png 、 .jpg 、 .jpeg 、 .webp 、 .tiff 、 .bmp 、 .heic
等主流图像格式。
输入分辨率限制：宽高均不得超过 6000 px。
