8.4.5.5.2 智能表情合成
智能处理基于输入文件和驱动素材，智能模拟真实表情、口型等精细化细节合成一段视频，辅助提高视频智能合成的效率和质量。
当输入文件是图片类型时：
驱动素材为视频：输入图片中的人物，结合视频驱动素材中的人物说话的音频和人物头部及眼部动作，输出合成后的视频。
驱动素材为音频：输入图片中的人物，结合音频驱动素材中的人物说话的音频和预设好的人物头部及眼部动作，输出合成后的视频。
驱动素材为文本：输入图片中的人物，结合文本驱动素材以及选择的音色类型合成出的音频和预设好的人物头部及眼部动作，输出合成后的视频。
当输入文件是视频类型时：
驱动素材为视频：输入视频中的人物，结合视频驱动素材中的人物说话的音频，输出合成后的视频。驱动素材为音频：输入视频中的人物，结合音频驱动素材中的人物说话的音频，输出合成后的视频。驱动素材为文本：输入视频中的人物，结合文本驱动素材以及选择的音色类型（支持选择原视频音色）合成出的音频，输出合成后的视频。
前提条件
您已登录智能处理控制台 。
操作步骤
您可以管理已创建的模板，进行模板查看、编辑、复制、删除等操作。
创建模板
选择左侧导航栏媒体处理模板>影视后处理，切换至智能表情合成页签，进入列表页。单击左上角创建智能表情合成模板按钮，进入模板创建详情页。
根据页面提示完成参数设置。
详细参数说明如下表所示。
参数 说明
模板名称
必填，仅只支持中文、英文、数字、下划线
(_)、短横线(-)和句点(.)，长度不能超过 64个字
符。
模板描述
选填，仅只支持中文、英文、数字、下划线
(_)、短横线(-)和句点(.)，长度不能超过 128个
字符。
驱动类型 支持的选择：视频驱动、音频驱动、文本驱
动，默认视频驱动。
音色选择
单击确认按钮，完成智能表情合成模板创建并在列表页新增一条。
查看模板
支持您创建处理模板后，在列表中找到对应处理模板，单击查看按钮，查看该模板中所有配置信息，模板中信息不支持修改。
参数 说明
驱动类型选择：文本驱动，支持的音色选择：
原视频音色、男声、女声。
说明： 当选择原视频音色时，需确保:
输入视频中人声部分长度超过10秒，越长效
果越好
输入视频中人声部分为单人
输入视频中人声部分的语言为中文或英文
输入视频中人声部分的内容建议是朗读一段
文本
生成字幕文件
驱动类型选择：文本驱动，支持选择是否在合
成视频的同时生成格式为WebVTT的字幕文
件。
字幕文件生成后保存位置：
如果输出文件保存于视频点播，则字幕文件
保存在合成视频的字幕文件系统中；
如果输出文件保存于对象存储，则字幕文件
保存在合成视频的同目录中；
驱动文件
驱动类型选择：视频驱动或者音频驱动。单击
选择文件按钮，上传文件；如果没有文件，单
击上传文件按钮，跳转到点播控制台 进行文
件上传。详情请参考上传视频 。
驱动文件 驱动类型选择：文本驱动，长度不能超过 1000
个字符。

编辑模板
支持您创建处理模板后，在列表中找到对应处理模板，单击编辑按钮，支持修改该模板中所有配置信息。
复制模板
支持您创建处理模板后，在列表中找到对应处理模板，单击复制按钮，创建成功后在列表中新增一个：除模板名称/ID外，与原模板配置信息完全相同的媒体处理模板。新增模板名称为：原模板名称-复制，模板 ID 为新增 ID。
删除模板
支持您创建处理模板后，在列表中找到对应处理模板，单击删除按钮，出现弹窗确认，单击确认后删除成功。
智能表情合成模板使用
支持您自定义配置模板之后，将其添加至工作流管理中，用于云端视频处理设置。
在工作流模板页单击创建工作流模板，在工作流配置中添加智能表情合成的处理节点，选择所需的智能表情合成模板。
说明
输入类型选择图片时，支持在工作流节点配置，按照智能表情合成-图片的价格计费。
输入类型选择视频时，支持在工作流节点配置，按照智能表情合成-视频的价格计费。
输入类型选择视频、驱动类型选择文本驱动、音色选择原视频音色时，支持在工作流节点配置，按照智能表情合成-视频-原视频音色的价格计费。
说明
您可以根据不同业务场景需求，同时配置画质增强、基础转码、极智超清、画质检测修复、智能抠图等处理能力。
在任务管理页面创建工作流任务，选择含智能表情合成处理能力的工作流模板，输入待处理文件并指定输出空间，执行智能表情合成任务。
注意
当输入文件为图片时，输入文件需要选择素材库，才能支持任务创建。
当输入文件为视频时，输入文件需要选择视频库，才能支持任务创建。
