3.1.15 高光智剪-影视拆条
AI MediaKit 的“高光智剪-影视拆条”工具，依托先进的长视频理解算法，针对电影、电视剧、纪录片等长视频进行深度分析，自动识别并拆分出多个包含完整故事弧线的“高光拆条”片段。该工具旨在将长视频“短剧化”，批量生产可在短视频平台进行分发的内容。其核心能力包括：
智能拆条：自动识别剧情转折点、故事线索，将长达数小时的影片拆分成多个 2-3 分钟的独立高光片段。
“钩子”设计：为每个拆条片段自动添加“高光前置开场”与“结尾悬念”，最大化提升视频的完播率和吸引力。
低密度信息过滤：自动识别并去除纯景色、缓慢运镜、片头片尾等低信息密度的内容，确保每个片段都节奏紧凑。
本篇开发指南将引导您：
快速体验如何从一部电影中拆分出多个高光短视频。
理解如何通过参数控制拆条片段的时长、开场钩子等。
了解该功能的工作原理与使用限制。
快速体验：从一部电影中拆分出多个高光短视频
本节将演示如何从一个长视频中，快速拆分出多个时长在 90-180 秒之间的高光片段。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备视频文件：准备一部电影或一集电视剧，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。
操作流程
影视拆条是一个异步任务，完整调用流程如下：
成功调用 POST /api/v1/tools/generate-highlights-movie 提交任务后，您将获得一个任务 ID。您可以轮询 GET /api/v1/tasks/{task_id} 接口，直到任务状态 status 变为 completed ；或者使用事件回调 自动接收任务状态变化。
任务完成后，解析响应中的 result 字段，即可在 video_urls 数组中获取所有拆条视频的下载地址。第 1 步：提交任务
您需要调用提交高光智剪（影视拆条）任务 API 。可直接复制以下 cURL 命令，提交一个影视拆条任务。

开启/关闭高光前置开场（钩子）
默认情况下，系统会为每个拆条片段的开头自动拼接一段从该片段中提取的、最精彩的“钩子”，以快速吸引观众。您可以通过 opening_hook_param 对象来控制此行为。
is_enabled ：设为 false 可关闭高光前置功能，所有拆条将严格按原始剧情顺序播放。
min_duration / max_duration ：控制“钩子”片段本身的时长范围（单位：秒）。
示例：关闭高光前置功能
如果您希望产出的视频严格遵循原片的时间线，可以按如下方式关闭高光前置（钩子）功能。获取详细分镜信息
如果您不仅需要视频文件，还想了解每个拆条视频具体由哪些原始片段构成（用于数据分析或二次剪辑），可以将 highlight_cuts_param.enable_detailed_info 设为 true 。开启后，任务结果中的 result_cuts_info 数组会增加一个 clips 字段，其中详细列出了构成该拆条的每个分镜片段的类型（钩子/主体）、评分、在原片中的起止时间、在拆条视频中的起止时间等。
示例：在任务结果中请求详细分镜信息

-d '{

项目 说明
输入视频限制
视频来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、来源于火山引擎视频点
播 ( vod:// ) 和火山引擎对象存储 ( tos:// ) 四
种输入协议。关于各协议的具体说明和使用
示例，请参阅多源媒体输入与本地上传。
支持格式： mp4 , flv , ts , avi , mov , 
wmv , mkv 等主流视频格式。
数量限制：当前单次任务仅支持输入单个视
频文件。
时长限制：单文件时长不超过 180 分钟。
输入分辨率限制：最高支持 1080p。
输入素材要求：视频必须同时包含视频流和
音频流。 
适用于电影（更优）、电视剧等长视频内
容；不建议用于纯综艺、纪录片、广告或
纯 BGM 视频。
音频流要求：建议视频音频轨道中包含清
晰可识别的中文对话文本，以便算法准确
理解剧情逻辑。
