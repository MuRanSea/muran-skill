3.3.2.5 音视频调速
AI MediaKit 的音视频调速工具支持调整媒体文件的播放倍速，以实现快放或慢放效果。该功能广泛应用于内容重剪、精彩集锦制作、延时摄影、教学演示以及播客/有声书的倍速播放等多种场景。本指南将带您了解如何通过 API 调用，轻松改变视频的播放速度。
工具说明
AI MediaKit 为视频和音频的调速分别提供了独立的 API，但它们遵循完全相同的异步任务流程，并使用同一个 API 查询任务结果。
效果预览
通过视频调速工具，您可以实现以下效果：
快速体验：将视频调整为 2 倍速快放
本节将以视频调速为例，通过一个具体的示例，演示如何将一个 MP4 格式的视频的播放速度提升至 2倍。
工具 API 核心能力
视频调速 提交视频调速任务 API 调整视频的播放速度，音轨会
同步处理以保持音画同步。
音频调速 提交音频调速任务 API 调整音频的播放速度，同时通
过算法保持音调自然。
输入视频 输出视频（1.5 倍速播放后）
准备工作
获取访问凭证：在开始之前，请访问 AI MediaKit 控制台的 API Key 管理页面 ，创建并获取您的 AIMediaKit API Key。
准备视频文件：准备一个需要调速的视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。
操作流程
视频调速是一个异步任务，整体流程如下：
成功调用 POST /api/v1/tools/adjust-video-speed 提交任务后，您将获得一个唯一的 task_id 。您可以通过轮询 GET /api/v1/tasks/{task_id} 来查询任务状态，直到状态 status 变为 completed 。或者，您也可以配置事件回调 来自动接收任务完成的通知。
任务完成后，解析响应中的 result 字段，即可在 video_url 字段中获取调速后视频的下载地址。第 1 步：提交任务
调用提交视频调速任务 API 。您可以直接复制以下 cURL 命令，提交一个 2 倍速的视频调速任务。说明
需替换参数：
请将 {Your_API_Key} 替换为您的有效 API Key。
请将 video_url 的值替换为您自己准备的视频文件 URL。
speed 参数大于 1.0 表示快放，小于 1.0 表示慢放。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/adjust-video-speed' \-H 'Authorization: Bearer {Your_API_Key}' \
-H 'Content-Type: application/json' \
-d '{
 "video_url": "https://example.com/your_source_video.mp4",
 "speed": 2.0
}'
Bash

}

第 2 步：获取结果
由于视频处理需要时间，您需要通过轮询查询任务信息 API 来获取最终结果，直到任务状态变为 completed 。
说明
需替换参数：将 URL 末尾的 {task_id} 替换为第 1 步返回的任务 ID。
当任务成功完成后，您将收到如下响应。 result 字段中的 video_url 即是调速后视频的下载地址（默认输出为 MP4 格式，有效期为 24 小时）。
说明
音频调速说明： 音频调速的流程与上述完全一致。唯一的区别在于，您需要调用音频调速 POST /api/v1/tools/adjust-audio-speed API，并将参数名从 video_url 换成 audio_url 。
