3.2.9 集智瘦身
AI MediaKit 的集智瘦身工具，通过先进的 AI 算法，能在大幅优化图片体积的同时，智能修复压缩带来的毛刺、彩噪、块效应等画质问题，增强图像的边缘与纹理细节，最终输出比原图更轻量且更清晰的图像。该功能适用于需要大规模优化图片存储成本、提升页面加载速度、改善用户图显体验的各类业务场景。
效果示例
集智瘦身工具能在保证甚至提升视觉质量的前提下，显著降低图片文件大小。
快速体验：对一张图片进行集智瘦身处理
本节将通过一个具体示例，演示如何调用 API 对一张图片进行集智瘦身处理。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备图像文件：准备一张待增强的图片，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。为方便您快速测试，本文后续步骤的示例代码中提供了一个可直接使用的演示图像 URL。
操作流程
集智瘦身是一个同步任务。您只需调用提交集智瘦身任务 API ，即可在 API 的响应体中直接获取处理后的图片地址。
步骤 1：提交任务并获取结果
可直接复制以下 cURL 命令，替换其中的参数后执行。
输入图片（5.5 MiB） 输出图片（体积减少至 4.6 MiB 但清晰度无损）
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/slim-image' \-H 'Authorization: Bearer {Your_MediaKit_API_Key}' \
-H 'Content-Type: application/json' \
说明
将 {Your_MediaKit_API_Key} 替换为您的有效 API Key。
image_url ：示例中已提供可直接用于测试的演示图片 URL。您也可以将其替换为您自己的图片地址。
请求成功后，您会直接收到如下响应。 result 字段中的 image_url 即是瘦身处理后图片的下载地址。该地址的有效期为 24 小时，请务必及时下载保存。

heic 、 avif 、 webp 。暂不支持动图。
