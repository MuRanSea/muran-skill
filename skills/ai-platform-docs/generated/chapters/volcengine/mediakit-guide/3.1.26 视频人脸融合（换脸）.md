3.1.26 视频人脸融合（换脸）
AI MediaKit 的视频人脸融合工具，能够将用户提供的目标人脸照片融合替换到视频中的人物上，输出高质量换脸视频，同步保持原视频的动作、背景、脸型、表情和口型。此功能主要适用于生成式视频脱敏需要换脸的场景。当前仅支持单人换脸。
本篇开发指南将引导您：
快速体验为视频替换目标人脸。
了解视频人脸融合工具的输入规范、输出结果与使用限制。
效果预览
通过视频人脸融合工具，您可以将一个包含人脸的视频作为输入，并提供一张目标人脸图片，快速生成一个视频中人脸被替换为目标人脸的换脸视频。
快速体验：将视频中的人脸替换为目标人脸
本节将演示如何使用 face-swap-video 工具，将一个视频中的主体人脸替换为您提供的目标人脸照片。准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备视频文件：准备一个待换脸的视频，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
换脸前视频 目标人脸图片 换脸后视频
准备目标人脸照片：准备一张清晰可见、无遮挡的正脸照片（JPEG/PNG 格式，建议分辨率 256×256～1080×1080），并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的URL。
说明
为方便您快速测试，本文后续步骤的示例代码中提供了可直接使用的演示视频和照片 URL。操作流程
视频人脸融合是一个异步任务，完整流程如下：
成功调用 POST /api/v1/tools/face-swap-video 提交任务后，您将获得一个任务 ID。
您可以轮询 GET /api/v1/tasks/{task_id} 接口，直到任务状态 status 变为 completed ；或者使用事件回调 自动接收任务状态变化。
任务完成后，解析响应中的 result 字段，即可在 video_url 字段获取最终生成的视频文件下载地址。第 1 步：提交任务
您需要调用提交视频人脸融合（换脸）任务 API 。可直接复制以下 cURL 命令，提交一个视频人脸融合任务。
说明
将 {Your_API_Key} 替换为您的有效 API Key。
video_url ：示例中已提供可直接用于测试的演示视频 URL。您也可以将其替换为您自己的视频地址。
face_mappings[0].target_face_url ：示例中已提供可直接用于测试的演示图像 URL，您也可以将其替换为您自己的目标人脸照片地址。当前仅支持单人换脸， face_mappings 数组传入一项即可。

限制项 说明
输入视频限制
视频来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、来源于火山引擎视频点
播 ( vod:// ) 和火山引擎对象存储 ( tos:// ) 四
种输入协议。关于各协议的具体说明和使用
示例，请参阅多源媒体输入与本地上传。
支持格式：当前仅支持 MP4。
分辨率限制：不得超过 1080P。
时长限制：不得超过 10 分钟（600 秒）。
多人视频处理：当前在处理包含多个人脸的
视频时，会在每一帧中识别并替换尺寸最大
的人脸。这可能导致在不同镜头或人物位置
变化时，被替换的目标在不同人物间切换。
为获得最佳效果，建议输入单人为主的视
频。
目标人脸图限制
文件来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// ) 和火山引擎对象存储
( tos:// ) 三种输入协议。关于各协议的具体
说明和使用示例，请参阅多源媒体输入与本
地上传。
支持格式：JPEG、PNG。
分辨率建议：256×256～1080×1080。
画面要求：一张清晰可见、无遮挡的正脸；
不支持动漫人脸。
