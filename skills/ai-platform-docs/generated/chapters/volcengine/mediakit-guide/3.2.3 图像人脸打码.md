3.2.3 图像人脸打码
AI MediaKit 图像人脸打码工具，能够自动检测图片中的所有人脸区域，并对检测到的人脸进行马赛克处理，实现一键人脸隐私保护。该工具适用于社交平台内容审核、街景或监控画面脱敏、新闻媒体素材处理、AI 训练数据集脱敏等多种需要批量保护人脸隐私的场景。
本篇开发指南将引导您：
快速体验通过一次 API 调用，为图片中的所有人脸打上马赛克。
理解如何通过调整参数，精细化控制打码的形状、强度与检测灵敏度。
效果示例
快速体验：一键为人脸打码
图像人脸打码是一个同步任务，您发起的请求会直接在响应中返回处理结果。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备图像文件：准备一张待处理的图片，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。为方便您快速测试，本文后续步骤的示例代码中提供了一个可直接使用的演示图像 URL。
操作流程
您只需调用提交图像人脸打码任务 API ，即可在 API 的响应体中直接获取打码后的图片地址。步骤 1：提交任务并获取结果

参数 说明
blur_shape
人脸模糊区域的形状。
circle ：（默认）圆形
rectangle ：矩形
mosaic_step
马赛克像素格大小，单位为 px 的正整数。值越
大马赛克颗粒越大、脱敏强度越高。建议范围 
[5, 100] ，默认值为 12 。

调整检测灵敏度
通过 face_detect_thresh 参数，您可以调整人脸检测的置信度阈值，取值范围为 (0, 1)。调高此值：检测更严格，可以减少对非人脸区域的误判，但可能漏掉一些清晰度较低或非正面的人脸。
调低此值：检测更宽松，可以召回更多模糊、遮挡的人脸，但可能会增加误判。
默认值为 0.9 。
示例：降低检测阈值以召回更多模糊人脸

限制项 说明
输入图像限制
图像来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、火山引擎对象存储
( tos:// ) 三种输入协议。关于各协议的具体
说明和使用示例，请参阅多源媒体输入与本
地上传。
文件大小：建议不超过 35 MB，图片文件过
大可能导致处理失败。
分辨率限制：图片宽度和高度的乘积不得超
过 4 亿像素。
支持格式：支持
.png 、 .jpg 、 .jpeg 、 .webp 、 .avif 等
主流图像格式，不支持动图。
