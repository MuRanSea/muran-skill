3.1.7 视频暗水印
AI MediaKit 的视频暗水印工具，可以在不影响视频画面视觉质量与完整性的前提下，将一串数字信息（如用户 ID、内容 ID）隐藏式地嵌入视频文件中。这项技术对于视频版权保护、内容泄露溯源、文件真实性校验等场景至关重要。即使视频经过压缩、转码、裁剪或录屏，嵌入的暗水印信息仍有很大概率被成功提取，为版权追踪和维权提供有力证据。
本篇开发指南将引导您：
理解视频暗水印的工作流程。
快速上手，通过调用 API 为视频添加一个暗水印，并从处理后的视频中将其成功提取出来。掌握如何通过参数调整暗水印的抗攻击性。
工作原理
视频暗水印的核心流程包含“添加”和“提取”两个主要环节：
添加暗水印：将原始视频和一个自定义的数字串（水印内容）作为输入，经过算法处理，生成一个肉眼看不出差异、但已包含隐藏信息的新视频。
提取暗水印：将被泄露或盗播的视频作为输入，通过暗水印提取 API 进行分析，还原出当初嵌入的数字信息。如果同一视频被多次嵌入暗水印，本工具能够提取出所有的水印信息。
快速体验：添加并提取一个视频暗水印
本节将演示如何通过 API 调用，完成“为视频添加暗水印”及“从视频中提取暗水印”的完整流程。准备工作
获取访问凭证：在开始之前，您需要获取调用 API 所需的访问凭证（API Key）。请前往 AI MediaKit 控制台的 API Key 管理页面 创建并复制您的 API Key。
准备视频文件：准备一个视频文件，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。为方便您快速测试，本文后续步骤的示例代码中提供了一个可直接使用的演示视频 URL。
操作流程
添加并提取暗水印是一个包含两个异步任务的流程，核心步骤如下：
提交暗水印添加任务并获取产物： 
调用 POST /api/v1/tools/add-video-invisible-watermark ，提交一个暗水印添加任务。轮询 GET /api/v1/tasks/{task_id} 直至任务完成，然后从响应的 result 字段中解析出已添加暗水印的视频 URL（ video_url ）。
提交暗水印提取任务并获取结果： 
调用 POST /api/v1/tools/extract-video-invisible-watermark 并传入上一步获得的视频 URL，提交一个暗水印提取任务。
轮询 GET /api/v1/tasks/{task_id} 查询最终任务状态。任务完成后，从 result 字段中获取提取出的水印内容（ watermark_contents ）。

在调用提交视频暗水印添加任务 API 时，您可以通过 watermark_level 参数来调整暗水印的强度。强度决定了暗水印的抗攻击性（抵抗视频压缩、转码、录屏等处理的能力）与画面影响程度的平衡。抗攻击性越强：意味着水印在经过各种形式的二次处理后，越不容易丢失，越容易被成功提取。画面影响程度：虽然暗水印在设计上是肉眼不可见的，但其本质仍是对视频像素数据的修改。强度越高，对原始画面的修改幅度也相对越大。
您可以根据业务场景，在以下强度等级中进行选择：
normal ：（默认值）标准强度。在画质与抗攻击性之间取得较好的平衡，适用于绝大多数场景。high ：高强度。抗攻击性最强，能抵抗更强的视频处理（如高压缩比转码、多次录屏），但对画面的潜在影响也相对更大。
示例：添加一个高强度的暗水印
典型场景与最佳实践
本章节介绍视频暗水印在真实业务场景中的典型应用流程与最佳实践，帮助您更有效地利用该功能保护您的数字资产。
场景一：AI 生成视频的全链路溯源
在 AI 内容生成（AIGC）应用中，您不仅需要保护最终合成的成品，往往还需要追溯到构成该成品的具体原始素材。通过为素材和成品分别添加不同层级的暗水印，可以建立一个完整的版权追溯链路。推荐流程：
素材级别水印：假设您通过 AI 生成了视频片段 A 和视频片段 B，可分别对这两个视频调用暗水印添加API，嵌入第一层水印（使用 high 强度），用于标识每个原始素材。
内容拼接：将已添加了第一层水印的视频 A 和视频 B 进行拼接，生成最终成品视频 C。
成品级别水印：再次调用暗水印添加 API，为最终视频 C 嵌入第二层水印（使用 normal 强度）。这一层水印用于标识最终分发的内容（如标记分发渠道、购买用户 ID 等）。
最终效果：
如果仅视频 A 或 B 被泄露，您可以从泄露的片段中提取出第一层水印，从而精确定位到是哪个原始素材被泄露。
如果最终视频 C 被盗播，您可以从盗播视频中提取出全部两层水印，既能追溯到最终成品的流向，也能关联到其所包含的原始素材信息。

先处理，后水印： 为确保暗水印的抗攻击性和提取成功率，强烈建议您在添加暗水印之前完成其他视频处理操作（如画质增强、字幕擦除、剪辑、拼接等）。对已包含暗水印的视频进行再次编辑，可能会破坏已嵌入的水印信息，导致其无法被正常提取。
场景二：双层水印增强视频抗攻击性
对于版权价值极高、防盗版需求强的核心视频内容，为应对二次压缩、录屏翻录等恶意破坏行为，可以通过叠加两层不同强度的暗水印来最大化提升其抗攻击性。
推荐流程：
第一层水印：针对原始视频，调用暗水印添加 API 嵌入第一层水印（例如，使用 high 强度），产出视频 A。
第二层水印：再针对视频 A，调用暗水印添加 API 嵌入第二层水印（需要使用与第一层不同的强度，例如 normal ）。
AI MediaKit 的暗水印提取 API 能够自动识别并解析出视频中存在的双层水印。
最终效果：
增强抗攻击性：使用不同强度的水印，相当于应用了不同的算法和嵌入策略。这使得盗版者即使通过某种处理手段侥幸破坏了其中一层水印，另一层水印仍有很大概率得以保留并被成功提取。成本与收益平衡：从攻防成本和技术效果的角度来看，叠加两层暗水印通常已能满足绝大多数高安全场景的需求，是一种性价比较高的保护方案。
使用限制
限制项 说明
输入视频
文件来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、来源于火山引擎视频点
播 ( vod:// ) 和火山引擎对象存储 ( tos:// ) 四
种输入协议。关于各协议的具体说明和使用
示例，请参阅多源媒体输入与本地上传。
支持格式：支持 mp4, mov, mkv, flv, ts, avi,
wmv 等主流视频格式。
分辨率限制：最高支持 4K 分辨率。
水印内容
格式：必须是纯数字字符串，例如 
"12345" 。
范围：字符串对应的数字必须在 1 至 
9223372036854775807 （64位正整数）之
间。
约束：不允许使用前导零（如 "0123" ）或包
含任何非数字字符。
兼容性
暗水印提取 API 仅支持提取由 AI MediaKit 暗水
印添加 API 所嵌入的水印，无法提取通过其他第
三方工具添加的任何形式的暗水印。
