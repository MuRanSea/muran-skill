3.3.2 基础剪辑
3.3.2.1 多轨道剪辑
AI MediaKit 的多轨道剪辑工具，支持视频、音频、图片、文字、字幕等多轨道编辑，同时支持转场、特效、花字、滤镜、裁剪、变速、音量调节等增强效果。您通过一个结构化的 track 时间线，配合 canvas （画布）、 output （输出）等配置，以声明式的方式描述完整的剪辑意图，工具即可据此合成最终成片。任务完成后，您将获得合成产物的下载地址。多轨道剪辑适用于短视频批量合成、模板化二次创作、图文视频混排、画中画、分屏视频墙等场景。
核心概念
多轨道剪辑的所有参数都围绕画布 → 轨道 → 元素 → 滤镜这一四层模型组织。四层之间是自顶向下的包含关系：画布承载多条轨道，轨道容纳多个元素，元素再叠加滤镜。
在时间线上，多条轨道自下而上叠放，每条轨道内的元素按 target_time 先后排列：

画布（Canvas）
画布定义了最终输出视频的分辨率和背景色，是所有视觉元素的渲染底板。您可以通过 canvas.width /canvas.height 直接指定分辨率（单位：像素，取值范围 [160, 8192]），通过 canvas.background_color 指定背景色。若不传 canvas ，系统会根据输入资源与输出配置自动确定画布。详见自定义画布。轨道（Track）与渲染层级
track 是多轨道剪辑的核心，定义了剪辑的时间线。您可以把它想象成专业剪辑软件中的多层轨道，用于在时间和空间上组织所有内容。 track 本身是一个二维数组，格式为 track[轨道索引][元素索引] ：第一维（外层数组）：代表轨道列表。索引 [轨道索引] 决定了轨道的渲染层级。 track 数组中索引越大，轨道层级越高，高层轨道的视觉内容会覆盖在低层轨道之上。 
track[0] ：最底层，通常放置背景视频或主视频。
track[1] ：位于 track[0] 之上，可放置画中画、贴纸、动态特效等。
track[2] ：位于 track[1] 之上，可放置全局文字标题或字幕，以此类推。
第二维（内层数组）：代表单条轨道，包含在该轨道上排列的一个或多个元素。同一轨道内的多个元素在时间上可以前后相接，但不应重叠。

您可以根据元素的性质，将它们放置在不同的轨道上，以实现复杂的视觉叠加和音频混合效果。视觉轨道：包含 video 、 image 、 text 、 effect 等具有视觉表现的元素，在合成时遵循「上层覆盖下层」的渲染规则。常见布局实践： 
轨道 0（底层）：放置主视频片段或背景图片。
轨道 1（中层）：放置画中画视频、贴纸或动态特效。
轨道 2（顶层）：放置全局文字标题或字幕。
video 和 image 元素可以放在同一个轨道上。
subtitle 元素必须独占一个轨道，且字幕轨道总数不超过 10 条。
音频轨道：包含 audio 元素，以及 video 元素自带的音轨，在合成时遵循「混音」规则（而非覆盖）。您可以创建一个或多个专门放置 audio 元素的轨道，例如：一个轨道放全程背景音乐，另一个轨道放特定时段的旁白或音效。

准备素材文件：准备待合成的视频、音频、图片等素材，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程
多轨道剪辑是一个异步任务，完整的调用流程如下：
成功调用 POST /api/v1/tools/multi-track-edit 提交任务后，API 将返回一个任务 ID（ task_id ）。您可以轮询查询任务信息 API 查询任务状态，直到 status 变为 completed ；或者使用事件回调自动接收任务状态变化。
任务完成后，从响应的 result 字段中获取输出视频下载地址（ video_url ）。

示例 1：多个视频时域拼接并添加转场
场景：将多个独立的视频片段按时间顺序拼接，并在片段之间添加转场动画，使衔接更自然。实现要点：转场滤镜 transition 用于在同一条轨道的相邻视频元素（下文称 A 和 B）之间创建过渡效果，并且必须添加在前一个元素（A）的 extra 数组中。根据您设置 target_time 的方式和所选转场资源的不同，分为非交叠转场和交叠转场两种模式。
交叠转场：前后两个元素在时间线上需要有重叠部分，转场效果将在该重叠时段内发生。所有转场类型都支持此模式。
实现方式：设置 A 元素的 target_time 和 B 元素的 target_time 使其重叠，重叠时长应等于或大于 transition 的 duration 。
示例：A 的 target_time 为 [0, 5000] ，B 的 target_time 为 [4000, 9000] ，在 A 上设置 duration 为 1000 的转场。效果将在 [4000, 5000] 区间内呈现。
示例代码（交叠转场）：以下示例将两个视频的时间线重叠 1000ms，并使用“风车”转场在重叠区域创建过渡。
