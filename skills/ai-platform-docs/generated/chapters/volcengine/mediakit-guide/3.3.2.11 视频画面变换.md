3.3.2.11 视频画面变换
AI MediaKit 提供一系列视频画面变换工具，允许您通过 API 对视频的空间属性进行灵活调整。这些工具包括：
视频画面翻转：对视频进行水平（左右镜像）或垂直（上下颠倒）的翻转处理。
视频画面旋转：将视频画面整体向左旋转 90 度、向右旋转 90 度或旋转 180 度。
视频画面裁剪：根据指定的像素坐标，从视频画面中裁剪出矩形区域，生成新的视频。
视频画面拼接：将多个视频在水平或垂直方向上拼接成一个新的视频。
所有画面变换工具均为异步任务，遵循统一的 API 调用流程，方便您快速集成。

快速体验：水平翻转一个视频
本节将通过一个具体的示例，演示如何将一个视频进行水平翻转。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key。
工具 输入视频 输出视频
准备视频文件：准备一个需要翻转的视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。
操作流程
视频画面变换是一个异步任务，整体流程如下：
成功调用相应工具的 POST 接口提交任务后，您将获得一个唯一的 task_id 。
您可以通过轮询 GET /api/v1/tasks/{task_id} 来查询任务状态，直到状态 status 变为 completed 。或者，您也可以配置事件回调 来自动接收任务完成的通知。
任务完成后，解析响应中的 result 字段，即可获取变换后视频的下载地址。

处理耗时
处理耗时与视频时长和分辨率正相关。视频越长、分辨率越大，耗时越长。平均 RTF（处理耗时/原片时长）为 1。

限制项 说明
输入文件限制
文件来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、来源于火山引擎视频点
播 ( vod:// ) 和火山引擎对象存储 ( tos:// ) 四
种输入协议。关于各协议的具体说明和使用
示例，请参阅多源媒体输入与本地上传。
数量限制：单次任务支持传入 1 到 100 个
URL。
支持格式： 
mp4 , flv , ts , avi , mov , wmv , 
mkv 等主流视频格式。
mp3 , m4a , wav 等主流音频格式。
文件大小：建议单个输入文件大小不超过 10
GB。
输入分辨率限制：输入视频最高支持 4K
(3840×2160) 分辨率。
