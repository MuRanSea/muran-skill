3.2.4 图像擦除修复
AI MediaKit 图像擦除修复工具，能够自动检测并移除图片中的文字或常见图标，并利用智能填充技术对擦除后的区域进行修复，使其与背景自然融合，适用于内容清洗、素材二次创作、AIGC 内容修正等多种场景。
本篇开发指南将引导您：
快速体验通过一次 API 调用去除图片中的所有文字。
掌握不同擦除场景的使用方法：擦除指定文字、擦除图标。

快速体验：一键去除图片中的所有文字
图像擦除修复是一个同步任务，您发起的请求会直接在响应中返回处理结果，无需轮询。默认的擦除场景是全屏文字擦除。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备图像文件：准备一张带有文字的图片，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程
您只需调用一次提交图像擦除修复任务 API ，即可在 API 的响应体中直接获取处理后的图片地址。步骤 1：提交任务并获取结果

擦除文字
当您需要精确擦除图片中某些特定的文字水印时，可以使用 standard_erase_text 参数。此功能仅在standard_scene 为 full_screen_text_erase 时生效。
擦除所有文字：使用默认场景 ( full_screen_text_erase )，且不提供 standard_erase_text 参数。擦除指定文字：使用默认场景，并通过 standard_erase_text 参数指定需要擦除的文字内容。系统会精确查找并擦除匹配的文字。
示例：擦除图片中所有“内部资料”字样
擦除指定区域
当您需要擦除的目标（如杂物、路人）不属于文字或图标，或者需要对图像中一块精确的区域进行修复时，可以将 standard_scene 参数设置为 selected_area_erase 。
该场景下，您需要通过以下两种方式来定义擦除区域。您可以单独使用，也可以组合使用（此时系统将擦除二者定义区域的并集）：
**坐标框 ** selected_area ：通过传入一个矩形框的归一化坐标来指定擦除区域。这种方式适用于擦除规则的矩形区域。坐标系以图片左上角为原点 (0, 0)，右下角为 (1, 1)。您需要提供矩形左上角( top_left_x , top_left_y ) 和右下角 ( bottom_right_x , bottom_right_y ) 的坐标。
**遮罩图 ** mask_url ：通过提供一张黑白遮罩图的 URL 来指定任意形状的擦除区域。这种方式较为灵活，适用于擦除不规则的物体。
遮罩图 (Mask) 说明
您可以将“遮罩图”理解为一张指导系统进行擦除的“蒙版”或“模板”。它是一张与原图等大
的黑白图片：
白色区域：对应您想从原图中擦除的部分。

上传 ( mediakit:// )、火山引擎对象存储

说明和使用示例，请参阅多源媒体输入与本
地上传。
文件大小：单张图片不得超过 10 MB。
支持格式：支持
.png 、 .jpg 、 .jpeg 、 .webp 、 .tiff 、 .bmp
和 .heic 。
图像输入分辨率： 
不得小于 10x10 像素
不得超过 2560×1440 像素（宽x高）
