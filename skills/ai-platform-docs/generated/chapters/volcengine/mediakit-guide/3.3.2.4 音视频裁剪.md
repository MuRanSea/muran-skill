3.3.2.4 音视频裁剪
AI MediaKit 的音视频裁剪工具，可以从一个较长的媒体文件中精确提取出您需要的任意时间段，生成一个全新的媒体文件。无论是从一场完整的直播录像中剪辑出精彩高光时刻，还是从一段录音中截取核心对话，都可以通过一次简单的 API 调用完成。
工具说明
AI MediaKit 为视频和音频的裁剪分别提供了独立的 API，但它们遵循完全相同的异步任务流程，并使用同一个 API 查询任务结果。
效果预览
裁剪工具根据您指定的开始和结束时间点（单位：秒），从原始文件中“切”出目标片段。
快速体验：从长视频中剪辑精彩片段
本场景将演示如何从一段完整的视频录像中，裁剪出 第 15 分 30 秒 到 第 16 分钟 之间的精彩片段。工具 API 核心能力
视频裁剪 提交视频裁剪任务 API 根据指定的开始和结束时间
点，从原始视频中提取片段。
音频裁剪 提交音频裁剪任务 API 根据指定的开始和结束时间
点，从原始音频中提取片段。
输入视频 输出视频（裁剪 0 到 10 秒）
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备视频文件：准备一个待裁剪的视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。
操作流程
音视频裁剪是一个异步任务：
成功调用视频裁剪 POST /api/v1/tools/trim-video API 后，API 将返回一个任务 ID。
您可以轮询 GET /api/v1/tasks/{task_id} API，直到任务状态 status 变为 completed ；或者使用事件回调自动接收任务状态变化。
任务完成后，解析 result 字段，即可在 video_url 字段处获取最终裁剪视频的下载地址。第 1 步：提交任务
您需要调用提交视频裁剪任务 API 。可直接复制以下 cURL 命令提交。
说明
需替换参数：
将 {Your_API_Key} 替换为您的有效 API Key。
将 video_url 替换为您真实的视频文件地址。
start_time 和 end_time 指定了裁剪的起始和结束时间点，类型为数字，单位是秒。本例中 930 代表 15 分 30 秒， 960 代表 16 分钟。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/trim-video' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {Your_API_Key}' \
--data '{
 "video_url": "https://example.com/full_game_recording.mp4",
 "start_time": 930,
 "end_time": 960
}'

校验裁剪时间范围
在提交任务前，我们建议您在业务逻辑中增加校验步骤：
检查时间有效性：确保 end_time 晚于 start_time 。
比对文件时长：确保 start_time 和 end_time 都在原始文件的总时长范围之内。
将无效的参数提前拦截，可以避免不必要的 API 调用和任务失败。
输出规格说明
输出视频格式：视频裁剪任务默认输出的视频格式 mp4。
输出视频分辨率：默认与原始视频文件的分辨率保持一致。
输出音频格式：音频裁剪任务默认输出的音频格式为 m4a。
参考信息
使用限制
处理耗时
处理耗时与视频时长和分辨率正相关。视频越长、分辨率越大，耗时越长。平均 RTF（处理耗时/原片时长）为 1。

限制项 说明
输入文件限制
文件来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、来源于火山引擎视频点
播 ( vod:// ) 和火山引擎对象存储 ( tos:// ) 四
种输入协议。关于各协议的具体说明和使用
示例，请参阅多源媒体输入与本地上传。
支持格式： 
mp4 , flv , ts , avi , mov , wmv , 
mkv 等主流视频格式。
mp3 , m4a , wav 等主流音频格式。
文件大小：建议单个输入文件大小不超过 10
GB。
输入分辨率限制：输入视频最高支持 4K
(3840×2160) 分辨率。
