3.5.4 AIGC 视频生成质量评估
AI MediaKit 的 AIGC 视频生成质量评估工具，面向 AIGC 视频生产场景，对视频（可选结合参考图）按需检查参考信息一致性、世界合理性、内容持续性、视觉保真度等质量问题，自动定位异常时间区间、输出问题说明与典型问题帧，帮助您快速完成采用、复核或重新生成决策。它既可独立用于生成结果检查，也可接入创作 Agent，形成「视频生成 — 质量检查 — 人工复核或重新生成」的生产闭环。本篇开发指南将引导您：
了解 AIGC 视频质量评估的检测模块与问题类型。
快速体验如何对一段 AIGC 视频进行全模块质量评估。
掌握按场景组合检查模块，以及结合参考图检查参考信息一致性的用法。
检测模块与问题类型
AIGC 视频质量评估工具通过 modules 参数提供 4 个检测模块，覆盖 AIGC 视频生产中最常见的质量问题。您可以按业务场景自由组合，每个模块检出的问题会在结果中标注所属 module 与具体问题类型 type 。
应用场景
AI 短剧与漫剧质检：检查角色面貌、服装、道具与场景的一致性，以及动作连贯性、物理合理性等问题，避免角色变脸、物体突变、剧情穿帮。
电商广告素材视频质检：结合参考图，检查商品外观、颜色、Logo、包装文字、品牌元素等是否保持一致，识别商品变形、画面时序和物理表现等问题。
创作 Agent 生成闭环：视频生成后自动触发质量检查，合格视频进入编辑环节，疑似问题视频转人工复核，严重问题视频自动重新生成。

准备工作
获取访问凭证：在开始之前，请访问 AI MediaKit 控制台的 API Key 管理页面 ，创建并获取 MediaKitAPI Key。
开通火山方舟大模型服务：AIGC 视频生成质量评估工具依赖火山方舟（Ark）视觉大模型完成评估。请前往火山方舟控制台 ，确认本工具所需的大模型（如 Doubao 系列）已开通且可用。模型能力会影响检测效果，推荐使用 doubao-seed 系列中最新的 pro 模型，例如 doubao-seed-2-1-pro-260628 。完成跨服务授权：首次使用 AIGC 视频质量评估工具前，请前往 AI MediaKit 控制台的授权管理页面，授权 AI MediaKit 访问您的 ARK 火山方舟资源，否则任务将因权限不足而失败。
准备视频文件：准备一个待评估的视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。
操作流程
AIGC 视频质量评估是一个异步任务，其标准流程如下：
成功调用 POST /api/v1/tools/evaluate-aigc-video-quality 提交任务后，您将获得一个任务 ID。您可以轮询 GET /api/v1/tasks/{task_id} 接口，直到任务状态 status 变为 completed ；或者使用事件回调 自动接收任务状态变化。
任务完成后，解析响应中的 result 字段，即可在 issues 中获取检出的问题明细。未检查到问题时 issues 为空数组。
第 1 步：提交质量评估任务
您需要调用提交 AIGC 视频质量评估任务 API 。可直接复制以下 cURL 命令，提交一个执行全部适用模块的评估任务。
说明

prefer_models ：指定评估使用的火山方舟模型 ID (Model ID)。模型能力会影响检测效果，推荐使用 doubao-seed 系列中最新的 pro 模型，例如 doubao-seed-2-1-pro-260628 。您可以在火山方舟控制台在线推理页面 查看您账号下可用的模型 ID。

按场景组合检查模块
快速入门中不传 modules ，执行的是全部适用模块。您也可以通过 modules 参数按业务场景自由组合检查维度。可选模块如下：
reference_consistency ：参考信息一致性。对比视频中的元素与提供的参考图是否一致。启用该模块时必须提供 reference_images （数组长度 1~6，每张图需通过 category 标注类型： character =人物、clothing =服饰、 product =商品、 scene =场景、 prop =道具、 other =其他）。
world_plausibility ：世界合理性。检查画面是否符合物理与运动规律（如重力、碰撞、穿模、惯性等）。
content_continuity ：内容持续性。检查人物、商品等实体在时间维度上是否保持一致。
visual_fidelity ：视觉保真度。检查人体、物体、文字的结构与自然度。

费用说明
AIGC 视频质量评估工具的费用由两部分组成：
AI MediaKit 任务费用：由 AI MediaKit 收取，按输入视频的总时长计费。公测阶段暂不收取该部分费用。
火山方舟大模型调用费用：功能运行依赖的底层大模型由火山方舟提供。您通过跨服务授权使用这些模型所产生的费用，将由火山方舟根据其自身定价直接向您收取。关于详细的计费规则与价格，请参阅火山方舟计费说明 。

限制项 说明
输入视频限制
* 视频来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、来源于火山引擎视频点播
( vod:// ) 和火山引擎对象存储 ( tos:// ) 四种输
入协议。关于各协议的具体说明和使用示例，请
参阅多源媒体输入与本地上传。
* 支持格式： mp4 、 flv 、 ts 、 avi 、
mov 、 wmv 、 mkv 等主流视频格式。
* 视频时长：单个视频时长不超过 3 分钟。
参考图限制
仅在启用 reference_consistency 模块时需要提供 
reference_images 。最少 1 张，最多 6 张。每张
图需标注 category （ character / clothing /
product / scene / prop / other ）。
