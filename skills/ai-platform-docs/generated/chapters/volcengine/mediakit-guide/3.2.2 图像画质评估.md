3.2.2 图像画质评估
AI MediaKit 图像画质评估工具，能够对输入图片进行多维度的主客观质量分析和美学评分，适用于媒体质量监控、低质图筛查、AIGC 内容审核、推荐系统排序及训练数据清洗等多种场景。
本篇开发指南将引导您：
快速体验通过一次 API 调用获取图像的质量分数。
理解“标准版”与“专业版”评估模型的差异与适用场景。
学习如何解读返回的各项画质与美学分数。
掌握如何根据需求指定评估维度，实现更灵活的调用。
快速体验：一键获取图像质量分
图像画质评估是一个同步任务，您发起的请求会直接在响应中返回评估结果。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备图像文件：准备一张待评估的图片，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程
您只需调用提交图像画质评估任务 API ，即可在 API 的响应体中直接获取评估分数。
步骤 1：提交任务并获取结果
可直接复制以下 cURL 命令，提交一个画质评估任务。本示例使用默认的标准版模型，评估图片的主观质量（ vqscore ）和噪声（ noise ）两个维度。
说明
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/evaluate-image-quality' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {Your_API_Key}' \
--data '{
 "image_url": "https://example.com/your_image.jpg",
 "tool_version": "standard",
 "standard_evaluate_items": [
 "vqscore",
 "noise"
 ]
}'
Bash
需替换参数：
将 {Your_API_Key} 替换为您的有效 API Key。
将 image_url 替换为您真实的图片地址。
步骤 2：查看响应与分数解读
由于是同步接口，请求成功后，您会立即收到包含最终分数的响应。 result 字段即为评估结果。vqscore : 85.5 分，表示图片主观质量较好。
noise : 10.2 分，表示图片噪声强度较低，画面干净。
进阶使用
标准版和专业版对比
图像画质评估提供“标准版”和“专业版”两个版本，您可以通过 tool_version 参数进行选择。指定评估维度（仅标准版）
当您使用标准版时，如果不需要全部 15 个维度的分数，可以通过 standard_evaluate_items 参数指定您关心的评估项。这可以减少响应体大小，使结果更聚焦。如果不传此参数，默认会返回 ["vqscore", "noise",
"aesthetic", "blur"] 四个维度的分数。

应用场景
AI 生成图像质量筛选：自动过滤低质量 AI 图像、AIGC 生图。例如平台仅允许上传综合评分大于 70 的图像。
内容审核：自动识别模糊、噪声大、有压缩痕迹的图片，避免低质内容上线。例如电商平台上如果用户上传的商品图模糊评分小于 60，则自动打回重传。
图像增强工具反馈：在 Photoshop 插件、在线修图工具等图像增强工具中，如果用户上传的图片模糊评分较低，则建议"去模糊"或"降噪"。
AI 模型训练数据清洗：在训练视觉模型前，自动剔除低质量图像，避免影响模型性能。例如在训练人脸识别模型前，过滤掉模糊评分小于 65 的图像。
图库推荐：自动评估上传图像的质量，决定是否推荐到首页。例如美学评分小于 70 的图片，不会进入"编辑推荐"流。

输入图像限制
图像来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、火山引擎对象存储
( tos:// ) 三种输入协议。关于各协议的具体
说明和使用示例，请参阅多源媒体输入与本
地上传。
文件大小：单张图片不得超过 10 MB。
支持格式：支持 png 、 jpeg 、 webp 和 
heic 。
图像输入分辨率： 
短边不得超过 4320 px
长边不得超过 7680 px
