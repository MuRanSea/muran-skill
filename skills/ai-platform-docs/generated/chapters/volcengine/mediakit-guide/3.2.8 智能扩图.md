3.2.8 智能扩图
AI MediaKit 智能扩图工具，利用 AI 算法对原图上、下、左、右四个方向进行内容扩展。算法会根据原图内容对扩展区域自动补充相似内容，使补充结果图在纹理、内容和边缘过渡上与原图保持自然一致。支持按比例灵活控制每个方向的扩展幅度，适用于竖屏转横屏、横屏转竖屏、广告素材多平台尺寸适配等需要调整图片画幅的场景。
本篇开发指南将引导您：
快速体验通过一次 API 调用扩展图片画布。
掌握如何自定义扩展的方向和比例。
效果示例
通过智能扩图工具，您可以轻松改变图片的画幅和构图。

为确保生成质量，单次任务对单个方向（上、下、左、右）的最大扩展比例为 40%。如需进行更大范围的扩展，您可以通过多次调用本工具，以“渐进式”的方法达到最终画幅。

图像智能扩图是一个同步任务，您发起的请求会直接在响应中返回处理结果，无需轮询。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key。
准备图像文件：准备一张待处理的图片，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程
您只需调用提交智能扩图任务 API ，即可在 API 的响应体中直接获取处理后的图片地址。步骤 1：提交任务并获取结果
可直接复制以下 cURL 命令，提交一个扩图任务。本示例将一张竖屏图的左右各扩展 20%，将其转换为横屏图。
场景 输入图 生成示例结果
（尺寸为 750 × 500）
（尺寸为 918 × 1624）
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/expand-image-canvas' \-H 'Authorization: Bearer {Your_API_Key}' \
-H 'Content-Type: application/json' \
-d '{
 "image_url": "https://example.com/portrait_image.jpg",
说明
将 {Your_API_Key} 替换为您的有效 API Key。
将 image_url 替换为您真实的图片地址。
通过 expand_top 、 expand_bottom 、 expand_left 、 expand_right 这四个参数控制每个方向的扩展程度。所有方向（上、下、左、右）的扩展比例均是相对于原图短边的长度来计算。示例：对于一张 1920×1080（横屏）的图片，其短边为 1080 像素。若设置 expand_top: 0.2 ，则实际向上扩展 1080 * 0.2 = 216 像素。每个方向的比例值取值范围均为 [0, 0.4] 。设置为 0 表示该方向不扩展。
步骤 2：查看响应
由于是同步接口，请求成功后，您会在几秒内收到包含最终结果的响应。您可以直接从 result.image_url字段获取扩图后图片的下载地址（有效期为 24 小时）。
