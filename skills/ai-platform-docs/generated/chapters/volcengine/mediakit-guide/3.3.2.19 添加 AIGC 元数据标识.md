3.3.2.19 添加 AIGC 元数据标识
根据《人工智能生成合成内容标识办法》，自 2025 年 9 月 1 日起，AI 生成的图片、音频、视频等内容需添加显式标识与隐式标识，以确保内容来源可识别、可追溯。AI MediaKit 提供添加 AIGC 元数据标识工具，面向 AIGC 内容生成、处理与分发场景，支持将 AI 生成属性、服务提供者信息、内容唯一编号等标识信息写入文件元数据，帮助您在不改变内容观看体验的情况下完成隐式标识嵌入，满足内容声明、主体留痕与合规溯源要求。
本指南将带您了解如何通过 API 调用，为视频、图片或音频写入 AIGC 元数据标识。
快速体验：为视频写入 AIGC 元数据标识
本节将通过一个具体的示例，演示如何为一段视频写入生成合成标签与服务提供者信息。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key。
准备素材：准备一个待写入标识的媒体文件（视频 mp4 / mov 、图像 jpeg / png / webp 或音频 mp3 / ogg / wav ），并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程
添加 AIGC 元数据标识是一个异步任务，整体流程如下：
成功调用 POST /api/v1/tools/add-aigc-metadata 提交任务后，您将获得一个唯一的 task_id 。您可以通过轮询 GET /api/v1/tasks/{task_id} 来查询任务状态，直到状态 status 变为 completed 。或者，您也可以配置事件回调 来自动接收任务完成的通知。
任务完成后，解析响应中的 result 字段，即可在与输入模态一致的 video_url 、 image_url 或 audio_url 字段中获取处理后文件的下载地址，并在 aigc_metadata_content 字段中获取写入后的标识内容。
第 1 步：提交任务
调用提交提交添加 AIGC 元数据标识任务 API 。您可以直接复制以下 cURL 命令，向 API 提交一个为视频写入 AIGC 元数据标识的任务。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/add-aigc-metadata' \-H 'Authorization: Bearer {Your_API_Key}' \
-H 'Content-Type: application/json' \
-d '{
 "video_url": "https://example.com/your_source_video.mp4",
 "aigc_metadata_content": {
 "label": "1",
 "content_producer": "your_company_name",
 "produce_id": "your_unique_content_id_001"
 }
}'
Bash
说明
请将 {Your_API_Key} 替换为您的有效 API Key。
请将 video_url 的值替换为您自己准备的媒体文件 URL。
请根据实际业务需要填写 aigc_metadata_content 中的标识字段。对于您在请求参数 
aigc_metadata_content 中提供的字段，系统将遵循以下更新逻辑： 
覆盖：如果字段已存在，新值将覆盖旧值。
新增：如果字段不存在，将新增该字段与值。
保留：如果未在请求中提供某字段，元数据中的原始值将保持不变。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。
第 2 步：获取结果
由于媒体处理需要时间，您需要通过轮询查询任务信息 API 来获取最终结果，直到任务状态变为 completed 。
说明
将 URL 末尾的 {task_id} 替换为第 1 步返回的任务 ID。
当任务成功完成后，您将收到如下响应。因输入为 video_url ， result 字段中返回 video_url （处理后视频下载地址，有效期为 24 小时），并返回写入后完整的 aigc_metadata_content 。

JSON
字段 说明
label
生成合成标签：
1 表示属于人工智能合成内容
2 表示可能为人工智能合成内容
3 表示疑似人工智能合成内容
content_producer 生成合成服务提供者名称或编码。
produce_id 生成合成服务提供者对内容生成过程或内容的唯
一编号。
reserved_code1 生成合成服务提供者预留字段，用于自主开展安
全防护。
content_propagator 内容传播服务提供者名称或编码。
propagate_id 内容传播服务提供者对传播过程或内容的唯一编
号。
reserved_code2 内容传播服务提供者预留字段，用于自主开展安
全防护。
