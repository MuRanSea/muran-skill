3.1.17 视频抠图
AI MediaKit 提供人像抠图和绿幕抠图两种工具，能够将视频中的主体（人物、物品等）与背景精准分离，生成背景透明或纯色背景的视频素材，为虚拟背景替换、创意合成、电商展示等后期处理场景提供强大支持。本篇开发指南将引导您快速上手，通过 API 实现视频的自动化抠图处理。
工具说明
AI MediaKit 为人像抠图和绿幕抠图分别提供了独立的 API，但它们遵循完全相同的异步任务流程，并使用同一个 API 查询任务结果。

准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 MediaKit APIKey（用于媒体处理功能鉴权）。
准备视频文件：准备一个待处理的视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。
操作步骤
视频抠图是一个异步任务，整体流程如下：
成功调用 POST /api/v1/tools/matte-portrait-video 后，API 将返回一个任务 ID 。
您可以轮询 GET /api/v1/tasks/{task_id} ，直到任务状态 status 变为 completed ；或者使用事件回调自动接收任务状态变化。
任务完成后，您可解析 result 字段，在 video_url 字段处获取背景透明视频的下载地址。第 1 步：提交人像抠图任务

选择输出格式与背景颜色
视频抠图工具支持三种输出格式，您可以通过 format 参数在提交任务时指定：
WEBM （默认）：输出透明背景视频，兼容性好、文件体积较小。
MOV ：输出透明背景视频，提供无损 Alpha 通道，文件体积较大。
MP4 ：输出纯色背景视频。当选择 MP4 时，您还可以通过 background_color 参数指定背景颜色，支持 black （黑色）、 white （白色）、 green （绿色）。两种抠图工具的默认背景色不同： 绿幕抠图： format 为 MP4 且未传 background_color 时，默认背景色为 black （黑色）。人像抠图： format 为 MP4 且未传 background_color 时，默认背景色为 green （绿色）。以下示例演示如何将人像抠图结果输出为白色背景的 MP4 视频：

应用场景
虚拟背景与直播：在视频会议、在线教育或直播中，实时或离线替换人物背景，打造专业、有趣的虚拟场景。
影视与短视频创作：将拍摄的人物或物品素材与任意背景、特效视频进行合成，创造出天马行空的视觉效果。
电商视频制作：为商品动态展示视频更换不同风格的背景，或生成背景透明的素材，方便在各种营销场景中重复使用。
教育与演示：将讲解人抠出并叠加在课件或演示内容之上，制作更具吸引力的画中画式教学视频。使用限制
处理耗时
任务处理时长与视频的原始时长和分辨率相关，通常处理耗时在视频时长的 1~3 倍之间。
