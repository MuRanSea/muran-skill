3.2.14 图像基础编辑
本指南介绍 AI MediaKit 提供的一系列同步图像基础编辑工具，涵盖空间几何变换（旋转/翻转/裁剪）、视觉风格调整（锐化/模糊/打码）等。
工具说明
AI MediaKit 提供一系列同步的图像基础编辑 API，调用后可直接在响应体中获取处理结果。工具名称 API 参考 说明
圆角矩形 提交圆角矩形任务 API 为图像四角添加正圆或椭圆形
的圆角效果。
图像旋转 提交图像旋转任务 API 按指定角度逆时针旋转图像，
并可设置空白区域的填充色。
图像翻转 提交图像翻转任务 API 对图像进行水平（左右镜像）
或垂直（上下翻转）的翻转。
图像锐化 提交图像锐化任务 API 增强图像的边缘细节与整体清
晰度，提供三档强度可选。
图像高斯模糊 提交图像高斯模糊任务 API 对图像进行高斯模糊处理，支
持自定义模糊强度。
图像打码 提交图像打码任务 API
对全图或指定矩形区域应用马
赛克，可自定义像素格形状与
大小。
添加图文水印 提交图像添加图文水印任务
API
在图像上添加文字或图片水
印，支持九宫格定位、平铺、
透明度等多种自定义设置。
图像调整 提交图像调整任务 API
调整图像的亮度、对比度和饱
和度，提供调亮/调暗、增强/
减弱对比度、增强/减弱饱和度
等效果。
图像裁剪 提交图像裁剪任务 API
对输入图像进行多模式裁剪，
包括方向裁剪、定向裁剪、自
定义裁剪与内切圆裁剪。
图像压缩 提交图像压缩任务 API
提供一站式图像体积优化方
案，支持指定压缩质量、文件
体积上限、输出格式转换等。
图像缩放 提交图像缩放任务 API
按指定尺寸或缩放比例对图像
进行放大或缩小，支持多种缩
放模式。
图像负片 提交图像负片任务 API 将图像的颜色反转，一键生成
底片风格的艺术效果。
