3.1.27 视频插帧
AI MediaKit 的视频插帧工具，基于深度学习的智能补帧能力，可在相邻视频帧之间智能生成过渡帧，提升视频帧率与运动连续性。它能有效改善低帧率、快速运动、大屏播放等场景下的卡顿、跳帧和画面不连贯问题；同时适用于 AIGC 视频增强，可将 Seedance 等模型生成的 24fps 视频提升至更高帧率，优化人物动作、镜头运动和动态细节的衔接效果，让视频播放更流畅、画面过渡更自然。
本篇开发指南将引导您：
快速体验如何将一段视频补帧至指定帧率。
了解目标帧率的取值建议与使用限制。
效果预览
通过视频插帧工具，您可以将低帧率视频提升至更高帧率，显著改善画面的流畅度。以下示例展示了将一段低帧率视频提升至 60fps 后的效果对比。对比处理前后的视频，可以观察到整体视觉感受更丝滑，卡顿感明显消失，运动表现更自然。
快速入门：将视频补帧至 60fps
本节以将一段 24fps 的视频补帧至 60fps 为例，演示视频插帧的完整流程。
准备工作
获取访问凭证：在开始之前，请访问 AI MediaKit 控制台的 API Key 管理页面 ，创建并获取 MediaKitAPI Key。
原视频 ( 24 fps) 插帧至 60 fps
准备视频文件：准备一个待处理的视频文件，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。为方便您快速测试，本文后续步骤的示例代码中提供了一个可直接使用的演示视频 URL。
操作流程
视频插帧是一个异步任务，其标准流程如下：
成功调用 POST /api/v1/tools/video-frame-interpolation 提交任务后，您将获得一个任务 ID。您可以轮询 GET /api/v1/tasks/{task_id} 接口，直到任务状态 status 变为 completed ；或者使用事件回调 自动接收任务状态变化。
任务完成后，解析响应中的 result 字段，即可在 video_url 中获取补帧后视频的下载地址。第 1 步：提交插帧任务
您需要调用提交视频插帧任务 API 。可直接复制以下 cURL 命令，提交一个将视频补帧至 60fps 的任务。
说明
将 {Your_API_Key} 替换为您的有效 API Key。
video_url ：示例中已提供可直接用于测试的演示视频 URL。您也可以将其替换为您自己的视频地址。
fps ：目标输出帧率，取值范围为 [15, 120]。建议目标帧率不超过原片帧率的 4 倍，以获得更自然的补帧效果。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/video-frame-interpolation' \-H 'Authorization: Bearer {Your_API_Key}' \
-H 'Content-Type: application/json' \
-d '{
 "video_url": "https://vod-ai-test.tos-cn-beijing.volces.com/demo/demo_video_24fps.mp4",
 "fps": 60
}'

插帧任务需要一定的处理时间（与视频文件大小、时长相关）。您需要轮询查询任务信息 API ，直到任务状态 status 变为 completed 。
说明
将 URL 末尾的 {task_id} 替换为第 1 步返回的任务 ID。
