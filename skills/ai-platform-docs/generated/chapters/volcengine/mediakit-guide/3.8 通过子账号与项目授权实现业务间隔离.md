3.8 通过子账号与项目授权实现业务间隔离
当一个火山引擎账号下承载多个业务时，业务之间通常需要明确的权限与数据边界：业务 A 的成员不应该看到业务 B 的任务和用量，业务 A 产生的费用也需要单独核算。AI MediaKit 基于火山引擎访问控制（IAM）的项目能力实现这种隔离：您为每个业务创建一个项目，把子账号的权限限制在对应项目上，子账号访问控制台或调用 API 时，就只能触达该项目下的队列、任务和数据。
本文以一个账号下有两个业务（业务 A 和业务 B）为例，介绍从创建项目、分配队列，到创建子账号并完成授权的完整流程。完成后，两个业务各自使用独立的子账号和队列，互不可见。
前提条件
已拥有火山引擎主账号。创建项目和子账号、为子账号授权均需要使用主账号操作，子账号无法为自己或他人授权。
已开通 AI MediaKit 。
已了解访问控制的核心概念（用户、策略、项目、授权范围）。详情请参见基本概念 。
隔离生效方式
AI MediaKit 的隔离单元是项目，队列是项目下的任务入口。子账号被授权到某个项目后，控制台和 API 两侧都会按该项目收敛可见范围。

步骤 4：为子账号授权并限制到项目
给子账号添加 AI MediaKit 策略，并把策略的授权范围限制到目标项目，隔离在这一步生效。在权限设置页面中，按所属服务筛选 AI MediaKit，或直接搜索策略名（服务标识为 imp ），勾选需要的策略。
在页面下方的限制到项目资源区域选择是，并在下拉列表中选择步骤 1 创建的业务项目。
检查策略与项目无误后单击提交。从新建用户流程进入时，该按钮为下一步。
说明
如果限制到项目资源保持默认的否，策略将对账号下所有项目（包括后续新增的项目）生效，子账号可以切换到任意项目，隔离不会生效。
同一个子账号需要访问多个业务项目时，可以为其多次添加授权，每次指定一个项目。
其他授权方式（两种方式的结果一致，按团队的分工习惯选择）： 
从项目侧授权：在项目管理 中进入目标项目的授权策略页签，单击添加权限，选择需要访
问该项目的用户。
从用户侧授权：在访问控制控制台 的用户页，单击添加权限，选择 AI MediaKit 策略并把授权范围限制到项目。
步骤 5：验证隔离效果
授权完成后，建议先用子账号实际登录一次，确认可见范围符合预期，再把账号交给业务方。登录后按下述步骤操作，再逐项对照检查项确认结果。
打开火山引擎登录页 ，选择 IAM 子用户登录，填写主账号、子账号用户名和密码后登录。在产品与服务中心选择 AI MediaKit，进入 AI MediaKit 控制台。
展开顶部的项目选择器，确认只列出被授权的项目。

步骤 6：为子账号配置 API 凭证（可选）
AI MediaKit 接口只接受 API Key，不支持 Access Key 与 Secret Access Key 的签名方式，因此这里只需要创建 API Key。如果业务通过 API 调用 AI MediaKit，给子账号配好 API Key，API 侧才会同样受项目权限约束。
使用主账号登录访问控制控制台 ，在用户列表中单击目标子账号的用户名。
在用户详情页切换到密钥页签，在 API Key 区域单击创建 API Key，填写密钥名称后单击确定。密钥只在创建时完整显示一次，请立即复制并妥善保存。
调用 API 时把 API Key 放在 Authorization 请求头，以 Bearer 方式传入，并在请求体中传入被授权项目下的 queue_id 。

使用限制
常见问题
子账号登录后看不到任何项目
先确认策略是否已添加且授权范围限定到了项目，再确认该策略属于 AI MediaKit。授权生效可能有短暂延迟，修改后请让子账号退出并重新登录再验证。
能进入项目，但队列列表为空
说明队列还没有归属到该项目。可以在该项目的项目选择器下新建队列，或在访问控制控制台中把已有队列转入该项目。
子账号调用 API 提示无权限
排查两个容易出错的点：一是使用了 AI MediaKit 控制台创建的 API Key，这类密钥不受项目权限约束，也无法体现隔离；二是请求中的 queue_id 属于其他业务的项目。改用 IAM 子账号在密钥页签创建的 APIKey，并传入被授权项目下的 queue_id 即可。
能否按业务查看费用
可以。费用中心的账单明细按项目维度拆分，切换到对应项目即可查看该业务的独立消费金额。限制项 说明
AI MediaKit 控制台创建的 API Key
在 AI MediaKit 控制台的基础配置中创建的 API
Key 不受 IAM 项目权限约束，无法用项目授权限
制其访问范围，只能通过 queue_id 区分任务归
属。需要真正隔离权限时，请使用 IAM 子账号
的 API Key。
异步任务并发上限
并发限制为账号维度，默认 20，所有项目和队
列共享。项目隔离不改变这一上限，拆分子账号
也不能提升并发。
队列数量 每个账号最多 10 个队列（含默认队列），多业
务场景需要提前规划队列分配。
队列迁移 队列可跨项目迁移，但迁移前后的用量统计与账
单口径不同，可能无法完全对应。
