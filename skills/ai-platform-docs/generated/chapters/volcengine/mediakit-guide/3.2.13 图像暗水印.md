3.2.13 图像暗水印
AI MediaKit 的图像暗水印工具，可以在不明显破坏图片完整性与画质的前提下，将一段自定义文本信息隐藏式地嵌入图片中。这项技术对于版权保护、AIGC 生图合规、传播链路追踪、搬运取证等场景至关重要。即使图片经过缩放、压缩、转码等处理，嵌入的暗水印信息仍有很大概率能被成功提取，为版权追踪与维权提供有力证据。
本篇开发指南将引导您：
理解图像暗水印的工作流程。
快速上手，通过调用 API 为图片添加一个暗水印，并从处理后的图片中将其成功提取出来。掌握如何通过参数选择模型版本与暗水印强度。
工作原理
图像暗水印的核心流程包含“添加”和“提取”两个主要环节：
添加暗水印：将原始图片和一段自定义文本（水印内容）作为输入，经过算法处理，生成一张肉眼看不出差异、但已包含隐藏信息的新图片。添加时需显式指定暗水印模型版本。
提取暗水印：将疑似泄露或被搬运的图片作为输入，通过暗水印提取 API 进行分析，还原出当初嵌入的文本信息。提取时必须使用与添加时相同的模型版本。
快速体验：添加并提取一个图像暗水印
本节将演示如何通过 API 调用，完成为图片添加暗水印及从图片中提取暗水印的完整流程。图像暗水印的添加与提取均为同步任务，您发起的请求会直接在响应中返回处理结果。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备图像文件：准备一张图片，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供API 调用的 URL。
操作流程
添加并提取暗水印是一个包含两个同步任务的流程，核心步骤如下：
提交暗水印添加任务并获取产物：调用提交图像暗水印添加任务 API ，在响应的 result 字段中直接获取已添加暗水印的图片 URL（ image_url ）。
提交暗水印提取任务并获取结果：调用提交图像暗水印提取任务 API 并传入上一步获得的图片 URL与**相同的 ** tool_version ，在响应的 result 字段中获取提取出的水印内容（ watermark_content ）。第 1 步：提交图像暗水印添加任务
首先，调用提交图像暗水印添加任务 API 来为一张图片嵌入您指定的文本信息。可直接复制以下 cURL命令提交任务。本示例使用 adapt 模型版本，将文本 "copyright-2026" 作为暗水印内容嵌入图片中。说明

进阶使用
调整暗水印强度
在调用提交图像暗水印添加任务 API 时，可通过 strength_level 参数来调整暗水印的强度。强度越高，抵抗攻击（缩放、压缩、转码等处理）的性能越强，但对原始画面的潜在影响也相对越大（暗水印本质仍是对图像像素数据的修改）。
low ：低强度。适用于纯色图场景以及对图像质量要求较高的场景。

计费说明
图像暗水印工具的费用根据成功调用次数进行计算。无论是添加暗水印还是提取暗水印，每次成功的 API调用都将计为一次处理。关于详细的计费标准和计费示例，请参阅图像智能编辑（按次计费）。

限制项 说明
输入图像
图像来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、火山引擎对象存储
( tos:// ) 等输入协议。关于各协议的具体说
明和使用示例，请参阅多源媒体输入与本地
上传。
支持格式： .png 、 .jpg 、 .jpeg 、 .webp
等常见主流图像格式。
水印内容
格式：自定义文本内容。
长度：最长 128 字符；若均为中文文字，建
议不超过 42 个字。
兼容性
暗水印提取仅支持提取由 AI MediaKit 图像暗水
印添加 API 嵌入的水印，且提取时使用的 
tool_version 必须与添加时一致；无法提取通过
其他第三方工具添加的任何形式的暗水印。
