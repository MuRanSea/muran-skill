3.3.2.14 视频加图片
AI MediaKit 视频加图片工具，允许您将一张静态图片（如 Logo、二维码、水印或任何装饰性元素）叠加到视频画面的指定位置。您可以精确控制图片的大小、位置以及其在视频中出现的起止时间。本指南将带您了解如何通过 API 调用，为您的视频添加图片水印。
效果预览
通过视频加图片工具，您可以实现以下效果：
快速体验：为视频添加右下角 Logo
本节将通过一个具体的示例，演示如何将一个 PNG 格式的 Logo 图片，作为水印添加到视频的右下角，并让它贯穿整个视频。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key。
准备素材：将以下两个文件上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的URL。 
视频文件：准备一个需要添加水印的视频文件。
图片文件：准备一张用作水印的图片（建议使用带透明通道的 PNG 格式）。
操作流程
输入视频 输出视频（右上角添加 Logo 后）

◦
视频加图片是一个异步任务，整体流程如下：
成功调用 POST /api/v1/tools/add-image-to-video 提交任务后，您将获得一个唯一的 task_id 。您可以通过轮询 GET /api/v1/tasks/{task_id} 来查询任务状态，直到状态 status 变为 completed 。或者，您也可以配置事件回调 来自动接收任务完成的通知。
任务完成后，解析响应中的 result 字段，即可在 video_url 字段中获取处理后视频的下载地址。第 1 步：提交任务
调用提交视频加图片任务 API 。您可以直接复制以下 cURL 命令，向 API 提交一个添加水印的任务。该示例将使用默认参数，把图片放在视频的右下角区域。
说明
需替换参数：
请将 {Your_API_Key} 替换为您的有效 API Key。
请将 video_url 和 sub_image_url 的值替换为您自己准备的视频和图片文件 URL。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。
第 2 步：获取结果
由于视频处理需要时间，您需要通过轮询查询任务信息 API 来获取最终结果，直到任务状态变为 completed 。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/add-image-to-video' \-H 'Authorization: Bearer {Your_API_Key}' \
-H 'Content-Type: application/json' \
-d '{
 "video_url": "https://example.com/your_source_video.mp4",
 "sub_image_url": "https://example.com/your_logo.png"
}'

进阶使用
控制水印的显示时长
默认情况下，添加的图片会从视频开始一直显示到结束。您可以利用 start_time 和 end_time 参数，让图片仅在视频的特定时间段内出现。例如，下面的配置将让 Logo 只在视频的第 5 秒到第 15 秒之间显示。
curl -X GET 'https://mediakit.cn-beijing.volces.com/api/v1/tasks/{task_id}' \
-H 'Authorization: Bearer {Your_API_Key}'
