2.2 快速入门：视频理解前处理
AI MediaKit 的视频理解工具，基于火山方舟视觉大模型 ，专为大文件视频（URL 传入方式的视频上限从 50 MB 放宽至 5 GB）的内容解析而设计。通过 Chat API，您可以像对话一样对视频进行总结、问答、抽帧分析或视觉定位，从而在海量视频数据中快速提取核心价值信息。
本篇快速入门将引导您在几分钟内通过 API 调用视频理解工具。
效果示例
准备工作
由于视频理解工具集成了火山方舟的模型推理与 AI MediaKit 的媒体处理能力，在发起请求前，您需要获取以下两类凭证：
1. 获取模型相关信息（火山方舟侧）
获取火山方舟 API Key：访问火山方舟控制台 API Key 管理页面 ，创建并获取火山方舟 API Key（用于模型推理鉴权）。
开通模型服务并获取模型 ID：访问火山方舟控制台开通管理页面 ，开通视觉理解相关模型服务，并获取对应的火山方舟模型 ID（Model ID）。
说明
模型列表 ：快速浏览方舟提供的模型全集以及各个模型所具备的能力，快速根据你的实际场景匹配到合适的模型。
输入 输出
Prompt：总结描述视频的主要内容？
这是一段AI生成的视频，呈现了黄昏时分伦敦的
标志性场景：画面中心是大本钟（伊丽莎白
塔），时钟指针快速转动，一旁的桥上车流穿梭
不息，其中包含伦敦标志性红色双层巴士，背景
是笼罩在暖调暮色里的城市天际线，整体展现出
这座城市繁忙的日常与时间的流转感。
2. 获取媒体处理凭证（AI MediaKit 侧）
访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKit API Key（用于视频拉取与预处理鉴权）。
