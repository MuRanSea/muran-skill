3.3.2.15 视频添加滤镜
AI MediaKit 视频加滤镜工具支持为视频一键添加多种专业级、电影感的预设滤镜，能够显著提升视频的视觉氛围与艺术质感。输出的视频为 MP4 格式。
本指南将带您了解如何通过 API 调用，轻松为您的视频添加滤镜效果。
效果预览
通过视频加滤镜工具，您可以将普通视频快速转换为具有特定氛围感的作品。
快速体验：为风景视频添加“晚霞”滤镜
本节将通过一个具体的示例，演示如何调用 API 为一段风景视频添加“晚霞” ( sunset ) 滤镜。准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取您的 AIMediaKit API Key。
准备视频文件：准备一个需要添加滤镜的视频文件，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程
视频加滤镜是一个异步任务，调用 API 的整体流程如下：
成功调用 POST /api/v1/tools/apply-video-filter 提交任务后，您将获得一个唯一的 task_id 。您可以通过轮询 GET /api/v1/tasks/{task_id} 接口来查询任务状态，直到状态（ status ）变为 completed 。或者，您也可以配置事件回调 自动接收任务状态变化。
输入视频 输出视频（添加“鲜亮”滤镜后）
任务完成后，解析响应中的 result 字段，即可在 video_url 字段中获取添加滤镜后视频的下载地址。第 1 步：提交任务
您需要调用提交视频添加滤镜任务 API 。可直接复制以下 cURL 命令提交。
说明
请将 {Your_API_Key} 替换为您的有效 API Key。
请将 video_url 的值替换为您自己准备的视频文件 URL。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。
第 2 步：获取结果
由于视频处理需要一些时间，您需要轮询查询任务信息 API ，直到任务状态 status 变为 completed 。说明
需替换参数：将 URL 末尾的 {task_id} 替换为第 1 步返回的任务 ID。
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/apply-video-filter' \-H 'Authorization: Bearer {Your_API_Key}' \
-H 'Content-Type: application/json' \
-d '{
 "video_url": "https://example.com/your_landscape_video.mp4",
 "filter_style": "sunset"
}'
Bash
{
"success": true,
"task_id": "amk-tool-apply-video-filter-123456789",
"request_id": "20240521113000ABCDEFG12345"
}
JSON
curl -X GET 'https://mediakit.cn-beijing.volces.com/api/v1/tasks/{task_id}' \
-H 'Authorization: Bearer {Your_API_Key}'
Bash
当任务成功完成后，您将收到如下响应。 result 字段中的 video_url 即是添加滤镜后视频的下载地址。该地址的有效期为 24 小时，请务必及时下载保存。
附录：支持的滤镜风格
除了“晚霞”滤镜，您还可以通过 filter_style 参数指定以下多种预设风格。如果不指定该参数，系统将默认使用 spring （春日）滤镜。

"status":"completed",

"resolution": "1080p",
"duration": 125.8
},
