3.3.2.18 文字生成滚屏视频
AI MediaKit 的文字生成滚屏视频工具，能够将大段文本内容与背景图片、音乐相结合，快速生成一个专业、流畅的竖版（9:16）文字滚动视频。该功能是制作小说推文、内容讲解、歌词视频等场景的绝佳选择。输出的视频为 MP4 格式。本指南将带您了解如何通过 API 调用，轻松将您的文本转换为引人入胜的滚屏视频。
效果预览
通过文字生成滚屏视频工具，您可以将一段纯文本、一张背景图和一段音频，转换为一个完整的视频作品。
快速体验：生成一个基础的文字生成滚屏视频
本节将通过一个具体的示例，演示如何调用 API，将一段小说文本生成为滚屏视频。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取您的 AIMediaKit API Key。
准备素材： 
文本内容：准备好您想展示的小说文本。
背景图片：准备一张将用作视频背景的图片，并将其上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。

进阶使用：自定义视频效果
除了必需的文本和背景图，您还可以通过丰富的可选参数，对视频的视听效果进行精细化定制。自定义视觉元素（分辨率、字体、颜色）
resolution ：设置视频分辨率，默认为 720p 。示例： "resolution": "1080p"
font_type ：选择预设字体，默认为 sy_black （思源黑体）。示例： "font_type": "pm_zhengdao"font_color ：设置文字颜色，为 8 位 RGBA 十六进制格式，默认为 #1F1F1FFF （不透明深灰）。示例（白色字体）： "font_color": "#FFFFFFFF"
调整滚动节奏（速度、起止停留）
single_roll_duration ：单页文字完全滚过屏幕的时长（秒），值越小，滚动越快。默认为 3 。示例（加快滚动）： "single_roll_duration": 2.5
start_hold_duration ：视频开始时文字静止的时长（秒）。默认为 2 。示例（立即开始滚动）： "start_hold_duration": 0
end_hold_duration ：视频结束时文字静止的时长（秒）。默认为 2 。示例（延长结尾停
留）： "end_hold_duration": 5

为保证开箱即用的效果，系统内置了一系列默认配置。本附录详细说明文字生成滚屏视频生成过程中的各项默认设置。
布局与尺寸
输出尺寸：视频画面固定为 9:16 的竖版。您可以通过设置 resolution 参数来选择输出的分辨率档位。各档位对应的具体像素尺寸如下： 
360p : 360 × 640
480p : 480 × 854
720p : 720 × 1280（默认）
1080p : 1080 × 1920
字体大小：字体大小会随您选择的 resolution 档位进行线性缩放，以确保视觉效果一致。例如，在 720p 分辨率下，字号约为 36px。该缩放行为由系统自动处理，不支持直接设置字号。
边距与间距：为保证阅读舒适性，系统内置了固定的文本边距和间距。不支持自定义。 
左右边距：约为画布宽度的 16%。
行间距：20px。
字间距：3px。
时序与滚动
起止停留：视频在开始滚动前和滚动结束后，会有一段静止展示的时间。您可以通过 
start_hold_duration （默认 2 秒）和 end_hold_duration （默认 2 秒）参数分别进行设置。滚动速度：指单页文字从进入画面到完全滚出画面所需的时间。您可以通过 single_roll_duration 参数进行控制，默认值为 3 秒/页。值越小，滚动越快。

滚动位置：文字的滚动路径为从屏幕中心附近进入，滚到中间附近结束。不支持自定义。
字体与背景
字体颜色：您可以通过 font_type 参数选择预设的字体，通过 font_color 参数自定义设置字体颜色（默认为 #1F1F1FFF ）。请注意，默认颜色仅适配浅色背景，若使用深色背景，请务必传入对比度足够的浅色字体（如 #FFFFFFFF ）。
字体背景优化：为避免文字在滚动时边缘出现黑色毛刺或跳变，系统会自动为字体设置一个与字体颜色相同但完全透明的背景。此为系统内置的优化行为，无法关闭或修改。
背景图片处理（顶部/底部遮罩）：您必须传入 image_url 提供背景图片。系统会自动裁切背景图片的顶部 10% 和底部 10% 区域，并将其作为半透明遮罩叠加在视频的顶部和底部，以增强滚屏文字的可读性。因此，请确保图片在这两个区域没有关键信息。
背景音乐处理：您可以通过 audio_url 参数提供背景音乐的 URL。音乐将循环播放，直到视频结束。如果音乐时长超过视频时长，超出部分将被自动截断。
