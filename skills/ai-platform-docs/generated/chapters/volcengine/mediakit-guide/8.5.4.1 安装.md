8.5.4 PHP SDK
8.5.4.1 安装
环境要求
可通过 php -v 命令查看当前的 PHP 版本。
若未安装，请到 PHP 官网 下载合适的版本完成安装，请使用 PHP 7.1.0 及以上版本。
安装 SDK
安装 Composer
您可以使用 Composer 安装和管理 PHP SDK。 Composer 是一款 PHP 工具，用于管理和安装项目的依赖项。Composer 的安装、使用方法，详见 getcomposer.org 。
获取 SDK
通过 Composer 直接获取最新版本的 SDK。
更新 SDK
若某些接口或功能在使用的 SDK 版本中不存在，可更新到最新版本 SDK。
composer require volcengine/volc-sdk-php
php
composer update
