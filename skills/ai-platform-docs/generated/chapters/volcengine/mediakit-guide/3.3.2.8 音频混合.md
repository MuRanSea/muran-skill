3.3.2.8 音频混合
AI MediaKit 的音频混合工具可以帮助您轻松地将多个音频文件（如背景音乐、音效、人声）进行混音，并生成一个新的音频文件。无论是为播客制作带 BGM 和音效的片头，还是将多段录音合并为一段完整的音频，都可以通过简单的 API 调用实现。
本篇开发指南将引导您：
理解音频混合的核心能力与应用场景。
快速体验将一段旁白和一首背景音乐混合。
了解音频混合任务的输入限制与输出规格。
快速体验：将旁白与背景音乐混合
本场景演示如何将两段独立的音频（一段旁白和一段背景音乐）混合成一个音频文件。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备媒体文件：准备多个待处理的音频文件，将它们上传至公网可访问的服务器或视频点播服务中，以获取可供 API 调用的 URL。
操作流程
音频混合是一个异步任务：
成功调用 POST /api/v1/tools/mix-audio 后，API 将返回一个任务 ID。
您可以轮询 GET /api/v1/tasks/{task_id} ，直到任务状态 status 变为 completed ；或者使用事件回调自动接收任务状态变化。
任务完成后，解析 result 字段，即可在 audio_url 字段处获取最终合成音频的下载地址。第 1 步：提交任务
您需要调用提交音频混合任务 API 。您可以直接复制以下 cURL 命令，提交一个音频混合任务。curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools/mix-audio' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {Your_API_Key}' \
--data '{
 "audio_urls": [
 "https://example.com/narration.mp3",
 "https://example.com/background_music.mp3"
 ]
}'
Bash
说明
需替换参数：
将 {Your_API_Key} 替换为您的有效 API Key。
将 audio_urls 列表中的 URL 替换为您真实的音频文件地址。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。
第 2 步：获取结果
由于音频处理需要一定时间，您需要轮询查询任务信息 API ，直到任务状态 status 变为 completed 。说明
需替换参数：将 URL 末尾的 {task_id} 替换为第 1 步返回的任务 ID。
当任务成功完成后，您将收到如下响应。 result 字段是一个 JSON 对象，您可以直接从其下的 audio_url字段获取混合后音频的下载地址（默认输出为 MP3 格式，有效期为 24 小时）。
{
"success": true,
"task_id": "amk-tool-mix-audio-1501200",
"request_id": "20260326160000B9CF8E68B9A4F28F1EC2"
}
JSON
curl -X GET 'https://mediakit.cn-beijing.volces.com/api/v1/tasks/{task_id}' \
--header 'Authorization: Bearer {Your_API_Key}'
Bash
说明
输出音频的总时长由所有输入音频中最长的一个决定。如果您混合一个 30 秒的旁白和一个 60 秒的背景音乐，最终生成的音频文件时长将为 60 秒。在前 30 秒，旁白和背景音乐会同时播放；在后 30 秒，只有背景音乐。

处理耗时
处理耗时与最长输入音频的时长正相关。平均 RTF（处理耗时/原片时长）约为 1。

限制项 说明
输入文件限制
文件来源：支持公网 HTTP/HTTPS URL、本地
上传 ( mediakit:// )、来源于火山引擎视频点
播 ( vod:// ) 和火山引擎对象存储 ( tos:// ) 四
种输入协议。关于各协议的具体说明和使用
示例，请参阅多源媒体输入与本地上传。
支持格式： mp3 , wav , flac 等主流音频
格式。
文件数量：单次任务最少输入 1 个，最多
100 个音频文件。
文件大小：建议单个输入文件大小不超过 10
GB。
