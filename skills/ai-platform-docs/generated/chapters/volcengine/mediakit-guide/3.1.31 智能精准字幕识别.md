3.1.31 智能精准字幕识别
AI MediaKit 的智能精准字幕识别工具可以对视频或音频进行字幕识别。处理视频输入时，该工具会融合ASR 与 OCR，减少复杂画面造成的误识别和漏识别，并结合上下文修正专有名词与错别字。任务完成后，您可以直接获取 JSON 格式的结构化字幕，也可以导出 SRT 或 WebVTT 字幕文件。
本篇开发指南将引导您：
了解如何通过纯 ASR 或语音与画面字幕融合快速生成音视频字幕。
掌握提交识别任务、查询状态及解析结果的完整流程。
探索语种指定、说话人识别及多格式导出等高级配置。
快速体验：生成视频字幕
准备工作
开通模型：在豆包语音控制台 开通录音文件识别 2.0。
进行跨服务授权：前往 AI MediaKit 控制台的授权管理页面 ，为 AI MediaKit 授予访问您豆包语音资源的权限。如果未开通模型或未完成授权，任务不会进入处理队列，而会直接创建失败并返回错误信息。
获取访问凭证：访问 AI MediaKit 控制台的 API Key 管理页面 ，创建并获取 MediaKit API Key。准备媒体文件：准备一个待识别的视频或音频文件，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程
智能精准字幕识别是一个异步任务，完整流程如下：
成功调用提交智能精准字幕识别任务 API 后，您将获得一个任务 ID（ task_id ）。
您可以轮询查询任务信息 API ，直到任务状态 status 变为 completed 或 failed 。也可以使用事件回调 自动接收任务状态变化。
任务完成后，解析响应中的 result 字段。未指定 output_format 时，从 segments 中获取结构化字幕。指定 output_format 且识别结果不为空时，从 subtitle_url 获取字幕文件下载地址。第 1 步：提交字幕识别任务
调用提交智能精准字幕识别任务 API 。您可以直接复制以下 cURL 命令，为一个视频提交基本的字幕识别任务。本示例使用默认的 asr_only 模式，并直接返回结构化字幕数据。
说明

将 video_url 的值替换为您自己的视频地址。处理纯音频文件时，请改用 audio_url 。
video_url 与 audio_url 必须二选一。
请求成功后，您会收到如下包含 task_id 的响应，请保存此 ID 用于后续查询。

字幕识别任务需要一定的处理时间。您需要轮询查询任务信息 API ，直到任务状态 status 变为 completed 或 failed 。若任务失败，请查看返回的错误信息并排查原因。

选择字幕识别模式
您可以通过 transcription_mode 选择字幕识别模式：
asr_only ：纯 ASR 模式，也是默认模式。仅返回语音识别结果，不运行画面字幕 OCR 或字幕融合。full ：完整模式。融合语音与画面字幕 OCR，并结合上下文修正专有名词和错别字。
画面字幕 OCR 仅在同时满足以下条件时执行：
输入为视频。
language 显式指定为 zh-CN 或 en-US 。
视频时长不超过 10 分钟。
transcription_mode 设置为 full 。
如果输入为音频、自动识别语种、指定其他语种，或视频时长超过 10 分钟，系统会跳过画面字幕 OCR，仅返回语音识别字幕。以下示例对一个不超过 10 分钟的中文视频启用完整模式：

如果您需要直接获得可供播放器加载的字幕文件，可通过 output_format 指定导出格式：

指定 output_format 后，任务完成时的 result 返回实际格式 output_format 和媒体时长 duration ，不返回 segments 。仅当识别结果不为空时， result 中才会返回字幕文件下载地址 subtitle_url 。该地址的有效期为 24 小时，请务必及时保存产物。
