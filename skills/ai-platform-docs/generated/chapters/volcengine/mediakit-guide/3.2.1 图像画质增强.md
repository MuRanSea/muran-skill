快速体验：一键提升图片清晰度
图像画质增强是一个同步任务，您发起的请求会直接在响应中返回处理结果。
准备工作
获取访问凭证：在开始之前，访问 AI MediaKit 控制台 API Key 管理页面 ，创建并获取 AI MediaKitAPI Key（用于媒体处理功能鉴权）。
准备图像文件：准备一张待增强的图片，并将其上传至公网可访问的服务器或视频点播服务 中，以获取可供 API 调用的 URL。
操作流程
您只需调用提交图像画质增强任务 API ，即可在 API 的响应体中直接获取增强后的图片地址。步骤 1：提交任务并获取结果
可直接复制以下 cURL 命令，替换其中的参数后执行。

target_height 指定输出尺寸

宽高比，遵循以下原则：
只指定一边（宽或高）：系
统会在保持原图宽高比的前
提下，将指定的一边缩放至
目标值，另一边等比缩放。
同时指定宽和高：如果目标
宽高比与原图不一致，系统
会以能完整容纳于目标尺寸
框内的最大尺寸为准进行缩
放，并保持原图的宽高比。
例如，一张 100x100（1:1）
的图片，如果目标尺寸设置
为 400x300（4:3），系统
为了保持原图的 1:1 比例，
最终会输出 300x300 的图
片。
