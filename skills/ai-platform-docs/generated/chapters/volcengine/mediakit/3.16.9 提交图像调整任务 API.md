3.16.9 提交图像调整任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/adjust-image-color本 API 用于提交一个同步的图像调整任务，对输入图像的亮度、对比度和饱和度进行调整。该工具支持调亮/调暗、增强/减弱对比度、增强/减弱饱和度共 6 种快速调整效果，适用于素材基础优化、统一内容视觉风格、营造特殊氛围（如庄重、复古）等场景。
