7.4 错误码
当您调用 AI MediaKit 的 API 接口时，如果请求处理失败，系统将返回一个包含错误信息的 JSON 响应。一个典型的错误响应结构如下：
code : 错误类型代码，供程序识别。
message : 对错误的详细描述，供开发者阅读。
request_id : 本次请求的唯一标识。当您需要技术支持时，请务必提供此 ID。
错误码列表
{
"code": "InvalidParameter",
"message": "tool(unknown-tool) not found",
"request_id": "1742012dcc1938455d84dbe56beb7acc"
}
