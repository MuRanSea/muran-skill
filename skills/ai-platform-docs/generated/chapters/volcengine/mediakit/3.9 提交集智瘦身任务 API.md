3.9 提交集智瘦身任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/slim-image
本 API 用于提交一个同步的集智瘦身任务，通过 AI 技术在大幅缩小图片体积的同时，修复毛刺、彩噪、块效应等问题，增强图像边缘与纹理细节，输出更轻量且更清晰的图像。
获取任务结果：这是一个同步接口，处理结果将直接在本接口的响应体中返回。
