3.16.12 提交图像负片任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/invert-image
本 API 用于提交一个同步的图像负片任务，对输入图像执行负片（反相）效果，将图像的明暗关系与颜色映射为原图的相反效果，即明暗反转、色彩转为补色。适用于创意视觉生成、内容二次创作、自动化图像处理、教学演示及艺术风格化等多种场景。
