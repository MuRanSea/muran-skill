2.34 提交视频横转竖任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/reframe-video-to-vertical本 API 用于提交一个异步的视频横转竖任务，通过 AI 完成逐帧主体检测、发言主体识别、主体跟踪与智能裁剪，并对多人场景自动进行布局决策，无需人工编辑，即可将您输入的一段横版视频智能转换为竖版（默认 9:16）成片。输出可直接分发到竖屏平台。
