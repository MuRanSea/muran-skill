3.16.11 提交图像压缩任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/compress-image
本 API 用于提交一个同步的图像压缩任务。该工具提供一站式的图像体积优化方案，支持指定压缩质量、文件体积上限、输出格式转换（如 WebP, AVIF, HEIC）以及针对 PNG 格式的瘦身处理，适用于用户上传图片前的体积治理、AIGC 与多模态模型的媒体预处理、网站与 App 的图片分发加载优化等场景。说明
如需了解该功能的详细说明及应用，请参阅图像压缩 。
