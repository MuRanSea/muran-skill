3.14 提交图像暗水印添加任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/add-image-invisible-watermark本 API 用于提交一个同步的图像暗水印添加任务，在不明显破坏图片完整性与画质的前提下，将一段自定义文本信息隐藏式地嵌入图片中，可用于版权保护、AIGC 生图合规、传播追踪与搬运取证等场景。您需要显式指定暗水印模型版本（ tool_version ），后续提取时使用同一版本。

响应参数
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/add-image-invisiblewatermark' \-H 'Authorization: Bearer {Your_API_Key}' \
-H 'Content-Type: application/json' \
-d '{
 "image_url": "https://example.com/source_image.jpg",
 "tool_version": "adapt",
 "watermark_content": "my-copyright-info"
}'
