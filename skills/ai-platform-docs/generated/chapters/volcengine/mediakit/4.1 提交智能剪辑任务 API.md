4. 剪辑工具 API
4.1 提交智能剪辑任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/vibe-editing
本 API 用于提交一个异步的智能剪辑（vibe editing）任务。您可以通过传入图片、视频、音频、字幕素材 URL 与自然语言指令，让系统自动完成意图理解、参数转换、多轨剪辑、云端渲染与成片导出。获取任务结果：任务提交成功后，您需要保存返回的 task_id ，并通过轮询查询任务信息 API 或配置事件回调获取最终结果。
开发指南：如需了解完整的使用流程和应用示例，请参阅模式 1：直接生成 。
前置条件： 
跨服务授权： 智能剪辑工具会在剪辑过程中根据自然语言意图调用其他 AI MediaKit 工具以及剪辑合成工具完成最终成片。因此在首次调用本 API 前，您必须先在 AI MediaKit 控制台基础配置 > 授权管理 页面，为 AI MediaKit 授予访问您 IMP 智能处理资源的权限。否则，任务将因无权限访问而失败。同一账号下只需授权一次，后续调用无需重复操作。
（可选）当您的剪辑指令包含需要理解视频内容的意图时（例如，识别特定物体、场景或行为并进行剪辑），智能剪辑工具可以依赖火山方舟视觉大模型进行内容分析。为确保任务正常执行，请在使用前完成以下准备工作： 
开通火山方舟大模型服务：请前往火山方舟控制台 ，确保您计划使用的模型服务已开通并可正常调用。
进行跨服务授权：首次使用涉及视频理解的智能剪辑功能前，您需要为 AI MediaKit 授予访问您火山方舟资源的权限。请前往 AI MediaKit 控制台基础配置 > 授权管理 页面，为 AI MediaKit 授予访问您 AMK 火山方舟资源的权限。
