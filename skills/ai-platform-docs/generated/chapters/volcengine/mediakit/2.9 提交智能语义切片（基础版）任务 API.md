2.9 提交智能语义切片（基础版）任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/semantic-segment
本 API 用于提交一个异步的智能语义切片任务，综合分析视频的画面、语音和叙事结构，在保证语义完整（如避免将单句从中间切断）的前提下，通过镜头切换、语音停顿检测等策略，将长视频智能地切分为多个独立的素材片段。

异步任务结果
智能语音切片是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二（事件回调）： 在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
当任务成功完成后，您获取到的任务信息中的 result 字段将包含以下内容。
最终的完整任务信息示例：
"error": {
"code": "InvalidParameter",
"message": "`min_duration` must be less than or equal to `max_duration`.",
"param": "min_duration",
"type": "BadRequest"
}
}
