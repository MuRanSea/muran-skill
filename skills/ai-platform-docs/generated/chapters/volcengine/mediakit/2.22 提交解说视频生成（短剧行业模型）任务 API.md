2.22 提交解说视频生成（短剧行业模型）任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/drama-recap-vertical
本 API 用于提交一个异步的解说视频生成（短剧行业模型）任务，基于对输入短剧剧集的角色和剧情故事线理解（剧本还原），自动提取高光片段，并按您的要求生成全新的解说视频。支持以下两种核心模式：
文字解说视频：原片高光混剪 + 屏幕文字解说。
旁白解说视频：原片高光混剪 + AI 语音解说 + BGM。
此外，您还可以通过参数配置成片剪辑效果，例如套用短剧三要素（剧名、角标、提示语）的视觉模板。

异步任务结果
解说视频生成是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二（事件回调）： 在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
