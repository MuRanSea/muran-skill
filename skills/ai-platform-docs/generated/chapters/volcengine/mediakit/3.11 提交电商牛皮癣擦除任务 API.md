3.11 提交电商牛皮癣擦除任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/remove-image-elements本 API 用于提交一个同步的电商牛皮癣擦除任务，可自动检测并擦除商品图中的水印、Logo、促销贴纸、价格标签和多余文字，输出更干净、更适合二次流转和再创作的商品图，整个过程无需人工框选即可完成，适用于电商搬家、商品图净化、素材二次创作等场景。默认输出 PNG 格式图像。
获取任务结果：这是一个同步接口，处理结果将直接在本接口的响应体中返回。

响应说明
成功响应
请求处理成功后，接口会直接返回包含处理结果的 JSON 对象，其主要字段结构如下。
result 结构
响应示例：
参数 类型 描述
success Boolean
任务是否成功。
true ：成功。
false ：失败。更多信息请
查看错误响应。
task_id String 任务的唯一标识。
task_type String 任务类型。对于本 API，取值
为 remove-image-elements 。
request_id String 本次 API 请求的唯一标识，可
用于问题排查。
expires_at Integer
任务结果的过期时间戳（Unix
Time，单位：秒）。仅当任务
成功且有结果时返回。
result Object 包含图像处理结果的对象。详
见下文 result 结构。
参数 类型 描述
image_url String
清理后的图片文件下载地址。
该地址的有效期为 24 小时，
请务必及时保存产物。
image_size Integer 生成图像的大小，单位为字
节。
image_format String 生成图像的格式，例如 
png 。
image_width Integer 生成图像的宽度，单位为 px。
image_height Integer 生成图像的高度，单位为 px。
