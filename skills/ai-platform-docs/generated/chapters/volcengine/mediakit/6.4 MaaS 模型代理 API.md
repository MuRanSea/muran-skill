6.4 MaaS 模型代理 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/call-maas-proxy
本 API 用于提交一个异步的 MaaS 模型能力代理调用任务。通过本 API，您可以用一套统一的方式，调用已在火山方舟、豆包语音等模型产品中开通的能力（当前支持视频生成、图片生成、音频生成、语音识别），并由 AI MediaKit 统一处理任务的异步执行、结果回调、幂等控制与队列调度。
说明
本 API 调用的是火山方舟、豆包语音等模型产品的能力，并非 AI MediaKit 自有算法。使用前，您需先在对应模型产品中开通所需能力，并在 AI MediaKit 控制台完成对该模型产品的跨服务授权。各能力的完整功能说明与使用示例，请参阅对应指南：
通过 AI MediaKit 调用视频生成大模型
通过 AI MediaKit 调用图片生成大模型
通过 AI MediaKit 调用音频生成大模型
通过 AI MediaKit 调用语音识别大模型

异步任务结果
参数说明
模型能力调用是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二（事件回调）： 在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
当任务成功完成后，您获取到的任务信息中的 result 字段将包含以下内容。
"error": {
"code": "InvalidParameter",
"message": "The 'api' parameter is required",
"param": "api",
"type": "BadRequest"
}
}
