7.2 获取媒体上传地址 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/request-media-upload-url本 API 用于申请一个媒体文件上传地址，返回可直接发起 PUT 请求的上传 URL、方法和所需请求头。适用于客户端先申请上传地址、再自行上传图片/音频/视频文件的场景。这是通过本地上传方式媒体文件的第一步。完整流程如下：
调用本 API，获取预签名上传地址 upload_url 、上传方法 method 、上传请求头 upload_headers 和文件唯一标识 file_id 。
使用 HTTP PUT 方法，并附带 upload_headers 中的所有请求头，将文件的二进制内容上传到获取的 upload_url 。
上传成功后，在其他处理任务（如视频拼接、裁剪等）中，通过 mediakit://{file_id} 的格式来引用该文件。
关于本地文件上传的完整流程，请参阅多源媒体输入与本地上传 。

获取到 upload_url 和 upload_headers 后，您需要通过 PUT 方法，将文件的二进制内容作为请求体（body）上传到该地址，并携带所有指定的请求头。
上传格式：必须使用纯二进制流（Raw Binary）上传，严禁使用 multipart/form-data （表单）格式。Content-Type ：请求头中的 Content-Type 需与您上传文件的实际类型匹配（例如：视频为 video/mp4 ，图片为 image/png ）。
注意
upload_url 具有时效性（有效期为 24 小时），获取后请尽快使用。
PUT 请求必须包含 upload_headers 响应中返回的所有 HTTP 头部。请以编程方式构造请求，而不是手动复制示例。
响应说明
成功响应
请求成功后，接口会返回一个包含任务信息和上传凭证的 JSON 对象。
# 假设步骤 1 返回的 upload_url 为 "https://bucket.s3.com/..."
# 假设步骤 1 返回的 upload_headers 为 [{"key": "Content-Type", "value": "video/mp4"}]
# 将 /path/to/your/local/my-video.mp4 替换为您的本地文件路径
curl -X PUT 'https://bucket.s3.com/...' \
-H 'Content-Type: video/mp4' \
--data-binary '@/path/to/your/local/my-video.mp4'
Bash
