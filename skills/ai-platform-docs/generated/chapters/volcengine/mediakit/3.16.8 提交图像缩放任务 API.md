3.16.8 提交图像缩放任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/resize-image
本 API 用于提交一个同步的图像缩放任务，对输入图像进行缩放处理。支持按指定宽高精确缩放，也支持按长边或短边缩放及等比缩放模式。该功能适用于多端素材适配、封面与缩略图生成、批量图片预处理等多种场景。
说明
如需了解该功能的详细说明及应用，请参阅图像缩放 。
