2.29 提交视频画质检测 VQScore 任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/assess-video-quality
本 API 用于提交一个异步的视频画质检测任务。VQScore（Video Quality Score）是火山引擎自研的无参考视频质量评价算法，可对视频和图像的视觉质量进行客观打分。区别于 PSNR、SSIM、VMAF 等需要原始参考源的传统算法，VQScore 无需参考视频即可独立完成评估，直接模拟人眼主观感受输出贴近真实观感的质量分数。
获取任务结果：任务提交成功后，您需要保存返回的 task_id ，并通过轮询查询任务信息 API 或配置事件回调获取最终结果。
开发指南：如需了解完整的使用流程和应用示例，请参阅视频画质检测 VQScore 。
