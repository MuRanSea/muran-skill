2.29 提交视频画质检测 VQScore 任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/assess-video-quality
本 API 用于提交一个异步的视频画质检测任务。VQScore（Video Quality Score）是火山引擎自研的无参考视频质量评价算法，可对视频和图像的视觉质量进行客观打分。区别于 PSNR、SSIM、VMAF 等需要原始参考源的传统算法，VQScore 无需参考视频即可独立完成评估，直接模拟人眼主观感受输出贴近真实观感的质量分数。

异步任务结果
视频画质检测 VQScore 是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二（事件回调）： 在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
当任务成功完成后，您获取到的任务信息中的 result 字段将包含以下内容。
