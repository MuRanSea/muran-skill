2.28 提交视频转封装任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/remux-video
本 API 用于提交一个异步的视频转封装任务。视频转封装仅修改容器格式，不会重新编解码音视频码流，因此可以在无画质损失、成本极低的前提下，实现 MP4、FLV、MPEG-TS 等主流容器格式之间的快速转换。该功能广泛适用于点播分发适配、流媒体切片打包与多端兼容等场景。

异步任务结果
视频转封装是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）：使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二（事件回调）：在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
当任务成功完成后，您获取到的任务信息中的 result 字段将包含以下内容。
