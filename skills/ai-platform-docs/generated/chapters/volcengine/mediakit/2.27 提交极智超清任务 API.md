2.27 提交极智超清任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/martencode-video
本 API 用于提交一个异步的极智超清转码任务。极智超清基于人眼视觉系统特性，在转码过程中对视频的场景、动作、内容、纹理等进行智能分析，并选择最优的编码参数，以相对较低的码率输出主观画质更优的视频。这能在降低带宽成本的同时，为您的用户带来更好的视觉体验。

极智超清是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二（事件回调）： 在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
