2.35 提交视频流畅度提升任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/enhance-video-smoothness本 API 用于提交一个异步的视频流畅度提升任务。工具基于视频画面与运动信息，自动识别运动节奏突变、重复帧等卡顿问题，并通过光流、运动矢量等算法生成中间帧、删除重复帧，在异常片段进行智能修复，还原连续、自然的运动画面。
说明
默认情况下，工具将同时开启周期性卡顿检测和重复帧检测，并对检测到的问题自动修复，直接返回修复后的视频。当您希望关闭修复（即只检测不修复）或进行人工指定插帧等进阶操作时，需要显式传入 periodic_stutter_detect 和 duplicate_frame_detect 这两个配置对象。如需了解完整的使用流程和应用示例，请参阅视频流畅度提升 。
