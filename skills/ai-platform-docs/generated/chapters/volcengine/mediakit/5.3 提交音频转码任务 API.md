5.3 提交音频转码任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/transcode-audio
本 API 用于提交一个异步的音频转码任务。音频转码是将一个音频码流转换成另一个音频码流的过程，通常涉及编码格式（如 AAC）、编码参数（如采样率、码率）、封装格式（如 MP3）等的转换，以适应不同的业务场景、播放终端和网络环境。
说明
如需了解完整的使用流程和应用示例，请参阅音频转码 。

异步任务结果
音频转码是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二（事件回调）： 在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
当任务成功完成后，您获取到的任务信息中的 result 字段将包含以下内容。
以下是一个任务执行完成后的完整任务信息示例：
