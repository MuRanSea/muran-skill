2.36 提交深度动作捕捉任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/video-depth
本 API 用于提交异步深度动作捕捉任务，逐帧估计视频画面的空间层次，弱化人物外观、服装、背景和画风信息，保留动作轮廓、空间位移和镜头运动，生成具有时间连续性的相对深度视频，适用于 AI 视频动作参考、角色替换与动作复刻、运镜控制、三维内容与视觉特效预处理。

如需了解完整的使用流程和应用示例，请参阅深度动作捕捉 。

异步任务结果
深度动作捕捉是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二（事件回调）： 在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
