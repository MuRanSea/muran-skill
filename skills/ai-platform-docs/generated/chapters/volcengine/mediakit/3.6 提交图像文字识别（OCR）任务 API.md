3.6 提交图像文字识别（OCR）任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/image-ocr
本 API 用于提交一个同步的图像文字识别（OCR）任务。支持标准版（简体中文和英文印刷体通用识别）与加强版（支持印刷体、手写体及 100+ 语种，并支持通用文字识别与关键词匹配识别两种任务类型），并返回每个文本块的位置坐标及置信度。
说明
如需了解完整应用示例和使用方式，请参阅图像文字识别（OCR） 。

参数 类型 描述
success Boolean
任务是否成功。
true ：成功。请查看 
result 字段以获取任务结
果。
false ：失败。请查看 
error 字段以获取详细错误
信息。
result Object
包含图像处理结果的对象，仅
在 success 为 true 时返回。
详见下文 Result 对象。
error Object
错误详情对象，仅在 success
为 false 时返回。详见下文 
Error 对象。
task_id String 任务的唯一标识。
task_type String 任务类型。
request_id String 本次 API 请求的唯一标识，可
用于问题排查。
expires_at Integer
任务结果的过期时间戳（Unix
Time，单位：秒）。仅当任务
成功且有结果时返回。
queue_id String 任务提交的目标队列 ID。
参数 类型 描述
ocr_result Array
Ocr result 对象
Error 对象
参数 类型 描述
通用文字识别结果列表。标准
版或加强版 ** task_type=spotti
ng ** 时返回。每个 Object 代
表一个识别出的文本块。详见
下文 Ocr result 对象。
keyword_result Object
关键词匹配识别结果。仅加强
版 ** task_type=keyword ** 时
返回。对象的 key 为您传入
的关键词， value 为识别到的
匹配文本（String 类型）。
参数 类型 描述
content String 识别出的文字内容。
confidence Number
识别结果的置信度，取值范围
为 [0, 1] ，值越高表示结果越
可信。仅标准版返回。
top_left_x Number 文字框左上角的横坐标，单位
为像素（px）。
top_left_y Number 文字框左上角的纵坐标，单位
为像素（px）。
bottom_right_x Number 文字框右下角的横坐标，单位
为像素（px）。
bottom_right_y Number 文字框右下角的纵坐标，单位
为像素（px）。
参数 类型 描述

BadRequest。
message String 对错误的详细描述，可用于开
