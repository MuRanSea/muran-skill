POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/evaluate-image-quality本 API 用于提交一个同步的图像画质评估任务，对输入图片进行主客观画质和美学评分，适用于质量监控、低质图筛查、内容审核、推荐排序和训练数据清洗等场景。

参数 类型 描述
tool_version String 画质评估版本，固定为 
standard 。
vqscore Number 图片主观质量，值越高表示质
量越好。取值范围：[0, 100]。
aesthetic Number
综合大众美学的质量评分，值
越高表示更具美感。取值范
围：[0, 100]。
advcolor Number
图片整体色彩质量，值越高表
示色彩质量越高。
* [0, 50]：表示色彩质量差。
* [50, 60]：表示色彩质量中。
* [60, 100]：表示色彩质量好。
blockiness Number
图片的块效应严重程度，值越
高图片块效应越强。
* [0, 50]：表示差。
* [50, 60]：表示中。
* [60, 100]：表示好。
* -1：表示检测的图像为非常
参数 类型 描述
规图像（如游戏、特效图
等）。
blur Number
模糊评分，即图像是否清晰。
评分越高，图像越清晰和锐
利。取值范围：[0, 100]，支持
两位小数。
brightness Number 平均亮度，值越高表示越亮。
取值范围：[0, 255]。
cg Number
是否为非自然场景。数值接近
0 表示为自然场景；数值接近
100 表示为非自然场景（游
戏、录屏等）。取值范围：[0,
100]。
cmartifacts Number
压缩失真强度，分数越高表示
压缩失真越显著，画质越差。
取值范围：[0, 100]。
* [0, 30)：无或轻微压缩失真。
* [30, 60)：存在压缩失真。
* [60, 100]：存在明显噪声。
contrast Number 对比度程度，值越低表示对比
度越低。取值范围：[0, 100]。
green Number
图像绿色区域面积大小，数值
越大表示绿色区域面积越大，
即是绿幕的概率越大。取值范
围：[0, 255]。
hue Number
色调的均衡程度，值越高表示
色调越均衡。取值范围：[0,
100]。
noise Number
噪声评分，即图像中是否存在
颗粒感或随机噪声。评分越
高，图像越干净。取值范围：
[0, 100]，支持两位小数。
overexposure Number
过曝光面积大小程度，值越高
越可能存在过曝光。取值范
围：[0, 100]。
saturation Number
饱和度的均衡程度，值越高表
示饱和度越均衡。取值范围：
[0, 100]。

noise Number

颗粒感或随机噪声。评分越
高，图像越干净。取值范围为 
[0, 100] ，支持两位小数。
