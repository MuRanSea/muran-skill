3. 图像工具 API
3.1 提交图像画质增强任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/enhance-image
本 API 用于提交一个同步的图像画质增强任务，基于图像内容理解进行智能决策，全方位提升图片的分辨率、清晰度与色彩表现。
说明
如需了解该功能的详细说明、应用场景、计费说明等信息，请参阅图像画质增强 。
