3.16.7 提交图像添加图文水印任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/add-image-watermark本 API 用于提交一个同步的图文水印（明水印）添加任务。支持文字水印和图片水印两种模式，并支持配置水印位置、旋转角度、透明度、字号颜色、铺满密度等参数，适用于版权标识与素材分发防盗链场景。
说明
如需了解该功能的详细说明及应用，请参阅添加图文水印 。
