3.12 提交电商万创（商品场景图生成）任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/generate-product-scene-image本 API 用于提交一个同步的电商万创（商品场景图生成）任务，基于输入的商品图智能生成高质量的背景与营销场景。支持以下版本：
Standard 版：使用预设场景模板，快速出图。
Professional 版：使用提示词、参考图、自定义商品位置等，进行高度自定义创作。
Industry 版：专为汽车行业设计，支持棚拍风格的汽车场景图生成。
说明
如需了解完整应用示例，请参阅电商万创（商品场景图生成） 。
