3.4 提交图像擦除修复任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/erase-image
本 API 用于提交一个同步的图像擦除修复任务，通过指定不同场景，自动检测并擦除图片中的文字或常见图标，并利用智能填充技术对擦除后的区域进行修复，使其与背景自然融合。
说明
如需了解完整应用示例和使用方式，请参阅图像擦除修复 。

响应说明
这是一个同步接口，处理结果将直接在本接口的响应体中返回。

Result 对象
参数 类型 描述
