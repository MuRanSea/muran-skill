2.14 提交高光片段提取任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/analyze-video-highlights本接口用于提交一个异步的高光片段提取任务，能智能捕捉视频的“情绪波峰”与“关键动作”，输出包含精准时间戳、高光打分、OCR 文本和画面描述的详细信息，供您进行灵活的二次开发或内容分析。本接口支持短剧 Miniseries ** 和小游戏 Game ** 两种分析模型。
调用说明
获取任务结果：任务提交成功后，您需要保存返回的 task_id ，并通过轮询查询任务信息 API 或配置事件回调获取最终结果。
开发指南：如需了解完整的使用流程和应用示例，请参阅高光片段提取 。
