5.2 提交语音端点识别任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/detect-voice-activity
本 API 用于提交一个异步的语音端点识别任务，自动定位音频或视频文件中有效语音的起止时间，将人声和静音、背景噪声等无效片段区分开来，返回一个包含所有有效人声片段起止时间戳的列表，为后续识别、分析、剪辑和训练提供更干净的音频输入。

异步任务结果
语音端点识别是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
参数 类型 描述
错误的宏观类型。例如 
BadRequest 。
message String 对错误的详细描述，可用于开
发调试。
param String （可选）指出导致错误的具体
参数。
{

"task_id": "amk-tool-detect-voice-activity-123456789",
