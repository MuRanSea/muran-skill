7.3 取消异步任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tasks/terminate
本接口用于主动取消指定的异步任务。在提交异步任务后，若不再需要任务结果或为了节省计算资源，您可以使用此接口批量终止正在排队（Pending）或准备阶段（Preparing）的任务。
使用限制
仅支持取消处于排队中（Pending）或准备阶段（Preparing）的任务。已完成（Completed）或已失败（Failed）的任务无法通过此接口更改执行结果。
支持取消 AI MediaKit 下视频工具、剪辑工具、音频工具等绝大多数异步任务，不支持智能剪辑(VCreative)、剧本还原、解说视频生成、Chat API 等任务。
取消操作遵循“尽力而为”原则。若底层计算任务已开始执行且无法物理中断，AI MediaKit 会在服务层将其标记为取消，但可能无法完全避免瞬时的资源消耗。
单个账号默认每秒最多支持发起 10 个任务的取消请求。
单个账号每日默认拥有 1000 个任务取消额度。
