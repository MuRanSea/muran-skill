3.16.10 提交图像裁剪任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/crop-image
本 API 用于提交一个同步的图像裁剪任务，可对输入图像进行多模式裁剪，包括方向裁剪、定向裁剪、自定义裁剪与内切圆裁剪，适用于多端尺寸适配、主体保留、商品图去边以及指定区域截取等多种场景。说明
如需了解该功能的详细说明及应用，请参阅图像裁剪 。
