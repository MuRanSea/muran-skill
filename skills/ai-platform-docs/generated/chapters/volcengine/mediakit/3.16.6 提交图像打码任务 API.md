3.16.6 提交图像打码任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/mosaic-image
本 API 用于提交一个同步的图像打码任务。您可以对整张图像或指定矩形区域进行马赛克（打码）处理，并自定义像素格的形状与大小。该工具适用于遮挡人脸、证件信息、车牌、聊天记录等敏感内容。说明
如需了解该功能的详细说明及应用，请参阅图像打码 。

响应说明
这是一个同步接口，处理结果将直接在本接口的响应体中返回。
响应参数
curl -X POST 'https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/mosaic-image' \-H 'Authorization: Bearer {Your_API_Key}' \
-H 'Content-Type: application/json' \
-d '{
 "image_url": "https://example.com/privacy_image.jpg",
 "mosaic_type": "specify-region",
 "mosaic_regions": [
 {
 "top_left_x": 100,
 "top_left_y": 150,
 "bottom_right_x": 300,
 "bottom_right_y": 250
 }
 ],
 "mosaic_shape": "rectangle",
 "mosaic_step_x": 16,
 "mosaic_step_y": 16,
 "output_format": "jpeg"
}'

参数 类型 描述

任务是否成功。

result 字段以获取任务结
果。
false ：失败。请查看 
error 字段以获取详细错误
信息。
result Object
包含图像处理结果的对象，仅
在 success 为 true 时返回。
详见下文 Result 对象。
error Object
Result 对象
Error 对象
参数 类型 描述
错误详情对象，仅在 success
为 false 时返回。详见下文

task_id String 任务的唯一标识。
task_type String 任务类型。
request_id String 本次 API 请求的唯一标识，可
用于问题排查。
expires_at Integer
任务结果的过期时间戳（Unix

成功且有结果时返回。
queue_id String 任务提交的目标队列 ID。
