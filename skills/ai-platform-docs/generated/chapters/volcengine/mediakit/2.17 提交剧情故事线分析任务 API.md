2.17 提交剧情故事线分析任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/analyze-video-storyline本 API 用于提交一个异步的剧情故事线分析任务，基于大模型视频理解能力，对输入的单个或多个长视频（如电影、电视剧）进行分析，智能解析影视剧内容，生成结构化的剧情数据。分析结果包含两部分：剧情片段 (Clips) ：算法基于剧情故事线理解分析输出的、按时间顺序排列的基础视频片段。高光故事线 (Highlights) ：算法基于视频片段整理、归纳出的核心故事线。
调用说明
获取任务结果：任务提交成功后，您需要保存返回的 task_id ，并通过轮询查询任务信息 API 或配置事件回调获取最终结果。
开发指南：如需了解完整的使用流程和应用示例，请参阅剧情故事线分析 。

的基础视频片段。每个片段都
包含标题、简介、在源视频中
的起止时间以及精彩度评分。
详见下文storyline_clip 结构。
