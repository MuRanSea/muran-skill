2.12 提交高光智剪（小游戏）任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/generate-highlights-minigame本 API 用于提交一个异步的小游戏高光智剪任务。它能识别小游戏录屏视频中的核心玩法与高光事件（如连击、通关、极限操作等），快速生成用于买量推广的视频素材。您可以通过提供游戏名称、玩法描述、高光定义等信息，来辅助模型更精准地识别精彩内容。

异步任务结果
高光智剪是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二（事件回调）： 在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
