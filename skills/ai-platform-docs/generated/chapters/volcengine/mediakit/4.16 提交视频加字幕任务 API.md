4.16 提交视频加字幕任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/add-subtitle-to-video
本接口用于提交一个异步的视频加字幕任务，将指定的字幕文件或文本内容，以自定义样式压制到视频画面中，生成带内嵌字幕的新视频。

异步任务结果
视频加字幕是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二（事件回调）： 在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
