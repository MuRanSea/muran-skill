3.16.2 提交图像旋转任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/rotate-image
本 API 用于提交一个同步的图像旋转任务，通过设置旋转角度和旋转背景样式，对图片进行旋转处理，适用于图片方向校正、创意编辑和批量图像处理等场景。
说明
如需了解该功能的详细说明及应用，请参阅图像旋转 。
