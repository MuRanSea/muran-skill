2.35 提交智能精准字幕识别任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/smart-transcribe
本 API 用于对视频或音频进行字幕识别。处理视频输入时，智能精准字幕识别工具会融合 ASR 与 OCR，减少复杂画面造成的误识别和漏识别，并结合上下文修正专有名词与错别字。任务完成后，您可以获取结构化字幕片段，或下载 SRT、WebVTT 格式的字幕文件。
说明
如需了解完整的使用流程和应用示例，请参阅智能精准字幕识别 。
前提条件
开通豆包语音模型：智能精准字幕识别工具依赖豆包语音模型。请前往豆包语音控制台 ，确保您已开通录音文件识别 2.0。
进行跨服务授权：首次使用智能精准字幕识别工具前，请前往 AI MediaKit 控制台基础配置 > 授权管理页面，为 AI MediaKit 授予访问您豆包语音资源的权限。否则，任务将因无权限访问而失败。请求参数

异步任务结果
智能精准字幕识别是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）：使用提交任务时获取的 task_id ，定期调用查询任务信息 API ，直到 status字段变为 completed 或 failed 。
方法二（事件回调）：在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调 。
当任务成功完成后， result 字段将返回识别结果。返回的具体内容取决于您在请求时是否指定了 output_format ：
未指定 output_format ：返回 segments 数组，包含带时间轴的结构化字幕数据。
指定了 output_format ：返回实际的 output_format 格式；识别结果不为空时，同时返回 subtitle_url下载链接。
