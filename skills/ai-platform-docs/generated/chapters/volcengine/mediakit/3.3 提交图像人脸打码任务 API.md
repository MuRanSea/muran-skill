3.3 提交图像人脸打码任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/face-blur-image
本 API 用于提交一个同步的图像人脸打码任务，自动检测图片中的所有人脸区域并进行马赛克处理，实现一键人脸隐私保护。适用于社交平台内容审核、街景/监控画面脱敏、新闻媒体素材处理、AI 训练数据集脱敏等需要批量保护人脸隐私的场景。
获取任务结果：这是一个同步接口，处理结果将直接在本接口的响应体中返回。
