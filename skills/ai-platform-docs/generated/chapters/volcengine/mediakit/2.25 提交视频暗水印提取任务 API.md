2.25 提交视频暗水印提取任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/extract-video-invisible-watermark本 API 用于提交一个异步的视频暗水印提取任务，从已嵌入暗水印的视频中，将隐藏的数字信息解析并还原出来。如果同一视频被多次嵌入暗水印，此接口能够提取出所有的水印信息。
说明
如需了解完整的使用流程和应用示例，请参阅视频暗水印 。
使用限制
兼容性：本 API 仅支持提取由提交视频暗水印添加任务 API 添加的暗水印，无法提取通过其他第三方工具添加的任何形式的暗水印。

异步任务结果
视频暗水印提取是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
