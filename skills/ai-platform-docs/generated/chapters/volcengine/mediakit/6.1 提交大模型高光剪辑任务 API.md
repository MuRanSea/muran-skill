6. 大模型处理工具 API
6.1 提交大模型高光剪辑任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/video-highlights-llm
本 API 用于提交一个异步的大模型高光剪辑任务，从一个或多个输入视频中，按场景预设、评分标准或故事目标智能识别精彩片段，自动挑选、裁剪并拼接成一个或多个指定时长的高光成片。
说明
如需了解完整的使用流程和应用示例，请参阅大模型高光剪辑 。
前提条件
开通火山方舟大模型服务：大模型高光剪辑工具依赖火山方舟大模型。请前往火山方舟控制台开通管理页面 ，确保您已开通以下模型： 
视觉理解模型： doubao-seed-2-0-lite-260428
文本推理模型：请至少开通以下任一模型。当您未在请求中通过 customer_ark_config 参数指定Endpoint 时，系统将按场景复杂度，自动查找并使用您账号下已开通的模型服务。 
doubao-seed-2-0-pro-260215
doubao-seed-2-1-turbo-260628
doubao-seed-2-1-pro-260628
此外，您还需开启 Cache 功能，用于启用模型的上下文缓存 API，若不开启，任务虽不会失败，但可能会影响最终的效果。
进行跨服务授权：首次使用大模型高光剪辑工具前，请前往 AI MediaKit 控制台基础配置 > 授权管理页面，为 AI MediaKit 授予访问您 ARK 火山方舟资源的权限。否则，任务将因无权限访问而失败。请求参数

大模型高光剪辑是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
