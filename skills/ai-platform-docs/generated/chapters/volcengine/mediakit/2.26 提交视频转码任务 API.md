2.26 提交视频转码任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/transcode-video
本 API 用于提交一个异步的视频转码任务。视频转码是将一个视频码流转换成另一个视频码流的过程，通常涉及编码格式（如 H.264）、编码参数（如分辨率、码率、I 帧间隔）、封装格式（如 MP4、TS）等的转换，以适应不同的业务场景、播放终端和网络环境。

如需了解完整的使用流程和应用示例，请参阅视频转码 。
