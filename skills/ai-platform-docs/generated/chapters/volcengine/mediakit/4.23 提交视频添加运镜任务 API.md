4.23 提交视频添加运镜任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/apply-camera-motion
本 API 用于提交一个异步的视频添加运镜任务，对输入视频在指定时间段内添加一种运镜特效。输出为MP4 格式，分辨率默认对齐原片。此功能常用于素材二次创作、营销片头、短剧动效等场景。说明
如需了解完整的使用流程和应用示例，请参阅视频添加运镜 。

异步任务结果
视频添加运镜是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二（事件回调）： 在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
当任务成功完成后，您获取到的任务信息中的 result 字段将包含以下内容。
