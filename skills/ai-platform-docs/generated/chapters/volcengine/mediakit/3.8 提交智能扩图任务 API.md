3.8 提交智能扩图任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/expand-image-canvas本 API 用于提交一个同步的智能扩图任务，基于 AI 能力对图片上下左右四个方向进行内容扩展，自动补充与原图纹理、内容一致的区域，实现画面自然延伸。适用于竖屏转横屏、横屏转竖屏、广告素材多平台尺寸适配等场景。
说明
如需了解该功能的详细说明及应用，请参阅智能扩图 。
