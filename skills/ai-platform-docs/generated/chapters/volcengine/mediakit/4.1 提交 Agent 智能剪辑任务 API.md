4. 剪辑工具 API
4.1 提交 Agent 智能剪辑任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/agentic-editing
本 API 用于提交一个异步的 Agent 智能剪辑任务。您可以指定主推理模型，输入文本和媒体素材，并配置返回格式。Agent 根据任务指令调用媒体理解、生成和剪辑工具，完成后返回业务数据、Token 用量及关联的工具任务。
前置条件
在使用本 API 前，请确保已完成以下准备工作：
获取 API Key：参考基础概念及准备工作获取您的 API Key。
开通火山方舟大模型：Agent 依赖大模型理解任务指令并调用工具。 
开通模型：前往火山方舟控制台 开通主推理模型。当前主推理模型需同时支持文本和图片输入，且上下文窗口为 256K。推荐使用 deepseek-v4-1-flash 或 doubao-seed-2-1-pro ，支持的模型列表见model 对象。
创建接入点：在在线推理页面 为模型创建推理接入点（Endpoint），并获取其 ID（以 ep- 开头）。
特定模型配置：若通过 tool_config.media_understanding_models 指定媒体理解模型，请确保对应接入点可用；若指定图片、视频或音频生成模型，请预先开通对应模型能力。
完成跨服务授权： 
火山方舟授权（必选）：前往 AI MediaKit 控制台的授权管理 页面，授权 AI MediaKit 访问您的ARK 火山方舟资源。
智能处理授权（必选）：在 AI MediaKit 控制台的授权管理 页面，为 AI MediaKit 授权访问您的IMP 智能处理资源。Agent 依赖该授权调用 AI MediaKit 的媒体理解、生成和剪辑工具，未授权时任务将因无权限访问而失败。
媒体访问授权（按需）：若输入素材涉及 vod:// 或 tos:// 协议，需分别授权访问视频点播（VOD）或对象存储（TOS）的权限。HTTP/HTTPS 链接需确保服务端可公网访问。
