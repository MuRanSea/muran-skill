3.10 提交图像翻译任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/translate-image-text本 API 用于提交一个同步的图像翻译任务，自动识别图像中的文字内容并将其翻译为指定目标语言，输出保留原图视觉结构的新图像，适用于跨境电商商品图、漫画页、行业文献图、路牌菜单等多语言本地化场景。
获取任务结果：这是一个同步接口，处理结果将直接在本接口的响应体中返回。
开发指南：如需了解该功能的详细说明及应用，请参阅图像翻译 。
