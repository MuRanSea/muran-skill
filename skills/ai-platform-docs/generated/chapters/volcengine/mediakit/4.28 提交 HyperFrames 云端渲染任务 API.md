4.28 提交 HyperFrames 云端渲染任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/hyperframes-to-video
本 API 用于提交一个异步的 HyperFrames 云端渲染任务，将 ZIP 资源包中的 HTML 工程在云端逐帧渲染为视频，支持输出 MP4、WebM、MOV 或 GIF。该功能常用于口播视频片头、章节标题、产品介绍动画等场景。
说明
如需了解完整的使用流程和应用示例，请参阅 HyperFrames 云端渲染 。

异步任务结果
HyperFrames 云端渲染是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二（事件回调）： 在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
当任务成功完成后，您获取到的任务信息中的 result 字段将包含以下内容：
