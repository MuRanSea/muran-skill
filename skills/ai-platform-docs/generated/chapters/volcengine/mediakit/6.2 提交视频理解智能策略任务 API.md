6.2 提交视频理解智能策略任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/video-understand-router本 API 用于提交一个异步的视频理解智能策略任务，基于视觉大模型，对输入的视频 URL 列表进行通用视频内容分析，输出视频级别的结构化理解结果，适用于内容审核、视频检索、标签生成等场景。说明
如需了解完整的使用流程和应用示例，请参阅视频理解智能策略 。
前提条件
开通火山方舟大模型服务：视频理解智能策略工具依赖火山方舟大模型。请前往火山方舟控制台在线推理页面 ，确保您已开通并可使用相关模型服务。 
通用视频分析场景：默认情况下，任务需要依赖视觉理解大模型，请确保您账号下有可用的视觉理解大模型。
创作剪辑场景（ scene 取值为 editing ）：使用此场景时，系统需要结合视觉理解与文本推理能力，请确保您已开通并可使用以下模型： 
doubao-seed-2-0-lite-260428（必需）
doubao-seed-2-1-turbo-260628、doubao-seed-2-1-pro-260628（二选一）
进行跨服务授权：首次使用视频理解智能策略工具前，请前往 AI MediaKit 控制台基础配置 > 授权管理页面，为 AI MediaKit 授予访问您 ARK 火山方舟资源的权限。否则，任务将因无权限访问而失败。请求参数

异步任务结果
视频理解是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二（事件回调）： 在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
