4.8 提交图片转视频任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/image-to-video
本接口用于提交一个异步的图片转视频任务，将多张图片按顺序组合，并可选地配置转场动画和镜头内动画，最终生成一段动态视频。

异步任务结果
图片转视频是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
