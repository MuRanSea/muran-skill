7. 其他
7.1 查询任务信息 API
GET https://mediakit.cn-beijing.volces.com/api/v1/tasks/{task_id}
本接口用于查询指定 task_id 的异步任务状态和最终结果。在提交异步任务后，您可以间隔一定时间轮询此接口来获取任务的最新动态。
查询时效性调整
为提升服务稳定性，自 2026 年 8 月 20 日起，本 API 将仅支持查询 30 天内创建的任务。届时，查询超过 30 天的任务将失败。请您务必在此日期前调整业务逻辑。详情请参见关于 AI MediaKit 查询任务信息 API 查询范围调整的公告 。
说明
在生产环境中，您也可配置事件回调。配置后，AI MediaKit 会在任务完成时主动将结果推送到您的服务器，从而避免不必要的轮询。
接口特性
统一查询：支持查询 AI MediaKit 服务下所有类型的异步任务（如视频拼接、画质增强等）。结果时效：任务成功后的结果数据（如下载链接）默认在系统内保留 24 小时，请及时下载保存资源。自动续期：当任务结果的剩余有效期不足 2 小时，调用本接口会自动延长其有效期，避免链接过早失效。

task_type String
任务类型。例如 mux-audiovideo （视频加音频）、

status String
任务当前的状态。枚举值：
running ：任务正在处理

成。
Error 对象
当 success 为 false 或 status 为 failed 时，会返回 error 对象，包含错误详情。
参数 类型 描述
failed ：任务处理失败。
result Object
任务成功时返回的结果对象。
