2.21 提交解说视频生成任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/drama-recap
本 API 用于提交一个异步的解说视频生成任务。您需要提供一个已完成的剧本还原任务 ID，并可自定义解说词或让 AI 自动生成解说词，然后一键生成带有 AI 配音和解说字幕的全新营销或解说视频。您可以对音色、字幕样式、原文字幕擦除等进行灵活配置。
