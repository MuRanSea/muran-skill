3.15 提交图像暗水印提取任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/extract-image-invisible-watermark本 API 用于提交一个同步的图像暗水印提取任务，识别图片是否嵌入暗水印并还原出当初嵌入的文本内容，适用于版权保护、AIGC 内容识别、传播泄露溯源、搬运取证等场景。
说明
如需了解完整的使用流程和应用示例，请参阅图像暗水印 。
使用限制
本 API 仅支持提取由提交图像暗水印添加任务 API 嵌入的水印，且提取时使用的 tool_version 必须与添加时一致；无法提取通过其他第三方工具添加的任何形式的暗水印。
