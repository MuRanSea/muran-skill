2.30 提交视频人脸打码任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/face-blur-video
本 API 用于提交一个异步的视频人脸打码任务，自动并精准地识别视频画面中的人脸区域，并对所有人脸进行模糊或马赛克处理。此功能适用于需要保护人物五官隐私的场景，例如短剧内容脱敏、生成式视频的参考素材处理等。

异步任务结果
视频人脸打码是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二（事件回调）： 在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
