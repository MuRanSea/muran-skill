4.24 提交视频高斯模糊任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/gaussian-blur-video
本 API 用于提交一个异步的视频高斯模糊任务。您可以对输入视频在指定时间段内的指定矩形区域叠加高斯模糊，常用于打码隐私信息、遮挡水印、角标或路人脸。输出视频为 MP4 格式，分辨率默认对齐原片。

异步任务结果
视频高斯模糊是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二（事件回调）： 在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
当任务成功完成后，您获取到的任务信息中的 result 字段将包含以下内容。
"task_id": "",
