3.5 提交图像背景移除任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/remove-image-background本 API 用于提交一个同步的图像背景移除（抠图）任务，能够自动识别并保留图像主体，同时移除背景，生成背景透明的图片。
说明
如需了解完整应用示例和使用方式，请参阅图像背景移除（智能抠图） 。
