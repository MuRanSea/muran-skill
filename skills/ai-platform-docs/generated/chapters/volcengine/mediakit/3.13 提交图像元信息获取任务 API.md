3.13 提交图像元信息获取任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/probe-image-metadata本 API 用于提交一个同步的图像元信息获取任务，支持查询图像的基础元数据（ metadata ）、主题色（ avghue ）、透明通道（ alpha ）以及 BlurHash（ blurhash ）四种信息。可广泛应用于素材管理、AIGC 元数据识别、透明通道分析、主题色提取和低成本预览图生成等场景。这是一个同步接口，处理结果将直接在本接口的响应体中返回。
注意事项
获取图像基础元数据（ info_type 为 metadata ）的特殊说明
获取色彩模型：仅支持处理 jpeg 、 webp 、 png 、 heic 和 avif 格式。各格式支持返回的色彩模型如下： 
jpeg： gray 、 ycbcr 、 rgba 、 cmyk
webp： ycbcr 、 nycbcra 、 nrgba
png： rgba 、 rgba64 、 nrgba 、 nrgba64 、 gray 、 gray16 、 palette
heic： ycbcr
avif： ycbcr
获取压缩质量参数：仅支持处理 jpeg 格式。
获取 AIGC 元数据：请确保您的图片格式和 AIGC 元数据位置符合以下要求： 
jpeg：AIGC 元数据需位于 XMP 元素/属性字段、App 11 字段或 EXIF 的 Usercomment 字段。png：AIGC 元数据需位于 XMP 元素/属性字段、tEXt chunk 信息或 EXIF 的 Usercomment 字段。webp：AIGC 元数据需位于 XMP 元素/属性字段或 EXIF 的 Usercomment 字段。
avif/heic：AIGC 元数据需位于 EXIF 的 Usercomment 字段。
注意：如果 jpeg 或 png 图片的 XMP 字段中已包含 AIGC 元数据，系统将仅从该字段获取，不再检查其他位置。
获取动图元信息的特殊说明
若输入为动图（如 GIF），不同 info_type 的处理逻辑存在差异：
info_type 为 metadata ：可获取动图的帧数（ frame_count ）和时长（ duration ）等元信息。info_type 为 alpha ：不支持对动图进行透明通道分析。
info_type 为 avghue 和 blurhash ：仅处理动图的首帧，并将其作为静态图片返回分析结果。请求参数
