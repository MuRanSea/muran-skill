3.16 图像基础编辑
3.16.1 提交圆角矩形任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/round-corner-image本 API 用于提交一个同步的圆角矩形任务，为图片四角快速添加正圆或椭圆圆角，适配头像、卡片、电商主图等常见视觉编辑场景。这是一个同步接口，处理结果将直接在本接口的响应体中返回。说明
如需了解该功能的详细说明及应用，请参阅圆角矩形 。
