2.10 提交智能语义切片（专业版）任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/semantic-segment-pro
本 API 用于提交一个异步的智能语义切片（专业版）任务，结合镜头边界、场景语义、ASR/OCR 文本和时长约束，将长视频切成语义完整、时长合适的片段，支持短剧、影视剧、小游戏和自定义策略。详细的切片、镜头、场景及分句结果直接在任务结果中返回。

异步任务结果
智能语义切片是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二（事件回调）： 在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
当任务成功完成后，您获取到的任务信息中的 result 字段将包含以下内容。其中切片列表 segments 始终返回； shots / scenes / sentences 等明细按请求参数 include_detail_types 与所选策略按需返回。
