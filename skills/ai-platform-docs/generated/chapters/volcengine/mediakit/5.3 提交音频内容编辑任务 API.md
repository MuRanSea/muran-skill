5.3 提交音频内容编辑任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/edit-speech
本 API 用于提交一个异步的音频内容编辑任务。上传一段音频或包含有效音频流的视频后，您只需通过自然语言指令（如“把‘喝酒’替换成‘喝茶’”）描述要修改的内容，工具即可自动定位目标片段，生成与原音频音色、情绪、韵律连贯的新语音并无缝替换，同时保持时序基本对齐，无需重录整段。该工具适用于短视频、播客、有声内容、课程及广告等多种场景的口误修正、文案更新与局部改词。当前仅支持中文。

异步任务结果
音频内容编辑是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二： 在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
当任务成功完成后，您获取到的任务信息中的 result 字段将包含以下内容。输出模态与输入模态一致：视频输入时仅返回 video_url ，音频输入时仅返回 audio_url 。
