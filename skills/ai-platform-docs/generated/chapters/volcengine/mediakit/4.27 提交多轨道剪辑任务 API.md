4.27 提交多轨道剪辑任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/multi-track-edit
本 API 用于提交一个异步的多轨道剪辑任务。您通过一个结构化的 track 时间线，配合 canvas （画布）、 output （输出）等配置，以声明式的方式描述从画布、轨道到每一个素材、滤镜、动画的完整剪辑意图，工具会据此合成视频、音频、图片、文字、字幕等多轨道内容，并支持转场、特效、花字、滤镜、裁剪、变速、音量调节等增强效果，最终返回产物的下载 URL。
说明
多轨道剪辑的参数以“画布 → 轨道 → 元素 → 滤镜”四层模型组织。如果您是首次使用，强烈建议先阅读多轨道剪辑 理解核心概念、使用方式和常见场景示例，再对照本 API 文档逐字段构造请求。
