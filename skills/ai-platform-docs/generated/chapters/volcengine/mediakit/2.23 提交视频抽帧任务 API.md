2.23 提交视频抽帧任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/extract-frames
本 API 用于提交一个异步的视频抽帧任务。您可以根据不同的业务场景，选择按时间间隔、按指定时间点、按指定帧（首/尾帧） 或按场景变化四种策略，从视频中截取一或多张静态图片。截取的图片可用于视频封面、预览图、雪碧图或作为其他视频理解任务的输入。
说明
如需了解完整的使用流程和应用示例，请参阅视频抽帧 。

视频抽帧是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二（事件回调）： 在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
