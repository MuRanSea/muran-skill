6.5 提交 AIGC 视频质量评估任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/evaluate-aigc-video-quality本 API 用于提交一个异步的 AIGC 视频生成质量评估任务，面向 AIGC 视频规模化生产场景，对待检视频（可选结合参考图）按需检查参考信息一致性、世界合理性、内容持续性、视觉保真度等质量问题，自动定位异常时间区间、输出问题说明与典型问题帧，帮助您快速完成采用、复核或重新生成决策。说明
公测说明：AIGC 视频生成质量评估工具当前处于公测阶段，预计 2026 年 11 月正式发布。公测期间，接口与能力可能存在微调，请以最新文档为准。
如需了解完整的使用流程和应用示例，请参阅 AIGC 视频生成质量评估 。
前提条件
开通火山方舟大模型服务：AIGC 视频生成质量评估工具依赖火山方舟（Ark）视觉大模型完成评估。请前往火山方舟控制台 ，确认本工具所需的大模型（如 Doubao 系列）已开通且可用。模型能力会影响检测效果，推荐使用 doubao-seed 系列中最新的 pro 模型，例如 doubao-seed-2-1-pro-260628 。完成跨服务授权：首次使用 AIGC 视频生成质量评估工具前，请前往 AI MediaKit 控制台的授权管理页面 ，授权 AI MediaKit 访问您的 ARK 火山方舟资源，否则任务将因权限不足而失败。

异步任务结果
AIGC 视频生成质量评估是一个异步任务，任务的执行状态和最终结果不会在提交时同步返回。您可以通过以下两种方式获取任务结果：
方法一（轮询查询）： 使用提交任务时获取的 task_id ，定期调用查询任务信息 API，直到 status 字段变为 completed 或 failed 。
方法二（事件回调）： 在 AI MediaKit 控制台预先配置一个接收回调的 URL，或在提交任务时通过 callback_url 参数为单次任务指定回调地址。任务完成后，系统会将包含最终结果的详细信息 POST 到您指定的地址。详情请参阅事件回调。
