2.37 提交智能擦除任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/erase-video-vlm
本 API 用于提交一个异步的智能擦除任务。系统结合音频语义和视频画面，自动识别视频中的字幕、水印等后期叠加文字，定位其出现的时间和区域，并对目标区域进行无痕擦除。您可以通过 presets 指定擦除目标类别（口播字幕、字幕、水印或全部类别），通过 mode 选择由系统自动定位或按 
erase_hint_rules 手动指定擦除范围。
说明
如需了解完整的使用流程和应用示例，请参阅智能擦除 。
前提条件
完成 IMP 智能处理跨服务授权：首次调用本 API 前，您必须先在 AI MediaKit 控制台基础配置 > 授权管理 页面，为 AI MediaKit 授予访问您 IMP 智能处理资源的权限。否则，任务将因无权限访问而失败。同一账号下只需授权一次，后续调用无需重复操作。

以下示例使用默认的 presets （ ["all"] ）和 mode （ auto ），由系统自动检测并擦除画面中的字幕与水印，同时使用画质优先的输出编码模式。

-H 'Content-Type: application/json' \
-d '{
 "video_url": "https://example.com/source_video.mp4",
 "presets": ["all"],
 "mode": "auto",
 "output_encode_mode": "Quality"
