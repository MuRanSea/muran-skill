6.3 对话 Chat API
POST https://amk-ark.cn-beijing.volces.com/api/v1/chat/completions
本接口是对火山方舟 Chat API 的封装，支持发送包含文本及超大视频（最高 5GB）的多模态消息列表，实现对长视频、高清视频的深度语义理解、时序分析及内容总结。
接口能力： 
工程级大视频支持：针对视频 URL 传入方式，AI MediaKit 内部自动执行抽帧及序列化预处理，将视频理解能力扩展至 5 GB。
深度思考模式：支持 thinking 字段，调用具备思维链（CoT）能力的模型，提升复杂逻辑问题和长视频分析的准确度。
流式输出：支持 stream 模式，实时返回模型生成的推理内容，有效降低用户等待焦虑并规避长任务超时。
前提条件：在调用 AI MediaKit Chat API 前，请参考快速入门 完成创建 API Key 及开通模型等准备工作。
鉴权：您需要将**火山方舟 API Key ** 与 MediaKit API Key 用英文斜杠 / 拼接（格式为 火山方舟Key/MediaKitKey ），填入示例代码中的 api_key 或 Authorization 占位符处。
Tips：一键展开折叠，快速检索内容
说明
打开页面右上角开关后，**ctrl ** + f 可检索页面内所有内容。

messages.content.video_url.fps float/ null 默认值 1
取值范围： [0.01, 5] 。
设置每秒抽取的视频帧数（Frames Per Second）。
高 fps 值：能捕捉更密集的画面信息，适用于分析快速变化的场景（如体育集锦），但会增加潜在的Token 消耗。
低 fps 值：适用于内容变化较慢的视频（如风景或演讲），可有效节约成本并提升处理速度。注意：最终抽帧数并非仅由 fps 决定。系统会在用户设定的 fps 、 max_frames 以及内置的 Token 上限（约 200k）三者之间，取最严格的限制进行抽帧。例如，即使 fps 设置得很高，最终帧数也可能因 max_frames 或总成本预算的限制而下调。详见视频理解 。
messages.content.video_url.**max_frames ** integer
单次视频理解任务处理的最大帧数。可用于精细控制 Token 总消耗。系统会在用户设定的 fps 、max_frames 以及内置的 Token 上限（约 200k）三者之间，取最严格的限制进行抽帧。例如，即使 fps设置得很高，最终抽帧数也不会超过 max_frames 的值。详见视频理解 。
messages.content.video_url.**max_pixels ** integer
设置单帧画面的最大分辨率（宽 × 高）。系统在抽帧后，会将单帧图片的总像素点数限制在此值内。适当降低此值可以显著减少高分辨率视频的 Token 消耗。
• 默认值：677,376
• 最大值：9,031,680（超出部分将按最大值处理）

frequency_penalty float / null 默认值 0
取值范围为 [ -2.0 , 2.0 ]。
频率惩罚系数。如值为正，根据新 token 在文本中的出现频率对其进行惩罚，从而降低模型逐字重复的可能性。
presence_penalty float / null 默认值 0
取值范围为 [ -2.0 , 2.0 ]。
存在惩罚系数。如果值为正，会根据新 token 到目前为止是否出现在文本中对其进行惩罚，从而增加模型谈论新主题的可能性。
temperature float / null 默认值 1
取值范围为 [ 0 , 2 ]。
采样温度。控制了生成文本时对每个候选词的概率分布进行平滑的程度。当取值为 0 时模型仅考虑对数概率最大的一个 token。
较高的值（如 0.8）会使输出更加随机，而较低的值（如 0.2）会使输出更加集中确定。
通常建议仅调整 temperature 或 top_p 其中之一，不建议两者都修改。
top_p float / null 默认值 0.7
取值范围为 [ 0 , 1 ]。
核采样概率阈值。模型会考虑概率质量在 top_p 内的 token 结果。当取值为 0 时模型仅考虑对数概率最大的一个 token。
0.1 意味着只考虑概率质量最高的前 10% 的 token，取值越大生成的随机性越高，取值越低生成的确定性越高。通常建议仅调整 temperature 或 top_p 其中之一，不建议两者都修改。
