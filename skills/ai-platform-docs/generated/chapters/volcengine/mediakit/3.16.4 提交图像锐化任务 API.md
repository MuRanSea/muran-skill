3.16.4 提交图像锐化任务 API
POST https://mediakit.cn-beijing.volces.com/api/v1/tools-sync/sharpen-image
本 API 用于提交一个同步的图像锐化任务，通过对输入图像进行锐化处理，有效增强图像的边缘细节与整体清晰度，适用于电商素材优化、UGC 画质增强、封面海报二创等场景。
说明
如需了解该功能的详细说明及应用，请参阅图像锐化 。

-H 'Content-Type: application/json' \
