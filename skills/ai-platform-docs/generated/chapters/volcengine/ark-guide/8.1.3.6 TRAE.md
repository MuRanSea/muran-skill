8.1.3.6 TRAE
本文介绍如何在 TRAE 中配置并使用方舟 Coding Plan。
前提条件
您已按需订阅 Coding Plan 套餐。如未订阅，请访问 方舟 Coding Plan 活动 按需订阅套餐。安装 TRAE
访问 TRAE 官网 下载并安装对应操作系统的版本。
配置 TRAE
根据个人用户入口登录后，进入设置中心添加模型。 
选择个人用户入口登录后，点击界面右上角的 设置 图标，进入设置中心。
在左侧导航栏中，选择 模型，在模型管理页面进行配置。
点击 + 添加模型 按钮，界面上显示 添加模型 窗口。
在添加模型窗口中，配置模型信息。 
选择服务商：火山引擎。
配置方式：Coding Plan
选择模型。 
直接从列表中选择提供的模型。
若希望使用 Coding Plan 支持的其他模型，单击使用其他模型，模型 ID 需使用文本生成模型的名称，详细模型名称参见 支持的模型 。
填写 API 密钥：专属 API Key
单击添加模型，完成模型的配置。
使用 TRAE
在 AI 对话输入框的右下角选择配置的模型，发送简单任务并检查实际响应。
