使用流程
3D 生成任务为异步任务。
通过 创建任务接口 创建3D生成任务，获得 任务 ID 。
通过 任务查询接口 + 任务 ID 查询任务状态，直到任务完成时，获取返回的 3D 产物下载链接，下载生成结果。
说明
3D 生成过程耗时在分钟级别，通常在数分钟到十数分钟不等，具体受任务复杂度和平台负载影响。
返回的产物链接有效期为 24 小时，过时失效，请及时下载/转存产物。

限流说明
同一主账号下，使用同一模型（不区分版本）的请求受到以下限制。超过对应限制会返回 “429: 'TooMany Requests'” 错误。
模型维度的限流
不同模型的 RPM 和最大并发任务数不同，详见 3D生成能力 。
RPM（Requests Per Minute） ：每分钟允许创建的 3D 生成任务数上限。超过上限时，创建任务请求将因触发限流而失败。
最大并发任务数：同一时刻可处于处理状态的任务数上限。达到上限后，新创建的任务将进入队列等待处理。
非推理 API 请求频率限制
QPS（Queries Per Second） ：每秒允许的请求数上限。超过上限时，任务请求将因触发限流而失败。接口名称 账号维度的 QPS 上限
