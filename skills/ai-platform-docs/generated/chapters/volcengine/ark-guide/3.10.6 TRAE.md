3.10.6 TRAE
本文介绍如何在 TRAE 中配置并使用方舟 按量计费模型服务。
前提条件
在配置工具前，需要 开通所需的模型服务 。
安装 TRAE
访问 TRAE 官网 下载并安装对应操作系统的版本。
配置 TRAE
根据个人用户入口登录后，进入设置中心添加模型。 
选择个人用户入口登录后，点击界面右上角的 设置 图标，进入设置中心。
在左侧导航栏中，选择 模型，在模型管理页面进行配置。
点击 + 添加模型 按钮，界面上显示 添加模型 窗口。
在添加模型窗口中，配置模型信息。 
选择服务商：火山引擎。
配置方式：按量计费
选择模型。 
直接从列表中选择 TRAE 预置的模型。
若希望使用其他模型，单击使用其他模型，然后在输入框中填写 Model ID，模型列表参见 模型列表 。
填写 API 密钥：API Key
单击添加模型，完成模型的配置。
使用 TRAE
在 AI 对话输入框的右下角选择配置的模型，发送简单任务并检查实际响应。
其他操作
接入 MCP Server
若内置工具未覆盖您的使用场景，可在 TRAE 中接入二方、三方 MCP Server，扩展模型可用的能力。获取 MCP Server
二方：访问 智能体工具商店 ，获取火山引擎生态内的 MCP 工具（如巨量千川、知识库等），在MCP 详情页获取服务地址与鉴权信息。
三方：接入其他 MCP 市场提供的 MCP Server，或自行部署开源 MCP Server。
注意
请从可信来源获取 MCP Server，其安全性与稳定性由提供方负责，接入前请确认其权限范围符合您的预期。
配置 MCP Server
在 TRAE 设置中配置 MCP Server。更多配置方式与参数说明，请参考 TRAE 官方文档。
