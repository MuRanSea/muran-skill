3.10.9 DeepSeek Harness
本文介绍如何在 DeepSeek Harness 中配置并使用方舟 按量计费模型服务。
注意
DeepSeek Harness 目前处于开发者预览阶段，正在快速迭代，后续可能会出现破坏兼容性的变更。
前提条件
在配置工具前，需要 开通所需的模型服务 。
您已安装 Node.js（建议使用 LTS 版本）。
配置 DeepSeek Harness
您可以按下面任一方式在 DeepSeek Harness 中接入方舟 按量计费模型服务。通过 Web UI 手动配置 可在DeepSeek Harness Web UI 中逐项填写；通过 Ark 插件配置 可借助方舟官方插件自动完成 provider 添加，只需填入 API Key。
方式 1：一键配置（推荐）
Ark CLI 是火山方舟平台官方命令行工具，支持在本地终端快速完成认证与资源管理，并可将能力安装到常用 AI Agent 中，降低手动配置的时间成本和出错风险。
安装 Ark CLI
环境要求：Node.js 18 或更新版本。支持 macOS、Linux、Windows。
登录 Ark CLI
根据界面提示选择登录方式，推荐选择 火山 SSO (浏览器登录) ，在浏览器中完成授权即可。一键配置 DeepSeek Harness
npm install -g @volcengine/ark-cli@latest
arkcli --version

arkcli auth login

选择 Profile： platform_cn-beijing_accountwide 。
选择 Endpoint：按需选择要使用的推理接入点。
选择 AI Agent： DeepSeek Harness 。
配置完成后，DeepSeek Harness 会自动识别配置的模型。启动 DeepSeek Harness 即可使用。方式 2：通过 Web UI 手动配置
启动 DeepSeek Harness。

在 DeepSeek Harness Web UI 中，单击左下角设置。
在左侧导航栏单击模型，根据界面信息进行配置。

方式 2：通过火山方舟插件配置
方舟提供 DeepSeek Harness 官方插件 dsh-volcengine-plugin 。安装并启用插件后，可以在 火山方舟 插件中配置方舟 Agent Plan、Coding Plan 或后付费模型的接入方式。本文以接入 按量计费模型服务为例。启动 DeepSeek Harness。 
在终端执行以下命令启动 DeepSeek Harness 的 Web UI。
在浏览器打开命令输出的访问地址。默认地址为 http://127.0.0.1:3080/ 。
安装并启用火山方舟插件。 
在 DeepSeek Harness Web UI 中，单击左侧导航插件进入插件添加入口。
API 协议 API 地址
openai-completions https://ark.cn-beijing.volces.com/api/v3
openai-responses https://ark.cn-beijing.volces.com/api/v3
anthropic-messages https://ark.cn-beijing.volces.com/api/compatible

name: doubao-seed-2-1-pro

输入插件包名 dsh-volcengine-plugin ，单击安装。
插件安装完成后，单击 立即启用。
配置火山方舟插件。 
单击 火山方舟 插件卡片，进入插件配置页面。
在连接配置区域，选择接入方式 PayGo。
填写 API Key ，单击 保存。
（可选）如需调整调用协议或服务地址，展开自定义配置，按实际接入环境修改调用协议和 BaseURL。
配置模型。 
选择模型目录中的模型。
单击 保存模型配置。
完成上述操作后，回到对话页，在输入框右下角的模型下拉菜单中选择配置的模型，即可开始使用。使用 DeepSeek Harness
在页面中点击 选择工作区，添加你启动 dsh 时所在的项目目录。选中工作区后，会话输入框才可用。
在输入框右下角的模型下拉菜单中选择已配置的模型，即可开始使用。模型列表参见 模型列表 。在输入框输入需求即可开始使用 DeepSeek Harness。
Agent 可以读取和编辑工作区文件、运行命令、委派工作并维护计划。当操作在当前权限策略下需要审批时，Web UI 会先询问你。
