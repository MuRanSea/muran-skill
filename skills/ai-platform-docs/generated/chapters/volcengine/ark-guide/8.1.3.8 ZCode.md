8.1.3.8 ZCode
ZCode 是智谱推出的桌面 AI 编程客户端（macOS / Windows / Linux），深度集成 GLM 系列模型，同时兼容自定义 OpenAI / Anthropic 协议供应商。本文介绍如何在 ZCode 中接入方舟 Coding Plan。一、前置操作
访问 方舟 Coding Plan 活动 ，按需订阅套餐后再配置使用编程工具。
访问 ZCode 官网 ，下载并安装适合您操作系统的版本。安装步骤可参考 ZCode 官方安装教程 ，安装完成后按提示登录。

```mixin-react
配置 ark-code-latest (控制台管理)
在配置文件中指定模型为 ark-code-latest 。\n2. 通过开通管理页面 选择或切换目标模型，切换模型后 3\-5 分钟即可生效。\n 支持 Auto 模式，通过「效果 + 速度」双维度智能算法自动选择模型。\n);
```
Base URL
不同的工具配置的 Base URL 根据兼容的协议会有不同：
兼容 Anthropic 接口协议工具：`https://ark.cn-beijing.volces.com/api/coding`
兼容 OpenAI 接口协议工具：`https://ark.cn-beijing.volces.com/api/coding/v3`
注意
请勿使用 `https://ark.cn-beijing.volces.com/api/v3` ：该 Base URL 不会消耗您的 Coding Plan 额度，而是会产生额外费用。

二、配置 ZCode
Coding Plan 同时兼容 OpenAI 与 Anthropic 接口协议，ZCode 均支持。以下以 OpenAI 协议为例；如需使用 Anthropic 协议，将 API 格式改为 Anthropic 并把 Base URL 换成 https://ark.cn-beijing.volces.com/api/coding即可。
方式 1：自动化助手（推荐）
ArkCLI Helper 是一个编码工具助手，支持快速配置选择的工具接入 Coding Plan。安装并运行该助手，根据界面提示操作可自动完成工具配置，降低手动配置的时间成本和出错风险。
注意
ArkCLI Helper 是基于 Ark Helper 升级演进的工具配置服务，相关能力将持续在 ArkCLI Helper 上迭代更新。建议优先使用 ArkCLI Helper 完成工具配置。
ArkCLI Helper 支持 macOS、Linux、Windows 系统。
安装 Ark CLI。
登录 Ark CLI。
# 1. 通过 NPM 安装
npm install -g @volcengine/ark-cli@latest
# 2. 验证安装
arkcli --version
Bash
arkcli auth login
Bash
根据界面提示选择登录方式。若之前已登录过 arkcli，会沿用上次选择的配置；如需重新选择，请先执行 arkcli config reset 后再运行 arkcli auth login 。首次登录时，按提示完成以下配置：选择项目（Project） ：可按需选择，或默认选择账号全部资源。
选择消费模式（Type） ：选择 coding-plan 。
其中：
<ARK_API_KEY> ：运行 ArkCLI Helper 时填写的 Coding Plan API Key。
运行 ArkCLI Helper，根据界面提示完成 ZCode 的配置。
在命令行界面输入 arkcli helper 命令，启动 ArkCLI Helper。
选择要配置的 Plan profile：选择 coding-plan_cn-beijing_personal (Coding Plan) 。选择默认 model：按需选择。
选择要配置的 AI Agent： ZCode 。
完成上述操作后，将自动完成 ZCode 的基础配置，无需手动安装。
方式 2：手动配置
打开 ZCode 客户端，单击左下角 设置 图标，进入 模型设置，单击 添加供应商。
◦
在弹出的表单中填写以下字段，保存供应商。 
名称：自定义，便于识别，例如 Ark Coding Plan 。
Base URL： https://ark.cn-beijing.volces.com/api/coding/v3 （OpenAI 协议）；若使用 Anthropic 协议，填 https://ark.cn-beijing.volces.com/api/coding 。
API Key：填写您的 方舟 API Key 。
API 格式：取决于选择的 Base URL。
◦
◦
◦
◦
API 格式 Base URL
Anthropic Messages https://ark.cn-beijing.volces.com/api/coding
Chat Completions https://ark.cn-beijing.volces.com/api/coding/v3
Responses https://ark.cn-beijing.volces.com/api/coding/v3
单击 添加模型，在表单中填写以下字段，保存模型。可以多次点击 添加模型，为一个供应商添加多个模型。 
模型 ID：填入支持的 Model Name（详见上方核心配置），或使用 ark-code-latest 。
上下文窗口：按所选模型的最大上下文长度填写。
最大输出 Token（可选）：按需填写，默认可留空跟随模型上限。
除了在客户端 UI 中添加供应商，也可以直接编辑本地配置文件 ~/.zcode/v2/config.json （Windows 系统为 %USERPROFILE%\.zcode\v2\config.json ）。首次通过 UI 完成任意配置后该文件会自动生成，已有内容时在 provider 对象中追加一条即可。

三、使用 ZCode
在 ZCode 主界面顶部的模型下拉中，选中刚添加的模型。
在对话框输入你的需求（如生成代码、修复 bug、重构、写单元测试），回车即可开始对话开发。ZCode 支持规划、编码、评审与上线等全流程研发场景。
更多使用技巧和高级功能参见 ZCode 官方文档 。
