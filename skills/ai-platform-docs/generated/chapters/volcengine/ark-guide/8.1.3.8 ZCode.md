Base URL
不同的工具配置的 Base URL 根据兼容的协议会有不同：
兼容 Anthropic 接口协议工具：`https://ark.cn-beijing.volces.com/api/coding`
兼容 OpenAI 接口协议工具：`https://ark.cn-beijing.volces.com/api/coding/v3`
注意
请勿使用 `https://ark.cn-beijing.volces.com/api/v3` ：该 Base URL 不会消耗您的 Coding Plan 额度，而是会产生额外费用。
API Key
获取 API Key
前提条件
您已按需订阅 Coding Plan 套餐。如未订阅，请访问 方舟 Coding Plan 活动 按需订阅套餐。安装 ZCode
访问 ZCode 官网 ，下载并安装适合您操作系统的版本。安装步骤可参考 ZCode 官方安装教程 ，安装完成后按提示登录。
配置 ZCode
Coding Plan 同时兼容 OpenAI 与 Anthropic 接口协议，ZCode 均支持。以下以 OpenAI 协议为例；如需使用 Anthropic 协议，将 API 格式改为 Anthropic 并把 Base URL 换成 https://ark.cn-beijing.volces.com/api/coding即可。
方式 1：一键配置（推荐）
Ark CLI 是火山方舟平台官方命令行工具，支持在本地终端快速完成认证与资源管理，并可将能力安装到常用 AI Agent 中，降低手动配置的时间成本和出错风险。
安装 Ark CLI
环境要求：Node.js 18 或更新版本。支持 macOS、Linux、Windows。
登录 Ark CLI
根据界面提示选择登录方式，推荐选择 火山 SSO (浏览器登录) ，在浏览器中完成授权即可。一键配置 ZCode
运行 ArkCLI Helper，根据界面提示完成配置。
选择 Profile： coding-plan_cn-beijing_personal 。
选择默认 model：按需选择。
npm install -g @volcengine/ark-cli@latest
arkcli --version
Bash
arkcli auth login
Bash
arkcli helper
Bash
选择 AI Agent： ZCode 。
配置完成后，ZCode 会自动识别配置的模型。启动 ZCode 即可使用。
方式 2：手动配置
打开 ZCode 客户端，单击左下角 设置 图标，进入 模型设置，单击 添加供应商。
在弹出的表单中填写以下字段，保存供应商。
名称：自定义，便于识别，例如 Ark Coding Plan 。
Base URL： https://ark.cn-beijing.volces.com/api/coding/v3 （OpenAI 协议）；若使用 Anthropic 协议，填 https://ark.cn-beijing.volces.com/api/coding 。
API Key：填写您的 专属 API Key 。
API 格式：取决于选择的 Base URL。
单击 添加模型，在表单中填写以下字段，保存模型。可以多次点击 添加模型，为一个供应商添加多个模型。
模型 ID：填入支持的 Model Name（详见上方核心配置），或使用 ark-code-latest 。
上下文窗口：按所选模型的最大上下文长度填写。
