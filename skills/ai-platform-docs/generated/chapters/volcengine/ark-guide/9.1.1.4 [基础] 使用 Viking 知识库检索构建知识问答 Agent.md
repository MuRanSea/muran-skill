9.1.1.4 [基础] 使用 Viking 知识库检索构建知识问答 Agent
企业知识问答往往需要同时检索制度文档、产品资料、售后政策和视频教程等多种业务资料。你可以为Agent 接入 Viking 知识库检索 Skill，让 Agent 基于这些资料回答问题，而不是只依赖模型自身知识。本教程演示如何完成从「选择创建入口 → 配置知识库鉴权 → 创建 Session → 验证检索结果」的完整流程。
完成目标
完成本教程后，你将获得一个能够在 Session 中检索 Viking 知识库并回答业务问题的 Agent。核心概念
viking-knowledge-search Skill：让 Agent 检索 Viking 知识库中的内容。需要基于企业资料、产品文档或视频内容回答问题时使用。
Viking API Key：可以绑定指定知识库或知识服务。需要按知识库范围控制访问权限时使用。火山 API Key：用于以 IAM 子账号身份访问 Viking 知识库。选择这种鉴权方式时，需要在该子账号下创建 API Key，并在 Credential 中将其配置为 VOLC_API_KEY 。
Credential：在 Credentials Vault 中保存 API Key，并限制密钥可以发送到哪些域名。
Environment：承载 Agent 运行所需的环境配置。创建 Session 时需要选择对应的 Environment。Session：绑定 Agent、Credential 和 Environment，承载一次实际对话。
前提条件
开始前，完成以下准备：
已开通火山方舟 Managed Agents。
已开通 Viking 知识库 。
已在 Viking 知识库中准备可检索的业务资料。
已准备具备 Viking 知识库访问权限的账号。
注意
Viking API Key 和火山 API Key 选择一种配置。创建 Credential 时，变量名必须与所选鉴权方式匹配。
步骤 1 · 创建 Agent
先创建负责执行知识库检索的 Agent，并为它启用 viking-knowledge-search Skill。你可以从 Agents 页面自行配置 Agent，也可以基于 QuickStart 模板快速创建。
从 Agents 创建
打开 Agents 创建页 。
在 Skills 中选择 Ark 预置。
搜索并选择 viking-knowledge-search 。
完成其他 Agent 配置后，创建 Agent。
验证：Agent 的 Skills 列表中显示 viking-knowledge-search 。
从 QuickStart 创建
打开 Managed Agents QuickStart 。
选择以下任一模板： 
视频知识：检索视频资料并定位关键片段。
Deep Search：跨文档检索行业报告、产品报告和技术报告。
售后客服：依据产品资料与售后政策回答问题。
企业知识问答：依据企业制度与内部资料回答问题。
需要调整 Agent 配置时，直接在对话中描述修改要求。

步骤 2 · 创建 API Key
为 Viking 知识库准备调用凭据，供 Agent 发起经过鉴权的检索请求。根据已有权限管理方式，选择一种知识库鉴权方式。
Viking API Key
打开 Viking 知识库 API Key 页面 。
创建 API Key。
选择 Agent 需要访问的知识库或知识服务。
完成创建并记录 API Key。
验证：API Key 已绑定 Agent 需要检索的知识库。
火山 API Key
选择以 IAM 子账号身份访问 Viking 知识库时，需要在该子账号下创建火山 API Key，并在后续 Credential中使用。
打开火山引擎访问控制用户管理 。
选择用于访问 Viking 知识库的子账号。
在用户详情的 密钥 页签中创建 API Key。
记录创建后的 API Key。
验证：子账号的 API Key 列表中显示新建的 API Key。
步骤 3 · 创建 Credential
把步骤 2 创建的 API Key 保存到 Credentials Vault，并限制密钥可以发送到的域名。
打开 Credentials Vault 。
创建 Vault，并在 Vault 中添加 Credential。
将 Credential 类型 设为 ENV。
根据步骤 2 选择的鉴权方式，只填写一组变量名和值： 
选择 Viking API Key 时，变量名填写 VIKING_API_KEY ，Value 填写对应的 Viking API Key。选择火山 API Key 时，变量名填写 VOLC_API_KEY ，Value 填写对应的火山 API Key。
将 出网范围 设为 受限。
在 允许的域名 中填写 api-knowledgebase.mlp.cn-beijing.volces.com ，然后创建 Credential。Viking API Key

注意
保存 Credential 后，页面不再显示完整密钥。提交前确认变量名、Value 和允许域名填写正确。步骤 4 · 创建 Environment
创建 Agent 运行所需的 Environment，供后续 Session 选择。
打开 Managed Agents 的 Environments 页面，输入名称，选择运行方式，并按业务需要完成配置后创建Environment。
验证：Environment 列表中显示新建的 Environment。
步骤 5 · 创建 Session
将 Agent、Credential 和 Environment 绑定到同一个 Session，开始验证知识库检索。
打开 Sessions ，创建 Session。
依次选择步骤 1 创建的 Agent、步骤 3 创建的 Credential 和步骤 4 创建的 Environment，然后创建Session 并进入调试页面。
验证：Session 创建成功，并显示已绑定的 Agent、Credential 和 Environment。
验证结果
向 Session 发送一个只能从目标知识库中回答的问题。例如，知识库中保存了售后政策时，询问某个产品的退换条件。
检查以下结果：
Agent 返回的内容与目标知识库中的资料一致。
Agent 没有混入其他知识库的内容。
Session 没有显示知识库鉴权失败。
