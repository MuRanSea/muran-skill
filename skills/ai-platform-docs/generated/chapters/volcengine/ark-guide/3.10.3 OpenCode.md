3.10.3 OpenCode
本文介绍如何在 OpenCode 中配置并使用方舟按量计费模型服务。
前提条件
在配置工具前，需要 开通所需的模型服务 。
安装 OpenCode
前提条件：安装 Node.js 18 或更新版本 。
在命令行界面，执行以下命令安装 OpenCode。
安装结束后，执行以下命令查看安装结果，若显示版本号则安装成功。
配置 OpenCode
需配置的信息
如您对 OpenCode 熟悉，或本地已有配置，可获取以下信息直接配置。
Base URL： https://ark.cn-beijing.volces.com/api/v3 。
API Key：获取API Key 。
Model：按需选择模型并获取 Model ID。可用模型参见模型列表 。
方式 1：一键配置（推荐）
Ark CLI 是火山方舟平台官方命令行工具，支持在本地终端快速完成认证与资源管理，并可将能力安装到常用 AI Agent 中，降低手动配置的时间成本和出错风险。
安装 Ark CLI
环境要求：Node.js 18 或更新版本。支持 macOS、Linux、Windows。
npm install -g opencode-ai
Bash
opencode --version
Bash
登录 Ark CLI
根据界面提示选择登录方式，推荐选择 火山 SSO (浏览器登录) ，在浏览器中完成授权即可。一键配置 OpenCode
运行 ArkCLI Helper，根据界面提示完成配置。
选择 Profile： platform_cn-beijing_accountwide 。
选择 Endpoint：按需选择要使用的推理接入点。
选择 AI Agent： OpenCode 。
配置完成后，OpenCode 会自动识别配置的模型。启动 OpenCode 即可使用。
方式 2：手动配置
新建 ~/.config/opencode/opencode.json （Windows 路径： %USERPROFILE%\.config\opencode\opencode.json ），配置信息如下：
<ARK_API_KEY> ：替换为您自己的 API Key 。
model ：按需选择模型并获取 Model ID。可用模型参见模型列表 。
按量计费模型服务兼容 OpenAI 接口协议，支持 Responses API、Chat API。推荐使用 Responses API 的配置，推理效果更好。
支持的两类 API 仅在 npm 配置上不同：
Responses API 配置： "npm": "@ai-sdk/openai"
Chat API 配置： "npm": "@ai-sdk/openai-compatible"
以配置 doubao-seed-evolving 为例，具体信息如下。
Responses API
说明
npm 必须使用 @ai-sdk/openai ，模型才会使用 Responses API，在 baseURL 的基础上自动拼接 /responses 。
npm install -g @volcengine/ark-cli@latest
arkcli --version
Bash
arkcli auth login
Bash
arkcli helper
Bash
Chat API
说明
npm 必须使用 @ai-sdk/openai-compatible ，模型才会使用 Chat API，在 baseURL 的基础上自动拼接 /chat/completions 。

使用 OpenCode
启动 OpenCode：
输入 /models ，选择配置的模型并在 OpenCode 中使用。
其他操作
接入 MCP Server
若内置工具未覆盖您的使用场景，可在 OpenCode 中接入二方、三方 MCP Server，扩展模型可用的能力。
获取 MCP Server
二方：访问 智能体工具商店 ，获取火山引擎生态内的 MCP 工具（如巨量千川、知识库等），在MCP 详情页获取服务地址与鉴权信息。
三方：接入其他 MCP 市场提供的 MCP Server，或自行部署开源 MCP Server。
注意
请从可信来源获取 MCP Server，其安全性与稳定性由提供方负责，接入前请确认其权限范围符合您的预期。
配置 MCP Server
OpenCode 支持在设置中配置二方、三方 MCP Server，具体操作参考 OpenCode 官方文档。
