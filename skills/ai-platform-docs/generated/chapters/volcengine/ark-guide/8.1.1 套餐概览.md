8.1 Coding Plan 个人版
8.1.1 套餐概览
方舟 Coding Plan 是为开发者量身定制的订阅服务，助力高效编码开发。具备如下优势：
支持主流模型：不仅支持主流大语言模型，还支持 Embedding 向量化模型，涵盖 Doubao SeedEvolving、Doubao Seed 2.0 系列、GLM 系列、MiniMax 系列、Kimi系列、DeepSeek 系列、DoubaoEmbedding Vision 等模型。
兼容主流 AI 编码工具：支持 Claude Code、OpenCode、OpenClaw、TraeCode、Cline、Cursor、RooCode、Kilo Code 等主流编程工具，套餐额度共享，适配多种开发场景。
多种套餐适配不同场景：提供 Lite 与 Pro 套餐，适应普通与高强度编程场景。
稳定平稳运行：平台具有多租户隔离能力，调用高峰不会明显降速，TPM 满足正常开发需求。说明
已了解方舟 Coding Plan 的用户，可以访问 方舟 Coding Plan 活动 按需订阅套餐，参见快速开始 开启 AI 编程之旅。

套餐额度刷新规则
套餐额度在时间周期内耗尽后，需要等待下一个周期自动恢复额度，不会消耗其他资源包或账户余额。每5小时限额：根据首次请求发生时间，以 5 小时为周期定时刷新限额。
周限额：每周一 00:00:00 重置周限额。
月限额：每订阅月第 1 日 00:00:00 重置月限额。
套餐额度使用限制
同一订阅套餐可在所有支持的工具中使用，额度共享。
套餐额度仅在 AI 编程工具中生效，不可用于 API 调用。在非 AI 编程工具中使用方舟 Coding Plan 权益对应的 Base URL 和 API Key 有可能被识别为滥用/违规，会导致订阅停用或账号封禁。
