8.1.3.11 OpenViking
OpenViking 是专为 AI 智能体（Agent）打造的上下文数据库，主要适用于多 Agent 协同、长期记忆管理、复杂任务执行等场景。该数据库采用 viking://文件系统范式，将智能体的记忆、资源与技能进行统一组织管理，依托分层加载机制按需供给上下文，在减少 Token 消耗的同时提升运行效率，结合目录式检索优化信息召回效果。功能上，OpenViking 支持多租户、多用户及多 Agent 隔离，且能在会话结束后自动沉淀长期记忆，实现智能体能力的持续积累与自我优化，既有效降低开发者的上下文管理成本，也能显著提升 OpenClaw 等智能体的整体运行表现。
本文介绍如何在 OpenViking 中配置并使用方舟 Coding Plan。
注意
OpenViking 工具处于快速迭代阶段，本文使用的版本为 0.4.15。如果实际使用方式与本文存在差异，请参见 OpenViking：AI 智能体的上下文数据库 。

配置 OpenViking
创建配置文件 ~/.openviking/ov.conf ，并按以下说明修改配置：
storage.workspace ：替换为实际的工作空间路径。
embedding ：配置向量化模型，用于向量化和语义检索。 
embedding.dense.model ：支持的 Embedding 模型 doubao-embedding-vision 。
embedding.dense.api_key ：替换为您自己的 API Key 。
vlm ：配置语言模型，用于图像和内容理解。 
vlm.model ：支持的语言模型。
vlm.api_key ：替换为您自己的 API Key 。
根据系统环境选择对应的方式设置环境变量。

安装及配置
# Check system health
openviking observer system
# Add a resource to memory
openviking add-resource https://raw.githubusercontent.com/volcengine/OpenViking/refs/heads/main/README.md
# List all synchronized resources
openviking ls viking://resources
# Query
openviking find "what is openviking"

 -H "Content-Type: application/json" \
