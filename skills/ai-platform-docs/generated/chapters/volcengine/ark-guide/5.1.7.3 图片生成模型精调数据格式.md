5.1.7.3 图片生成模型精调数据格式
进行模型精调前，需要准备符合模型类别和精调方法要求的训练集与验证集。数据集采用 JSONL 格式，每行包含一个完整的 JSON 对象。
注意
精调 JSONL 文件绝对路径不可包含以下特殊字符： * 、 ? 、 [ 、 ] 。
支持模型
图片生成模型支持 SFT，具体模型 ID 和版本以创建精调任务时控制台可选项为准。
SFT 精调
图片生成模型总体上分为两类数据，一类是文生图 (t2i) 数据，特点为输入只有 prompt。另一类是编辑（edit）数据，即图生图，特点是输入是 文本 + 单图/多图。两类数据均采用相同的格式，以下是完整的格式示例、说明及字段定义。
格式示例
