Base URL
不同的工具配置的 Base URL 根据兼容的协议会有不同：
兼容 Anthropic 接口协议工具：`https://ark.cn-beijing.volces.com/api/coding`
兼容 OpenAI 接口协议工具：`https://ark.cn-beijing.volces.com/api/coding/v3`
注意
请勿使用 `https://ark.cn-beijing.volces.com/api/v3` ：该 Base URL 不会消耗您的 Coding Plan 额度，而是会产生额外费用。
API Key
获取 API Key
前提条件
您已按需订阅 Coding Plan 套餐。如未订阅，请访问 方舟 Coding Plan 活动 按需订阅套餐。安装 OpenCode
前提条件：安装 Node.js 18 或更新版本 。
在命令行界面，执行以下命令安装 OpenCode。
安装结束后，执行以下命令查看安装结果，若显示版本号则安装成功。
配置 OpenCode
需配置的信息
如您对 OpenCode 熟悉，或本地已有配置，可获取以下信息直接配置。
Base URL： https://ark.cn-beijing.volces.com/api/coding/v3 。
API Key：获取API Key 。
Model：支持配置 Model Name（实时切换模型）或 ark-code-latest （控制台切换模型）。具体配置方式参见 模型配置 。
方式 1：一键配置（推荐）
Ark CLI 是火山方舟平台官方命令行工具，支持在本地终端快速完成认证与资源管理，并可将能力安装到常用 AI Agent 中，降低手动配置的时间成本和出错风险。
安装 Ark CLI
环境要求：Node.js 18 或更新版本。支持 macOS、Linux、Windows。
npm install -g opencode-ai
Bash
opencode --version
Bash
登录 Ark CLI
根据界面提示选择登录方式，推荐选择 火山 SSO (浏览器登录) ，在浏览器中完成授权即可。一键配置 OpenCode
运行 ArkCLI Helper，根据界面提示完成配置。
选择 Profile： coding-plan_cn-beijing_personal 。
选择默认 model：按需选择。
选择 AI Agent： OpenCode 。
配置完成后，OpenCode 会自动识别配置的模型。启动 OpenCode 即可使用。
方式 2：手动配置
新建 ~/.config/opencode/opencode.json （Windows 路径： %USERPROFILE%\.config\opencode\opencode.json ），配置信息如下：
<ARK_API_KEY> ：替换为您自己的 API Key 。
model ：更新为需要使用的模型信息。支持的模型信息参见 模型配置 。
Coding Plan 兼容 OpenAI 接口协议，支持 Responses API、Chat API。推荐使用 Responses API 的配置，推理效果更好。
支持的两类 API 仅在 npm 配置上不同：
Responses API 配置： "npm": "@ai-sdk/openai"
Chat API 配置： "npm": "@ai-sdk/openai-compatible"
以配置 ark-code-latest 为例，具体信息如下。
注意
部分模型支持开启 1M 上下文窗口，可用于包含大型代码库的长会话，可通过 limit.context 字段显式指定窗口大小。
provider.volcengine-coding-plan.models 节点下有两处（对象键、 name 字段）需替换为同一Model Name，切勿遗漏。
npm install -g @volcengine/ark-cli@latest
arkcli --version
Bash
arkcli auth login
Bash
arkcli helper
Bash
若需开启模型图片理解能力，需在模型配置节点下新增如下配置项： "modalities": {"input": ["text",
"image"], "output": ["text"]}
