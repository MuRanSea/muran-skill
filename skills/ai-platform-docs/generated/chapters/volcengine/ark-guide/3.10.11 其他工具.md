3.10.11 其他工具
方舟 API 支持 OpenAI 和 Anthropic 接口协议，配置对应协议的 Base URL、API Key 和模型后，即可在兼容的工具中使用。
前提条件
在配置工具前，需要 开通所需的模型服务 。
适用工具
获取 MCP Server
二方：访问 智能体工具商店 ，获取火山引擎生态内的 MCP 工具，在 MCP 详情页获取服务地址与鉴权信息。
三方：接入其他 MCP 市场提供的 MCP Server，或自行部署开源 MCP Server。
注意
从可信来源获取 MCP Server。接入前，确认其权限范围符合预期。
Chatbox
安装 Chatbox
访问 Chatbox 官网 ，下载并安装适合您操作系统的版本，或直接启动网页版。
配置 Chatbox
打开 Chatbox，进入 Settings 页面。
在 Model Provider 中单击添加提供商，将 API Mode 设置为 OpenAI API Compatible 。
配置以下信息。 
API Key：获取API Key 。
API Host： https://ark.cn-beijing.volces.com/api/v3
接口协议 Base URL 适用工具
兼容 Anthropic 接口协议 https://ark.cn-beijing.volces.com/
api/compatible Claude Code 等
兼容 OpenAI 接口协议 https://ark.cn-beijing.volces.com/
api/v3

Hermes Agent、WorkBuddy、
ZCode、DeepSeek Harness、

Code、Kilo Code 等

Model：填写要使用的 Model ID，模型列表参见 模型列表 。
配置完成后，即可在输入框中输入需求，与模型进行交互。
Cherry Studio
安装 Cherry Studio
访问 Cherry Studio 官网 ，下载并安装 Cherry Studio 客户端。
配置 Cherry Studio
打开 Cherry Studio，进入设置页面。
在模型服务中单击添加提供商，将提供商类型设置为 OpenAI 。
配置以下信息。 
API 密钥：获取API Key 。
API 地址： https://ark.cn-beijing.volces.com/api/v3
模型：单击添加模型，填写要使用的 Model ID，模型列表参见 模型列表 。
配置完成后，即可在输入框中输入需求，与模型进行交互。
Cline
安装 Cline
打开 VSCode，在扩展市场搜索 Cline 并安装。
配置 Cline
Cline 安装完成后，配置以下信息。
API Provider： OpenAI Compatible
Base URL： https://ark.cn-beijing.volces.com/api/v3
API Key：获取API Key
Model ID：填写要使用的 Model ID，模型列表参见 模型列表 。
配置完成后，即可在输入框中输入需求，与模型进行交互。
接入 MCP Server
若内置工具未覆盖您的使用场景，可在 Cline 设置中配置二方、三方 MCP Server。获取方式参见 获取MCP Server ，配置方法参见 Cline 官方文档。
