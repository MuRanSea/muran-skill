9.1.17 火山方舟分账最佳实践
使用火山方舟大模型服务的客户，尤其是企业级客户，普遍存在强烈的分账诉求。例如：通过分账实现大模型服务成本精准核算、业务绩效评估及内部责任划分等。若想做好分账管理，通常在使用大模型前就需要做好内部设计，例如：分账维度梳理、分摊规则定义等。本文将火山方舟支持的分账场景做了典型梳理，沉淀了常见场景的分账解决方案和操作方法，助企业高效落地分账。
说明
每个场景都是一个独立的解决方案。其中，场景1、2、3可叠加使用，满足复杂的企业级分账场景。
分账概述
什么是分账
分账是指将已经明确的账单数据，依据用户企业内部的实际使用情况或用户自身的业务逻辑，进行账单数据的拆分。分配至不同的业务，部门，甚至个人等。通俗来说，就是通过分账体现出谁在什么产品或者服务上花了多少钱。
支持的分账维度
账号（对应下文场景1） ：账号间的资源隔离，资源归属不同，天然具备分账的能力。用户可以根据业务情况，将不同的部门或不同的业务线独立使用不同的账号进行资源和费用划分，分别各自管理资源和账单，也可通过企业财务能力集中管理费用。
项目（对应下文场景2） ：在单一账号下，单个资源（接入点）可关联唯一项目，如上图 Account_02所示。当资源产生费用时，会根据资源所属的项目，将费用也自动归属到对应项目中，得到按项目维度的分账数据。
标签（对应下文场景3） ：在单一项目中，单个资源（接入点）可关联多个标签，如上图 Account_02中的项目 02 所示。标签可标记资源的详细信息，当资源产生费用时，会根据资源所绑定的标签，将费用也自动关联到标签上，得到按标签维度的分账数据。
配置名称/计费单元（对应下文场景4） ：配置名称和计费单元记录了用户使用大模型时所选择的模型和具体计费项目，可以按照配置名称&计费单元进行分组求和，得到模型和模型中计费项目的具体费用，如上图 Account_01 所示。
createdBy系统标签（对应下文场景5） ：在标签系统中，有一类由系统自动创建的标签，典型的就是创建者标签createdBy。当用户开通该功能时，无论使用何种身份登录账号创建资源，系统都会自动在资源上标记该用户的登录身份信息，记录该资源的创建者，如上图 Account_02 中的项目 03 所示。我们可以利用该标签的内容，来得到创建者维度的分账数据。
API Key（对应下文场景6） ：为每个 API Key 生成唯一的资源 ID（Resource ID），账单系统会自动记录该资源 ID，可按该 ID 分组求和实现 API Key 维度分账（支持范围与生效时间见场景 6）。准备工作

场景1：多部门分账
场景描述
某个公司主体采购了方舟的一个或多个模型服务，多个部门同时使用这些模型服务，需要按照部门维度进行账单统计。
解决方案
选择一个火山引擎账号作为财务托管（托管账号，又称托管主账号），管理各部门账号（被托管账号，又称托管子账号）的财务履约。各部门账号仅可查看自己消费的账单，账单结算、开票、还款均由托管主账号负责。托管主账号可通过账号维度查看各部门产生的账单。
企业下每个部门独立使用一个火山引擎账号，托管子账号可由托管主账号协助申请，无需重复实名认证。
财务部门账号作为托管主账号，在费用中心 > 财务关联 页面，邀请其他账号完成财务托管关联。操作步骤详见 财务托管关联和解除 。
查询账单
使用托管主账号登录，在分账账单 页面， 默认展示当前主账号（Payer 账号）下的所有子账号（Owner 账号）的消费账单。您也可以过滤要查询的 Owner 账号，查询目标子账号的消费账单。场景2：多项目组分账

规划并创建推理接入点 。每个项目，按需创建一个或多个推理接入点，创建推理接入点时选择归属的项目。

场景描述
企业或开发者在同一个项目下，为不同的业务应用、测试环境或个人开发者分配了不同 API Key。为了实现精细化成本核算，需要明确每一个 API Key 产生的模型调用用量和费用，进而按 API Key 维度进行账单统计与成本归属。
解决方案
火山方舟为每个 API Key 生成唯一的 资源 ID（Resource ID），用于账单分账与用量统计。您可以在 APIKey 管理 页面获取该标识，并将不同的 API Key 下发给对应业务或人员使用。产生消费后，可在账单系统使用 资源 ID 分组对账。
说明
为实现按 API Key 分账，您会遇到以下名词。在此场景下，它们指代的是 API Key 的同一个唯一标识，仅命名不同：
资源 ID（Resource ID） ：火山方舟控制台 “API Key 管理” 页面展示的列名。
ApikeyID / apikey_id：分账账单系统中的分账维度名称，以及查账单 API 过滤条件 Filters 的键名。
查询账单
在获取目标 API Key 的 资源 ID 后，通过控制台查询按 API Key 拆分的账单或用量。
获取 API Key 的 资源 ID：在 API Key 管理 页面的 资源 ID 列，复制待查询 API Key 对应的唯一 资源ID。
按照 资源 ID 进行分账： 
进入 分账账单 页面，点击 “设置方舟分账维度”，选择 apikey_id 。
在 分拆项 ID 搜索框中粘贴已复制的资源 ID 进行精准查询。
使用限制与注意事项
生效时间：支持查询 2026-05-01 00:00 之后产生的账单数据。
支持的场景：后付费按量计费的推理请求用量。
不支持的场景
特定模型：向量化模型、语音同传模型、LoRA 精调模型。
特定计费方式：非后付费/按量计费的用量（如模型单元、TPM 保障包、Coding Plan 等）。未使用 API Key 鉴权的接口调用： 
离线推理任务类型的推理用量；
非推理请求的用量（如缓存存储费用、精调任务费用、推理代工算力费用、动态模型单元算力费用、素材库费用等）；
使用 JWT token 鉴权的请求。
常见问题
已删除的 API Key 是否支持查询账单？
暂不支持。未来会支持，建议您在删除 API Key 前做好对应 资源ID 的内部记录。
什么是推理接入点? 有什么作用？
在使用大语言模型进行推理服务时，推理接入点（Endpoint）是模型调用的关键入口。开发者只需通过指定的 ID 即可向大模型发起 API / SDK 推理请求，实现快速接入与灵活调用。推理接入点分为预置推理接入点和自定义推理接入点。用户主动创建的推理接入点为自定义推理接入点，支持更全面的配置能力，适用于需要精调模型接入、权限控制（配置项目和标签）、算力保障、数据回流等企业级或业务集成场景。更多详情请参见 什么是推理接入点 。
什么是财务托管？有什么作用？
财务托管，即账号授权其他账号对其云资源消费产生的账单进行托管，并负责后续的对账、开票、还款等履约内容。托管主账号(托管账号)管理托管子账号(被托管账号)的财务履约，托管子账号(被托管账号)只有资源操作的权限。在企业财务中，托管账号在关联被托管账户时可以设置关系类型为“财务托管”，即实现被托管账号的财务履约内容托管给托管账号来进行管理。更多详情请参见 财务托管概述 。什么是项目？有什么作用？
资源项目（项目）是火山引擎提供的一种资源分组管理的机制，帮助达成逻辑层面的资源隔离，您能够通过资源项目进行项目制授权和分账等操作。更多详情请参见 项目概述 。

什么是标签？有什么作用？
资源标签是由一组KV键值对组成，您可以通过资源标签从不同维度对云资源进行分类和聚合管理，并且使用于标签制授权和标签分账等场景。更多详情请参见 标签概述 。
如何快速查看某个推理接入点的费用？
在方舟控制台的在线推理 页面，切换至 自定义推理接入点 页签，单击目标推理接入点名称，进入 概览信息 页面。单击 前往查看账单，即可跳转至分账账单页面查看该推理接入点的账单信息。知识库如何绑定项目和标签？
