方舟 API 兼容 OpenAI 和 Anthropic 接口协议，支持在三方工具中使用，可参考本文进行配置及使用。说明
本文详细介绍 Claude Code、Codex 等三方工具的接入配置。若要按标准三阶段流程把方舟模型接入生产环境（参数配置、联通性核验、突发流量爬坡、上线监控），请参考 模型接入指南
（LLM） - 标准流程 。

方舟 Agent Plan VS 方舟 API 调用
两种方式在计费、支持模型、API Key、Base URL 上存在差异，配置时需注意区分。
生态兼容
