8.1.3.4 OpenClaw
OpenClaw（原 Clawdbot） 是一款开源、自托管的个人 AI 助手，可以在本地计算机上运行，兼容macOS、Windows 及 Linux 等多种系统，支持接入常用聊天工具，除了内置多种 Agent 常用工具外，还可以通过插件和 Skill 扩展更多能力。
方舟 Coding Plan 支持在 OpenClaw 中使用，可参考本文进行配置及使用。
说明
需要先访问 方舟 Coding Plan活动 ，按需订阅套餐后再配置使用编程工具。

Base URL
不同的工具配置的 Base URL 根据兼容的协议会有不同：
兼容 Anthropic 接口协议工具：`https://ark.cn-beijing.volces.com/api/coding`
兼容 OpenAI 接口协议工具：`https://ark.cn-beijing.volces.com/api/coding/v3`
注意
请勿使用 `https://ark.cn-beijing.volces.com/api/v3` ：该 Base URL 不会消耗您的 Coding Plan 额度，而是会产生额外费用。

方式 2：手动配置
Coding Plan 兼容 OpenAI 接口协议，支持 Responses API、Chat API。推荐使用 Responses API 的配置，推理效果更好。
两类 API 的配置方式基本一致，只需在 models.providers 中指定对应的 API 适配器：
Responses API 配置： "api": "openai-responses"
Chat API 配置： "api": "openai-completions"
注意
glm-5.3 、 deepseek-v4-flash 、 deepseek-v4-pro 、 kimi-k2.8-preview 支持 1M 上下文窗口用于包含大型代码库的长会话，可以通过 contextWindow 字段显式指定窗口大小。

高级配置：配置 Embedding 模型
方舟 Coding Plan 提供的 doubao-embedding-vision 模型（向量模型）可以为 OpenClaw 提供语义向量能力，将对话、文档与任务信息转换为高维向量表示，实现基于语义相似度的高效检索。
相比传统关键词匹配，Embedding 检索在信息量大、对话长、资料分散的场景下，能够更准确地召回相关内容，显著降低遗漏与误判。同时，Embedding 为记忆检索、知识库问答与工具调用提供统一的语义索引层，帮助 OpenClaw 在不增加主模型推理成本的前提下，提升跨轮次上下文追踪能力与整体效果。选择以下任一方式配置向量模型。
