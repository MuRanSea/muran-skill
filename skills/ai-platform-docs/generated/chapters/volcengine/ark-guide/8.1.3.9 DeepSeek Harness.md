8.1.3.9 DeepSeek Harness
DeepSeek Harness 是 DeepSeek AI 开发的一套用来构建、运行和扩展智能体的应用框架，采用一切皆插件的架构。本文介绍如何在 DeepSeek Harness 中接入方舟 Coding Plan 个人版使用。
注意
DeepSeek Harness 目前处于开发者预览阶段，正在快速迭代，后续可能会出现破坏兼容性的变更。
说明
需要先访问 方舟 Coding Plan活动 ，按需订阅套餐后再配置使用编程工具。

不同的工具配置的 Base URL 根据兼容的协议会有不同：

注意
请勿使用 `https://ark.cn-beijing.volces.com/api/v3` ：该 Base URL 不会消耗您的 Coding Plan 额度，而是会产生额外费用。

一、配置 DeepSeek Harness
您可以按下面任一方式在 DeepSeek Harness 中接入方舟 Coding Plan。自动化助手 通过 ArkCLI Helper 引导完成工具配置；通过 Web UI 手动配置 通过 DeepSeek Harness Web UI 逐项填写；通过 Ark 插件配置 借助方舟官方插件自动完成 provider 添加，只需填入 API Key。
方式 1：自动化助手（推荐）
ArkCLI Helper 是一个编码工具助手，支持快速配置选择的工具接入 Coding Plan。安装并运行该助手，根据界面提示操作可自动完成工具配置，降低手动配置的时间成本和出错风险。
注意
ArkCLI Helper 是基于 Ark Helper 升级演进的工具配置服务，相关能力将持续在 ArkCLI Helper 上迭代更新。建议优先使用 ArkCLI Helper 完成工具配置。
ArkCLI Helper 支持 macOS、Linux、Windows 系统。
安装 Ark CLI。
登录 Ark CLI。
# 1. 通过 NPM 安装
npm install -g @volcengine/ark-cli@latest
# 2. 验证安装
arkcli --version
Bash
arkcli auth login
Bash
根据界面提示选择登录方式。若之前已登录过 arkcli，会沿用上次选择的配置；如需重新选择，请先执行 arkcli config reset 后再运行 arkcli auth login 。首次登录时，按提示完成以下配置：选择项目（Project） ：可按需选择，或默认选择账号全部资源。
选择消费模式（Type） ：选择 coding-plan 。
其中：
<ARK_API_KEY> ：运行 ArkCLI Helper 时填写的 Coding Plan API Key。
运行 ArkCLI Helper，根据界面提示完成 DeepSeek Harness 的配置。
在命令行界面输入 arkcli helper 命令，启动 ArkCLI Helper。
选择要配置的 Plan profile：选择 coding-plan_cn-beijing_personal (Coding Plan) 。选择默认 model：按需选择。
选择要配置的 AI Agent： DeepSeek Harness 。
完成上述操作后，将自动完成 DeepSeek Harness 的基础配置，无需手动安装。

二、使用 DeepSeek Harness
在页面中点击 选择工作区，添加你启动 dsh 时所在的项目目录。选中工作区后，会话输入框才可用。
在输入框右下角的模型下拉菜单中选择 Ark Coding Plan 下的模型即可开始使用。可用模型列表参见 支持的模型 。
在输入框输入需求即可开始使用 DeepSeek Harness。
Agent 可以读取和编辑工作区文件、运行命令、委派工作并维护计划。当操作在当前权限策略下需要审批时，Web UI 会先询问你。
