Base URL
不同的工具配置的 Base URL 根据兼容的协议会有不同：
兼容 Anthropic 接口协议工具：`https://ark.cn-beijing.volces.com/api/coding`
兼容 OpenAI 接口协议工具：`https://ark.cn-beijing.volces.com/api/coding/v3`
注意
请勿使用 `https://ark.cn-beijing.volces.com/api/v3` ：该 Base URL 不会消耗您的 Coding Plan 额度，而是会产生额外费用。

前提条件
您已按需订阅 Coding Plan 套餐。如未订阅，请访问 方舟 Coding Plan 活动 按需订阅套餐。您已安装 Node.js（建议使用 LTS 版本）。
配置 DeepSeek Harness
您可以按下面任一方式在 DeepSeek Harness 中接入方舟 Coding Plan。自动化助手 通过 ArkCLI Helper 引导完成工具配置；通过 Web UI 手动配置 通过 DeepSeek Harness Web UI 逐项填写；通过 Ark 插件配置 借助方舟官方插件自动完成 provider 添加，只需填入 API Key。
方式 1：一键配置（推荐）
Ark CLI 是火山方舟平台官方命令行工具，支持在本地终端快速完成认证与资源管理，并可将能力安装到常用 AI Agent 中，降低手动配置的时间成本和出错风险。
安装 Ark CLI
环境要求：Node.js 18 或更新版本。支持 macOS、Linux、Windows。
登录 Ark CLI

方式 3：通过火山方舟插件配置
方舟提供 DeepSeek Harness 官方插件 dsh-volcengine-plugin 。安装并启用插件后，可以在 火山方舟 插件中配置方舟 Agent Plan、Coding Plan 或后付费模型的接入方式。本文以接入 Coding Plan 为例。启动 DeepSeek Harness。 
在终端执行以下命令启动 DeepSeek Harness 的 Web UI。
在浏览器打开命令输出的访问地址。默认地址为 http://127.0.0.1:3080/ 。
安装并启用火山方舟插件。 
在 DeepSeek Harness Web UI 中，单击左侧导航插件进入插件添加入口。

- id: doubao-seed-2.1-pro
