tool_calls 数组中的函数调用数量，必须与后续 role 为 tool 的消息数量完全对应。
您必须遵循 JSON Schema 规范。在函数参数定义中， type 字段的值必须是以下类型之一，否则会导致错误： 
string
number
boolean
integer
object
array
如果您希望模型在返回函数调用（ fc ）的同时输出思考过程（如 CoT、reasoning），请将这部分文本内容填写在 content 字段中。
如果您的训练样本不需要包含一个完整的函数调用流程，可以进行截断，但样本必须以一个 role 为 assistant 的消息结尾。

注意
Seed 2.0 260415 以上模型，RL 强化学习 rollout 过程的推理默认仅支持 thinking disable，不支持设置此项。
不同模型深度思考能力可配置的枚举值不同，详细信息请参见 开启/关闭深度思考。
enabled 表示强制模型进行思考，此时模型rollout过程预期会输出reasoning_content
disabled 表示强制模型不进行思考, 此时模型rollout过程预期不会输出reasoning_content。auto 表示允许模型根据问题自主判断是否需要思考，复杂问题进行思考，简单问题直接回答。custom 表示训练的数据预处理过程不就对 reasoning_content 内容做任何的校验与处理，在训练过程中，会按模型配套的 chat template 对数据进行处理。以 qwen 为例 ，样本内的 content 和reasoning_content 会使用 https://huggingface.co/Qwen/Qwen3-32B/blob/main/
tokenizer_config.json#L230 所示 chat template 逻辑进行处理。在推理时也需要使用custom type以及和训练相同的reasoning_content。
对于上述格式要求，存量数据集可参考 数据集 Thinking 字段处理工具 进行格式转换。
