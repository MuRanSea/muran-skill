7.1.1 套餐概览
方舟 Coding Plan 是为开发者量身定制的订阅服务，助力高效编码开发。
核心优势
支持主流模型：不仅支持主流大语言模型，还支持 Embedding 向量化模型，涵盖 Doubao SeedEvolving、Doubao Seed 2.0 系列、GLM 系列、MiniMax 系列、Kimi 系列、DeepSeek 系列、DoubaoEmbedding Vision 等模型。
兼容主流 AI 编程工具：支持 Claude Code、OpenCode、OpenClaw、TraeCode、Cline、Cursor、RooCode、Kilo Code 等主流编程工具，套餐额度共享，适配多种开发场景。
多种套餐适配不同场景：提供 Lite 与 Pro 套餐，适应普通与高强度编程场景。
稳定平稳运行：平台具有多租户隔离能力，调用高峰不会明显降速，TPM 满足正常开发需求。方舟 Coding 开发者交流群

套餐 适用场景
Lite 套餐 中等强度的开发任务，适合大多数开发者。
Pro 套餐 复杂项目开发，适合高强度工作的开发者。
实际可用量会因项目复杂度、代码库规模、是否启用自动接受、是否开启 thinking 等因素而有所不同。套餐用量信息可在 开通管理页面 查看。
有效期
套餐有效期以自然月为单位，自购买成功当日开始计算。1 个月套餐有效期示例：01.31日订购成功，02.28日 23:59 到期（非闰年）。
额度刷新规则
套餐额度在时间周期内耗尽后，需要等待下一个周期自动恢复额度，不会消耗其他资源包或账户余额。每5小时限额：根据首次请求发生时间，以 5 小时为周期定时刷新限额。
周限额：每周一 00:00:00 重置周限额。
月限额：每订阅月第 1 日 00:00:00 重置月限额。
额度使用限制
同一订阅套餐可在所有支持的工具中使用，额度共享。
套餐额度仅在 AI 编程或 AI 智能体等工具中生效，不可用于 API 调用。在非本服务支持的工具或场景中使用方舟 Coding Plan 权益对应的 Base URL 和 API Key 有可能被识别为滥用/违规，会导致订阅停用或账号封禁。
