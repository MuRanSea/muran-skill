8.1.7.1 限时邀请活动
方舟 Coding Plan 是为开发者打造的 AI 编程订阅套餐，点击前往活动 。
模型与工具自选 ：支持在 Claude Code、OpenCode、Cursor 等主流编程工具中，选用 Doubao SeedCode、Doubao Seed 2.0 系列、GLM 系列、MiniMax 系列、Kimi系列、DeepSeek 系列、DoubaoEmbedding Vision 等模型，也可开启 Auto 模式，根据场景选择最优模型。
限时邀请有礼 ：邀请好友成功订阅，好友可享 9.5 折优惠；您也可获得 5% 的代金券奖励，上不封顶。点击邀请好友 。
本活动中，邀请人可获得代金券奖励，奖励上不封顶，被邀请人将获得首单限时叠加优惠奖励。本文为您详细介绍 限时邀请活动 。
活动时间
2026.05.19 - 2026.11.19
活动入口
单击前往活动 ，立即邀请。
邀请者福利
邀请人成功邀请好友（即“受邀用户”）完成首单有效支付后，可获得代金券奖励：
奖励计算： 
每成功邀请 1 名有效好友，邀请人即可获得该好友首单实际支付金额的 5% 作为代金券奖励。邀请人数无上限，奖励多邀多得。
实际支付金额定义：指被邀请人首单订阅时，最终实际支付的现金金额。
代金券使用规则： 
性质：代金券是平台提供的优惠权益，不可提现、转让或找零。
抵扣范围：方舟 Coding Plan Pro 套餐与方舟 Coding Plan Lite 套餐。
有效期：发放即日起至2027.5.19，逾期自动作废。
被邀请者福利
受邀用户通过有效的邀请链接或邀请码完成方舟 Coding Plan 任意套餐的首次订阅时，可享受首次订阅订单应付金额 9.5 折的叠加优惠。
适用对象与条件：受邀用户从未购买过任何方舟 Coding Plan 套餐。一旦用户创建邀请码，即成为“邀请人”，将无法再作为“被邀请人”享受首单折扣，但“被邀请人”可以作为新的“邀请人”邀请其他人。每个用户仅可以以受邀用户身份享受一次 9.5 折叠加优惠。
强烈建议：9.5 折叠加优惠适用于整个首单订单。因此，一次性订阅多月套餐，相比订阅单月并自动续费更为划算。

邀请关系的绑定
邀请好友：点击活动页上的邀请好友按钮，即可生成专属邀请链接与邀请码。当好友点击您的专属链接或通过邀请码完成登录（或注册）时，双方邀请关系即绑定。
获取奖励：被邀请人须在本活动有效期内完成首单支付，方可计为一次有效邀请，作为计算邀请奖励的依据。
注意：此绑定关系以首次绑定为准，作为后续计算邀请奖励的唯一依据。
特别说明
邀请关系以受邀用户点击专属链接或填写邀请码完成登录（或注册）为准，系统记录为唯一凭证。平台将综合账号、设备、支付等信息判定用户身份合理性。任何作弊行为（如批量注册、虚假支付等）将导致所有相关奖励无效。
平台可根据运营情况调整或终止本活动，并于页面公告。在法律允许范围内，本规则的最终解释权归平台所有。
若活动终止，对于活动终止前已建立的邀请关系，被邀请人需在活动公告的终止日期前完成支付方可生效，对于已发放至用户账户的代金券，其相关权益将予以保障。
