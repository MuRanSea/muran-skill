配置 Claude Code
需要配置的信息
如您熟悉 Claude Code、使用 CC Switch 等配置工具，或本地已有配置，可直接使用以下信息完成配置。ANTHROPIC_BASE_URL： https://ark.cn-beijing.volces.com/api/coding 。
ANTHROPIC_AUTH_TOKEN：获取API Key 。
ANTHROPIC_MODEL：配置 Model Name（实时切换模型）或 ark-code-latest （控制台切换模型）。模型信息参见 支持模型 。
注意
若您本地已有Claude Code配置（如终端启动命令.bashrc/.zshrc等），可能因为配置冲突导致Claude Code 不生效，可以尝试备份并清理本地配置后再次运行。

方式 1：一键配置（推荐）
Ark CLI 是火山方舟平台官方命令行工具。使用 ArkCLI Helper 可快速完成 Claude Code 配置。安装 Ark CLI。
环境要求：Node.js 18 或更新版本。支持 macOS、Linux、Windows。
登录 Ark CLI。
根据界面提示选择登录方式，推荐选择 火山 SSO（浏览器登录） ，在浏览器中完成授权即可。运行 ArkCLI Helper。
根据界面提示完成以下配置：
选择 Profile： coding-plan_cn-beijing_personal 。
选择默认 model：按需选择。
选择 AI Agent： Claude Code 。
配置完成后，Claude Code 会自动识别配置的模型。启动 Claude Code 即可使用。
方式 2：手动配置
新建 ~/.claude/settings.json 。Windows 路径为 %USERPROFILE%\.claude\settings.json 。将以下配置写入文件，并替换占位符：
<ARK_API_KEY> ：替换为您的 API Key 。
<MODEL_NAME> ：替换为要使用的模型名称，如 ark-code-latest 。模型信息参见 支持模型 。npm install -g @volcengine/ark-cli@latest

使用 Claude Code
进入项目目录，执行 claude 命令，启动 Claude Code。
选择信任当前文件夹，允许 Claude Code 访问文件夹中的文件。
输入 /status ，确认模型状态。
在 Claude Code 中输入问题，开始对话。
更多使用方法参见 Claude Code 官方快速入门 。
