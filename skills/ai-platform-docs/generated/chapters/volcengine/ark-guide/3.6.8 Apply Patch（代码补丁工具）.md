3.6.8 Apply Patch（代码补丁工具）
apply_patch 工具适用于让模型以结构化补丁格式生成文件修改方案。开发者可以通过 Responses API 调用该工具，或在 Codex 中使用该工具，让模型对指定文件执行创建、更新或删除操作，并根据返回的补丁结果继续后续流程。
适用场景
apply_patch 工具适用于以下场景：
批量代码改写：例如重命名函数、统一替换旧接口调用方式、批量修正文档或配置文件中的固定格式。
机械化重构：例如拆分文件、补充样板代码、批量插入测试桩或模板化内容。
自动生成修改方案：例如根据用户描述直接生成可执行的补丁内容，再由业务侧执行补丁并回传结果。
支持的接入场景
apply_patch 工具支持通过 API 直接接入，也支持在 Codex 中使用。
Codex 配置要求
要在 Codex 中触发 apply_patch 自定义工具形态，需要配置以下两个文件。
