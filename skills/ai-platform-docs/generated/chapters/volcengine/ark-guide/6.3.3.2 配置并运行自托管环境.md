6.3.3.2 配置并运行自托管环境
本文介绍如何从零配置自托管环境（Self-hosted Environment），选择 Go、Python 或 Java SDK 启动Worker，并完成一次完整的 Session 工具执行。
你将完成什么
在控制台创建 self_hosted 类型的环境
为 Worker 配置并安全保存 API Key
选择 Go、Python 或 Java SDK，在企业主机启动 Worker
创建绑定自托管环境的 Session
发送用户消息，让 Agent 在企业主机执行工具
验证工具执行结果、Session 终态和 Worker 状态
核心概念
工作流程
以下是自托管环境端到端的工作流程：
企业管理员创建自托管 Environment，并为 Worker 准备 API Key。
企业运维人员在企业主机启动 Worker，Worker 开始轮询 Work Queue。
业务应用使用业务 API Key 创建 Session，建立事件流后发送用户消息。
方舟控制面生成 Work Item，Worker 领取并 Ack。
Worker 在企业 Sandbox 中执行工具调用（Bash、文件读写、自定义工具）。
Worker 将 Tool Result 回传方舟，驱动下一轮推理。
重复步骤 5-6，直到 Session 进入 idle 或终态。
Worker 完成 Work Item，继续轮询。

常驻 Worker
适用于 VM、独立容器或已有隔离节点直接执行。 EnvironmentWorker.run() / EnvironmentWorker.Run() 管理完整生命周期：Poll、Ack、Heartbeat、工具执行、结果回传和 Work Complete。
