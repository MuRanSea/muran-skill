方式 1：一键配置（推荐）
Ark CLI 是火山方舟平台官方命令行工具，支持在本地终端快速完成认证与资源管理，并可将能力安装到常用 AI Agent 中，降低手动配置的时间成本和出错风险。
安装 Ark CLI
环境要求：Node.js 18 或更新版本。支持 macOS、Linux、Windows。
登录 Ark CLI
根据界面提示选择登录方式，推荐选择 火山 SSO (浏览器登录) ，在浏览器中完成授权即可。一键配置 Grok CLI
运行 ArkCLI Helper，根据界面提示完成配置。
选择 Profile： platform_cn-beijing_accountwide 。
选择 Endpoint：按需选择要使用的推理接入点。
选择 AI Agent： Grok 。
配置完成后，Grok CLI 会自动识别配置的模型。启动 Grok CLI 即可使用。
说明
如果 ArkCLI 提示不支持 grok ，升级 ArkCLI 后重新配置。更多检查命令参见 ArkCLI Helper 命令参考 。
如果返回鉴权错误，核对 profile、API Key 和 Base URL 是否属于同一接入方式。
方式 2：手动配置
创建并编辑 ~/.grok/config.toml 文件，Windows 系统为 %USERPROFILE%\.grok\config.toml 。关注的配置信息如下：
<ARK_API_KEY> ：替换为您自己的 API Key 。
model ：更新为需要使用的 Model ID，模型列表参见 模型列表 。
npm install -g @volcengine/ark-cli@latest

如需将配置写入其他目录，设置 GROK_HOME 环境变量，配置文件路径为 $GROK_HOME/
config.toml 。
如果配置后仍使用旧模型，退出 Grok CLI，确认启动终端中的 GROK_HOME 与配置时一致，再重新启动。
使用 Grok CLI
在终端进入需要使用的项目目录，启动 Grok CLI。
输入以下需求，验证模型能够回复并读取工作区。如果返回当前项目的文件结构，说明 Grok CLI 已完成方舟接入。
[model."doubao-seed-evolving"]
model = "doubao-seed-evolving"
base_url = "https://ark.cn-beijing.volces.com/api/v3"
api_backend = "chat_completions"
api_key = "<ARK_API_KEY>"
name = "doubao-seed-evolving"
[models]
default = "doubao-seed-evolving"
