Base URL
不同的工具配置的 Base URL 根据兼容的协议会有不同：
兼容 Anthropic 接口协议工具：`https://ark.cn-beijing.volces.com/api/coding`
兼容 OpenAI 接口协议工具：`https://ark.cn-beijing.volces.com/api/coding/v3`
注意
请勿使用 `https://ark.cn-beijing.volces.com/api/v3` ：该 Base URL 不会消耗您的 Coding Plan 额度，而是会产生额外费用。

Kilo Code
安装 Kilo Code
打开 VSCode，在扩展市场搜索 Kilo Code 并安装，安装完成后选择信任发布者。
配置 Kilo Code
选择 Settings - Providers - Custom provider，配置以下信息。
Provider ID：填写 Provider 的唯一标识。
Display Name：填写 Provider 的显示名称。
API Provider： OpenAI Compatible
Base URL： https://ark.cn-beijing.volces.com/api/coding/v3
API Key：获取专属 API Key
Model ID：配置 ark-code-latest 或 Model Name，具体参见 核心配置 。
Model Name：填写模型的显示名称。
注意
Kilo Code 客户端 UI 迭代较为频繁，字段名称、顺序或数量可能随版本变化。若本文与客户端界面存在差异，以客户端实际提示为准。
配置完成后，即可在输入框中输入需求，与模型进行交互。
