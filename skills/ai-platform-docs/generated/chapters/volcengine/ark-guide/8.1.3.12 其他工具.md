Base URL
不同的工具配置的 Base URL 根据兼容的协议会有不同：
兼容 Anthropic 接口协议工具：`https://ark.cn-beijing.volces.com/api/coding`
兼容 OpenAI 接口协议工具：`https://ark.cn-beijing.volces.com/api/coding/v3`
注意
请勿使用 `https://ark.cn-beijing.volces.com/api/v3` ：该 Base URL 不会消耗您的 Coding Plan 额度，而是会产生额外费用。

接入Kilo Code
安装步骤
打开 VSCode，在扩展市场搜索 kilo code 进行安装，安装完成后选择信任发布者。
配置工具
选择Settings - Providers - Custom provider，然后配置以下信息。
Provider ID：Provider 的唯一标识，按需填写。
Display Name：Provider 的显示名称，按需填写。
API Provider： OpenAI Compatible （Coding Plan 接口兼容 OpenAI 标准）
Base URL： https://ark.cn-beijing.volces.com/api/coding/v3
API Key：获取API Key
Model ID：即要配置的模型名称，如 ark-code-latest 。支持的模型见 核心配置 。
Model Name：模型的显示名称，按需填写。
注意
Kilo Code 客户端 UI 迭代较为频繁，字段名称、顺序或数量可能随版本变化，本文内容以近期版本为准，仅供参考。若与您本地界面存在差异，请以客户端实际提示为准。
配置完成后，就可以在输入框中输入需求，与模型进行交互。
