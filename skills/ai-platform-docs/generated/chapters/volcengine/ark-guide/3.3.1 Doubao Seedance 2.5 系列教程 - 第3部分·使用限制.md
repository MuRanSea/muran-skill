保存时间
视频任务 ID 存在有效期（从 created_at 时间戳开始计算），超时后将自动失效。 
Draft 视频任务 ID：2026 年 10 月 28 日 10:00（UTC+8）及之后创建的 Draft 视频任务 ID 有效期为14 天，此前创建的 Draft 视频任务 ID 有效期仍为 7 天。超出有效期后，无法使用该 Draft 视频生成正式视频。
其他视频任务 ID：有效期均为 7 天。
视频 URL：保存 24 小时（超时后无法访问），下载次数上限为 100 次，请及时下载或转存。限流说明
同一主账号下，使用同一模型（不区分版本）的请求受到以下限制。超过对应限制会返回 “429: 'TooMany Requests'” 错误。
模型维度的限流
RPM（Requests Per Minute） ：每分钟允许创建的视频生成任务数上限。超过上限时，创建任务请求将因触发限流而失败。
最大并发任务数：同一时刻可处于处理状态的任务数上限。达到上限后，新创建的任务将进入队列等待处理。
非推理 API 请求频率限制
QPS（Queries Per Second） ：每秒允许的请求数上限。超过上限时，任务请求将因触发限流而失败。◦
