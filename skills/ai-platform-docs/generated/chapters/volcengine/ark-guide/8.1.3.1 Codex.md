Base URL
不同的工具配置的 Base URL 根据兼容的协议会有不同：
兼容 Anthropic 接口协议工具：`https://ark.cn-beijing.volces.com/api/coding`
兼容 OpenAI 接口协议工具：`https://ark.cn-beijing.volces.com/api/coding/v3`
注意
请勿使用 `https://ark.cn-beijing.volces.com/api/v3` ：该 Base URL 不会消耗您的 Coding Plan 额度，而是会产生额外费用。

在命令行界面，执行以下命令安装 Codex CLI。
安装结束后，执行以下命令检查版本。
配置 Codex CLI
方式 1：一键配置（推荐）
Ark CLI 是火山方舟平台官方命令行工具，支持在本地终端快速完成认证与资源管理，并可将能力安装到常用 AI Agent 中，降低手动配置的时间成本和出错风险。
安装 Ark CLI
环境要求：Node.js 18 或更新版本。支持 macOS、Linux、Windows。
npm i -g @openai/codex
Bash
codex --version
Bash
登录 Ark CLI
根据界面提示选择登录方式，推荐选择 火山 SSO (浏览器登录) ，在浏览器中完成授权即可。一键配置 Codex
运行 ArkCLI Helper，根据界面提示完成配置。
选择 Profile： coding-plan_cn-beijing_personal 。
选择默认 model：按需选择。
选择 AI Agent： Codex 。
配置完成后，Codex 会自动识别配置的模型。启动 Codex 即可使用。

env_key ：设置的是环境变量名称，请不要直接修改 ARK_API_KEY ，您需要在下一步设置该环境变量的值。

使用 Codex 的 Web Search 功能
说明
在 Coding Plan 场景下，通过 Responses API 接入的 Codex 也可原生使用 Web Search 功能。使用豆包搜索承接的 Web Search 会额外发起大模型 API 请求，对搜索结果进行总结。使用前需前往方舟控制台 > 开通管理 > 应用组件库 > 豆包搜索启用并开通豆包搜索 Custom 版服务，否则将无法使用 Web Search 功能。
完成配置后，按以下步骤在 Codex 使用 Web Search 功能。
登录方舟控制台，打开 应用组件库 > 豆包搜索 标签页。
在豆包搜索 Custom 版的操作列中点击开通服务。
在 Codex 中直接提问，例如"GitHub 最近有哪些热门开源项目"。
