使用 Codex 的 Web Search 功能
说明
在 Coding Plan 场景下，通过 Responses API 接入的 Codex 也可原生使用 Web Search 功能。使用豆包搜索承接的 Web Search 会额外发起大模型 API 请求，对搜索结果进行总结。使用前需前往方舟控制台 > 开通管理 > 应用组件库 > 豆包搜索启用并开通豆包搜索custom版服务，否则将无法使用 Web Search 功能。
完成配置后，按以下步骤在 Codex 使用 Web Search 功能。
登录方舟控制台，打开 应用组件库 > 豆包搜索 标签页。
在豆包搜索 Custom 版的操作列中点击开通服务。
在 Codex 中直接提问，例如"GitHub 最近有哪些热门开源项目"。
