二、配置 Codex CLI
方式 1：自动化助手（推荐）
ArkCLI Helper 是一个编码工具助手，支持快速配置选择的工具接入 Coding Plan。安装并运行该助手，根据界面提示操作可自动完成工具配置，降低手动配置的时间成本和出错风险。
注意
ArkCLI Helper 是基于 Ark Helper 升级演进的工具配置服务，相关能力将持续在 ArkCLI Helper 上迭代更新。建议优先使用 ArkCLI Helper 完成工具配置。
ArkCLI Helper 支持 macOS、Linux、Windows 系统。
安装 Ark CLI。
npm i -g @openai/codex
Bash
codex --version
Bash
登录 Ark CLI。
根据界面提示选择登录方式。若之前已登录过 arkcli，会沿用上次选择的配置；如需重新选择，请先执行 arkcli config reset 后再运行 arkcli auth login 。首次登录时，按提示完成以下配置：选择项目（Project） ：可按需选择，或默认选择账号全部资源。
选择消费模式（Type） ：选择 coding-plan 。
运行 ArkCLI Helper，根据界面提示完成 Codex 的配置。
在命令行界面输入 arkcli helper 命令，启动 ArkCLI Helper。
选择要配置的 Plan profile：选择 coding-plan_cn-beijing_personal (Coding Plan) 。选择默认 model：按需选择。
选择要配置的 AI Agent： Codex 。
# 1. 通过 NPM 安装
npm install -g @volcengine/ark-cli@latest
# 2. 验证安装
arkcli --version
Bash
arkcli auth login
Bash

使用 Codex 的 Web Search 功能
说明
在 Coding Plan 场景下，通过 Responses API 接入的 Codex 也可原生使用 Web Search 功能。使用豆包搜索承接的 Web Search 会额外发起大模型 API 请求，对搜索结果进行总结。使用前需前往方舟控制台 \> 开通管理 \> 应用组件库 \> 豆包搜索启用并开通豆包搜索custom版服务，否则将无法使用Web Search 功能。
完成配置后，按以下步骤在 Codex 使用 Web Search 功能。
登录方舟控制台，打开 应用组件库 > 豆包搜索 标签页。
在豆包搜索 Custom 版的操作列中点击开通服务。
在 Codex 中直接提问，例如"GitHub 最近有哪些热门开源项目"。
错误码
在编程工具中使用 Coding Plan 套餐时可能会遇到报错，您可以根据错误信息查看对应的报错场景并定位问题，具体可参考错误码 。
