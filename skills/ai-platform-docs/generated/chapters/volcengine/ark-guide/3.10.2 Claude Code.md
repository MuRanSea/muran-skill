使用 Claude Code 的 Web Search 功能
说明
Claude Code 通过兼容 Anthropic Messages 接口协议的服务调用豆包搜索能力。
调用 Web Search 工具时，大模型可能会发起额外的 API 请求来总结搜索结果，因此会消耗额外的 token。
完成配置后，按以下步骤在 Claude Code 使用 Web Search 功能。
登录控制台，打开 应用组件库 > 豆包搜索 标签页。
在豆包搜索 Custom 版的操作列中点击开通服务。
在 Claude Code 中直接提问，例如"GitHub 最近有哪些热门开源项目"。

接入 MCP Server 与 Skill
若内置工具未覆盖您的使用场景，可在 Claude Code 中接入二方、三方 MCP Server 与 Skill，扩展模型可用的能力。
获取 MCP Server
二方：访问 智能体工具商店 ，获取火山引擎生态内的 MCP 工具（如巨量千川、知识库等），在MCP 详情页获取服务地址与鉴权信息。
三方：接入其他 MCP 市场提供的 MCP Server，或自行部署开源 MCP Server。
注意
请从可信来源获取 MCP Server，其安全性与稳定性由提供方负责，接入前请确认其权限范围符合您的预期。
配置 MCP Server 与 Skill
接入 MCP Server：执行以下命令添加（以 stdio 类型为例）。
添加完成后，可执行 claude mcp list 查看已接入的 MCP Server。更多说明（如 HTTP/SSE 类型、作用域管理）参考 Claude Code 官方文档 。
接入 Skill：将 Skill 目录放入 ~/.claude/skills/ （个人全局）或项目下的 .claude/skills/ 目录即可。更多说明参考 Claude Code Skills 说明 。
