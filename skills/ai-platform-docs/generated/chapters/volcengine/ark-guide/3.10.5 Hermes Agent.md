方式 1：一键配置（推荐）
Ark CLI 是火山方舟平台官方命令行工具，支持在本地终端快速完成认证与资源管理，并可将能力安装到常用 AI Agent 中，降低手动配置的时间成本和出错风险。
安装 Ark CLI
环境要求：Node.js 18 或更新版本。支持 macOS、Linux、Windows。
登录 Ark CLI
根据界面提示选择登录方式，推荐选择 火山 SSO (浏览器登录) ，在浏览器中完成授权即可。一键配置 Hermes Agent
运行 ArkCLI Helper，根据界面提示完成配置。
选择 Profile： platform_cn-beijing_accountwide 。
选择 Endpoint：按需选择要使用的推理接入点。
选择 AI Agent： Hermes Agent 。
配置完成后，Hermes Agent 会自动识别配置的模型。启动 Hermes Agent 即可使用。
方式 2：手动配置
按量计费模型服务兼容 OpenAI 接口协议，支持 Responses API、Chat API。推荐使用 Responses API 的配置，推理效果更好。
Responses API
使用 Responses API，需要配置 api_mode: codex_responses 。
执行以下命令配置 Hermes Agent，其中需要将 <ARK_API_KEY> 替换为您的 API Key ，并将 
<MODEL_ID> 替换为需要使用的 Model ID。
npm install -g @volcengine/ark-cli@latest
arkcli --version
Bash
arkcli auth login

arkcli helper
