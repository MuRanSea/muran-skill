8.1.4.2 记忆增强-Embedding模型
方舟 Coding Plan 提供 Embedding 模型，可以为工具提供语义向量能力，将对话、文档与任务信息等转换为高维向量表示，实现基于语义相似度的高效检索。
相比传统关键词匹配，Embedding 检索在信息量大、对话长、资料分散的场景下，能够更准确地召回相关内容，显著降低遗漏与误判。同时，Embedding 为记忆检索、知识库问答与工具调用提供统一的语义检索层，帮助工具在不增加主模型推理成本的前提下，提升跨轮次上下文追踪能力与整体效果。核心配置
在 Coding Plan 中使用 Embedding 模型时，需要的核心配置如下：
支持的 Embedding 模型： doubao-embedding-vision （对应模型 doubao-embedding-vision-251215）
注意
建议固定使用同一版本的 Embedding 模型，请勿混用不同版本。
专属 Base URL： https://ark.cn-beijing.volces.com/api/coding/v3 （兼容 OpenAI 接口协议）API Key：获取 API Key
配置 Embedding 模型
注意
Embedding 模型与其他模型一致，均会消耗套餐额度，按模型调用次数进行估算。
OpenClaw
OpenClaw 支持配置 Embedding 模型，解决大模型原生记忆有限、易产生幻觉、无法适配私有数据的问题，从而提升模型在处理复杂任务时的准确性和可靠性。
前提条件：已完成 OpenClaw 的安装与配置，步骤参见安装和配置 OpenClaw。
选择以下任一方式配置 Embedding 模型。
Web UI 方式
执行以下命令打开 Web UI。
在左侧菜单栏选择配置 - All Settings - Raw，在 agents.defaults 节点下增加 memorySearch 相关配置信息，增加的配置信息如下。其中需要将 <ARK_API_KEY> 替换为您自己的 API Key 。
