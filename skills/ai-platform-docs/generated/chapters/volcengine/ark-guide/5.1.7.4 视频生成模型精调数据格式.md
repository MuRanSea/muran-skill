5.1.7.4 视频生成模型精调数据格式
本文介绍视频生成模型进行 SFT 精调时的数据集格式，涵盖 Seedance 1.0 的格式说明、样例及参数范围。注意
精调 JSONL 文件绝对路径不可包含以下特殊字符： * 、 ? 、 [ 、 ] 。
视频生成模型输入素材的图片、视频、音频要求，请参见全模态输入 。
支持模型
SFT 精调
Seedance 1.0
格式示例
Seedance 1.0 与 Seedance 2.0 均采用 messages 格式，不支持旧版 output.content.video_url 顶层结构。每条样本必须包含 1 个 user 消息和 1 个 assistant 消息，并确保单个样本独占一行。
格式说明
为便于展示各个字段关系，将 JSONL 格式文件的一条数据展开，如下：
模型系列 精调方法 支持的数据场景
Doubao Seedance 1.0 SFT 文生视频、图生视频
{"messages":[{"role":"user","content":[{"type":"text","text":"生成一段小狗在草地上奔跑的视频"}]},
{"role":"assistant","content":[{"type":"video_url","video_url":{"url":"tos://bucketname/video/dog_run.mp4"}}],"loss_weight":1.0}]}
