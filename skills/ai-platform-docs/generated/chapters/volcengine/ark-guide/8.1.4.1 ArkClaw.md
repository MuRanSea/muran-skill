8.1.4 专属权益
8.1.4.1 ArkClaw
ArkClaw 是火山引擎提供的云端 AI 智能体（Agent）服务，能帮助您 一键云端部署 OpenClaw， 享有一对一专属 ECS 资源 ，免去复杂配置、7 × 24 在线，让您零门槛使用 OpenClaw，还能无缝使用您订阅的火山方舟 Coding Plan，告别 Token 按量计费焦虑。
用户权益
已订阅方舟 Coding Plan Pro 套餐 的历史用户：可畅享 ArkClaw 提供的服务。 Coding Plan Pro 到期时，您创建的 ArkClaw 将被删除，其中的数据将为您 保留 24 小时 。（自 2026.05.18 12:00 起，CodingPlan Pro 套餐赠送 ArkClaw 活动已下线，新订阅用户不再赠送该权益。）
说明
自2026.05.18 12:00起， Coding Plan Pro 套餐赠送 ArkClaw 正式下线 ，具体规则参见 CodingPlan Pro 套餐赠送 ArkClaw 活动下线公告 。
自2026.03.24起， Coding Plan Lite 套餐 新购用户不再赠送 ArkClaw 的7日免费体验。
体验中心提供的 ArkClaw 服务要求一个主账号只能开通一个 ArkClaw，主账号下的子账号会共享数据记录。
步骤一：订阅方舟 Coding Plan
访问 方舟 Coding Plan 活动 ，单击“ 立即订阅 ”完成订阅操作。套餐介绍请参见套餐概览。步骤二：创建并使用 ArkClaw
登录火山方舟 体验中心 。
在左侧目录选择“Agent > ArkClaw”。
单击“ 立即开始 ”按钮，提交创建申请。
注意
使用子账号创建 ArkClaw 前，需先联系账号管理员为子账号添加权限 iam:CreateRole 、
iam:GetRole 、 iam:AttachRolePolicy 、 iam:ListAttachedRolePolicies ，权限配置完成后再单击 立即开始 创建 ArkClaw。
待创建成功后，即可在方舟中与 ArkClaw 进行对话。

使用技巧
查看并配置技能 ：支持查看、安装技能。
查看并配置定时任务 ：不仅支持实时解答问题，还支持完成设置的定时任务，主动发送提醒。配置消息渠道 ：支持与您的 IM 工具（例如飞书机器人、钉钉机器人）进行快捷集成。
配置人格 ：可以为 ArkClaw 定义人格，将其塑造为一个“有灵魂”的AI助手。
使用文件快传功能上传/下载文件 ：将 对象存储（TOS） 服务的TOS桶作为网盘，实现本地与云端的文件快速上传/下载操作。
管理 ArkClaw ：支持调整推理模型、重启、初始化 ArkClaw 服务等。
