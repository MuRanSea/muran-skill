6.2.6 模型支持的参数列表
本文介绍方舟 Managed Agents 在定义 Agent 或创建 Session 时可配置的 thinking 、 reasoning_effort 和 service_tier 参数，并列出当前各模型对思考与服务档位参数的支持情况。
Managed Agents 会根据目标模型版本分别校验 thinking 、 reasoning_effort 和 service_tier 。在创建Agent、更新 Agent 或临时覆写 Session 模型参数前，应先确认目标模型版本是否支持对应取值。注意
模型支持范围可能随模型版本发布而变化，各字段实际支持的取值和默认值以目标模型版本为准。调用时，如果传入当前模型不支持的取值，Managed Agents 会返回 400 InvalidParameter 。模型参数字段
默认值与校验规则
不设置 thinking 、 reasoning_effort 或 service_tier ，或在 Agent 定义中传空字符串时，ManagedAgents 会优先使用模型元数据中的默认值。
如果模型元数据未配置默认值，Managed Agents 不会向底层模型调用传递对应字段，由底层模型服务按默认策略处理。
支持模型与参数列表
表中取值后标注“默认”的值，表示该模型版本的默认值。
字段 可选取值 说明
model.id 模型 ID
Agent 使用的模型版本，例如 
doubao-seed-2-1-
pro-260628 。
model.thinking enabled 、 disabled 、 auto
思考开关，对应底层模型调用
的 thinking.type 字段。 auto
表示由模型判断是否思考，不
表示继承。
model.reasoning_effort
none 、 minimal 、 low 、
medium 、 high 、 xhigh 、
max
推理投入档位，对应底层模型
调用的 reasoning_effort 字
段。不同模型支持的档位不
同。
model.service_tier auto 、 default 、 fast
推理服务档位，对应底层模型
调用的 service_tier 字段。只
有部分模型版本支持 fast 快
速档位。
支持快速服务档位的模型
以下模型版本支持 service_tier: "fast" ：
doubao-seed-2-1-turbo-260628
doubao-seed-2-0-lite-260428
其他模型版本当前支持 auto 和 default ，默认值为 default 。
注意
service_tier: "fast" 只表示请求快速服务档位，不改变模型本身的能力边界。配置快速档位前，应确认业务能够接受对应模型版本的能力边界和推理参数限制。
