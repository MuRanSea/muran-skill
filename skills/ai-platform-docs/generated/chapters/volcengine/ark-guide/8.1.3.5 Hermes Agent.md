<Tab zoneid="Q88APiZftk" title="Responses API">
<TabTitle>Responses API</TabTitle>
<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">注意</div>
<div data-tips="true" data-tips-type="warning">使用 Responses API，需要配置 <code>api_mode: codex_responses</code>。</div>
执行以下命令配置 Hermes Agent，其中需要将 `<ARK_API_KEY>` 替换为您自己的 [API Key](https://ark.volcengine.com/region:cn-beijing/apikey)，可用的模型参见[模型配置](https://
ark.volcengine.com/region:cn-beijing/docs/ark/coding-plan-personal-ai-hermes文档指南 8. 订阅 [Agent/Coding Plan]agent#3a775131)。
```Bash
hermes config set model.provider custom
hermes config set model.base_url https://ark.cn-beijing.volces.com/api/coding/v3hermes config set model.api_key <ARK_API_KEY>
hermes config set model.default ark-code-latest
hermes config set model.api_mode codex_responses
```
配置完成后，配置文件 `~/.hermes/config.yaml` 内容如下。您也可以直接编辑该配置文件。```YAML
model:
 default: ark-code-latest
 provider: custom
 base_url: https://ark.cn-beijing.volces.com/api/coding/v3
 api_key: <ARK_API_KEY>
 api_mode: codex_responses
```

说明
如需使用 1MB 上下文，直接选择支持 1M 上下文的模型，Hermes Agent 会自动完成调整，无需手动配置。
若模型本身支持 1M 上下文，但 Hermes Agent 未正确识别，可在 ~/.hermes/config.yaml 中手动添加或修改相应模型的 context_length 字段： context_length: 1048576 。
