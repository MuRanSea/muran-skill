9.1.18 用量明细 CSV 解析最佳实践
本文介绍如何解析通过 查询用量明细导出任务状态 返回的 DownloadUrl 下载得到的 CSV 文件，重点说明切换时刻、生效规则、 charge_value_list 字段结构、兼容策略和多语言示例代码。
切换时刻与生效规则
GetRecordExportTask 每次调用按导出任务查询窗口的结束时间 EndTime 决定该任务的 CSV 使用哪种格式。切换时刻按调用用户分为两类：
2026 年 9 月 2 日前已产生调用的用户：切换时刻为 2026 年 9 月 15 日。
2026 年 9 月 2 日及以后新增调用的用户：切换时刻为 2026 年 9 月 2 日。
生效规则如下：
EndTime 早于或等于对应切换时刻：CSV 返回旧格式。
EndTime 晚于对应切换时刻：CSV 返回新格式。
任务提交后，该任务对应的 CSV 字段格式保持不变，不会在轮询期间发生切换。
CSV 格式变更说明
GetRecordExportTask 接口的请求参数、响应参数以及 DownloadUrl 的生成方式保持不变。本次变更仅影响通过 DownloadUrl 下载的 CSV 文件内容格式。
旧格式：18 列。
新格式：16 列。
删除字段： input_token_charge_item 、 output_token_charge_item 、 cache_hit_token_charge_item 。新增字段： charge_value_list 。该字段位于 volc_instance_id 之后、 timestamp 之前，用于统一返回各计费项信息。
其他字段：其余字段名称、顺序和含义保持不变。
新旧 CSV 对比
charge_value_list 字段说明
当导出任务对应的 CSV 使用新格式时， charge_value_list 字段的单元格值为 JSON 数组字符串，数组中的每个元素表示一个计费项。
示例如下：
旧格式（18 列）
... | volc_instance_id | input_token_charge_item | output_token_charge_item | 
cache_hit_token_charge_item | timestamp | pt_hour
新格式（16 列）
... | volc_instance_id | charge_value_list | timestamp | pt_hour
text
字段说明：
code ：计费项名称，对应旧格式中的 *_charge_item 字段值。
value ：整数计量值，例如 token 数或其他计费计量值。
scale ：整数缩放因子。
真实计费值为 value / scale 。
接入建议
如需同时兼容历史 CSV 与新 CSV：建议优先按列名判断；若读取链路依赖列位置，也可按列数 18 或 16 做分支处理。
当读取到 charge_value_list 字段时：需先执行 JSON 解析，再遍历数组元素获取各计费项的真实计费值。
若已有旧逻辑依赖 input_token_charge_item 、 output_token_charge_item 、 cache_hit_token_charge_item 三列：需迁移为读取 charge_value_list 后按 code 分发处理。
注意事项
该变更仅影响通过 DownloadUrl 下载的 CSV 文件内容，不影响 GetRecordExportTask 接口的请求参数、响应参数 schema 和 DownloadUrl 字段本身的返回逻辑。
建议在任务完成并拿到 DownloadUrl 后尽快下载文件。下载链接有效期为 12 小时，过期后需重新提交任务以获取新链接。
若业务需要长期兼容历史导出结果，建议同时保留旧格式和新格式的解析分支，不要只按固定列位置解析。

private static List<String> parseCsvLine(String line) {
List<String> result = new ArrayList<>();
StringBuilder current = new StringBuilder();
boolean inQuotes = false;
for (int i = 0; i < line.length(); i++) {
char ch = line.charAt(i);
if (inQuotes) {
if (ch == '"') {
if (i + 1 < line.length() && line.charAt(i + 1) == '"') {
 current.append('"');
 i++;
 } else {
 inQuotes = false;
 }
 } else {
 current.append(ch);
 }
 } else {
if (ch == '"') {
 inQuotes = true;
 } else if (ch == ',') {
 result.add(current.toString());
 current.setLength(0);
 } else {
 current.append(ch);
 }
 }
 }
 result.add(current.toString());
return result;
 }
