3.10.11 Kimi Code
本文介绍如何在 Kimi Code 中配置并使用方舟 按量计费模型服务。
前提条件
在配置工具前，需要 开通所需的模型服务 。
安装 Node.js 18 或更新版本 。
安装 Kimi Code
macOS/Linux
在命令行界面，执行以下命令安装 Kimi Code。
安装结束后，执行以下命令查看安装结果，若显示版本号则安装成功。
Windows
首次启动前安装 Git for Windows ，Kimi Code 使用其提供的 Git Bash 运行 shell 命令。在 PowerShell 中执行以下安装命令。
安装结束后，执行以下命令查看安装结果，若显示版本号则安装成功。
配置 Kimi Code
方式 1：一键配置（推荐）
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
Bash
kimi --version
Bash
irm https://code.kimi.com/kimi-code/install.ps1 | iex
PowerShell
kimi --version
Bash
Ark CLI 是火山方舟平台官方命令行工具，支持在本地终端快速完成认证与资源管理，并可将能力安装到常用 AI Agent 中，降低手动配置的时间成本和出错风险。
安装 Ark CLI
环境要求：Node.js 18 或更新版本。支持 macOS、Linux、Windows。
登录 Ark CLI
根据界面提示选择登录方式，推荐选择 火山 SSO (浏览器登录) ，在浏览器中完成授权即可。一键配置 Kimi Code
运行 ArkCLI Helper，根据界面提示完成配置。
选择 Profile： platform_cn-beijing_accountwide 。
选择 Endpoint：按需选择要使用的推理接入点。
选择 AI Agent： KimiCode 。
配置完成后，Kimi Code 会自动识别配置的模型。启动 Kimi Code 即可使用。
说明
如果 ArkCLI 提示不支持 kimi-code ，升级 ArkCLI 后重新配置。更多检查命令参见 ArkCLIHelper 命令参考 。
如果返回鉴权错误，核对 profile、API Key 和 Base URL 是否属于同一接入方式。
方式 2：手动配置
创建并编辑 ~/.kimi-code/config.toml 文件，Windows 系统为 %USERPROFILE%\.kimi-code\config.toml 。关注的配置信息如下：
<ARK_API_KEY> ：替换为您自己的 API Key 。
model ：更新为需要使用的 Model ID，模型列表参见 模型列表 。
npm install -g @volcengine/ark-cli@latest
arkcli --version
Bash
arkcli auth login
Bash
arkcli helper
Bash
说明
如需将配置写入其他目录，设置 KIMI_CODE_HOME 环境变量，配置文件路径为 
$KIMI_CODE_HOME/config.toml 。
如果配置后仍使用旧模型，退出 Kimi Code，确认启动终端中的 KIMI_CODE_HOME 与配置时一致，再重新启动。
使用 Kimi Code
在终端进入需要使用的项目目录，启动 Kimi Code。
输入以下需求，验证模型能够回复并读取工作区。如果返回当前项目的文件结构，说明 Kimi Code 已完成方舟接入。
default_model = "volcengine/doubao-seed-evolving"
[providers.volcengine]
type = "openai"
base_url = "https://ark.cn-beijing.volces.com/api/v3"
api_key = "<ARK_API_KEY>"
[models."volcengine/doubao-seed-evolving"]
provider = "volcengine"
model = "doubao-seed-evolving"
max_context_size = 1024000
