根据图片宽高像素计算得到 token 用量。不同模型的图片 token 用量估算逻辑如下。单图 token 范围参见通过 detail 字段（图片理解） 。
doubao-seed-2.0 及后续模型估算逻辑：
以传入 doubao-seed-2.0 模型的单图 token 最大值为 1280 为例，计算图片消耗的 token 数的逻辑如下：图片尺寸为 1280 px × 960 px ：理解这张图消耗的 token 为 1280×960÷1764=697 ，该值小于 1280，根据公式计算消耗 token 数为 697。
图片尺寸为 2560 px × 1440 px ：理解这张图消耗的 token 为 2560×1440÷1764=2090 ，该值大于1280，根据公式计算消耗 token 数为 1280。
这种情况会对图片进行压缩，即图片会丢失部分细节。譬如字体很小的图片，模型可能会无法识别文字内容。
图片数量说明
单次请求传入图片数量受限于模型上下文窗口。当输入过长，触发模型上下文窗口，信息会被截断。模型上下文窗口请参见模型列表 。
举例说明：
当图片总像素值大，使用的模型上下文窗口为 32k token，每张图片转为 1312 token ，单次请求可传入的图片数量为 32000 ÷ 1312 = 24 张。
当图片总像素值小，使用的模型上下文窗口为 32k token，每张图片转为 256 token，单次请求可传入的数量为 32000 ÷ 256 = 125 张。
