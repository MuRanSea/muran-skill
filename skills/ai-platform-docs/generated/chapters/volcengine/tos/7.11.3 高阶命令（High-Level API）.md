7.11.3 高阶命令（High-Level API）
高阶命令用于文件传输、对象与桶的日常管理，语义贴近人类操作习惯，可直接用于脚本化自动化。本章节介绍如何使用高阶命令组。

参数 说明
--recursive / --include-parent / --include / --

--checkpoint / --checkpoint-dir / --checkpointthreshold <20MB> 启用断点续传并配置检查点目录与触发阈值。
--batch-concurrency（默认 16）/ --listconcurrency（默认 4）/ --multipartconcurrency分别控制批量操作、列举及分片上传的并发数。
--recursive-list-mode <auto|flat|hierarchical>
设置递归列举模式。默认值为 auto 。
即 FNS 桶使用扁平列举，HNS 桶使用层级列
举；如需对 FNS 桶启用前缀级并发，可显式指
定 hierarchical 。
--bandwidth-limit <100MB> 限制传输带宽上限。
--overwrite-strategy <force|no-clobber|
newer> / --no-clobber 设置文件覆盖策略。
--content-type / --meta key=v#key2=v2 设置对象的 Content-Type 及自定义元数据。
--report-path / --report-failures-only / --
manifest-path / --no-manifest
配置操作日志的输出路径、过滤规则及清单文
件。
--progress / --no-progress
--progress-granularity <part|byte>
启用或禁用传输进度显示，设置进度统计粒度。
可按分片（ part ）或按字节（ byte ）计算。
远端路径以 / 结尾。 将被识别为目录标记。
