9.14.7.3.3 DeleteObjectTagging（Rust SDK）
delete_object_tagging 接口用于删除对象标签，本文介绍如何通过 Rust SDK 的 delete_object_tagging 接口删除对象标签。支持指定 versionId 删除版本标签。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
未携带 version_id 时，delete_object_tagging 默认作用于当前版本。
若目标版本已存在 delete_marker ，delete_object_tagging 返回 404 Not Found。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行delete_object_tagging 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:DeleteObjectTagging
