3.2.4 数据取回费用
访问低频存储、归档闪回存储等类型文件时，会产生数据取回费用。本文介绍数据取回费用的具体规则。
说明
本文仅介绍计费项详情，关于计费项的具体定价，请参见 TOS 定价详情 。
计费项 计费项介绍 计算公式（按量计费）
低频存储 - 数据取回费用
访问低频存储类型文件时产生
的费用，按数据取回量计费。
说明
通过 HTTP Range 等
方式读取文件中的
部分内容时，按照
取回的字节范围计
算取回量。
通过其他方式访问
低频存储文件时，
按照文件的实际大
小计算取回量。
低频存储数据取回费用 = 数据
取回量（GiB）× 取回单价
归档闪回存储 - 数据取回费用
访问归档闪回存储类型文件时
产生的费用，按数据取回量计
费。
说明
归档闪回存储类型的数
据可直接取回，不需要
解冻。
归档闪回存储数据取回费用 =
数据取回量（GiB）× 取回单
价
归档存储 - 数据取回费用
归档存储文件需要恢复取回后
才能访问，恢复取回时会产生
取回费用。
归档存储文件恢复时间在 1 分
钟内。
归档存储数据取回费用 = 数据
取回量（GiB）× 取回单价
冷归档 - 数据取回费用
计费项 计费项介绍 计算公式（按量计费）
冷归档文件需要恢复取回后才
能访问，恢复取回时会产生取
回费用。取回单价与恢复时间
有关，恢复时间越快，单价越
高。恢复时间说明如下：
快速：1~5 分钟
标准：2~5 小时
批量：5~12 小时
冷归档存储数据取回费用 = 数
据取回量（GiB）× 取回单价
深度冷归档 - 数据取回费用
深度冷归档文件需要恢复取回
后才能访问，恢复取回时会产
生取回费用。取回单价与恢复
时间有关，恢复时间越快，单
价越高。恢复时间说明如下：
标准：12 小时内
批量：48 小时内
深度冷归档存储数据取回费用
= 数据取回量（GiB）× 取回
单价
