5.11 操作审计
对象存储 TOS 支持通过操作审计功能，跟踪当前账号及子账号的访问行为，方便您查询与记录。操作审计说明
操作审计（CloudTrail）是火山引擎为客户提供的账号访问日志审计服务。通过操作审计，您可以跟踪主账号或访问控制内用户、角色等身份访问控制台及 OpenAPI 的行为。
当你创建火山引擎账号时，操作审计将立即启用，并将您账号内的访问行为记录在操作审计服务中，供您后续进行查询与跟踪。更多信息，请参见什么是操作审计 。
注意事项
操作审计当前支持记录 Bucket 基本的行为，暂不支持记录 Object 相关的行为。
支持记录的 API 操作如下。
分类 操作 说明
桶基础操作
CreateBucket 创建一个新的 TOS 桶。
DeleteBucket 删除已经创建的桶。
ListBuckets 查询当前请求用户拥有的所有
桶。
PutBucketStorageClass 为存储桶（Bucket）设置默认
存储类型。
GetBucketLocation 查询当前桶的地域信息。
生命周期规则
PutBucketLifecycle 为存储桶设置生命周期规则。
GetBucketLifecycle 获取指定存储桶生命周期规
则。
DeleteBucketLifecycle 删除存储桶设置生命周期规
则。
桶 ACL
PutBucketACL 设置桶的访问控制权限。
GetBucketACL 获取指定桶的访问控制权限
（ACL）。

PutBucketCORS
为存储桶设置跨域资源共享
CORS（Cross-Origin Resource
Sharing）规则。
GetBucketCORS
获取指定存储桶当前的跨域资
源共享 CORS（Cross-Origin
Resource Sharing）的配置规
则。
DeleteBucketCORS
删除指定存储桶的跨域资源共
享 CORS（Cross-Origin
分类 操作 说明
Resource Sharing）的配置规

桶清单
PutBucketInventory 为存储桶创建桶清单。
DeleteBucketInventory 删除某个存储桶中指定的清单
规则。
桶策略
PutBucketPolicy 修改或创建桶策略。
GetBucketpolicy 获取指定桶的桶策略。
DeleteBucketpolicy 删除存储桶的桶策略。
回源规则
PutBucketMirrorBack 设置的回源规则。
GetBucketMirrorBack 获取 Bucket 的回源规则。
DeleteBucketMirrorBack 删除一个 Bucket 的镜像回源规
则。
存储桶复制
PutBucketReplication 为存储桶设置跨区域复制规则
或同区域复制规则。
GetBucketReplication
获取指定存储桶当前的数据复
制进度、跨区域复制规则或同
区域复制规则。
DeleteBucketReplication 删除存储桶设置的跨区域复制
规则或同区域复制规则。
版本控制
PutBucketVersioning 为存储桶设置版本控制功能。
GetBucketVersioning 获取存储桶的版本控制状态。
静态网站托管
PutBucketWebsite 将 Bucket 设置为静态网站托管
模式，并设置跳转规则。
GetBucketWebsite 获取指定存储空间的网站配
置。
DeleteBucketWebsite 删除指定存储空间的网站配
置。
事件通知
PutBucketNotification 为存储桶设置事件通知规则。
GetBucketNotification 获取指定存储桶设置的事件通
知规则。
自定义域名

GetBucketCustomDomain 获取指定存储空间的自定义域
名配置。
分类 操作 说明
DeleteBucketCustomDomain 删除指定存储桶的单条自定义
域名配置。
