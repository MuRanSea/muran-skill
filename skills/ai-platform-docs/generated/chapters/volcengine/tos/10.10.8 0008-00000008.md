10.10.8 0008-00000008
问题描述
ACL 配置非法。
问题原因
用户设置桶或对象 ACL 时，ACL 配置缺少 Grantee 配置项。
问题示例
您进行桶 ACL 配置时，缺少 Grantee 配置项。
解决方案
参见 PutBucketACL 或 PutObjectACL ，，正确构造 ACL 配置，确保 Grantee 配置项存在。PUT /?acl HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
{ 
"Owner": { "ID": "test-cid" },
"Grants": [{
"Permission": "FULL_CONTROL"
 }]
}
