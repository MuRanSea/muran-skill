7.5.2 安装 TOS PyTorch Connector
本文介绍 TOS PyTorch Connector 的环境要求与安装。
环境要求
操作系统：Linux x86-64。
Python：3.8~3.13。
PyTorch：>=2.0 。
安装步骤
您需要在 Python 环境中成功安装 TOS PyTorch Connector 。
说明
安装过程中涉及相关依赖的下载和编译，可能较为耗时，请您耐心等待。
通过 pip 执行以下命令进行安装。
安装完成后，执行 pip show tostorchconnector 命令验证安装状态，出现如下信息代表安装成功。后续步骤
配置TOS PyTorch Connector
pip install -v tostorchconnector
