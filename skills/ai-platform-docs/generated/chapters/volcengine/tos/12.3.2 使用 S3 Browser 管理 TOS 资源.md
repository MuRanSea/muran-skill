12.3.2 使用 S3 Browser 管理 TOS 资源
本文介绍如何通过 S3 Browser 管理 TOS 资源。
背景信息
S3 Browser 是一款免费的 Amazon S3 Windows 客户端工具，火山引擎 TOS 兼容 S3 协议，所以您可以使用 S3 Browser 来管理您的 TOS 资源。
关于 S3 Browser 的更多信息，请参见 S3 Browser 官网 。
前提条件
请确保您已创建火山引擎账号，并已开通对象存储 TOS 服务，具体步骤，请参见开通 TOS 服务。请确保您已获取当前账号的 AccessKey ID 和 Secret Access Key 信息。
获取 TOS 的外网 S3 Endpoint 信息，详情请参见地域和访问域名（Endpoint）。
安装及配置步骤
说明
本文以 10.3.1 版本的 S3 Browser 为例，说明安装及配置 S3 Browser 的操作步骤。
下载 S3 Browser 软件，下载地址请参见 S3 Browser 。
下载完成后，双击 exe 文件，安装 S3 Browser。
打开软件，单击界面左上方的 Accounts > Add new account。
在弹出的 Add New Account 对话框中，设置如下参数。
参数 说明
Display name 设置显示的名称。
Account type 选择 S3 Compatible Storage。
REST Endpoint
设置 TOS 的 S3 域名，例如 tos-s3-cnbeijing.volces.com。TOS 支持的域名地址，请
参见地域和访问域名（Endpoint）。
Access Key ID 设置 AccessKey ID。
Secret Access Key 设置 Secret Access Key。
Encrypt Access Keys with a password 保持默认即可。
单击下方的 Advanced S3-compatiable storage settings，在弹出的对话框中，设置如下参数。设置完成后，单击 Add new account，保存配置信息。
说明
如果您设置的密钥信息拥有 ListBuckets 权限，则可以看到账号下的桶列表。
常用操作
上传文件
上传单个或多个文件，在界面上方单击 Files > Upload files(s) 。
上传单个或多个文件夹，在界面上方单击 Files > Upload folder(s) 。
下载文件
选中要下载的文件或文件夹，在界面上方单击 Files > Download，选择下载路径即可。
参数 说明
Use secure transfer（SSL/TLS） 保持默认即可。
参数 说明
Signature version 选择 Signature V4。
Addressing model 选择 Virtual hosted style。
Override storage regions 保持默认即可。
Region-specific endpoint(optional) 保持默认即可。
重命名文件
选中需要重命名的文件，在界面上方单击 Files > Rename。
在弹出的对话框中，输入新文件名后，单击 Rename。
挂载外部桶
说明
以下场景下，您可能需要挂载外部的存储桶：
账号 A 将自己的 BucketA 授权给账号 B 访问，账号 B 需要在 S3 Browser 里访问BucketA。账号 A 授权自己的 IAM 子用户 B 只能访问 BucketA，IAM 子用户 B 需要在 S3 Browser 里访问BucketA。
使用 S3 Browser 工具挂载外部桶的操作步骤如下所示。
在界面上方单击 Buckets > Add External Bucket。
在弹出的对话框中，输入外部桶路径，单击 Add External bucket。
