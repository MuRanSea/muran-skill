6.5.1.3.7 DeleteVectorBucketPolicy（TOS Vectors Python SDK）
delete_vector_bucket_policy 接口用于删除指定向量 Bucket 的访问策略，本文介绍如何通过 TOS VectorsPython SDK 的 delete_vector_bucket_policy 接口完成该操作。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名（Endpoint）。
为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
TOS Vectors Python SDK 支持使用临时访问凭证；也支持配置超时机制、重试策略等多种机制，您可以根据业务需求灵活设置，提升应用安全性，详细介绍，请参见 常见配置场景。
删除向量桶之前，要保证向量桶是空桶，即桶中的向量索引已经被删除掉。
权限说明
主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行
delete_vector_bucket_policy 操作，主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tosvectors:DeleteVectorBucketPolicy
代码示例
删除向量桶的 IAM Policy
# 删除向量桶的IAM Policy
import os
import tos
# 从环境变量获取 AK 和 SK 信息。
ak = os.getenv('TOS_ACCESS_KEY')
sk = os.getenv('TOS_SECRET_KEY')
# your endpoint 和 your region 填写Bucket 所在区域对应的Endpoint。# 以华北2(北京)为例，your endpoint 填写 https://tosvectors-cn-beijing.volces.com，your region 填写 cn-beijing。endpoint = 'Provide your endpoint'
region = 'Provide your region'
vector_bucket_name = 'Provide your bucket name'
# 从环境变量获取账户ID
account_id = os.getenv('TOS_ACCOUNT_ID')
try:
# 创建 VectorClient 对象，对向量的操作都通过 VectorClient 实现
 client = tos.VectorClient(ak, sk, endpoint, region)
# 删除向量存储桶的IAM策略
相关文档
关于 DeleteVectorBucketPolicy 的 API 文档，请参见 DeleteVectorBucketPolicy。
# vector_bucket_name: 向量存储桶名称，需要提前创建
# account_id: 账户ID，用于身份验证
 result = client.delete_vector_bucket_policy(
 vector_bucket_name=vector_bucket_name,
 account_id=account_id
 )
# 打印删除结果信息
print('成功删除向量桶IAM策略')
print('Request ID:', result.request_id)
print('Status Code:', result.status_code)
print('Response Headers:', result.header)
except tos.exceptions.TosClientError as e:
# 操作失败，捕获客户端异常，一般情况为非法请求参数或网络异常

# request id 可定位具体问题，强烈建议日志中保存

except Exception as e:
