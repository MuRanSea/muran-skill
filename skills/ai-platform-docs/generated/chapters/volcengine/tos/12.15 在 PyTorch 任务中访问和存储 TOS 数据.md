12.15 在 PyTorch 任务中访问和存储 TOS 数据
本文介绍如何在 PyTorch 任务中访问和存储 TOS 数据。
前提条件
在使用 TOS 之前，请确保您已注册火山引擎账号 并完成实名认证 。
请确保您已开通 TOS 服务并创建 TOS 存储桶，具体步骤，请参见快速入门。
必须使用 Linux x86-64 操作系统。
已安装 Python 3.8 ~ 3.11 版本。
环境准备
对接 TOS 前，请先在 Python 3.8 ~ 3.11 环境安装 PyTorch。更多信息，请参见 PyTorch 。注意
PyTorch 暂不支持 Python 3.12 及以上版本，不建议使用 Python 3.12 及以上版本。
安装完成后，您可以通过以下示例验证是否安装成功。
# 安装 torch 基本依赖
pip3 install torch torchvision
# 安装 torch lighting
pip3 install lightning
# 安装 torchdata
pip3 install torchdata==0.9.0

对接方式 说明
使用 tosfsspec 对接
tosfsspec 是火山引擎基于 fsspec 规范封装的
TOS 文件系统接口，用于将 TOS 桶对象封装为
Python 标准文件读写接口，可直接与
torchdata、PyTorch 等训练框架集成。更多信
息，请参见 tosfsspec 概述 。
使用 FSX 对接
FSX 支持将存储桶挂载到 Linux 系统作为本地
文件系统使用，适用于需要按照文件系统语
义使用存储桶中数据的场景，例如 AI 机器学
习场景下需要按照文件系统语义训练模型数
据。
FSX 客户端处于邀测状态，如需试用，请提交
工单 。
支持的运行环境及约束限制详情，请参见 FSX
概述 。
使用 S3 Connector 对接
S3 Connector 是 AWS 提供的 PyTorch 连接
器，用于增强 torchdata 提供的 S3 相关访
问能力，支持 map-style datasets、iterablestyle datasets 以及 checkpointing 接口。更多信息，请参见 S3-connector-for-PyTorch
。
当前仅支持 TOS FNS 桶，即扁平桶。更多信
息，请参见存储桶类型。

import torch
import torchvision
from s3torchconnector import S3Checkpoint, S3ClientConfig
if __name__ == '__main__':
 checkpoint_uri = 's3://bucketname/checkpoint/'
 region = 'your region'
 endpoint = 'your endpoint'
 s3_config = S3ClientConfig(force_path_style=False)
print('测试 checkpointing')
 checkpoint = S3Checkpoint(region=region,
 endpoint=endpoint,
 s3client_config=s3_config)
 model = torchvision.models.resnet18()
with checkpoint.writer(checkpoint_uri + 'epoch0.ckpt') as writer:
 torch.save(model.state_dict(), writer)
with checkpoint.reader(checkpoint_uri + 'epoch0.ckpt') as reader:
 state_dict = torch.load(reader)
 model.load_state_dict(state_dict)
