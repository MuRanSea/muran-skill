9.6.2 安装 Go SDK
本文介绍 TOS Go SDK 的下载地址及安装方式。
前提条件
安装 SDK 前，您需要先安装 Golang 1.13 及以上版本。您可以前往 Golang 官网 下载安装包。安装完成后，可使用 go version 命令，查看版本信息。
