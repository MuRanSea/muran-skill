问题描述
URL 参数 X-Tos-Policy 错误。
问题原因
URL 参数 X-Tos-Policy 中，桶相关的匹配条件配置数量不为 1。
问题示例
假设构造 X-Tos-Policy 参数的文本如下：
若用其构造 X-Tos-Policy 参数访问 TOS，则返回该错误。
解决方案
采用正确的方式构造 X-Tos-Policy 参数。具体操作，请参见携带查询参数 X-Tos-Policy 的 URL 预签名。
{
"conditions": [
{"bucket":"examplebucket"},
["eq","$bucket","examplebucket"]
]
}
