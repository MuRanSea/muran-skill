10.9.24 0007-00000304
问题描述
在生命周期规则中，存在多条 AbortIncompleteMultipartUpload 字段之间，其前缀有包含关系。问题原因
生命周期规则不支持多条 AbortIncompleteMultipartUpload 字段之间的前缀有包含关系。问题示例
解决方案
多条 AbortIncompleteMultipartUpload 规则的 prefix 不能重叠。
{
"Rules": [
{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"AbortIncompleteMultipartUpload": {
"DaysAfterInitiation": 1
}
},
{
"ID": "id1",
"Prefix": "prefix/1",
"Status": "Enabled",
"AbortIncompleteMultipartUpload": {
"DaysAfterInitiation": 1
}
}
]
}
JSON
