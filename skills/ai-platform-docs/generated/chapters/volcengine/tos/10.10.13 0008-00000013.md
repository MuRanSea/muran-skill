问题描述
ACL 配置非法。
问题原因
用户设置桶或对象 ACL 时， Type 字段取值为 Group 时， Canned 字段取值非 AllUsers 、AuthenticatedUsers 。
问题示例
您配置桶 ACL 时， Type 字段取值为 Group 时， Canned 字段取值非法。
解决方案
参见 PutBucketACL 或 PutObjectACL ，正确构造 ACL 配置，确保 Type 字段取值为 Group 时，Canned 字段取值合法。
PUT /?acl HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
{ 
"Owner": { "ID": "test-cid" },
"Grants": [{
"Grantee": {
"Type": "Group",
"Canned": "abc"
 },
"Permission": "FULL_CONTROL"
 }]
}
