5.10.3.2 日志分析操作
本文介绍日志分析功能的使用方式，涵盖开启日志分析、关闭日志分析等相关操作。
开启日志分析
日志分析支持以下几种开启方式，具体操作步骤如下：
return (<Tabs>
<Tab zoneid="Z2IYzvny3G" title="从数据洞察入口开启">
<TabTitle>从数据洞察入口开启</TabTitle>
1. 登录[对象存储控制台](https://console.volcengine.com/tos)。
2. 在左侧导航栏，单击**数据洞察**。
3. 在**数据洞察**页面左侧导航栏，单击**日志分析**。
4. 单击**看板配置**，在看板配置页面找到目标存储桶。
5. 单击目标存储桶**日志分析**列的开启按钮。
6. 在**开启日志分析**弹窗，单击**开启**。
</Tab>
<Tab zoneid="vMrQdKPckE" title="创建存储桶时开启">
<TabTitle>创建存储桶时开启</TabTitle>
1. 登录[对象存储控制台](https://console.volcengine.com/tos)。
2. 在左侧导航栏，单击**桶列表，** 在桶列表页面左上方单击**创建桶**。
3. 在**创建存储桶**页面，展开**高级设置**，打开**日志分析**开关。
 <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">说明 </div>
 <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">创建存储桶时的其他参数说明，请参见<a href="https://docs.volcengine.com/docs/6349/75024">创建存储桶</a>。 </div>
</Tab>
关闭日志分析
日志分析支持以下几种关闭方式，具体操作步骤如下：
<Tab zoneid="JDTrfEZNpG" title="已创建的存储桶开启">
<TabTitle>已创建的存储桶开启</TabTitle>
1. 登录[对象存储控制台](https://console.volcengine.com/tos)。
2. 在左侧导航栏，单击**桶列表**。
3. 在顶部导航栏，选择存储桶所属项目。
4. 在**桶列表**页面，单击目标桶名称。
5. 在左侧导航栏单击**日志管理**，在**日志管理**页面，单击**编辑**。
6. 打开日志分析的开关，单击**确定**。
</Tab>
</Tabs>
)
return (<Tabs>
<Tab zoneid="bdgD7zuPHi" title="从数据洞察入口关闭">
<TabTitle>从数据洞察入口关闭</TabTitle>
1. 登录[对象存储控制台](https://console.volcengine.com/tos)。
2. 在左侧导航栏，单击**数据洞察**。
3. 在**数据洞察**页面左侧导航栏，单击**日志分析**。
4. 单击**看板配置**，在看板配置页面找到目标存储桶。
5. 单击目标存储桶**日志分析**列的按钮，按钮置灰即可关闭日志分析。
</Tab>
<Tab zoneid="mEsOQa8d15" title="在存储桶内关闭">
<TabTitle>在存储桶内关闭</TabTitle>
1. 登录[对象存储控制台](https://console.volcengine.com/tos)。
设置日志保存时间
登录对象存储控制台 。
在左侧导航栏，单击桶列表。
在顶部导航栏，选择存储桶所属项目。
在桶列表页面，单击目标桶名称。
在左侧导航栏单击日志管理，在日志分析页面，单击设置日志保存时间。
2. 在左侧导航栏，单击**桶列表**。
3. 在顶部导航栏，选择存储桶所属项目。
4. 在**桶列表**页面，单击目标桶名称。
5. 在左侧导航栏单击**日志管理**，在**日志分析**页面，单击**关闭关联日志**。
6. 在弹出的对话框中，单击**确定**。
</Tab>
<Tab zoneid="BTOdGnHFs2" title="相关操作">
<TabTitle>相关操作</TabTitle>
关闭日志分析后，日志主题不会自动删除。您可以在关闭关联日志前，先在日志服务删除日志主题，以避免关闭关联日志后继续产生日志费用。
在存储桶日志管理页面进行关闭关联日志的操作时，会弹出对话框提示该存储桶对应的日志项目 ID 和主题 ID，您可以根据 ID 删除该存储桶对应的日志主题。具体操作，请参见删除[日志主题](https://docs.volcengine.com/docs/6470/72004#.5Yig6Zmk5pel5b-X5Li76aKY)和[删除日志项目](https://docs.volcengine.com/docs/6470/72005#.5Yig6Zmk5pel5b-X6aG555uu)。
<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">注意</div>
<span id="4byltLIz"></span>
### <div data-tips="true" data-tips-type="warning">由于同一地域下所有桶共用一个主题，删除某个桶的主题后，会同时删除同一地域下其他桶的历史日志记录，详细介绍，请参见<a 
href="https://docs.volcengine.com/docs/6349/1338063">为什么删除某个桶的日志 topic 后，无法正常使用其他桶的日志功能</a>。</div>
</Tab>
</Tabs>
)
在弹出的对话框中，设置具体时间，单击确定。
说明 
自定义数据保存时间支持 1~3650 天。
