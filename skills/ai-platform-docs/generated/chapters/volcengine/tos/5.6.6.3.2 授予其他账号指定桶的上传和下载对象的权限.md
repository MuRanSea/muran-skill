5.6.6.3.2 授予其他账号指定桶的上传和下载对象的权限
本文档介绍如何授予其他账号指定桶上传和下载对象的权限。
场景说明
授权账号：其他账号（本文以 210000**** 为例）。
授权资源： bucketname1 存储桶。
动作：GetObject 和 PutObject
注意事项
权限配置后略有延迟，如果您配置的权限没有立即生效，建议您稍后重试。
操作步骤
登录对象存储控制台 。
在左侧导航栏，单击桶列表。
在顶部导航栏，选择存储桶所属项目。
在桶列表页面，单击目标桶名称。
在左侧导航栏，选择权限管理 > 存储桶授权策略管理。
根据需要选择授权方式。
可视化视图
单击创建策略。
在创建存储桶授权策略页面，选择自定义策略模板，然后单击下一步。
设置如下参数。
类别 参数 说明
基本配置
策略配置方式 无需手动配置，默认选择可
视化视图方式。
策略名称 设置策略名称。同一存储桶
内，策略名称不允许重名。
效力 效力
选择策略的作用效果，无需
手动配置。
允许（默认） ：说明该策
略创建的权限为接受请
求。
拒绝：说明该策略创建的
权限为拒绝请求。
被授权用户
授权用户 无需手动配置，默认选择指
定账号。
其他账号 选择其他主账号，输入其他
主账号 ID。
◦
◦
设置完成后，单击下一步。
确认策略无误后，单击确定。
JSON 视图
单击编辑，将以下内容复制到文本框中，单击确定。
类别 参数 说明
资源 资源范围 选择桶内对象，然后选择所
有对象。
动作
通用动作 可以不配置。也可以根据您
的需求选择需要授权的动
作，详细动作说明，请参见
桶策略支持的动作 。
桶动作
对象动作
选择 GetObject 和 
PutObject。 也可以根据您的
需求选择需要授权的动作，
详细动作说明，请参见对象
动作 。
操作策略
无需手动配置，默认选择包
含以上动作，表示允许用户
拥有执行指定动作的权限。
条件（可选） -
可以不配置。也可以单击添
加字段图标，设置您所需要
的条件及值。
关于条件的参数说明，请参
见条件说明 。

后续操作
按照本文完成授权后，其他账号可以通过以下方式对授权桶执行上传对象、下载对象的操作。使用 API 或 SDK 对授权桶执行上传对象、下载对象的操作。
在 TOS Browser 通过访问路径进入到授权桶，执行上传对象、下载对象的操作。
使用 tosutil 对授权桶执行上传对象、下载对象的操作。
注意
TOS 不支持跨账号列举桶，按照本文完成授权后，其他账号不支持在控制台对授权桶执行上传对象、下载对象的操作。
