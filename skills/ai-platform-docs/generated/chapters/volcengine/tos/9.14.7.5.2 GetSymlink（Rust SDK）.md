9.14.7.5.2 GetSymlink（Rust SDK）
get_symlink 接口用于获取软链接对象信息，本文介绍如何通过 Rust SDK 的 get_symlink 接口读取软链接指向的目标文件及版本号。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
symlink_target_key 给出 symlink 指向的目标文件路径，需结合 symlink_target_bucket 确定完整对象位置。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行get_symlink 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：
tos:GetObject
