5.3.7.2 桶 ACLs
您可以在 TOS 控制台通过创建账号授权，对 IAM 主账号授予当前桶的读写权限及桶 ACL（Access ControlList，访问控制列表） 的读写权限，从而管理存储桶及 ACL 的相应权限。授权后，被授权用户即可凭借自己的 AK/SK 信息访问该桶。
前提条件
配置桶 ACL 的账号必须是该桶的创建者，或拥有该桶 ACL 的写权限。
创建账号授权
登录对象存储控制台 。
在左侧导航栏，单击桶列表。
在顶部导航栏，选择存储桶所属项目。
在桶列表页面，单击目标桶名称。
在左侧导航栏，选择权限管理 > 桶ACLs，在桶ACLs页面，单击创建账号授权。
在弹出的对话框中，设置如下参数。
参数 说明 注意
账户 ID IAM 主账号的 ID 信息。 仅支持对主账号 ID 配置
ACL，不支持子账号。

创建公共访问权限
您可以通过以下步骤授予所有用户（包括匿名用户）权限。
注意
创建公共访问权限后，任意用户（包括匿名用户）均可不通过验证访问您的存储桶，为了保证您的文件安全性，请谨慎操作。
公共权限创建后只能编辑无法删除。
登录对象存储控制台 。
在左侧导航栏，单击桶列表。
在顶部导航栏，选择存储桶所属项目。
在桶列表页面，单击目标桶名称。
在左侧导航栏，选择权限管理 > 桶ACLs。
在桶ACLs页面，单击公共访问权限区域所有用户组操作列的编辑。
在弹出的对话框中，设置如下参数。
单击保存。
