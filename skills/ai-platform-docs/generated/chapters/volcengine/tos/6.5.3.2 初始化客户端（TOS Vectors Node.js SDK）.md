6.5.3.2 初始化客户端（TOS Vectors Node.js SDK）
初始化 TosVectorsClient 实例之后，您才可以向 TOS Vectors 服务发送 HTTP/HTTPS 请求。本文介绍Node.js SDK 的初始化方式。
背景信息
TOS Vectors Node.js 客户端提供了一系列接口用来与 TOS Vectors 服务进行交互，用来管理桶和向量等TOS Vectors 上的资源。初始化客户端时，需要带上 Access Key ID（AK）、Secret Access Key（SK） 和Region 等信息。在初始化时，您可以设置建立连接超时时间、超时重试次数和最大空闲连接数量等可选参数。

使用可选参数初始化
TOS Vectors Node.js SDK 提供了多个可选参数来自定义配置 TosVectorsClient，例如配置 STS、HTTP 请求超时时间、请求重试策略等。
以下代码展示如何自定义配置 TosVectorsClient 的 HTTP 连接超时时间，具体的配置场景请参见下文的配置超时机制。
常见配置场景
配置超时机制
import { TosVectorsClient } from '@volcengine/tos-sdk';
// 创建客户端
const client = new TosVectorsClient({
accessKeyId: process.env['TOS_ACCESS_KEY'], 
accessKeySecret: process.env['TOS_SECRET_KEY'], 
region: "Provide your region", // 填写 Bucket 所在地域。以华北2（北京)为例，则 "Provide your region" 填写为 cn-beijing。
endpoint: "Provide your endpoint", // 填写域名地址
});

您可以在初始化 TosVectorsClient 时，通过添加可选参数配置网络请求的超时时间。目前 TOS VectorsNode.js SDK 提供了以下超时参数用于 HTTP 请求的超时配置：
requestTimeout ：HTTP 请求超时时间，单位毫秒，默认值为 120000，即 120 秒。
connectionTimeout ：建立 HTTP 连接的超时时间，单位毫秒，默认值为 10000，即 10 秒。以下代码展示如何在初始化 TosVectorsClient 时配置超时时间。
配置重试策略
网络波动或短期 TOS Vectors 服务异常（例如返回 500 HTTP 状态码）等场景会导致请求 TOS 服务失败。针对此问题，SDK 内部提供了重试机制，根据设置的重试次数进行指数退避重试，默认重试次数为 3 次。幂等操作的接口在失败后会使用指数退避策略进行重试，非幂接口则直接抛出对应异常。您可以在初始化 TosVectorsClient 时，添加可选参数配置重试次数。
以下代码展示如何设置 SDK 的重试次数。
// 导入 SDK, 当 TOS Node.JS SDK 版本小于 2.5.2 请把下方 TosVectorsClient 改成 TOS 导入import { TosVectorsClient } from '@volcengine/tos-sdk';
const connectionTimeout = 10000;
const requestTimeout = 120000;
// 创建客户端
const client = new TosVectorsClient({
accessKeyId: process.env['TOS_ACCESS_KEY'], 
accessKeySecret: process.env['TOS_SECRET_KEY'], 
region: "Provide your region", // 填写 Bucket 所在地域。以华北2（北京)为例，则 "Provide your region" 填写为 cn-beijing。
endpoint: "Provide your endpoint", // 填写域名地址
 connectionTimeout,
 requestTimeout,
});
console.log(client);
