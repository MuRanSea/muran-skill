问题描述
配置的生命周期规则中， Transitions 字段的 Days 参数取值小于 0。
问题原因
配置的生命周期规则中， Transitions 字段的 Days 参数取值小于 0，要求其取值大于 0。问题示例
解决方案
设置 Days 的值大于 0。
{
"Rules": [{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"Transitions": [
{
"StorageClass": "IA",
"Days": -1
}
]
}]
}
JSON
