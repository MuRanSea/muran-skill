9.14.6.17.2 GetBucketRealTimeLog（Rust SDK）
get_bucket_real_time_log 接口用于查询存储桶的实时日志配置信息，返回角色、TLS 项目、主题、仪表盘 ID 及 TTL。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行get_bucket_real_time_log 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:GetBucketRealTimeLog
