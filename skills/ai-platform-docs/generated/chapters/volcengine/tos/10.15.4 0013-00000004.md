问题描述
静态网站配置非法。
问题原因
用户设置静态网站配置时， Protocol 字段取值非 http 或 https 。
问题示例
您进行静态网站配置时， Protocol 字段取值非 http 或 https 。
解决方案
参见 PutBucketWebsite ，正确构造静态网站配置，确保 Protocol 字段取值合法。
