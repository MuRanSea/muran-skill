本文介绍 TOS 支持的流控事件指标，流控事件告警通知示例。
流控事件指标
说明
事件指标分为限制阈值和汇报阈值，具体说明如下：
限制阈值：当前账号可以使用的 TOS 资源最大值。默认可使用的资源最大值的详细介绍，请参见约束限制。
汇报阈值：汇报阈值 = 限制阈值 × 0.8

Bash
参数 说明
AccountId 火山引擎账号 ID。
BucketName
存储桶名称。
说明
参数 说明
仅触发桶流控事件告警时，告警通知才
会返回 BucketName 。
PercentThresholdLevel 触发事件告警的流量值占流控限制阈值的百分
比。
QosPolicySid
流控策略名称。
说明
仅触发流控策略事件告警时，告警通知
才会返回 QosPolicySid 。
TrafficSource
触发流控告警的网络带宽类型，取值说明如下：
extranet ：外网带宽。
net_all ：总带宽，同时包含外网带宽和内网
带宽。
