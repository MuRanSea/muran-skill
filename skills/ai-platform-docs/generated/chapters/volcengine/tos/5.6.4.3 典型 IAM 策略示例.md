5.6.4.3 典型 IAM 策略示例
本文介绍常见的 IAM 策略内容，方便您直接选择使用。
授权策略
授予 IAM 用户某个存储桶 test 的所有权限
授予 IAM 用户某个存储桶 test 的只读权限
{ 
 "Statement": [
 {
 "Effect": "Allow",
 "Action": [
 "tos:*"
 ],
 "Resource": [
 "trn:tos:::test",
 "trn:tos:::test/*"
 ]
 }
 ]
 }
