5.15.3.3 查看视频信息
获取指定视频资源的元信息。本文介绍获取信息相关参数说明和使用示例。
计费说明
使用查看视频信息功能时，会产生查看视频信息费用、请求费用和流量费用。详细计费介绍，请参见数据处理费用 、请求次数费用和流量费用。
查看低频存储、归档闪回存储类型文件的视频信息时，会产生数据取回费用，按照查看后返回的内容大小进行收费，计费详情，请参见数据取回费用。
注意事项
查看视频信息功能支持的视频格式请参考媒体处理概述 相关使用限制。
参数说明
使用请求 URL 获取指定视频元信息时，您只需要在请求 URL 中增加 info ，无需设置其他请求参数。返回参数部分说明如下：
