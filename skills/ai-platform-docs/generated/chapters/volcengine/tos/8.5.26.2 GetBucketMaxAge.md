8.5.26.2 GetBucketMaxAge
功能描述
此接口用于获取存储桶（Bucket）的浏览器缓存有效期。
注意事项
请确保当前账号已具备 tos::GetBucketMaxAge 权限。
请求消息样式
请求参数和消息头
该请求使用的公共消息头，请参见公共参数。
请求元素
该请求不使用消息元素。
响应消息头
该请求返回公共响应消息头，请参见公共参数。
响应元素
**请求示例 **
GET /?max-age HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: GMT Date
Authorization: authorization string
JSON
