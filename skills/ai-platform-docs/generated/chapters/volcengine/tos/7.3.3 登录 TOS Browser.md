前提条件

使用账号登录 TOS Browser
您可以使用账号登录 TOS Browser，登录后，您将拥有账号对应的文件和文件夹权限。
注意
账号登录 TOS Browser 的有效期为 12 小时，过期后，系统将自动登出，您将无法执行任务，可能会中断正在进行中的任务，如果您有长时间执行任务的需求，建议您使用 AK 登录 TOS Browser。完成 TOS Browser 安装后，双击 TOS Browser 图标，打开登录界面。
在 TOS Browser 登录界面，单击帐号登录页签，单击登录。
浏览器默认会打开火山引擎控制台登录页面，在该页面输入账号和密码，单击立即登录。
登录火山引擎控制台后，TOS Browser 会自动获取账号信息，并进行自动登录。
说明
如果您登录时关闭浏览器，您可以在 TOS Browser 单击重新唤起浏览器登录，从而重新打开浏览器登录 TOS Browser。您也可以单击取消登录，然后重新使用账号登录 TOS Browser。
使用共享链接登录 TOS Browser
使用共享链接登录 TOS Browser 前，您需要提前获取共享链接。
注意
使用共享链接登录 TOS Browser 后，只拥有对应文件或文件夹的读权限。
共享链接的登录信息不支持保存在历史会话中。

单击删除，在弹出的对话

您可以通过控制台或 TOS Browser 创建共享链接，具体操作，请参见文件基本操作的分享文件和分享文件夹内容。
完成 TOS Browser 安装后，双击 TOS Browser 图标，打开登录界面。
在 TOS Browser 登录界面，单击共享链接登录。
输入共享链接，单击登录。
使用共享链接登录 TOS Browser 后，您可以选择多个文件，单击下载，批量下载文件。您也可以单击一键下载所有，下载所有文件。
使用授权码登录 TOS Browser
使用授权码登录 TOS Browser 前，您需要提前获取授权码。
说明
授权码可根据需求授予用户对应文件或文件夹的读写权限，相较于共享链接，其权限控制更为灵活和精细。详细介绍，请参加创建授权码。
授权码的登录信息不支持保存在历史会话中。
完成 TOS Browser 安装后，双击 TOS Browser 图标，打开登录界面。
在 TOS Browser 登录界面，单击授权码登录。
输入授权码，单击登录。
切换会话和语言
切换会话
您可以参考以下步骤，在使用过程中切换相应会话。
单击工具右上方的 图标。
在弹出的对话框中单击切换会话。
在切换会话对话框中，单击目标会话操作列的切换，即可切换至相应会话。
切换语言
TOS Browser 支持中文和英文，您可以根据需要切换语言。切换语言的操作如下：
完成 TOS Browser 安装后，双击 TOS Browser 图标，打开登录界面。
在 TOS Browser 登录页面右上角，单击 图标。
在设置对话框，单击系统设置。
选择语言，可选中文和 English，单击保存。
在提示对话框，单击立即重启，重启后即可使用对应语言。
使用 HTTP 代理
当服务器处于内网环境，且对外网络访问需通过统一出口时，您需要通过 HTTP 代理才能访问对象存储TOS。在 TOS Browser 使用 HTTP 代理的操作如下：
完成 TOS Browser 安装后，双击 TOS Browser 图标，打开登录界面。
在 TOS Browser 登录页面右上角，单击 图标。
在设置对话框，单击系统设置。
设置代理配置为自定义代理，填写代理地址和代理端口，单击保存。
在提示对话框，单击立即重启，使代理配置生效。
