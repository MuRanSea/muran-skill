7.7.3 配置与挂载
本文主要介绍在 Windows 上使用 tos-fsp 完成 TOS 存储桶首次挂载的关键准备、配置、启动、验证、只读挂载与正常卸载流程。
前提条件
在开始挂载前，请确认以下条件已满足：
已有可用的存储桶，确认存储桶所在地域与 endpoint 匹配，且本机网络可访问该 endpoint 。已准备好具有列举和读取权限的 AK/SK。 
使用临时凭证时，还需提供配套的 security_token ，三者缺一不可。
可写挂载需额外具备写入、修改元数据、完成及中止分段上传的权限；如需删除与重命名文件，还需删除与重命名权限。
首次读写建议挂载存储桶内独立前缀（如 windows-data/），避免误操作影响其他业务数据。如需验证只读访问，请提前在该前缀下放置一个内容已知的文件。
本地缓存目录须具备写入权限，并根据业务文件规模预留充足磁盘空间。
IAM 权限策略
在访问策略控制台 创建自定义策略，选择 JSON 编辑方式，将所有 YOUR_BUCKET 替换为实际存储桶名后，将策略授予客户端所使用的 IAM 用户。
以下 IAM 用户示例策略仅授权指定存储桶，不包含其他存储桶，无需填写 Principal 。
只读挂载策略
允许检查存储桶、列举目录和读取文件，挂载时需指定 -o ro 参数。
读写挂载策略
允许读取、写入、删除和重命名文件，以及清理异常分段上传任务，挂载时需指定 -o rw 参数。◦

权限配置。 
如无需删除或重命名文件，可从策略中分别移除 tos:DeleteObject 或 tos:RenameObject 。重命名时，源路径和目标路径均须在授权资源范围内，且须同时具有 tos:PutObject 权限。
示例策略授权指定存储桶内的全部对象。如需仅授权业务前缀下的对象，可将对象资源改为 trn:tos:::YOUR_BUCKET/windows-data/* 。该设置不会限制存储桶级 tos:ListBucket 权限的列举范围；如需限制列举范围，还须配置列举前缀条件。策略语法与资源范围，请参见 TOS 权限策略说明 。访问采用 SSE-KMS 加密的对象时，还须具有对应密钥的权限：读取需要 kms:Decrypt 权限，写入需要 kms:GenerateDataKey 权限。基础权限与密钥权限要求，请参见 FSX 官方权限说明 。
使用临时凭证时，可执行的操作受签发时授予的权限限制，且凭证须在有效期内。
挂载与重命名限制。 
即使存储桶为空，或指定前缀下没有对象，也可以将该存储桶或前缀挂载为本地磁盘。挂载源中的前缀仅限定本地磁盘映射的对象范围，不限制访问权限；权限隔离仍须通过 TOS 凭证和存储桶策略实现。
分层桶默认支持重命名。扁平桶须先开启 RenameObject 功能，且开启前已有的对象不支持通过该功能重命名。具体前提、权限和限制，请参见 RenameObject 说明 。

正常卸载
为避免未提交的数据丢失，卸载前请先保存文件，并关闭所有正在访问挂载盘的应用。
请根据运行方式执行对应的正常卸载操作：
通用卸载命令如下，如果是在新打开的 CMD 窗口中执行，需要重新设置 WinFsp 的 DLL 搜索路径；如果安装目录不同，请替换为实际的 bin 路径。
执行该命令后，程序会等待挂载进程完成写入提交、释放资源并退出。卸载成功后，对应盘符会消失。默认等待时间为 120 秒。
如果存在大文件写入或网络较慢，可适当延长等待时间。
如果等待超时，命令会报错，但不会强制终止挂载进程。此时建议先检查日志，再重新执行卸载操作。
如果日志中提示提交失败或收尾失败，请保留日志并核对对应对象，不要仅因盘符消失就认定数据已经成功保存。
对于前台模式，也可以返回原挂载窗口，按 Enter 或 Ctrl+C ，并等待进程正常退出。

关机、重启、注销和休眠
关机、重启或注销前，请先保存并关闭文件，再正常卸载所有挂载盘。
后台运行不能替代正常卸载，未提交的写入可能会因进程结束而丢失。
在睡眠或休眠前，也应先保存并关闭文件。
如果需要确认本次写入已经成功提交，建议先正常卸载。
系统恢复后，请检查盘符和文件访问是否正常；如果使用的是临时凭证，还需确认凭证仍在有效期内。
