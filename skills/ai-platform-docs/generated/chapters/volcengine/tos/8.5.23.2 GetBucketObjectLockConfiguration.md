8.5.23.2 GetBucketObjectLockConfiguration
功能描述
此接口用于获取桶的保留策略。
请求消息样式
请求参数和消息头
该请求使用的公共消息头，请参见公共参数。
请求元素
该请求不使用消息元素。
响应消息头
该请求返回公共响应消息头。
响应元素
GET /?object-lock HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: GMT Date
Authorization: authorization string
JSON

名称 参数类型 示例值 说明
ObjectLockEnabled String Enabled
是否开启保留策略，
取值仅为 Enabled ，
表示开启保留策略。
Rule Object - 桶保留策略规则。
DefaultRetention Object - 桶的默认保留策略。
父节点： Rule。

Days Integer 1
对象锁定天数，在指
定天数内对象不能被

单位。
父节点：
DefaultRetention
Years Integer 1
对象锁定年数，在指
定年数内对象不能被
删除或覆盖，以年为
单位，一年为 365
天。
父节点：
DefaultRetention
Mode String COMPLIANCE
保留策略模式，取值
仅为 COMPLIANCE ，
表示合规模式，即任
何用户在保留期内均
不能删除或覆盖被锁
定的对象。
父节点：
DefaultRetention
