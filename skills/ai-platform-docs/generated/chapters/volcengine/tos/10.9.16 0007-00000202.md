问题描述
生命周期规则中的 NoncurrentVersionExpiration 字段没有 NoncurrentDays 或 NoncurrentDate 参数。问题原因
生命周期规则中的 NoncurrentVersionExpiration 字段没有 NoncurrentDays 或 NoncurrentDate 参数，要求有且仅有其中一个。
问题示例
解决方案
NoncurrentDays 或 NoncurrentDate 需有且仅有一个。
{
"Rules": [{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"NoncurrentVersionExpiration": {
}
}]
}
