9.14.6.6.2 GetBucketInventory（Rust SDK）
get_bucket_inventory 接口用于查看存储桶中指定清单规则，本文介绍如何通过 Rust SDK 的get_bucket_inventory 接口获取该规则配置。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
查询参数 inventory 与 id 必须同时携带，缺失任意一项均返回 400 错误。
若目标存储桶未配置对应 Role 的读写权限，接口将返回 403 且无法获取清单配置。
清单文件仅支持 CSV 格式并以 GZIP 压缩，其他格式请求会被拒绝。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行get_bucket_inventory 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:GetBucketInventory

fn handle_error(err: TosError) {
match err {
 TosError::TosClientError { message, .. } => {
println!("Client error: {}", message);
 }
 TosError::TosServerError { request_id, ec, code, .. } => {
println!("Server error: request_id: {}, ec: {}, code: {}", request_id, ec, code);
 }
 _ => println!("Unknown error: {:?}", err),
 }
