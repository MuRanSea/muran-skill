9.14.7.1.4 GetObject（Rust SDK）
get_object 接口用于从桶中下载指定对象，支持多版本、服务端加密、分段下载及条件下载。本文介绍如何通过 Rust SDK 的 get_object 接口完成对象下载。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
下载归档、冷归档或深度冷归档对象前，需先调用 restore_object 完成恢复。
携带 range 参数时，返回的 e_tag 仍为整个对象的 e_tag ，而非分片 e_tag 。
若同时指定 response_content_type 、 response_content_disposition 等 response_* 参数，服务端将按指定值覆盖对应响应头。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行get_object 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：
tos:GetObject

use async_trait::async_trait;
use futures_core::future::BoxFuture;
use std::env;
use std::future::Future;
use std::time::Duration;
use tokio::runtime::Handle;
use ve_tos_rust_sdk::common::init_tracing_log;
use ve_tos_rust_sdk::asynchronous::tos;
use ve_tos_rust_sdk::asynchronous::tos::AsyncRuntime;
use ve_tos_rust_sdk::object::{GetObjectInput};
use ve_tos_rust_sdk::error::TosError;
use ve_tos_rust_sdk::asynchronous::object::{ObjectAPI, ObjectContent};
#[derive(Debug, Default)]
pub struct TokioRuntime {}
#[async_trait]
impl AsyncRuntime for TokioRuntime {
type JoinError = tokio::task::JoinError;
async fn sleep(&self, duration: Duration) {
 tokio::time::sleep(duration).await;
 }
fn spawn<'a, F>(&self, future: F) -> BoxFuture<'a, Result<F::Output, Self::JoinError>>where
 F: Future + Send + 'static,
 F::Output: Send + 'static,
 {
Box::pin(Handle::current().spawn(future))
 }
fn block_on<F: Future>(&self, future: F) -> F::Output {
 Handle::current().block_on(future)
 }
}
#[tokio::main]
async fn main() {
let _guard = init_tracing_log("info", "temp/logs", "app.log");
let ak = env::var("TOS_ACCESS_KEY").unwrap_or("".to_string());
let sk = env::var("TOS_SECRET_KEY").unwrap_or("".to_string());
let endpoint = "https://tos-cn-beijing.volces.com";
let region = "cn-beijing";
let client = tos::builder::<TokioRuntime>()
 .connection_timeout(3000)
 .request_timeout(10000)
 .max_retry_count(3)
 .ak(ak)
 .sk(sk)
 .region(region)
 .endpoint(endpoint)
 .build().unwrap();
let bucket = "example-bucket";
let key = "example-object.txt";
let input = GetObjectInput::new(bucket, key);
let output = client.get_object(&input).await;
