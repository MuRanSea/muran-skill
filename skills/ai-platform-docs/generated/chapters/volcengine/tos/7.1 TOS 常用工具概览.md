7. 工具指南
7.1 TOS 常用工具概览
本文介绍 TOS 支持的各种工具，便于您管理存储桶和对象。
工具 说明
tosutil
tosutil 是用于访问和管理火山引擎对象存储
（TOS）的命令行工具。通过该命令行工具，您
可进行本地与 TOS 之间的批量数据处理，以应
对本地中小数据上云、云上中小数据下载、自动
化脚本任务集成等常见业务场景。
TOS Browser
TOS Browser 是火山引擎对象存储 TOS 提供的图
形化管理工具。您可以通过该工具，完成存储桶
及对象的管理。
TOS FSX
TOS FSX 是用于挂载存储桶的客户端，通过该客
户端，您可以把 TOS 存储桶挂载到 Linux 系统，
使得存储桶可以作为 Linux 系统的本地文件系
统，实现数据的存储和管理。
TOS PyTorch Connector
TOS PyTorch Connector 是火山引擎 TOS 针对 AI
训练场景所提供的高性能数据读写工具。通过
TOS PyTorch Connector ，可以高效地读取 TOS
中的大模型训练数据，显著加速 PyTorch 框架下
大规模机器学习或深度学习项目的数据加载效
率。
tosfsspec 
tosfsspec 是一个遵循 fsspec 规范的 Python
库，它让开发者能够像操作本地文件系统一样，
便捷、高效地读写火山引擎对象存储（TOS）。
无论您是数据分析师还是后端开发者，只要您需
要将 TOS 作为 Python 应用的存储后端，
tosfsspec 都能为您提供标准、简洁且功能丰富
的接口。
ve-tos-cli
ve-tos-cli 是对象存储服务 TOS 提供的官方命令
行工具，该工具覆盖文件传输、桶配置管理、高
级特性调用以及控制面操作等完整工作流。同时
提供低阶（Low-Level）API 与桶配置、高级特
性、控制面命令，满足不同粒度的使用需求。
TOS Import
TOS Import 是用于迁移数据的命令行工具。您
可以将该工具部署在本地服务器或云服务器，然
后使用该工具将本地文件、URL 列表文件或支
持 S3 协议的对象存储文件迁移至 TOS。
工具 说明
注意
TOS Import 工具即将于2026年3月下
线，DMS具有托管化和大规模跨云迁移
能力，强烈推荐您使用 DMS2.0 半托管
。
自助签名工具
自助签名工具是用于计算 Header 签名的工具。
您可以使用自助签名工具生成 Header 签名，免
于复杂的计算。
自助诊断工具
自助诊断工具是用于诊断错误问题的工具。该工
具可以根据 EC 错误码和 Request ID 定位错误问
题，并提供解决方案。
