9.14.7.1.9 RestoreObject（Rust SDK）
restore_object 接口用于恢复归档、冷归档、深度冷归档对象，并支持延长临时副本有效期。本文介绍如何通过 Rust SDK 的 restore_object 接口完成恢复操作。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
软链接不支持恢复，直接访问即可；若通过软链接访问的目标文件为归档、冷归档或深度冷归档类型，需先恢复目标文件。
归档、冷归档、深度冷归档对象恢复后生成标准存储临时副本，副本有效期由 Days 参数指定，范围1~365，到期自动删除。
再次调用 restore_object 可延长副本有效期，仅支持延长，不支持缩短。
冷归档与深度冷归档的 Tier 取值决定恢复时长。 
Expedited ：1~5 分钟
Standard ：2~5 小时 / 12 小时
Bulk ：5~12 小时 / 48 小时
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行restore_object 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:RestoreObject
