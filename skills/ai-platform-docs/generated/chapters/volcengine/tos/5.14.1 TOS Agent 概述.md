5.14 TOS Agent
5.14.1 TOS Agent 概述
TOS 智能助手（TOS Agent）是火山引擎对象存储（TOS）基于大语言模型构建的智能体服务。支持用户通过自然语言进行 Bucket 管理、文件管理、访问异常诊断、数据分析、查看账单详情，并提供对视频、图片、文档等多模态数据的语义检索与对话交互能力。该服务可自动解析用户意图，规划并执行多步 API调用链，同时在工作区可视化呈现执行过程与结果。所有操作均按风险等级实施分级管控，以保障数据安全。
说明
TOS Agent 功能目前处于邀测状态。如需使用，请联系客户经理。
前提条件
已注册火山引擎账号并完成实名认证。
已开通对象存储 TOS 服务 。
如使用 IAM 子用户访问 TOS Agent，请确保该用户具备目标 Bucket 的相关操作权限。具体权限配置请参见权限配置概述 。
如需使用 Chat to SenseFlow 功能，请确保目标 Bucket 已开通 SenseFlow 内容感知数据索引。注意事项
TOS Agent 内置安全围栏可有效防止用户数据被误删，请放心使用。
单次 prompt 的最大长度为 8000 字符。
TOS Agent 基于提示词生成的内容或识别的结果仅供参考。
功能介绍
智能运维
通过自然语言完成 Bucket 配置、访问异常诊断、健康巡检等运维操作。适用于需要快速完成多步骤配置、排查访问异常或定期评估 Bucket 健康状况等场景。
访问异常诊断
将无法访问的 Object 链接或报错信息发给 TOS Agent，Agent 自动发起多步诊断，输出根因定位结果，并给出可操作的修复建议。
Bucket 健康巡检
对指定 Bucket 发起健康检查，TOS Agent 自动检测安全、数据保护、水位管理和基础信息四大维度，输出每项状态及说明，对存在风险的项给出优化建议。确认后，Agent 可逐项执行修复操作。数据洞察
Agent 作为数据分析助手，支持查询桶内资源使用状况，如存储情况、带宽、流控及总体评估等，帮助用户了解资源使用状态。
多模态检索（Chat to SenseFlow）
说明
多模态语义检索能力的开通依赖 TOS 内容感知与处理功能（SenseFlow）。
基于 TOS SenseFlow 数据索引能力，对 Bucket 中的视频、图片、文档等多模态数据发起自然语言检索与对话。适用于从海量非结构化数据中按内容语义定位目标文件的场景，如安防监控溯源、媒资素材检索、企业文档查找等。
方案咨询
TOS Agent 集成了 TOS 产品知识库，支持功能特性、计费配额、最佳实践等方面的智能问答。安全围栏
通过操作风险分级确保 Agent 在安全可控的边界内执行操作，高危和越权操作一律阻断并引导用户走官方控制台操作。
配额与限制
计费说明
TOS Agent 功能当前暂不收费，但通过 TOS Agent 触发的 TOS 产品操作按 TOS 对应计费项收费，详细计费请参见计费概述 。
