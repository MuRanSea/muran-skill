5.3.3 创建存储桶
存储桶（Bucket）是用于存储对象（Object）的空间。在上传任意对象前，您需要先创建存储桶。前提条件
请确保您已注册火山引擎账号并完成实名认证，具体步骤，请参见账号注册 和实名认证 。请确保您的账号或者子账号已开通 TOS 服务，具体步骤，请参见开通 TOS 服务。
注意事项
主账号默认拥有全部权限，IAM 子用户默认没有任何权限。如果您需要使用子账号执行该操作，则需要主账号通过 IAM 策略 或桶策略 为该子账号授予 tos:CreateBucket 权限。
每个账号及其子账号最多只能创建 100 个存储桶。
操作步骤
登录对象存储控制台 。
在左侧导航栏单击桶列表，在页面左上方单击创建桶。
设置存储桶参数，单击确定。
参数 说明 约束限制
基础设置 名称
存储桶的名称，创建
后不可更改。命名规
范如下：
* 在 TOS 范围内全局
唯一，即所有地域所
有账号下的桶名均不
能重复。
* 只能包含数字、中划
线（-）、字母 a-z。
* 开始和结尾只能是数
字或字母。
* 长度在 3～63 字符。
-
区域
存储桶所归属的地
域，创建后不可更
改。
-
版本控制
是否开通版本控制
功能。开通后针对
对象覆盖及删除操
作，TOS 将保存对
象的历史版本。
-
桶策略
设置存储桶的桶策
略（Bucket -
参数 说明 约束限制
Policy），说明如
下：
* 私有：默认值，只
有该桶的归属者及
有授权的账号对桶
中的对象有读写权
限，推荐使用。
* 公共读/公共读
写：任何人均可对
存储桶进行读取
（读写）操作，同
时产生流量费用，
存在财产损失和数
据泄露风险，建议
选择私有。
如需更精细的资源
授权，创建存储桶
后可通过桶 ACL
、桶策略
（Policy） 和访问
控制 IAM 策略 进
行配置。
对象 ACL 默认策略
是否开启对象 ACL
默认策略功能，默
认关闭。
* 关闭（默认）：桶
内新上传对象默认
私有。
* 开启：桶内新上传
对象的 ACL 默认将
和桶 ACL 保持一
致。
对象 ACL 和桶 ACL
的对应关系，请参
见对象继承桶 ACL
。
-
项目
在下拉列表中选择
存储桶所属的项
目，选填。
* 项目是一个虚拟的概
念，包括一组资源、
用户和角色。通过项
参数 说明 约束限制
目可以对一组资源进
行统一的查看和管
理，并且控制项目内
用户和角色对这些资
源的权限。更多详
情，请参见资源管理
。
* 您可以单击右侧的创
建新项目，前往 IAM
控制台 创建新的项
目。
高级设置 分层命名空间
设置是否开启分层命
名空间。
* 关闭（默认）：扁平
桶，即传统对象存储
模型，适合通用存储
场景。
* 开启：分层桶，在扁
平桶基础上增加文件
系统的目录层级能
力，更适合大数据、
数据湖和 AI 领域的使
用场景。
详细介绍，请参见什
么是分层命名空间
。
分层命名空间开启后
暂时不支持关闭，请
谨慎选择。
开启回收站
控制是否为当前存
储桶启用回收站功
能。
* 关闭（默认）：删
除操作将直接永久
删除文件/目录。
* 开启：删除的文
件/目录会先进入回
收站。
* 只有开启分层命名空
间时才可配置当前参
数。
* 回收站中的文件会按
回收策略指定的清理
时间自动清理，默认
保留 7 天，超期后将
被永久删除。
* 可在存储桶内自主调
整回收站文件/目录保
留时长，保留期间，
支持从回收站手动恢
复或彻底删除文件/目
录。
参数 说明 约束限制
多 AZ 冗余
设置是否开启多 AZ
冗余。开启多 AZ 冗
余功能后，TOS 会
将您的数据存储在
同一地域的多个可
用区，当某个可用
区发生故障时，其
他可用区仍然能为
您提供稳定的存储
服务。详细介绍，
请参见多 AZ 冗余。
* 仅华北2（北京）、
华东2（上海）、华南
1（广州）和亚太东南
（柔佛）地域支持多
AZ 冗余功能。
* HNS 桶的多 AZ 冗余
功能支持状态，请以
控制台显示为准。
* 多 AZ 冗余的存储容
量收费标准高于单 AZ
存储，且开启后不能
关闭，请您谨慎开
启。关于多 AZ 冗余的
存储容量费用说明，
请参见存储容量计费
。
默认存储类型

型，TOS 存储类型
如下所示：
* 标准存储：默认

天。

数据，可根据访问
频率转换访问层。
* 归档闪回：适用于
基本不会被访问的
数据，最少存储 90
天。
* 归档/冷归档：适

* 支持深度冷归档，且
都处于邀测状态，如
您需要使用该功能，
请联系客户经理。
* 关于存储类型的详细
说明，请参见存储类
型 。
* 开启多 AZ 冗余后，
默认存储类型仅支持
标准存储（多 AZ）、
低频存储（多 AZ）、
归档闪回（多 AZ）。
关于多 AZ 的详细介
绍，请参见多 AZ 冗余
。
参数 说明 约束限制
天、180天。
* 深度冷归档：适用
于需要超长时间存
放的极冷数据，最
少存储 180 天。
服务端加密
设置存储桶的服务
端加密方式。在存
储桶设置服务端加
密后，在该存储桶
上传文件时，如果
您没有指定文件的
服务端加密方式，
则文件会默认继承
存储桶的服务端加
密方式。不同加密
方式说明如下：
* 无：不加密。
* SSE-TOS：TOS 托
管密钥方式，是指
文件上传后 TOS 对
文件自动加密落盘
存储，下载时自动
解密，密钥由 TOS
托管，更多信息，
请参见服务端加
密。
* SSE-KMS：使用火
山引擎 KMS 托管的
密钥对文件进行加
解密，更多信息，
请参见服务端加
密。
* 仅华北2（北京）、
华东2（上海）、亚太
东南（柔佛）和亚太
东南（雅加达）地域
支持 SSE-TOS 和 SSEKMS。
* 首次使用 SSE-KMS
进行服务端加密，您
需要开通 KMS 服务
。开通 KMS 服务免
费，使用 KMS 服务会
收费。使用 SSE-KMS
进行服务端加密会产
生 API 调用费用，创
建 KMS 密钥会产生密
钥托管费用，API 调用
费用和密钥托管费用
由 KMS 收取，更多信
息，请参见 KMS 计费
说明 。
加密算法
选择密钥的加密算
法， 可选 AES256
和 SM4 算法。
* 仅服务端加密选择 
SSE-KMS 或 SSE-TOS
时，展示该参数。
* 仅华北2（北京）、
华东2（上海）、亚太
东南（柔佛）和亚太
东南（雅加达）地域
支持 AES-256 算法；
仅华北2（北京）、华
东2（上海）支持
SM4 算法。
