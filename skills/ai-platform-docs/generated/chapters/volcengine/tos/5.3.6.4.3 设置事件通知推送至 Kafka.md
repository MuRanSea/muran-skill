5.3.6.4.3 设置事件通知推送至 Kafka
为了实时掌握 TOS 内资源变动，您可以配置事件通知监控存储桶内资源变动，当发生指定事件时，系统会自动向消息队列 KafKa 发送通知。本文介绍设置事件通知推送至 Kafka 的前提条件、操作步骤等内容。背景信息
消息队列 Kafka 版 是一款基于 Apache Kafka 构建的分布式消息中间件服务。对象存储 TOS 支持将事件通知消息推送到消息队列 Kafka 版。如果您在消息队列 Kafka 配置了消费者，消息队列 Kafka 版接收到消息后会传递给下游的消费者，消费者在接收到消息后，会按照预定义的业务逻辑执行相关操作。前提条件
已创建 Kafka 实例，具体操作，请参见创建实例 。
已创建 Kafka Topic，具体操作，请参见创建 Topic 。
已创建 SASL 用户，且该用户的密码类型必须为 PLAIN，并具备 Kafka Topic 写入权限（即已开启用户All Permitted 功能），具体操作，请参见创建 SASL 用户 。
注意事项
一个存储桶最多只能创建 30 条事件通知规则。
一个对象不能匹配多个包含了相同事件类型的规则，即同一个存储桶内，不同规则间类型+前后缀的组合范围不允许重叠。
一个存储桶中所有事件通知规则的 JSON 描述总大小不能超过 20 KB。
Kafka 实例不建议配置 IP 白名单。TOS 事件通知采用服务端推送方式，推送源 IP 不固定，因此无法提供固定 IP 列表。配置 IP 白名单会导致事件推送失败、消息丢失。安全管控请使用 PLAIN 账号密码权限机制。

在事件通知页面，单击创建规则。

查看事件通知消息
您可以在消息队列 Kafka 版控制台查看事件通知消息，具体操作如下：
登录消息队列 Kafka版控制台 。
在顶部菜单栏中，选择实例所在的地域。
在实例列表页面，单击绑定事件通知规则的 Kafka 实例名称。
在实例详情页面，单击消息查询页签。
选择按时间查询、Topic，设置分区为全部，指定查询的时间范围，单击查询。
页面展示符合筛选条件的消息列表，其中包括 Topic 名称、分区、位点、Key、Value、消息大小和存储时间。您可以在 Value 列获取事件通知的具体内容，关于事件通知参数详细介绍，请参见事件通知格式。
