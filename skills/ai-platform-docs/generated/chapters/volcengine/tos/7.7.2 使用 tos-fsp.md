7.7.2 使用 tos-fsp
本文主要介绍如何使用 tos-fsp 及相关组件。
注意事项
请使用 MSI 安装包完整安装 WinFsp，不能通过仅复制单个 DLL 的方式完成安装。
安装失败时，请保留错误信息和安装日志以便排查，不要通过从第三方网站单独下载 DLL 的方式尝试修复。
环境要求
支持的操作系统
使用 Windows x64 系统，确保系统可访问目标存储桶所在地域的 endpoint ，并预留足够的本地缓存空间。
实际支持的系统与 WinFsp 版本组合，以对应版本的发布说明为准。
版本信息与下载
tos-fsp 以单个可执行文件 tos-fsp.exe 交付，配置文件需按本文档创建，WinFsp 和 VC 运行库需另行安装。

说明
请安装 Microsoft 官方最新支持版本。
安装 WinFsp
安装 WinFsp。
从 WinFsp 官方网站 下载最新 MSI 安装包，双击安装。安装可能要求管理员权限，若提示重启，请完成重启后再挂载。
安装 VC++ 运行库。
下载 Microsoft 官方 x64 安装程序 并运行，按提示安装或更新，提示重启时先完成重启。已有满足发布说明要求的 x64 版本可跳过此步骤，不要卸载其他应用使用的 x86 或旧版运行库。版本与系统要求，请参见 Microsoft 说明 。
下载 tos-fsp.exe。
注意
tos-fsp.exe 仅支持 CMD 命令行方式运行（必须配置参数），请勿直接双击，否则会弹出**找不到 winfsp-x64.dll ** 的系统错误提示。
下载 tos-fsp.exe 。
在本地创建 C:\TosFsp 目录，并将 tos-fsp.exe 复制至该目录。
本文后续涉及的命令、配置文件路径及相关示例，均以 C:\TosFsp 作为程序目录进行说明。校验文件完整性。
下载 SHA256SUMS ，在 CMD 中执行以下命令，将输出的哈希值与 SHA256SUMS 中的值比对，一致则说明文件完整。 certutil 命令说明的相关信息，请参见 Microsoft certutil 。
检查安装
完成安装后，按以下步骤逐项确认各组件状态。
在文件资源管理器中打开 C:\TosFsp ，确认 tos-fsp.exe 文件存在。
确认 winfsp-x64.dll 文件。
在**控制面板 ** > **程序 ** > 程序和功能中确认 WinFsp 已安装，并在默认安装目录 C:\Program Files(x86)\WinFsp\bin 下确认存在 winfsp-x64.dll 文件。
非默认安装路径时，请替换为实际目录路径。
确认 VC 运行库。
在程序和功能页面中搜索 Microsoft Visual C++ ，确认存在名称包含 x64 的 v14 运行库.项目 本版本信息

确认未被占用的盘符。
在文件资源管理器此电脑，确认一个未被占用的盘符（例如 Z:）用于后续挂载，该盘符无需提前创建，也无需新建分区或格式化磁盘。
挂载成功后系统会自动显示该盘符（类似插入 U 盘后自动出现盘符）。
注意
请避免使用已被占用的盘符（如 C:、D:、E:），以免发生冲突。
打开 CMD，执行以下命令，确认帮助信息可正常显示，以验证程序启动所需的 DLL 能否正常加载。set "PATH=C:\Program Files (x86)\WinFsp\bin;%PATH%" 将 WinFsp 的 bin 目录加入当前 CMD 及其子进程的 DLL 搜索路径，使程序能够找到 winfsp-x64.dll 。
该设置仅对当前 CMD 及其子进程生效，不影响系统环境变量，新打开的 CMD 窗口需重新执行该命令。
如果 WinFsp 安装在其他目录，请将命令中的路径替换为实际的 bin 路径。
帮助信息正常显示，表示程序启动所需的 DLL 已可加载。
如果出现加载器或 DLL 错误，请根据报错名称，检查 WinFsp 或 x64 运行库是否完整安装。各项检查通过后，请继续配置 mount.toml 文件并完成挂载。更多信息请参见配置与挂载 。升级与回退
升级或回退前，须先正常卸载所有挂载盘，再替换程序文件。升级时保留原配置和当前有效凭证；回退时恢复备份程序，并根据配置兼容性决定是否恢复旧配置。
