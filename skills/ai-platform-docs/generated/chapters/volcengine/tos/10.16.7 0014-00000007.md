问题描述
函数服务ID 为空。
问题原因
创建函数服务类型的事件通知规则时，没有设置函数服务 ID。
问题示例
• PutBucketNotification 接口示例，对应 CloudFunction 字段值为空。

Host: bucketname.tos-cn-beijing.volces.com
Date: GMT Date

{

{

"tos:ObjectCreated:*",
"tos:ObjectRemoved:*"
],
"Filter": {
"TOSKey": {
"FilterRules": [
{
"Name": "prefix",
"Value": "test_"
},
{
"Name": "suffix",
"Value": ".jpg"
}
]
}
},
"RuleId": "string",
"CloudFunction": ""
}
]
}

PutBucketNotificationV2 接口示例，对应 FunctionId 字段值为空。
解决方案
