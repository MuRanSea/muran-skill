3.3.2.3 查看资源包
本文介绍查看资源包使用明细的操作步骤。
操作步骤
登录对象存储控制台 。
在左侧导航栏单击资源包管理，单击资源包使用明细。
根据需要查看资源包使用明细。 
查看整体抵扣明细。
单击抵扣明细，可查看当前已经抵扣完的所有资源包。
查看单个资源包使用明细。
单击目标资源包操作列对应的明细，可查看当前资源包的使用明细。
其他操作
您还可以在当前页面执行以下操作：
定制展示列：单击页面右上方的定制列图标，可设置当前页面需要展示的参数，默认为选择所有列。导出明细：单击页面右上方的导出图标，可导出当前页面所有资源包的抵扣明细。
设置余量预警：单击页面右上方的余量预警，可根据需要设置资源包余量预警，当资源包达到余量预警阈值时，会触发告警。更多信息，请参见设置余量预警 。
