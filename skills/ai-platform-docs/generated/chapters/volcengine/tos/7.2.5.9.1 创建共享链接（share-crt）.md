7.2.5.9 分享对象
7.2.5.9.1 创建共享链接（share-crt）
您可以通过 share-crt 命令，为需要分享的对象创建共享链接。
命令格式
Linux/macOS
Windows
参数说明
通用可选参数的说明，请参见通用可选参数。
./tosutil share-crt tos://bucket[/prefix] [-vp=xxx] [-dst=xxx] [-em] [-e=xxx] [-re=xxx] [-i=xxx] [-k=xxx] [-t=xxx] [-conf=xxx]
Shell
tosutil share-crt tos://bucket[/prefix] [-vp=xxx] [-dst=xxx] [-em] [-e=xxx] [-re=xxx] [-i=xxx] [-k=xxx] [-t=xxx] [-conf=xxx]
cmd
参数名 参数类型 描述
bucket String 待分享的对象所在的存储桶。
prefix String
待分享的对象名前缀，说明如
下：
取值为空：表示分享整个桶
内的对象。
取值不为空：表示分享以该
前缀开头的所有对象。
Tip
设置该参数时，建
议以 / 结尾。
如果您希望通过浏
览器或 TOS Browser
工具浏览分享的指
定前缀的对象，则
使用示例
分享桶内所有对象
以下命令用于分享 bucketname 桶内所有对象，共享链接有效期为 1 小时。
命令
参数名 参数类型 描述
该参数必须以 /
结尾。
-vp String
设置共享链接的有效期，有效
期取值范围为 1 分钟 ～ 7 天。
如果您配置 tosutil 工具时使用
的是临时访问密钥，则共享链
接有效期可选最大值与临时访
问密钥的过期时间保持一致。
默认值为 1 天，表示生成的共
享链接将在 1 天后失效，该参
数支持以下配置方式：
w：表示设置单位为周。
d：表示设置单位为天。
h：表示设置单位为小时。
min：表示设置单位为分
钟。
s：表示设置单位为秒。
例如 1d 表示有效期为 1
天， 1w 表示有效期为 1
周， 1h 表示有效期为 1 小
时。
Tip
如果您没有选择时间单
位，则默认单位为秒，
例如 2400 表示有效
期为2400秒。
-dst String 共享链接的保存路径。
-em Bool 设置精准匹配，表示仅分享单
个对象。
返回
