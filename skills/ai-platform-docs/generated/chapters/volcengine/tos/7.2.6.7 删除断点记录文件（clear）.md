7.2.6.7 删除断点记录文件（clear）
您可以使用 clear 命令删除指定文件夹下的断点记录文件，并执行云端清理工作。
命令语法
Linux/macOS
Windows
参数说明
通用可选参数的说明，请参见通用可选参数。
运行示例
命令
./tosutil clear [checkpoint_dir] [-u] [-d] [-c] [-e=xxx] [-re=xxx] [-i=xxx] [-k=xxx] [-t=xxx] [-conf=xxx]Bash
tosutil clear [checkpoint_dir] [-u] [-d] [-c] [-e=xxx] [-re=xxx] [-i=xxx] [-k=xxx] [-t=xxx] [-conf=xxx]Bash
参数名 参数类型 描述
checkpoint_dir String
指定断点续传记录文件的文件
夹，默认为配置文件中的 
defaultCheckpointDir 。
-u Bool 删除所有分片上传任务的断点
记录文件。
-d Bool 删除所有分片下载任务的断点
记录文件。
-c Bool 删除所有分片复制任务的断点
记录文件。
