7.2.6.11 抓取网络（traceroute）
您可以通过 traceroute 命令跟踪数据的网络路径。
traceroute
命令语法
Linux/macOS
域名
IP 地址
Windows
对域名建立网络连接并计算耗时
对 IP 地址建立网络连接并计算耗时
参数说明
./tosutil traceroute domain [-s=1] [-m=1] [-w=1] [-q] [-ipv6] [-n]
Bash
./tosutil traceroute ipaddress [-s=1][-m=1] [-w=1] [-q] [-ipv6] [-n]
Bash
tosutil traceroute domain [-s=1] [-m=1] [-w=1] [-q] [-ipv6] [-n]
Bash
tosutil traceroute ipaddress [-s=1][-m=1] [-w=1] [-q] [-ipv6] [-n]
Bash
参数名 参数类型 描述
domain String
目标主机域名。TOS 支持的地
域和访问域名，请参见地域和
访问域名（Endpoint）。
使用示例
命令
返回
参数名 参数类型 描述
ipaddress String 目标主机 IP 地址。
-s=1 String
执行 traceroute 命令时的数据
包大小，单位：字节，默认为
56B。取值范围为 [1B，
63KB]。
-m=1 String 执行 traceroute 命令时的最大
探测次数，默认为 30 次。
-w=1 String
执行 traceroute 命令时每次探
测的超时等待时间，单位：
秒，默认为 5 秒。
-q String
执行 traceroute 命令时每次探
测发送的数据包个数，默认为
3 个，最大为 10 个。
-ipv6 String 解析域名时选择 IPv6 地址。
-n String 执行 traceroute 命令时不解析
IP 地址对应的域名。
./tosutil traceroute tos-cn-beijing.ivolces.com
