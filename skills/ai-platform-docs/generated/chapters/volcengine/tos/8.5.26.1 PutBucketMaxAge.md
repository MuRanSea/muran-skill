8.5.26 浏览器缓存
8.5.26.1 PutBucketMaxAge
功能描述
此接口用于设置存储桶（Bucket）的浏览器缓存有效期。配置成功后，新上传至该存储桶的对象将默认应用此有效期，即系统会自动在对象元数据中增加 Cache-Control: max-age=xxx 属性。
注意事项
请确保当前账号已具备 tos::PutBucketMaxAge 权限。
浏览器缓存有效期的支持范围为 1 - 31536000 秒。
配置成功后，该规则仅对新上传的对象生效，存储桶中已有的历史对象不受影响。
请求消息样式
请求参数和消息头
该请求使用的公共消息头，请参见公共参数。
请求元素

Host: bucketname.tos-cn-beijing.volces.com
Date: GMT Date
Authorization: authorization string
{
"MaxAge": 86400
}
JSON
