9. SDK 参考
9.1 SDK 概览
本文介绍火山引擎对象存储 TOS 支持的 SDK 及说明。
SDK 信息
SDK 名称：对象存储 SDK
SDK 开发者：北京火山引擎科技有限公司
主要功能：提供海量、安全、低成本、易用、高可靠、高可用的分布式云存储服务，提供多种主流语言的 SDK，极大提高您的开发效率。
前提条件
已注册火山引擎账号并完成实名认证，具体步骤，请参见账号注册 及实名认证 。
已开通 TOS 服务，具体步骤，请参见开通 TOS 服务。
已获取账号的 AccessKey，具体步骤，请参见获取 AccessKey 。
