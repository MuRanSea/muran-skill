12.3 使用第三方工具访问 TOS
12.3.1 使用 Rclone 访问 TOS
Rclone 是一款功能强大的开源命令行工具，支持对接各种云存储系统（包括兼容 S3 协议的对象存储），可用来执行数据上传、下载等操作。本文介绍如何使用 Rclone 工具访问 TOS。
背景信息
关于 Rclone 的详细信息，请参见 Rclone 官网 。
前提条件
已创建火山引擎账号，并已开通对象存储 TOS 服务。
已获取当前账号的 AccessKeyID 和 AccessKeySecret 信息。
说明
您可以登录火山引擎控制台 ，然后单击右上角头像，选择开发者与工具 > API 密钥管理，即可查看 AccessKeyID 和 AccessKeySecret 信息，更多信息，请参见密钥管理 。
已获取 TOS 的 S3 Endpoint 信息，详情请参见地域和访问域名（Endpoint）。
步骤一：安装工具
使用 Rclone 访问 TOS 前，您需要先安装工具，本章节介绍在不同操作系统下的安装方式。macOS 操作系统（或 Linux 及 BSD 操作系统）
本章节以在 macOS 操作系统下安装 Rclone 为例（Linux 及BSD 操作系统下安装命令相同），您可以直接执行如下命令。

常见问题
使用 rclone 工具上传对象时发现速率无法提升，是什么原因？
这种情况可能是 rclone 的使用姿势不对，您可以尝试携带跳过数据检查的参数 --no-check-dest 和 --no-traverse ，确认能否提升上传速率。更多关于 rclone 的参数说明，请参见 rclone global flags 。使用 rclone 工具上传对象时，报错 Forbidden path to access server 怎么办？
对象存储不支持 Path Style 形式访问，应使用 Virtual Style 形式（即虚拟主机访问方式）访问。目前第三方 SDK 默认仍使用 Path Style 形式访问，所以会产生此问题。Path 和 VirtualHost 的区别主要在于HTTP URL 中桶名的位置，如下所示：
rclone size volces-tos:bucket-demo/testdir
Plain
rclone check source:path dest:path [flags]
Plain
