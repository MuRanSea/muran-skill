6.5.3.3 向量桶
6.5.3.3.1 CreateVectorBucket（TOS Vectors Node.js SDK）
CreateVectorBucket 接口用于创建向量桶，本文介绍如何通过 TOS Vectors Node.js SDK 的CreateVectorBucket 接口完成该操作。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见地域和访问域名（Endpoint）。
为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见配置长期访问凭证。
TOS Vectors Node.js SDK 支持使用临时访问凭证；也支持配置超时机制、重试策略等多种机制，您可以根据业务需求灵活设置，提升应用安全性，详细介绍，请参见常见配置场景。
不允许匿名请求创建桶，并且一个用户在全局内最多可创建 100 个向量桶（包含普通桶）。权限说明
主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用 IAM 用户执行CreateVectorBucket 操作，主账号需通过 IAM策略和桶策略为该 IAM 用户授予以下权限：tosvectors:CreateVectorBucket
代码示例
创建向量桶
// 创建向量桶
import {
TosVectorsClient,
TosClientError,
TosServerError,
} from "@volcengine/tos-sdk";
// 从环境变量中获取认证信息和配置
const client = new TosVectorsClient({
accessKeyId: process.env["TOS_ACCESS_KEY"] as string, // TOS_ACCESS_KEY: 您的 Access Key IDaccessKeySecret: process.env["TOS_SECRET_KEY"] as string, // TOS_SECRET_KEY: 您的 Secret Keyregion: 'Provide your region', //向量桶所在地域，例如 cn-beijing
endpoint: 'Provide your vector endpoint', // 向量服务域名，例如 tosvectors-cn-beijing.volces.com
});
// 从环境变量中读取要创建的向量桶名称
const vectorBucketName = 'Provide your vector bucket name'; // 待创建的向量桶名称/**
 * 处理 SDK 调用过程中可能出现的错误。
 * @param error 捕获到的错误对象
 */
function handleError(error: Error) {
if (error instanceof TosClientError) {
// 客户端异常，通常是参数错误或网络问题
console.log("Client Error:");
console.log(" Message:", error.message);
if (error.stack) {
console.log(" Stack:", error.stack);
 }
 } else if (error instanceof TosServerError) {
// 服务端异常，表示请求已送达但处理失败
console.log("Server Error:");
console.log(" Request ID:", error.requestId);
console.log(" Status Code:", error.statusCode);
console.log(" Code:", error.code);
console.log(" Message:", error.message);
console.log(" Headers:", error.headers);
 } else {
// 其他未知异常
console.log("Unexpected Error:");
console.log(" Message:", error.message);
 }
}
async function main() {
try {
// 1. 根据用例场景，准备 API 需要的参数。
console.log(`开始创建向量桶: ${vectorBucketName} ...`);
// 2. 调用对应的 API 方法。
const result = await client.createVectorBucket({
 vectorBucketName,
 });
// 3. 处理并打印返回结果中的关键信息。
console.log("Request ID:", result.requestId);
console.log("Status Code:", result.statusCode);
console.log("Headers:", result.headers);
// 创建成功后可使用 getVectorBucket 查询详情
console.log("Result Data:", result.data);
 } catch (error: any) {
handleError(error);
 }
}
main();
