8.3 公共参数
本文列举了公共请求消息头和公共响应消息头的名称和对应的详细说明。
公共请求消息头
公共响应消息头
消息头名称 说明
Authorization 验证请求消息的合法性。关于 Authorization 的
计算方法，请参见签名机制。
Content-Length RFC 2616 中定义的请求内容不包含消息头长
度。
Content-Type 请求内容的类型。
Date 请求发起时的日期，GMT 时间，例如 Fri, 30 Jul
2021 08:05:36 GMT 。
Host 域名。
消息头名称 说明
Content-Length 响应的消息体的长度。
Date 响应请求的日期，GMT 时间。
Server 响应请求的服务端。
ETag 在创建每个对象的时候生成，唯一标识一个对象
的内容。
消息头名称 说明
x-tos-request-id
此次请求的响应 ID，唯一标识这个请求。如果
使用 TOS 服务遇到问题，您可以凭借此字段联
系 TOS 的工作人员，快速定位问题。
x-tos-id-2 定位问题的特殊符号。
x-tos-server-time 请求在服务端的处理时间。
