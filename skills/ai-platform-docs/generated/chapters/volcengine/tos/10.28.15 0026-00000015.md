问题描述
在分层桶中，批量删除不支持删除目录类型的对象。
问题原因
发起 DeleteMultiObjects 请求时，携带了目录类型的对象。
问题示例
解决方案
使用 DeleteObject 接口删除目录类型的对象。
POST /?delete HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com 
Date: GMT Date
Authorization: authorization string
Content-MD5: md5 string
{
"Objects": [{
"Key": "dir1",
"VersionId": "string"
}],
"Quiet": false
}
