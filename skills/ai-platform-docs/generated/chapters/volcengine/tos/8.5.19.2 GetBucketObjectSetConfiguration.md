8.5.19.2 GetBucketObjectSetConfiguration
功能描述
此接口用于查询 Bucket 级 ObjectSet 配置。
注意事项
未配置时返回 NoSuchBucketObjectSetConfiguration 类错误。
通过子账号使用时，需要授予当前桶的 GetBucketObjectSetConfiguration 权限。
请求消息样式
请求参数和消息头
该请求使用的公共请求消息头，请参见公共参数 。
请求元素
该请求不使用消息元素。
响应消息头
该请求返回的公共响应消息头，请参见公共参数 。
响应元素
GET /?objectsetconfiguration HTTP/1.1
Host: bucket-name.tos-cn-beijing.volces.com
Date: GMT Date
Authorization: authorization string
JSON
名称 参数类型 示例值 说明
PathLevel Integer 3
桶 ObjectSet 支持的
Prefix 按分隔符切分
后的固定深度。 该参
数取值为 1 至 5 的正
整数。
CustomDelimiter String -
桶 ObjectSet 支持自
定义分隔符，默认值
为 / 。例如： / 、
# 、 - 、 _ 。
名称 参数类型 示例值 说明
Qos Container -
为所有 ObjectSet 指
定默认限高的流控配
置。
子节点：
ReadsQps , WritesQps , ListQps , ReadsRate , WritesRate
ReadsQps Integer 1000
读请求QPS限制，如
果不设置或取值为
0，则表示不限制。
父节点： Qos
WritesQps Integer 1000
写请求QPS限制，如
果不设置或取值为
0，则表示不限制。
父节点： Qos
ListQps Integer 1000
List请求QPS限制，如
果不设置或取值为
0，则表示不限制。
父节点： Qos
ReadsRate Integer 1000
读请求带宽限制，单
位为 Mb/s，如果不设
置或取值为 0，则表
示不限制。
父节点： Qos
WritesRate Integer 1000
写请求带宽限制，单
位为 Mb/s，如果不设
置或取值为 0，则表
示不限制。
父节点： Qos
StorageQuota String "1024"
为所有ObjectSet指定
默认的容量配额，单
位为 Byte，如果不设
置或取值为 0，则表
示不限制。取值范围
为 [0, 2^63-1]。
