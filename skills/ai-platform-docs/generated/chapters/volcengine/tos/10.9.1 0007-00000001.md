10.9 07-LIFECYCLE
10.9.1 0007-00000001
问题描述
生命周期规则配置格式非法。
问题原因
生命周期规则内容格式不合法。
问题示例
Transitions 字段的格式需要设置为 JSON 数组。
解决方案
设置 Transitions 字段的格式为 JSON 数组，详细介绍，请参见 PutBucketLifecycle 。
{
"Rules": [{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"Transitions": {
"StorageClass": "IA",
"Days": 30
}
}]
}
JSON
