设置 ObjectSet 容量配额（Java SDK）
本文介绍如何通过 TOS Java SDK 为指定 ObjectSet 设置存储容量配额。
注意事项
ObjectSet 必须存在。
通过子账号调用时，需要具备当前 Bucket 的 tos:PutObjectSetQuota 权限。

import com.volcengine.tos.TOSV2;
import com.volcengine.tos.TOSV2ClientBuilder;
import com.volcengine.tos.TosClientException;
import com.volcengine.tos.TosServerException;
import com.volcengine.tos.model.bucket.PutObjectSetQuotaInput;
import com.volcengine.tos.model.bucket.PutObjectSetQuotaOutput;
public class PutObjectSetQuotaExample {
public static void main(String[] args) {

String region = System.getenv("TOS_REGION");
String accessKey = System.getenv("TOS_ACCESS_KEY");
String secretKey = System.getenv("TOS_SECRET_KEY");
String bucket = System.getenv("TOS_BUCKET");
String objectSetName = System.getenv("TOS_OBJECT_SET_NAME");
TOSV2 tos = new TOSV2ClientBuilder().build(region, endpoint, accessKey, secretKey);try {
PutObjectSetQuotaInput input = PutObjectSetQuotaInput.builder()
 .bucket(bucket)
 .objectSetName(objectSetName)

覆盖写入 ObjectSet 标签（Java SDK）
本文介绍如何通过 TOS Java SDK 覆盖写入指定 ObjectSet 的标签集合。
注意事项
ObjectSet 必须存在。
该接口会覆盖目标 ObjectSet 的标签集合，请确保请求中包含完整的目标标签集合。
通过子账号调用时，需要具备当前 Bucket 的 tos:PutObjectSetTagging 权限。
每个 ObjectSet 最多可添加 10 个标签，同一 ObjectSet 内标签 Key 不能重复。
代码示例
import com.volcengine.tos.TOSV2;

import com.volcengine.tos.TosServerException;
import com.volcengine.tos.model.bucket.PutObjectSetTaggingInput;
import com.volcengine.tos.model.bucket.PutObjectSetTaggingOutput;
import com.volcengine.tos.model.bucket.Tag;
import com.volcengine.tos.model.object.TagSet;
import java.util.Collections;
public class PutObjectSetTaggingExample {
public static void main(String[] args) {
String endpoint = System.getenv("TOS_ENDPOINT");
String region = System.getenv("TOS_REGION");
String accessKey = System.getenv("TOS_ACCESS_KEY");
String secretKey = System.getenv("TOS_SECRET_KEY");
String bucket = System.getenv("TOS_BUCKET");
String objectSetName = System.getenv("TOS_OBJECT_SET_NAME");
TOSV2 tos = new TOSV2ClientBuilder().build(region, endpoint, accessKey, secretKey);try {
Tag tag = Tag.builder().key("owner").value("java-sdk-example").build();

设置 QoS 与容量配额规则（Java SDK）
本文介绍如何通过 TOS Java SDK 根据 ObjectSet 标签设置默认 QoS 与容量配额规则。
注意事项
rules 不能为空。
同一请求中不允许出现重复的 tag.key=tag.value 。
请求体大小受服务端限制，默认上限为 20 KiB。
通过子账号调用时，需要具备当前 Bucket 的 tos:PutObjectSetQuotaByTag 权限。
该规则会覆盖基于标签的配额规则，请谨慎在生产 Bucket 上调用。

import java.util.Collections;
