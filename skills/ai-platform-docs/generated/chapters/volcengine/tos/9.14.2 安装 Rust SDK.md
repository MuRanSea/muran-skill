9.14.2 安装 Rust SDK
运行 TOS Rust SDK 前，您需要先安装 SDK，本文提供 SDK 的运行环境要求及多种安装方式。前提条件
安装 SDK 前，您需要先搭建 Rust 开发环境。您可通过 Rust 官网 介绍完成开发环境搭建。安装完成后，可使用 cargo version 命令，查看版本信息。

安装方式
TOS Rust SDK 使用 https://crates.io/ 管理安装包。搭建好开发环境和 Rust 工程后，可使用 cargo 引入依赖，如下：
您也可以直接在 Cargo.toml 文件中新增 TOS Rust SDK 的依赖，如下：
cargo add ve-tos-rust-sdk -F tokio-runtime
Rust
[dependencies]
ve-tos-rust-sdk = { version = "2.9.2", features = ["tokio-runtime"] }
