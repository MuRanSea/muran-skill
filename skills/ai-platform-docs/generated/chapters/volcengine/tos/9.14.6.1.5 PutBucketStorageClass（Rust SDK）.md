9.14.6.1.5 PutBucketStorageClass（Rust SDK）
put_bucket_storage_class 接口用于设置存储桶默认存储类型，本文介绍如何通过 Rust SDK 的put_bucket_storage_class 接口完成该配置。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
TOS SDK 支持使用临时访问凭证；也支持配置超时机制、重试策略等多种机制，您可以根据业务需求灵活设置，提升应用安全性。
冷归档与深度冷归档类型仅在华北 2（北京）、华东 2（上海）、华南 1（广州）地域开放，深度冷归档需额外申请邀测。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行put_bucket_storage_class 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:PutBucketStorageClass
