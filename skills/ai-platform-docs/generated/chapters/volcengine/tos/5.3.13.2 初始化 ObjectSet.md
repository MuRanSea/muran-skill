5.3.13.2 初始化 ObjectSet
使用 ObjectSet 功能前，您需要先在存储桶中设置 ObjectSet 的基础配置，并开启 ObjectSet 功能。本文介绍初始化 ObjectSet 功能的具体操作。
注意事项
ObjectSet 的层级深度和自定义分隔符一旦设定后，仅在桶内无任何 ObjectSet 时才可修改，请谨慎操作。操作步骤
登录对象存储控制台 。
在左侧导航栏，单击桶列表。
在顶部导航栏，选择存储桶所属项目。
在桶列表页面，单击目标桶名称。
在左侧导航栏，选择 ObjectSet > ObjectSet 管理。
单击立即初始化 ObjectSet，设置 ** ** ObjectSet 基础信息。
参数 说明
ObjectSet 层级深度
ObjectSet 的目录层级数量。
所有新建 ObjectSet 的路径前缀都必须严格匹
配此层级深度。例如，若指定层级为 2，则 
user/123/ 是合法前缀，而 user/ 或 
user/123/data/ 则不合法。
注意
层级深度一旦设定后，仅在桶内无任
何 ObjectSet 时才可修改。
自定义分隔符
ObjectSet 内部通过分隔符来定义层级。
分隔符长度为 1 个字符，支持 / 、
# 、 - 、 _ 等，默认为 / 。建议使用默
认值 / 。
注意
分隔符一旦设定后，仅在桶内无任何
ObjectSet 时才可修改。
配置默认 ObjectSet QoS 和存储配额
勾选后，可配置 ObjectSet 默认的流控限制与
容量上限。
默认 QoS 流控限制：
ReadsQps：读请求的 QPS，取值范围为
0 到 100000000 的整数，设置为 0 代表不
限制。
◦
单击保存设置。
ObjectSet 初始化过程大约需要 1 分钟时间，请耐心等待。
其他操作
在 ObjectSet 管理页面，您可以修改已初始化的 ObjectSet 基础配置信息，包括 ObjectSet 层级深度、自定义分隔符、配置默认 ObjectSet QoS 和存储配额。
注意
ObjectSet 的层级深度和自定义分隔符一旦设定后，仅在桶内无任何 ObjectSet 时才可修改。参数 说明
WritesQps：写请求的 QPS，取值范围为
0 到 100000000 的整数，设置为 0 代表不
限制。
ListQps：List 请求的 QPS，取值范围为 0
到 100000000 的整数，设置为 0 代表不
限制。
ReadsRate (Mb/s) ：下载带宽，单位为
Mb / s，取值范围为 0 到 100000000 的整
数，设置为 0 代表不限制。
WritesRate (Mb/s) ：上传带宽，单位为
Mb / s，取值范围为 0 到 100000000 的整
数，设置为 0 代表不限制。
默认容量上限：
设置容量上限值，取值范围为 0 到 100
PiB，设置为 0 代表无上限。
