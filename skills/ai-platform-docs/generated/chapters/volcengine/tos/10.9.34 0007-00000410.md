10.9.34 0007-00000410
问题描述
配置的生命周期规则中，多个 Transitions 规则存在时间冲突。
问题原因
配置的生命周期规则中，多个 Transitions 规则存在时间冲突。TOS 要求转到不同存储类型的天数大小满足以下顺序：
低频 < 智能分层 < 归档闪回 < 归档 < 冷归档 < 深度冷归档。
问题示例
以下配置为 30 天转低频存储，3 天转智能分层存储，不满足要求。
解决方案
按照存储类型之间沉降时间要求（低频 < 智能分层 < 归档闪回 < 归档 < 冷归档 < 深度冷归档）设置生命周期规则。 例如设置为 60 天后转换到智能分层存储。

"Prefix": "prefix",
"Status": "Enabled",
"Transitions": [
{
"StorageClass": "IA",
"Days": "30"
},
{
"StorageClass": "INTELLIGENT_TIERING",
"Days": "3"
}
]
}]
}
