7.2.6.3 测试网络速率（probe）
您可以使用 probe 命令，测试上传或下载时的单流速率。
使用系统存储桶测试
使用系统存储桶测试网速时，无需配置 AK 和 SK 等信息，安装 tosutil 工具后即可使用 probe 命令测速。命令格式
Linux/macOS
Windows
参数说明
./tosutil probe [-pt=xxx] [-file=xxx] [-tr=xxx] [-nt=xxx] [-ps=1073741824] [-timeout=30]Bash
tosutil probe [-pt=xxx] [-file=xxx] [-tr=xxx] [-nt=xxx] [-ps=1073741824] [-timeout=30]Bash
参数名 参数类型 描述
-pt String
测速的业务类型。取值说明如
下：
upload（默认）：测试上传
业务速率。
download：测试下载业务
速率。
-file String
测速时用于上传或下载的本地
文件路径。如果未配置该参
数， tosutil 会从内存生成数据
用于上传或将下载的数据从内
存直接丢弃。
-tr String
使用示例
使用系统存储桶测试上传速率
命令
参数名 参数类型 描述
测速的区域，覆盖 TOS 主要区
域。取值说明如下：
cn-beijing（默认）：华北2
（北京）
cn-guangzhou：华南1（广
州）
cn-shanghai：华东2（上
海）
ap-southeast-1：亚太东南
（柔佛）
-nt String
测速的网络类型，支持指定公
网或内网进行测速。取值说明
如下：
public（默认）： 测试公网
速率。
internal：测试内网速率。
-ps String
测速的对象大小，单位：字
节，取值区范围为 [100MB,
5GB]，默认为 1GB。
说明
支持带容量单位配置，
例如，配置 100MB 表
示 104857600 字节。
-timeout Integer 测速的超时时间，单位：秒，
默认为 30。最小为 30。
返回
