问题描述
不支持携带 URL 参数 X-Tos-Policy。
问题原因
采用非 GET、HEAD 请求访问 TOS，并在请求 URL 中携带了 X-Tos-Policy 参数。
问题示例
您通过 PUT 方式访问 TOS，并在请求 URL 中携带了 X-Tos-Policy 参数。
解决方案
使用 GET、HEAD 方式发送请求，或去除请求 URL 中的 X-Tos-Policy 参数。
PUT https://bucketname.tos-cn-beijing.volces.com/
?X-Tos-Algorithm=TOS4-HMAC-SHA256
&X-Tos-Credential=<access-key-id>/<YYYYMMDD>/<region>/tos/request
&X-Tos-Date=20220101T000000Z
&X-Tos-Expires=86400
&X-Tos-Policy=<policy>
&X-Tos-Signature=<signature>
&X-Tos-Security-Token=<security-token>
JSON
