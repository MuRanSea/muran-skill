6.5.1.4 向量索引
6.5.1.4.1 CreateIndex（TOS Vectors Python SDK）
create_index 接口用于创建向量索引，本文介绍如何通过 TOS Vectors Python SDK 的 create_index 接口创建向量索引。接口支持指定索引名称、维度、距离类型与描述。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名（Endpoint）。
为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
TOS Vectors Python SDK 支持使用临时访问凭证；也支持配置超时机制、重试策略等多种机制，您可以根据业务需求灵活设置，提升应用安全性，详细介绍，请参见 常见配置场景。
向量索引名需要在向量桶中唯一。
权限说明
主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行 create_index操作，主账号需通过 IAM策略和桶策略为该子账号授予以下权限：
tosvectors:CreateIndex
代码示例
创建向量索引基本用法
# 创建向量索引基本用法
import os
import tos
# 从环境变量获取 AK 和 SK 信息。
ak = os.getenv("TOS_ACCESS_KEY")
sk = os.getenv("TOS_SECRET_KEY")
# your endpoint 和 your region 填写Bucket 所在区域对应的Endpoint。# 以华北2(北京)为例，your endpoint 填写 https://tosvectors-cn-beijing.volces.com，your region 填写 cn-beijing。endpoint = os.getenv("TOS_ENDPOINT")
region = os.getenv("TOS_REGION")
account_id = os.getenv("TOS_ACCOUNT_ID")
vector_bucket_name = os.getenv("TOS_BUCKET")
try:
# 创建 VectorClient 对象，对向量的操作都通过 VectorClient 实现
 client = tos.VectorClient(ak, sk, endpoint, region)
# 调用 create_index 创建向量索引
相关文档
关于 CreateIndex 的 API 文档，请参见 CreateIndex。
 response = client.create_index(
 account_id=account_id,
 vector_bucket_name=vector_bucket_name,
 index_name="examplevectorindex",
 data_type=tos.DataType.DataTypeFloat32,
 dimension=128,
 distance_metric=tos.DistanceMetricType.DistanceMetricCosine,
 )
# 打印返回结果
print("创建向量索引成功")
print("request_id: {}".format(response.request_id))
print("status_code: {}".format(response.status_code))
except tos.exceptions.TosClientError as e:
# 操作失败，捕获客户端异常，一般情况为非法请求参数或网络异常
print("fail with client error, message:{}, cause: {}".format(e.message, e.cause))except tos.exceptions.TosServerError as e:
# 操作失败，捕获服务端异常，可从返回信息中获取详细错误信息
print("fail with server error, code: {}".format(e.code))
# request id 可定位具体问题，强烈建议日志中保存
print("error with request id: {}".format(e.request_id))
print("error with message: {}".format(e.message))
print("error with http code: {}".format(e.status_code))
print("error with ec: {}".format(e.ec))
print("error with request url: {}".format(e.request_url))
except Exception as e:
print("fail with unknown error: {}".format(e))
