说明
如您需要上传对象到某个文件夹（对象存储的逻辑概念）下，可以为对象名添加以 / 结尾的前缀，且支持多级文件夹，例如对象名 folder1/folder2/objectName 是指将 objectName 上传到 folder1 文件夹下的 folder2 文件夹下。
上传对象到某个文件夹时，由于文件夹只是对象存储的逻辑概念，因此实际上不会在对象存储服务端生成真实的文件夹。
下载对象时，必须使用带前缀的全路径，例如下载对象时需要传入的对象名同样为 folder1/folder2/objectName 。
