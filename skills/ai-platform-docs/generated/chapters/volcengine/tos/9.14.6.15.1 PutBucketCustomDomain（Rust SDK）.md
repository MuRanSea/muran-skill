9.14.6.15 自定义域名
9.14.6.15.1 PutBucketCustomDomain（Rust SDK）
put_bucket_custom_domain 接口用于为存储桶绑定自定义域名，本文介绍如何通过 Rust SDK 的put_bucket_custom_domain 接口完成绑定。绑定后需将域名 CNAME 指向桶外网域名。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
每个存储桶最多可绑定 20 条自定义域名，超出后 put_bucket_custom_domain 将返回错误。请求体中 domain 字段必须填写已通过 ICP 备案的域名，否则 put_bucket_custom_domain 不会生效。若 cert_id 留空，put_bucket_custom_domain 将使用 HTTP 协议；提供 cert_id 后，系统强制使用HTTPS 并校验证书有效性。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行put_bucket_custom_domain 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:PutBucketCustomDomain

let domains = vec![

 ("domain2.com", AuthProtocolType::AuthProtocolS3, "cert-1234567890"),
 ("domain3.com", AuthProtocolType::AuthProtocolTos, ""),
 ];
for (domain, protocol, cert_id) in domains {
// 创建自定义域名规则
let mut rule = CustomDomainRule::new(domain, protocol);
// 如果有证书ID则设置
if !cert_id.is_empty() {
 rule.set_cert_id(cert_id);
 }

let input = PutBucketCustomDomainInput::new("my-bucket", rule);
// 调用接口绑定自定义域名
let output = client.put_bucket_custom_domain(&input).await;
match output {
Ok(output) => {
println!("域名 {} 绑定成功，请求ID: {}", domain, output.request_id());
 }
Err(err) => {
eprintln!("域名 {} 绑定失败: {:?}", domain, err);
 }
 }
