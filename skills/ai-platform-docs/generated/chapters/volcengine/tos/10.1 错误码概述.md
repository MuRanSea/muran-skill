10. 错误码
10.1 错误码概述
当您使用 TOS 出现错误时，TOS 会返回 Code、RequestId、HostId、Message 及 EC 码等信息，方便您快速定位并解决错误。
错误响应示例
响应说明如下：
HTTP/1.1 400 Bad Request
server: TosServer
Date: Fri, 30 Jul 2021 13:55:03 GMT
x-tos-request-id: 580c15f00eca4e70d84e3c4e036d0b64-ac12****
x-tos-id-2: 580c15f00eca4e70d84e3c4e036d0b64-ac12****
x-tos-ec: 0014-00000034
Content-Type: application/json
Content-Length: Content-Length
{
"Error": {
"Code": "InvalidArgument",
"RequestId": "580c15f00eca4e70d84e3c4e036d0b64-ac12****",
"HostId": "kElQBDtQvIsxwFYgDlZVQQszhbHt****",
"Message": "multi destination is not support",
"EC": "0014-00000034"
}
}
JSON
响应 说明
Code 返回的错误码，更多信息，请参见响应码。
RequestId 请求 ID，您可以通过该 ID 排查相应问题。
HostId 请求时使用的 Host 地址。
Message 错误详细描述。
EC
TOS 提供的更细粒度的错误码。每个错误均会对
应一个唯一的 EC Code。与 Code 及 Message 相
比，EC Code 更细粒度，问题描述也更精准，方
便您快速定位问题并发现解决方法。
响应 说明
如果请求出现错误，响应头域（x-tos-ec）和响
应 Body 中都会返回 EC，您可以通过 EC 自助排
查错误的原因及解决方法，具体步骤，请参见使
用 EC 码自助排查。
