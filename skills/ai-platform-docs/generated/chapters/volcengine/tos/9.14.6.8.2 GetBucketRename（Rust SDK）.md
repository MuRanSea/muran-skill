9.14.6.8.2 GetBucketRename（Rust SDK）
get_bucket_rename 接口用于查询存储桶是否开启 RenameObject 功能，本文介绍如何通过 Rust SDK 的get_bucket_rename 接口获取该配置状态。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
该接口仅返回当前存储桶的重命名开关状态，不返回历史配置记录或操作日志。
若存储桶未开启 RenameObject 功能，调用 RenameObject 相关接口将返回 403 Forbidden。权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行get_bucket_rename 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:GetBucketRename
