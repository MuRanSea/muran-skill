7.2.5.9.2 通过授权码列举对象（share-ls）
您可以通过 share-ls 命令，使用授权码查询存储桶内对象，返回的对象列表将按照对象名以字典序排列。
命令格式
Linux/macOS
基于直接输入的授权码，列举桶内对象或列举桶内多版本对象
基于授权码的文件路径，列举桶内对象或列举桶内多版本对象
Windows
基于直接输入的授权码，列举桶内对象或列举桶内多版本对象
基于授权码的文件路径，列举桶内对象或列举桶内多版本对象
参数说明
通用可选参数的说明，请参通用可选参数。
./tosutil share-ls authorization_code [-key=xxx] [-s] [-d] [-v] [-marker=xxx] [-versionIdMarker==xxx] [-bf=xxx] [-limit=1] [-bt=xxx] [-et=xxx] [-conf=xxx]
Bash
./tosutil share-ls file://authorization_code_file_url [-key=xxx] [-s] [-d] [-v] [-marker=xxx] [-versionIdMarker==xxx] [-bf=xxx] [-limit=1] [-bt=xxx] [-et=xxx] [-conf=xxx]
Bash
tosutil share-ls authorization_code [-key=xxx] [-s] [-d] [-v] [-marker=xxx] [-
versionIdMarker==xxx] [-bf=xxx] [-limit=1] [-et=xxx] [-conf=xxx]
Bash
tosutil share-ls file://authorization_code_file_url [-key=xxx] [-s] [-d] [-v] [-marker=xxx] [-versionIdMarker==xxx] [-bf=xxx] [-limit=1] [-et=xxx] [-conf=xxx]
Bash
参数名 参数类型 描述
authorization_code String 使用的授权码。
file://
authorization_code_file_url String 使用的授权码文件路径。
-key String 列举单个对象时的对象名称，
或者列举的对象前缀。
-s Bool 以精简格式显示查询结果。
-d Bool
仅列举当前目录下的对象和子
目录，而非递归列举所有对象
和子目录。
-v Bool
列举桶内多版本对象，如果有
历史版本对象，则列举结果包
含最新版本的对象和历史版本
的对象。
-marker String
列举桶内多版本对象的起始位
置，返回结果包括对象的最新
版本和历史版本。
-versionIdMarker String
列举桶内多版本对象的起始位
置，必须与 -marker 配合使
用。返回结果是对象名和版本
号按照字典序排序后该参数以
后的所有对象。
-bf Enum
列举桶内对象时返回结果中字
节数的显示格式。支持的值：
human-readable
raw

参数名 参数类型 描述
-limit Integer 列举结果的最大个数，最大值
为 100000。
-bt String
存储桶的类型。取值说明如
下：
fns ：扁平桶。
hns ：分层桶。
说明
若未指定存储桶的类
型，在列举文件时，将
默认从桶元数据获取存
储桶的类型；在列举目
录时，将无法识别存储
桶类型，可能导致请求
报错。
-et Enum
指定对返回的对象名进行编码
的编码类型。当前仅支持 
url 。
