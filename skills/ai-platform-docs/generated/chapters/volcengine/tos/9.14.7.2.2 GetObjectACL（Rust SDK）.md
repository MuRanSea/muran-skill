9.14.7.2.2 GetObjectACL（Rust SDK）
get_object_acl 接口用于获取对象的访问控制权限（ACL），支持指定版本。本文介绍如何通过 Rust SDK的 get_object_acl 接口查询 ACL 信息。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
若请求携带 version_id 参数，则返回该 version_id 对应版本的 ACL 信息；未携带时默认返回当前版本的 ACL 信息。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行get_object_acl 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:GetObjectACL
