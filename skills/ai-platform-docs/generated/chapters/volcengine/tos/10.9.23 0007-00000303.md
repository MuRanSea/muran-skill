10.9.23 0007-00000303
问题描述
在生命周期规则中，存在多条 AbortIncompleteMultipartUpload 字段之间，其前缀相同。问题原因
生命周期规则不支持多条 AbortIncompleteMultipartUpload 字段之间有相同前缀。
问题示例
解决方案
相同 prefix 的 AbortIncompleteMultipartUpload 规则只能保留一个。
{
"Rules": [
{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"AbortIncompleteMultipartUpload": {
"DaysAfterInitiation": 1
}
},
{
"ID": "id1",
"Prefix": "prefix",
"Status": "Enabled",
"AbortIncompleteMultipartUpload": {
"DaysAfterInitiation": 1
}
}
]
}
JSON
