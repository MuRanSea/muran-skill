1.3.4 对象存储自定义域名归属信息校验能力说明
为了保证业务的安全性和稳定性，火山引擎对象存储产品预计将于 ** 2026 年 6 月 24 日**上线自定义域名归属信息校验能力。在创建自定义域名时，系统将新增域名归属校验流程，以确认域名所有权。预计变更时间
2026 年 6 月 24 日，具体上线时间请以控制台和实际发布为准。
变更说明
2026 年 6 月 24 日能力上线后，TOS 在创建自定义域名时将校验域名归属信息。
控制台创建场景：控制台将同步完成升级，您按照页面引导完成归属验证后，即可继续绑定域名，正常使用不受影响。
SDK 创建场景：若您通过 SDK 调用接口创建自定义域名，但未完成相应的 SDK 升级适配，请求将会返回报错。报错示例如下：
说明
归属验证记录通常具有有效期，若超时未完成验证，需重新生成记录并再次校验。请以控制台展示信息为准。
对您的影响
如果您主要通过对象存储控制台创建自定义域名，基本不受影响，只需按照页面新增指引完成域名归属验证。
如果您通过 SDK / API 创建自定义域名，需要尽快完成 SDK 升级和适配，以支持新的域名归属校验流程。
如未完成 SDK 升级适配，创建自定义域名时可能出现 NeedVerifyDomainOwnership 报错，导致创建失败。
变更前检查
建议您在变更正式上线前完成以下检查：
梳理当前是否存在通过 SDK / API 创建自定义域名的业务场景。
检查所使用的 SDK 版本及调用逻辑，确认是否已支持域名归属校验。
