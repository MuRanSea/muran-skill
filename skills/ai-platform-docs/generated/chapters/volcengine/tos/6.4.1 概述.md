6.4 API 参考
6.4.1 概述
TOS Vectors 是面向语义检索和 AI 应用打造的高性价比向量存储服务，适用于大规模、长周期存储、高弹性和低频查询等场景的高性价比解决方案。
本文介绍了 TOS Vectors API 接口、请求参数和使用示例，您可以使用本文档提供的 API 对 TOS 服务进行相关操作，如创建向量桶/索引、删除向量桶/索引，上传、下载、删除向量等。
说明
该功能目前处于免费邀测阶段，仅开放华北2（北京）地域，如需使用，请联系客户经理进行申请。
使用说明
TOS Vectors 支持的全部操作，请参见 API 概览。
API 参考主要介绍了接口的请求语法、相关参数的含义以及请求和响应示例。
TOS Vectors 相关概念
术语 描述
向量桶（Vector Bucket）
向量桶是 TOS Vectors 的顶层命名空间，桶名称
在同一账号、同一地域内唯一。在操作 TOS
Vectors 上传向量前，需先创建向量桶。为方便
理解，可以将其类比为数据库的库概念。
向量索引（Vector Index）
向量索引是 TOS Vectors 的次层命名空间，一个
向量桶可以创建多个向量索引，索引名称在同一
向量桶内唯一；一个向量索引相当于向量的容
器，用来存储向量数据。在操作 TOS Vectors 上
传向量前，需在向量桶下创建向量索引。为方便
理解，可以将其类比为数据库的表概念。
向量（Vector）
向量是向量索引中唯一标识某个数据的基本单
元，向量由向量名（key）、向量数据
（data）、向量元数据（metadata）组成。
地域（Region） 地域表示 TOS Vectors 的数据中心所在的地理位
置。
用户（User） 由账号在平台中创建的用户，服务的使用人员，
具有身份凭证（密码和访问密钥）。
访问域名（Endpoint） 表示 TOS Vectors 对外服务的访问域名。
访问密钥 AK（AccessKey ID）
访问密钥 ID。与私有访问密钥关联的唯一标识
符；访问密钥 ID 和私有访问密钥一起使用，对
请求进行加密签名。
术语 描述
私有访问密钥 SK（SecretAccess Key）
与访问密钥 ID 结合使用的私有访问密钥，对请
求进行加密签名，可标识发送方，并防止请求被
修改。
