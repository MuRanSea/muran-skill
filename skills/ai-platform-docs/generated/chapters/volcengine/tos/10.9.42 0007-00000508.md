问题描述
配置的生命周期规则中， NoncurrentVersionTransitions 字段的 NoncurrentDate 参数取值非 UTC 零点。问题原因
配置的生命周期规则中， NoncurrentVersionTransitions 字段的 NoncurrentDate 参数取值非 UTC 零点。问题示例
解决方案
设置 NoncurrentDate 的值为 2024-02-27T00:00:00.000Z 格式，即 UTC 零点。
{
"Rules": [{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"NoncurrentVersionTransitions": [
{
"StorageClass": "IA",
"NoncurrentDate": "2024-02-27T08:00:00.000Z"
}
]
}]
}
JSON
