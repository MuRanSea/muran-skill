7.2.5.4 计算对象和分片大小和数量（du）
您可以通过 du 命令计算整个桶或桶前缀下所有对象和分片上传任务（包括未合并的分片）的总大小和总数量。
注意事项
如果您需要计算的对象数量较多（数量为百万级以上），使用该命令计算时可能会消耗较多时间。如果您确实需要计算对象大小及数量，建议您分目录计算。
命令语法
Linux/macOS
Windows
参数说明
通用可选参数的说明，请参见通用可选参数。
./tosutil du tos://bucket[/prefix] [-d] [-m] [-v] [-bf=xxx] [-bt=xxx] [-e=xxx] [-re=xxx] [-i=xxx] [-k=xxx] [-t=xxx] [-conf=xxx]

Bash
参数名 参数类型 描述
bucket String 计算时指定的桶名。
prefix String 计算时指定的对象名前缀。
-v Bool
同时计算所有对象最新版本以
及历史版本（如果有）的总大
小和总数量。
-m Bool
