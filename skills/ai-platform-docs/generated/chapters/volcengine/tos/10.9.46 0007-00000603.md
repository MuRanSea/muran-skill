问题描述
同一条生命周期规则，或前缀存在包含关系的多条规则， Expiration 和 Transition 之间同时存在 Date和 Days 配置。
问题原因
同一条生命周期规则，或前缀存在包含关系的多条规则， Expiration 和 Transition 之间同时存在 Date和 Days 配置。
问题示例
如下规则配置了 30 天删除，10天转低频存储，但 Expiration 用了 Days ， Transition 用了 Date ，不符合要求。
解决方案
生命周期规则中同时配置 Expiration 和 Transition 时，需要都配置 Days ，或都配置 Date 。
{
"Rules": [{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"Expiration": { "Days": 10 },
"Transitions": [
{
"StorageClass": "IA",
"Date": "2024-02-27T00:00:00.000Z"
}
]
}]
}
JSON
