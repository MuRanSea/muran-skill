6.5.1.1 安装 TOS Vectors Python SDK 
本文介绍 TOS Vectors Python SDK 的下载地址及安装方式。
环境准备
TOS Vectors Python SDK 适用于 Python 3.5 及以上版本。
下载地址
最新源码地址：https://github.com/volcengine/ve-tos-python-sdk
版本修订记录：修订记录
历史版本地址：历史版本
安装方式
目前 TOS Vectors Python Vectors SDK 支持 pip 安装和源码安装两种方式。

执行以下命令。
说明
当前 TOS Vectors 为预览版，使用 TOS Vectors API，请安装 beta版本 2.8.8b1，例如： pip installtos==2.8.8b1 。
通过源码安装
从 Github 下载相应版本的 SDK 包，解压后进入目录，执行如下命令。
