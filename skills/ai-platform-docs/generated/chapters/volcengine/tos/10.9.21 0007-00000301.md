问题描述
配置的生命周期规则中， AbortIncompleteMultipartUpload 字段的 DaysAfterInitiation 参数取值小于等于 0。问题原因
配置的生命周期规则中， AbortIncompleteMultipartUpload 字段的 DaysAfterInitiation 参数取值小于等于 0。要求其大于 0。
问题示例
解决方案
设置 DaysAfterInitiation 的值大于 0。
{
"Rules": [{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"AbortIncompleteMultipartUpload": { "DaysAfterInitiation": 0 }
}]
}
