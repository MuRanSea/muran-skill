5.3.5 查看桶信息
对象存储 TOS 支持在控制台查看存储桶基本信息。您也可以将账号下所有桶的信息导出到本地，然后在本地查看桶信息。
注意事项
主账号默认拥有全部权限，IAM 子用户默认没有任何权限。如果您需要使用子账号执行以下操作，则需要主账号通过 IAM 策略 或桶策略 为该子账号授予以下权限：
查看桶信息： tos:ListBuckets
查看访问权限： tos:GetBucketAcl 、 tos:GetBucketPolicy
查看默认存储类型： tos:HeadBucket
查看冗余类型： tos:HeadBucket
查看容量指标： Volc_Observe:GetMetricsData
查看桶列表
操作步骤
登录对象存储控制台 。
在左侧导航栏，单击桶列表，在页面右上方，单击设置图标。
在弹出的对话框，选择您想在桶列表展示的字段。
选择字段后，桶列表页面就会展示您自定义的字段信息。
字段说明
字段 说明
桶名称 存储桶的名称，默认展示，无法选择。
桶类别 存储桶类型。
操作 在桶列表页面支持执行的操作，当前仅支持删除
操作。默认展示，无法选择。
区域 存储桶所属地域。
匿名访问
存储桶的访问权限，说明如下：
公共读：任何用户都拥有存储桶的读权限，
但仅存储桶拥有者及授权账号具有写权限。
公共写：任何用户都拥有存储桶的写权限，
但仅存储桶拥有者及授权账号具有读权限。
公共读写：任何用户都拥有存储桶的读写权
限。
私有：仅存储桶拥有者及授权账号具有存储
桶的读写权限。
字段 说明
注意
当桶 ACL 和桶 Policy 同时允许公共
读，且桶内对象 ACL 开启默认继承
桶，则判断为公共读；否则判断为禁
止公共读。
当桶 ACL 和桶 Policy 同时允许公共
写，则判断为公共写；否则判断为禁
止公共写。
在桶列表页面显示的存储桶访问权限
根据已有的桶策略（Bucket Policy）
和 ACL 权限计算得出的结果，未考虑
IAM 权限配置。若您已配置 IAM 权
限，页面展示的访问权限将可能不准
确。如需修改 ACL、Policy 访问权
限，请参见桶 ACLs 和存储桶授权
策略 。
标签 存储桶的标签，详细介绍，请参见设置桶标签。
默认存储类型 存储桶的默认存储类型。
冗余类型 存储桶的冗余类型，详细介绍，请参见多 AZ 冗
余。
容量 存储桶的计费总存储量。
本月公网流量 存储桶自然月累计使用的公网流出流量。
本月访问次数
存储桶自然月累计调用 API 的次数，包括 Put 类
请求和 Get 类请求，详细介绍，请参见 Put 类
和 Get 类请求的 API 明细。
标准存储容量 标准存储类型的对象在存储桶中的存储量。
低频存储计费容量 低频存储类型的对象在存储桶中的计费存储量。
归档闪回存储计费容量 归档闪回存储类型的对象在存储桶中的计费存储
量。
归档存储计费容量 归档存储类型的对象在存储桶中的计费存储量。
冷归档存储计费容量 冷归档存储类型的对象在存储桶中的计费存储
量。
智能分层计费容量 智能分层存储类型的对象在存储桶中的计费存储
量。
智能分层高频访问层存储计费容量 智能分层高频访问层的对象在存储桶中的计费存
储量。
查看桶详情
登录对象存储控制台 。
在左侧导航栏，单击桶列表。
在顶部导航栏，选择存储桶所属项目。
在桶列表页面，单击目标桶名称。
在左侧导航栏，单击概览，在右侧页面查看该存储桶的用量概览、基本信息和访问域名等信息。说明
关于存储桶概览参数详细介绍，请参见存储桶概览。
其他操作
字段 说明

储量。
智能分层归档闪回访问层存储计费容量 智能分层归档闪回访问层的对象在存储桶中的计

深度冷归档计费容量 深度冷归档存储类型的对象在存储桶中的计费存

创建时间 存储桶的创建时间。
项目 存储桶所属项目，详细介绍，请参见项目管理。
操作 说明
导出桶信息 在桶列表页面右上方，单击下载图标，在弹出的
页面选择您想导出的信息类目，单击确定。
存储桶排序 在桶列表页面，单击桶名称/容量/创建时间列的
排序图标即可进行排序。
