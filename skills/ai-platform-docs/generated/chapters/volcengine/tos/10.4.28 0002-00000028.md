10.4.28 0002-00000028
问题描述
携带 X-Tos-Policy 参数的预签名 URL 中，缺少必要参数。
问题原因
使用携带 X-Tos-Policy 参数的预签名 URL 访问 TOS，但 URL 中缺少必要的参数。
问题示例
您使用携带 X-Tos-Policy 参数的预签名 URL 发起请求，但 URL 中未包含预签名必须的参数。在预签名 URL 中，参数 X-Tos-Algorithm 、 X-Tos-Credential 、 X-Tos-Date 、 X-Tos-Expires 、 X-TosPolicy 、 X-Tos-Signature 为必选参数。上述请求中缺少了必选参数 X-Tos-Signature 。解决方案
采用正确的方式构造携带 X-Tos-Policy 参数的 URL。具体操作，请参见携带查询参数 X-Tos-Policy 的URL 预签名 。
GET https://bucketname.tos-cn-beijing.volces.com/
?X-Tos-Algorithm=TOS4-HMAC-SHA256
&X-Tos-Credential=<access-key-id>/<YYYYMMDD>/<region>/tos/request
&X-Tos-Date=20220101T000000Z
&X-Tos-Expires=86400
&X-Tos-Policy=<policy>
&X-Tos-Security-Token=<security-token>
JSON
