9.14.6.1.4 HeadBucket（Rust SDK）
head_bucket 接口用于判断桶是否存在及访问权限，本文介绍如何通过 Rust SDK 的 head_bucket 接口完成该操作。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
当桶不存在或权限不足时，接口返回 404 Not Found 或 403 Forbidden，不会返回响应消息头中的桶元数据。
若需获取桶的存储类型、可用区冗余类型等属性，必须确保请求身份已获授权且桶存在，否则无法读取对应响应头。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行head_bucket 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：
tos:HeadBucket

let region = "cn-beijing";

 }
