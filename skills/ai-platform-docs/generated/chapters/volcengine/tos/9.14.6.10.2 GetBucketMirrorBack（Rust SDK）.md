9.14.6.10.2 GetBucketMirrorBack（Rust SDK）
get_bucket_mirror_back 接口用于获取 Bucket 的回源规则，本文介绍如何通过 Rust SDK 的get_bucket_mirror_back 接口读取已配置的镜像或重定向回源策略。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
分层桶不支持调用 get_bucket_mirror_back。
仅当下载请求返回 404 时，回源条件才会生效。
回源地址最多配置 5 个，单地址长度不超过 255 个字符。
透传 Host、Content-Length、Date、Authorization 类型的 HTTP Header 会被自动过滤。权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行get_bucket_mirror_back 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:GetBucketMirrorBack
