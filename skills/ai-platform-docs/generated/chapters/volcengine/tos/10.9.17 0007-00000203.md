问题描述
生命周期规则中的 NoncurrentVersionExpiration 字段的 NoncurrentDays 参数取值小于 0。问题原因
生命周期规则中的 NoncurrentVersionExpiration 字段的 NoncurrentDays 参数取值小于 0，要求其取值大于0。
问题示例
解决方案
设置 NoncurrentDays 大于0。
{
"Rules": [{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"NoncurrentVersionExpiration": {
"NoncurrentDays": -1
}
}]
}
