9.10.2 安装 PHP SDK
本文介绍如何安装 TOS PHP SDK。
环境准备
TOS PHP SDK 适用于 PHP 5.6 及以上版本，本文档后续均以 PHP 5.6 为例。
说明
由于 TOS 提供的是 HTTP 协议接口，因此您的 PHP 环境需要通过 php.ini 配置开启 cURL 和OpenSSL 扩展库，用于发送 HTTP 或 HTTPS 请求。
当前支持的操作系统：Linux、macOS 及 Windows。
源码下载
TOS PHP SDK 源码请参见：GitHub 。
版本修订记录信息：CHANGELOG 。
安装方式
您可以使用以下方式安装 SDK：
（推荐）使用 PHP 的包管理工具 composer
注意
composer V1 版本已于2025年9月1日停止支持，请使用 composer V2 版本。
运行以下代码将 Composer 从 V1.x 升级到 V2.x。
直接运行 composer require volcengine/ve-tos-php-sdk ，或者在 composer.json 文件中添加如下依赖关系再运行 composer install 。
// 下载指定版本的 Composer 2
curl -sS https://getcomposer.org/installer | php -- --version=2.7.6
//安装到全局 PATH
sudo mv composer.phar /usr/bin/composer
//验证
composer --version
PHP
安装成功后，TOS PHP SDK 会被包含到 vendor/ 目录下，在代码中可以通过如下方式引入依赖。使用 TOS PHP SDK 的 phar 文件
在 GitHub 选择相应的版本并直接下载打包好的 phar 文件。
在代码中通过如下方式引入依赖。
使用 TOS PHP SDK 源码
在 GitHub 选择相应的版本并直接下载源码。
下载完成后，TOS PHP SDK 源码中会包含 autoload.php 文件，在代码中可以通过如下方式引入依赖。
{
"require": {
"volcengine/ve-tos-php-sdk": "^2.1"
}
}
json
// 假设需要集成 SDK 的脚本与 vendor/ 目录在同一个父目录下
require_once __DIR__ . '/vendor/autoload.php';
php
// 假设使用源码安装且需要集成 SDK 的脚本与 TOS PHP SDK 的源码在同一个父目录下
require_once __DIR__ . '/ve-tos-php-sdk-2.x.x.phar';
php
// 假设使用源码安装且需要集成 SDK 的脚本与 TOS PHP SDK 的源码在同一个父目录下
require_once __DIR__ . '/autoload.php';
php
