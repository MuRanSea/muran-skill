9.14.6.5 跨域资源共享
9.14.6.5.1 PutBucketCORS（Rust SDK）
put_bucket_cors 接口用于为存储桶设置 CORS 规则，本文介绍如何通过 Rust SDK 的 put_bucket_cors 接口配置跨域访问。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
所有 CORS 规则总大小不可超过 20 KiB。
若设置 ResponseVary 为 true ，响应会携带 Vary: Origin 头，可能增加浏览或回源次数。权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行put_bucket_cors 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:PutBucketCORS

 rule.set_response_vary(true);
let input = PutBucketCORSInput::new_with_rules(bucket_name, vec![rule]);
let output = client.put_bucket_cors(&input).await;
