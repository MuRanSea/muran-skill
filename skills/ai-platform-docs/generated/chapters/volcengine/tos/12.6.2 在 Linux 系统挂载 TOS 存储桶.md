12.6.2 在 Linux 系统挂载 TOS 存储桶
TOS 支持将存储桶挂载为 Linux 磁盘，像文件系统一样管理存储桶。本文以 CentOS stream8 的 ECS 实例为例，介绍如何通过 Goofys 和 S3FS 挂载存储桶。
前提条件
确保账号拥有存储桶的读写权限，并获取该账号的 Access Key ID 和 Secret Access Key。更多信息，请参见 Access Key（密钥）管理 。
已获取存储桶的 S3 Endpoint。更多信息，请参见地域和访问域名（Endpoint）。
使用 root 用户或者具有 sudo 权限的用户。
注意事项
S3FS 无法提供与本地文件系统相同的性能。 由于网络延迟，元数据操作（例如列出目录）性能较差。随机或者追加写文件会导致整个文件的下载以及重新上传。当多个客户端挂载同一个 TOS 存储桶时，您需要自行协调各个客户端的行为。更多 S3FS 工具的注意事项，请参见 S3FS 。
使用 Goofys 或 S3FS 工具挂载存储桶适用于小量测试等场景，不建议生产环境使用此方式。说明
FSX 工具具有强大的崩溃恢复能力，可以有效减少数据丢失和服务中断时间，提高系统的可靠性和安全性。强烈推荐使用 FSX 工具挂载存储桶。详细介绍，请参见概述 。
