9.2.6.3.5 基础操作
创建 ObjectSet（Java SDK）
本文介绍如何通过 TOS Java SDK 在已开启 ObjectSet 的 Bucket 中创建一个 ObjectSet，并可同时设置ObjectSet 标签。
注意事项
Bucket 必须已开启 ObjectSet，可先调用 putBucketObjectSetConfiguration 配置。
如果已存在同名 ObjectSet，服务端会返回 ObjectSet 已存在相关错误。
通过子账号调用时，需要具备当前 Bucket 的 tos:PutObjectSet 权限。
代码示例
import com.volcengine.tos.TOSV2;
import com.volcengine.tos.TOSV2ClientBuilder;
import com.volcengine.tos.TosClientException;
import com.volcengine.tos.TosServerException;
import com.volcengine.tos.model.bucket.PutObjectSetInput;
import com.volcengine.tos.model.bucket.PutObjectSetOutput;
import com.volcengine.tos.model.bucket.Tag;
import com.volcengine.tos.model.object.TagSet;
import java.util.Collections;
public class PutObjectSetExample {
public static void main(String[] args) {
String endpoint = System.getenv("TOS_ENDPOINT");
String region = System.getenv("TOS_REGION");
String accessKey = System.getenv("TOS_ACCESS_KEY");
String secretKey = System.getenv("TOS_SECRET_KEY");
String bucket = System.getenv("TOS_BUCKET");
String objectSetName = System.getenv("TOS_OBJECT_SET_NAME");
TOSV2 tos = new TOSV2ClientBuilder().build(region, endpoint, accessKey, secretKey);try {
Tag tag = Tag.builder().key("owner").value("java-sdk-example").build();
TagSet tagSet = TagSet.builder().tags(Collections.singletonList(tag)).build();
PutObjectSetInput input = PutObjectSetInput.builder()
 .bucket(bucket)
 .objectSetName(objectSetName)
 .tagSet(tagSet)

列举 ObjectSet（Java SDK）
本文介绍如何通过 TOS Java SDK 列举 Bucket 下的 ObjectSet，支持按前缀、标签和 marker 分页过滤。注意事项
Bucket 必须已开启 ObjectSet。
通过子账号调用时，需要具备当前 Bucket 的 tos:ListObjectSet 权限。
maxKeys 默认值和最大值均由服务端控制，最大值为 1000。
当返回结果被截断时，可使用 nextMarker 继续列举。
代码示例
import com.volcengine.tos.TOSV2;
import com.volcengine.tos.TOSV2ClientBuilder;
import com.volcengine.tos.TosClientException;
import com.volcengine.tos.TosServerException;
import com.volcengine.tos.model.bucket.ListObjectSetsInput;
import com.volcengine.tos.model.bucket.ListObjectSetsOutput;
import com.volcengine.tos.model.bucket.ObjectSetInfo;
public class ListObjectSetsExample {
public static void main(String[] args) {
String endpoint = System.getenv("TOS_ENDPOINT");
String region = System.getenv("TOS_REGION");
String accessKey = System.getenv("TOS_ACCESS_KEY");
String secretKey = System.getenv("TOS_SECRET_KEY");
String bucket = System.getenv("TOS_BUCKET");
String prefix = System.getenv("TOS_OBJECT_SET_PREFIX");
TOSV2 tos = new TOSV2ClientBuilder().build(region, endpoint, accessKey, secretKey);try {
String marker = null;
do {
ListObjectSetsInput input = ListObjectSetsInput.builder()
 .bucket(bucket)
 .prefix(prefix)
 .maxKeys(100)
 .marker(marker)
 .build();

查询 ObjectSet（Java SDK）

ObjectSet 必须存在，不存在时服务端会返回 ObjectSetNotExist 。
通过子账号调用时，需要具备当前 Bucket 的 tos:GetObjectSet 权限。
ObjectSetName 需满足 Bucket 的 ObjectSet 分隔符和层级配置。

删除 ObjectSet（Java SDK）
本文介绍如何通过 TOS Java SDK 删除指定 ObjectSet 的元数据。
注意事项
只删除 ObjectSet 相关元数据，不删除对象数据。
通过子账号调用时，需要具备当前 Bucket 的 tos:DeleteObjectSet 权限。
删除前请确认 objectSetName 指向的 ObjectSet 不再需要。
