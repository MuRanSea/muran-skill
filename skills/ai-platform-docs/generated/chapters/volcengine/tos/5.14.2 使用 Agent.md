5.14.2 使用 Agent
本文主要介绍 TOS Agent 的界面布局及使用操作。
说明
TOS Agent 功能目前处于邀测状态。如需使用，请联系客户经理。
前提条件
请确保您已注册火山引擎账号并完成实名认证，具体步骤，请参见账号注册 和实名认证 。请确保您的账号或者子账号已开通 TOS 服务，具体步骤，请参见开通 TOS 服务。
使用 TOS Agent
登录对象存储控制台 。
在左侧导航栏单击 **TOS Agent ** 进入会话页面。
在页面下方对话框中输入您的需求，或选择首页展示的场景卡片上的问题快速开始。
TOS Agent 界面由以下三个区域组成：
左侧栏：提供新建会话、Region 和 Bucket ** 选择框以及历史任务**列表。
中间对话框：输入需求与 TOS Agent 交互。输入框支持使用 @ 临时引用 Bucket 和 Flow 规则，指定该Bucket 或 Flow 规则进行操作。
右侧工作区：Agent 与控制台之间的协同联动区域，默认不显示。仅当输入需求涉及创建桶、上传对象相关描述时，才会弹出待填写表单。
使用案例参考
通用对话交互
用户通过自然语言与 TOS Agent 进行对话，Agent 回复时会展示完整的思考和执行过程，帮助用户实时了解处理状态。
访问异常诊断
当用户遇到 TOS 资源访问异常时，Agent 会自动诊断定位原因（如签名过期、权限拒绝等），输出结构化的原因分析和分步修复方案。涉及修改配置等敏感操作时，需用户二次确认后才执行。
创建存储桶
用户以自然语言描述创建桶需求，Agent 将其解析为结构化表单参数并打开结构化表单供用户确认填写后提交，完成创建。若操作因权限不足等原因失败，Agent 将展示具体错误原因，支持重试或取消。数据洞察
Agent 作为数据分析助手，支持查询桶内资源使用状况，如存储情况、带宽、流控及总体评估等，帮助用户了解资源使用状态。
多模态检索
输入框输入您的文件检索需求，Agent 会将单个结果以大图/视频预览弹窗展示（支持缩放、下载等操作）。
