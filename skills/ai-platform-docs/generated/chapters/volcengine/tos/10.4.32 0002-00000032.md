10.4.32 0002-00000032
问题描述
签名 URL 已过期。
问题原因
使用过期的签名 URL 发送请求。
问题示例
您使用基于 URL 签名的方式发起请求，但该 URL 已过期。
该请求的时间为 20220721T201207Z ，URL 有效期为 604800 ，若在 2023 年使用该 URL 发送请求，则返回该错误。
解决方案
确保签名 URL 未过期。
GET https://bucketname.tos-cn-beijing.volces.com/object
?X-Tos-Algorithm=TOS4-HMAC-SHA256
&X-Tos-Credential=<access-key-id>/<YYYYMMDD>/<region>/tos/request
&X-Tos-Date=20220721T201207Z
&X-Tos-Expires=604800
&X-Tos-SignedHeaders=host
&X-Tos-Signature=<signature> 
&X-Tos-Security-Token=<security-token>
JSON
