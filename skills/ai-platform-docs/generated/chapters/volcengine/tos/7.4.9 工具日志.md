日志搜集
如果您在使用 FSX 过程中出现异常情况，建议您先运行 /opt/fsx/tools/sysinfo_collector.sh 脚本，该脚本会自动收集系统基本信息、挂载点信息、系统日志等内容，并默认会在脚本所在目录生成一个 
system_info__.tar.gz 压缩文件。您可以提交工单 将该压缩文件发送给我们，我们将协助您解决问题。注意
请勿在挂载目录运行 /opt/fsx/tools/sysinfo_collector.sh 脚本。异常情况下，在挂载目录使用脚本收集信息可能会失败。
cd /opt/fsx/bin && ./fusetool flags set --instance tos --flag v --value 20 --forcePlain
cd /opt/fsx/bin && ./fusetool flags set --instance tos --flag tosfuse_log_level --value 1 --forcePlain
