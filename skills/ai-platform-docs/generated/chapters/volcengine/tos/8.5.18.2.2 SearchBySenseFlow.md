8.5.18.2.2 SearchBySenseFlow 
功能描述
调用 SearchBySenseFlow 接口，可根据指定 SenseFlow Rule 对已建立索引的桶内对象执行智能检索。支持文档、图片和视频检索。
支持组合文本查询与结构化过滤条件，并按需返回相关文本片段。
接口会在执行检索前，依次进行如下校验： 
Rule 是否存在。
Rule 是否与请求中的桶关联。
Rule 是否已开启所请求的检索类型。
校验通过后使用该 Rule 对应的数据集执行检索。
注意事项
前提条件
调用接口前，必须已创建 SenseFlow Rule，并为 Rule 开启 Search 能力。
SearchTypes 仅支持 doc 、 image 和 video ，且请求中的每种类型都必须已在 Rule 中开启。其中， doc 类型当前仅支持检索 .txt 格式文件。

权限控制
调用方需拥有 tos:SearchBySenseFlow 权限，授权
资源为 
trn:tos::<account-id>:senseflow/rule/<rule-id> 。
请求参数
请求路径 /v1/senseflow/search 必须填写 
RuleId 和 BucketName 。
BucketName 必须与 Rule 关联的桶一致。
返回结果
单次最多返回 100 条结果；未指定或指定非
正数时，默认返回 10 条；超过 100 时按 100
条处理。
仅单一媒体类型检索支持使用 NextToken 翻
页；一次请求包含多个 SearchTypes 时，不
返回翻页 Token。
当 Rule 对应的检索数据集尚不存在时，接口
返回 HTTP 200 和空结果，而非 404。
