5.6.6.2.2 授予 IAM 用户指定桶上传和下载对象的权限
本文档介绍如何授予当前账号下的 IAM 用户指定桶上传和下载对象的权限。
场景说明
授权账号：当前账号（本文以 210015**** 为例）下的 iamuser 用户。
授权资源： bucketname 存储桶。
动作：GetObject 和 PutObject
注意事项
权限配置后略有延迟，如果您配置的权限没有立即生效，建议您稍后重试。
操作步骤
登录对象存储控制台 。
在左侧导航栏，单击桶列表。
在顶部导航栏，选择存储桶所属项目。
在桶列表页面，单击目标桶名称。
在左侧导航栏，选择权限管理 > 存储桶授权策略管理。
根据需要选择授权方式。
可视化视图
单击创建策略。
在创建存储桶授权策略页面，选择自定义策略模板，然后单击下一步。
设置如下参数。

相关操作
根据本文授权后，可以使用 API 或 SDK 完成上传或下载对象的操作，
控制台：如果要在控制台上传或下载对象，还需要通过 IAM 策略授予用户列举桶（ListBuckets）、列举桶内对象（ListBucket）、判断桶是否存在（HeadBucket）的权限。
TOS Browser：如果要在 TOS Browser 工具上传或下载对象，则还需要通过 IAM 策略授予用户列举桶内对象（ListBucket）的权限。
关于 IAM 策略支持的 Action 说明，请参见 IAM 策略支持动作。
