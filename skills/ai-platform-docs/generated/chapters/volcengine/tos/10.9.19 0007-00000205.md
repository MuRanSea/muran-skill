问题描述
生命周期规则中 NoncurrentVersionExpiration 字段的 NoncurrentDate 参数取值非 UTC 零点。问题原因
生命周期规则中 NoncurrentVersionExpiration 字段的 NoncurrentDate 参数取值非 UTC 零点。问题示例
解决方案
设置 NoncurrentDate 参数的值为 UTC 零点。
{
"Rules": [{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"NoncurrentVersionExpiration": {
"NoncurrentDate": "2024-02-27T08:00:00.000Z"
}
}]
}
JSON
