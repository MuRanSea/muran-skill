10.8.15 0006-00000403
问题描述
rename 配置中 RenameEnable 字段取值非 true 。
问题原因
用户配置 rename 时， RenameEnable 字段取值非 true 。
问题示例
您发起 rename 配置请求， RenameEnable 字段取值非法。
解决方案
rename 配置时确保 RenameEnable 字段取值为 true 。
PUT /?rename HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: GMT Date
Authorization: authorization xxx
{ 
"RenameEnable":false
}
Go
