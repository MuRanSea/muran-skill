7.5.3 配置TOS PyTorch Connector
TOS PyTorch Connector 在与 TOS 进行交互时，需要有效的访问凭证来验证请求的合法性。本文将详细介绍如何为 TOS PyTorch Connector 配置鉴权信息与参数配置。
前提条件
已安装 TOS PyTorch Connector。具体操作，请参见安装 TOS PyTorch Connector。
鉴权方式
为了确保访问 TOS 服务的安全性，您必须提供有效的访问密钥 (AK/SK)。TOS PyTorch Connector 推荐采用直接传参的方式，将凭证在代码中显式传递。通过 CredentialProvider(ak=ak, sk=sk) 对象，在创建TosMapDataset 、 TosIterableDataset 或 TosCheckpoint 实例时直接传入 cred 参数。该方式代码可移植性强，且凭证作用域清晰，不会污染全局环境。
配置 TOS PyTorch Connector
通过 CredentialProvider 将访问密钥直接传递给 TOS PyTorch Connector 是最灵活和推荐的方式。获取访问密钥 (AK/SK)
访问密钥是您访问 TOS 服务的安全凭证，请妥善保管。
获取途径：登录火山引擎控制台 ，在访问控制 ＞ API访问密钥页面创建和管理您的 Access Key。权限管理：为了安全起见，强烈建议遵循最小权限原则。请为您的 AK/SK 分配精确的权限策略。如果您的应用仅需要读取训练数据，请为其授予 TOS 的只读权限 TosReadOnlyAccess ，这可以有效防止因密钥泄露导致的数据篡改或删除风险。
传入凭证

import torch
from tostorchconnector import TosCheckpoint, CredentialProvider
checkpoint_uri = 'tos://bucket/key'
region = 'cn-beijing'
endpoint = 'http://tos-cn-beijing.ivolces.com'
ak = '<your-access-key>'
sk = '<your-secret-key>'
with TosCheckpoint(region, endpoint, cred=CredentialProvider(ak, sk)) as checkpoint:
#写数据
with checkpoint.writer(checkpoint_uri) as writer:
 writer.write(b'hello')
 writer.write(b'world')
# 读数据
with checkpoint.reader(checkpoint_uri) as reader:
 data = reader.read()
assert data == b'helloworld'
