9.14.7.1.8 SetObjectMeta（Rust SDK）
set_object_meta 接口用于更新已上传对象的元数据，本文介绍如何通过 Rust SDK 的 set_object_meta 接口替换 Cache-Control、Content-Type、x-tos-meta-* 等头域。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
调用 set_object_meta 时，未在请求头中显式给出的元数据将被全部删除，仅保留本次提交的值。若目标对象处于归档、冷归档或深度冷归档存储类型，需先完成 restore_object 操作，再调用set_object_meta。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行set_object_meta 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:PutObject
