5.4.19 对象托管
本文介绍对象存储 TOS 提供的对象托管能力。
功能说明
对象托管是对象存储 TOS 提供的用于支持用户存储桶中的对象被其他服务托管的能力，真正的托管动作发生在对应的托管服务处。对象被托管后，将由托管服务统一管理，保证该对象在被持续读取或调用的链路中保持稳定、不被误改。

计费说明
对象被其他服务托管后，相关费用的承担方有所区分：
项目 说明
能力提供方 TOS 提供“用户对象可被其他服务托管”的能
力，托管动作本身在对应的托管服务处产生。
权限变化
对象被托管后，用户仅可读取对象，不支持通
过 TOS 控制台或 TOS API 删除、覆盖、修改该
对象，命中该对象的生命周期删除、覆盖式复制
等异步写、删、改链路，也会受到托管保护限
制。托管服务仍可按其业务链路管理对象。
托管服务标识
在 TOS 控制台中，被托管对象会显示对应的托
管服务名称。例如被方舟托管的对象，会显
示“Ark 托管”。
取消托管
托管动作由托管服务方发起，能否取消托管需咨
询对应的托管服务方，无法在 TOS 侧直接解
除。
场景 说明
对象交由其他服务托管 用户将存储桶中的对象交由其他服务托管，由该
服务统一管理对象的状态与生命周期。
数据持续调用
对象在被托管服务持续读取或调用期间，需要保
证文件稳定、不被中途变更的场景。如方舟推
理/精调等。
文件一致性保障 需要确保对象不被误删、误改的场景，依托只读
权限保障数据一致性。
使用说明
使用前提
已开通对象存储 TOS 服务，并创建存储桶。
已接入需要托管对象的其他服务（如方舟等）。
使用流程
通过对应的托管服务创建新的托管对象。
托管完成后，被托管对象进入只读状态，用户仅保留对该对象的只读权限。
在 TOS 控制台可查看被托管对象，被托管对象会显示对应的托管服务名称（例如“Ark 托管”）。如需取消托管或对被托管对象进行变更，请咨询对应的托管服务方。
常见问题
对象被托管后，我还能删除或修改它吗？
不能。对象被托管后，用户仅可读取对象，但无法通过 TOS 控制台或 TOS API 删除、覆盖、修改该对象，命中该对象的生命周期删除、覆盖式复制等异步写、删、改链路，也会受到托管保护限制；托管服务仍可按其业务链路管理对象。因此建议谨慎托管对象。
如何取消对象的托管？
托管动作由托管服务方发起，如何取消托管需咨询对应的托管服务方，无法在 TOS 侧直接解除。对象被托管后会产生哪些费用，分别由谁承担？
托管服务方：被托管对象的数据处理费用。
用户：存储容量、流量、请求次数、数据取回等其他费用，具体明细可参考对象存储计费概述 。如何确认某个对象已被托管、以及被哪个服务托管？
在 TOS 控制台中，被托管对象会显示对应的托管服务名称（例如被方舟托管的对象显示“Ark 托管”），并且对其执行删除、修改等操作会被禁止，据此即可判断对象是否被托管及托管方。费用类型 承担方 说明
数据处理费用 托管服务方
被托管对象产生的数据处理费
用由托管服务方承担，用户无
需为此付费。
其他费用 用户
除数据处理费用由托管服务方
承担外，被托管对象的其他费
用（如存储容量费用、流量费
用、请求次数费用、数据取回
费用等）均按对象存储 TOS 的
正常标准由用户承担，具体计
费明细可参考对象存储计费概
述 。
通过调用 HeadObject 、GetObject 接口，从响应消息头当中的 x-tos-service-managed-by header 字段获取托管服务名称。
通过调用 ListObjects 、ListObjectsV2 接口，从响应元素当中的 ServiceManagedBy 字段获取托管服务名称。
