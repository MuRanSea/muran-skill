5.4.10 管理对象元数据
对象元数据是一组描述对象属性的健值对。元数据分为 HTTP 标准属性和用户自定义两类。本文介绍对象元数据的说明及设置对象元数据的操作步骤。
HTTP 标准属性
名称 说明 是否可修改
Content-Disposition
指定浏览器访问对象时的展示
形式，是以内联形式（即网页
或者页面的一部分），还是以
附件的形式下载保存到本地：
当该值设置为 
attachment;filename="test.png" ，
表示下载对象到本地，并以
test.png 对象名进行保存。
说明
在浏览器访问 TOS 对
象时，对象的展示形式
还和存储桶的创建时
间、域名类型等相关，
详细介绍，请参见如何
在浏览器预览对象？。
是
Content-Encoding
指定对象被下载时的编码格
式。
请按实际编码类型填写，否则
可能导致解析编码失败。若对
象未编码，该项无需设置。
是
Content-Language 指定对象内容使用的语言。 是
Content-Length 对象的大小，单位为字节。 否
Content-Type
指定对象的对象类型， 使用浏
览器访问对象时，浏览器会根
据 Content-Type 决定以何种
形式打开该对象。
使用控制台和 SDK 等工具上传
对象时，会根据对象的对象扩
展名，匹配对应的 ContentType。如果对象没有对象扩展
名，则对象默认 ContentType 为 
application/octet-stream 。
是
常见的 Content-Type
名称 说明 是否可修改
Content-Type的常见类型，请
参见常见的 Content-Type。
Cache-Control
指定对象在浏览器上的缓存机
制，取值说明如下：
可缓冲性：public、
private、no-cache、onlyif-cached。
到期时间：maxage=<seconds>、smaxage=<seconds>、maxstale[=<seconds>]、minfresh=<seconds>、stalewhilerevalidate=<seconds>、stale-if-error=<seconds>。
重新验证和重新加载：
must-revalidate、proxyrevalidate、immutable。
其他：no-store、notransform。
是
Expires
缓存过期时间(GMT)，若
Cache-Control 设置了 maxage=<seconds> ， 则以 maxage 为准。
是
Last-Modified 对象的最后修改时间。 否

用户自定义元数据
TOS 支持以 "x-tos-meta-" 开头，设置自定义的元数据，用于对象的自定义管理。在获取对象或查询对象元数据时，消息头中会返回自定义元数据。一个对象可以有多个自定义元数据，但所有的自定义元数据大小不能超过 8KB。
设置对象元数据
本文介绍为已上传的对象设置元数据的操作步骤。如果您希望在上传对象时设置元数据，具体步骤，请参见上传文件。
注意
归档、冷归档和深度冷归档类型的对象需要先恢复为可读取状态，才能设置元数据。
登录对象存储控制台 。
在左侧导航栏，单击桶列表。
在顶部导航栏，选择存储桶所属项目。
在桶列表页面，单击目标桶名称。
在文件列表页面，选择指定文件操作列的 ··· > 修改元数据信息。
在弹出的对话框中，根据需要设置元数据信息。
设置完成后，单击保存。
