7.2.5.11 删除桶、对象或分片上传任务（rm）
您可以使用 rm 命令删除桶及桶内的对象和分片任务。
删除桶
注意事项
删除存储桶前，请确保桶内的对象及分片均已删除。
删除资源时需要工具会提示您进行二次确认，取值说明如下： 
y ：表示确认删除。
n ：表示不删除，不会执行删除操作。
命令格式
Linux/macOS
Windows
参数说明
通用可选参数的说明，请参见通用可选参数。
使用示例
以下命令用于删除 bucketname1 存储桶。
命令
◦
◦
./tosutil rm tos://bucket [-f] [-e=xxx] [-re=xxx] [-i=xxx] [-k=xxx] [-t=xxx] [-conf=xxx]Bash
tosutil rm tos://bucket [-f] [-e=xxx] [-re=xxx] [-i=xxx] [-k=xxx] [-t=xxx] [-conf=xxx]Bash
参数名 参数类型 描述
bucket String 需要删除的桶名。
-f Bool 强制操作，不进行询问提示。
返回
删除对象
注意
通过 tosutil 删除 HNS 桶中对象时，存在以下使用限制：
仅开启回收站功能后，才可删除目录（不包括回收站中目录）。
暂不支持删除回收站中目录和文件。

tosutil rm tos://bucket/[prefix] -r [-f] [-j=1] [-v] [-o=xxx] [-bt=xxx] [-e=xxx] [-re=xxx] [-i=xxx] [-k=xxx] [-t=xxx] [-conf=xxx]
Bash
参数名 参数类型 描述
bucket String 桶名。
key String 对象名。
prefix String 批量操作时的对象名前缀。
-r Bool 执行批量删除操作。
-f Bool 强制操作，不进行询问提示。
-fr Bool 删除单个对象或单个分片上传
任务时生成结果清单文件。
-j Integer
批量任务的最大并发数，默认
为配置文件中的 
defaultJobs 。
-v Bool
按指定的对象名前缀批量删除
多版本对象和多版本删除标
记。
-versionId String 待删除的单个对象的版本号。
-o String
生成结果清单文件的文件夹，
默认为配置文件中的 
defaultOutputDir 。
-bt String
存储桶的类型。取值说明如
下：
fns ：扁平桶。
hns ：分层桶。
