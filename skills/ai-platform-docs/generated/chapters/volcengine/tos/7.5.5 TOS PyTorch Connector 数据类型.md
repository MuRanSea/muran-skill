7.5.5 TOS PyTorch Connector 数据类型
本文为您介绍 TOS PyTorch Connector 中的数据类型。
TosMapDataset
TosIterableDataset
TosObjectWriter
属性/方法 类型/返回值类型 描述
getitem int 根据索引返回单条样本。
len int 返回数据集样本总数。
close None 释放并关闭相关资源。
enter None 进入上下文管理器的方法。
exit None 退出上下文管理器的方法，用
于释放资源或执行清理操作。
属性/方法 类型/返回值类型 描述
iter Any 返回迭代器，用于顺序遍历样
本。
len int 返回数据集样本总数。
close None 释放并关闭相关资源。
enter None 进入上下文管理器的方法。
exit None 退出上下文管理器的方法，用
于释放资源或执行清理操作。
方法 类型 描述
bucket str 对象所属的桶名。
key str 对象名。
closed bool 是否已关闭。
write int 写入数据接口，返回写入的字
节数。
close None 关闭写入流，会触发数据上传
到火山 TOS。
tell int 返回当前写入位置。
TosObjectReader
方法 类型 描述
writable bool 判断是否可写。
enter None 进入上下文管理器的方法。
exit None 退出上下文管理器的方法，用
于释放资源或执行清理操作。
方法 类型 描述
bucket str 对象所属的桶名。
key str 对象名。
size int 对象大小。
etag str 对象 ETag。
crc64 int 对象 crc64。
closed bool 是否已关闭。
read bytes 读取数据接口，返回实际读取
到的数据。
readinto int 将数据读取到数据缓冲区，返
回实际读取的字节数。
seek int 设置读取位置，返回设置后的
当前读取位置。
close None 关闭读取流。
tell int 返回当前读取位置。
readable bool 判断是否可读。
seekable bool 判断是否可设置读取位置。
