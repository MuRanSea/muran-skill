7.11.6 AI-Agent 指南
ve-tos-cli 支持作为 Skill 集成到 AI-Agent 生态，可通过标准化的能力描述、命令调用与结果解析，为Agent 提供 TOS 对象存储的完整操作能力。本章节介绍 AI-Agent 指南。
六大设计原则
可发现性（ help / capabilities / describe ）：通过标准化接口暴露命令结构，支持自动发现。可理解性（参数 / 风险 / 示例 / API 元数据）：提供清晰的参数说明、风险提示、使用示例及 API 元数据。
安全执行（ dry-run + 确认）：支持预演模式与二次确认机制，降低误操作风险。
可控输出（四路径结构化）：输出遵循四路径结构化规范，确保结果可预期、可解析。
确定性错误（稳定 Envelope + 退出码）：错误信息采用稳定 Envelope 格式，配合标准退出码，便于程序化处理。
Agent 生态（Skill / MCP）：兼容 Skill 与 MCP 协议，可无缝接入 Agent 生态系统。
Agent 推荐流程
结构化输出 Envelope
ve-tos-cli capabilities --view compact --output json # 发现
ve-tos-cli object upload --describe --output json # 读契约
ve-tos-cli rm tos://b/p/ --recursive --dry-run --output json # 预览
ve-tos-cli ls tos://b/p/ --output json --query "data.objects[].key" # 执行 + 取值Bash

MCP 集成
MCP（Model Context Protocol）是一种开放协议，用于将外部工具、数据源或服务以标准化方式暴露给AI Agent 调用。
ve-tos-cli 将 CLI 命令封装为 MCP 工具，使 AI Agent 可以直接调用 ve-tos-cli 的功能，而无需人工在终端输入命令。
stdio （默认）不监听端口，由 MCP 客户端以子进程方式拉起；
sse 模式绑定 127.0.0.1:<port> ，暴露 /sse 与 /message 端点。
工具名由 Skill 名转换而来： ve-tos ls > ve_tos_ls ， ve-tos bucket create > ve_tos_bucket_create 。tools / call 默认仅执行规划，不触发底层操作；传入 execute: true 后才实际执行命令。列举语义提醒（Agent 须知）
ve-tos 默认列举模式为 auto ：
HNS 桶采用层级列举。
FNS 桶采用扁平列举。
如需启用前缀级并发，请显式指定 --recursive-list-mode hierarchical ，该选项同时影响 --list-concurrency是否生效。
