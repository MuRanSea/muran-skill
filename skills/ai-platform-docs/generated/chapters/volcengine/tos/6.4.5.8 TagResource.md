6.4.5.8 TagResource
功能描述
为 TRN 标识的资源添加或更新一个或多个用户自定义标签。每个标签由一个键值对组成。标签可以帮助您组织资源、跟踪资源成本并控制对资源的访问。
注意事项
您最多可以为每个资源添加 50 个标签。
Resource TRN 最大长度不能超过 1011 个字符。
目前仅支持为向量桶资源添加标签
请求消息样式
请求参数和消息头
无。

POST /tags/resourceTrn HTTP/1.1
Host: tosvectors-cn-beijing.volces.com

{
 "tags": { 
 "string" : "string" 
 }
