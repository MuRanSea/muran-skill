7.3.5 桶基本操作
您可以通过 TOS Browser 工具，完成存储桶的相关操作，例如创建桶、查看桶详情等。
前提条件
安装 TOS Browser
登录 TOS Browser
支持操作
登录 TOS Browser 后，您可以完成以下关于存储桶的操作。
支持操作 说明
创建存储桶
单击页面左上方的创建存储桶。
在弹出的对话框中设置存储桶参数，然后单
击确定。
说明
创建存储桶的参数说明，请参见创建
存储桶。
TOS Browser 创建桶时支持的参数与
控制台有一定差异，请以 Browser 实
际界面为准。
查看桶详情
在桶列表页面，单击目标桶操作列对应的详情，
即可查看桶的详细信息，包括存储桶名称、创建
时间、区域及存储桶域名。
设置桶 ACL
在桶列表页面，单击目标桶操作列对应的 ...
> ACL权限。
在弹出的面板中设置 ACL 权限。
说明
关于 ACL 权限的详细说明，请参见桶
ACL 概述。
查看分片
在桶列表页面，单击目标桶操作列对应的 ...
> 分片管理。
在分片管理面板中，查看分片信息。
支持操作 说明
说明
TOS Browser 当前仅支持查看分片，如果
您需要清空桶中的分片，请登录 TOS 控
制台 操作，详细步骤，请参见清空分
片。
删除桶
在桶列表页面，单击目标桶操作列对应的删
除。
在弹出的对话框中单击删除。
说明
关于删除桶的详细说明，请参见删除
桶。
切换存储桶 在任意页面左侧桶列表展示栏中，单击目标桶
名，可以进入到其他存储桶。
