5.13.3 创建 SenseFlow 模板
SenseFlow 模板是 SenseFlow 规则的核心配置单元，每个规则创建时必须选择一个模板。SenseFlow 提供智能安防预设模板、媒资管理预设模板帮助您快速启用智能能力，详情请参见系统预设模板介绍 。您也可以创建自定义模板满足业务多样化定制需求，本章节主要介绍如何创建 SenseFlow 自定义模板的使用与限制。
说明
SenseFlow 功能目前处于邀测状态，仅开放华北2（北京）地域。如需使用，请联系客户经理。前提条件
注意事项
在首次使用 SenseFlow 时，您需要先在控制台通过去授权完成数据处理和 KMS 跨服务授权 ， 创建 ServiceRoleforTOSDataProcess 与 ServiceRoleforTOSSenseflow 的 IAM 角色。
创建自定义模板
登录对象存储控制台 。
在左侧导航栏，选择内容感知与处理 > 模板管理。
在模板管理页面，单击创建自定义模板或单击 + 自定义模板。
在创建自定义模板页面，设置模板参数。
事项 说明
账号注册与实名认证 请确保您已注册火山引擎账号 并完成实名认
证 。
开通 TOS 服务 请确保您的账号或者子账号已开通 TOS 服务。
具备可用的工作流（自定义模板）
自定义模板必须至少绑定一个工作流，请先创建
满足业务需求的工作流。具体步骤，请参见工作
流管理 。

基本信息
模板名称 自定义模板名称。
描述 SenseFlow 模板的描述。描述
内容不能超过 50 个字符。

选择并查看您的工作流。

加工作流页面添加您所需
工作流。若无合适工作流
可单击创建工作流创建您

查看模板详情
登录对象存储控制台 。
在左侧导航栏，选择内容感知与处理，单击模板管理。
在模板管理页面，选择您所需要查看的模板，单击对应模板卡片的详情。
在模板详情页面，您可查看对应模板的基本信息、工作流、视频描述摘要等信息。
