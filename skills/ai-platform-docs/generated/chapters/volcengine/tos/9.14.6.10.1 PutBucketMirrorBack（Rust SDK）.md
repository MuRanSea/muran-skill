9.14.6.10 回源规则
9.14.6.10.1 PutBucketMirrorBack（Rust SDK）
PutBucketMirrorBack 接口用于为存储桶配置回源规则，支持按条件设置最多 20 条镜像或重定向规则。本文介绍如何通过 Rust SDK 的 PutBucketMirrorBack 接口完成该配置。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
仅 Bucket Owner 可调用此接口设置回源规则。
单桶最多支持 20 条回源规则。
私有桶回源时，Role 鉴权与 AK/SK 鉴权只可二选一，不可同时启用。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行 put_bucket_mirror_back 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:PutBucketMirrorBack 。
代码示例
配置存储桶的回源规则
use async_trait::async_trait;
use futures_core::future::BoxFuture;
use std::env;
use std::future::Future;
use std::time::Duration;
use tokio::runtime::Handle;
use ve_tos_rust_sdk::common::init_tracing_log;
use ve_tos_rust_sdk::asynchronous::bucket::BucketAPI;
use ve_tos_rust_sdk::asynchronous::tos;
use ve_tos_rust_sdk::asynchronous::tos::AsyncRuntime;
use ve_tos_rust_sdk::bucket::{PutBucketMirrorBackInput, MirrorBackRule, Condition, Redirect, PublicSource, SourceEndpoint};
use ve_tos_rust_sdk::enumeration::RedirectType;
use ve_tos_rust_sdk::error::TosError;
#[derive(Debug, Default)]
pub struct TokioRuntime {}
#[async_trait]
impl AsyncRuntime for TokioRuntime {
type JoinError = tokio::task::JoinError;
async fn sleep(&self, duration: Duration) {
 tokio::time::sleep(duration).await;
 }
fn spawn<'a, F>(&self, future: F) -> BoxFuture<'a, Result<F::Output, Self::JoinError>>where
 F: Future + Send + 'static,
 F::Output: Send + 'static,
 {
Box::pin(Handle::current().spawn(future))
 }
fn block_on<F: Future>(&self, future: F) -> F::Output {
 Handle::current().block_on(future)
 }
}
#[tokio::main]
async fn main() {
let _guard = init_tracing_log("info", "temp/logs", "app.log");
let ak = env::var("TOS_ACCESS_KEY").unwrap_or("".to_string());
let sk = env::var("TOS_SECRET_KEY").unwrap_or("".to_string());
let endpoint = "https://tos-cn-beijing.volces.com";
let region = "cn-beijing";
let client = tos::builder::<TokioRuntime>()
 .connection_timeout(3000)
 .request_timeout(10000)
 .max_retry_count(3)
 .ak(ak)
 .sk(sk)
 .region(region)
 .endpoint(endpoint)
 .build().unwrap();
let bucket_name = "example-bucket";
let mut input = PutBucketMirrorBackInput::new(bucket_name);
// Create public source rule
let mut rule = MirrorBackRule::new("rule1");
let mut condition = Condition::default();
 condition.set_http_code(404);
 condition.set_key_prefix("prefix1");
 condition.set_http_method(vec!["GET".to_string(), "HEAD".to_string()]);
 rule.set_condition(condition);
相关文档
关于 PutBucketMirrorBack 的 API 文档，请参见 PutBucketMirrorBack。
let mut redirect = Redirect::default();
 redirect.set_redirect_type(RedirectType::RedirectMirror);
let public_source = PublicSource::new(SourceEndpoint::new(vec!["http://publicsource.example.com".to_string()]));
 redirect.set_public_source(public_source);
 rule.set_redirect(redirect);
 input.add_rule(rule);
let output = client.put_bucket_mirror_back(&input).await;
match output {
Ok(output) => println!("Public source mirror back rule configured successfully, request_id: {}", output.request_id()),
Err(err) => match err {
 TosError::TosClientError { message, .. } => println!("Client error: {}", message),
 TosError::TosServerError { request_id, ec, .. } => println!("Server error: request_id: {}, ec: {}", request_id, ec),
 },
 }
}
