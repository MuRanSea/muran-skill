方法/属性 描述
read(size=-1) 从当前位置读取指定字节数的数据。 size=-1
表示读取到文件末尾。
readinto(buf) 将数据直接读取到可写的缓冲区对象 buf 中，
返回实际读取的字节数，避免额外的内存拷贝。
readuntil(char=b'\n', blocks=None) 持续读取数据直到遇到指定的分隔符 char （包
含该分隔符），或文件结束。
write(data) 将字节数据 data 写入文件缓冲区。
seek(loc, whence=0) 移动文件指针到指定位置。 whence 可为 0
(开头)、 1 (当前位置)、 2 (文件末尾)。
tell() 返回当前文件指针的位置。
flush(force=False) 将缓冲区中累积的数据刷新到底层写入流。通常
由 commit() 或关闭文件时自动调用。
commit() 提交当前缓冲区中的所有数据。对于启用了自动
提交的写入模式，一般不需要显式调用。
discard() 放弃当前写入会话，终止底层分片上传并丢弃未
提交的数据。
close() 关闭文件，并确保所有数据都已写入。在 with
语句块退出时会自动调用。
readable() / writable() / seekable() 返回文件是否支持读、写、随机访问的布尔值。
closed 文件是否已关闭。
bucket 当前文件所属的 Bucket 名称。
