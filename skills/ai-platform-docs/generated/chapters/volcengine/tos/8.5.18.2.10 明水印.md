8.5.18.2.10 明水印
PutVideoWatermarkTemplate
功能描述
此接口用于上传明水印模板。
注意事项
单条规则 body 最大不超过 20KB，最多允许配置 300 条自定义模板。
通过子账号使用时，需要授予当前桶的 PutDataProcessTemplate 权限。
请求消息样式
文字水印
图片水印
PUT /?process_template&tag=Watermark HTTP/1.1
Host: {BucketName}.tos-cn-beijing.volces.com
Date: Fri, 30 Jul 2021 08:05:36 +0000
Content-Type: application/json
Content-Length: <length>
Authorization: authorization string
{
"Tag": "Watermark", // 固定标识
"Name": "my-test-watermark", // 用户自定义名称
"WatermarkConfig": {
"Type": "Text", // 文字水印
"Pos": "TopRight", // 基准位置
"LocMode": "Relative", // 偏移方式
"Dx": 10, // 水平偏移
"Dy": 10, // 垂直偏移
"StartTime": 0, // 明水印开始时间，单位毫秒，默认 0
"EndTime": 10000, // 明水印结束时间，单位毫秒，默认 0 表示视频结束时间
"Text": { // 文字水印设置，Type 为 Text 时生效
"FontSize": 100, // 字体大小
"FontType": "fangzhengheiti", // 字体类型
"FontColor": "#FF0000", // 字体颜色
"Transparency": 20, // 透明度，单位 %
"Text": "hello world" // 水印内容
}
}
}
