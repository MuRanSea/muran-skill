5.18.4.2 Java SDK 概览（分层桶）
TOS 支持通过 Java SDK，完成分层桶的上传对象等操作。本文介绍 Java SDK 的安装等信息。安装 SDK
SDK 安装地址及安装步骤等信息，请参见安装 Java SDK。
初始化客户端
使用 SDK 前，您需要先初始化客户端，具体步骤，请参见初始化客户端（Java SDK）。
支持功能
分层桶与扁平桶共通大部分 SDK，您可以参考以下文档，了解 SDK 功能列表及差异：
Java SDK 全部功能概览，请参见 Java SDK 简介。
详细差异说明，请参见 API 列表（分层桶）。
常见 SDK 操作文档，请参见下表。
功能说明 参考文档
CreateBucket 创建分层命名空间（Java SDK）
ListBuckets 列举分层命名空间（Java SDK）
ListObjects 列举分层命名空间内对象（Java SDK）
ListObjectsV2 列举分层命名空间内对象V2（Java SDK）
RenameObject 重命名分层命名空间内对象（Java SDK）
