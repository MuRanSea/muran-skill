8.5.18.3 文档预览
8.5.18.3.1 CreateDocConvertJob
功能描述
此接口用于提交文档转码任务。
注意事项
CreateDocProcessJob 接口处于邀测状态，如需使用，请联系客户经理开通白名单。
源文档支持 doc、docx、ppt、pptx 和 pdf 格式。
支持文档转码为 markdown 和 json 格式。
存储结果的目标桶需和源桶在同一 Region 和同一账号下。
请求消息样式
请求参数和消息头
该请求使用的公共请求消息头，请参见公共参数。
POST /?doc_jobs&job_type=DocConvert HTTP/1.1
Host: <bucket_name>.tos-cn-beijing.volces.com
