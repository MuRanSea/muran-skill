12.16 通过 TOS 搭建方舟批量推理任务
本文介绍如何通过 TOS 搭建方舟批量推理任务。
背景信息
对象存储
火山引擎对象存储 TOS（Torch Object Storage）是火山引擎提供的海量、安全、低成本、易用、高可靠、高可用的分布式云存储服务。您可以通过 RESTful API 接口、SDK 和工具等多种形式使用火山引擎 TOS。通过网络，您可以在任何应用、任何时间、任何地点管理和访问火山引擎 TOS 上的数据。更多信息，请参见什么是对象存储 。
火山方舟
火山方舟是面向开发者的企业级大模型服务平台，提供模型训练、推理、评测、精调等全方位功能与服务，并重点支撑大模型生态。更多信息，请参见什么是火山方舟 。
批量推理（Batch Inference）适用于无需实时响应的推理场景，可以一次性离线处理大量数据。使用存储在火山引擎对象存储的数据搭建方舟批量推理任务，有以下优势：
输入数据：不需要额外支付对象外网访问流量等费用；火山方舟和对象存储深度结合，提供高性能的任务体验。
输出数据：不需要支付对象外网访问流量等费用；可便捷使用火山引擎对象存储的各项能力，支持的功能列表，请参见控制台功能概述。
创建批量推理任务流程
前提条件
请确保您已注册火山引擎账号 并完实名认证 。
请确保您的账号或者子账号已开通 TOS 服务 。

常见场景 描述
从微信小程序直传数据到 TOS
微信小程序作为一个不需要下载即可使用的应
用，吸引了越来越多的人进行开发和使用。如何
将微信小程序上的文件上传到 TOS 成为开发者
关心的一个问题。
图片处理
TOS 支持处理存储的图片文件，您可以通过
GetObject 接口，在请求中携带图片处理的相关
参数。TOS 支持的图片处理功能包括图片缩放、
图片裁剪、图片水印、格式转换等。
视频处理
TOS 支持处理存储的视频文件，您可以通过
GetObject 接口，在请求中携带视频处理的相关
参数。TOS 支持的视频处理功能包括视频截帧、
获取视频元信息。
设置静态网站
静态网站，即网站所有的内容均由静态内容构
成，包括首页、图片、执行脚本等。TOS 支持托
管静态网站，您可以将静态网站的所有内容存储
至 TOS 存储桶，配置静态网站规则后，即可通
过存储桶域名访问该网站。
挂载存储桶
TOS 支持通过 FUSE 技术将存储桶作为磁盘挂载
到 Windows 或 Linux 系统，便于您像管理文件
系统一样管理存储桶。
