问题描述
URL 参数 partNumber 取值非法。
问题原因
用户请求携带的 URL 参数 partNumber ，不是有效的整数或不在 [1, 10000] 范围内。
问题示例
以下分片对象上传请求中， partNumber 参数取值非法。
解决方案
确认 URL 参数 partNumber 取值合法。
PUT /objectName?partNumber=10001&uploadId=UploadId HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: GMT Date
Authorization: authorization xxx
Content-Length: length
