<TabTitle>通过包管理器安装</TabTitle>
* 使用 npm 安装：
 ```Shell
 npm install -g ve-tos-cli
 ```
* 使用 pip 安装：
 ```Shell
 pip install ve-tos-cli
 ```
* 在 macOS 上使用 Homebrew 安装，依次执行以下命令：
 ```Plain Text
 brew tap volcengine/ve-storage-uni-cli https://github.com/volcengine/ve-storage-uni-cli
 brew trust volcengine/ve-storage-uni-cli
 brew install ve-tos-cli
 ```
* 使用 cargo 安装：
 ```Shell
 cargo install ve-tos-cli
 ```

指定 TOML 配置文件路径，

该目录同时存放用于保护落盘
密钥的本地加密 key 。
若显式指定路径但文件不存
在，命令将直接报错退出

-r, --region <REGION> - 覆盖当前配置的区域

-e, --endpoint <URL> - 覆盖当前配置的数据面

-o, --output <FORMAT> TOS_OUTPUT

--query <JMESPATH> - 使用 JMESPath 表达式对输出

--describe -

现象 排查方法
鉴权失败（exit 2）
1. 确认 TOS_ACCESS_KEY 和 TOS_SECRET_KEY
已正确配置。
2. 执行 ve-tos-cli doctor --check auth 进行诊
断。
配置缺失（exit 3）
若通过 --config-path 或 TOS_CONFIG_PATH
指定了不存在的配置文件，运行类命令将报 
exit 3 。
执行 ve-tos-cli config init 并设置 region 和 
endpoint 。
控制面命令报错
需指定控制面相关信息：
* 通过参数 --control-endpoint 和 
--account-id 指定。
* 通过环境变量 config set 指定。
拒绝删除 非交互模式下须附加 --force 及精确的 --
confirm <RESOURCE> 参数。
递归并发不生效 显式指定 --recursive-list-mode hierarchical 。
查看低阶子动作 执行 ve-tos-cli <group> --describe --output json
查看可用子动作。
