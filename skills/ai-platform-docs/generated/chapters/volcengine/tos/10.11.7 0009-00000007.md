10.11.7 0009-00000007
问题描述
CORS 规则非法。
问题原因
用户设置桶 CORS 规则时，CORS 规则中 MaxAgeSeconds 取值小于 0。
问题示例
您进行桶 CORS 配置时，CORS 规则中 MaxAgeSeconds 取值小于 0。
解决方案
参见 PutBucketCORS ，正确构造 CORS 规则，确保 MaxAgeSeconds 取值合法。
PUT /?cors HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization string
{
"CORSRules":[{
"AllowedOrigins":["http://www.example.com"],
"AllowedMethods":["PUT"],
"AllowedHeaders":["*"],
"ExposeHeaders":["x-tos-test"],
"MaxAgeSeconds":-1}
 ]
}
