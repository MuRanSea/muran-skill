7.3.8 系统设置
TOS Browser 支持配置上传/下载任务的参数、设置安全等级、切换语言、配置 HTTP 代理。本文介绍设置配置上传/下载任务的参数、设置安全等级等操作步骤。
操作步骤
登录 TOS Browser。
在桶列表页面右上方，单击 图标。
在弹出的对话框中，根据需要选择设置类型，然后设置如下参数。
上传下载设置
单击上传下载设置，配置如下参数：
最大上传任务数：可同时运行上传任务的最大数量。默认为 10，取值范围为 1~100。
上传分片并发数：上传大文件时，TOS Browser 默认使用分片上传的方式上传文件，您可以设置在 1个上传任务中，同时上传分片的最大数量，上传分片并发数值越大，文件上传的速度越快。默认为1， 取值范围为 1~100。
最大下载任务数：可同时运行下载任务的最大数量。默认为 10，取值范围为 1~100。
下载分片并发数：下载大文件时，TOS Browser 默认使用分片下载的方式下载文件，您可以设置在 1个下载任务中，同时下载分片的最大数量，下载分片并发数值越大，下载文件的速度越快。默认为1， 取值范围为 1~100。
超时时间：默认为 120s，取值范围为 30s~600s。
分片大小：分片上传时，每个分片的大小，默认为 8MiB，取值范围为 5MiB~1024MiB。
重试次数：默认为 10，取值范围为 0~20。
上传完二次校验：文件上传完成后，TOS Browser 会对云端文件和本地文件进行一致性校验，如果校验不通过，则上传任务会失败，适用于上传过程中，本地文件被意外修改的场景。
注意
开启上传完二次校验功能会额外消耗系统资源，可能会引发卡顿。
下载完二次校验：文件下载完成后，TOS Browser 会对云端文件和本地文件进行一致性校验，如果校验不通过，则下载任务会失败，适用于下载过程中，本地文件被意外修改的场景。
注意
开启下载完二次校验功能会额外消耗系统资源，可能会引发卡顿。
安全设置
单击安全设置，选择是否打开危险操作等级提示，说明如下：
打开后，当您需要删除文件时，需要手动输入确认信息，降低您误操作的可能，保护相应数据安全。
默认不打开，即删除文件时仍会有对话框提示风险，但不需要手动输入确认信息。
切换语言
单击系统设置，选择语言，可选中文和 English。

使用 HTTP 代理
单击系统设置，设置代理配置为自定义代理，填写代理地址和代理端口。
设置完成后，单击保存。
（可选）在提示对话框，单击立即重启，使代理配置生效。
说明
上传下载设置、切换语言或 HTTP 代理配置需要重启 TOS Browser 后才会生效。
