7.3.8 系统设置
TOS Browser 支持配置上传/下载任务的参数、设置安全等级、切换语言、配置 HTTP 代理。本文介绍设置配置上传/下载任务的参数、设置安全等级等操作步骤。
操作步骤
登录 TOS Browser 。
在桶列表页面右上方，单击 图标。
在弹出的对话框中，根据需要选择设置类型，然后设置如下参数。
return (<Tabs>
<Tab zoneid="nNUR7qjv3b" title="上传下载设置">
<TabTitle>上传下载设置</TabTitle>
单击**上传下载设置**，配置如下参数：
 * **最大上传任务数**：可同时运行上传任务的最大数量。默认为 10，取值范围为 1~100。
 * **上传分片并发数**：上传大文件时，TOS Browser 默认使用分片上传的方式上传文件，您可以设置在 1 个上传任务中，同时上传分片的最大数量，上传分片并发数值越大，文件上传的速度越快。默认为 1， 取值范围为 1~100。
 * **最大下载任务数**：可同时运行下载任务的最大数量。默认为 10，取值范围为 1~100。
 * **下载分片并发数**：下载大文件时，TOS Browser 默认使用分片下载的方式下载文件，您可以设置在 1 个下载任务中，同时下载分片的最大数量，下载分片并发数值越大，下载文件的速度越快。默认为 1， 取值范围为 1~100。
 * **超时时间**：默认为 120s，取值范围为 30s~600s。
 * **分片大小**：分片上传时，每个分片的大小，默认为 8MiB，取值范围为 5MiB~1024MiB。
 * **重试次数**：默认为 10，取值范围为 0~20。
 * **上传完二次校验**：文件上传完成后，TOS Browser 会对云端文件和本地文件进行一致性校验，如果校验不通过，则上传任务会失败，适用于上传过程中，本地文件被意外修改的场景。
 <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapperindent="2">注意 </div>
 <div data-tips="true" data-tips-type="warning" data-wrapper-indent="2">开启<strong>上传完二次校验</strong>功能会额外消耗系统资源，可能会引发卡顿。 </div>
 * **下载完二次校验**：文件下载完成后，TOS Browser 会对云端文件和本地文件进行一致性校验，如果校验不通过，则下载任务会失败，适用于下载过程中，本地文件被意外修改的场景。

<Tab zoneid="mfHyFbWPe6" title="安全设置">
<TabTitle>安全设置</TabTitle>
单击**安全设置**，选择是否打开危险操作等级提示，说明如下：
 * 打开后，当您需要删除文件时，需要手动输入确认信息，降低您误操作的可能，保护相应数据安全。
 * 默认不打开，即删除文件时仍会有对话框提示风险，但不需要手动输入确认信息。
</Tab>

<TabTitle>切换语言</TabTitle>
