问题描述
通过桶清单查询或删除桶清单规则时，Query 参数中携带的 id 为空。
问题原因
该报错存在以下两种情况：
使用 GetBucketInventory 接口查询桶清单规则时， id 为空，导致报错。
使用 DeleteBucketInventory 接口创建桶清单规则时， id 为空，导致报错。
问题示例
您在查询桶清单规则时，传入的 id 为空。
您在删除桶清单规则时，传入的 id 为空。
解决方案
按照规范填写桶清单规则，具体格式，请参见 GetBucketInventory 和 DeleteBucketInventory 。GET /?inventory&id= HTTP/1.1
Host: BucketName.tos-cn-beijing.volces.com
Authorization: authorization string
JSON
DELETE /?inventory&id= HTTP/1.1
Host: BucketName.tos-cn-beijing.volces.com
Authorization: authorization string
JSON
