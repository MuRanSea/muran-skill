9.14.6.6.3 ListBucketInventory（Rust SDK）
list_bucket_inventory 接口用于批量获取存储桶中的所有桶清单规则，本文介绍如何通过 Rust SDK 的list_bucket_inventory 接口完成该操作。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
当 IsTruncated 为 true 时，需将 NextContinuationToken 作为下一次请求的 continuation-token 参数，否则无法获取剩余清单配置。
continuation-token 仅在未完整列举时返回，缺失或错误值将导致从头开始列举。
返回的清单文件格式固定为 GZIP 压缩的 CSV，不支持其他格式。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行list_bucket_inventory 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:ListBucketInventory
