5.3.2 存储桶概览
在存储桶概览页，您可以查看该存储桶的用量概览、基本信息、域名信息等信息。
前提条件
已创建存储桶，具体步骤，请参见创建存储桶。
查看存储桶概览
登录对象存储控制台 。
在左侧导航栏，单击桶列表。
在顶部导航栏，选择存储桶所属项目。
在桶列表页面单击目标桶名称。
单击左侧导航栏的概览，查看存储桶的概览信息。
概览信息 说明
用量概览
桶对象数量：单击下拉列表，选择目标存储
类型，即可查看当前存储桶内各个存储类型
的对象数量以及总对象数量。对象数量统计
包含历史对象，不包含分片对象。
桶对象总容量：当前存储桶内对象的总容
量。
桶今日外网下载总量：当前存储桶当天
00:00:00 到现在的外网下行流量。
桶今日内网下载总流量：当前存储桶当天
00:00:00 到现在的内网下行流量。
桶今日CDN回源流量：当前存储桶当天
00:00:00 到现在的 CDN 回源流量。
桶今日总请求次数：当前存储桶当天
00:00:00 到现在的总请求次数。
注意
您需要拥有云监控只读权限，才可以查
看用量概览信息，授权步骤，请参见授
予账号云监控只读权限。
基本信息
存储桶名称：创桶时自定义的桶名称。
所属地域：该存储桶所在的地域。
多AZ冗余：该存储桶是否开启多AZ冗余功
能。详细介绍，请参见多 AZ 冗余。
默认存储类型：该存储桶的存储类型。
创建时间：该存储桶的创建时间。
生命周期：该存储桶是否配置生命周期规
则。

查看存储桶用量统计
登录对象存储控制台 。
在左侧导航栏，单击桶列表。
概览信息 说明
单击设置可跳转至生命周期页面，设置规则
详情请参见设置生命周期规则 。
回源设置：该存储桶是否配置回源规则。
单击设置可跳转至回源设置页面，设置规则
详情请参见回源概述。
跨域访问：该存储桶是否配置跨域访问策
略。
单击设置可跳转至跨域访问页面，设置规则
详情请参见跨域访问设置。
版本控制：该存储桶是否开启版本控制功
能。
单击设置可跳转至版本控制页面，详情请参
见开启和暂停版本控制。
标签：该存储桶的标签。
服务端加密：该存储桶是否开启服务端加密
功能。
单击设置可跳转至服务端加密页面，详情请
参见服务端加密概述。
告警配置：该存储桶的告警配置情况。 
单击查看告警策略，可以跳转到云监控控
制台，然后单击告警策略页签，可以查看
告警策略信息。
单击配置告警策略，可以跳转到云监控控
制台，在该控制台创建告警策略，具体步
骤，请参见创建告警策略 。
RenameObject：该存储桶是否开启
RenameObject 功能。
单击设置可跳转至 RenameObject 页面，详
情请参见使用 RenameObject。
项目：存储桶所属项目。
对象 ACL 默认策略：该存储桶的上传对象的
默认 ACL 策略。详细介绍，请参见配置对
象 ACL。
访问域名
外网访问：公网可访问的桶域名，包括 
Endpoint 、S3 Endpoint 以及 Bucket 域名。
内网访问：VPC网络内可访问的桶域名，包
括 Endpoint 、S3 Endpoint 以及 Bucket 域
名。

在顶部导航栏，选择存储桶所属项目。
在桶列表页面，单击目标桶名称。
在左侧导航栏，选择用量统计 > 基础数据，查看存储桶的用量统计，包括存储容量、取回容量、流量及请求次数、带宽、状态码。
您可以在基础数据页面左上角切换统计周期。
FAQ
存储桶概览页面提示没有权限，无法查看概览页面内容
您的账号没有云监控的权限，您需要为您的账号添加云监控 GetMetricsData 这个 Action 的权限，也可以授予您的账号 CloudMonitorReadOnlyAccess 权限，具体操作，请参见为 IAM 用户授权 。
