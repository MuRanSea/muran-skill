桶标签
您可以通过桶标签功
能标识资源，帮助您
从不同维度（如用
途、类型、所有者、
环境等）对具有相同
特征的存储桶进行标
记和分类，便于管
理。
-
桶清单
您可以通过桶清单功
能，定期获取固定存
储桶内所有或者指定
前缀的对象信息，清
单内容包括对象大
小、存储类型、最后
更新日期等。
HNS 桶清单不支持
导出对象复制状
态、加密状态。
首次创建桶清单规
则，将于 48 小时
内输出桶清单文
件。
批量处理
批量处理功能支持对
存储桶中的对象批量
执行某些操作，例如
批量数据复制、批量
替换对象 ACL 等。
-
RenameObject
TOS 支持使用
RenameObject 功能重
命名对象。
与普通桶存在差异，
详情请参见 API 列表
（分层桶）。
桶策略
针对单独存储桶及桶
内资源设置的策略，
您可以通过桶策略授
予其他用户相应资源
的权限。
-
IAM 策略
IAM 是火山引擎为客
户提供的一套权限管
理系统，用于控制不
同身份对云资源的访
问权限。您可以通过
-
功能 说明 是否支持 备注

户相应资源的权限。
桶 ACL
ACL 是基于账号的读
写访问控制，桶或对
象的所有者拥有该资
源的完全控制权限。
您可以对 IAM 主账号
授予当前桶的读写权
限及桶 ACL 的读写权
限。授权后，被授权
用户即可凭借自己的
AKSK 信息访问该桶。
-
对象 ACL
ACL 是基于账号的读
写访问控制，桶或对
象的所有者拥有该资
源的完全控制权限。
您可以在 TOS 控制台
设置单个对象的文件
读写权限（ACL）。
-
跨域访问设置
设置跨域规则后，当
TOS 收到跨域请求或
OPTIONS 请求时，会
读取存储桶对应的
CORS 规则，进行相
应的权限检查并返回
相应的 Header，保证
跨域传输数据的安全
性。
-
自定义域名
如果您希望使用您自
己的域名访问存储在
TOS 的文件，您可以
为存储桶绑定您自己
的域名。绑定后，即
可使用相应域名访问
文件。
-
跨区域复制
跨区域复制支持将一
个存储桶的文件自动
复制到不同地域的其
他存储桶，支持根据
需要筛选复制的文
件，查看复制进度。
-
同区域复制
同区域复制支持将一
个存储桶的文件自动
复制到相同地域的其
他存储桶，支持根据 -
功能 说明 是否支持 备注
需要筛选复制的文
件，查看复制进度。
版本控制
版本控制功能支持保
留存储桶数据的历史
版本，避免存储桶内
的数据被误删除。
-
多 AZ 冗余
多 AZ 冗余功能支持
您的数据存储在同一
地域的多个可用区，
当某个可用区发生故
障时，其他可用区仍
然能为您提供稳定的
存储服务。
仅华北2（北京）支持
分层桶的多 AZ 冗余
功能。
图片样式
图片样式是指包含格
式转换、渐进显示等
多个图片处理参数的
一个模板。您可以使
用图片样式统一处理
多个图片，达到简化
操作的目的。
-
原图保护
原图保护功能是对图
片的一种保护措施，
用于防止原图被匿名
用户盗用。
-
用量统计
TOS 支持查看存储桶
的多项基础数据，包
括用量、流量、请求
次数等。
-
日志管理
您可以通过日志服
务，检索分析您访问
TOS 过程中产生的访
问日志，查看日志报
表。
-
数据透视
数据透视支持统计总
存储量、总对象数
量、历史版本字节
数、未合并的分片上
传字节数等数据，帮
助您了解对象存储的
使用情况。
-

服务端加密
TOS 收到您上传的数
据后，会在服务端对
数据进行加密并持久
化存储；下载文件
时，TOS 会自动解密
并返回数据。
-
双端加密
双端固定指通过设置
VPC 终端节点策略和
桶策略，实现存储桶
内资源 VPC 粒度的权
限控制。即您可以在
私有网络限制 VPC 访
问特定的 TOS 存储桶
资源，同时在对象存
储限制存储桶内资源
被特定的 VPC 访问。
-
安全设置
安全设置即危险操作
提示等级设置，设置
为高等级时，删除数
据操作需要手动输入
确认信息，可以有效
降低您误操作的可
能。
-
图片处理
TOS 支持处理存储的
图片文件，您可以通
过 GetObject 接口，
在请求中携带图片处
理的相关参数进行图
片缩放、图片裁剪、
图片水印等操作。
-
视频处理
TOS 支持处理存储的
视频文件，您可以通
过 GetObject 接口，
在请求中携带视频处
理的相关参数进行视
频截帧、获取视频元
信息操作。
-

TOS 加速器
TOS 支持 AZ 级别的
加速器功能，将 TOS
中的高频访问文件缓
存在 NVMe SSD 高性
能存储介质上，支持
毫秒级延迟的快速响
应和高吞吐量的数据
传输能力，满足业务
性能需求。

上传到存储桶。
下载文件 通过 TOS 控制台，将已上传到
存储桶中的对象下载到本地。
查看文件详情
TOS 支持查看文件的详细信
息，包括文件名、文件大
小、URL、存储类型等。
支持其他操作，如切换文件
展示数量、复制文件路径、
排序文件、搜索文件。
分享文件
当您将文件上传至对象存储
后，您可以通过 URL 将文件或
文件夹分享给其他用户。
重命名文件 您可以在 TOS 控制台更改存储
桶中文件的名称。
复制文件 TOS 支持将存储桶中的文件或
者文件夹复制到其他路径。
移动文件 TOS 支持将存储桶中的文件或
者文件夹移动到其他路径。
管理文件标签
功能 说明 是否支持
TOS 支持为对象设置标签，并
根据对象标签，完成特定对象
的生命周期管理。
管理文件元数据
文件元数据是一组描述文件属
性的键值对。您可以自定义文
件元数据。
修改文件访问权限
文件上传会自动继承存储桶的
访问权限，您可以在文件列表
页面修改单个文件的访问权限
（ACL）。
修改文件存储类型
TOS 支持多种存储类型，您可
以根据需要修改文件的存储类
型。
删除文件
当您不再需要保留某些文件
时，可以将其删除，以减少存
储空间占用和存储费用。
管理分片
当您使用分片上传大型文件
时，如果分片未被合并，分片
会存储在分片列表中。您可以
在分片列表中查看和删除分
片。
创建文件夹 TOS 支持文件夹功能，帮助您
对文件进行分类管理。
删除文件夹
TOS 支持删除不再需要的文件
夹。删除后，该文件夹及其中
的文件均会被删除。
恢复文件
归档存储、冷归档和深度冷归
档类型的文件，需要恢复后才
可以访问。
任务中心
TOS 支持在提交上传文件、复
制文件、移动文件、删除目
录、恢复文件或删除分片任务
后，在任务中心查看任务状
态，并对任务进行管理。
