问题描述
静态网站配置非法。
问题原因
用户设置静态网站配置时， RedirectAllRequestsTo 字段与 IndexDocument 、 ErrorDocument 、RoutingRules 字段互斥。
问题示例
您进行静态网站配置时，存在 RedirectAllRequestsTo 字段时，又存在 IndexDocument 字段。解决方案
参见 PutBucketWebsite ，正确构造静态网站配置。
PUT /?website HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
{
"RedirectAllRequestsTo": {
"HostName": "example.com",
"Protocol": "https"
 },
"IndexDocument": {
"Suffix": "index.html"
 }
 }
Go
