6.5.3.3.2 GetVectorBucket（TOS Vectors Node.js SDK）
GetVectorBucket 接口用于获取向量 Bucket 的元数据信息，本文介绍如何通过 TOS Vectors Node.js SDK 的GetVectorBucket 接口完成该操作。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见地域和访问域名（Endpoint）。
为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见配置长期访问凭证。
TOS Vectors Node.js SDK 支持使用临时访问凭证；也支持配置超时机制、重试策略等多种机制，您可以根据业务需求灵活设置，提升应用安全性，详细介绍，请参见常见配置场景。
权限说明
主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用 IAM 用户执行GetVectorBucket 操作，主账号需通过 IAM策略和桶策略为该 IAM 用户授予以下权限：
tosvectors:GetVectorBucket
代码示例
查询指定向量桶的信息
// 查询指定向量桶的信息
import {
TosVectorsClient,
TosClientError,
TosServerError,
} from "@volcengine/tos-sdk";
// 创建客户端
const client = new TosVectorsClient({
accessKeyId: process.env["TOS_ACCESS_KEY"],
accessKeySecret: process.env["TOS_SECRET_KEY"],
region: 'Provide your region', // 填写 Bucket 所在地域。以华北2（北京)为例，"Provide your region" 填写为 cn-beijing。
endpoint: 'Provide your vector endpoint', // 填写域名地址
});
const bucketName = 'Provide your vector bucket name';
const accountId = process.env["TOS_ACCOUNT_ID"];
function handleError(error: Error) {
if (error instanceof TosClientError) {
console.log("Client Err Msg:", error.message);
console.log("Client Err Stack:", error.stack);
 } else if (error instanceof TosServerError) {
console.log("Request ID:", error.requestId);
console.log("Response Status Code:", error.statusCode);
console.log("Response Header:", error.headers);
console.log("Response Err Code:", error.code);
console.log("Response Err Msg:", error.message);
 } else {
console.log("unexpected exception, message: ", error);
 }
}
async function main() {
try {
const res = await client.getVectorBucket({
vectorBucketName: bucketName,
accountID: accountId,
 });
console.log("vector bucket name", res.data.vectorBucket.vectorBucketName);
console.log(
"vector bucket creation time",
 res.data.vectorBucket.creationTime,
 );
console.log("vector bucket trn", res.data.vectorBucket.vectorBucketTrn);
 } catch (error: any) {
handleError(error);
 }
}
main();
