权限说明
挂载存储桶所需要的权限
使用 IAM 用户挂载存储桶，并执行相应操作时，需要拥有对应的权限，否则挂载会失败，具体权限说明如下：
挂载存储桶时，需要拥有 ListBucket 和 HeadBucket 权限。
读取挂载的存储桶内对象时，需要拥有 GetObject 权限。
在挂载的存储桶写入文件时，需要拥有 PutObject 和 AbortMultipartUpload 权限。
在挂载的存储桶删除文件时，需要拥有 DeleteObject 权限。
对于开启服务器端加密 (SSE-KMS)的存储桶，则在读取或写入对象时需要额外的 KMS 操作权限。使用SSE-KMS 上传加密对象，您需要具备该密钥的 kms:GenerateDataKey 权限；若要下载 SSE-KMS 加密对象，您需要具备该密钥的 kms:Decrypt 权限。关于服务端加密的更多信息，请参见服务端加密概述 。以下是一个最小权限策略举例：

确认需要授予的权限策略后，您需要在 IAM 控制台 使用权限策略创建自定义策略，然后授予 IAM 用户该策略，具体操作，请参见配置 IAM 策略 和添加授权 。

FSX 访问权限
默认情况，FSX 客户端进程的 UID 和 GID 拥有挂载的系统内所有的文件和目录权限，文件默认权限为644，目录默认权限为 755，这些信息支持通过 chown 和 chmod 命令修改，您可以在挂载存储桶时通过 uid 、 gid 、 file_mode 和 dir_mode 参数来修改默认值。

免密挂载
免密挂载指通过 FSX 挂载存储桶时，无需指定密钥，而是通过安全令牌服务（STS）提供的临时安全凭证验证身份，完成挂载。该方式无需透露长期 AccessKey，可以保证账号下的密钥安全。

注意
集群创建完成后才支持开启 IRSA 鉴权。如需要使用 csi-fsx 组件的 IRSA 鉴权能力，创建集群时请不要安装该组件。
csi-fsx 组件的 IRSA 鉴权开启后不支持修改，如果存量组件想要修改鉴权方式，需要卸载重装。IRSA OIDC 未开启的时候不允许使用 IRSA 鉴权。
IAM 角色仅支持选择 OIDC 身份提供商类型，且已绑定本组件服务账号的信任关系的角色。csi-fsx 组件安装完成后，暂不支持修改鉴权方式，仅可修改 IAM 角色，且仅对新增的存储卷生效（已有存量储卷不受影响）。同时，修改 IAM 角色会触发组件短暂重启，请在业务低峰期操作。
登录容器服务控制台 并创建集群。具体操作请参见创建集群 。
开启 IRSA 能力并创建 OIDC 身份提供商类型的 IAM 角色。具体操作请参见集群中使用 IRSA 能力 。使用 IRSA 实现存储挂载鉴权 。
完成 IAM 角色信任并安装 csi-fsx 组件后，集群中的存储卷即可根据实际情况配置访问密钥鉴权。如您无需独立的访问密钥鉴权，需要免密挂载，则使用 IRSA 鉴权。
存储卷创建完成后，您可以在创建工作负载时添加对应的卷，在 Pod 中挂载存储使用。

异常处理
如果您在使用 FSX 过程中出现异常情况，建议您先运行 /opt/fsx/tools/sysinfo_collector.sh 脚本。该脚本会自动收集系统基本信息、 挂载点信息、系统日志等内容，并默认会在脚本所在目录生成一个 system_info_****_****.tar.gz 压缩文件。您可以提交工单 将该压缩文件发送给我们，我们将协助您解决问题。
