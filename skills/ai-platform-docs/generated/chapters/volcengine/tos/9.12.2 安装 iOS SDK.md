9.12.2 安装 iOS SDK
本文介绍 TOS iOS SDK 的安装方式。
环境要求
iOS 系统版本：iOS 8.0 以上。
SDK 下载地址
iOS SDK 的源码地址，请参见 iOS SDK 。
安装
您可以选择以下方式的任意一种，安装 iOS SDK。
直接引入 Framework
您需要根据平台类型自行编译 VeTOSiOSSDK.framework，然后将 VeTOSiOSSDK.framework 添加到 Xcode工程中。
注意
直接将 framework 包拖入 Xcode 工程，请注意勾选 Copy items if needed，然后引入头文件即可进行使用。
使用 TOS iOS SDK 源码
在工程中直接引入 TOS iOS SDK 的源代码。
#import <VeTOSiOSSDK/VeTOSiOSSDK.h>
