5.13.1.3 系统预设算子介绍
TOS 内容感知与处理（SenseFlow）功能提供多种系统预设算子，本章节介绍当前提供的预设算子详情。说明
SenseFlow 功能目前仅开放华北2（北京）地域。如需使用，请联系客户经理。

字幕擦除算子
字幕擦除算子可将输入的 MP4 格式视频，通过预设的算子模版，获取擦除字幕后的视频。
通过设置如下转换参数，获取擦除视频。
参数 说明
截取时长 设置视频的截取时长。
动图格式 设置转换的动态格式，支持 gif、webp 格式动
态。
配置输出宽高 设置自定义输出宽高，不配置将和原视频保持一
致。
帧率 设置帧率和缩放模式，支持 crop、stretch、
fill、fit 缩放模式。
抽帧间隔 设置抽帧间隔和抽帧数。
参数 说明
识别语言
设置视频中待识别的语言类型：
auto：自动识别
zh：中文
en：英文
单段结果
设置是否输出单段结果：
true：输出单段结果
false：不输出单独结果
输出格式 设置识别内容输出格式，当前仅支持 json 格
式。
参数 说明
擦除模式
设置擦除模式：
• Subtitle：擦除检测为字幕的文本。
参数 说明
Text：擦除检测到的所有类型的文本，而不
仅仅是字幕。
