9.2.2 安装 Java SDK
运行 TOS Java SDK 前，您需要先安装 SDK，本文提供 SDK 的运行环境要求及多种安装方式。环境准备
SDK 要求在 JDK 1.8 及以上版本运行。
本文所有示例代码在 IntelliJ IDEA 上可正常运行，并使用 Maven 3.6.3 版本作为包管理工具。注意事项
Java SDK 依赖 OkHttp，推荐您使用 4.x 版本的 OkHttp 库。OkHttp 的最低版本要求为 3.9.1，若低于此版本，可能会导致 SDK 无法正常编译。

安装方式
目前 TOS Java SDK 支持通过 Maven 安装、通过 Gradle 安装、通过 Jar 包直接安装三种方式。以 SDK 版本2.8.8 为例，配置如下。
说明
建议您使用最新版本的 SDK，最新版本请以 Git 更新为准。
通过 Maven 安装
在 pom.xml 文件中进行如下配置。
通过 Gradle 安装
在 build.gradle 文件中进行如下配置，在 dependencies 中添加依赖。
<dependency>
<groupId>com.volcengine</groupId>
<artifactId>ve-tos-java-sdk</artifactId>
<version>2.8.8</version>
</dependency>
xml
通过 JAR 包引入
说明
通过 JAR 包引入前，请您先下载最新的 JAR 包文件 。
在 IntelliJ IDEA 工程项目中导入 ve-tos-java-sdk JAR 包。
将下载的 ve-tos-java-sdk-2.8.8.jar 文件复制到您的项目中。
在 IntelliJ IDEA 中选择您的工程，右键选择 File > Project Structure > Modules > Dependencies > + >JARs or directories。
选中 ve-tos-java-sdk-2.8.8.jar 文件导入到 External Libraries 中。
在 Eclipse 工程项目中导入 ve-tos-java-sdk JAR 包。
将下载的 ve-tos-java-sdk-2.8.8.jar 文件复制到您的项目中。
在 Eclipse 中选择您的工程，右键选择 Properties > Java Build Path > Add JARs。
选中 ve-tos-java-sdk-2.8.8.jar 文件导入到 Libraries 中。
implementation 'com.volcengine:ve-tos-java-sdk:2.8.8'
