7.4 FSX
7.4.1 TOS FSX 概述
本文为您介绍 FSX 客户端的功能特性、运行环境、使用限制、使用流程及版本更新日志等信息，帮助您快速了解并使用该工具。FSX 是用于挂载存储桶的客户端，通过该客户端，您可以把 TOS 存储桶挂载到Linux 系统，并将其作为本地文件系统使用。这使您无需适配 TOS API，即可直接通过文件系统操作来管理 TOS 存储桶数据，从而简化开发流程，提升数据操作效率。
使用场景
FSX 支持将存储桶挂载到 Linux 系统作为本地文件系统使用，适用于需要按照文件系统语义使用存储桶中数据的场景，例如 AI 机器学习场景下需要按照文件系统语义训练模型数据。
FSX 支持在挂载存储桶时配置预读、数据缓存，用于提升文件读取性能，使用场景及性能优化详情请参见 FSX 性能调优。
功能特性
支持挂载桶或桶下的目录到 Linux 系统。
挂载存储桶到 Linux 后，在本地新增或覆盖等操作会自动同步到 TOS 存储桶，在 TOS 存储桶的新增、覆盖等操作也会自动同步到本地。
支持数据缓存，具体包括读缓存和写缓存功能，可以减少数据访问的延迟，提升系统性能。支持元数据缓存，提升文件操作效率。
运行环境
FSX 客户端当前仅支持 x86_64、ARM64（当前仅支持 ecs.c3bl 系列机型）的体系架构，暂不支持在Windows 和 macOS 环境使用。支持的环境请参考下表。

FSX 客户端默认会先写入数据

关于写缓存的详细介绍，请

通过 part_size 挂载参数
指定单个写缓存临时文件

限制 说明
访问限制
归档存储、冷归档或深度冷归档的数据需要
取回后才能访问，不支持直接读取。
使用 FSX 工具挂载存储桶时，仅支持 TOS 域
名，暂不支持 S3 域名。
写入限制
多客户端同时挂载同一存储桶并写入同一文
件时，无法保证数据一致性。
新写入的文件必须在文件关闭后才会上传到
TOS，因此文件关闭后，才能对其他客户端可
见。
对文件执行追加写操作后，不同类型的对
象，支持执行的 flush 操作次数不同，说明
如下： 
追加写 FNS 桶中的对象时，云端的历史数
据会使用 UploadPartCopy 接口对 TOS 中
的数据进行复制，追加的新数据则使用 
UploadPart 或 PutObject 接口进行上
传。该场景下，一次 open 操作仅支持一次
flush 操作。
追加写 HNS 桶中的对象时，TOS 会使用 
AppendObject 接口进行数据的追加写操
作。该场景下，支持对追加写的对象执行
多次 flush 操作。
对已存在的文件覆盖写时，打开该文件需要
设置 O_TRUNC 标志位。
文件写入时，大文件会通过分片上传的方式
进行上传，单个对象最多 10000 个分片，默
认参数分片大小为 8MB，如需上传超过
80000MB 的文件，请按需调大分片大小，详
细介绍，请参见 FSX 挂载参数说明 章节中
的 part_size 参数。
挂载 FNS 桶 时，重命名文件可能为非原子
操作： 
FSX 会优先使用 RenameObject API，如果
执行成功，则为原子操作；
如果该 Object 不支持使用 
RenameObject ，FSX 会使用 CopyObject +

POSIX 语义兼容
挂载存储桶到 Linux 系统后，Linux 系统可以通过兼容的 POSIX 文件接口管理桶内对象。由于 FSX 客户端只兼容部分 POSIX 语义，因此在 Linux 系统对存储桶执行的操作受限。

限制 说明
DeleteObject 实现重命名行为，如果 
DeleteObject 失败，那么重命名的源对象
会被保留。
不支持并发写入同一个文件，如果发生并发
写入请求，则第一个请求会成功，后续的请
求将失败。
