10.9.27 0007-00000403
问题描述
配置的同一条生命周期规则中，或相同前缀的多条规则中， Transitions 字段配置的多个 StorageClass 参数值重复。
问题原因
配置的生命周期规则中，或相同前缀的多条规则中， Transitions 字段配置的多个 StorageClass 参数值重复。
问题示例
场景1：同一条规则内同时配置了 30 天转低频存储，40 天转低频存储的沉降规则。
场景 2：多条相同前缀的规则，分别配置了 30 天转低频存储的沉降规则和 40 天转低频存储的沉降规则。
{
"Rules": [{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"Transitions": [
{
"StorageClass": "IA",
"Days": 30
},
{
"StorageClass": "IA",
"Days": 40
}
]
}]
}
JSON
{
"Rules": [
{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"Transitions": [
解决方案
Transitions 的多个配置值中 StorageClass 字段保持唯一。
{
"StorageClass": "IA",
"Days": 30
}
]
},
{
"ID": "id1",
"Prefix": "prefix",
"Status": "Enabled",
"Transitions": [
{
"StorageClass": "IA",
"Days": 40
}
]
}
]
}
