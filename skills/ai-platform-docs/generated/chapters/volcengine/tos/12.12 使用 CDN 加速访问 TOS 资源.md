12.12 使用 CDN 加速访问 TOS 资源
本文介绍如何将存储在火山引擎对象存储（TOS）中的静态资源，通过火山引擎内容分发网络（CDN）进行加速分发。
场景描述
如果您的业务需要分发大量的静态文件（例如图片、视频、安装包等），可以使用 TOS 作为存储源，并配合 CDN 来提升用户的访问体验。
对象存储（TOS） ：提供海量、可靠、低成本的云存储服务，适合存放各类静态资源。
内容分发网络（CDN） ：在全球范围内部署了大量边缘节点。CDN 可以将源站内容缓存到靠近用户的节点上，让用户可以就近获取所需内容，从而避免网络拥堵，提升访问速度。
前提条件
已开通火山引擎内容分发网络服务 。
已开通火山引擎对象存储服务 。
拥有一个已备案的域名。
操作步骤
步骤一：创建 TOS 私有桶并上传文件
创建存储桶。
出于安全考虑，建议您创建私有桶来存储您的静态资源，即创建存储桶时将桶策略配置为私有即可。存储桶创建后，进入该存储桶，单击上传文件，上传用于测试的静态文件。
步骤二：添加 CDN 加速域名
登录内容分发网络控制台 。
在左侧导航栏，单击域名管理。
在域名管理页面，单击新增。
在新增域名页面，配置加速域名和项目组，其他参数保持默认。
单击页面底部的新增源站。
在新增源站页面，完成以下配置，然后单击确定。
参数 说明
源站模式
指定该源站在回源链路中的角色，用于实现主
备容灾。支持配置如下：
主源站（默认）：优先回源的源站。
备源站：主源站异常时切换使用的备用源
站。
源站类型 指定回源目标的类型。本场景选择对象存储源
站，即回源至对象存储。
◦
◦
在新增域名页面，单击下一步，然后单击提交。
步骤三：配置 CNAME 解析
添加域名后，CDN 会为该域名分配一个 CNAME 地址。您需要将加速域名指向此 CNAME 地址，这样访问该域名的请求才能转发到 CDN 节点。
返回域名管理页面，找到刚刚添加的域名。
在 **CNAME ** 列，复制该域名的 CNAME 地址。
前往您的域名解析服务商处，为加速域名添加一条 CNAME 记录。以下配置以火山引擎云解析 DNS为例。
参数 说明
存储桶来源 跟随选择的源站类型显示来源信息。
鉴权方式
CDN 回源访问对象存储时的身份鉴权方式。支
持以下配置：
跨服务授权（默认）：通过服务间授权访
问，无需手动管理密钥。
固定秘钥：使用固定的 AK/SK 进行鉴权。
服务授权
如果是首次配置私有 TOS 桶作为源站，系统会
提示您授权 CDN 服务访问 TOS 服务。请单击
前往授权，并根据页面提示完成授权。授权
后，关闭设置源站页面，然后重复步骤 5。如
果之前已经完成授权，页面会显示已授权。
存储桶 在下拉列表中，选择您在步骤一中创建的 TOS
存储桶。
回源 Host
回源请求中携带的 Host 头，用于源站按 Host
区分站点或路由。未填写时默认与回源地址一
致。
私有桶访问 是否以私有桶方式访问对象存储。开启后可回
源访问私有权限的存储桶。当前需要开启。
权重 多个同模式源站之间的回源流量分配比例，权
重越高分到的回源请求越多，默认值 1。
HTTP 端口 回源使用 HTTP 协议时访问源站的端口，默认
80。
HTTPS 端口 回源使用 HTTPS 协议时访问源站的端口，默认
443。
◦
◦
参数 说明
域名 填写加速域名的前缀。例如，如果您的加速域
名是 cdn.example.com ，则填写 cdn 。
记录类型 选择 CNAME 。
单击提交。
CNAME 记录生效通常需要几分钟到几十分钟不等。
结果验证
等待 CNAME 记录生效后，您可以通过以下方式验证加速效果：
在浏览器中，访问您上传到 TOS 的文件。URL 格式为 http://<您的加速域名>/<文件名> 。例如，如果您上传的文件是 image.jpg ，加速域名是 cdn.example.com ，则访问 http://cdn.example.com/image.jpg 。
如果能够正常访问到文件，表示配置已成功。
参数 说明
记录值 单击添加记录值，然后粘贴您复制的 CNAME
地址。
您还可以使用 ping 或 dig 命令来检查域名的 CNAME 解析是否已生效。如果解析指向了以.volces.com 结尾的域名，则表示 CNAME 已配置成功。
