7.5.4 使用TOS PyTorch Connector
7.5.4.1 TosMapDataset
本文为您介绍如何通过 TosMapDataset 构建 Dataset。
前提条件
已安装并配置 TOS PyTorch Connector 。具体操作，请参见安装 TOS PyTorch Connector和配置TOSPyTorch Connector。
构建 Dataset
构建方式
在使用 TosMapDataset 构建 Dataset 时，有两种构建方式：
TOS_URI 前缀：适用于 TOS 存储路径具有统一规律的场景。
TOS_URI 的列表：适用于 TOS 存储路径位置明确但分散的场景。
通过 TOS_URI 前缀构建 Dataset
以下示例用于使用 TosMapDataset 的 from_prefix() 方法构建 Dataset。
通过 TOS_URI 的列表构建 Dataset
以下示例用于使用 TosMapDataset 的 from_urls() 方法构建 Dataset。

from tostorchconnector import CredentialProvider
from tostorchconnector import TosMapDataset
from torch.utils.data import DataLoader
# 数据集路径
dataset_uri = 'tos://bucket/prefix'
region = 'cn-beijing'
# 火山 TOS Endpoint
endpoint = 'http://tos-cn-beijing.ivolces.com'
ak = '<your-access-key>'
sk = '<your-secret-key>'
# 数据批次大小
BATCH_SIZE = 256
# 工作进程数
NUM_WORKERS = 32
# 数据转换函数
def transform(item):
 data = item.read()
return item.key, item.size
# 使用 TosMapDataset.from_prefix 从指定的数据集前缀构建数据集对象
with TosMapDataset.from_prefix(dataset_uri,
 region=region, endpoint=endpoint,
 transform=transform,
 cred=CredentialProvider(
 ak=ak,
 sk=sk)) as dataset:
#基于构建好的 dataset 创建 DataLoader 
 train_loader = DataLoader(dataset=dataset, batch_size=BATCH_SIZE, 
num_workers=NUM_WORKERS, shuffle=True)
# 使用 DataLoader 进行迭代训练/读取
for data in train_loader:
print(data)
