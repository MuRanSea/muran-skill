5.6.4.2 配置 IAM 策略
本文介绍自定义 IAM 策略的操作步骤及参数说明。
背景信息
关于访问控制 IAM 的详细说明，请参见访问控制 。
IAM 策略的说明及适用场景，请参见 IAM 策略概述 。
IAM 策略支持的动作说明，请参见 IAM 策略支持动作 。
使用可视化编辑器配置 IAM 策略
登录 IAM 控制台 。
在左侧导航栏中，单击权限策略。
在策略列表页面，单击新建自定义策略。
在新建自定义策略页面，设置策略基本信息。
在可视化编辑器页签下，设置如下策略参数。

参数 是否必选 说明
操作 是
定义该条权限的操作范围，
可选全部操作或指定操作。
选择指定操作后，控制台会
展示可选的操作以及操作的
含义，然后根据实际情况选
择具体操作。
资源 是
定义该条权限的资源范围，
可选全部资源或指定资源，
系统会根据您选择服务和操
作匹配可配置的资源类型，
如您选择指定资源，您还需
要单击添加TRN，配置具体资
源的 TRN。关于资源的详细
介绍，请参见 IAM 策略支持
资源 。
条件 否
定义该条权限的生效条件，
单击添加条件，配置条件
健、运算符和条件值，关于
条件的详细介绍，请参见 IAM
策略支持条件 。

命名规范如下：
test

参数 是否必选 说明 示例
Statement 是
策略的授权信息，包
含 Effect、Action 及 
Resource。
Plain
{ "Statement": [
{
"Effect": "Allow",
"Action": [
"tos:List*"
],
"Resource": [
"trn:tos:::bucket"
]
}
]
}
Effect 是
指定策略是允许还是
拒绝访问，取值范围
为：
* Allow：允许
* Deny：拒绝
Plain
"Effect": "Allow"
Action 是
指定策略允许或拒绝
的操作列表，TOS 支
持的操作列表请参见
IAM 策略支持动作
。
* 以字符串形式表
示，不区分大小写，
格式为 "Action":
["tos:Action名称"] 。
* 支持通配符 * ，表
示该资源能进行的所
有操作。例
如： "Action":
["tos:List*"] 。
Plain
"Action": ["tos:List*"]
Resource 否
策略参数设置完成后，单击提交。
后续操作
自定义策略创建完成后，您可以通过以下方式授予账号或角色权限：
创建用户时直接授予权限
参数 是否必选 说明 示例
设置该策略指定操作
适用的资源列表，如
果不填则表示所有资
源均不匹配。
* 以字符串形式表
示，不区分大小写，
格式为 "Resource":
["trn:tos:::{BucketName}/
{ObjectName}"]
* 如果您只需要对桶
执行相应操作，则资
源只设置桶名，例如 
"Resource": ["trn:tos:::
{BucketName}"] 。
* 如果您只需要对桶
中对象执行相应操
作，则需要设置桶内
资源，例如 
"Resource": ["trn:tos:::
{BucketName}/
{ObjectName}"] 。
* 支持通配符 * ，
设置在桶上表示所有
桶，设置在对象上表
示所有资源。
Plain
"Resource": [
"trn:tos:::bucket/*",
"trn:tos:::bucket",
"trn:tos:::bucket*/*"
]
Condition 否
设置该策略生效的条
件，TOS 支持的条
件，请参见 IAM 策略
支持条件 。
一个策略中可以有多
条 Condition，一个
Condition 中可以有
多对条件键，每个条
件键对应的条件值可
以是多个（表达为数
组形式）。
Plain
"Condition": {
"IpAddress": {
"volc:SourceIp": [
"203.0.113.0/24"
]
}
}
通过角色授予权限
说明
使用 IAM 授予账号或角色权限时，预计需要等待 1 分钟，才能生效。

<Tab zoneid="dw4W2Blwr8" title="授权 IAM 策略">
<TabTitle>授权 IAM 策略</TabTitle>
1. 在**自定义策略**列表，单击目标策略**操作**栏对应的**授权。** 
2. 在添加权限页面，配置如下信息。
 |区域 |说明 |
 |---|---|
 |限制到项目资源 |默认**否**，选**是**时权限将仅在访问项目内资源时生效。 |
 |授权身份 |选择被授权身份。可以直接在搜索框输入身份名、显示名或备注搜索。也可以在**用户**、**用户组**、**角色**页签下选择对应身份。 |
3. 配置完成后，单击**提交**，即可为不同的目标群体授权。
</Tab>
<Tab zoneid="PAaLOz2hS8" title="编辑 IAM 策略">
<TabTitle>编辑 IAM 策略</TabTitle>
1. 在**自定义策略**列表，单击目标策略**操作**栏对应的**编辑。** 
2. 选择对应的编辑器页签，编辑策略信息。
3. 单击**提交**，即可修改策略内容。
</Tab>
<Tab zoneid="ZduIgWJ6tH" title="删除 IAM 策略">
<TabTitle>删除 IAM 策略</TabTitle>
1. 在**自定义策略**列表，单击目标策略**操作**栏对应的**删除。** 
2. 在弹出的对话框中单击**删除**，即可删除该策略。
