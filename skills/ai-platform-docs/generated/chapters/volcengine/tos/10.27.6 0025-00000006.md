问题描述
桶清单规则的 ID 不合法。
问题原因
桶清单规则的 ID 设置不合法，桶清单规则的 ID 需要符合以下要求：
长度为 0~64 个字符。
只能包含小写字母 a-z、大写字母 A-Z、数字 0-9、中划线（-）、下划线（_）和英文句号（.）。开头和结尾只能是小写字母 a-z、大写字母 A-Z、数字 0-9 。
问题示例
您在设置桶清单规则时，ID 项填写了非法值。
PUT /?inventory&id=report1 HTTP/1.1
