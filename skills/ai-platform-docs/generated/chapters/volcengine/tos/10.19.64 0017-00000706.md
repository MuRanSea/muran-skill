问题描述
软链接不支持 RestoreObject 操作。
问题原因
用户对软链接发起 RestoreObject 请求，导致请求失败。
问题示例
以下请求中，请求的对象（link-file）为软链接，则返回该错误。
解决方案
确保请求的对象非软链接，您可以通过 HeadObject 接口响应中的 x-tos-object-type 来判断对象是否为软链接。
POST /link-file?restore
Host: examplebucket.tos.cn-beijing.com
Date: Mon, 18 Mar 2019 08:25:17 GMT
Authorization: SignatureValue
{
"RestoreRequest": {
"Days": 10
 },
"RestoreJobParameters": {
"Tier": "Standard"
 }
}
Go
