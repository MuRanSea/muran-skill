7.2.6.2 查看支持命令或帮助文档（help）
您可以使用 help 命令查看 tosutil 工具支持的命令，或查看某个具体命令的帮助文档。

用法： tosutil [command] [args...] [options...]
您可以使用 "tosutil help command" 查看每个命令的详细帮助信息
基本命令：
 cp file_url cloud_url [options...]
 cloud_url file_url [options...]
 cloud_url1 cloud_url2 [options...]
 -recover=xxx [options...] 
 上传对象、下载对象或复制对象 
 ls [cloud_url] [options...] 
 列举桶、列举桶内对象或列举桶内分片上传任务 
 mb cloud_url [options...] 
 按照用户指定的桶名和参数创建一个新桶 
 rm cloud_url [options...] 
 删除桶、删除对象或删除分片上传任务 
 setmeta cloud_url [options...] 
 设置对象元数据 
 stat cloud_url [options...] 
 查询桶属性或查询对象属性 
辅助命令：
 clear [checkpoint_dir] [options...] 
 删除指定文件夹下的断点记录文件，并尽力执行云端清理工作 
 config [options...] 
 更新配置文件中的关键配置信息 
 help [command] [options...]
