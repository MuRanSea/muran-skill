问题描述
URL 参数 append-last-time 取值非法。
问题原因
用户上传追加写对象时，URL 参数 append-last-time 取值非 true 或 false 。
问题示例
您发起 AppendObject 请求，URL 参数 append-last-time 取值非法。
解决方案
确保 URL 参数 append-last-time 取值合法。
POST /objectName?append&offset=101&append-last-time=abc HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: GMT Date
Authorization: authorization xxx
