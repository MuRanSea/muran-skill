10.7.37 0005-00000101
问题描述
列举对象时，URL 参数 marker 、 key-marker 或 start-after 不以 prefix 参数的取值为前缀。问题原因
用户列举对象时，请求中的 marker 、 key-marker 或 start-after 字段不以 prefix 字段取值为前缀。问题示例
您发起列举对象请求，请求中 marker 字段取值不合法。
解决方案
确保 URL 参数 marker 、 key-marker 或 start-after 使用 prefix 字段取值为前缀。
GET /?marker=abc&prefix=aaa HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: GMT Date
Authorization: authorization xxx
