问题描述
在生命周期规则中，同时配置了 AbortIncompleteMultipartUpload 和 tag 字段 。
问题原因
生命周期规则不支持同时存在 AbortIncompleteMultipartUpload 字段与 tag 字段。
问题示例
解决方案
配置生命周期规则时， AbortIncompleteMultipartUpload 字段与 tag 字段二选一，即只配置 AbortIncompleteMultipartUpload 字段，或者只配置 tag 字段。
{
"Rules": [
{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"Tags": [
{
"Key": "a",
"Value": "b"
}
],
"AbortIncompleteMultipartUpload": {
"DaysAfterInitiation": 1
}
}
]
}
JSON
