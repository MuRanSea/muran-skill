9.14.6.14 事件通知
9.14.6.14.1 PutBucketNotificationType2（Rust SDK）
put_bucket_notification_type2 接口用于为存储桶配置事件通知规则，本文介绍如何通过 Rust SDK 的put_bucket_notification_type2 接口设置规则，将对象创建或删除事件推送至 VeFaaS 或 Kafka。注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
分层桶不支持调用 put_bucket_notification_type2 接口。
同一存储桶内 rule_id 不可重复，长度上限为 255 个字符。
destination 至少包含 1 个且不超过 5 个不同目标。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行put_bucket_notification_type2 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：
tos:PutBucketNotificationType2

设置通知规则的目标为 VeFaaS 函数
use async_trait::async_trait;
use futures_core::future::BoxFuture;
use std::env;

use ve_tos_rust_sdk::bucket::{PutBucketNotificationType2Input, NotificationRule, NotificationDestination, DestinationVeFaaS};
use ve_tos_rust_sdk::error::TosError;
#[derive(Debug, Default)]
pub struct TokioRuntime {}
#[async_trait]
impl AsyncRuntime for TokioRuntime {
type JoinError = tokio::task::JoinError;
async fn sleep(&self, duration: Duration) {
 tokio::time::sleep(duration).await;
 }
fn spawn<'a, F>(&self, future: F) -> BoxFuture<'a, Result<F::Output, Self::JoinError>>where
 F: Future + Send + 'static,
 F::Output: Send + 'static,
 {
Box::pin(Handle::current().spawn(future))
 }
fn block_on<F: Future>(&self, future: F) -> F::Output {
 Handle::current().block_on(future)
 }
}
#[tokio::main]
async fn main() {
let _guard = init_tracing_log("info", "temp/logs", "app.log");
let ak = env::var("TOS_ACCESS_KEY").unwrap_or("".to_string());
let sk = env::var("TOS_SECRET_KEY").unwrap_or("".to_string());
let endpoint = "https://tos-cn-beijing.volces.com";
let region = "cn-beijing";
let client = tos::builder::<TokioRuntime>()
 .connection_timeout(3000)
 .request_timeout(10000)
 .max_retry_count(3)
 .ak(ak)
 .sk(sk)
 .region(region)
 .endpoint(endpoint)
 .build().unwrap();
// 创建通知规则
let mut rule = NotificationRule::new("vefaas-notify-rule");
 rule.set_events(vec!["tos:ObjectRemoved:Delete".to_string()]);
// 设置VeFaaS函数目标
let mut destination = NotificationDestination::new();
 destination.set_ve_faas(vec![DestinationVeFaaS::new("vefaas-function-123")]);
 rule.set_destination(destination);
// 创建输入

// 调用API设置通知配置

println!("客户端错误: {}", message);

println!("服务器错误: request_id: {}, ec: {}, code: {}", request_id, ec, code);
 }
 }
 }
 }
