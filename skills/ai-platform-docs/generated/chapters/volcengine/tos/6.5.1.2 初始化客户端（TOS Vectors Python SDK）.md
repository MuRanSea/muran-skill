6.5.1.2 初始化客户端（TOS Vectors Python SDK） 
TOSVectorClient 提供了一系列接口用与 TOS 服务进行交互，以管理存储桶和对象等 TOS 服务上的资源。可通过AccessKey/SecretKey、STS (Security Token Service）等方式初始化 TOSVectorClient。在初始化时，可设置建立连接超时时间、超时重试次数和最大空闲连接数量等可选参数。本文介绍如何初始化 TOSVectors Python SDK。
前提条件
安装 TOS Vectors Python SDK
获取 AKSK 信息
注意事项
单进程多线程场景建议使用一个 VectorClient，避免重复初始化 VectorClient；多进程场景下需要创建多个 VectorClient，不能共享同一个 VectorClient，否则会有多进程并发安全问题，可能会导致读写请求数据错乱。

常见配置场景
配置 STS
您可以通过 STS 服务向其他用户颁发临时访问凭证，在凭证有效期内，用户可访问您的 TOS Vectors 资源，而无需透露您的长期密钥，保障您 TOS Vectors 资源的安全性。
说明
您可以通过 STS 服务的 AssumeRole 接口获取临时访问凭证，临时访问凭证中包含安全密钥（AccessKeyId、SecretAccessKey）和安全令牌（SessionToken），后续您可以使用该信息访问TOS Vectors 服务。关于搭建 STS 服务的基本操作，请参见 使用 STS 临时 AK/SK+Token 访问火山引擎 TOS。

配置超时机制
您可以在初始化 VectorClient 时，通过添加可选参数配置网络请求的超时时间，目前 TOS Vectors PythonSDK支持配置连接超时 connection_time 和请求超时 socket_timeout 。
以下代码用于初始化 TosClient 时配置超时时间。
import os
import tos
# ak和sk为临时访问凭证中的安全密钥（AccessKeyId、SecretAccessKey）
ak = "your access key"
sk = "your secret key"
# sts_token为临时访问凭证中的安全令牌（SessionToken）
sts_token = "your security token"
# your endpoint 和 your region 填写Bucket 所在区域对应的Endpoint。# 以华北2(北京)为例，your endpoint 填写 tos-cn-beijing.volces.com，your region 填写 cn-beijing。
endpoint = "your endpoint"
region = "your region"
# 使用临时访问凭证中的认证信息初始化TosClient
client = tos.VectorClient(ak, sk, endpoint, region, security_token=sts_token)

配置重试策略
网络波动或短期 TOS Vectors 服务异常（返回 500 状态码）等场景会导致调用 TOS Vectors 服务失败，针对此问题 Python SDK 内部提供了重试机制，幂等操作的接口在失败后会使用指数避让策略进行重试，非幂接口则直接抛出对应异常。您可以在初始化 TosClient 时，添加可选参数配置重试次数。配置代理服务器
TOS Vectors Python SDK 支持配置代理服务器的方式访问 TOS Vectors 服务，您可以在初始化 VectorClient时，添加可选参数配置代理服务器。
说明
目前只支持 HTTP 协议代理。

配置连接池
TOS Vectors Python SDK 支持连接池配置，您可以在初始化 VectorClient 时，添加可选参数配置连接池大小。
说明
连接池大小默认配置为 1024，单进程多线程场景建议您使用一个 VectorClient 实例。
初始化参数列表
