8.5.19.7.3 GetObjectSetQuotaByTag
功能描述
此接口用于查询基于 ObjectSet 标签配置的 QoS 与容量配额规则。
注意事项
如果未配置QoS 与容量配额规则，接口将返回 ObjectSetQuotaConfigNotExist 错误。
通过子账号使用时，需要授予当前桶的 GetObjectSetQuotaByTag 权限。
请求消息样式
请求参数和消息头
该请求返回的公共响应消息头，请参见公共参数 。
请求元素
该请求不使用消息元素。
响应消息头
该请求返回的公共响应消息头，请参见公共参数 。
响应元素
GET /?objectsetquotabytag HTTP/1.1
Host: bucket-name.tos-cn-beijing.volces.com
Date: GMT Date
Authorization: authorization string
JSON
名称 参数类型 示例值 说明
Rules Array - 规则列表。
Tag Container -
ObjectSet 标签列表信
息。
Key String owner 标签 Key 的值。
Value String zhangsan 标签 Value 的值。
Qos Container -
Qos自定义流控信
息。
子节点：
ReadsQps , WritesQps , ListQps , ReadsRate , WritesRate
请求示例
名称 参数类型 示例值 说明
ReadsQps Integer 1000
读请求QPS限制，如
果不设置或取值为
0，则表示不限制。

WritesQps Integer 1000
写请求 QPS 限制，如
果不设置或取值为
0，则表示不限制。
父节点： Qos
ListQps Integer 1000
List 请求 QPS 限制，
如果不设置或取值为
0，则表示不限制。
父节点： Qos
ReadsRate Integer 1000
读请求带宽限制，单
位为 Mb/s，如果不设
置或取值为 0，则表
示不限制。
父节点： Qos
WritesRate Integer 1000

父节点： Qos

定默认的容量配额，
单位为 Byte，如果不
设置或取值为 0，则
表示不限制。取值范
围为 [0, 2^63-1]。
