9.2.6.3.1 查询 ObjectSet 访问域名（Java SDK）
本文介绍如何通过 TOS Java SDK 查询指定 ObjectSet 在已启用 ObjectSet 规则的汇聚接入点下生成的访问域名，包括 TOS 协议域名和 S3 协议域名。
注意事项
ObjectSet 必须存在。
查询 ObjectSet Endpoint 仅返回 CAP ObjectSet 规则状态为 Enabled 的接入点。
通过子账号调用时，需要具备当前 Bucket 的 tos:GetObjectSetEndPoint 权限。
代码示例
import com.volcengine.tos.TOSV2;
import com.volcengine.tos.TOSV2ClientBuilder;
import com.volcengine.tos.TosClientException;
import com.volcengine.tos.TosServerException;
import com.volcengine.tos.model.bucket.GetObjectSetEndpointInput;
import com.volcengine.tos.model.bucket.GetObjectSetEndpointOutput;
import com.volcengine.tos.model.bucket.ObjectSetEndpoint;
public class GetObjectSetEndpointExample {
public static void main(String[] args) {
String endpoint = System.getenv("TOS_ENDPOINT");
String region = System.getenv("TOS_REGION");
String accessKey = System.getenv("TOS_ACCESS_KEY");
String secretKey = System.getenv("TOS_SECRET_KEY");
String bucket = System.getenv("TOS_BUCKET");
String objectSetName = System.getenv("TOS_OBJECT_SET_NAME");
TOSV2 tos = new TOSV2ClientBuilder().build(region, endpoint, accessKey, secretKey);try {
GetObjectSetEndpointInput input = GetObjectSetEndpointInput.builder()
 .bucket(bucket)
 .objectSetName(objectSetName)
 .build();
GetObjectSetEndpointOutput output = tos.getObjectSetEndpoint(input);
 System.out.println("getObjectSetEndpoint succeed");
if (output.getEndpoints() != null) {
for (ObjectSetEndpoint item : output.getEndpoints()) {
 System.out.println("CAP: " + item.getCapname());

 } catch (TosClientException e) {
