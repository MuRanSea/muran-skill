9.2.6.2.1 管理桶 ACL（Java SDK）
桶（Bucket）是 TOS 的全局唯一的命名空间，相当于数据的容器，用来储存对象（Object）数据。TOS针对桶（Bucket）资源的权限控制包括桶授权策略（Bucket Policy）和桶读写权限控制（Bucket ACL）。本文介绍如何通过 TOS Java SDK 管理桶的读写权限（ACL）。有关桶的授权策略管理请参考授权策略配置。设置桶的访问权限
您可以通过 TOS Java SDK 的 putBucketACL 接口设置指定桶的读写权限。
注意
设置桶的读写权限，您的账号必须具备 tos:PutBucketACL 权限，或具备 WRITE_ACP 桶 ACL 权限。具体操作，请参见权限配置概述。
桶 ACL 说明

桶的访问权限可通过在请求 Body 中填写详细的 ACL 权限信息，或在请求的 Header 中进行设置。访问权限 描述 访问权限值
