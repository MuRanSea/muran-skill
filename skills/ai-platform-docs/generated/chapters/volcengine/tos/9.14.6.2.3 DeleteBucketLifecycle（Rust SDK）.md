9.14.6.2.3 DeleteBucketLifecycle（Rust SDK）
delete_bucket_lifecycle 接口用于删除存储桶生命周期规则，本文介绍如何通过 Rust SDK 的delete_bucket_lifecycle 接口删除存储桶生命周期规则。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
删除不存在的 Lifecycle 时，接口仍返回 204 状态码。
该操作会一次性移除 Bucket 内所有生命周期规则，无法部分删除。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行delete_bucket_lifecycle 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:DeleteBucketLifecycle
