7.2.4 命令格式
本文介绍 tosutil 工具支持的命令的基本格式及常见的基本参数。
基本格式
Windows 系统
macOS/Linux 系统
常见基本参数
tosutil [command] [args...] [options...]
Plain
./tosutil [command] [args...] [options...]
Plain
参数 说明
[command] 需要运行的命令，例如 ls 、 cp 、 rm 等。
[args...] 运行命令的基本参数，一般为必选，可能存在多
个参数，以空格分隔。
[options...]
运行命令的可选参数。 当存在多个参数时，以 
- 开头作为参数名，以 = 分隔作为参数值，
例如 -limit=100 。
注意
当可选参数为布尔类型时，支持仅以 
- 开头（不带 = ），表示取值为 
true。
通用可选参数
除部分特殊的辅助命令外，所有命令均可包含可选参数，可选参数说明如下。
参数 说明
cloud_url
表示 TOS 上的路径，格式为 tos://bucket/
[prefix] ，其中 prefix 为可选，代表对象名或对
象名前缀。
file_url 代表本地文件路径。
folder_url 代表本地文件夹路径。
参数 说明
-e
代表执行本次命令所使用的 TOS 服务端的
Endpoint。
-re
代表执行本次命令所使用的 TOS 服务端的
Region。
说明
TOS 支持的 Endpoint 和 Region 信息，请
参见地域和访问域名。
-i
代表执行本次命令所使用的 Access Key ID。
说明
匿名访问 TOS 时，无需指定 Access Key
ID，设置参数为 -i= 即可。
-k
代表执行本次命令所使用的 Secret Access Key 。
注意
当您的命令同时设置了 -conf 和 -e/-re/-i/-k/-t 参数时， -conf 参数仍有效，但该路径下配置文件中的 Access key、Secret key 等参数不生效，以运行命令时指定的 -e/-re/-i/-k/-t 参数优先。参数 说明
说明
匿名访问 TOS 时，无需指定 Secret
Access Key，设置参数为 -k= 即可。
-t
代表执行本次命令所使用的 Security Token，使
用临时 AccessKey 时需要。
说明
匿名访问 TOS 时，无需指定 Security
Token，设置参数为 -t= 即可。
-conf 代表执行本次命令所使用的配置文件路径。
