9.14.7.1.6 AppendObject（Rust SDK）
append_object 接口用于追加写对象，本文介绍如何通过 Rust SDK 的 append_object 接口在指定 offset 处追加数据，支持 5 GB 内 Appendable 对象并发安全写入。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
追加后对象大小不可超过 5 GB，超出将导致 append_object 失败。
仅当 offset 为 0 时可设置 content_type ，后续追加该参数会被忽略。
append_object 不支持服务端加密，设置相关加密头域将返回错误。
对同一 appendable_object 并发执行 append_object 可能产生冲突，建议串行调用。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行append_object 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:PutObject
