5.9.1.6 多区域接入点支持的 API 操作
通过多区域接入点域名访问 TOS 时，只支持对 TOS 执行对象级别的操作，不支持桶操作。本文介绍多区域接入点支持的 API 操作。
分类 操作 说明
基础操作
GetObject 下载指定对象。
PutObject 向桶中添加对象。
HeadBucket 判断桶是否存在和是否有桶的
访问权限。
ListObjects 列举对象。
HeadObject 获取对象的元数据。
CopyObject
拷贝对象。
说明
通过多区域接入点拷贝
对象时，多区域接入点
下存储桶仅支持作为
CopyObject 的目标存
储桶，不支持作为源端
目标桶。
SetObjectMeta 更新对象元数据。
AppendObject 追加写对象。
RestoreObject 恢复对象。
RenameObject 重命名对象。
DeleteObject 删除指定对象。
对象 ACL
PutObjectACL 设置对象的访问控制权限
（ACL）。
GetObjectACL 获取指定对象的访问控制权限
（ACL）。
对象标签
PutObjectTagging 设置和更新对象的标签信息。
GetObjectTagging 获取对象的标签信息。
DeleteObjectTagging 删除对象的标签信息。
抓取对象 FetchObject 从指定 URL 抓取资源，并存储
到存储桶。
分类 操作 说明
PutFetchTask 创建从指定 URL 抓取资源，并
存储到存储桶的异步任务。
GetFetchTask 查询异步任务的详细信息。
软链接
PutSymlink 创建软链接。
GetSymlink 获取软链接对象信息。
分片上传
CreateMultipartUpload 初始化分片上传任务。
UploadPart 上传分片数据。
CompleteMultipartUpload 合并已经上传的分片数据。
AbortMultipartUpload 取消分片上传任务。
UploadPartCopy 已上传对象的一部分或者全部
拷贝为分片。
ListMultipartUploads 列举正在进行的分片上传任
务。
