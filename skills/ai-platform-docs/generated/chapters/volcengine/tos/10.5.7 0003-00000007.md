10.5.7 0003-00000007
问题描述
VPC 策略拒绝。
问题原因
配置双端固定策略后，请求不满足该策略，导致请求被拒绝。
问题示例
假设 VPC 终端节点的配置如下：
此策略表示禁止该 VPC 内的服务器，使用任意账号对桶 tos-example 进行上传对象操作，若某用户进行上传对象操作，则返回该错误。
解决方案
检查 VPC 终端节点配置。
{
"Statement": [
{
"Effect": "Deny",
"Principal": ["*"],
"Action": ["tos:PutObject"],
"Resource": [
"trn:tos:::tos-example/*"
]
}
]
}
JSON
