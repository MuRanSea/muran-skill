9.14.6.4 桶 ACL
9.14.6.4.1 PutBucketACL（Rust SDK）
put_bucket_acl 接口用于设置桶的访问控制权限，支持请求体或头域方式覆盖原有 ACL。本文介绍如何通过 Rust SDK 的 put_bucket_acl 接口完成该操作。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
单次调用最多写入 100 条 Grant，新 ACL 会完全覆盖旧 ACL。
使用 x-tos-acl 头域时，不可再使用其他授权头域。
若通过 x-tos-grant-read-non-list 授权，必须同时携带 x-tos-grant-read-acp ，否则该字段无效。开启 BucketAclDelivered 需同时提供 Owner 字段，否则配置不生效。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行put_bucket_acl 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:PutBucketACL

async fn main() {
let _guard = init_tracing_log("info", "temp/logs", "app.log");
let ak = env::var("TOS_ACCESS_KEY").unwrap_or("".to_string());
let sk = env::var("TOS_SECRET_KEY").unwrap_or("".to_string());
let endpoint = "https://tos-cn-beijing.volces.com";
let region = "cn-beijing";
let client = tos::builder::<TokioRuntime>()
 .connection_timeout(3000)
 .request_timeout(10000)
 .max_retry_count(3)
 .ak(ak)
 .sk(sk)
 .region(region)
 .endpoint(endpoint)
 .build().unwrap();
let bucket = "example-bucket";
let key = "example-object";
let mut input = PutObjectACLInput::new(bucket, key);
// Replace with actual owner ID
 input.set_owner(Owner::new("your-account-id"));
let grant = Grant::new(
 Grantee::new_with_canned(GranteeType::GranteeGroup, 
CannedType::CannedAuthenticatedUsers),
 PermissionType::PermissionRead
 );
 input.set_grants(vec![grant]);
let output = client.put_object_acl(&input).await;
match output {
Ok(_) => println!("Successfully set object ACL via request body"),
Err(err) => {
match err {
 TosError::TosClientError { message, .. } => {
println!("Client error: {}", message);
 }
 TosError::TosServerError { request_id, ec, code, .. } => {
println!("Server error: request_id: {}, ec: {}, code: {}", request_id, ec, code);
 }
 }
 }
