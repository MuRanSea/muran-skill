5.3.7.4 访问控制 IAM 策略
本文介绍如何在访问控制（IAM）中创建当前主账号下的 IAM 用户，并通过配置 IAM 策略，按需授予其访问 TOS 资源的权限。并提供典型策略示例与常见问题指引，帮助您快速完成 TOS 资源的访问控制配置。背景信息
访问控制（Identity and Access Management，IAM）是火山引擎提供的统一身份与权限管理服务。您可以在当前主账号下创建 IAM 用户、用户组和角色，并通过绑定权限策略，为不同身份授予相应的资源访问权限。
针对不同人员、应用或业务系统，建议分别创建独立的访问身份，并按照最小权限原则授予其完成工作所需的权限，从而避免多人或多个业务场景共享主账号或同一访问凭证，有效降低凭证泄露和越权访问的风险。
进入访问控制 IAM 策略页面
登录对象存储控制台 。
在左侧导航栏，单击桶列表。
在顶部导航栏，选择存储桶所属项目。
在桶列表页面，单击目标桶名称。
在左侧导航栏，单击权限管理。
在权限管理页面，选择访问控制 IAM 策略页签。
如需配置 IAM 策略，请参照下文使用指引完成配置。
使用指引
您可以按照以下流程为当前主账号下的 IAM 用户授予 TOS 资源访问权限。
创建 IAM 用户：单击前往 IAM 控制台 ，进入 IAM 用户管理页面，创建用于访问 TOS 的 IAM 用户。确定权限范围：根据 IAM 用户的实际工作内容，确定其需要执行的 TOS 操作和允许访问的资源范围。关于 TOS 支持的 IAM 策略、操作及资源范围，请参见 IAM 策略概述。
创建并绑定策略：根据所需权限创建自定义 IAM 策略，并将策略绑定到对应的 IAM 用户。具体操作请参见配置 IAM 策略。
验证访问权限：使用该 IAM 用户登录控制台或调用 TOS API，验证其是否仅能访问已授权的资源和执行已授权的操作。
建议遵循最小权限原则。除非业务确有需要，请勿直接授予所有 TOS 操作或所有 TOS 资源的访问权限。典型策略示例
