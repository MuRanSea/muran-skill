5.3.7.4 浏览器缓存有效期
通过配置浏览器缓存有效期，可实现在规定的时效内更新浏览器缓存。本文介绍配置浏览器缓存有效期的具体操作。
背景信息
Cache-Control 消息头用于在 HTTP 请求和响应中，通过指定指令来实现缓存机制。在 HTTP 消息头中，服务器可以通过对 Cache-Control 的设置来指定缓存文件的过期时间。TOS 可以通过配置 
Cache-Control: max-age=<您设置的时间> 头部，来实现对浏览器缓存文件过期时间的控制。注意事项
配置浏览器缓存有效期后，缓存时间仅对新上传到该存储桶的对象生效，存储桶中已有的历史对象不受影响。新上传到该存储桶的对象若未指定 Cache-Control 头部，将自动继承存储桶的缓存配置。主账号默认拥有全部权限，IAM 子用户默认没有任何权限。如果您需要使用子账号执行该操作，则需要主账号通过 IAM 策略 或桶策略 为该子账号授予 tos:PutBucketMaxAge 、 tos:GetBucketMaxAge 、tos:DeleteBucketMaxAge 权限。
操作步骤
登录对象存储控制台 。
在左侧导航栏，单击桶列表。
在顶部导航栏，选择存储桶所属项目。
在桶列表页面，单击目标桶名称。
在左侧导航栏，选择权限管理 > 浏览器缓存有效期。
在浏览器缓存有效期页面，单击编辑，将浏览器缓存有效期置于开启状态，然后配置缓存时间。单击确定，完成配置。
参数 说明
缓存时间
浏览器缓存文件的过期时间。
取值为 1 到 31536000 之间的正整数，单位为
秒。
配置后，新上传到该存储桶的文件，若未指定 
Cache-Control 头部，将自动添加 CacheControl: max-age=<您设置的时间> 头部。
