10.9.32 0007-00000408
问题描述
配置的生命周期规则中， Transitions 字段的 Date 参数取值非 UTC 零点。
问题原因
配置的生命周期规则中， Transition 字段的 Date 参数取值非 UTC 零点。
问题示例
解决方案
设置 Date 的值为 2024-02-27T00:00:00.000Z 格式，即 UTC 零点。
{
"Rules": [{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"Transitions": [
{
"StorageClass": "IA",
"Date": "2024-02-27T08:00:00.000Z"
}
]
}]
}
JSON
