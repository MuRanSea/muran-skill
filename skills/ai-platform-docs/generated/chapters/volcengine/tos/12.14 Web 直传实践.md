12.14 Web 直传实践
您使用 PostObject 接口，将文件以 HTML 表单的格式，直接从 Web 端上传到 TOS。上传所需的签名可以从服务端获取，参见 Post 表单预签名。
步骤一：配置跨域访问
从 Web 上传数据到 TOS 时，会向 TOS 发送跨域请求。当 TOS 收到跨域请求，会读取存储桶对应的跨域规则进行相应的权限检查。您需要在 TOS 设置跨域访问规则，实现 Web 正常传输数据到 TOS。关于跨域访问规则的详细介绍，请参见跨域访问设置。
登录对象存储控制台 。
在左侧导航栏，单击桶列表，在桶列表页面，单击目标桶名称。
在左侧导航栏，选择权限管理 > 跨域访问设置。
在跨域访问设置页面，单击创建规则。
在创建CORS规则页面，配置如下参数。
