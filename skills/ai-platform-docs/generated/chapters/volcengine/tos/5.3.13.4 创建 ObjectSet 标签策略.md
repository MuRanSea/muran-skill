5.3.13.4 创建 ObjectSet 标签策略
您可以为 ObjectSet 设置标签，并配置 QoS 流控限制、容量上限和生命周期管理规则，实现对特定标签下所有 ObjectSet 内的对象进行批量数据沉降或归档。本文介绍创建标签策略的具体操作。
注意事项
每个 Key/Value 唯一对应一条标签策略。
操作步骤
登录对象存储控制台 。
在左侧导航栏，单击桶列表。
在顶部导航栏，选择存储桶所属项目。
在桶列表页面，单击目标桶名称。
在左侧导航栏，选择 ObjectSet > ObjectSet 策略。
单击创建标签策略，设置如下参数。
分类 参数 说明
标签信息
标签 Key
ObjectSet 标签的 Key。
取值规则如下：
Key 长度不能超过 128 个
字符。
Key 不支持中文字符。
每个 Key/Value 唯一对应一
条策略。
标签 Value
ObjectSet 标签的 Value。
取值规则如下：
Value 长度不能超过 256 个
字符。
Value 不支持中文字符。
每个 Key/Value 唯一对应一
条策略。
QoS 流控限制
ReadsQps
ObjectSet 的读请求 QPS 上
限。
取值范围为 0 到 100000000
的整数，设置为 0 代表不限
制。
WritesQps
ObjectSet 的写请求 QPS 上
限。
取值范围为 0 到 100000000
的整数，设置为 0 代表不限
制。
ListQps
ObjectSet 的列表请求 QPS 上
限。

其他操作
在标签策略页面，您可以对已创建的标签策略进行以下管理操作：
编辑：单击指定标签策略操作列的编辑，修改标签策略的 QoS 流控限制和生命周期规则。
删除：单击指定标签策略操作列的删除， 在弹出的对话框中单击确定，即可删除标签策略。分类 参数 说明
取值范围为 0 到 100000000
的整数，设置为 0 代表不限
制。
ReadsRate
ObjectSet 的读带宽上限。
单位为 Mbps，取值范围为 0
到 100000000 的整数，设置
为 0 代表不限制。
WritesRate
ObjectSet 的写带宽上限。
单位为 Mbps，取值范围为 0
到 100000000 的整数，设置
为 0 代表不限制。
容量上限
ObjectSet 的容量上限。
取值范围为 0 到 100PiB，设
置为 0 代表不限制。
