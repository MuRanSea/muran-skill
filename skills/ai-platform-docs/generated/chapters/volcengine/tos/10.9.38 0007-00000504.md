问题描述
配置的生命周期规则中， NoncurrentVersionTransitions 字段同时存在 NoncurrentDays 和 NoncurrentDate参数。
问题原因
配置的生命周期规则中， NoncurrentVersionTransitions 字段同时存在 NoncurrentDays 和 NoncurrentDate 参数，要求有且仅有其中一个。
问题示例
解决方案
配置生命周期规则时， NoncurrentDays 或 NoncurrentDate 二选一，即只配置 NoncurrentDays ，或只配置 NoncurrentDate 。
{
"Rules": [{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"NoncurrentVersionTransitions": [
{
"StorageClass": "IA",
"NoncurrentDays": 30,
"NoncurrentDate": "2024-02-27T00:00:00.000Z"
}
]
}]
}
