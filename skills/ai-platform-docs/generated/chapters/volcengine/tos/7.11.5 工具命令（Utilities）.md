7.11.5 工具命令（Utilities）
工具命令提供能力探测、通用 API 调用、配置管理、Shell 补全、本地服务、Skill 管理与自检诊断等辅助能力。本章节介绍如何使用工具命令组。
命令概览
工具命令
capabilities
通过 capabilities 命令查看工具的命令能力列表，支持按层级、分组或关键词过滤输出。支持通过 --view 参数指定输出视图，可选值为： groups （默认）、 text 、 compact 、 full 。支持通过 --group 、 --search 、 --layer 参数过滤输出内容。

config
通过 config 命令初始化或管理工具配置，支持多 profile 场景。
配置文件默认路径为 ~/.tos/config.toml ，可通过 --config-path 或环境变量 TOS_CONFIG_PATH 覆盖；TOS 专属配置写入 profile.ve-tos 配置文件。
支持调整的字段如下：
checkpoint_dir 、 batch_report_dir 、 batch_report_format 、 progress_enabled 、 max_retry_count 、requesttimeout 、 connecttimeout 、 maxconnections 。

api（原始 API 透传）
通过 api 命令直接透传请求至 TOS 服务端 API，适合调试或执行工具未封装的操作。
--request 参数支持内联 JSON 或 file://path 文件引用，可配置字段如下：
method 、 endpoint_rule （或 endpoint_kind ）、 bucket 、 key 、 path 、 query 、 headers 、body 。
非幂等操作须附加 --force 方可执行。

doctor
通过 doctor 命令诊断工具配置、凭证、网络连通性等运行环境问题。
支持的检查项： auth 、 config 、 registry 、 permissions 、 region 、 network 、 version 、 mcp 、principles 、 completion 。
可通过 --live-network 和 --network-timeout-ms 控制实网探测行为。

skill
通过 skill 命令列举或导出工具的 Skill 定义文件，供 AI-Agent 集成使用。
导出结果写入 dir/SKILL.md 及 dir/{domain}/{skill_name}/SKILL.md 文件。
目标路径已存在时，拒绝覆盖。
