6.4.5.10 ListTagsForResource
功能描述
列举应用于 TRN 资源的标签。
注意事项
Resource TRN 最大长度不能超过 1011 个字符。
目前仅支持列举向量桶资源的标签
请求消息样式
请求参数和消息头
无。
请求元素
无。
响应消息头
返回公共的响应头，请参见公共参数。
响应元素
如果操作成功，服务将返回一个 HTTP 200 响应以及如下响应元素。
如果操作失败，返回响应码中定义的错误码。
请求示例
GET /tags/resourceTrn HTTP/1.1
Host: tosvectors-cn-beijing.volces.com
Content-type: application/json
Authorization: authorization string
Date: Wed, 10 Dec 2025 12:49:14 GMT
Plain
名称 参数类型 示例值 说明
tags map[string]string
{
"key1": "value2"
}
