5.3.15 日志管理
5.3.15.1 日志分析
TOS 支持日志分析功能，支持通过日志服务，检索分析您访问 TOS 过程中产生的访问日志。本文介绍日志分析功能相关的前提条件及操作步骤。
背景信息
关于日志服务的功能说明，请参见什么是日志服务 。
前提条件
使用日志分析功能前，请确保您已完成以下操作：
已开通日志服务功能。
已授权 TOS 访问火山引擎日志服务 TLS。如果您之前已授权 TOS 访问 TLS，则无需重复授权。注意事项
开启日志分析功能后，日志服务会自动创建日志项目及主题存放 TOS 的相关日志。
您可以在日志服务中修改 TOS 日志管理功能创建的日志项目、主题及索引的相关配置。但请注意，修改后可能会导致日志管理功能异常，因此不建议您进行修改。

关闭日志分析
操作步骤
登录对象存储控制台 。
在左侧导航栏，单击桶列表。
在顶部导航栏，选择存储桶所属项目。
在桶列表页面，单击目标桶名称。
在左侧导航栏单击日志管理，在日志分析页面，单击关闭关联日志。
在弹出的对话框中，单击确定。
相关操作
关闭日志分析后，日志主题不会自动删除。您可以在关闭关联日志前，先在日志服务删除日志主题，以避免关闭关联日志后继续产生日志费用。
在日志管理页面进行关闭关联日志的操作时，会弹出对话框提示该存储桶对应的日志项目 ID 和主题 ID，您可以根据 ID 删除该存储桶对应的日志主题。具体操作，请参见删除日志主题 和删除日志项目 。注意
由于同一地域下所有桶共用一个主题，删除某个桶的主题后，会同时删除同一地域下其他桶的历史日志记录，详细介绍，请参见为什么删除某个桶的日志 topic 后，无法正常使用其他桶的日志功能。
设置日志保存时间
关于日志的计费详情，请参见计费说明。如果您需要延长日志的保存时间，您可以参考以下步骤设置。登录对象存储控制台 。
在左侧导航栏，单击桶列表。
在顶部导航栏，选择存储桶所属项目。
在桶列表页面，单击目标桶名称。
在左侧导航栏单击日志管理，在日志分析页面，单击设置日志保存时间。
在弹出的对话框中，设置具体时间，单击确定。
说明
自定义数据保存时间支持 1~3650 天。
使用案例
您可以通过日志统计一天内最新版本对象存储容量、历史版本对象存储容量和总存储容量的变化。为 DeltaDataSize 和 HistoricalVersionDeltaSize 配置键值索引，并设置字段类型为 long，具体操作，请参见配置索引 。
说明
索引配置将仅应用于新写入的日志，已有数据不会生效，因此您只能查询索引配置后的数据。登录对象存储控制台 。
在左侧导航栏单击桶列表，单击目标桶名称。
在左侧导航栏单击日志管理，在检索分析页签下设置时间范围为近1天。
查询存储桶内一天内的存储容量变化。 
总存储量变化
在检索分析页签下输入 Bucket: <存储桶的名称> AND NOT Operation: "BatchDeleteDetails" | SELECTSUM(DeltaDataSize) ，单击搜索，即可查看一天内存储桶内总存储容量的变化。
历史版本对象存储容量变化
在检索分析页签下输入 Bucket: <存储桶的名称> | SELECT SUM(HistoricalVersionDeltaSize) ，单击搜索，即可查看该存储桶在所选时间段内历史版本对象存储容量的变化量。
最新版本对象存储容量变化
您可以通过总存储量变化和历史版本对象存储容量变化计算得出最新版本对象存储容量变化，计算公式如下：
最新版本对象存储容量变化 = 总存储量变化 - 历史版本对象存储容量变化
