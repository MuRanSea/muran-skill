10.9.8 0007-00000101
问题描述
生命周期规则中的 Expiration 字段同时存在 Days 和 Date 参数。
问题原因
生命周期规则中的 Expiration 字段同时存在 Days 和 Date 参数，要求有且仅有其中一个。问题示例
解决方案
设置 Expiration 字段取值为 Days 或 Date 。
{
"Rules": [{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"Expiration": {
"Days": 120,
"Date": "2024-02-27T00:00:00.000Z"
}
}]
}
JSON
