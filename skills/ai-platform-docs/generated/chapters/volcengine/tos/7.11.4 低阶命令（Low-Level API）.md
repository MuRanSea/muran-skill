7.11.4 低阶命令（Low-Level API）
低阶命令与 TOS 服务端 API 逐一映射，覆盖桶、对象、分片上传、加速通道等原子操作，适用于精细化控制与高级特性调用。本章节介绍如何使用低阶命令组。
命令概览
核心命令
桶配置命令（Bucket Configuration）
桶配置命令组用于管理 TOS 桶的各类配置项，每个命令组通常支持 get 、 put 、 delete 等子动作，可通过 --describe 参数查看具体可用动作。
支持的配置命令组如下：
quota 、 policy 、 lifecycle 、 storageclass （旧别名 storgeclass ）、 cors 、 versioning 、replication 、 encryption 、 custom-domain 、 notification 、 website 、 mirror 、 inventory 、tagging 、 acl 、 rename 、 real-time-log 、 access-monitor 、 worm 、 trash 、 payment 、logging 、 intelligent-tiering 、 transfer-acceleration 、 cdn-notification 、 https-config 、 pay-bytraffic 、 max-age 、 redundancy-transition 。命令类别 作用 示例链接

高级特性命令（Advanced）
高级特性命令组用于管理 TOS 的扩展功能，支持以下命令组：
data-process （图片样式、工作流、内容审核）、 object-set 、 accelerator 、 mrap （多区域接入点）、 ap （接入点）、 cap （融合接入点）、 dataset （智能检索与数据集）、 control （控制面操作）。
说明
推荐用法：
先执行 ve-tos-cli <group> --describe --output json 读取命令契约。
再通过 <group> <action> --dry-run 预览待执行操作，确认无误后执行正式命令。
ve-tos-cli lifecycle --describe --output json
ve-tos-cli versioning --describe --output json
ve-tos-cli cors --describe --output json
