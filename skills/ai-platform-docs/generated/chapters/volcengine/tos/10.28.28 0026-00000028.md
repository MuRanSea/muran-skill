问题描述
暂不支持创建非标准类型的分层桶。
问题原因
发起 CreateBucket 请求时，携带头域 x-tos-storage-class ，取值非 STANDARD 。
问题示例
解决方案
请检查 x-tos-storage-class 的取值是否符合预期。
PUT / HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
x-tos-storage-class: ARCHIVE_FR
x-tos-acl: ACL
Content-Length: 0
Date: Fri, 30 Jul 2021 06:45:39 GMT
Authorization: authorization string
