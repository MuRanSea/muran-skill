问题描述
配置的生命周期规则中， Transitions 字段同时存在 Days 和 Date 参数。
问题原因
配置的生命周期规则中， Transitions 字段同时存在 Days 和 Date 参数。
问题示例
解决方案
配置生命周期规则时， Days 和 Date 只能二选一，即只配置 Days ，或只配置 Date 。
{
"Rules": [{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"Transitions": [
{
"StorageClass": "IA",
"Days": 30,
"Date": "2024-02-27T00:00:00.000Z"
}
]
}]
}
JSON
