6.4.3 公共参数
本文列举了 TOS Vectors 公共请求消息头和公共响应消息头的名称和对应的详细说明。
公共请求消息头
公共响应消息头
消息头名称 说明
Authorization 验证请求消息的合法性。关于 Authorization 的
计算方法，请参见签名机制 。
Content-Length RFC 2616 中定义的请求内容不包含消息头长
度。
Content-Type 请求内容的类型。固定为 application/json。
Date 请求发起时的日期，GMT 时间，例如 Fri, 30 Jul
2021 08:05:36 GMT 。
Host 域名。
消息头名称 说明
Content-Length 响应的消息体的长度。
Date 响应请求的日期，GMT 时间。
Server 响应请求的服务端。
x-tos-id-2
服务端为本次请求生成的辅助请求 ID，用于链
路追踪和问题定位。如果请求出现异常，请将该
字段与 x-tos-request-id 一并提供给技术支持人
员，方便快速定位问题。
x-tos-request-id
此次请求的响应 ID，唯一标识这个请求。如果
使用 TOS Vectors 服务遇到问题，请将此字段提
供给 TOS 技术支持人员，以便快速定位问题。
x-tos-server-time 请求在服务端的处理时间。
