6.2 地域和访问域名（Endpoint）
本文介绍 TOS Vectors 支持的地域及访问域名。
注意事项
TOS Vectors 当前域名解析的网段地址可能存在变动，请勿使用以下方式：
在机器中配置了仅能访问固定 IP 或 IP 段的 ACL 或安全组。
直接使用 IP 或在机器中直接配置了 TOS Vectors 的域名映射。
CEN 企业专线中配置了访问固定 IP 或 IP 段的路由。
如果您确实有以上使用方式的需求，请提交工单 联系技术支持人员。
地域及访问域名
地域（Region）：表示 TOS Vectors 的数据中心所在物理位置。
访问域名（Endpoint）：表示 TOS Vectors 对外服务的访问域名。当前为不同接口提供了两类访问域名。 
Region Endpoint：用于 Account 下的 CreateVectorBucket/ListVectorBuckets 操作，为固定的域名，参见下表。
Bucket Endpoint：用于已创建的 Vector Bucket 下的 API 操作，需要拼接 Vector Bucket/Account ID 至域名中，参见下表。
说明
当前 TOS Vectors 只开放华北2（北京）地域，未来将会开放更多地域。
