7.3.6.2 定时上传文件
TOS Browser 支持定时上传功能，该功能可以按照预设的时间将本地文件或文件夹上传到对象存储，便于您备份数据。本文介绍如何创建定时上传策略、查看定时上传任务。
规则说明
TOS Browser 会按照指定的周期重复执行定时上传策略，一天仅会执行一次，直到策略失效为止。在策略有效期内，仅会上传符合条件的文件，如果不符合，则不会上传文件。TOS Browser 会上传的本地文件类型说明如下：
本地存在，但目标桶不存在的文件。
本地与目标桶同名，但大小不一致的文件。
本地与目标桶同名，但桶内对象修改时间早于本地的文件。
创建定时上传策略
登录 TOS Browser。
在桶列表页面，单击右上角的闹钟图标。
在定时任务管理面板上传策略页签下，单击创建策略。
在创建策略对话框配置如下参数。
单击下一步，配置目标桶、目标文件等参数。
参数 说明
策略名称 定时上传策略的名称。
是否启用 选择是否启用定时上传策略。
生效时间 设置定时上传策略的生效时间。
开始时间 设置定时策略开始执行的时间。
结束时间 设置定时策略结束执行的时间。
重复周期 选择定时策略重复执行的周期，可选星期一~
星期日中的的一天或多天。
策略预览 展示定时策略执行时间和次数。
立即执行
定时上传策略创建成功后，选择是否需要立即
执行。如果未选择立即执行，将在到达开始时
间后才执行定时上传策略。
参数 说明
目标桶 选择文件上传的目标存储桶。
目标路径
设置文件在存储桶的的存储路径，默认存储在
Backup 目录下。说明如下：
支持中文、英文、数字及常见字符。
支持使用正斜线（/）快速创建子文件夹，
但文件夹命名不能以正斜线（/）或反斜线

完成参数配置后，单击创建。
定时上传策略创建成功后，您可以在定时任务管理面板上传策略页签下查看下一次上传时间、上一次触发时间、上传目标桶等信息。
说明
TOS Browser 会在到达开始时间后执行定时上传策略，您也可以单击目标策略操作列下的手动上传，手动触发定时上传策略。
查看定时上传任务
查看定时上传任务
登录 TOS Browser。
在桶列表页面，单击右上角的闹钟图标。
在定时任务管理面板，单击定时上传任务页签，查看定时策略触发的所有定时上传任务。
说明
定时上传任务的名称以 策略名称-触发方式-触发时间 格式命名。
在定时上传任务页签下，单击目标任务操作列下的导出，可以导出目标任务下的所有文件信息。
查看定时上传任务下文件信息
登录 TOS Browser。
在桶列表页面，单击右上角的闹钟图标。
在定时任务管理面板，单击定时上传任务页签。
单击目标任务的名称，查看该定时上传任务下文件信息，包括上传的文件名称、文件大小、文件存储路径等信息。
说明
在任务详情面板右侧支持查看该任务下处于准备中、上传中、上传成功、暂停和上传失败状态的文件信息。
参数 说明
（\）开头，且不能使用连续的正斜线
（/）。
不能以 .. 作为文件夹名称。
选择文件 选择上传的文件或文件夹。
