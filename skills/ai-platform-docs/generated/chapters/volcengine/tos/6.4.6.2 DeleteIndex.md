6.4.6.2 DeleteIndex
功能描述
删除向量桶的向量索引。
请求消息样式
Endpoint 需使用 Bucket Endpoint。
请求参数和消息头
无。
请求元素
响应消息头
返回公共的响应头，请参见公共参数。
响应元素
如果操作成功，服务将返回一个 HTTP 200 响应且响应元素为空。
如果操作失败，返回响应码中定义的错误码。
请求示例
POST /DeleteIndex HTTP/1.1
Host: {VectorBucketName}-{AccountID}.tosvectors-cn-beijing.volces.com
Authorization: authorization string
Date: Wed, 10 Dec 2025 12:49:14 GMT
{
 "vectorBucketName": "test-vector-bucket",
 "indexName":"test-index"
}
Plain
