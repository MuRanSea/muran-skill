10.8.17 0006-00000411
问题描述
配置跨区域复制规则时，选择传输加速链路，但是桶传输加速还未生效。
问题原因
开启传输加速功能后，预计需要等待 30 分钟才能生效，生效后跨区域复制规则才能配置使用传输加速链路。
问题示例
您发起 PutBucketReplication 配置请求， TransferType 字段取值为 tos_acc ，但是桶传输加速还未生效。解决方案
等待桶传输加速生效后，再配置跨区域复制规则。
PUT /?replication HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization string
Content-Length: 120
Content-MD5: XrY7u+Ae7tCTyyK7j1rNww==
{
 "Role": "ServiceRoleforReplicationAccessTOS",
 "Rules": [{
 "ID": "1",
 "Status": "Enabled",
 "PrefixSet": ["prefix_1", "prefix_2"],
 "Destination": {
 "Bucket": "Target Bucket Name",
 "Location": "cn-beijing",
 "StorageClass": "STANDARD"
 },
 "TransferType":"tos_acc",
 "HistoricalObjectReplication": "Enabled",
 "AccessControlTranslation": {
 "Owner": "BucketOwnerEntrusted"
 }
 }]
}
