5.15.5.3 视频转码
视频转码支持对 TOS 中的视频文件进行格式、编码、分辨率、码率等处理，并生成符合指定模板要求的目标视频文件，适用于视频播放适配、文件压缩和多终端分发等场景。
说明
视频转码功能当前处于邀测阶段，如需使用，请联系客户经理。
计费说明
视频转码功能当前暂不收费。后续如调整为收费模式，将提前发布通知，请及时关注产品公告，避免因计费规则变化产生非预期费用。
前提条件
使用视频转码功能前，请确认已完成以下准备：
操作步骤
登录对象存储控制台 。
在左侧导航栏，单击桶列表。
在顶部导航栏，选择存储桶所属项目。
在桶列表页面，单击目标桶名称。
在左侧导航栏，选择数据处理 > 任务处理。
在任务处理页面，视频转码页签下，单击创建任务。
在弹出的创建视频转码任务弹窗，配置如下参数。
准备事项 说明
完成跨服务授权 已授权 TOS 对象存储服务访问存储桶中的文
件，用于读取源视频并写入转码后的目标文件。
完成 KMS 授权
如源文件或目标文件涉及服务端加密，需授权
TOS 对象存储服务访问 KMS 服务，以便完成加
密文件的读取、处理或写入。
准备源视频文件 待转码的视频文件已上传至当前存储桶，且文件
格式满足 MP4、TS 或 HLS。
确认目标路径 已确定转码后文件的保存路径，避免目标文件覆
盖已有文件或写入到错误目录。
参数 是否必选 描述
源文件路径 是
选择需要进行转码处理的源
视频文件。
目标存储桶 是
选择转码后文件保存的目标
存储桶。
配置完成后，单击确定即可完成创建任务。
管理视频转码任务
在任务处理页面的视频转码页签中，您可以在任务列表查看已创建的视频转码任务，并对任务执行以下操作。
参数 是否必选 描述
目标文件路径 否
转码输出文件存放的目标路
径，如未填写则默认保存至
存储桶根路径。
目标文件名 是
设置转码后生成文件的名
称。
转码模板类型 是
选择转码任务使用的模板类
型，支持系统预设模板和自
定义模板。
转码模板 是
选择具体的转码模板，模板
定义了输出的视频编码格
式、分辨率、码率等参数。
系统预设转码模板详情请参
见视频转码算子。
自定义模板需提前创建才可
选择，操作步骤请参见创建
自定义模板。
操作 说明
查看任务详情 单击目标任务 ID，即可进入详情页查看视频转
码任务基本信息、输入信息和输出信息。
搜索目标任务 任务列表支持通过所选时间和任务 ID ** ** 进行
筛选，帮助用户快速定位历史转码任务。
