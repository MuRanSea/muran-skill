5.6.6.14.1 对主账号下的 IAM 用户授权
本文介绍对 IAM 用户授权的典型授权场景及操作说明，您可以根据实际情况选择合适的场景完成授权。授予 IAM 用户所有资源支持的所有动作权限
可以使用 IAM 系统策略授予 IAM 用户当前账号下所有 TOS 资源的所有使用权限。具体操作请参见创建用户并授权 ，授权时选择 TOSFullAccess 系统策略。
授予 IAM 用户创建桶及列举所有桶的权限
可以使用 IAM 自定义策略授予 IAM 用户创建存储桶及列举所有桶的权限，授予 IAM 用户自定义策略的操作步骤，请参见策略管理 。
策略内容示例如下：
授予 IAM 用户指定资源的相关权限
{
 "Statement": [
 {
 "Effect": "Allow",
 "Action": [
 "tos:CreateBucket",
 "tos:ListBuckets"
 ],
 "Resource": [
 "trn:tos:::*"
 ]
 }
 ]
}

<TabTitle>桶策略</TabTitle>
1. 登录[对象存储控制台](https://console.volcengine.com/tos)。
2. 在左侧导航栏，单击**桶列表。** 
3. 在顶部导航栏，选择存储桶所属项目。
4. 在**桶列表**页面，单击目标桶名称。
5. 选择左侧导航栏中的**权限管理** \> **存储桶授权策略管理**。
6. 在**存储桶授权策略管理**页面的**可视化视图**页签下，单击**创建策略**。
7. 在**创建存储桶授权策略**页面，选择**文件夹读写**模板，单击**下一步**。
8. 配置如下参数。
 |**类型** |**说明** |
 |---|---|
 |被授权用户 |选择**指定账号**，选择需要授权的主账号，说明如下<br><br><br>* **当前主账号
**：用于为当前主账号下的 IAM 用户（子用户）授权。无需输入主账号 ID，单击子用户名称右边的**添加字段**，您可以在**子用户名称**的下拉框中选择 IAM 用户名称。<br><br>* **其他主账户**：用于为其他主账号的 IAM 用户（子用户）授权。需要输入其他主账号ID，单击子用户名称右边的**添加字段**，输入其他主账号的子用户名称。 |
 |资源 |选择**指定对象**，单击**添加字段**图标，设置指定资源字段。 |
 |动作 |选择需要授权的通用动作，详情请参见[通用动作](https://docs.volcengine.com/docs/6349/102127?lang=zh#b46f3fac)。 |
 |条件（可选） |单击**添加字段**图标，设置您所需要的条件及值。关于条件的参数说明，请参见[条件说明](https://docs.volcengine.com/docs/6349/102127?lang=zh#eaa7b0fa)。 |
7. 设置完成后，单击**下一步**，确认当前配置的策略信息。
8. 确认信息无误后，单击**确定**，完成策略的创建。
 授权策略创建完成后，您可以在策略管理列表查看已创建的策略。
