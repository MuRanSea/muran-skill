9.2.6.2.11 管理实时日志（Java SDK）
TOS 支持日志分析功能，支持通过日志服务，检索分析您访问 TOS 过程中产生的访问日志。通过 TOSJava SDK 您可以设置日志分析功能的相关配置。
设置实时日志配置规则
您可以通过 TOS Java SDK 的 putBucketRealTimeLog 接口设置桶的实时日志配置。
注意
使用日志分析功能需要您已开通日志服务功能，并已授权 TOS 访问火山引擎日志服务 TLS。开启日志分析功能后，日志服务会自动创建日志项目及主题存放 TOS 的相关日志。

以下代码展示如何设置桶的实时日志配置规则。
