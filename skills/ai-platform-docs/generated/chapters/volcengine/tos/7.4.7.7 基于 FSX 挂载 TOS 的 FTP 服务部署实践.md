7.4.7.7 基于 FSX 挂载 TOS 的 FTP 服务部署实践
通过 FSX 将对象存储（TOS）的存储桶挂载为本地文件系统目录，可使传统应用（如 FTP 服务）在无需修改代码的情况下，直接访问和操作存储在 TOS 中的对象，充分利用其海量存储、高可靠性和高性价比。本文介绍如何基于 FSX 挂载部署 FTP Server，对外提供 FTP/FTPS 服务，使客户端（以 FileZilla 为例）可以便捷地向 TOS 读写文件。
前提条件
已绑定公网 IP 、正常运行且具备管理员权限的 Linux 云服务器。
对象存储中已创建用于存放通过 FTP 上传文件的存储桶。
网络环境（防火墙、安全组）已放行外部客户端访问 FTP/FTPS 所需端口。
软件版本
Linux 操作系统：本文以 CentOS 7.6 为例。
FTP 客户端：本文以 FileZilla 为例。
FTP 服务端：本文以 Vsftpd 3.0.2 为例。

参数 说明
region 存储桶所在地域。
endpoint TOS 访问域名，支持 https://{host}:{port} 格式。
credential_filepath 包含 AK/SK/STS 的 JSON 凭证文件的绝对路径。
no_writeback_cache 是否禁用写回缓存。禁用后，数据将直接写入对
象存储，适用于对数据一致性要求高的场景。
file_mode 挂载后文件的默认权限为 777（所有用户可读/
写/执行）。
dir_mode 挂载后目录的默认权限为 777。

5.连接云服务器远程站点
注意
传输文件类型必须设置为二进制（Binary） 文件类型进行上传，否则不支持断点续传。
参数 说明
tos_allow_delete 允许通过挂载目录直接删除 TOS 上的对象/文
件。
tos_incremental_upload 启用增量上传（通常表示分片/按需上传，减少
整体重传开销）。
num_prefetch_threads 预取线程数，用于优化读性能。
allow_other
允许其他系统用户（如 vsftpd 运行用户）访问
挂载点。
注意
使用此参数需要修改 /etc/fuse.conf 文
件，取消对 user_allow_other 的注释。
# /mnt/point FSX 示例挂载点（TOS 挂载到本地的目录）
# /home/ftp FTP 服务示例根目录（对外提供访问的目录）
sudo mount --bind /mnt/point /home/ftp

在本地计算机下载 FileZilla 并安装。
双击 FileZilla，打开客户端。 
在 FileZilla 导航栏，填写如下信息，单击快速连接(Q) 。
主机：云服务器公网 IP。登录云服务器控制台 ，在实例列表中可查看对应云服务器的公网 IP。用户名：搭建 FTP 服务时设置的 FTP 用户帐号。本文以 ftptest 为例。

上传文件：在 FileZilla 左侧的本地站点下方窗格中，右键单击待上传的本地文件，选择上传，即可将文件上传到云服务器。
下载文件：在 FileZilla 右侧的远程站点下方窗格中，右键单击待下载的远程站点文件，选择下载，即可将云服务器上的文件下载到本地计算机。
