5.19 TOS-豆包 AIGC
TOS 已与火山方舟的豆包大模型完成联动，实现跨平台的能力融合。通过 TOS 提供的 AIGC 接口，您在使用智能生图能力的同时，还能借助 TOS 的图片处理、图片压缩、格式转换等一系列强大功能，满足您多样化的业务需求。本文介绍使用 AIGC 接口完成图片处理的能力说明、计费说明、操作步骤等内容。能力说明
豆包的文生图模型可以根据文本描述生成高度细致和精确的图像；图生图模型可以生成多种创意风格的图像，可用于头像定制、相册写真等多种场景，详细介绍，请参见图文生图能力介绍 。由于豆包大模型当前对图片格式、文件大小等方面限制，在实际使用过程中，您需要对图片进行预处理，以满足豆包大模型对图片的处理要求，您也可能需要对豆包大模型的处理结果进行后处理，以满足业务需求。对象存储提供了高效的数据存储和灵活的图片处理能力，例如图片缩放、图片格式转换、图片亮度调整等能力，能够为豆包大模型提供有力支持。您可以通过 TOS 的 AIGC 接口组合使用使用对象存储的图片处理功能，和豆包的文生图、图生图模型，满足多样化的业务需求。
适应场景
TOS 联合豆包大模型打造的 AIGC 能力可广泛应用但不限于下述场景：
社交媒体内容：生成吸引人的图像内容，用于品牌的社交媒体平台，提升用户互动和关注度。广告创意：快速生成创意广告图像，帮助市场营销团队探索和实验不同的广告设计。
教学辅助：为复杂的教学内容（如历史事件、科学概念）创造直观的图像，帮助学生更好地理解和记忆。
艺术创作：艺术家可以通过文生图技术探索新的艺术风格和表达形式，创作出独一无二的艺术作品。电影和游戏设计：在电影或视频游戏的前期概念设计阶段，文生图技术可以快速生成场景草图或角色设计，帮助创意团队形成更具体的视觉概念。
计费说明
使用 AIGC 接口会产生智能绘图 API 调用次数费用 和图片处理费用 。TOS 并不会收取智能绘图 API 调用次数费用，该部分能力由豆包收取，同时豆包为每个账号提供了一定的智能绘图免费额度。使用 AIGC接口在 TOS 有可能会产生图片处理费用，每个月提供了 10TiB 免费额度，超过 10TiB，按处理的原图大小计费，由对象存储 TOS 单独收取。
使用方式
TOS 支持 3 种图片处理功能和豆包大模型的组合使用方式：图片预处理、图片后处理、图片预处理&后处理，说明如下：
图片预处理：先通过对象存储的图片处理功能对原始图片完成格式转换、图片缩放等预处理操作，再调用豆包大模型生成所需的新图片。
图片后处理：先通过豆包大模型生成图片，再使用对象存储的图片处理功能对图片进行格式、亮度、对比度等方面的优化。
图片预处理&后处理：先通过对象存储的图片处理功能对原始图片完成格式转换、图片缩放等预处理操作，再调用豆包大模型生成所需的新图片，最后通过对象存储的图片处理功能对图片进行格式、亮度、对比度等方面的优化。
操作步骤
开通并授权豆包智能绘图模型。 
登录对象存储控制台 。
在左侧导航栏，单击 AIGC。
在 AIGC 页面模型开通处，单击点击开通，开通智能绘图模型。
在模型授权处，单击授权，授于 TOS 调用智能绘图模型的权限。
在对象存储授权处，单击授权，授于 TOS 访问您的 TOS 存储桶内文件的权限。
调用 AIGC 接口组合使用对象存储的图片处理功能和豆包大模型。
