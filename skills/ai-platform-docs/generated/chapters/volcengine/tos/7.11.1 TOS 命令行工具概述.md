7.11 TOS 命令行工具
7.11.1 TOS 命令行工具概述
本章节介绍火山引擎对象存储服务的官方命令行工具 ve-tos-cli 。
功能介绍
火山引擎对象存储服务 TOS 提供官方命令行工具 ve-tos-cli ，该工具覆盖文件传输、桶配置管理、高级特性调用以及控制面操作等完整工作流。同时提供低阶（Low-Level）API 与桶配置、高级特性、控制面命令，满足不同粒度的使用需求。 ve-tos-cli 支持如下功能特性：
版本信息
当前版本为 v1.0.0。
相关文档
功能 说明
指定存储类型 通过 --storage-class 指定存储类型。
调用控制面能力 通过 --control-endpoint 、 --account-id 可调用
控制面能力。
自动适配命名空间 通过 auto 列举语义，可自动适配 FNS 扁平命
名空间与 HNS 层级命名空间。
命令分层
提供三层命令使用场景：
High-Level 高阶命令：面向日常操作与自动
化。
Low-Level 低阶命令：与 TOS 服务端 API 一一
对应，适合精细控制。
Utilities 工具命令：提供配置、诊断等辅助能
力。
