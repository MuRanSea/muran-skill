5.6.6.2.3 授予 IAM 用户删除指定桶的权限
本文档介绍如何授予当前账号下的 IAM 用户删除指定桶的权限。
场景说明
授权账号：当前账号（本文以 210015**** 为例）下的 iamuser 用户。
授权资源： bucketname 存储桶
动作：DeleteBucket
注意事项
权限配置后略有延迟，如果您配置的权限没有立即生效，建议您稍后重试。
按照本文完成授权后，仅可以删除已清空桶内对象的存储桶。
操作步骤
登录对象存储控制台 。
在左侧导航栏，单击桶列表，在桶列表页面单击目标桶名称。
在左侧导航栏，选择权限管理 > 存储桶授权策略管理。
根据需要选择授权方式。
可视化视图
单击创建策略。
在创建存储桶授权策略页面，选择自定义策略模板，然后单击下一步。
设置如下参数。
类别 参数 说明
基本配置
策略配置方式 无需手动配置，默认选择可
视化视图方式。
策略名称 设置策略名称。同一存储桶
内，策略名称不允许重名。
效力 效力
选择策略的作用效果，无需
手动配置。
允许（默认） ：说明该策
略创建的权限为接受请
求。
拒绝：说明该策略创建的
权限为拒绝请求。
被授权用户
授权用户 无需手动配置，默认选择指
定账号。
其他账号
选择当前主账号，然后单击
子用户名称后的添加字段，
在下拉列表中选择需要授权
◦
◦
设置完成后，单击下一步。
确认策略无误后，单击确定，完成策略的创建。
授权策略创建完成后，您可以在策略管理列表查看已创建的策略。
JSON 视图
单击编辑，将以下内容复制到文本框中，单击确定。
后续操作
根据本文授权后，您可以使用 API 或 SDK 完成删除指定桶的操作。
类别 参数 说明
的子用户名称，本文中以 
iamuser 为例。
资源 资源范围 选择当前桶。
动作
通用动作 无需配置。
桶动作 选择 DeleteBucket。
对象动作 无需配置。
操作策略
无需手动配置，默认选择包
含以上动作，表示允许用户
拥有执行指定动作的权限。
条件（可选） -
可以不配置。也可以单击添
加字段图标，设置您所需要
的条件及值。
关于条件的参数说明，请参
见条件说明 。
