7.2.6.9 测量网络延迟（ping）
您可以通过 ping 命令测试主机与 TOS 的网络连通性并测量网络延迟。
命令语法
Linux/macOS
测试与域名的网络连通性
测试与 IP 地址的网络连通性
Windows
对域名
对 IP 地址
参数说明
./tosutil ping domain [-s=1] [-t=1] [-count=1] [-ipv6]
Bash
./tosutil ping ipaddress [-s=1] [-t=1] [-count=1] [-ipv6]
Bash
tosutil ping domain [-s=1] [-t=1] [-count=1] [-ipv6]
Bash
tosutil ping ipaddress [-s=1] [-t=1] [-count=1] [-ipv6]
Bash
参数名 参数类型 描述
domain String
目标主机域名。TOS 支持的地
域和访问域名，请参见地域和
访问域名（Endpoint）。
ipaddress String 目标主机 IP 地址。
使用示例
测试与域名的网络连通性
以下命令用于测试主机与北京地域的网络连通性，共测试 5 轮。
命令
返回
参数名 参数类型 描述
-s String
执行 ping 命令时的数据包大
小，单位：字节，默认为
56B。取值范围为 [1B，
63KB]。
-t String ping 命令的最大执行时间，单
位：秒。
-count String 执行 ping 时发送或接收轮次的
计数。
-ipv6 String 解析域名时选择 iPv6 地址。
./tosutil ping tos-cn-beijing.ivolces.com -count=5
