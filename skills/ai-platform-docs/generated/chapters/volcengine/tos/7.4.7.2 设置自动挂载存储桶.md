7.4.7.2 设置自动挂载存储桶
云服务器关机重启后，挂载点会被卸载，此时您需要使用 FSX 工具重新挂载存储桶。您可以通过配置自启动脚本，在云服务器启动时自动启动 FSX 客户端，并挂载存储桶。本文介绍设置自动挂载存储桶的前提条件、操作步骤。
前提条件
已安装 FSX 客户端，并挂载存储桶。具体操作，请参见FSX 配置与挂载。
操作步骤
执行以下命令，在 root 目录下创建 script.sh 文件。
打开 script.sh 文件，写入以下内容并保存。
您需要根据实际情况修改 script.sh 文件的 region 、 endpoint 和 credential_filepath 等参数，说明如下：
touch /root/script.sh
JSON
echo "start to mount fsx"
# 必须等待 5s，fusemonitor 懒加载完成
sleep 5
echo sleep done
# 修改为实际需要的挂载参数
mount -t fsx /tos/<挂载的桶名>:/<桶内目录> <挂载点> -o region="<地域>",endpoint="<访问域名>",credential_filepath="<鉴权凭证文件的绝对路径
>",no_writeback_cache,num_prefetch_threads=180
echo "end to mount $?"
JSON
参数 说明
region 存储桶所在地域。
endpoint
TOS 的访问域名，仅支持 TOS 域名，暂不支持
S3 域名。如果没有指定协议，则默认使用
HTTPS 协议，完整格式为 https://{host}:{port} 。

需的认证信息。您需要自行创建鉴权凭证文

JSON
touch /etc/systemd/system/fuse-fsx.service
JSON
[Unit]
Description=Mount FUSE filesystem
# 必须依赖fusemonitor.service
After=multi-user.target fusemonitor.service 
Wants=multi-user.target
[Service]
Type=oneshot
ExecStart=/bin/bash /root/script.sh
RemainAfterExit=yes
[Install]
WantedBy=multi-user.target
