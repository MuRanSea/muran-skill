9.14.7.3.2 GetObjectTagging（Rust SDK）
get_object_tagging 接口用于获取对象的标签信息，支持指定版本。本文介绍如何通过 Rust SDK 的get_object_tagging 接口获取标签。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
当 version_id 指向的 object 版本为 delete_marker 时，get_object_tagging 返回 404 Not Found。若未提供 version_id ，get_object_tagging 默认读取 object 当前版本的标签。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行get_object_tagging 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:GetObjectTagging
