10.9.15 0007-00000201
问题描述
生命周期规则中的 NoncurrentVersionExpiration 字段同时存在 NoncurrentDays 和 NoncurrentDate 参数。问题原因
生命周期规则中的 NoncurrentVersionExpiration 字段同时存在 NoncurrentDays 和 NoncurrentDate 参数，要求有且仅有其中一个。
问题示例
解决方案
设置生命周期规则时， NoncurrentDays 和 NoncurrentDate 二选一，即只设置 NoncurrentDays ，或只设置NoncurrentDate 。
{
"Rules": [{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"NoncurrentVersionExpiration": {
"NoncurrentDays": 120,
"NoncurrentDate": "2024-02-27T00:00:00.000Z"
}
}]
}
JSON
