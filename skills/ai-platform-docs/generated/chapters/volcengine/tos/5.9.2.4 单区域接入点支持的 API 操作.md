5.9.2.4 单区域接入点支持的 API 操作
通过单区域接入点域名访问 TOS 时，只支持对 TOS 执行部分操作。本文介绍单区域接入点支持的 API 操作列表。
桶操作
对象操作
分类 操作 说明
基础操作
ListObjects 列举桶中的对象。
ListObjectVersions 列举桶中的多版本对象。
HeadBucket 判断桶是否存在和是否有桶的
访问权限。
桶 ACL GetBucketACL 获取指定桶的访问控制权限。
桶策略 GetBucketPolicy 获取指定桶的桶策略。
跨域资源共享 GetBucketCORS 获取指定存储桶当前的跨域资
源共享 CORS的配置规则。
分类 操作 说明
基础操作 GetObject 下载指定对象。
PutObject 向桶中添加对象。
HeadObject 获取对象的元数据。
DeleteObject 删除指定对象。
分类 操作 说明
RestoreObject 恢复对象。
AppendObject 追加写对象。
CopyObject 拷贝对象。
SetObjectMeta 更新对象元数据。
SetObjectExpires 为对象添加过期时间，或修改
对象的过期时间。
RenameObject 重命名对象。
对象 ACL
PutObjectACL 设置对象的访问控制权限
（ACL）。
GetObjectACL 获取指定对象的访问控制权限
（ACL）。
对象标签
PutObjectTagging 设置和更新对象的标签信息。
GetObjectTagging 获取对象的标签信息。
DeleteObjectTagging 删除对象的标签信息。
抓取对象 FetchObject 从指定 URL 抓取资源，并存储
到存储桶。
软链接 PutSymlink 创建软链接。
分类 操作 说明
GetSymlink 获取软链接对象信息。
对象 WORM
PutObjectRetention 创建或修改对象的保留策略。
GetObjectRetention 获取对象的保留策略信息。
分片上传
CreateMultipartUpload 初始化分片上传任务。
UploadPart 上传分片数据。
CompleteMultipartUpload 合并已经上传的分片数据。
AbortMultipartUpload 取消分片上传任务。
UploadPartCopy 已上传对象的一部分或者全部
拷贝为分片。
ListMultipartUploads 列举正在进行的分片上传任
务。
