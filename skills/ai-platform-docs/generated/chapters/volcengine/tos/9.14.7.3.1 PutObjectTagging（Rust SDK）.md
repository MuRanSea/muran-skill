9.14.7.3 对象标签
9.14.7.3.1 PutObjectTagging（Rust SDK）
put_object_tagging 接口用于为对象设置或覆盖标签，支持版本控制。本文介绍如何通过 Rust SDK 的put_object_tagging 接口完成该操作。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
调用 put_object_tagging 时，若对象已存在标签，新标签会完全覆盖旧标签；若对象无标签，则直接写入新标签。
单个对象最多支持 10 个标签，且 tags 列表中 key 必须唯一，不可重复。
key 与 value 区分大小写，长度分别不得超过 128 与 256 个字符。
当存储桶启用版本控制且目标版本为删除标记时，put_object_tagging 返回 404 not found；可通过 version_id 参数指定非当前版本进行设置。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行put_object_tagging 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:PutObjectTagging

设置对象标签
use async_trait::async_trait;
use futures_core::future::BoxFuture;
use std::env;
use std::future::Future;
use std::time::Duration;
use tokio::runtime::Handle;
use ve_tos_rust_sdk::common::init_tracing_log;
use ve_tos_rust_sdk::asynchronous::bucket::BucketAPI;
use ve_tos_rust_sdk::asynchronous::object::ObjectAPI;
use ve_tos_rust_sdk::asynchronous::tos;
use ve_tos_rust_sdk::asynchronous::tos::AsyncRuntime;
use ve_tos_rust_sdk::object::PutObjectTaggingInput;
use ve_tos_rust_sdk::common::TagSet;
use ve_tos_rust_sdk::common::Tag;
use ve_tos_rust_sdk::error::TosError;
#[derive(Debug, Default)]
pub struct TokioRuntime {}
#[async_trait]
impl AsyncRuntime for TokioRuntime {
type JoinError = tokio::task::JoinError;
async fn sleep(&self, duration: Duration) {
 tokio::time::sleep(duration).await;
 }
fn spawn<'a, F>(&self, future: F) -> BoxFuture<'a, Result<F::Output, Self::JoinError>>where
 F: Future + Send + 'static,
 F::Output: Send + 'static,
 {
Box::pin(Handle::current().spawn(future))
 }
fn block_on<F: Future>(&self, future: F) -> F::Output {
 Handle::current().block_on(future)
 }
}
#[tokio::main]
async fn main() {
let _guard = init_tracing_log("info", "temp/logs", "app.log");
let ak = env::var("TOS_ACCESS_KEY").unwrap_or("".to_string());
let sk = env::var("TOS_SECRET_KEY").unwrap_or("".to_string());
let endpoint = "https://tos-cn-beijing.volces.com";
let region = "cn-beijing";
let client = tos::builder::<TokioRuntime>()
 .connection_timeout(3000)
 .request_timeout(10000)
 .max_retry_count(3)
 .ak(ak)
 .sk(sk)
 .region(region)
 .endpoint(endpoint)
 .build().unwrap();
let bucket_name = "example-bucket-2";
let object_key = "example-object.txt";
let mut input = PutObjectTaggingInput::new(bucket_name, object_key);
 input.set_tag_set(TagSet::new(vec![
 Tag::new("project", "rust-sdk-demo"),
 Tag::new("env", "test")
 ]));
相关文档
关于 PutObjectTagging 的 API 文档，请参见 PutObjectTagging。
let output = client.put_object_tagging(&input).await;
match output {
Ok(res) => {
println!("Successfully set tags for object. Request ID: {}", res.request_id());
 },
Err(err) => {
match err {
 TosError::TosClientError { message, .. } => {
println!("Client error: {}", message);
 }
 TosError::TosServerError { request_id, ec, code, .. } => {
println!("Server error: Request ID: {}, EC: {}, Code: {}", request_id, ec, code);
 }
 }
 }
 }
}
