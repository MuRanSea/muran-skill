问题描述
URL 参数 offset 取值非法。
问题原因
用户修改写对象时，URL 参数 offset 取值非正整数。
问题示例
您发起 ModifyObject 请求，URL 参数 offset 取值为非法值 -1。
解决方案
发起 ModifyObject 请求时，确保 URL 参数 offset 取值合法。
POST /objectName?modify&offset=-1 HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: GMT Date
Authorization: authorization xxx
<modify data>
