7.2.5.7 设置对象元数据（setmeta）
您可以通过 setmeta 命令设置对象元数据。
命令格式
Linux/macOS
设置单个对象元数据
批量设置对象元数据
Windows
设置单个对象元数据
批量设置对象元数据
参数说明
通用可选参数的说明，请参见通用可选参数。
./tosutil setmeta tos://bucket/key [-versionId=xxx] [-meta=aaa:bbb#ccc:ddd] [-contentType=xxx] 
[-contentDisposition=xxx] [-contentEncoding=xxx] [-contentLanguage=xxx] [-
cacheControl=xxx] [-expires=xxx] [-fr] [-o=xxx] [-bt=xxx] [-e=xxx] [-re=xxx] [-i=xxx] [-k=xxx] [-t=xxx] [-conf=xxx]

参数名 参数类型 描述
bucket String 桶名。
key String 对象名。
prefix String 批量操作时的对象名前缀。
-r Bool 执行批量设置对象元数据操
作。
-j Integer
批量设置对象元数据的最大并
发数，默认为配置文件中的 
defaultJobs 。
-versionId String 待设置对象元数据的单个对象
的版本号。
-meta String 设置对象的自定义元数据。
-contentType String 设置对象的 Content-Type。
-contentDisposition String 设置对象的 ContentDisposition。
-contentEncoding String 设置对象的 ContentEncoding。
-contentLanguage String 设置对象的 ContentLanguage。
-cacheControl String 设置对象的 Cache-Control。
使用示例
设置单个对象元数据
以下命令用于将 bucketname 桶内的 object1.png 对象的自定义元数据设置为 aaa:bbb#ccc: ddd。命令
参数名 参数类型 描述
-expires String 设置对象的 Expires，格式为：
YYYYMMDDHHmmSS。
-fr Bool 设置单个对象元数据时生成结
果清单文件。
-o String
生成结果清单文件的文件夹，
默认为配置文件中的 
defaultOutputDir 。
-bt String
存储桶的类型。取值说明如
下：
fns ：扁平桶。
hns ：分层桶。
如果未指定存储桶的类型，则
默认从桶元数据获取存储桶的
类型。
./tosutil setmeta tos://bucketname/object1.png -meta aaa:bbb#ccc:ddd
