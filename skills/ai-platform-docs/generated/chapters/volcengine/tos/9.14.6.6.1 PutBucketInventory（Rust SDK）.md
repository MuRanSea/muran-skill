9.14.6.6 桶清单
9.14.6.6.1 PutBucketInventory（Rust SDK）
put_bucket_inventory 接口用于为存储桶创建清单，TOS 将按天或周输出对象数量、大小、存储类型等信息。本文介绍如何通过 Rust SDK 的 put_bucket_inventory 接口创建清单。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
每个存储桶最多配置 10 条清单规则，超出后新请求将被拒绝。
源存储桶与目标存储桶必须位于同一地域，否则接口返回 400 错误。
清单文件仅支持 CSV 格式，且默认使用 GZIP 压缩。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行put_bucket_inventory 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:PutBucketInventory

use async_trait::async_trait; 
use futures_core::future::BoxFuture;
use std::env;

use tokio::runtime::Handle;
use ve_tos_rust_sdk::common::init_tracing_log;

use ve_tos_rust_sdk::enumeration::{InventoryIncludedObjType, InventoryFormatType, InventoryFrequencyType};
use ve_tos_rust_sdk::error::TosError;
#[derive(Debug, Default)]
pub struct TokioRuntime {}
#[async_trait]
impl AsyncRuntime for TokioRuntime {
type JoinError = tokio::task::JoinError;
async fn sleep(&self, duration: Duration) {
 tokio::time::sleep(duration).await;
 }
fn spawn<'a, F>(&self, future: F) -> BoxFuture<'a, Result<F::Output, Self::JoinError>>where
 F: Future + Send + 'static,
 F::Output: Send + 'static,
 {
Box::pin(Handle::current().spawn(future))
 }
fn block_on<F: Future>(&self, future: F) -> F::Output {
 Handle::current().block_on(future)
 }
}
#[tokio::main]
async fn main() {
let _guard = init_tracing_log("info", "temp/logs", "app.log");
let ak = env::var("TOS_ACCESS_KEY").unwrap_or("".to_string());
let sk = env::var("TOS_SECRET_KEY").unwrap_or("".to_string());
let endpoint = "https://tos-cn-beijing.volces.com";
let region = "cn-beijing";
let client = tos::builder::<TokioRuntime>()
 .connection_timeout(3000)

 .ak(ak)
 .sk(sk)
 .region(region)
 .endpoint(endpoint)
 .build().unwrap();
let mut input = PutBucketInventoryInput::new("example-bucket", "basic-inventory");
 input.set_is_enabled(true);
 input.set_schedule(InventorySchedule::new(InventoryFrequencyType::InventoryFrequencyDaily));let mut tos_dest = TOSBucketDestination::new(InventoryFormatType::InventoryFormatCsv);
 tos_dest.set_account_id("200000****");
 tos_dest.set_role("provide your role");
 tos_dest.set_bucket("destination-bucket");
let dest = InventoryDestination::new_with_tos_bucket_destination(tos_dest);
 input.set_destination(dest);
