问题描述
桶数据复制规则非法。
问题原因
用户设置桶数据复制规则时，规则 ID 字段取值重复。
问题示例
您进行桶数据复制规则配置时，多条规则具有相同的 ID。
解决方案
参见 PutBucketReplication ，正确构造桶数据复制规则，确保规则 ID 字段取值唯一。
PUT /?replication HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization string
Content-Length: 120
Content-MD5: XrY7u+Ae7tCTyyK7j1rNww==
{
"Role": "Your role",
"Rules":[
 {
"ID": "1",
 ...此处省略其余配置...
 },
 {
"ID": "1",
 ...此处省略其余配置...
