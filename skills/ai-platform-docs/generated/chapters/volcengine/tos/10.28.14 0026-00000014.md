问题描述
在分层桶中，当列举对象携带参数 delimiter 时， delimiter 的取值必须为 / 。
问题原因
发起 ListObjectsV2/ListObjects 请求时， delimiter 的取值非 / 。
问题示例
解决方案
指定 delimiter 为 / 。
GET /?delimiter=# HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: GMT Date
Authorization: authorization string
