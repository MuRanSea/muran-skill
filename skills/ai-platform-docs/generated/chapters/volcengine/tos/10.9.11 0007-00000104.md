10.9.11 0007-00000104
问题描述
生命周期规则中 Expiration 字段的 Date 参数取值非 ISO8601 格式。
问题原因
生命周期规则中 Expiration 字段的 Date 参数取值非 ISO8601 格式。
问题示例
解决方案
设置 Date 的值为 2024-02-27T00:00:00.000Z 格式。
{
"Rules": [{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"Expiration": {
"Date": "2006-01-02"
}
}]
}
JSON
