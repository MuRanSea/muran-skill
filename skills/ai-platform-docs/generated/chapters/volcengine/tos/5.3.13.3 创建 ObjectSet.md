5.3.13.3 创建 ObjectSet
初始化 ObjectSet 后，您可以创建 ObjectSet 并绑定标签，对 ObjectSet 进行管理。本文介绍创建ObjectSet 的具体操作。
前提条件
已完成 ObjectSet 初始化，详细介绍请参见初始化 ObjectSet 。
注意事项
一旦创建 ObjectSet，ObjectSet 的层级深度、自定义分隔符将不可修改，请谨慎操作。
创建 ObjectSet
登录对象存储控制台 。
在左侧导航栏，单击桶列表。
在顶部导航栏，选择存储桶所属项目。
在桶列表页面，单击目标桶名称。
在左侧导航栏，选择 ObjectSet > ObjectSet 管理。
在右侧单击创建 ObjectSet， 设置 ObjectSet 参数 。
单击确认创建。
使用 ObjectSet
参数 说明
ObjectSet 名称
ObjectSet 名称。
名称规则如下：
长度为 3 到 256 个字符。
必须以小写字母或数字开头。
必须满足当前存储桶配置的层级数要求。
多级目录通过分隔符进行分隔，末尾的分隔
符会自动补全。
不允许以根目录 / 作为路径前缀。
初始绑定 Tags
ObjectSet 的初始绑定标签。
标签规则如下：
Key 不能重复。
Key 长度不能超过 128 个字符，Value 长度
不能超过 256 个字符。
Key/Value 不支持中文字符。
说明
最多可以设置 10 个标签。

创建 ObjectSet 后，您可以通过文件路径前缀将文件纳入指定 ObjectSet。每个 ObjectSet 在创建时都会绑定一个专属的路径前缀，该前缀作为该 ObjectSet 中文件的统一命名空间入口。当文件写入到该前缀下时，即可归属于对应的 ObjectSet。
例如，创建 ObjectSet 时指定的路径前缀为 folder1/folder2 ，则上传到 folder1/folder2 路径下的文件，均会纳入该 ObjectSet。
其他操作
在 ObjectSet 管理页面，您可以对已创建的 ObjectSet 进行以下管理操作：
编辑：单击指定 ObjectSet 操作列的详情，修改 ObjectSet 绑定的 Tags、QoS 流控限制。删除：单击指定 ObjectSet 操作列的删除， 在弹出的对话框中单击确认删除，即可删除 ObjectSet。说明
删除 ObjectSet 仅删除其配置元数据（如容量限制、独立域名、标签关联），不会删除其内部包含的对象数据，底层对象将变为游离态。
操作 说明
上传文件到 ObjectSet
在文件列表页面上传文件时，将上传目录指定
为 ObjectSet 对应的路径前缀。文件上传后即归
属于该 ObjectSet。例如 folder1/folder2/
example.jpg。
将已有文件纳入 ObjectSet 在文件列表页面，通过复制到或移动到方式，将
已有文件调整到 ObjectSet 对应的路径前缀下。
查看 ObjectSet 下的文件 在文件列表页面，按 ObjectSet 路径前缀筛选文
件，查看该 ObjectSet 下的文件数据。
管理 ObjectSet 下的文件 ObjectSet 下的文件仍按照 TOS 文件进行管理，
支持下载、删除、权限控制等文件相关操作。
