5.3.7 权限管理
5.3.7.1 权限管理概述
本文介绍 TOS 权限管理页面提供的访问控制与安全防护功能，以及各功能的适用场景，帮助您根据授权主体、资源范围和安全要求选择合适的权限配置方式。
背景信息
为保障数据安全，TOS 中的存储桶（Bucket）和对象（Object）默认均为私有资源，仅资源所有者和获得授权的身份可以访问。
如果需要允许当前主账号下的 IAM 用户、其他火山引擎账号或匿名用户访问 TOS 资源，您可以根据实际场景，通过桶 ACL、桶策略或 IAM 策略授予相应权限。
权限配置方式
目标存储桶的权限管理页面提供以下权限配置与安全防护功能：
功能 功能说明 适用场景
桶 ACLs
* 创建账号授权：为指定 IAM
主账号配置当前存储桶的读写
权限及桶 ACL 的读写权限；不
支持直接填写子账号 ID。
* 查看并管理账号授权：查看
已授权账号的账户 ID、桶访问
权限和 ACL 访问权限，并支持
编辑或删除相应授权。
* 编辑公共访问权限：配置所
有用户的公共访问权限。
* 查看拥有者权限：查看当前
存储桶拥有者的账户 ID，以及
其拥有的桶访问权限和 ACL 访
问权限。
* 配置上传对象 ACL 默认策
略：开启后，桶内新上传对象
的 ACL 默认继承当前存储桶的
ACL。
授权需求较简单，需要快速设
置存储桶的访问权限。
桶策略（Policy）
* 通过创建策略，为指定用户
配置当前桶或桶内对象的访问
权限，并可按资源、操作和条
件进行精细化控制。
* 策略支持通过可视化视图或
JSON 视图进行配置和管理。
将单个存储桶或桶内指定资源
授权给多个用户，并按资源、
操作和条件实施 API 级精细权
限控制的场景。
访问控制 IAM 策略
功能 功能说明 适用场景
* 可以为当前主账号下的 IAM
用户配置 TOS 资源访问权限。
支持按存储桶、目录或对象限
定资源范围，并配置读、写、
删除等操作权限及生效条件。
* 提供典型策略示例、使用指
南和权限问题排查入口。
需要从身份维度集中管理权
限，或为当前主账号下的 IAM
用户授予多个 TOS 资源的访问
权限。
