9.14.6.1.2 CreateBucket（Rust SDK）
create_bucket 接口用于创建 TOS 桶并设置默认存储类型，本文介绍如何通过 Rust SDK 的 create_bucket接口完成桶创建与权限配置。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
每个账号在全地域最多可创建 100 个桶，达到上限后再次调用将返回错误。
若需使用 DEEP_COLD_ARCHIVE 存储类型，当前仅华北 2（北京）、华东 2（上海）、华南 1（广州）支持且处于邀测状态，须先联系客户经理开通。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行create_bucket 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：tos:CreateBucket
