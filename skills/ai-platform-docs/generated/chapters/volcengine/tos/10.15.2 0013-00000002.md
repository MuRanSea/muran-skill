问题描述
静态网站配置非法。
问题原因
用户设置静态网站配置时，同时缺少 RedirectAllRequestsTo 和 IndexDocument 配置项。问题示例
您进行静态网站配置时，配置中无 RedirectAllRequestsTo 和 IndexDocument 配置项。
解决方案
参见 PutBucketWebsite ，正确构造静态网站配置。
PUT /?website HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
{
"ErrorDocument": {
"Key": "error.html"
 }
}
Go
