9.14.6.15.3 DeleteBucketCustomDomain（Rust SDK）
delete_bucket_custom_domain 接口用于删除指定存储桶的单条自定义域名配置，本文介绍如何通过 RustSDK 的 delete_bucket_custom_domain 接口完成该操作。
注意事项
您需要根据实际情况，填写示例代码中的地域和访问域名，详细介绍，请参见 地域和访问域名。为了防止密钥泄露，本文示例代码需要从环境变量中读取 Access Key ID 和 Secret Access Key。因此使用 SDK 前，您需要配置长期访问凭证，详细介绍，请参见 配置长期访问凭证。
调用者须为桶所有者或具备 DeleteBucketCustomDomain 权限。
customdomain 参数仅支持传入单个域名，不支持批量删除。
若 customdomain 值与桶已绑定的域名不匹配，接口返回 404 NoSuchCustomDomain。
删除成功后，该域名将在 1 分钟内停止解析到对应桶。
权限说明
火山引擎主账号默认拥有全部权限，但是 IAM 用户默认没有任何权限。如果您需要使用子账号执行delete_bucket_custom_domain 操作，火山引擎主账号需通过 IAM策略和桶策略为该子账号授予以下权限：
tos:DeleteBucketCustomDomain

async fn main() {
