3.2.10 加速器费用
使用加速器功能会收取相应的加速器容量和带宽费用。本文介绍加速器费用的具体规则。
说明
本文仅介绍计费项详情，关于计费项的具体定价，请参见 TOS 定价详情 。
存储容量以二进制计算，例如 1GiB = 1024MiB。
预置带宽以十进制计算，例如 1GB/s = 1000MB/s。

用
使用 TOS 加速器的读写缓存模
式时，会按照存储容量大小和
时长计费，每小时按照小时存
储容量峰值结算一次费用。

（天）÷ 24（小时）
加速器读写-basic125-预置带
宽费用
使用 TOS 加速器的读写缓存模
式，并且选择配置预置带宽
时，会按照配置的预置带宽值
和时长计费，每小时结算一次
费用。
使用预置带宽模式的 TOS加速
器同样可以免费获得存储容量
带来的基线带宽，因此在计算
预置带宽费用时仅计算超过基
线带宽部分的带宽费用，每小
时预置带宽计费量如下所示：
当预置带宽 > 小时基线带宽
峰值时：预置带宽计费量 =
预置带宽值 - 小时基线带宽
峰值。
当预置带宽 <= 小时基线带
宽峰值时：预置带宽计费量
= 0。
按量计费：每小时预置带宽费
用 = 该小时预置带宽计费量
（MB/s）× 月单价 ÷ 30
（天）÷ 24（小时）
