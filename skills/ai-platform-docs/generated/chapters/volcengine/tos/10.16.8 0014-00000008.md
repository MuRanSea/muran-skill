问题描述
RocketMQ 的角色没有权限操作 RocketMQ。
问题原因
在创建的 RocketMQ 类型事件通知规则中，所提供的 RocketMQ 的角色不具备操作 RocketMQ 的权限。问题示例
如下示例，缺少 RocketMQ:DescribeAuthKey 、 RocketMQ:GetSk 、 RocketMQ:GetTopic 权限会导致失败。需要至少包含 RocketMQ:GetInstance 、 RocketMQ:DescribeAuthKey 、 RocketMQ:GetSk 、 RocketMQ:GetTopic 这四个Action。
解决方案
检查提供的 Role 角色是否包含 RocketMQAccessForTOS 策略名（对象存储 TOS 访问消息队列 RocketMQ权限）。
{
"Statement": [
{
"Effect": "Allow",
"Action": [
"RocketMQ:GetInstance"
],
"Resource": [
"*"
]
}
]
}
