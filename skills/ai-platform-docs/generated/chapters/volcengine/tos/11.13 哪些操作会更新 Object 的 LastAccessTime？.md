11.13 哪些操作会更新 Object 的 LastAccessTime？
LastAccessTime 表示对象的最后访问时间，部分针对对象的操作可能会更新对象的 LastAccessTime。下表列举了会更新对象的 LastAccessTime 操作。
具体操作 涉及接口
上传或覆盖对象
PutObject
PostObject
CreateMultipartUpload
FetchObject
CopyObject
下载对象
GetObject
说明
通过 GetObject 访问软链接对象时，也
会更新对象的最后访问时间。
修改对象 ACL CopyObject
修改对象存储类型 CopyObject
追加写对象
ModifyObject
说明
仅 HNS 桶支持 ModifyObject 接口。
