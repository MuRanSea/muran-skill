6.4.2 API 概览
本文介绍 TOS Vectors 提供的 API 接口和功能描述。
分类 API 名称 功能
向量桶操作
CreateVectorBucket 创建向量桶。
DeleteVectorBucket 删除向量桶。
GetVectorBucket 获取向量桶信息。
ListVectorBuckets 列出向量桶列表。
PutVectorBucketPolicy 设置向量桶策略。
GetVectorBucketPolicy 获取向量桶策略。
DeleteVectorBucketPolicy 删除向量桶策略。
向量索引操作
CreateIndex 创建向量索引。
DeleteIndex 删除向量索引。
GetIndex 获取向量索引信息。
ListIndexes 列出向量索引列表。
向量操作
PutVectors 上传向量。
GetVectors 根据向量 Key 列表获取向量。
QueryVectors 根据目标向量查询 TopK 相似
向量。
DeleteVectors 删除向量。
ListVectors 列出向量列表。
