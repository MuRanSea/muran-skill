10.18.2 0016-00000002
问题描述
自定义域名配置非法。
问题原因
用户设置自定义域名时，配置中的 Domain 字段取值非有效的域名格式。
问题示例
您进行自定义域名配置时，Domain 字段取值非有效的域名格式。
解决方案
参见 PutBucketCustomDomain ，正确构造自定义域名配置，确保 Domain 字段取值为有效的域名格式。
PUT /?customdomain HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
{
"CustomDomainRule": {
"Domain": "123",
"CertId": "certID"
 }
}
Go
