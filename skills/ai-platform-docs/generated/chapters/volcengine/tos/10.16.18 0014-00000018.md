问题描述
事件通知单规则内，事件通知类型重复。
问题原因
事件通知单规则内，事件通知类型重复。
问题示例
如下所示， Events 元素中 tos:ObjectCreated:* 已包含 tos:ObjectCreated:Put 。
PUT /?notification HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: GMT Date
Authorization: authorization string
{
"CloudFunctionConfigurations": [
{
"Events": [
"tos:ObjectCreated:*",
"tos:ObjectCreated:Put"
],
"Filter": {
"TOSKey": {
"FilterRules": [
{
"Name": "prefix",
"Value": "test_"
},
{
"Name": "suffix",
"Value": ".jpg"
}
]
}
},
"RuleId": "string",
"CloudFunction": "string"
}
]
}
JSON
解决方案
调整事件通知类型，去除重复事件类型。
