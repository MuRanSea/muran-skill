5.10.5 洞察助手
洞察助手是 TOS Agent 面向数据洞察场景的应用入口。TOS Agent 是火山引擎面向对象存储场景推出的、基于大语言模型构建的智能体服务。您可通过自然语言与 TOS Agent 对话，无需在控制台逐级查找配置项或翻阅文档，即可完成从智能运维、数据洞察、多模态检索及方案推荐的各类任务。
说明
TOS Agent 当前处于邀测阶段，如需使用请联系客户经理。
支持的问答场景
推荐问法按业务目的划分为若干类别，可以直接点击卡片提交，也可参照示例改写为更贴合业务的提问。
使用场景
日志分析
推荐场景
日常运维与故障排查： 通过自然语言即可定位流量、请求或状态码异常发生的时间段和 Bucket，无需手写 SQL。
热点识别与访问优化： 支持基于客户端 IP、Referer、热点对象及下载流量的热点分析，并给出访问路径与缓存策略优化建议。
错误根因定位： 支持按 ErrorCode、HTTPStatus、Operation、RequestId 等条件层层下钻到原始访问日志，快速还原单次异常请求的上下文。
安全审计： 可一键追踪 DeleteObject、覆盖写、分片上传等高风险操作，输出操作时间、来源 IP 与访问身份，辅助合规审计。
近实时容量变化分析： 基于日志中的 DeltaDataSize 与 HistoricalVersionDeltaSize，快速计算指定时间段内请求带来的容量增量与历史版本变化。
使用示例
例如您在洞察助手中输入一段请求命令，洞察助手会基于访问日志按操作类型（Operation）和响应码（HTTPStatus）聚合统计，返回请求次数排名 Top N 的操作分布表，并给出请求占绝对主导的操作、异常响应码集中的操作等关键发现。
请求示例：
Bucket: * | SELECT
"Operation" AS Action,
 COUNT(*) AS `请求次数`,
 HTTPStatus AS `响应码`,
 COUNT(*) * 100.0 / NULLIF(SUM(COUNT(*)) OVER (), 0) AS `请求占比(%)`
 WHERE "Operation" IS NOT NULL AND "Operation" <> '-'
数据透视
推荐场景
容量规划： 通过对话即可查看存储量与对象数量的长期增长趋势，快速判断当前容量是否符合业务预期，并支持按 Region/Bucket/存储类型拆解增长来源。
成本优化： 一键定位存储量最大的 Bucket 或 Prefix，识别主要成本来源，帮助排出治理优先级。存储分层： 分析标准/低频/归档/冷归档各存储类型的容量分布与访问情况，评估现有分层策略是否合理。
历史版本治理： 定位历史版本字节数最大的 Bucket，给出治理建议。生命周期删除或降冷规则需在TOS 控制台配置。
未合并分片治理： 识别长期未完成的分片上传及其所在 Bucket，估算无效存储成本。
多业务共用桶治理： 支持通过 Prefix 聚合识别具体业务目录的容量与对象数量增长。
