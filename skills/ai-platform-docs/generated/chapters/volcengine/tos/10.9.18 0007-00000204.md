问题描述
生命周期规则中 NoncurrentVersionExpiration 字段的 NoncurrentDate 参数取值非 ISO8601 格式。问题原因
生命周期规则中 NoncurrentVersionExpiration 字段的 NoncurrentDate 参数取值非 ISO8601 格式。问题示例
解决方案
NoncurrentDate 的取值需要设置为 2024-02-27T00:00:00.000Z 格式。
{
"Rules": [{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"NoncurrentVersionExpiration": {
"NoncurrentDate": "2006-01-02"
}
}]
}
