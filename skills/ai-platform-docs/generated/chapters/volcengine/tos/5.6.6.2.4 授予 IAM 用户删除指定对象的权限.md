5.6.6.2.4 授予 IAM 用户删除指定对象的权限
本文档介绍如何授予当前账号下的 IAM 用户删除指定对象的权限。
场景说明
授权账号：当前账号（本文以 210015**** 为例）下的 amuser 用户。
授权资源： data/aaa
动作：DeleteObject
注意事项
权限配置后略有延迟，如果您配置的权限没有立即生效，建议您稍后重试。
操作步骤
登录对象存储控制台 。
在左侧导航栏，单击桶列表，在桶列表页面单击目标桶名称。
在左侧导航栏，选择权限管理 > 存储桶授权策略管理。
根据需要选择授权方式。

单击**编辑**，将以下内容复制到文本框中，单击**确定**。
```JSON
{
 "Statement": [
 {
 "Sid": "自定义策略-3b8a",
 "Effect": "Allow",
 "Principal": [
 "210015****/iamuser"
 ],
 "Action": [
 "tos:DeleteObjectVersion",
 "tos:DeleteObject"
 ],
 "Resource": "trn:tos:::bucketname/data/aaa"
 }
 ]
}
```
删除指定对象
根据本文授权后，可以使用如下方式删除指定对象：
使用 API 或 SDK 完成删除指定对象的操作。
如果要在控制台或者 TOS Browser 工具删除指定对象，还需要通过 IAM 策略授予用户列举桶（ListBuckets）、列举桶内对象（ListBucket）的权限。IAM 策略支持的 Action 说明，请参见 IAM 策略支持动作 。
说明
完成所有授权后，在控制台进行删除指定桶对象操作时，由于没有其他接口的权限，控制台可能会报错 Request failed with status code 403 和 权限不足 ，这些报错并不会影响已有权限，您可以忽略这些报错。
