7.6.2 tosfsspec 快速入门
本文旨在引导您快速上手 tosfsspec，完成环境准备、认证授权与基本的文件操作。
依赖说明
tosfsspec 的正常运行依赖以下核心组件， pip 会自动为您处理这些依赖的安装：
Python: >= 3.8, < 3.14 。
fsspec: >= 2023.5.0 ，提供了文件系统规范的基类。
tos: >= 2.8.0 ，火山引擎官方提供的 TOS Python SDK。
tosnativeclient: >=1.1.13 ，为 tosfsspec 提供底层的高性能内核，负责网络请求、并发控制、CRC 校验等核心功能。

使用 fs.open() 方法可以像操作本地文件一样读写 TOS 上的对象。它返回一个文件类对象，支持 read() 、 write() 等标准方法。

复制、移动和删除 ( cp / mv / rm )
以下操作用于在 TOS 内部管理对象。
fs.cp() : 复制对象。
fs.mv() : 移动或重命名对象。
fs.rm() : 删除对象或目录。
# 上传本地文件到 TOS
remote_path_for_put = f'tos://{bucket}/uploads/uploaded_file.txt'
fs.put(local_file_path, remote_path_for_put)
print(f'{local_file_path} 已上传至 {remote_path_for_put}')
# 从 TOS 下载文件到本地
local_download_path = 'downloaded_from_tos.txt'
fs.get(remote_path_for_put, local_download_path)
print(f'{remote_path_for_put} 已下载至 {local_download_path}')
# 验证下载内容
with open(local_download_path, 'r') as f:
print(f'下载的文件内容: {f.read()}')
# 清理本地文件
import os
os.remove(local_file_path)
os.remove(local_download_path)

dst_path = f'tos://{bucket}/data/file1_copy.txt'
fs.cp(src_path, dst_path)

# 移动 (重命名) 文件

print(f'原文件是否存在: {fs.exists(mv_src)}') # 输出: False
print(f'新文件是否存在: {fs.exists(mv_dst)}') # 输出: True
# 删除文件

exists = fs.exists(mv_dst)

目录与通配符 ( walk / glob )
使用 fs.walk() 和 fs.glob() 可以实现复杂的对象查找。
fs.walk() : 递归遍历指定目录下的所有对象和子目录。
fs.glob() : 使用通配符模式（如 * 和 ** ）查找匹配的对象。
获取元信息与检查存在性 ( info / exists )
info() 或 stat() : 获取文件或目录的详细信息。
exists() : 检查路径是否存在。
# 递归删除目录
fs.rm(f'tos://{bucket}/data/', recursive=True)
exists = fs.exists(f'tos://{bucket}/data/')
print(f'data 目录是否存在: {exists}') # 输出: False
