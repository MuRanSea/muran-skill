9.2.7.6.2 管理对象读写权限（Java SDK）
本文介绍如何获取和设置对象的访问权限。对象的访问权限优先级高于桶的访问权限，如果对象未设置访问权限，则遵循桶的访问权限。
设置对象的读写权限
您可以通过 TOS Java SDK 的 putObjectAcl 接口设置指定对象的读写权限。
注意
设置对象的读写权限，您的账号必须具备 tos:PutObjectAcl 权限。具体操作，请参见权限配置指南。
