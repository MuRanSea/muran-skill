11.12 哪些操作会更新 Object 的 LastModifyTime？
LastModifyTime 表示对象的最后修改时间，部分针对对象的操作可能会更新对象的 LastModifyTime。下表列举了会更新对象的 LastModifyTime 操作。
具体操作 涉及接口
重命名目录或文件
RenameObject
说明
HNS 桶默认支持通过 RenameObject 接
口重命名目录或文件， FNS 桶则需要先
开启 RenameObject 功能，才支持通过
RenameObject 接口重命名文件，并且不
支持重命名目录。
追加写文件
ModifyObject
说明
仅 HNS 桶支持 ModifyObject 接口。
覆盖同名文件
通过 PutObject 上传同名文件
通过 CopyObject 拷贝同名文件
