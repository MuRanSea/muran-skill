问题描述
配置的生命周期规则中，存在多条 NoncurrentVersionExpiration 之间，其前缀有包含关系。在未开启前缀重叠的选项前，不允许创建的规则前缀有重叠。
问题原因
配置的生命周期规则中，存在多条 NoncurrentVersionExpiration 之间，其前缀有包含关系。在未开启前缀重叠的选项前，不允许创建的规则前缀有重叠。
问题示例
规则 id 和规则 id1 的 prefix 有重叠，且都有 Expiration 。
解决方案
建议只保留一条生命周期规则。如果实际场景中生命周期规则的前缀需要重叠，您也可以开启前缀重叠功能，具体操作，请参见设置前缀重叠 。
{
"Rules": [
{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"NoncurrentVersionExpiration": { "NoncurrentDays": 120 }
},
{
"ID": "id1",
"Prefix": "prefix/a",
"Status": "Enabled",
"NoncurrentVersionExpiration": { "NoncurrentDays": 120 }
}
]
}
