9.5.12 异步 SDK 说明
异步处理（ ve-tos-cpp-sdk ）是指程序执行一个任务时，不需要等待该任务完成就能继续执行其他任务。本文介绍如何使用进行异步处理的场景，例如文件上传/下载、AsyncEvent 暂停/恢复、基础对象上传/下载等。
注意事项
目前异步 SDK 仅支持 Linux 平台。若在非 Linux 平台尝试开启 -DBUILD_ASYNC_SDK=ON 选项，编译过程将直接报错，以避免误编译不可用的异步代码。
设置 BUILD_ASYNC_SDK=ON 时，系统会同时编译同步 SDK 与异步 SDK。
回调中返回 0 必须配合 AsyncEvent 暂停机制使用。

io_uring 支持说明
io_uring 为可选特性，其生效状态由编译期及运行时环境共同决定。
编译参数： -DBUILD_ASYNC_SDK_IO_URING=AUTO 
该参数支持以下可选值：
AUTO ：默认设置。若系统环境中存在 liburing.h 及 liburing 库则自动启用，否则自动关闭。ON ：强制启用。若环境中缺少 liburing 库，CMake 将在编译时报错。
OFF ：强制关闭。
即使在编译期启用了 io_uring 特性，系统在运行时仍会检查当前环境是否真实支持。若运行时不可用且文件后端机制配置为 AUTO ，系统会自动回退至其他可用的实现路径。

 std::string bucket = "<bucket>";
 std::string key = "async-demo/hello.txt";
 std::string ak = "<access-key-id>";

 input.setContentLength(static_cast<int64_t>(body.size()));
auto offset = std::make_shared<std::size_t>(0);
auto sender = [body, offset](char* data, size_t len, AsyncEvent* ev) -> size_t {
 (void)ev;
const size_t remain = body.size() - *offset;
const size_t n = std::min(len, remain);
if (n > 0) {
memcpy(data, body.data() + *offset, n);
 *offset += n;
 }
return n;
 };
 std::promise<Outcome<TosError, PutObjectAsyncOutput>> promise;
auto future = promise.get_future();
 client.putObjectAsync(input, sender,
 [&promise](Outcome<TosError, PutObjectAsyncOutput>& outcome) mutable {
 promise.set_value(outcome);
 });
auto outcome = future.get();
 client.close();
CloseTosAsyncClient();
return outcome.isSuccess() ? 0 : 1;
}

AsyncEvent 暂停/恢复示例
当上传数据暂时不可用，或下载消费端暂时无法写入时，回调可以返回 0 并通过 AsyncEvent 显式暂停请求。
请勿在未显式暂停的情况下长期返回 0，否则 SDK 会将其作为错误处理，以防止请求长时间阻塞。也可在数据准备就绪后，由业务线程发起调用：
文件上传
使用 putObjectFromFdRangeAsync 可以从 fd 指定范围上传，适合大对象或已有本地文件的场景。auto sender = [](char* data, size_t len, AsyncEvent* ev) -> size_t {
if (!HasDataReady()) {
 ev->PauseFor(10); // 10ms 后重新调度
return 0;
 }
return FillData(data, len);
};

常见问题
只想使用同步 SDK，编译方式要改吗？
无需更改。系统默认设置 BUILD_ASYNC_SDK=OFF ，原有同步 SDK 的构建方式保持不变。
打开异步 SDK 后，同步 SDK 还能用吗？

callback 会在哪个线程执行？
异步 HTTP 回调由 SDK 的异步 worker 线程触发。请避免在业务回调中执行长时间的阻塞操作；若需等待外部数据或下游消费能力，建议使用 AsyncEvent::PauseFor() 或配合使用 Pause() 与 Resume() 。回调里返回 0 是什么意思？
回调中返回 0 必须配合 AsyncEvent 暂停机制使用。若在未显式暂停的情况下长期返回 0，SDK 会将其视为数据生产或消费异常。
