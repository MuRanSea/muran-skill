问题描述
当 rename 的目标文件存在时，不允许覆盖。
问题原因
携带 x-tos-forbid-overwrite 头域的值为 true 时，同时存在与 rename 的目标文件同名的文件，此时同名文件不允许被覆盖。
问题示例
解决方案
请查看该请求是否符合预期。
PUT /src-object?name=dst-object&rename HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: GMT Date
Authorization: authorization string
