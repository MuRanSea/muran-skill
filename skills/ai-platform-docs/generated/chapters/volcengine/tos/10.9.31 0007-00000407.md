10.9.31 0007-00000407
问题描述
配置的生命周期规则中， Transitions 字段的 Date 参数取值非 ISO8601 格式。
问题原因
配置的生命周期规则中， Transitions 字段的 Date 参数取值非 ISO8601 格式。
问题示例
解决方案
设置 Date 的值为 2024-02-27T00:00:00.000Z 格式。
{
"Rules": [{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"Transitions": [
{
"StorageClass": "IA",
"Date": "2006-01-02"
}
]
}]
}
JSON
