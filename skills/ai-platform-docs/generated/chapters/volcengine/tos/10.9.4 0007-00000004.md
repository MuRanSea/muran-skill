10.9.4 0007-00000004
问题描述
生命周期规则配置中存在重复的规则 ID 。
问题原因
配置生命周期规则时，设置了重复的规则 ID 。
问题示例
{
"Rules": [{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
"Expiration": { "Days": 120 },
"NoncurrentVersionExpiration": { "NoncurrentDays": 120 },
"AbortIncompleteMultipartUpload": { "DaysAfterInitiation": 10 },
"Transitions": [
{
"StorageClass": "IA",
"Days": 30
},
{
"StorageClass": "COLD_ARCHIVE",
"Days": 60
}
],
"NoncurrentVersionTransitions": [
{
"StorageClass": "IA",
"NoncurrentDays": 30
},
{
"StorageClass": "COLD_ARCHIVE",
"NoncurrentDays": 60
}
]
},
{
"ID": "id",
"Prefix": "prefix",
"Status": "Enabled",
解决方案
确保生命周期规则数组内 ID 字段唯一。
"Expiration": { "Days": 120 },
"NoncurrentVersionExpiration": { "NoncurrentDays": 120 }
}]
}
