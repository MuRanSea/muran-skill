storage_class 否
指定上传到 TOS 文件的存储类
型。可选参数为：
STANDARD ：标准存储，
默认值。
IA ：低频访问存储。
ARCHIVE_FR ：归档闪回存
储。
enable_verify_ssl 否
配置是否开启 SSL 证书校验，
默认开启，取值说明如下：
true ：开启 SSL 证书校
验。
false ：不开启 SSL 证书校
验。
max_inode_num 否
当前挂载点最大的 inode 数
量，最大值为
18446744073709551615，默
认值为 1000w，一般不建议修
改该值。如果挂载点下文件和
目录总数超过 1000w，建议按
照实际的使用数量调大该值。
max_file_num 否
当前挂载点支持同时打开的句
柄数量，通常操作系统会首先
限制用户能打开的文件句柄数
量。在操作系统限制放开时，
还需要关注该参数值是否够
用。参数默认值是65535。调
大该参数值时，会增加TOS
FSx的内存占用量，默认情况
下，为发放句柄准备的内存占
用约50MB内存，调大参数
时，内存随着参数值线性增
加。
rw 否
使用读写方式挂载文件系统，
默认开启。
ro 否
使用只读方式挂载文件系统，
默认关闭，可以通过指定挂载
选项 -o ro 开启。
max_retry_count 否
请求失败最大重试次数，默认
3 次。
参数 是否必选 说明
connection_timeout 否
建立连接超时时间，单位：毫
秒，默认 10000 毫秒。
socket_timeout 否
请求超时时间，请求超时没有
收到数据将会关闭连接，默认
为 30000 毫秒。
persist_dir 否
系统运行时的状态文件存放目
录，默认值为 /opt/tmp/fsx 。
该目录占用空间大小与 
max_inode_num 和 
max_file_num 参数的值有
关。建议预留 2GiB 磁盘空
间。
tos_is_custom_domain 否
当前域名是否为自定义域名，
默认为 false。
tos_incremental_upload 否
是否开启追加写，默认为
false。
tos_allow_delete 否
是否允许删除文件，默认为
false。
tos_create_empty_file 否
创建新文件场景，在 open 时
是否创建 0 字节文件到 TOS 桶
中，用于保证可见性，默认为
true。

kms ：使用 SSE-KMS 加密

算法。
关于 SSE-TOS、 SSE-KMS 加密

参数 是否必选 说明
prefetch_buffer_size 否
预读的数据块大小，默认为
4MB，单位为 MB。
prefetch_cache_pool_limit 否
预读缓存内存占用最大空间，
默认为 1024MB，单位为 MB。
prefetch_forward_buffer_count 否
单文件最大预读的数据块个
数，默认为 32。
prefetch_backward_buffer_cou
nt 否
保留当前读请求偏移之前的数
据块个数，默认为 1。
num_prefetch_threads 否
预读线程数量，默认为 32，建
议不要小于默认值。
参数 是否必选 说明
read_cache_dir 否
读缓存目录，默认为空 ，即不
使用读缓存。
说明
如果您需要使用读缓存
功能，建议为读缓存配
置独立的数据盘或独立
分区的文件系统，避免
与系统的其它应用互相
抢占磁盘空间。您可以
为读缓存和写缓存配置
相同的文件系统分区，
区分不同目录即可。若
读缓存和写缓存合用一
个分区，建议为读缓存
和写缓存预留总计
120GiB 的磁盘空间。
max_read_cache_size 否
写缓存参数
说明
写缓存默认开启，且不支持关闭。您可以在挂载存储桶时设置写缓存参数，配置写性能，关于写性能的详细介绍，请参见 FSX 性能调优 。
参数 是否必选 说明
读缓存占用最大空间，单位为
MB。默认为0，代表不使用读

参数 是否必选 说明
temp_dir 否
写缓存目录，默认为 /tmp 。
FSX 客户端默认会先写入数据
到本地临时文件目录，临时文
件目录可以在挂载时指定 
temp_dir 参数进行配置，默
认在 /tmp/ 下创建临时目录
作为临时文件目录。如果您对
性能敏感，可以在挂载时指定 
tmpfs 作为写临时文件目
录。关于写性能的详细介绍，
请参见写缓存性能。
说明
如果您需要使用写
缓存功能，建议为
写缓存配置独立的
数据盘或独立分区
的文件系统，避免
与系统的其它应用
互相抢占磁盘空
间。您可以为读缓
存和写缓存配置相
同的文件系统分
区，区分不同目录
即可。
num_bg_threads 否
上传多段数据的线程数量，默
认为 32 ，建议不要小于默认
值。
参数 是否必选 说明
part_size 否
多段上传时的段大小，单位为
MiB，默认为 8MiB，取值范围
为 [4，5120]。TOS 约束最多
上传 10000 个段，可以通过调
整段大小来调整上传的对象大
小。具体使用方式，请参见上
传大文件。
注意
part_size 的值必须
为正整数。
在高并发上传文件
的场景下，为了避
免写缓存占用的磁
盘空间超过上限值
（ 即
max_temp_capacity
的值），TOS 会限
制只写模式和读写
模式同时打开文件
的数量（即 Limit
值）。计算公式
为：Limit =
max_temp_capacity
/ part_size，因此提
升 part_size 的值，
会导致 Limit 上限降
低。该种情况下，
建议同时调大
max_temp_capacity
的值。
max_temp_capacity 否
最大写缓存占用磁盘空间，单
位为 GiB，默认为 10GiB，建
议不要小于默认值。
说明
仅 1.2.7.530 及以上版
本的 FSX 工具支持 
max_temp_capacity 参
数。
