7.4.4 FSX 挂载参数说明
本文介绍使用 FSX 客户端时支持配置的详细挂载参数，具体包括基本参数、读缓存参数、写缓存参数等。基本参数
参数 是否必选 说明
region 是 存储桶所在地域。
no_writeback_cache 是
不开启内核 page cache 回写功
能，保证 write 请求是顺序
写。
endpoint 是
TOS 的访问域名，仅支持 TOS
域名，暂不支持 S3 域名。如
果没有指定协议，则默认使用
HTTPS 协议，完整格式为 
https://{host}:{port} 。
access_key_id
否
在挂载命令中指定密钥信息，
关于获取 Access Key ID 和
Secret Access Key 的具体操
作，请参见 Access Key（密
钥）管理 。
说明
* 
请确保 Access Key ID 和 Secret
Access Key 所属账号拥有存储
桶的读写权限，如果权限不
足，可能导致挂载点无法使
用。
* 
在挂载命令中指定密钥信息和
在挂载命令中指定包含鉴权信
息的文件路径为二选一，您必
须设置其中一项。
* 
仅使用临时访问凭证的情况
下，需要设置 security_token
参数。
参数 是否必选 说明
secret_access_key
security_token
credential_filepath 否
指定鉴权凭证文件的绝对路
径，以加载访问所需的认证信
息。您需要自行创建鉴权凭证
文件，且该文件扩展名必须为 
json ，包含内容如下：
Bash
{
"VOLC_ACCESSKEY": "<ak_string>",
"VOLC_SECRETKEY": "<sk_string>",
"VOLC_SECURITY_TOKEN":
"<sts_string>"
}
credential_timeout_sec 否
FSX 客户端动态配置鉴权文件
的时间，单位：秒。
说明
credential_timeout_sec 和 
credential_filepath 参数需要搭
配使用。
num_meta_threads 否
元数据线程数量，默认为 32，
建议不要小于默认值。
num_io_threads 否
读线程数量，默认为 16，建议
不要小于默认值。
num_write_threads 否
写线程数量，当未指定 
num_write_threads 时，系统
自动将其默认值设置为 
num_io_threads 的值。
说明
仅 1.2.7.530 及以上版本的 FSX
工具支持 num_write_threads
参数。
参数 是否必选 说明
storage_class 否
指定上传到 TOS 文件的存储类
型。可选参数为：
* STANDARD ：标准存储，默
认值。
* IA ：低频访问存储。
* ARCHIVE_FR ：归档闪回存
储。
enable_verify_ssl 否
配置是否开启 SSL 证书校验，
默认开启，取值说明如下：
* true ：开启 SSL 证书校验。
* false ：不开启 SSL 证书校
验。
max_inode_num 否
当前挂载点最大的 inode 数
量，最大值为
18446744073709551615，默
认值为 1000w，一般不建议修
改该值。如果挂载点下文件和
目录总数超过 1000w，建议按
照实际的使用数量调大该值。
max_file_num 否
当前挂载点支持同时打开的句
柄数量，通常操作系统会首先
限制用户能打开的文件句柄数
量。在操作系统限制放开时，
还需要关注该参数值是否够
用。参数默认值是65535。调
大该参数值时，会增加TOS
FSx的内存占用量，默认情况
下，为发放句柄准备的内存占
用约50MB内存，调大参数
时，内存随着参数值线性增
加。
rw 否
使用读写方式挂载文件系统，
默认开启。
ro 否
使用只读方式挂载文件系统，
默认关闭，可以通过指定挂载
选项 -o ro 开启。
max_retry_count 否
请求失败最大重试次数，默认
3 次。
参数 是否必选 说明
connection_timeout 否
建立连接超时时间，单位：毫
秒，默认 10000 毫秒。
socket_timeout 否
请求超时时间，请求超时没有
收到数据将会关闭连接，默认
为 30000 毫秒。
persist_dir 否
系统运行时的状态文件存放目
录，默认值为 /opt/tmp/fsx 。
该目录占用空间大小与 
max_inode_num 和 
max_file_num 参数的值有
关。建议预留 2GiB 磁盘空
间。
tos_is_custom_domain 否
当前域名是否为自定义域名，
默认为 false。
tos_incremental_upload 否
是否开启追加写，默认为
false。
tos_allow_delete 否
是否允许删除文件，默认为
false。
tos_create_empty_file 否
创建新文件场景，在 open 时
是否创建 0 字节文件到 TOS 桶
中，用于保证可见性，默认为
true。
tos_sse 否
设置目标对象的加密方式，完
成挂载后，上传的对象默认会
使用该服务端加密方式，取值
说明如下：
* AES256 ：使用 SSE-TOS 加
密方式，并采用 AES256 加密
算法。
* kms ：使用 SSE-KMS 加密
方式，并采用 AES256 加密算
法。
关于 SSE-TOS、 SSE-KMS 加密
方式详细说明，请参见加密方
式 。
注意
预读参数
说明
参数 是否必选 说明
使用 SSE-TOS 或 SSE-KMS 服
务端加密时，暂不支持 SM4 加
密算法。
tos_sse_kms_key_id 否
KMS 主密钥的 TRN，用于指定
SSE-KMS 加密目标对象使用的
主密钥。格式为 
trn:kms:<region>:<accountID>:keyri
ngs/<keyring>/keys/<key> ，其
中 region 为密钥所属 Region
ID， accountID 为密钥所属账
号的 ID， keyring 为密钥环别
名， key 为主密钥别名。
说明
您可以登录 KMS 控制台 ，
在用户主密钥页面单击目标密
钥环，在密钥环详情页面，目
标密钥的密钥 TRN 及别名列获
取密钥 TRN。
tos_symlink_mode 否
软链接模式，取值说明如下：
* 0 ：保持原有软链接行为，
无法解析通过 TOS 控制台创建
的软链接对象指向的目标文件
路径，详细介绍，请参见在
Linux 系统中访问软链接对象
的使用建议 。
* 1 ：软链接兼容模式，该模
式会自动识别通过 TOS 控制台
创建的服务端软链接，访问该
软链接文件时，系统会重定向
到目标对象内容。
未指定 tos_symlink_mode 参数
时，其默认值为 0。
您可以在挂载存储桶时设置预读参数，配置预读性能，关于预读性能的详细介绍，请参见 FSX 性能调优。

说明
参数 是否必选 说明
prefetch_buffer_size 否
预读的数据块大小，默认为
4MB，单位为 MB。
prefetch_cache_pool_limit 否
预读缓存内存占用最大空间，
默认为 1024MB，单位为 MB。
prefetch_forward_buffer_count 否
单文件最大预读的数据块个
数，默认为 32。
prefetch_backward_buffer_cou
nt 否
保留当前读请求偏移之前的数
据块个数，默认为 1。
num_prefetch_threads 否
预读线程数量，默认为 32，建
议不要小于默认值。
参数 是否必选 说明
read_cache_dir 否
读缓存目录，默认为空 ，即不
使用读缓存。
说明
如果您需要使用读缓存功能，
建议为读缓存配置独立的数据
盘或独立分区的文件系统，避
免与系统的其它应用互相抢占
磁盘空间。您可以为读缓存和
写缓存配置相同的文件系统分
区，区分不同目录即可。若读
缓存和写缓存合用一个分区，
建议为读缓存和写缓存预留总
计 120GiB 的磁盘空间。
max_read_cache_size 否
读缓存占用最大空间，单位为
MB。默认为0，代表不使用读
缓存。
写缓存默认开启，且不支持关闭。您可以在挂载存储桶时设置写缓存参数，配置写性能，关于写性能的详细介绍，请参见 FSX 性能调优 。
参数 是否必选 说明
temp_dir 否
写缓存目录，默认为 /tmp 。
FSX 客户端默认会先写入数据
到本地临时文件目录，临时文
件目录可以在挂载时指定 
temp_dir 参数进行配置，默
认在 /tmp/ 下创建临时目录
作为临时文件目录。如果您对
性能敏感，可以在挂载时指定 
tmpfs 作为写临时文件目
录。关于写性能的详细介绍，
请参见写缓存性能 。
说明
* 
如果您需要使用写缓存功能，
建议为写缓存配置独立的数据
盘或独立分区的文件系统，避
免与系统的其它应用互相抢占
磁盘空间。您可以为读缓存和
写缓存配置相同的文件系统分
区，区分不同目录即可。
num_bg_threads 否
上传多段数据的线程数量，默
认为 32 ，建议不要小于默认
值。
part_size 否
多段上传时的段大小，单位为
MiB，默认为 8MiB，取值范围
为 [4，5120]。TOS 约束最多
上传 10000 个段，可以通过调
整段大小来调整上传的对象大
小。具体使用方式，请参见上
传大文件 。
注意
* 
part_size 的值必须为正整
数。
挂载参数
访问权限
参数 是否必选 说明
* 
在高并发上传文件的场景下，
为了避免写缓存占用的磁盘空
间超过上限值（ 即
max_temp_capacity 的值），
TOS 会限制只写模式和读写模
式同时打开文件的数量（即
Limit 值）。计算公式为：
Limit = max_temp_capacity /
part_size，因此提升 part_size
的值，会导致 Limit 上限降
低。该种情况下，建议同时调
大 max_temp_capacity 的值。
max_temp_capacity 否
最大写缓存占用磁盘空间，单
位为 GiB，默认为 10GiB，建
议不要小于默认值。
说明
仅 1.2.7.530 及以上版本的 FSX
工具支持 max_temp_capacity
参数。
参数 是否必选 说明
compatible_mode=true 否
是否开启 posix 语义兼容性，
默认值为 false ，取值说明如
下：
* true ：开启。
* false ：关闭。
参数 是否必选 说明
uid 否
挂载方式
参数 是否必选 说明
设置文件或目录属于某个用户
时，需要填写的用户 uid。
gid 否
设置文件或目录属于某个用户
组时，需要填写的用户 gid。
file_mode 否
用于设置挂载文件的权限，默
认取值为 644。
dir_mode 否
用于设置目录的权限，默认取
值为 755。
参数 是否必选 说明
native_fuse 否
是否使用 Linux 原生 Fuse 工具
挂载 TOS，取值说明如下：
* true ：使用 Linux 原生 Fuse
工具挂载 TOS。
* false ：使用 FSX 工具挂载
TOS。
默认为 false。
注意
使用 Linux 原生 Fuse 工具挂
载 TOS 后，需要注意以下事
项：
* 
不支持无损升级，即升级客户
端后，无法自动恢复业务，需
要重新挂载后手动恢复相关业
务。
* 
不支持自动清理临时文件，即
重启进程后，写缓存目录
参数 是否必选 说明
temp_dir 下的临时文件不会
被自动清除。为避免磁盘空间
占用，您需要定期手动清理临
时文件。
