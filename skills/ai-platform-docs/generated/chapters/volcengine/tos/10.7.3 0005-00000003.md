10.7.3 0005-00000003
问题描述
请求同时携带头域 x-tos-traffic-limit 和 URL 参数 x-tos-traffic-limit 。
问题原因
用户请求头域和 URL 中均包含 x-tos-traffic-limit 设置。
问题示例
您发起下载对象请求，头域和 URL 中均包含 x-tos-traffic-limit 设置。
解决方案
采用头域或 URL 参数中的一种方式，携带 x-tos-traffic-limit 设置。
GET /objectName/obj?x-tos-traffic-limit=819200 HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: GMT Date
Authorization: authorization xxx
x-tos-traffic-limit: 819200
Go
