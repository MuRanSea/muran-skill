除凭证外，可通过高级参数控制分片、并发与重试等行为。
参数名 类型 是否必需 描述
key str 是

目标 Bucket 所在的地

import tosfsspec
import os
import tos
# 从环境变量获取 AKSK 信息

参数名 类型 描述
directory str 日志文件目录。
common_log str
运行日志文件名的前缀，实际
文件名会在此基础上追加进程
ID。
common_level str 普通运行日志级别，例如 
INFO 、 DEBUG 。
audit_log str
审计日志文件名的前缀，实际
文件名会在此基础上追加进程
ID。
audit_level str 审计日志级别，例如 INFO 、
DEBUG 。
import multiprocessing
from tosfsspec import init_logs, TosFileSystem
def worker(index):
 init_logs(
 directory='./logs',
 common_log='tosfsspec-common',
 common_level='INFO',
 audit_log='tosfsspec-audit',
 audit_level='INFO',
 )
 fs = TosFileSystem(key=key,secret=secret, region='cn-beijing')
 path = f'tos://your-bucket/log-demo/file-{index}.txt'
with fs.open(path, 'wb') as f:
 f.write(f'worker {index}\n'.encode('utf-8'))
if __name__ == '__main__':
 processes = [multiprocessing.Process(target=worker, args=(i,)) for i in range(4)]for p in processes:
 p.start()
for p in processes:
 p.join()
