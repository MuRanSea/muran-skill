9.2.6.1.2 列举桶（Java SDK）
桶（Bucket）是 TOS 的全局唯一的命名空间，相当于数据的容器，用来储存对象（Object）数据。本文介绍如何通过 TOS Java SDK 的 listBuckets 接口列举您账号下所有地域的桶（Bucket）列表。注意事项
列举桶之前，您必须具有 tos:ListBuckets 权限。具体操作，请参见 IAM 策略概述。
此接口会返回当前账号所有地域的桶。
示例代码
以下代码展示如何列举当前账号所有地域的桶。
