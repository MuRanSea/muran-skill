10.5.10 0003-00000010
问题描述
桶策略拒绝。
问题原因
用户访问 TOS 时，请求被桶策略拦截，导致请求被拒绝。
问题示例
假设桶策略配置如下：
此策略表示禁止 210004xxxx 账号对 test 桶进行对象上传操作，若该用户发起对象上传请求，则返回该错误。
解决方案
检查桶策略配置。
{
"Version": "2012-10-17",
"Statement": [
 {
"Sid": "桶拒绝策略",
"Effect": "Deny",
"Principal": ["210004xxxx"],
"Action": ["tos:PutObject"],
"Resource": ["trn:tos:::test/*"]
 }
 ]
}
Go
