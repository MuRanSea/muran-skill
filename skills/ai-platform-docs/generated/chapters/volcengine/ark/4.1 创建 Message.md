4. Messages API
4.1 创建 Message
POST https://ark.cn-beijing.volces.com/api/compatible/v1/messages
根据输入的消息列表创建一条新的 Message，返回模型生成的下一条消息。本接口为无状态接口，多轮对话时每次请求都需传入完整的消息历史。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
