5.3.8 会话任务
5.3.8.1 查询会话任务
GET https://ark.cn-beijing.volces.com/api/v3/sessions/{session_id}/tasks/{task_id}查询指定后台工具任务的最新状态，以及结束后的执行结果和产物定位信息。
查询单个任务时，任务状态为 succeeded 、 failed 、 cancelled 或 unknown ，响应包含 result ；任务状态为 queued 或 running 时不返回。
unknown 表示当前无法确认任务状态，不是稳定结束状态。保留 task_id 并稍后查询；状态可能恢复为running 或实际结束状态，因此不要将该状态视为成功。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
session_id string 必选 | 会话 ID
任务所属的会话 ID，格式为 sesn- 开头的字符串。
task_id string 必选 | 任务 ID
要查询的后台工具任务 ID，格式为 task- 开头的字符串。可从工具调用返回或任务列表响应的 task_id字段获得。
响应参数
created_at integer | 创建时间
任务记录的创建时间，采用 Unix 毫秒时间戳。
session_id string | 会话 ID
任务所属的会话 ID。
session_thread_id string | 会话线程 ID
发起该任务的会话线程 ID。
state string | 任务状态
任务的当前状态：
queued ：任务正在等待执行。
running ：任务正在执行，或产物正在保存到会话工作区。
succeeded ：任务执行成功。
failed ：任务执行失败。
cancelled ：任务已取消。
unknown ：当前无法确认任务状态，不是稳定结束状态。保留 task_id 并稍后查询；状态可能恢复为running 或实际结束状态，因此不要将该状态视为成功。
task_id string | 任务 ID
后台工具任务的唯一标识，格式为 task- 开头的字符串。
tool object | 工具信息
产生该任务的工具调用信息。
name string | 工具名称
tool.name
产生该任务的工具名称，例如 bash 或 video_generate 。
description string | 工具调用说明
tool.description
工具调用的用途说明。没有可用说明时，不返回该字段。
tool_use_id string | 工具调用 ID
tool.tool_use_id
Agent 发起该次工具调用时生成的工具调用 ID。没有可用 ID 时，不返回该字段。
error_code string | 失败类型
任务失败、取消或状态未知，且服务端记录了失败原因时的失败类型：
upstream ：工具依赖的服务执行失败。
timeout ：任务执行超时。
fetch ：任务结果获取或保存失败。
killed ：任务执行过程被终止。
internal ：平台处理任务时发生错误。底层错误原因不会返回，请携带 task_id 联系技术支持。error_message string | 失败信息
任务失败、取消或状态未知，且服务端记录了失败原因时的原因说明。 error_code 为 internal 时，返回平台侧失败说明，不返回底层错误原因。
finished_at integer | 结束时间
任务进入结束状态的时间，采用 Unix 毫秒时间戳。任务尚未结束时，不返回该字段。
result object | 执行结果
任务执行结果。
查询单个任务时，任务状态为 succeeded 、 failed 、 cancelled 或 unknown ，响应包含 result ；任务状态为 queued 或 running 时不返回。
content object[] | 结果内容
result.content
工具返回的结果内容块列表。
text string | 文本内容
result.content.text
工具执行结果或失败原因的文本说明。
type string | 内容类型
result.content.type
内容块类型，固定为 text 。
status string | 结果状态
result.status
工具执行结果状态：
ok ：任务成功结束。
error ：任务失败、取消或状态未知。
meta_info object | 结果元信息
result.meta_info
用于读取日志、定位会话工作区产物或关联上游生成任务的信息。没有可用元信息时，不返回该字段。exit_code integer | 退出码
result.meta_info.exit_code
Bash 命令的退出码。执行环境未返回退出码时，不返回该字段。
generation_params object | 生成参数
result.meta_info.generation_params
实际提交给内容生成服务的生成参数。没有可用生成参数时，不返回该字段。
duration integer | 时长
result.meta_info.generation_params.duration
生成视频的时长，以秒为单位。
generate_audio boolean | 生成音轨
result.meta_info.generation_params.generate_audio
是否同时生成音轨。
model string | 模型
result.meta_info.generation_params.model
实际使用的模型。
ratio string | 宽高比
result.meta_info.generation_params.ratio
生成视频的宽高比。
resolution string | 分辨率
result.meta_info.generation_params.resolution
生成视频的分辨率。
seed integer | 随机种子
result.meta_info.generation_params.seed
生成视频的随机种子， -1 表示随机。
watermark boolean | 添加水印
result.meta_info.generation_params.watermark
是否添加水印。
meta_path string | 元数据归档路径
result.meta_info.meta_path
完整请求、响应和产物信息归档文件的会话工作区路径。
output object | 实际产物规格
result.meta_info.output
产物实际规格。没有可用规格时，不返回该字段。
duration number | 时长
result.meta_info.output.duration
实际视频时长，以秒为单位。
fps number | 帧率
result.meta_info.output.fps
实际视频帧率。
has_audio boolean | 是否含音轨
result.meta_info.output.has_audio
实际视频是否含有音轨。
height integer | 高度
result.meta_info.output.height
实际视频高度，以像素为单位。
ratio string | 宽高比
result.meta_info.output.ratio
实际视频宽高比。
resolution string | 分辨率
result.meta_info.output.resolution
实际视频分辨率。
width integer | 宽度
result.meta_info.output.width
实际视频宽度，以像素为单位。
output_path string | 产物路径
result.meta_info.output_path
工具产物或兼容模式输出在会话工作区中的文件路径。
provider_task_id string | 上游任务 ID
result.meta_info.provider_task_id
内容生成服务返回的上游任务 ID，用于关联生成任务。
stderr_path string | 标准错误路径
result.meta_info.stderr_path
Bash 标准错误在会话工作区中的文件路径。
stdout_path string | 标准输出路径
result.meta_info.stdout_path
Bash 标准输出在会话工作区中的文件路径。
task_id string | 生成任务 ID
result.meta_info.task_id
视频生成任务在内容生成服务中的任务 ID。
usage object | 生成用量
result.meta_info.usage
上游返回的用量信息。没有可用用量时，不返回该字段。
completion_tokens integer | 生成消耗
result.meta_info.usage.completion_tokens
本次视频生成消耗的 token 数，用于计费核算。
total_tokens integer | 总用量
result.meta_info.usage.total_tokens
本次视频生成的总 token 用量。
video_url string | 视频地址
result.meta_info.video_url
生成成功后返回的临时视频访问地址。地址未保留或不可用时，不返回该字段。
started_at integer | 开始时间
任务开始执行的时间，采用 Unix 毫秒时间戳。任务尚未开始时，不返回该字段。
summary string | 任务摘要
工具执行内容的摘要。服务端未生成摘要时，不返回该字段。
