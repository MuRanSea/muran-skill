11.1.6 停止批量推理任务
POST https://ark.cn-beijing.volcengineapi.com/?Action=StopBatchInferenceJob&Version=2024-01-01停止一个正在运行（Running）或排队中（Queued）的批量推理任务，使其提前结束执行。
注意
仅 Running 或 Queued 状态的任务可以被停止。停止后任务进入 Terminating → 
Terminated ，已处理完成的推理结果保留在 OutputDirTosLocation 中，可通过 
ResumeBatchInferenceJob 重启继续处理剩余请求。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 任务 ID
待停止的批量推理任务 ID。可通过 CreateBatchInferenceJob 接口创建任务时获取，或通过 ListBatchInferenceJobs 查询。
DryRun boolean 默认值 false | 预检请求
是否仅对此请求进行预检。 true 表示发送检查请求，仅校验参数合法性与权限，不实际停止任务；false 表示发送正常请求，执行停止操作。
响应参数
本接口无特有的返回参数，成功时 HTTP 状态码为 200 ，返回结构中 Result 为空对象 {} 。
