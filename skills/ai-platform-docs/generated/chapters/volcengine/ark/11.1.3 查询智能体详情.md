11.1.3 查询智能体详情
GET https://ark.cn-beijing.volces.com/api/v3/agents/{agentId}
根据智能体 ID 获取智能体的详细信息。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
agentId string 必选 | 智能体 ID
要查询的智能体 ID。通过创建智能体接口 (POST /agents) 返回, 或在控制台智能体列表页面获取。Query 参数
在 URL Query String 中传入。
响应参数
created_at string | 创建时间
智能体创建时间，ISO 8601 格式
id string | 智能体 ID
智能体唯一标识符，格式为 agent- 开头的字符串
name string | 智能体名称
智能体名称，用于用户识别和管理
type string | 对象类型
对象类型，固定为 agent
updated_at string | 更新时间
智能体最后更新时间，ISO 8601 格式
version integer | 版本号
智能体版本号，每次更新递增
description string | 智能体描述
智能体描述，用于说明智能体的用途、能力范围、适用场景等
mcp_servers object[] | MCP 服务列表
已配置的 MCP 服务列表
name string | 在本 Agent 内唯一
mcp_servers.name
被 tools[].mcp_server_name 引用。
type string | MCP server 类型，当前固定 "url"
mcp_servers.type
url string | MCP server URL
mcp_servers.url
metadata object | 自定义元数据
用户自定义元数据
model object | 模型配置
模型配置详情
id string | 模型 ID 或推理接入点 ID
model.id
例如模型 ID doubao-seed-2-1-pro-260628 ，或推理接入点 ID ep-20260907123456-abcd1 。reasoning_effort string | 推理投入档位，对应底层模型调用的 reasoning_effort 字段model.reasoning_effort
可填 none 、 minimal 、 low 、 medium 、 high 、 xhigh 、 max ；实际支持值与默认值以模型元数据为准。不设置或传空字符串时，Managed Agents 使用模型元数据中的默认值；如模型元数据未配置默认值，则不会向底层模型调用传递该字段，由底层模型服务按默认策略处理。各模型支持的取值和默认值，请参见 模型支持的参数列表 。
service_tier string | 推理服务档位，对应底层模型调用的 service_tier 字段
model.service_tier
可填 auto 、 default 、 fast ；实际支持值与默认值以模型元数据为准。不设置或传空字符串时，Managed Agents 使用模型元数据中的默认值；如模型元数据未配置默认值，则不会向底层模型调用传递该字段，由底层模型服务按默认策略处理。传入不支持的取值时返回 400 InvalidParameter 。各模型支持的取值和默认值，请参见 模型支持的参数列表 。
speed string | 模型推理速度档位，可填 standard 、 fast
model.speed
standard 为标准模式， fast 为快速模式；并非所有模型都支持 fast ，实际支持范围以模型元数据为准。不设置或传空字符串时，Managed Agents 不会向底层模型调用传递该字段，由底层模型服务按默认策略处理。
thinking string | 思考开关，对应底层模型调用的 thinking.type 字段
model.thinking
可填 enabled 、 disabled 、 auto ； auto 表示由模型判断是否思考，不表示继承。实际支持值与默认值以模型元数据为准。不设置或传空字符串时，Managed Agents 使用模型元数据中的默认值；如模型元数据未配置默认值，则不会向底层模型调用传递该字段，由底层模型服务按默认策略处理。传入不支持的取值时返回 400 InvalidParameter 。各模型支持的取值和默认值，请参见 模型支持的参数列表 。multiagent object | 多智能体配置
