11.3.3 查询会话详情
GET https://ark.cn-beijing.volces.com/api/v3/sessions/{session_id}
查询指定会话的详细信息，包括智能体、环境、资源、状态、用量、标签等。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
session_id string 必选 | 会话 ID
要查询的会话 ID。通过创建会话接口 (POST /sessions) 返回, 或通过查询会话列表接口 (GET /sessions) 获取。
响应参数
agent object | 智能体信息
创建会话时保存的智能体配置快照，包含该会话实际使用的模型、系统提示词、工具、MCP 服务和技能等配置。后续更新智能体不会影响该会话中的快照。
created_at string | 创建时间
创建时间，ISO 8601 格式
environment_id string | 环境 ID
id string | 会话 ID
会话唯一标识符
status string | 会话状态
会话运行状态。可选值： idle 、 running 、 terminated 、 rescheduling 、 initializing 、 failed 、upgrading 。
type string | 对象类型
对象类型，固定为 session
updated_at string | 更新时间
更新时间，ISO 8601 格式
archived_at string | 归档时间
会话归档时间，ISO 8601 格式
environment object | 环境信息
会话实际使用的环境对象
created_at string | 创建时间
environment.created_at
创建时间，ISO 8601 格式
id string | 环境 ID
environment.id
环境唯一标识符

environment.name
环境名称，用于用户识别和管理
type string | 对象类型
environment.type
对象类型，固定为 environment
updated_at string | 更新时间
environment.updated_at
更新时间，ISO 8601 格式
config object | 环境配置
environment.config
环境运行配置，包含运行类型、网络策略、依赖包与环境变量
type string | 环境类型
environment.config.type
运行环境类型： cloud 平台托管的云端 sandbox、 self_hosted 用户自托管环境

environment.config.packages
启动时预装的依赖包配置

environment.config.setup_script
沙箱启动阶段执行的初始化脚本；留空或未设置表示不执行任何脚本
tos object | 产物存储配置
environment.config.tos
智能体产物持久化存储配置。为空表示未配置用户 Bucket，产物落到方舟公共 TOS
bucket string | TOS 桶
environment.config.tos.bucket
用户 TOS 存储桶名称。Bucket 必须与当前方舟 API 接入地域一致，否则请求会被拒绝。
prefix string | 对象前缀
environment.config.tos.prefix
智能体产物存放在用户 Bucket 内的对象前缀。运行时最终对象 key 形如 {prefix}outputs/{env-id}/{session-id}/
{file}
