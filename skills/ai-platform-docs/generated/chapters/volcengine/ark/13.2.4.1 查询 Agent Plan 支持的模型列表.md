13.2.4 管理 Agent Plan
13.2.4.1 查询 Agent Plan 支持的模型列表
POST https://ark.cn-beijing.volcengineapi.com/?Action=ListArkAgentPlanModel&Version=2024-01-01查询 AgentPlan 套餐当前支持的模型列表，支持通过 Edition 区分个人版与企业版，结果用于在前端展示用户可在套餐内调用的模型。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Edition string | 套餐版本
套餐版本。可选值： personal （个人版）或 enterprise （企业版）。未传入或传入未识别值时，默认返回公共模型列表。
响应参数
Datas object[] | 模型列表
AgentPlan 套餐支持的模型列表。
ModelID string | 模型 ID
Datas.ModelID
