3.4 删除 Response
DELETE https://ark.cn-beijing.volces.com/api/v3/responses/{responseId}
本文介绍如何删除指定 ID 的 Response。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
responseId string 必选 | Response ID
要删除的 Response ID
响应参数
deleted boolean | 是否删除成功
取值范围：
true ：删除成功。
false ：未删除成功
id string | Response ID
被删除的 Response ID
object string | 对象类型
固定为 response
