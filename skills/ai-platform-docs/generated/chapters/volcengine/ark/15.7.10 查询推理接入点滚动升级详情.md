15.7.10 查询推理接入点滚动升级详情
POST https://ark.cn-beijing.volcengineapi.com/?Action=GetEndpointRolling&Version=2024-01-01查询指定滚动更新任务的详细信息，包括状态、灰度比例、滚动策略及执行日志。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 滚动更新任务 ID
要查询的滚动更新任务 ID
响应参数
RollingInfo object | 滚动更新详情
滚动更新任务的详细信息
CreateTime string | 创建时间
RollingInfo.CreateTime
滚动更新任务的创建时间
EndpointId string | 接入点 ID
RollingInfo.EndpointId
滚动更新所属的推理接入点 ID
Id string | 滚动更新任务 ID
RollingInfo.Id
滚动更新任务的唯一标识
RollingGray number | 灰度比例
RollingInfo.RollingGray
当前滚动更新的灰度比例，取值范围 0~1
RollingIn object | 滚动入快照
RollingInfo.RollingIn
滚动更新的目标模型快照（即将切入的版本）
ModelVersion string | 模型版本
RollingInfo.RollingIn.ModelVersion

RollingInfo.RollingIn.Name

RollingInfo.RollingIn.RouterInfo

RollingInfo.RollingIn.RouterInfo.Mode
路由模式。取值 Automatic (自动)、 CandidateSet (候选集合)、 Ordered (按顺序)
Strategy string | 路由策略
RollingInfo.RollingIn.RouterInfo.Strategy
路由策略。取值 EffectFirst (效果优先)、 CostFirst (成本优先)、 Balanced (均衡)

RollingInfo.RollingIn.RouterInfo.CandidateModels.FoundationModel.ModelVersion
Name string | 基础模型名称
RollingInfo.RollingIn.RouterInfo.CandidateModels.FoundationModel.Name
RollingOut object | 滚动出快照
RollingInfo.RollingOut

该快照对应的智能路由配置
Mode string | 路由模式

RollingInfo.RollingStrategy
滚动更新的执行策略配置
