10.3.9 会话线程
10.3.9.1 查询线程列表
GET https://ark.cn-beijing.volces.com/api/v3/sessions/{sessionId}/threads
分页查询指定会话下的主线程和子线程。会话开始执行后形成主线程；智能体委派子任务时形成子线程。
主线程排在最前，子线程按创建时间正序返回。
说明
新建会话在尚未开始处理任何事件时，线程列表可能为空。本接口仅支持 limit 和 page 分页，不支持按状态、智能体或父线程筛选，也不支持反转排序。单次最多返回 1000 条。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
sessionId string 必选 | 会话 ID
会话 ID，形如 sesn-...
Query 参数
在 URL Query String 中传入。
limit integer 默认值 1000 | 每页线程数
每页返回的线程数量，有效取值范围为 0～1000。
说明
省略 limit 或传入 0 时，按 1000 处理；传入大于 1000 的整数时，按 1000 处理。负数或无法解析为整数的值会返回参数错误。
最小值： 0
page string | 下一页标识
下一页标识。请将上一页响应中的 next_page 原样传入；不传则从第一页开始
响应参数
data object[] | 线程列表
线程列表。新建会话在尚未开始处理任何事件时可能返回空数组；首次执行开始后才会出现主线程视图agent_name string | 智能体名称
data.agent_name
线程关联的智能体名称
created_at string | 创建时间
data.created_at
首次观察到该线程的时间，采用 RFC 3339 格式。
id string | 线程 ID
data.id
线程唯一标识符，形如 sthr-...
parent_thread_id string / null | 父线程 ID
data.parent_thread_id
子线程的父线程 ID；主线程返回 null 。
session_id string | 会话 ID
data.session_id
所属会话 ID，形如 sesn-...
status string | 线程状态
data.status
线程状态：
running 智能体正在处理
idle 空闲（等待用户输入或工具结果）
rescheduling 调度中
terminated 已终止
线程不能单独删除； terminated 线程仍可能出现在列表中。
type string | 对象类型
data.type
对象类型，固定为 session_thread
updated_at string | 更新时间
data.updated_at
最近一次线程状态变化的时间，采用 RFC 3339 格式。
next_page string | 下一页标识
下一页标识。若为空或字段不返回，表示已到最后一页
