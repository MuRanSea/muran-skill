15.12.2 创建用量明细导出任务
POST https://ark.cn-beijing.volcengineapi.com/?Action=CreateRecordExportTask&Version=2024-01-01创建用户用量明细异步导出任务。提交成功后返回任务 ID，用于调用 GetRecordExportTask 查询状态与导出结果。
注意
同一账号下，活跃任务数量不可超过 3 个。
单个账号在滚动 24 小时内最多可提交 100 个导出任务。超出上限后，新的提交请求将失败。鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
EndTime number 必选 | 任务结束时间
任务结束时间（UTC Unix 时间戳，单位：秒）。需满足 EndTime − StartTime ≤ 10800 （最大时间跨度3 小时）。
注意
单次导出最大时间跨度为 10800 秒（3 小时）。如需导出更长区间，请按 3 小时窗口分批提交多个任务。
StartTime number 必选 | 任务起始时间
任务起始时间（UTC Unix 时间戳，单位：秒）。最小取值为 1777593600 （对应 UTC 时间 2026-05-0100:00:00 ）。配合 EndTime 圈定本次导出覆盖的时间窗口。
最小值： 1777593600
Filters object[] | 用量过滤条件
过滤条件数组。每个元素为一组 Key/Values 对，多个过滤条件之间为「与」关系。其中 Key 为 model_name 的过滤项为必填。
Key string 必选 | 过滤字段名
Filters.Key
过滤字段名。可取值：
model_name ：按模型名称过滤，必填
model_endpoint ：按模型接入点过滤
batch_job_id ：按批量推理任务 ID 过滤
volc_instance_id ：按火山实例 ID 过滤
Values string[] | 过滤值列表
Filters.Values
过滤值数组，需与 Key 配合使用。当 Key 为 model_name 时，可取值如 doubao-seed-2-0-pro 、 doubaoseed-2-0-lite 、 doubao-seed-2-0-mini 、 doubao-seed-2-0-code 、 doubao-seedance-2-0 、 doubaoseedance-2-0-fast 等。响应参数
Task object | 新建任务信息
新建任务的简要信息，包含可用于后续查询任务状态的任务 ID。
Id string | 任务 ID
Task.Id
任务 ID，调用 CreateRecordExportTask 接口时返回的唯一任务标识，格式为 
uet-YYYYMMDDhhmmss-<5 位字母数字> 。可作为 GetRecordExportTask 的入参查询任务状态及下载链接。
