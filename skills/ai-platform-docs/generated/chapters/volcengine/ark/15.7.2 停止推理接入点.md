15.7.2 停止推理接入点
POST https://ark.cn-beijing.volcengineapi.com/?Action=StopEndpoint&Version=2024-01-01停止指定的推理接入点（Endpoint）。停止后接入点不再接收推理请求，可通过 StartEndpoint 接口重新启动。
注意
仅处于运行中（ Running ）状态的接入点支持停止操作；已处于关闭状态（ Stopped ）的接入点重复调用会返回错误。停止操作为异步执行，调用成功后接入点进入停止中（ Stopping ）状态，完成后转为 Stopped ，停止期间不再接受推理请求；后付费模式下，接入点停止后不再计费。可通过 StartEndpoint 接口重新启动。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 推理接入点 ID
待停止的推理接入点（Endpoint）ID。以 ep- 开头，需为运行中（ Running 状态）的接入点。响应参数
本接口无特有的返回参数，成功时 HTTP 状态码为 200 ，返回结构中 Result 为空对象 {} 。
