10.2.2 查询环境列表
GET https://ark.cn-beijing.volces.com/api/v3/environments
分页查询当前账号或组织下的所有 Environment。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Query 参数
在 URL Query String 中传入。
limit integer | 每页数量
每页返回的数量
page string | 分页游标
分页 cursor（opaque），传入上一页返回的 next_page 获取下一页数据；首次请求可省略响应参数
data object[] | 环境列表
created_at string | 创建时间
data.created_at
创建时间，ISO 8601 格式
id string | 环境 ID
data.id
环境唯一标识符
name string | 环境名称
data.name
环境名称，用于用户识别和管理
type string | 对象类型
data.type
对象类型，固定为 environment
updated_at string | 更新时间
data.updated_at
更新时间，ISO 8601 格式
config object | 环境配置
data.config
环境运行配置，包含运行类型、网络策略、依赖包与环境变量
type string | 环境类型
data.config.type
运行环境类型： cloud 平台托管的云端 sandbox、 self_hosted 用户自托管环境
env object | 环境变量
data.config.env
注入到 sandbox 进程的环境变量键值对。环境变量 key 禁止使用 ARK_* / VOLC_* 保留前缀，否则返回 InvalidParameter 错误。
networking object | 出网策略
data.config.networking
容器出网策略配置
type string | 出网策略类型
data.config.networking.type
出网模式： unrestricted 不限制（其它字段不生效）、 limited 受限（配合 allowed_hosts 白名单）allow_mcp_servers boolean | 允许 MCP
data.config.networking.allow_mcp_servers
limited 模式下是否允许访问 MCP servers
allow_package_managers boolean | 允许包管理器
data.config.networking.allow_package_managers
limited 模式下是否允许包管理器（pip / npm / apt 等）访问其官方源
allowed_hosts string[] | 主机白名单
data.config.networking.allowed_hosts
limited 模式下允许出网的域名/IP 白名单；未设置时仅由 allow_mcp_servers 和 allow_package_managers控制，设置后与两者叠加生效
packages object | 依赖包配置
data.config.packages
启动时预装的依赖包配置
apt string[] | apt 包
data.config.packages.apt
通过 apt 预装的系统包
cargo string[] | cargo 包
data.config.packages.cargo
通过 cargo 预装的 Rust 包
gem string[] | gem 包
data.config.packages.gem
通过 gem 预装的 Ruby 包
go string[] | go 包
data.config.packages.go
通过 go 预装的 Go 包
npm string[] | npm 包
data.config.packages.npm
通过 npm 预装的 Node.js 包
pip string[] | pip 包
data.config.packages.pip
通过 pip 预装的 Python 包
type string | 配置类型
data.config.packages.type
依赖包配置类型，固定为 packages
setup_script string | 启动脚本
data.config.setup_script
沙箱启动阶段执行的初始化脚本，字符串形态直接透传给 sandbox init；留空 / 未设置表示不执行任何脚本
tos object | 产物存储配置
data.config.tos
智能体产物（ outputs/ ）持久化存储配置。为空表示未配置用户 Bucket，产物落到方舟公共 TOS说明
未配置 tos 时，智能体产物使用方舟默认存储，文件保留期限以平台策略为准。
配置 tos 后， outputs/ 目录中的产物存储到 {prefix}outputs/{env-id}/{session-id}/ 。bucket string | TOS 桶
data.config.tos.bucket
用户 TOS 存储桶名称。Bucket 必须与当前方舟 API 接入地域一致，否则请求会被拒绝。
prefix string | 对象前缀
data.config.tos.prefix
智能体产物存放在用户 Bucket 内的对象前缀。运行时最终对象 key 形如 {prefix}outputs/{env-id}/{session-id}/
{file}
description string | 环境描述
data.description
环境描述，用于说明环境的用途、网络策略、依赖包等配置
metadata object | 自定义元数据
data.metadata
用户自定义元数据
overridden_fields string[] | 覆写字段
data.overridden_fields
当会话使用 Environment override 快照时，本次被覆写的 config 子字段列表。普通 Environment 响应通常不返回该字段。
scope string | 作用域
data.scope
环境作用域。可选值： organization 、 account 。
next_page string | 下一页游标
下一页游标；无更多数据时不返回
