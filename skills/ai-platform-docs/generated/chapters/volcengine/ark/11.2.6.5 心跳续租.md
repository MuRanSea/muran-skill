11.2.6.5 心跳续租
POST https://ark.cn-beijing.volces.com/api/v3/environments/{environmentId}/work/{workId}/heartbeat心跳续租；expected_last_heartbeat 支持乐观并发控制。
本接口用于自托管环境的 Worker 调用。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
environmentId string 必选 | 环境 ID
workId string 必选 | Work 标识符
Work ID。
Query 参数
在 URL Query String 中传入。
desired_ttl_seconds integer | 期望租约 TTL
希望的租约 TTL（秒）；缺省则服务端使用默认值 300 秒。
expected_last_heartbeat string | 乐观并发校验值
乐观并发的期望值。特殊字面量 NO_HEARTBEAT 表示首次心跳（拿未认领的租约）。若与实际值不匹配，服务端返回 412 Precondition Failed。
响应参数
last_heartbeat string | 最近心跳时间
服务端 DB 中此刻实际的 heartbeat 时间戳（RFC 3339）。
lease_extended boolean | 租约是否续上
本次 heartbeat 是否成功续租。乐观并发失败或 work 已终态时为 false。
state string | 当前状态
当前 work 状态；心跳成功时通常为 active / stopping / stopped 之一。取值： queued / starting / active / stopping / stopped 。
ttl_seconds integer | 实际生效 TTL
实际生效的租约 TTL（秒），已按服务端上下界 clamp。默认 300 秒。
type string | 对象类型
类型标识，固定为 work_heartbeat 。
