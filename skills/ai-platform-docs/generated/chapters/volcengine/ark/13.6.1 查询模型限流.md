13.6 管理模型限流
13.6.1 查询模型限流
POST https://ark.cn-beijing.volcengineapi.com/?Action=ListModelRateLimit&Version=2024-01-01查询当前账号下各基础模型的限流配额信息，包括默认配额、当前配额、每日 Token 限额（TPD）及实时连接限制。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
FoundationModelNames string[] | 基础模型名称列表
指定要查询的基础模型名称列表。为空时返回全部模型的限流信息。
