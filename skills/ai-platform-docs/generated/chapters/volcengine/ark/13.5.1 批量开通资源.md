13.5 管理资源开通
13.5.1 批量开通资源
POST https://ark.cn-beijing.volcengineapi.com/?Action=ActivateResources&Version=2024-01-01批量开通指定资源，使其可用于对应业务场景。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
ResourceNames string[] 必选 | 资源名称列表
需要开通的资源名称列表。
ResourceType string 必选 | 资源类型
需要开通的资源类型。
DryRun boolean | 是否预检查
是否只进行开通条件预检查。开启后，接口仅校验请求参数和开通条件，不实际开通资源。响应参数
本接口无特有的返回参数，成功时 HTTP 状态码为 200 ，返回结构中 Result 为空对象 {} 。
