11.3.8 会话资源
11.3.8.1 添加会话资源
POST https://ark.cn-beijing.volces.com/api/v3/sessions/{sessionId}/resources
向指定会话添加文件资源，添加后智能体可以在运行环境中访问该资源。
说明
通过 file_id 引用 Files API 已上传的文件。已同时支持 purpose=user_data 与 purpose=agent 两类 file_id：挂载到会话后统一按沙箱资源使用，智能体通过 mount_path （默认落到 /mnt/session/uploads/{file} ）在沙箱内读取。若同一文件也希望进入模型上下文，需要在 user.message 的 content[] 中另外引用相同 file_id 。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
sessionId string 必选 | 会话 ID
会话 ID，格式为 sesn- 开头的字符串
Body 参数
type string 必选 | 资源类型
资源类型。当前仅支持 file 。
file_id string | 文件 ID
文件 ID，通过 Files API 上传获得。当 type=file 时必填；格式需匹配 ^[A-Za-z0-9_-]{1,128}$ 。mount_path string | 挂载路径
资源在智能体运行环境中的挂载路径，长度上限 512。仅 type=file 生效：前导 / 会被剥除；未传或空值时，服务端 fallback 到文件名，最终以 /mnt/session/uploads/{file} 形式挂载在 sandbox 内。响应参数
type string | 资源类型
资源类型。当前仅支持 file 。
created_at string | 创建时间
创建时间，ISO 8601 格式。
file_id string | 文件 ID
文件 ID；当 type=file 时返回。
id string | 资源 ID
资源唯一标识符
mount_path string | 挂载路径
挂载路径。 type=file 场景必返，形如 /mnt/session/uploads/{key} 。
updated_at string | 更新时间
更新时间，ISO 8601 格式。
