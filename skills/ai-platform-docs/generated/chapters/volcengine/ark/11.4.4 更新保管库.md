11.4.4 更新保管库
POST https://ark.cn-beijing.volces.com/api/v3/vaults/{vaultId}
更新指定保管库的信息，支持更新展示名与元数据。metadata 为 patch 语义（提供的 key 做 upsert，未出现的 key 保留）；display_name 与 metadata 至少提供一个。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
vaultId string 必选 | 保管库 ID
要更新的保管库 ID。通过创建保管库接口 (POST /vaults) 返回, 或通过查询保管库列表接口 (GET /vaults) 获取。
Body 参数
display_name string | 保管库展示名
保管库的展示名称，用于用户识别
metadata object | 自定义元数据
用户自定义元数据，patch 语义
用户级凭证场景可通过 patch 写入或更新 external_user_id 键映射客户产品侧的用户唯一标识；已存在的键做 upsert，未出现的键保留原值。
响应参数
created_at string | 创建时间
保管库创建时间，RFC 3339 格式时间戳
display_name string | 保管库展示名
保管库的展示名称，用于用户识别
id string | 保管库 ID
保管库唯一标识符
type string | 对象类型
对象类型，固定为 vault
updated_at string | 更新时间
保管库最后更新时间，RFC 3339 格式时间戳
metadata object | 自定义元数据
用户自定义键值对元数据；未设置或清空时返回 null
