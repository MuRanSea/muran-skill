11.6.6.6 删除记忆
DELETE https://ark.cn-beijing.volces.com/api/v3/memory_stores/{memory_store_id}/memories/{memory_id}删除单条记忆条目。删除后，原 path 可用于重新创建同名记忆。仅删除单条记忆时使用本接口；需要删除整个记忆库及其中全部记忆时，使用删除记忆库接口。
注意
即使所属记忆库已挂载到会话，也可以删除该记忆。删除后，相关会话将无法再读取该条目；删除前需确认业务影响。
说明
当记忆库不存在或当前账号、项目无权访问时，统一返回 404 InvalidMemoryStore.NotFound ；记忆不存在时返回 404 ResourceNotFound 。重复删除已不存在的记忆时，可将 404 ResourceNotFound视为目标记忆已不存在。并发修改导致删除失败时返回 409 ResourceConflict ，重新查询后再重试。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
memory_id string 必选 | 记忆 ID
用于定位要删除的记忆，以 mem- 开头。传入创建、列表或更新接口返回的完整 ID，不要自行拼接。memory_store_id string 必选 | 记忆库 ID
用于指定记忆所属的记忆库，以 memstore- 开头。传入创建或查询接口返回的完整 ID，不要自行拼接。响应参数
id string | 记忆 ID
已删除的记忆条目 ID，与请求中的 memory_id 相同。
type string | 对象类型
对象类型，固定为 memory_deleted 。
