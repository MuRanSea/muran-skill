11.5.6.6 删除记忆
DELETE https://ark.cn-beijing.volces.com/api/v3/memory_stores/{memoryStoreId}/memories/{memoryId}删除单条记忆条目， path 释放后可重建同名记忆；内部历史版本保留。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
memoryId string 必选 | 记忆 ID
要删除的记忆条目 ID。通过创建记忆接口 (POST /memory_stores/{memoryStoreId}/memories) 返回, 或通过查询记忆列表接口获取。
memoryStoreId string 必选 | 记忆库 ID
所属记忆库 ID。通过创建记忆库接口 (POST /memory_stores) 返回, 或通过查询记忆库列表接口 (GET /memory_stores) 获取。
响应参数
id string | 记忆 ID
被删除的记忆条目 ID
type string | 对象类型
对象类型，固定为 memory_deleted
