11.4.6.4 更新凭证
POST https://ark.cn-beijing.volces.com/api/v3/vaults/{vault_id}/credentials/{credential_id}更新指定凭证。auth 仅可更新可变字段（mcp_server_url / secret_name 创建后不可修改）；display_name / metadata 为 patch 语义。所有密文字段（access_token / token / secret_value /refresh_token / client_secret）均为 write-only，响应中不返回。
mcp_static 凭证的 injection_type 与 injection_name 为不可变结构字段，创建后不可原地变更，传入与现值不同的值将返回 409。变更注入方式需走「删除后重建」（软删旧凭证 → 新建凭证）； token 可通过 update 接口替换。
environment_variable 类型的 secret_name 是替换匹配键，创建后不可修改；如需修改环境变量名，请删除后重建凭证。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
