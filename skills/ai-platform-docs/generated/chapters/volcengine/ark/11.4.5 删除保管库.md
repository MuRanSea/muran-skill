11.4.5 删除保管库
DELETE https://ark.cn-beijing.volces.com/api/v3/vaults/{vaultId}
删除指定的保管库，删除后保管库及其中存储的所有凭证将永久无法恢复。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
vaultId string 必选 | 保管库 ID
要删除的保管库 ID。通过创建保管库接口 (POST /vaults) 返回, 或通过查询保管库列表接口 (GET /vaults) 获取。
注意
保管库删除后其中存储的所有凭证将永久删除，无法恢复，请确认后再操作。
响应参数
id string | 保管库 ID
被删除的保管库 ID
type string | 对象类型
对象类型，固定为 vault_deleted
