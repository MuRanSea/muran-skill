11.3.9 会话资源
11.3.9.1 添加会话资源
POST https://ark.cn-beijing.volces.com/api/v3/sessions/{session_id}/resources
将 Files API 中的文件添加到已有会话的托管运行环境。当前仅支持 file ，并以只读方式挂载。添加成功后，请使用响应中的 file_id 查询或引用该文件。本接口仅适用于绑定托管运行环境的会话。说明
挂载后，智能体通过 mount_path 读取文件；未指定该字段时，路径为 /mnt/session/uploads/
<filename> 。若还需要将同一文件传入模型上下文，请在 user.message 的 content[] 中引用响应中的 file_id 。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
session_id string 必选 | 会话 ID
填写要添加资源的会话 ID，形如 sesn-... 。
Body 参数
file_id string 必选 | 文件 ID
要挂载到会话的文件 ID，通过 Files API 上传文件后获得。
说明
文件不能超过 100 MiB。通过 Files API 上传文件时， purpose 必须为 user_data 或 agent ；文件ID 格式需匹配 ^[A-Za-z0-9_-]{1,128}$ 。
type string 必选 | 资源类型
要添加的资源类型，固定为 file ，表示通过 Files API 上传的文件。
mount_path string | 挂载路径
文件在托管运行环境中的路径。省略或传入空值时，使用文件上传时的原始文件名，最终路径为 /mnt/session/uploads/<filename> 。
说明
路径开头的 / 会自动移除。路径不得包含独立的 .. 或 . 路径段，例如 a/../b 和 a/./b 均不合法；也不得包含反斜杠、连续的 // 或控制字符，且不能以 / 结尾。
响应参数
access string | 访问模式
会话对文件的访问权限，固定为 read_only ，表示智能体可以读取文件，但不能修改。
type string | 资源类型
已挂载资源的类型，固定为 file ，表示通过 Files API 上传的文件。
created_at string | 创建时间
文件挂载到会话的时间，采用 RFC 3339 格式。
file_id string | 文件 ID
当前可用的文件 ID。该值可能与请求中提交的 file_id 不同；后续查询和引用请以响应值为准。id string | 资源 ID
会话资源 ID，形如 sesrsc-... 。
mount_path string | 挂载路径
文件在托管运行环境中的完整挂载路径。
说明
指定 mount_path 时，返回值由 /mnt/session/uploads/ 与规范化后的请求路径组成。例如传入 data/report.pdf 时，返回 /mnt/session/uploads/data/report.pdf 。未指定时，返回
/mnt/session/uploads/<filename> 。
updated_at string | 更新时间
会话资源信息最后更新的时间，采用 RFC 3339 格式。
