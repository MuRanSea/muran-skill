14.13.4 查询大语言模型效果问题结果
POST https://ark.cn-beijing.volcengineapi.com/?Action=CasePlatformV1SeedBadcaseQuery&Version=2024-01-01根据 Instance ID 查询方舟大语言模型效果问题（Seed Badcase）的处理状态与鉴定结果。本接口同时支持通过 Access Key 和方舟 API Key 两种方式鉴权。
关于 AssetIssues
多模态素材（图片、音视频等）会在受理后由后台异步搬运；搬运过程中若出现失败会写入 AssetIssues[] ，通过本接口返回。
40020/40021/40022/40023 为客户数据侧问题（URL 拉取失败、base64 解码失败、file_id 不存在或已过期、素材超大等），需上报方修正后重新提交。
50010 为平台侧存储失败（非客户数据问题），可稍后重新提交。
处理时效与链接有效期
上报大语言模型效果问题 没有上报时效限制：原始请求与响应由调用方直接提交，平台不向上游回查。受理后，即可使用返回的 InstanceId 查询。
Status 为 processing 时表示排查中， ProblemLabel 与 SolutionNote 尚未产出，请稍后再次查询；为 done 时，可读取处理结论。
多模态素材在受理后异步转存， AssetIssues 也会随转存过程更新。素材链接过期不影响 Case 受理，但会导致转存失败；链接拉取失败时， AssetIssues[].Code 返回 40020 。请在链接仍有效时尽快上报，并保持素材可用直到转存完成；使用 file_id 时也须确保文件未过期。
SolutionNote.Attachments[].Url 为预签名链接，每次查询时重新生成。请及时使用最新响应中的链接，过期后重新调用本接口；附件链接的有效期不代表 Case 记录的保留期。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
【推荐】API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
【可选】Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。
