10.6.5 删除技能
DELETE https://ark.cn-beijing.volces.com/api/v3/skills/{id}
删除指定的自定义技能。技能与技能版本是独立资源，删除最后一个版本不会删除技能。
删除技能前，按以下顺序处理：
更新引用该技能的 Agent，移除对应技能配置。删除技能不会自动移除引用；未移除时，相关 Agent 后续创建的 Session 可能运行失败。
删除该技能的全部版本。存在多个版本时，先删除非最新版本，再删除最后剩余的最新版本。调用本接口删除技能。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
id string 必选 | 技能 ID
用于指定要删除的技能。
响应参数
id string | 技能 ID
用于标识已删除的技能。
type string | 删除结果类型
用于标识删除成功响应的资源类型，固定为 skill_deleted 。
