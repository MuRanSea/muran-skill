12.2.6.8 创建共享包
POST https://ark.cn-beijing.volcengineapi.com/?Action=CreateSharedPackage&Version=2024-01-01为 Agent Plan 企业版创建共享包并提交订阅订单。共享包供绑定的席位共享使用。
您通过 API 接口发起部署请求或调用本服务的，即表示您已充分阅读、理解并同意 《火山方舟大模型订阅套餐服务专用条款》 、《豆包模型服务协议》 、《开源模型许可证》 、《Harness 能力说明和产品专用条款》 及其他适用的平台规则。如您不同意上述协议，请立即停止调用。使用说明
共享包的权益、订阅规则和使用方式请参见 共享包使用指南 。
下单后可通过 查询共享包订阅信息 确认共享包的订阅状态。
调用方应避免重复提交购买请求，以免重复下单。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Duration integer 必选 | 订阅时长
共享包的订阅时长，单位为月。当前仅支持订阅一个月。
取值固定为 1 。
PricingCycle string 必选 | 计费周期
共享包的计费周期，当前仅支持 Month 。
Quantity number 必选 | 购买数量
本次购买的共享包数量。当前仅支持整数购买。
最小值： 1
AutoPay boolean 默认值 false | 自动支付
是否自动支付共享包订单。
true ：自动支付订单。
false ：创建订单后，等待手动支付。
AutoRenew boolean 默认值 false | 自动续费
是否为共享包订阅开启自动续费。
true ：开启自动续费。
false ：不开启自动续费。
DryRun boolean 默认值 false | 预检模式
是否仅执行资源及交易预校验。
true ：仅校验，不创建共享包、订阅实例或订单。
false ：创建共享包并提交订阅订单。
ProjectName string 默认值 default | 项目名称
资源所属的项目名称。资源不在默认项目中时，填写实际项目名称。
说明
服务端会去除首尾空白字符；未传入或处理后为空时，使用字段默认值。
响应参数
InstanceID string | 订阅实例 ID
共享包关联的订阅实例 ID，用于续费共享包。将 DryRun 设置为 true 时，返回空字符串。NeedPay boolean | 待支付状态
是否仍需调用方完成支付。
true ：需要继续支付。
false ：无需继续支付。
Quantity number | 购买数量
实际用于计费的共享包购买数量。
SharedPackageID string | 共享包 ID
创建的共享包 ID，用于查询共享包订阅信息。该 ID 同时作为订阅实例名称。
将 DryRun 设置为 true 时，返回空字符串。
OrderNumber string | 订单号
订阅订单的正式订单号。 NeedPay 为 false 且有订单号时返回。
将 DryRun 设置为 true 时，不返回此字段。
PreOrderNumbers string | 预订单号
订阅订单的预订单号。 NeedPay 为 true 且有预订单号时返回。
将 DryRun 设置为 true 时，不返回此字段。
