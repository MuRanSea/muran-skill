15.2.3 查询个人版套餐
POST https://ark.cn-beijing.volcengineapi.com/?Action=GetPersonalPlan&Version=2024-01-01查询当前账号已购买的个人版套餐信息，包含套餐档位、生效状态、起止时间、自动续费设置等。注意
该接口仅返回当前账号已购买的个人版套餐信息，未购买或套餐已回收时会返回
ResourceNotFound.Plan 错误。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Plan string 必选 | 商品名称
待查询的商品名称。可选值： AgentPlan 、 CodingPlan 。
响应参数
AutoRenew boolean | 自动续费
是否已开启到期自动续费。
EndTime string | 到期时间
套餐当前到期时间，ISO 8601 格式。
PlanType string | 套餐档位
当前账号已订购的套餐档位。Plan 为 AgentPlan 时取值 Small 、 Medium 、 Large 、 Max ；Plan 为 CodingPlan 时取值 Lite 、 Pro 。
StartTime string | 生效时间
套餐首次生效时间，ISO 8601 格式。
Status string | 套餐状态
套餐的当前生效状态。 Running 表示生效中， Expired 表示已过期。
