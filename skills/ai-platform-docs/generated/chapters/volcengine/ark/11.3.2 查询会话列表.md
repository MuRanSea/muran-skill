11.3.2 查询会话列表
GET https://ark.cn-beijing.volces.com/api/v3/sessions
分页查询当前账号下的会话列表，支持按智能体、状态、标签、创建时间等过滤。分页采用 opaquecursor 机制（ page / next_page ）。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Query 参数
在 URL Query String 中传入。
agent_id string | 智能体 ID
按智能体 ID 过滤，只返回指定智能体的会话
agent_version integer | 智能体版本
按智能体版本过滤，仅在 agent_id 也传时生效
created_at_gt string | 创建时间下界(不含)
创建时间大于此值（ISO 8601），不含边界
created_at_gte string | 创建时间下界(含)
创建时间大于等于此值（ISO 8601），含边界
created_at_lt string | 创建时间上界(不含)
创建时间小于此值（ISO 8601），不含边界
created_at_lte string | 创建时间上界(含)
创建时间小于等于此值（ISO 8601），含边界
limit integer | 每页数量
每页返回的数量，服务端会 cap 到上限
memory_store_id string | 记忆库 ID
按 memory store 过滤，返回资源里挂着该 memory_store_id 的会话
order string | 排序方向
排序方向，可选 asc / desc ，默认 desc
page string | 分页游标
分页 opaque cursor，传入上一次响应返回的 next_page 以获取下一页
status string[] | 会话状态
按会话运行状态过滤。可重复传值，多个值之间取并集。可选值： idle 、 running 、 terminated 、rescheduling 、 initializing 、 failed 、 upgrading 。
响应参数
data object[] | 会话列表
匹配查询条件的会话列表，按创建时间倒序返回；无命中时返回空数组 []
agent object | 智能体信息
data.agent
关联的智能体信息
created_at string | 创建时间
data.created_at
创建时间，ISO 8601 格式
environment_id string | 环境 ID
data.environment_id
会话运行的环境 ID（由 Environments_create 返回），决定 sandbox 依赖包与网络策略
id string | 会话 ID
data.id
会话唯一标识符
status string | 会话状态
data.status
会话运行状态。可选值： idle 、 running 、 terminated 、 rescheduling 、 initializing 、 failed 、upgrading 。
type string | 对象类型
data.type
对象类型，固定为 session
updated_at string | 更新时间
data.updated_at
更新时间，ISO 8601 格式
archived_at string | 归档时间
data.archived_at
会话归档时间，ISO 8601 格式
environment object | 环境信息
data.environment
会话实际使用的环境对象
created_at string | 创建时间
data.environment.created_at
创建时间，ISO 8601 格式

data.environment.id
环境唯一标识符
name string | 环境名称
data.environment.name
环境名称，用于用户识别和管理
type string | 对象类型
data.environment.type
对象类型，固定为 environment
updated_at string | 更新时间
data.environment.updated_at
更新时间，ISO 8601 格式
config object | 环境配置
data.environment.config
环境运行配置，包含运行类型、网络策略、依赖包与环境变量
type string | 环境类型
data.environment.config.type
运行环境类型： cloud 平台托管的云端 sandbox、 self_hosted 用户自托管环境
env object | 环境变量
data.environment.config.env

networking object | 出网策略
data.environment.config.networking
容器出网策略配置

setup_script string | 启动脚本
data.environment.config.setup_script
沙箱启动阶段执行的初始化脚本；留空或未设置表示不执行任何脚本
tos object | 产物存储配置
data.environment.config.tos
智能体产物持久化存储配置。为空表示未配置用户 Bucket，产物落到方舟公共 TOS
bucket string | TOS 桶

智能体产物存放在用户 Bucket 内的对象前缀。运行时最终对象 key 形如 {prefix}outputs/{env-id}/{session-id}/
{file}
description string | 环境描述

用户自定义元数据

会话绑定的保管库 ID 列表，智能体可访问其中的凭据
next_page string | 下一页游标
下一页 opaque cursor，作为 page 参数传入以获取下一页；无更多数据时为空
