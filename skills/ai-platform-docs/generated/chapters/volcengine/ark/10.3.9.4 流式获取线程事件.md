10.3.9.4 流式获取线程事件
GET https://ark.cn-beijing.volces.com/api/v3/sessions/{sessionId}/threads/{threadId}/stream通过 SSE（Server-Sent Events）协议流式订阅指定线程内实时产生的事件，仅返回该线程相关的事件。适合子智能体 / 多线程场景下单独监听某个线程的执行状态。所有事件的结构定义请参考 会话事件结构参考 。
说明
不支持历史回放：订阅建立成功后只会收到此后产生的事件。断线重连后想补漏需要调用 获取线程事件列表 ，通过时间窗口拉取历史事件。
建立连接后，服务端先发送 SSE 注释行 : ready 。线程进入 idle 不会自动关闭连接；客户端不再监听时需要主动断开。
服务端会周期性发送 SSE 心跳注释行（ : heartbeat ）避免连接被中间代理超时切断；客户端按SSE 协议忽略以 : 开头的注释行即可。
若指定的 thread_id 在会话中不存在，服务端会直接返回 4xx 错误而不建立订阅。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
sessionId string 必选 | 会话 ID
会话 ID，格式为 sesn- 开头的字符串
threadId string 必选 | 线程 ID
线程 ID，格式为 sthr- 开头的字符串
响应参数
SSE 流式响应，每个事件为一个 SessionEvent 对象，仅包含当前线程相关事件
data string | 事件 JSON 数据
公共字段包括 id 、 type 和 processed_at ；部分事件还会携带 session_thread_id ，其他字段随 type不同。
event string | SSE 事件类型
SSE 事件类型，固定为 message 。服务端不显式返回 event: 行；请通过 data.type 区分具体的业务事件。
