15.13.4 查询大语言模型效果问题结果
POST https://ark.cn-beijing.volcengineapi.com/?Action=CasePlatformV1SeedBadcaseQuery&Version=2024-01-01根据 Instance ID 查询方舟大语言模型效果问题（Seed Badcase）的处理状态与鉴定结果。本接口同时支持通过 Access Key 和方舟 API Key 两种方式鉴权。
关于 AssetIssues
多模态素材（图片、音视频等）会在受理后由后台异步搬运；搬运过程中若出现失败会写入 AssetIssues[] ，通过本接口返回。
40020/40021/40022/40023 为客户数据侧问题（URL 拉取失败、base64 解码失败、file_id 不存在或已过期、素材超大等），需上报方修正后重新提交。
50010 为平台侧存储失败（非客户数据问题），可稍后重新提交。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
【推荐】API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
【可选】Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。
请求参数
Body 参数
InstanceId string[] 必选 | Case ID 列表
待查询的 instance id，来自上报接口的返回值。原名 CaseId ，仍兼容。
注意
单次请求 InstanceId 数量去重后为 1 ~ 50。
响应参数
Total integer | case 总数
提交的 case id 总数，等于去重前解析出的 CaseId 数量。
Accepted object[] | 受理列表
命中且归属当前账号的 case id 列表，返回上报快照与处理结果。
InstanceId string | Case ID
Accepted.InstanceId
查询的 case id。
Status string | 处理状态
Accepted.Status
处理状态。
processing ：排查中。
done ：已完成。
说明
状态为 processing 时， ProblemLabel 与 SolutionNote 尚未产出。
ApiType string | 接口类型
Accepted.ApiType
该条 case 对应的接口类型。
chat ：Chat Completions API。
responses ：Responses API。
AssetIssues object[] | 素材问题
Accepted.AssetIssues
未能转存到平台存储的多模态素材列表。
素材的原始引用仍会保留。异步产生，错误码含义参见错误码章节。
说明
错误码为 50010 的条目可重试。
Code integer | 错误码
Accepted.AssetIssues.Code
素材处理的错误码，含义参见错误码章节。
Message string | 错误说明
Accepted.AssetIssues.Message
素材未能转存的原因说明。
BadcaseType string[] | 问题类型
Accepted.BadcaseType
上报时选择的 Badcase 类型标识列表。
Feedback string | 问题描述
Accepted.Feedback
上报时填写的效果问题描述。
Model string | 模型名称
Accepted.Model
上报时记录的模型名称。
ProblemLabel string | 问题标签
Accepted.ProblemLabel
排查后归类的问题标签，处理完成后返回。
SolutionNote object | 解决方案
Accepted.SolutionNote
解决方案说明，处理完成后返回，包含说明文本与附件。
Attachments object[] | 附件列表
Accepted.SolutionNote.Attachments
解决方案说明的附件列表，为图片或视频。
注意
附件链接为预签名链接，每次查询时重新生成，请勿长期保存。
MimeType string | MIME 类型
Accepted.SolutionNote.Attachments.MimeType
附件的 MIME 类型。
Name string | 附件名称
Accepted.SolutionNote.Attachments.Name
附件文件名。
Type string | 附件类型
Accepted.SolutionNote.Attachments.Type
附件的媒体类型。
Url string | 附件链接
Accepted.SolutionNote.Attachments.Url
附件的预签名下载链接。
Text string | 说明文本
Accepted.SolutionNote.Text
解决方案说明的文字内容。
SubmitTime string | 上报时间
Accepted.SubmitTime
上报时间，ISO 8601 格式的 UTC 时间。
Rejected object[] | 拒绝列表
未命中或不归属当前账号的 case id 列表。
Code integer | 错误码
Rejected.Code
业务错误码，含义参见错误码章节。
InstanceId string | Case ID
Rejected.InstanceId
查询的 case id。
Message string | 拒绝原因
Rejected.Message
未返回结果的原因说明。
