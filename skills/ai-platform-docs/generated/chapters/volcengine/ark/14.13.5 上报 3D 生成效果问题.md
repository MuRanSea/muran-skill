14.13.5 上报 3D 生成效果问题
POST https://prompt-pilot.cn-beijing.volces.com/case-platform?
Action=CasePlatformV1BadcaseReport&Version=2024-01-01
本接口用于上报 Seed3D 2.0 模型的 3D 生成效果问题，例如几何缺失、破面、贴图错位或与参考图不符。系统根据指定的 task_id 读取任务的输入参考图、生成参数和输出模型，创建 Badcase 记录，并保存问题描述和可选截图。支持通过 Access Key 或方舟 API Key 鉴权。
本文列出 3D 上报的参数要求。受理后通过 查询 3D 生成效果问题结果 查看排查状态、结论及截图保存结果。视频任务参见 上报视频生成模型效果问题 。
注意
本接口及文档仅支持中国大陆火山方舟服务，不支持非中国大陆地区（如 BytePlus 等）。前提条件
任务使用 Seed3D 2.0，已成功完成并产出 3D 模型。
任务须在 7 天内上报。本接口根据 task_id 向上游查询原始任务数据，超过上报窗口后可能无法读取。请在生成完成后尽早提交。
凭证与任务属于同一火山引擎账号。
每个任务只能上报一次，请在提交前准备完整的描述和截图。
问题截图的源链接须在提交后至少 24 小时内保持可访问，以便平台异步下载。该要求与 3D 任务的上报窗口分别计算。
生成失败、被拦截或没有产出模型的任务，请通过火山引擎工单反馈。尚在生成中的任务，须等待生成完成后再上报。
请求头
使用方舟 API Key 时，请设置 Authorization: Bearer <API_KEY> 和 Content-Type: application/json ，请求体可省略 AccountId 。
使用 AK/SK 时，请设置 V4 签名所需的 Authorization 、 X-Date 和 X-Content-Sha256 。签名的 Service为 ark ， Region 为 cn-beijing ，请求体须包含 AccountId 。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
【推荐】API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
【可选】Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。
请求参数
Query 参数
在 URL Query String 中传入。
Action string 必选 | 接口名称，固定为 CasePlatformV1BadcaseReport
Version string 必选 | 接口版本，固定为 2024-01-01
Body 参数
Feedback string 必选 | 问题描述
3D 模型的效果问题描述，长度为 1 至 2000 个字符，不能仅包含空白字符。同一请求中的所有任务共用此描述。建议说明期望效果、实际问题、观察角度和使用的查看工具。3D 任务必须填写本字段，不能用 TimelineFeedbacks 替代。
Id string / string[] 必选 | 任务 ID 列表
待上报的任务 ID，支持单个字符串或字符串数组。服务端按半角逗号、全角逗号、换行、空格或制表符拆分，并移除首尾空白和空项。
拆分后的任务数量须为 1 至 50，否则返回 HTTP 422 、错误码 40011 。同一请求中的任务共用 Feedback 和 FeedbackImages 。
AccountId string | 火山引擎账号 ID
Id 中任务所属的火山引擎账号 ID。
使用 Access Key 调用时必填。
使用方舟 API Key 调用时可省略，系统根据 API Key 解析账号 ID。
ContactInfo string | 联系方式
提交人的联系方式，支持电子邮箱地址或电话号码，最多 255 个字符。建议填写，便于处理人员联系您补充信息。
FeedbackImages object[] | 问题截图
可选的问题截图，最多 5 张，同一请求中的所有任务共用。平台受理后异步下载，失败不影响 Case 建立，也不会自动重试。通过 查询 3D 生成效果问题结果 查看每张截图的下载状态和失败原因。Url string 必选 | 截图地址
FeedbackImages.Url
须使用公网可直接访问的 HTTPS 图片直链，不需要登录，不指向内网或私有地址，重定向不超过 3 次。不要提交网页、3D 模型文件、 tos:// 路径或 data: 内联图片。
支持 PNG、JPEG、WebP，以实际文件内容判断，每张不超过 10 MB。上报后至少 24 小时内保持可访问；单张下载时限为 60 秒。
错误码
请求级错误位于 ResponseMetadata.Error ；HTTP 200 时仍须检查 Result.Accepted 和 Result.Rejected ，不能仅凭 HTTP 状态码判断每个任务上报成功。
