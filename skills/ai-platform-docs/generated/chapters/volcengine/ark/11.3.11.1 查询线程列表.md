11.3.11 会话线程
11.3.11.1 查询线程列表
GET https://ark.cn-beijing.volces.com/api/v3/sessions/{session_id}/threads
分页查询指定会话下的主线程和子线程。会话开始执行后才会有主线程；智能体每委派一个子任务，就会新增一个子线程。
主线程排在最前，子线程按创建时间正序返回。
说明
新建会话在尚未开始处理任何事件时，线程列表可能为空。
支持动态 Subagent 的会话会返回平台记录的线程信息。历史会话没有单独的线程记录，接口会根据已有事件还原出线程列表和状态。
本接口仅支持 limit 和 page 分页，不支持按状态、智能体或父线程筛选，也不支持反转排序。单次最多返回 1000 条。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
session_id string 必选 | 会话 ID
会话 ID，形如 sesn-...
Query 参数
在 URL Query String 中传入。
limit integer 默认值 1000 | 每页线程数
每页返回的线程数量，有效取值范围为 0～1000。
说明
省略 limit 或传入 0 时，按 1000 处理；传入大于 1000 的整数时，按 1000 处理。负数或无法解析为整数的值会返回参数错误。
最小值： 0
page string | 下一页标识
下一页标识。请将上一页响应中的 next_page 原样传入；不传则从第一页开始
响应参数
data object[] | 线程列表
线程列表。新建会话在尚未开始处理任何事件时可能返回空数组；首次执行开始后才会返回主线程agent_name string | 智能体名称
data.agent_name
线程关联的智能体名称
created_at string | 创建时间
data.created_at
线程创建时间，采用 RFC 3339 格式。历史会话中，该值表示首次观察到线程的时间。
id string | 线程 ID
data.id
线程唯一标识符，形如 sthr-...
parent_thread_id string / null | 父线程 ID
data.parent_thread_id
子线程的父线程 ID；主线程不返回该字段。
session_id string | 会话 ID
data.session_id
所属会话 ID，形如 sesn-...
status string | 线程状态
data.status
线程状态：
可继续处理的状态：
running ：智能体正在处理当前工作
idle ：当前工作已暂停或结束，可以继续向该线程派发任务
重试或终态：
rescheduling ：正在从临时错误中自动恢复
archived ：会话归档后，其子线程进入该状态；不能再接收任务，但仍可查询
terminated ：线程已终止，不能再接收任何输入；历史协作模式的会话按事件还原线程时会出现该状态
unknown ：当前事件不足以确定线程状态，需要结合线程事件继续排查
不提供单独归档或删除线程的公开 API； archived 、 terminated 或 unknown 线程仍可能出现在列表中。
type string | 对象类型
data.type
对象类型，固定为 session_thread
updated_at string | 更新时间
data.updated_at
线程信息最近更新时间，采用 RFC 3339 格式。
stats object | 线程时长统计
data.stats
Thread 的运行时长统计。
active_seconds number | 活跃时长
data.stats.active_seconds
Thread 处于 running 状态的累计时长，单位为秒。
duration_seconds number | 总时长
data.stats.duration_seconds
Thread 从创建到当前或终止时的总时长，单位为秒。
startup_seconds number | 启动时长
data.stats.startup_seconds
会话主线程从创建到首次进入 running 的准备时长，单位为秒；子 Agent 线程返回 0。
usage object | 线程用量
data.usage
Thread 累计的模型和服务端工具用量。
active_seconds number | 活跃时长
data.usage.active_seconds
Thread 处于 running 状态的累计时长，单位为秒。
cache_read_input_tokens integer | 缓存读取 token 数
data.usage.cache_read_input_tokens
Thread 累计从缓存读取的输入 token 数。
input_tokens integer | 输入 token 数
data.usage.input_tokens
Thread 累计消耗的输入 token 数。
output_tokens integer | 输出 token 数
data.usage.output_tokens
Thread 累计生成的输出 token 数。
cache_creation object | 缓存创建统计
data.usage.cache_creation
缓存创建输入 token 统计。
ephemeral_1h_input_tokens integer | 1 小时缓存输入 token 数
data.usage.cache_creation.ephemeral_1h_input_tokens
1 小时缓存创建使用的输入 token 数。
ephemeral_5m_input_tokens integer | 5 分钟缓存输入 token 数
data.usage.cache_creation.ephemeral_5m_input_tokens
5 分钟缓存创建使用的输入 token 数。
server_tool_use object | 服务端工具用量
data.usage.server_tool_use
Thread 累计调用服务端工具的次数。
general_search_requests integer | 通用搜索次数
data.usage.server_tool_use.general_search_requests
general_search 工具调用次数。
visual_search_requests integer | 视觉搜索次数
data.usage.server_tool_use.visual_search_requests
visual_search 工具调用次数。
web_fetch_requests integer | 网页读取次数
data.usage.server_tool_use.web_fetch_requests
web_fetch 工具调用次数。
web_search_requests integer | 网页搜索次数
data.usage.server_tool_use.web_search_requests
web_search 工具调用次数。
next_page string | 下一页标识
下一页标识。若为空或字段不返回，表示已到最后一页
