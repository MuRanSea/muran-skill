10.6.4 设置技能内容保护
POST https://ark.cn-beijing.volces.com/api/v3/skills/{id}
设置是否对自定义技能开启内容保护。启用内容保护后，运行技能时，方舟平台会注入保护指令，降低技能内容被直接输出的风险。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
id string 必选 | 技能 ID
用于指定要更新的技能。
Body 参数
protection_enabled boolean | 内容保护开关
用于控制是否为技能启用内容保护。设置为 true 后，运行技能时，方舟平台会注入保护指令，降低技能内容被直接输出的风险。设置为 false 时，方舟平台不启用该保护。省略时，服务端沿用技能当前的内容保护设置，响应中的 protection_enabled 返回原值，且 updated_at 保持不变。
响应参数
created_at integer | 创建时间
表示技能的创建时间。
display_title string | 展示名称
表示技能的展示名称。服务端优先返回最新版本的展示名称。未配置时，服务端返回 SKILL.md 中的 name 。
id string | 技能 ID
用于唯一标识已更新的技能，值以 skill- 开头。
latest_version string | 最新版本
表示技能的最新版本号。
object string | 资源类型
用于标识响应对象的资源类型，固定为 skill 。
source string | 技能来源
表示技能来源，固定为 custom 。该值表示上传或导入的自定义技能。
updated_at integer | 更新时间
表示技能最后一次更新的时间。
description string | 技能描述
表示方舟平台从 SKILL.md 中解析出的技能描述。
name string | 技能名称
表示 SKILL.md 中定义的技能名称。
protection_enabled boolean | 内容保护开关
表示技能是否已启用内容保护。 true 表示运行技能时，方舟平台会注入保护指令，降低技能内容被直接输出的风险。 false 表示方舟平台未启用该保护。
