10.5.3 查询记忆库详情
GET https://ark.cn-beijing.volces.com/api/v3/memory_stores/{memoryStoreId}
查询指定记忆库的详细信息，包括基础配置、统计指标和自定义元数据。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
memoryStoreId string 必选 | 记忆库 ID
要查询的记忆库 ID。通过创建记忆库接口 (POST /memory_stores) 返回, 或通过查询记忆库列表接口 (GET /memory_stores) 获取。
响应参数
created_at string | 创建时间
创建时间，RFC 3339 UTC 毫秒格式
created_by object | 创建者
记忆库创建者信息
type string | 操作者类型
created_by.type
操作者类型，固定为 user_actor
user_id string | 用户 ID
created_by.user_id
操作者用户 ID
id string | 记忆库 ID
记忆库唯一标识符，格式为 memstore- 开头的小写 ULID
memory_count integer | 记忆条目数量
当前记忆库内的记忆条目数量
metadata object | 自定义元数据
用户自定义元数据，键值均为字符串；恒返回，缺省为空对象
name string | 记忆库名称
记忆库名称，用于用户识别和管理
session_count integer | 关联会话数
当前挂载该记忆库的活跃会话去重数
storage_bytes integer | 存储字节数
当前记忆库占用的存储字节数
type string | 对象类型
对象类型，固定为 memory_store
updated_at string | 更新时间
更新时间，RFC 3339 UTC 毫秒格式
description string | 记忆库描述
记忆库描述，说明记忆库的用途和适用场景；空串时省略
