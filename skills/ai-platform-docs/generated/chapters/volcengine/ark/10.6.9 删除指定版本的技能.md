10.6.9 删除指定版本的技能
DELETE https://ark.cn-beijing.volces.com/api/v3/skills/{skill_id}/versions/{version}删除当前账号中自定义技能的指定版本，不删除技能本身。
如果技能有多个版本，先删除所有非最新版本，再删除最后剩余的最新版本。仍有其他版本时删除最新版本会返回 HTTP 400 InvalidAction 。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
skill_id string 必选 | 技能 ID
用于指定要删除版本的技能。
version string 必选 | 版本号
用于指定要删除的版本号。
响应参数
id string | 版本 ID
用于标识已删除的版本。
type string | 删除结果类型
用于标识删除成功响应的资源类型，固定为 skill_version_deleted 。
