12.2.6.9 续费共享包
POST https://ark.cn-beijing.volcengineapi.com/?Action=RenewSharedPackage&Version=2024-01-01为 Agent Plan 企业版共享包续费。当前每次仅支持整体续费一个月，购买数量保持不变。您通过 API 接口发起部署请求或调用本服务的，即表示您已充分阅读、理解并同意 《火山方舟大模型订阅套餐服务专用条款》 、《豆包模型服务协议》 、《开源模型许可证》 、《Harness 能力说明和产品专用条款》 及其他适用的平台规则。如您不同意上述协议，请立即停止调用。使用说明
使用 创建共享包 或 查询共享包订阅信息 返回的 InstanceID 发起续费。
当前仅支持按共享包的购买数量整体续费，不支持调整购买数量或部分续费。
续费仅延长订阅有效期，不增加当前生效周期的 AFP 额度。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Duration integer 必选 | 续费时长
本次续费增加的订阅时长，单位为月。当前每次仅支持续费一个月。
取值固定为 1 。
InstanceID string 必选 | 订阅实例 ID
待续费的共享包订阅实例 ID，不是共享包 ID。
注意
不能传入空字符串或仅包含空白字符的字符串。
PricingCycle string 必选 | 计费周期
共享包续费的计费周期，当前仅支持 Month 。
AutoPay boolean 默认值 false | 自动支付
是否自动支付续费订单。
true ：自动支付续费订单。
false ：提交续费订单后，等待手动支付。
DryRun boolean 默认值 false | 预检模式
是否仅执行交易预校验。
true ：仅校验，不生成续费订单。
false ：提交续费订单。
响应参数
InstanceID string | 订阅实例 ID
本次续费请求对应的共享包订阅实例 ID。
NeedPay boolean | 待支付状态
是否仍需调用方完成支付。
true ：需要继续支付续费订单。
false ：无需继续支付。
OrderNumber string | 订单号
续费订单的正式订单号。 NeedPay 为 false 且有订单号时返回。
将 DryRun 设置为 true 时，不返回此字段。
PreOrderNumbers string | 预订单号
续费订单的预订单号。 NeedPay 为 true 且有预订单号时返回。
将 DryRun 设置为 true 时，不返回此字段。
