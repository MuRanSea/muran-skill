10.4.6 凭证管理
10.4.6.1 创建凭证
POST https://ark.cn-beijing.volces.com/api/v3/vaults/{vault_id}/credentials
在指定保管库中创建一条凭证。auth 按 type 选择字段：mcp_oauth（MCP OAuth，用于 MCP Server 授权）、static_bearer（静态 Bearer 令牌）、mcp_static（MCP 静态凭证，支持 bearer / header / query 三种注入方式）、environment_variable（环境变量注入，用于 CLI/OpenAPI 场景）。所有密文字段（access_token / token / secret_value / refresh_token / client_secret）一律 write-only——写入时接受，响应中永不返回。
mcp_static 与 static_bearer 长期并存、不做转换： mcp_static 是通用静态凭证，通过 injection_type 选择 bearer / header / query 三种注入方式； static_bearer 语义等价于 mcp_static + injection_type=bearer ，但两种类型在 wire、DB、运行面全程并存，各自保持字面值。同一保管库内 mcp_server_url 对mcp_oauth / static_bearer / mcp_static 三种类型活跃唯一，重复创建返回 409。
environment_variable 类型的凭证在 Egress 层做替换：Token 不进入沙箱，运行时通过环境变量名（secret_name）匹配后由网关注入到出向请求，并按 networking.allowed_hosts 白名单约束替换范围。鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。

injection_type string 必选 | 注入方式
auth.injection_type
密钥注入到出向 MCP 请求的方式。 bearer 使用 Authorization: Bearer <token> 且禁传 injection_name ；header 使用用户指定的自定义 Header 名（ injection_name 必填）； query 使用用户指定的 URL query参数名（ injection_name 必填）
mcp_server_url string 必选 | MCP 服务器 URL
auth.mcp_server_url
MCP 服务器 URL，创建后不可修改
token string 必选 | 密钥值
auth.token
静态密钥值，write-only（响应不返回）。不包含 Bearer 前缀， injection_type=bearer 时由服务端统一拼接 Authorization: Bearer <token>
type string 必选 | 鉴权类型
auth.type
MCP 静态凭证类型，固定为 mcp_static 。通用静态凭证，通过 injection_type 选择三种密钥注入方式；语义上等价于 static_bearer + injection_type=bearer ，但两种类型在 wire、DB、运行面全程并存，不做字面转换
injection_name string | 注入名
auth.injection_name
自定义 Header 名或 query 参数名。 injection_type=header 时必填，Header 名须符合 HTTP token 规则，禁止覆盖 Host / Content-Length / Cookie / Proxy-Authorization 等受限 Header； injection_type=query 时必填，须为单个参数名，不允许包含 ? / & / = ； injection_type=bearer 时禁传
