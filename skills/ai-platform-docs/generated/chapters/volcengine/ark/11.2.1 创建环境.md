11.2 Environments
11.2.1 创建环境
POST https://ark.cn-beijing.volces.com/api/v3/environments
创建一个新的 Environment，用于承载托管智能体运行时的环境配置（网络策略、预装依赖、环境变量、产物存储等）。
说明
Environment 挂载到智能体后，运行时可使用已配置的依赖包（如通过 pip 安装的 Python 包）与文件系统；具体挂载路径由平台管理。
说明
在 config.tos 中配置 bucket 与 prefix ，可将 outputs/ 目录中的智能体产物存储到用户自有TOS Bucket，避免受方舟默认存储保留期限的影响。该配置在会话创建时保存到会话的
Environment 快照，之后修改 Environment 不会影响已有会话。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Body 参数
name string 必选 | 环境名称
环境名称，用于用户识别和管理
config object | 环境配置
环境运行配置，按 type 区分 cloud 或 self_hosted
type string 必选 | 环境类型
config.type
运行环境类型： cloud 平台托管的云端 sandbox、 self_hosted 用户自托管环境
env object | 环境变量
config.env
注入到 sandbox 进程的环境变量键值对。环境变量 key 禁止使用 ARK_* / VOLC_* 保留前缀，否则返回 InvalidParameter 错误。
networking object | 出网策略
config.networking
容器出网策略配置
type string 必选 | 出网策略类型
config.networking.type
出网模式： unrestricted 不限制（其它字段不生效）、 limited 受限（配合 allowed_hosts 白名单）allow_mcp_servers boolean | 允许 MCP
config.networking.allow_mcp_servers
limited 模式下是否允许访问 MCP servers
allow_package_managers boolean | 允许包管理器
config.networking.allow_package_managers
limited 模式下是否允许包管理器（pip / npm / apt 等）访问其官方源
allowed_hosts string[] | 主机白名单
config.networking.allowed_hosts
limited 模式下允许出网的域名/IP 白名单；未设置时仅由 allow_mcp_servers 和 allow_package_managers控制，设置后与两者叠加生效
packages object | 依赖包配置
config.packages
启动时预装的依赖包配置
apt string[] | apt 包
config.packages.apt
apt 安装的系统包
cargo string[] | cargo 包
config.packages.cargo
cargo 安装的 Rust crate
gem string[] | gem 包
config.packages.gem
RubyGems 安装的 Ruby 包
go string[] | go 包
config.packages.go
Go module 依赖
npm string[] | npm 包
config.packages.npm
npm 安装的 Node.js 包
pip string[] | pip 包
config.packages.pip
pip 安装的 Python 包（如 ["numpy", "pandas==2.0.0"] ）
type string | 配置类型
config.packages.type
依赖包配置类型，固定为 packages
setup_script string | 启动脚本
config.setup_script
沙箱启动阶段执行的初始化脚本，字符串形态直接透传给 sandbox init；留空 / 未设置表示不执行任何脚本
tos object | 产物存储配置
config.tos
智能体产物（ outputs/ ）持久化存储配置
说明
省略 tos 时，智能体产物使用方舟默认存储，文件保留期限以平台策略为准。
配置 tos 后， outputs/ 目录中的产物存储到 {prefix}outputs/{env-id}/{session-id}/ 。Bucket 必须与当前方舟 API 接入地域一致，否则请求会被拒绝。
必须同时提供 bucket 和 prefix ；不允许传空对象 {} ，仅提供其中一个字段也会被拒绝。删除 Session 不会清理用户 Bucket 中的产物，您需要自行管理这些产物的生命周期。
该配置在创建会话时保存到 Session.environment 快照；后续更新 Environment 不会影响已有会话，需要重新创建会话才能使用新配置。
bucket string | TOS 桶
config.tos.bucket
用户 TOS 存储桶名称。Bucket 必须与当前方舟 API 接入地域一致，否则请求会被拒绝。
prefix string | 对象前缀
config.tos.prefix
智能体产物存放在用户 Bucket 内的对象前缀。运行时最终对象 key 形如 {prefix}outputs/{env-id}/{session-id}/
{file}
