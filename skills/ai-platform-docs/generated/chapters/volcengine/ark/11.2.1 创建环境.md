11.2 Environments
11.2.1 创建环境
POST https://ark.cn-beijing.volces.com/api/v3/environments
创建 Environment，用于配置托管智能体的运行环境。创建成功后，可在创建 Session 时通过返回的Environment ID 引用该环境。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Body 参数
config object 必选 | 环境配置
定义 Environment 的运行方式和启动配置。
说明
创建 cloud 环境时，必须提供 networking ，且 networking.type 当前只能设为 unrestricted 。创建 self_hosted 环境时，只能提供 type 。
type string 必选 | 环境类型
config.type
Environment 的运行方式。 cloud 表示由火山方舟提供运行环境， self_hosted 表示由调用方提供运行环境。
env object | 环境变量
config.env
Environment 运行时使用的环境变量，以变量名和变量值组成的字符串键值对形式传入。
说明
最多包含 64 个键值对，所有键和值合计不超过 32 KiB。键不能为空且不能包含 = 或 NUL 字符，值不能包含 NUL 字符。
networking object | 出网策略
config.networking
Environment 的出网配置。
type string 必选 | 出网策略类型
config.networking.type
Environment 的出网方式。 unrestricted 表示不限制出网目标。
packages object | 依赖包配置
config.packages
Environment 启动时预装的依赖包。
说明
每个依赖包名称去除首尾空白后不能为空，不能包含 NUL 字符，也不能以连字符开头。
apt string[] | apt 包
config.packages.apt
Environment 启动时通过 apt 预装的系统包。
cargo string[] | Cargo 包
config.packages.cargo
Environment 启动时通过 Cargo 预装的 Rust crate。
gem string[] | gem 包
config.packages.gem
Environment 启动时通过 RubyGems 预装的 Ruby 包。
go string[] | go 包
config.packages.go
Environment 启动时通过 Go 工具链预装的模块依赖。
npm string[] | npm 包
config.packages.npm
Environment 启动时通过 npm 预装的 Node.js 包。
pip string[] | pip 包
config.packages.pip
Environment 启动时通过 pip 预装的 Python 包。
type string | 配置类型
config.packages.type
依赖包配置的类型标识。
取值固定为 packages 。
setup_script string | 启动脚本
config.setup_script
Environment 启动时执行的初始化脚本。
tos object | 产物存储配置
config.tos
指定智能体产物的持久化存储位置。
说明
省略 tos 时，智能体产物存储于火山方舟默认存储。默认存储中的文件仅临时保留，请在平台 TTL 到期前下载；需要长期保存时，配置自己的 TOS Bucket 并自行管理对象生命周期。配置 tos 时，必须同时提供 bucket 和 prefix 。
bucket 长度为 3～63 字节，仅支持小写字母、数字和连字符，首尾必须是小写字母或数字。prefix 最长 512 字节，必须是相对目录，不能包含反斜杠、控制字符、空路径段、 . 或 ..路径段。
保存配置前，服务端会检查 Bucket 与 Prefix 已存在、Bucket 与当前 API 接入地域一致，并且方舟访问该 Bucket 的角色具有读写权限。
配置 tos 后，平台从 outputs 目录注册产物时，会以 {prefix}outputs/{env-id}/{session-id}/ 作为Files API 写入前缀。最终对象路径以 Files API 响应中的 tos.object_key 为准，通常还会包含 ark_processed/{file_id}/{file_type}/{filename} 。
直接调用 Files API 并传入 tos[prefix] 时，不会追加 Environment ID 或 Session ID，但 Files API仍会在该前缀下生成服务侧处理目录。该规则也不表示 resources 中 type: tos 的沙箱挂载目录。
bucket string | TOS 桶
config.tos.bucket
存储智能体产物的 TOS Bucket 名称。
prefix string | 对象前缀
config.tos.prefix
智能体产物在 TOS Bucket 内的基础目录前缀。平台注册 outputs 产物时，会以 {prefix}outputs/{env-id}/
{session-id}/ 作为 Files API 写入前缀。
最终对象路径以 Files API 响应中的 tos.object_key 为准，通常还会包含 ark_processed/{file_id}/{file_type}/
{filename} 。
name string 必选 | 环境名称
Environment 的名称，用于在当前项目中识别和管理该环境。
说明
名称长度为 3～64 个字符，仅支持小写字母、数字、点、下划线和连字符，且必须以小写字母或数字开头。同一项目内不能重名。
description string | 环境描述
用于说明 Environment 的用途，最长 300 个字符。
metadata object | 自定义元数据
用于记录 Environment 的业务属性，以字符串键值对形式传入，便于关联和管理资源。
说明
最多包含 16 个键值对。键最长 64 个字符，值最长 512 个字符。
响应参数
created_at string | 创建时间
Environment 创建时间，采用 RFC 3339 格式的 UTC 时间。
id string | 环境 ID
Environment ID，由服务端生成，以 env- 开头。
name string | 环境名称
Environment 的名称。
type string | 对象类型
对象类型，固定为 environment 。
updated_at string | 更新时间
Environment 最后更新时间，采用 RFC 3339 格式的 UTC 时间。
config object | 环境配置
Environment 当前生效的运行配置。
type string | 环境类型
config.type
Environment 的运行方式。 cloud 表示由火山方舟提供运行环境， self_hosted 表示由调用方提供运行环境。
env object | 环境变量
config.env
Environment 运行时使用的环境变量，以字符串键值对形式返回。
networking object | 出网策略
config.networking
Environment 当前生效的出网配置。对于 self_hosted Environment，服务端固定返回 type 为 unrestricted 。
type string | 出网策略类型
config.networking.type
Environment 的出网方式。 unrestricted 表示不限制出网目标。
packages object | 依赖包配置
config.packages
Environment 启动时预装的依赖包。
apt string[] | apt 包
config.packages.apt
Environment 启动时通过 apt 预装的系统包。
cargo string[] | Cargo 包
config.packages.cargo
Environment 启动时通过 Cargo 预装的 Rust crate。
gem string[] | gem 包
config.packages.gem
Environment 启动时通过 RubyGems 预装的 Ruby 包。
go string[] | go 包
config.packages.go

npm string[] | npm 包
config.packages.npm
Environment 启动时通过 npm 预装的 Node.js 包。
pip string[] | pip 包
config.packages.pip
Environment 启动时通过 pip 预装的 Python 包。
type string | 配置类型
config.packages.type
依赖包配置的类型标识。
取值固定为 packages 。
setup_script string | 启动脚本
config.setup_script
Environment 启动时执行的初始化脚本。
tos object | 产物存储配置
