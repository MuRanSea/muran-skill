14.4 管理模型开通
14.4.1 批量开通基础模型
POST https://ark.cn-beijing.volcengineapi.com/?Action=ActivateModels&Version=2024-01-01批量开通指定的基础模型，使其可用于推理调用。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
FoundationModelNames string[] 必选 | 基础模型名称列表
需要开通的基础模型名称列表。
