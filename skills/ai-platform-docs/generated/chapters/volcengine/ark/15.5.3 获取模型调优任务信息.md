15.5.3 获取模型调优任务信息
POST https://ark.cn-beijing.volcengineapi.com/?Action=GetModelCustomizationJob&Version=2024-01-01获取模型训练任务信息
说明
Status.Phase 反映任务当前阶段，常见取值包括 Queue （排队中）、 Running （运行中）、Completed （已完成）、 Failed （失败）、 Cancelled （已取消）等。
失败任务可通过 Status.Resumable 判断是否可恢复；若为 true ，可调用 
ResumeModelCustomizationJob 接口重试。
Outputs 数组按训练 Checkpoint 顺序列出产物；状态为 Available 的产物可发布为定制模型，Exported 表示已发布， Expired 表示已过期。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
