10.4.6.3 查询凭证详情
GET https://ark.cn-beijing.volces.com/api/v3/vaults/{vault_id}/credentials/{credential_id}根据凭证 ID 获取凭证的详细元信息。接口不返回任何密文字段（access_token / token / secret_value /refresh_token / client_secret）。
响应 auth.type 字段忠实回显 DB 原值：老 static_bearer 凭证回显 static_bearer 、新 mcp_static 凭证回显 mcp_static ，服务端不做归一化转换。 mcp_static 类型额外回显 injection_type ；injection_type=header 或 query 时回显 injection_name ， bearer 时 injection_name 不回显。对于 environment_variable 类型凭证，响应仅包含 secret_name 与 networking 网络范围配置，secret_value 不返回。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
