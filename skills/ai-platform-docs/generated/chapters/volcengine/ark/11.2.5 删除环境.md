11.2.5 删除环境
DELETE https://ark.cn-beijing.volces.com/api/v3/environments/{environmentId}
永久删除指定的环境，删除后环境不可恢复。请先确认没有会话仍绑定该环境。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
environmentId string 必选 | 环境 ID
要删除的环境 ID。通过创建环境接口 (POST /environments) 返回, 或在控制台环境管理页面获取。响应参数
id string | 环境 ID
被删除的环境 ID
type string | 对象类型
对象类型，固定为 environment_deleted
