14.10.7 停止评测任务
POST https://ark.cn-beijing.volcengineapi.com/?Action=TerminateEvaluationJob&Version=2024-01-01停止指定的模型评测任务。调用本接口可以终止一个正在运行中的模型评测任务，任务停止后不可恢复运行；如需重新评测，请通过 创建评测任务 重新创建任务。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 评测任务 ID
待停止的模型评测任务 ID。可在控制台评测任务列表页获取，或通过 ListEvaluationJobs 接口查询。DryRun boolean 默认值 false | 是否仅做预检
是否仅对此请求进行预检：
true ：仅做参数与权限校验，不会真正停止任务。
false ：发送正常请求，停止评测任务。
