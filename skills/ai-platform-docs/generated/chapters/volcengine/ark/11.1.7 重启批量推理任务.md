11.1.7 重启批量推理任务
POST https://ark.cn-beijing.volcengineapi.com/?Action=ResumeBatchInferenceJob&Version=2024-01-01重启一个已被终止（Terminated）或处于失败（Failed）状态的批量推理任务，将其重新拉起继续处理剩余请求。
说明
仅 Terminated 或 Failed 状态的任务可以被重启。重启后任务从已完成的进度继续处理剩余请求，已成功完成的请求不会重复推理。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 任务 ID
待重启的批量推理任务 ID。可通过 CreateBatchInferenceJob 接口创建任务时获取，或通过 ListBatchInferenceJobs 查询。
响应参数
Id string | 任务 ID
重启成功后返回的批量推理任务 ID，与请求中传入的 Id 一致。
