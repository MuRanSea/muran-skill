10.2.4 更新环境
POST https://ark.cn-beijing.volces.com/api/v3/environments/{environmentId}
更新指定 Environment。字段更新语义：
省略字段：保留原值不变
description 传 "" 或 null ：清空
config 嵌套字段同样按 patch 处理（ networking / packages 子字段省略即保留； env 整体替换）metadata 走 patch：key→value 表示 upsert；key→空字符串表示删除该 key
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
environmentId string 必选 | 环境 ID
要更新的环境 ID。通过创建环境接口 (POST /environments) 返回, 或在控制台环境管理页面获取。Body 参数
config object | 环境配置
环境运行配置，嵌套字段按 patch 处理
type string 必选 | 环境类型
config.type
运行环境类型： cloud 平台托管的云端 sandbox； self_hosted 用户自托管环境
env object | 环境变量
config.env
注入到 sandbox 进程的环境变量键值对，update 时替换。环境变量 key 禁止使用 ARK_* / VOLC_* 保留前缀，否则返回 InvalidParameter 错误。
networking object | 出网策略
config.networking
容器出网策略配置
type string 必选 | 出网策略类型
config.networking.type
出网策略类型： unrestricted 完全放行； limited 受限，仅放行白名单，可选配合 MCP Server / 包管理器allow_mcp_servers boolean | 允许 MCP
config.networking.allow_mcp_servers
limited 模式下是否允许访问 MCP Servers： true 允许访问； false 禁止访问。仅在 type=limited 时生效
allow_package_managers boolean | 允许包管理器
config.networking.allow_package_managers
limited 模式下是否允许包管理器（pip / npm / apt 等）访问其官方源： true 允许访问官方源； false禁止访问官方源。仅在 type=limited 时生效
allowed_hosts string[] | 主机白名单
config.networking.allowed_hosts
limited 模式下允许出网的域名 / IP 白名单；仅在 type=limited 时生效
packages object | 依赖包配置
config.packages
启动时预装的依赖包配置
apt string[] | apt 包
config.packages.apt
通过 apt 预装的系统包
cargo string[] | cargo 包
config.packages.cargo
通过 cargo 预装的 Rust crate
gem string[] | gem 包
config.packages.gem
通过 RubyGems 预装的 Ruby 包
go string[] | go 包
config.packages.go
通过 go 预装的 Go module
npm string[] | npm 包
config.packages.npm
通过 npm 预装的 Node.js 包
pip string[] | pip 包
config.packages.pip
通过 pip 预装的 Python 包，如 ["numpy", "pandas==2.0.0"]
type string | 配置类型
config.packages.type
依赖包配置类型标记，当前固定 packages
setup_script string | 启动脚本
config.setup_script
沙箱启动阶段执行的初始化脚本，字符串形态直接透传给 sandbox init；update 语义下整体替换（提供则替换，省略则保留 base）
tos object | 产物存储配置
config.tos
智能体产物（ outputs/ ）持久化存储配置。运行时按 {prefix}outputs/{env-id}/{session-id}/ 落到用户 Bucket说明
update 语义下 tos 是原子配置：省略 = 保留原有配置。
不允许传空对象 {} ； bucket 或 prefix 缺失时请求会被拒绝。
一旦提供非空 tos ， bucket 与 prefix 必须同时提供，仅提供其中一个会被拒绝。
不会追溯生效：更新 Environment 只影响新建会话；已存在会话的产物落位以创建时的
Environment 快照为准，需要重新创建会话才能切换到新的 Bucket / 前缀。
bucket string | TOS 桶
config.tos.bucket
用户 TOS 存储桶名称。名称必须匹配 ^[a-z0-9][a-z0-9-]*[a-z0-9]$ ，即仅包含小写字母、数字和短横线，且首尾不能为短横线。Bucket 必须与当前方舟 API 接入地域一致，否则请求会被拒绝。
prefix string | 对象前缀
config.tos.prefix
智能体产物存放在用户 Bucket 内的对象前缀。运行时最终对象 key 形如 {prefix}outputs/{env-id}/{session-id}/
{file}
description string | 环境描述
环境描述，传 "" 或 null 清空
metadata object | 自定义元数据
用户自定义元数据（patch）：key→value 表示 upsert；key→空字符串表示删除
name string | 环境名称
环境名称，用于用户识别和管理
scope string | 作用域
环境作用域。可选值： organization 、 account 。
响应参数
created_at string | 创建时间
创建时间，ISO 8601 格式
id string | 环境 ID
环境唯一标识符
name string | 环境名称
环境名称，用于用户识别和管理
type string | 对象类型
对象类型，固定为 environment
updated_at string | 更新时间
最后更新时间，ISO 8601 格式

config.type
