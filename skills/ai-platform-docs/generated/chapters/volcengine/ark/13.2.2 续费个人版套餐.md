13.2.2 续费个人版套餐
POST https://ark.cn-beijing.volcengineapi.com/?Action=RenewPersonalPlan&Version=2024-01-01续费个人版套餐
您通过 API 接口发起部署请求或调用本服务的，即表示您已充分阅读、理解并同意 《火山引擎数据授权协议》 、《方舟平台专用条款》 、《免责声明》 、《豆包模型服务协议》 、《开源模型许可证》 、《语音服务协议》 、《Harness能力说明和产品专用条款》 及其他适用的平台规则。如您不同意上述协议，请立即停止调用。
注意
自 2026 年 8 月 26 日起， RenewPersonalPlan 接口新增必填请求参数 AgreementAccepted ，用于确认调用方已阅读并同意当前 Plan 所适用的协议及条款。该参数仅支持传入 true 。未传入该参数时，将无法下单并返回参数缺失错误。 请您尽快完成接口适配，以避免影响套餐购买。
说明
接口为异步执行，自动扣费，下单前请确保云账户内余额充足。
调用 RenewPersonalPlan 提交续费请求后，订单存在异步处理或状态延迟情况。建议在调用 RenewPersonalPlan 接口续费个人版套餐后，通过 GetPersonalPlan 接口进行反查，以确认最终的续费结果。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
AgreementAccepted boolean 必选 | 协议确认
是否已阅读并同意当前 Plan 适用的协议及条款。该参数仅支持传入 true ；未传入时，将无法续费并返回参数缺失错误。
Duration number 必选 | 续费时长
续费时长，单位以 PricingCycle 为准。
取值范围： [1, 12]
Plan string 必选 | 商品名称
待续费的商品名称。可选值： AgentPlan 、 CodingPlan 。
PricingCycle string 必选 | 计费周期
计费周期。固定取值： Month 。
DryRun boolean 默认值 false | 预检模式
是否仅进行预检不下单。取值：
true ：仅校验请求
false （默认）：正式执行请求。
响应参数
本接口无特有的返回参数，成功时 HTTP 状态码为 200 ，返回结构中 Result 为空对象 {} 。
