10.5.5 删除记忆库
DELETE https://ark.cn-beijing.volces.com/api/v3/memory_stores/{memoryStoreId}
删除指定记忆库及其中的全部记忆条目。删除后不支持恢复；如需继续使用，需重新创建记忆库并写入内容。需要删除整个记忆库及全部记忆时使用本接口；仅删除一条记忆时，使用删除记忆条目接口。注意
即使记忆库已挂载到会话，也可以删除。删除后，相关会话将无法继续访问该记忆库及其中的记忆；删除前需确认业务影响。
说明
当记忆库不存在或当前账号、项目无权访问时，统一返回 404 InvalidMemoryStore.NotFound 。重复删除已不存在的记忆库时，可将该错误视为目标记忆库已不存在。请求路径参数无效时返回 400 InvalidParameter 。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
memoryStoreId string 必选 | 记忆库 ID
用于定位要删除的记忆库，以 memstore- 开头。传入创建或查询接口返回的完整 ID，不要自行拼接。响应参数
id string | 记忆库 ID
已删除的记忆库 ID，与请求中的 memoryStoreId 相同。
type string | 对象类型
对象类型，固定为 memory_store_deleted 。
