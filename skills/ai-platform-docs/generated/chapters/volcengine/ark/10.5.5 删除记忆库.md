10.5.5 删除记忆库
DELETE https://ark.cn-beijing.volces.com/api/v3/memory_stores/{memoryStoreId}
永久删除指定的记忆库，连同其下所有记忆条目及内部版本一并删除，不可恢复。请谨慎操作。鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
memoryStoreId string 必选 | 记忆库 ID
要删除的记忆库 ID。通过创建记忆库接口 (POST /memory_stores) 返回, 或通过查询记忆库列表接口 (GET /memory_stores) 获取。
响应参数
id string | 记忆库 ID
被删除的记忆库 ID
type string | 对象类型
对象类型，固定为 memory_store_deleted
