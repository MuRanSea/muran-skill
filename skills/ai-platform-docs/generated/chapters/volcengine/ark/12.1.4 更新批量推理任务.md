12.1.4 更新批量推理任务
POST https://ark.cn-beijing.volcengineapi.com/?Action=UpdateBatchInferenceJob&Version=2024-01-01更新批量推理任务的名称或描述信息。
说明
更新接口仅支持修改 Name 与 Description。任务的模型引用、输入输出位置、最大等待时间等关键参数在创建后不可变更。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 任务 ID
待更新的批量推理任务 ID。
Description string | 任务描述
批量推理任务的描述信息。
DryRun boolean 默认值 false | 预检请求
是否仅对此请求进行预检。 true 表示发送检查请求； false 表示发送正常请求，执行更新操作。Name string | 任务名称
批量推理任务名称。
