10.3.8.3 查询会话资源
GET https://ark.cn-beijing.volces.com/api/v3/sessions/{session_id}/resources/{resource_id}按 session_id 和 resource_id 查询单个已挂载资源。响应字段随 type 变化； file 资源的后续引用请以查询返回的 file_id 为准。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
resource_id string 必选 | 资源 ID
会话资源 ID，形如 sesrsc-... ，可从添加资源或资源列表响应的 id 字段获得
session_id string 必选 | 会话 ID
填写资源所属的会话 ID，形如 sesn-...
响应参数
资源详情
