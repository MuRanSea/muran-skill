15.11.3 获取方舟官方产物确认结果
POST https://ark.cn-beijing.volcengineapi.com/?Action=GetArkOfficialResult&Version=2024-01-01根据查询 ID 获取方舟官方结果鉴定的最终结论，包括是否为官方产出、模型名称等信息。鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
QueryID string 必选 | 查询 ID
创建官方鉴定查询时返回的查询 ID。
响应参数
IsOfficial string | 是否官方产出
鉴定结论，标识内容是否为官方产出。
Message string | 附加消息
鉴定结果的附加消息说明。
ModelName string | 模型名称
生成该内容所使用的模型名称。
QueryID string | 查询 ID
本次鉴定查询的唯一 ID。
Resolution string | 分辨率
鉴定内容的分辨率信息。
ResourceType string | 资源类型
鉴定内容的资源类型。
Size string | 文件大小
鉴定内容的文件大小。
Status string | 查询状态
鉴定查询的当前状态。
