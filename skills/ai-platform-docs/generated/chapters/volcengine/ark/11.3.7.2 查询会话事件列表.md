11.3.7.2 查询会话事件列表
GET https://ark.cn-beijing.volces.com/api/v3/sessions/{sessionId}/events
分页查询会话的历史事件列表，支持按时间范围、事件类型等条件过滤。返回的事件结构与流式接口一致，具体字段定义请参考 会话事件结构参考 。
说明
默认按事件产生时间正序返回（从旧到新）。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
sessionId string 必选 | 会话 ID
会话 ID，格式为 sesn- 开头的字符串
Query 参数
在 URL Query String 中传入。
created_at[gt] string | 起始时间（不含）
起始时间（不含），ISO 8601 / RFC3339 格式，仅返回该时间之后产生的事件。 created_at[gt] / created_at[gte] / created_at[lt] / created_at[lte] 四个边界至多用两个组成区间
created_at[gte] string | 起始时间（含）
起始时间（含），ISO 8601 / RFC3339 格式，仅返回该时间起（含）产生的事件。 created_at[gt] / created_at[gte] / created_at[lt] / created_at[lte] 四个边界至多用两个组成区间
created_at[lt] string | 结束时间（不含）
结束时间（不含），ISO 8601 / RFC3339 格式，仅返回该时间之前产生的事件。 created_at[gt] / created_at[gte] / created_at[lt] / created_at[lte] 四个边界至多用两个组成区间
created_at[lte] string | 结束时间（含）
结束时间（含），ISO 8601 / RFC3339 格式，仅返回该时间前（含）产生的事件。 created_at[gt] / created_at[gte] / created_at[lt] / created_at[lte] 四个边界至多用两个组成区间
limit integer 默认值 50 | 每页事件数
每页返回的事件数量。
说明
当 limit 大于 200 时，服务端会按 200 处理，不会返回参数错误。
取值范围： [1, 200]
order string 默认值 asc | 排序方向
排序方向， asc 按事件产生时间正序（从旧到新）， desc 倒序。
page string | 分页游标
分页游标（opaque cursor），传入上一页返回的 next_page 获取下一页
types string[] | 事件类型白名单
事件类型白名单，多个类型请使用数组传入，例如 types=user.message&types=agent.message响应参数
data object[] | 事件列表
事件列表，包含客户端发送事件与服务端推送事件（智能体域 agent.* / 会话域 session.* / Span 追踪 span.* ）。每个事件对象包含 id 、 type 、 processed_at 以及随 type 变化的业务字段；仅特定事件携带 session_thread_id 。完整事件类型与字段结构见 会话事件结构参考 。
id string | 事件 ID
data.id
事件唯一标识符
processed_at string | 处理时间
data.processed_at
事件处理时间，ISO 8601 格式
type string | 事件类型
data.type
事件类型（如 user.message 、 agent.message 、 session.status_idle 等）
session_thread_id string | 线程 ID
data.session_thread_id
事件所属线程 ID，仅特定事件类型（如 agent.tool_use 、 agent.mcp_tool_use 、 user.interrupt 等）携带，不属于固定公共字段；不属于任何线程时缺省
next_page string | 下一页游标
下一页游标（opaque），传入下一次请求的 page 参数即可获取下一页；若无更多数据则不返回该字段
