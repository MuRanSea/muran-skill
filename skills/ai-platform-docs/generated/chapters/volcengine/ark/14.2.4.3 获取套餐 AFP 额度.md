14.2.4.3 获取套餐 AFP 额度
POST https://ark.cn-beijing.volcengineapi.com/?Action=GetAFPUsage&Version=2024-01-01查询个人版 AgentPlan 套餐的 AFP（Agent Frame Point）额度用量，包含 5 小时、近一天、近一周、近一月四个滚动窗口的配额与已用量。企业版席位用量请改用 GetSeatAFPUsage 接口。
注意
仅适用于个人版 Agent Plan 套餐；企业版席位用量请改用 GetSeatAFPUsage。返回的 Quota /Used 单位为 AFP，时间戳为 epoch 毫秒。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
