14.9.5 删除推理接入点
POST https://ark.cn-beijing.volcengineapi.com/?Action=DeleteEndpoint&Version=2024-01-01删除指定的推理接入点。删除后该接入点不可恢复。
注意
接入点删除后不可恢复。删除前需满足以下条件：接入点已处于停止状态（ Stopped ），不存在活跃绑定的智能体；若为预付费模型单元绑定的接入点，仅当对应 TPM 资源处于已回收或创建失败状态时才能删除，否则需先退订。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 接入点 ID
待删除的推理接入点（Endpoint）ID，以 ep- 开头。可在火山方舟控制台的「推理接入点」页面查看，或通过 ListEndpoints 接口获取。
