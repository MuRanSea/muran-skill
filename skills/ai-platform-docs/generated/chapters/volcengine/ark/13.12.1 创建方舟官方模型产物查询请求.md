13.12 安全审计
13.12.1 创建方舟官方模型产物查询请求
POST https://ark.cn-beijing.volcengineapi.com/?Action=CreateArkOfficialResultQuery&Version=2024-01-01提交一份内容用于方舟官方结果鉴定，返回查询 ID 供后续轮询结果。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Type string 必选 | 鉴定类型
鉴定类型，指定本次查询的鉴定方式。
ContentURL string | 待鉴定内容 URL
待鉴定内容的 URL 地址。当 Type 为基于内容链接的鉴定方式时必填；其他鉴定方式下可省略。URL 需公网可访问，媒体格式与大小限制请参见官方文档。
响应参数
QueryID string | 查询 ID
本次鉴定查询的唯一 ID，用于后续调用获取鉴定结果接口。
