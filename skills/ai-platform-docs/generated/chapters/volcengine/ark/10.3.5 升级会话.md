10.3.5 升级会话
POST https://ark.cn-beijing.volces.com/api/v3/sessions/{sessionId}/upgrades
保留同一会话并刷新其当前使用的智能体、环境或保管库配置。升级会保留原会话 ID 和已有会话内容，不能换绑其他智能体、环境或保管库。
会话必须满足以下条件才能升级：
当前状态为 idle 。
上一轮以 end_turn 结束。
当前没有其他升级请求。
请求受理后，会话状态变为 upgrading 。请轮询 查询会话详情 ，等待状态恢复为 idle 后再继续发送事件。
根据目标选择接口：
保留同一会话并刷新当前智能体、环境或保管库配置时，使用本接口。
只修改标题或标签时，使用 更新会话标题和标签 。
需要新会话或更换绑定的智能体、环境时，使用 创建会话 。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。

目标智能体版本号。与创建会话不同，省略或传入 0 表示继续使用当前会话的智能体配置，不会自动切换到最新版本。

environment object | 环境配置
当前会话所用环境的引用，用于刷新该环境的最新配置。 id 用于确认要刷新的环境，必须与会话当前绑定的环境 ID 相同。

省略该字段表示保持现有绑定不变。传入 [] 仅适用于当前会话未绑定 Vault 的情况。
