10.3.5 升级会话
POST https://ark.cn-beijing.volces.com/api/v3/sessions/{sessionId}/upgrades
对已发起的 Session 的运行配置进行升级。在保持 session_id 不变的前提下变更 Agent 或 Environment 配置。升级过程中，Session 的状态为 upgrading ；客户端需要轮询 Session 状态，当状态从 upgrading 变为 idle 时，表示升级完成。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
