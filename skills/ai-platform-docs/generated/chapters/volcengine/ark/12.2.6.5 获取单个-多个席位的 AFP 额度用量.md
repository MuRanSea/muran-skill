12.2.6.5 获取单个/多个席位的 AFP 额度用量
POST https://ark.cn-beijing.volcengineapi.com/?Action=GetSeatAFPUsage&Version=2024-01-01查询企业版 AgentPlanTeam 模式下，单个或多个席位的 AFP 额度用量，包含 5 小时、近一天、近一周、近一月四个滚动窗口的配额与已用量。个人版用量请改用 GetAFPUsage 接口。
注意
仅适用于企业版 Agent Plan 套餐；个人版套餐用量请改用 GetAFPUsage。单次请求最多传入1000 个席位 ID，返回的 Quota / Used 单位为 AFP，时间戳为 epoch 毫秒。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
SeatIDs string[] 必选 | 席位 ID 列表
待查询的席位 ID 列表，单次请求最多支持传入 1000 个。
响应参数
SeatAFPUsages object[] | 用量列表
按请求顺序返回的席位 AFP 用量列表。
AFPDaily object | 近一天用量
SeatAFPUsages.AFPDaily
近 1 天滚动窗口的 AFP 用量。
适用于图片生成模型、视频生成模型、语音模型和 Harness。上述能力不受 5 小时额度和周额度限制，仅受模型日额度及套餐月额度限制。对于不适用日额度限制的模型，该字段返回 0 。
Quota string | 窗口总配额
SeatAFPUsages.AFPDaily.Quota
该窗口内的 AFP 总配额。
ResetTime integer | 下次重置时间
SeatAFPUsages.AFPDaily.ResetTime
下次额度刷新时间，Unix 时间戳，单位为毫秒。
SubscribeTime integer | 窗口起始时间
SeatAFPUsages.AFPDaily.SubscribeTime
本次额度刷新开始时间，Unix 时间戳，单位为毫秒。
Used string | 窗口已用量
SeatAFPUsages.AFPDaily.Used
该窗口内已消耗的 AFP 配额。

SeatAFPUsages.AFPFiveHour
