13.11.5 开启模型推理限额
POST https://ark.cn-beijing.volcengineapi.com/?Action=EnableModelInferenceLimit&Version=2024-01-01为指定基础模型开启累计推理用量限额。
提示
同一基础模型完成开启、关闭后，如需再次开启推理限额，需间隔至少 2 小时。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
FoundationModelNames string[] 必选 | 基础模型名称列表
指定需要开启推理限额的基础模型名称列表。一次最多可传入 100 个模型名称。
Limit integer 必选 | 累计推理用量上限
模型的累计推理用量上限，取值必须大于 0。
DryRun boolean 默认值 false | 是否只预检查请求
true ：仅校验请求参数，不实际开启模型推理限额。预检查通过时，接口返回 HTTP 状态码 400 ，错误码为 DryRunOperation ，表示请求参数校验通过，可将 DryRun 设置为 false 后重新发起请求。false ：校验请求参数，并开启模型推理限额。
响应参数
本接口无特有的返回参数，成功时 HTTP 状态码为 200 ，返回结构中 Result 为空对象 {} 。
