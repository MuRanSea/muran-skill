15.9.2 获取基础模型版本信息
POST https://ark.cn-beijing.volcengineapi.com/?Action=GetFoundationModelVersion&Version=2024-01-01获取基础模型版本信息
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数

ModelVersion string 必选 | 版本号
