14.9.12 取消推理接入点滚动升级
POST https://ark.cn-beijing.volcengineapi.com/?Action=CancelEndpointRolling&Version=2024-01-01取消指定的正在进行中的滚动更新任务，接入点保留当前灰度比例对应的模型版本。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 滚动更新任务 ID
要取消的滚动更新任务 ID
Message string | 取消原因
取消操作的原因说明
响应参数
Id string | 滚动更新任务 ID
已取消的滚动更新任务 ID
