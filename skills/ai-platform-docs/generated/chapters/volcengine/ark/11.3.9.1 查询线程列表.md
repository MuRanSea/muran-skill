11.3.9 会话线程
11.3.9.1 查询线程列表
GET https://ark.cn-beijing.volces.com/api/v3/sessions/{sessionId}/threads
分页查询指定会话下的线程列表。返回按 primary（顶级）线程在前、子线程按创建时间正序排列的结果。
说明
线程视图由服务端从会话事件流派生生成，不是独立持久化的资源。列表最多返回 1000 条。鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
sessionId string 必选 | 会话 ID
会话 ID，格式为 sesn- 开头的字符串
Query 参数
在 URL Query String 中传入。
limit integer 默认值 1000 | 每页线程数
每页返回的线程数量。
说明
当 limit 大于 1000 时，服务端会按 1000 处理，不会返回参数错误。
取值范围： [1, 1000]
page string | 分页游标
分页游标（opaque cursor），传入上一页响应返回的 next_page 字段值以获取下一页；不传则从第一页开始
响应参数
data object[] | 线程列表
agent_name string | 智能体名称
data.agent_name
线程关联的智能体名称。若创建事件缺失（如老数据），可能为空字符串。
created_at string | 创建时间
data.created_at
创建时间，ISO 8601 / RFC3339 格式
id string | 线程 ID
data.id
线程唯一标识符
session_id string | 会话 ID
data.session_id
所属会话 ID
status string | 线程状态
data.status
线程状态：
running 智能体正在处理
idle 空闲（等待用户输入或工具结果）
rescheduling 调度中
terminated 已终止
type string | 对象类型
data.type
对象类型，固定为 session_thread
updated_at string | 更新时间
data.updated_at
最近一次事件更新时间，ISO 8601 / RFC3339 格式
parent_thread_id string | 父线程 ID
data.parent_thread_id
父线程 ID。顶级线程（primary thread）该字段为 null 。
next_page string | 下一页游标
下一页游标。若为空或字段不下发，表示已到最后一页。
