14.9.8 获取接入点推理应用层加密证书
POST https://ark.cn-beijing.volcengineapi.com/?Action=GetEndpointCertificate&Version=2024-01-01获取指定推理接入点（Endpoint）的应用层加密证书链，用于客户端在调用推理接口前对请求/响应内容进行端到端加解密。证书由火山引擎私有 CA（PCA）签发，包含叶子证书、中间证书与根证书三层。注意
返回的证书链需配合方舟提供的加密 SDK（MaaS Crypto SDK）使用；证书具备有效期（参见 NotBefore 与 NotAfter），临近过期前需重新调用本接口获取最新证书。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 推理接入点 ID
推理接入点（Endpoint）ID。可通过 ListEndpoints 接口获取
Type string | 证书类型
证书类型。当前仅支持默认值，可不传
响应参数
NotAfter number | 证书过期时间
证书过期时间，使用秒级 Unix 时间戳表示。过期后证书不可用，需重新调用本接口获取新证书NotBefore number | 证书生效时间
证书生效起始时间，使用秒级 Unix 时间戳表示。早于该时间使用证书会校验失败
PCAHost string | 证书签发机构
证书签发机构（PCA）名称
PCAInstanceCertificate string | 叶子证书（PEM）
PEM 格式的叶子证书（Leaf Certificate），由中间证书签发，是客户端实际用于加解密的实例证书PCAName string | 证书产品名称
证书产品名称，标识当前证书所属的加密方案
PCARootCACertificate string | 根证书（PEM）
