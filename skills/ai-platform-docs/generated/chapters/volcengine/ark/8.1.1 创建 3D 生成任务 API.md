8. 3D生成 API
8.1 Seed3D API
8.1.1 创建 3D 生成任务 API
POST https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks
本文介绍创建 3D 生成任务 API 的输入输出参数，供您使用接口时查阅字段含义。模型会依据传入的图片信息生成 3D，待生成完成后，您可以按条件查询任务并获取生成的 3D 文件。
模型能力
doubao-seed3d
doubao-seed3d-2-0-260328 ：图生 3D，根据您输入图片（1 张）+ 参数（可选）生成一个带纹理和PBR 材质的 3D 文件。
参数传入方式说明
说明
对于 subdivision_level 和 file_format 参数，除了在 request body 中直接传入，也支持在文本提示词后追加 --[parameters] 的弱校验方式传参。
当输入的参数或取值不符合模型要求时，该参数将被忽略或触发报错： 
常规方式（推荐） ：在 request body 中直接传入参数。此方式为强校验，若参数填写错误，模型会返回错误提示。
弱校验方式：在文本提示词后追加 --[parameters] 。若参数填写错误，该参数将被忽略或触发报错。
常规方式（推荐）：在 request body 中直接传入参数

请求参数
Body 参数
model string 必选 | 模型 ID
您需要调用的模型的 ID（Model ID）。开通模型服务 后可 查询 Model ID 。
您也可通过 Endpoint ID 来调用模型，获得限流、计费类型（前付费 / 后付费）、运行状态查询、监控、安全等高级能力，可参考 获取 Endpoint ID 。
content object[] 必选 | 输入内容列表
输入给模型生成 3D 内容的信息，支持文本、图片等类型的元素。
支持以下几种组合：
纯文本
文本（可选）+ 图片
文本信息 object
文本部分，作为生成内容的文本提示词。
{
"model": "doubao-seed3d-2-0-260328",
"content": [
{
"type": "text",
"text": "--subdivisionlevel medium --fileformat obj"
},
{
"type": "image_url",
"image_url": {
"url": "<IMAGE_URL>"
}
}
]
}
JSON
text string 必选 | 文本提示词
content.text
输入给模型的文本提示词，描述期望生成的 3D 内容。
type string 必选 | 内容类型
content.type
输入内容的类型，此处固定为 text 。
图片信息 object
输入给模型的图片信息。
image_url object 必选 | 图片对象
content.image_url
输入给模型的图片对象。
url string 必选 | 图片来源
content.image_url.url
图片 URL、图片 Base64 编码。
图片 URL：填入图片的公网 URL。
Base64 编码：将本地文件转换为 Base64 编码字符串后提交给大模型，遵循格式 data:image/<图片格式
>;base64,<Base64 编码> ，注意 <图片格式> 需小写，如 data:image/png;base64,{base64_image} 。传入单张图片要求
格式： jpeg 、 png 、 webp 、 bmp 、 tiff 、 gif
宽高比（宽/高） ： [0.4, 2.5]
宽高长度（px） ： [300, 6000]
大小：单张图片小于 30 MB。请求体大小不超过 64 MB。大文件请勿使用 Base64 编码。
图片数量：1 张
type string 必选 | 内容类型
content.type
输入内容的类型，此处固定为 image_url 。
file_format string 默认值 glb | 输出文件格式
生成的 3D 文件格式。可选值： glb 、 obj 、 usd 、 usdz 。
subdivision_level string 默认值 medium | 多边形面数
3D 文件中多边形面的数量。可选值：
high ：1000000
medium ：500000
low ：100000。
响应参数
id string | 任务 ID
3D 生成任务 ID。仅保存 7 天（从 created_at 时间戳开始计算），超时后将自动清除。
创建 3D 生成任务为异步接口，获取 ID 后需要通过 查询 3D 生成任务 API 来查询任务状态。任务成功后会输出生成 3D 内容的 file_url 。
