13.8.7 重试模型调优任务
POST https://ark.cn-beijing.volcengineapi.com/?Action=ResumeModelCustomizationJob&Version=2024-01-01调用本接口重试因可恢复错误失败的模型调优任务（精调任务）。当任务因临时性故障（如资源不足、网络波动等）失败后，可通过本接口在不重新创建任务的情况下从断点继续训练，保留原任务的训练配置、数据集与已产生的中间产物。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 模型调优任务 ID
待重试的模型调优任务的 ID。可通过 获取模型调优任务列表 接口查询，仅处于失败状态的任务支持重试响应参数
本接口无特有的返回参数，成功时 HTTP 状态码为 200 ，返回结构中 Result 为空对象 {} 。
