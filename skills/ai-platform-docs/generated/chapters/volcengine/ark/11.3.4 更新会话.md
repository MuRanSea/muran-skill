11.3.4 更新会话
POST https://ark.cn-beijing.volces.com/api/v3/sessions/{sessionId}
更新指定会话的信息，支持修改标题和标签。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
sessionId string 必选 | 会话 ID
要更新的会话 ID。通过创建会话接口 (POST /sessions) 返回, 或通过查询会话列表接口 (GET /sessions) 获取。
Body 参数
tags object[] | 标签列表
更新后的会话标签列表，整体替换，传空列表视为清空
key string 必选 | 标签键
tags.key
value string | 标签值
tags.value
title string | 会话标题
新的会话标题，用于快速识别和检索
响应参数
agent object | 智能体信息
创建会话时保存的智能体配置快照，包含该会话实际使用的模型、系统提示词、工具、MCP 服务和技能等配置。后续更新智能体不会影响该会话中的快照。
created_at string | 创建时间
创建时间，ISO 8601 格式
environment_id string | 环境 ID
id string | 会话 ID
会话唯一标识符
status string | 会话状态
会话运行状态。可选值： idle 、 running 、 terminated 、 rescheduling 、 initializing 、 failed 、upgrading 。
type string | 对象类型
对象类型，固定为 session
updated_at string | 更新时间
更新时间，ISO 8601 格式
archived_at string | 归档时间
会话归档时间，ISO 8601 格式
resources object[] | 资源列表
type string | 资源类型
resources.type
access string | memory_store 类型：访问权限
resources.access
created_at string | RFC 3339 时间
resources.created_at
file_id string | file 类型：已注册的文件 ID
resources.file_id
id string | SessionResource ID
resources.id
memory_store_id string | memory_store 类型：挂载的 MemoryStore ID
resources.memory_store_id
mount_path string | 在 sandbox 中的挂载路径
resources.mount_path
tos_bucket string | TOS 存储桶
resources.tos_bucket
type=tos 时，要挂载到 sandbox 的源目录所在的 TOS 存储桶名称。
tos_key string | TOS 目录前缀
resources.tos_key
type=tos 时，TOS 中待挂载目录的路径前缀。必须以 / 结尾，不能指向单个文件。
tos_region string | TOS 地域
resources.tos_region
type=tos 时，源存储桶所在地域的 Region ID，可选。
updated_at string | RFC 3339 时间
resources.updated_at
tags object | 标签列表
会话标签列表
title string | 会话标题
会话标题，用于快速识别和检索
usage object | 用量统计
会话 Token 与缓存用量
vault_ids string[] | 保管库 ID 列表
