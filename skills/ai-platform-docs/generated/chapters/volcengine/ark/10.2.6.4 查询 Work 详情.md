10.2.6.4 查询 Work 详情
GET https://ark.cn-beijing.volces.com/api/v3/environments/{environmentId}/work/{workId}查询指定 Work 的详细信息，包括当前状态、关联的 Session、资源标签和生命周期时间。鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
environmentId string 必选 | 环境 ID
环境 ID，以 env- 开头，由创建环境或查询环境列表接口返回。
workId string 必选 | Work 标识符
要查询的 Work 唯一标识，取自 Poll 或查询 Work 列表响应的 id ，以 sesn- 开头。
响应参数
created_at string | 创建时间
服务端创建 Work 时记录的时间，格式为 RFC 3339。
data object | 工作载荷
Work 对应的 Session 信息。
id string | Session ID
data.id
Work 对应的 Session ID，可用于调用 Session 相关接口。
type string | 载荷类型
data.type
当前固定为 session ，表示 data.id 指向一个 Session。
environment_id string | 环境 ID
Work 所属的环境 ID，以 env- 开头。
id string | Work 标识符
Work ID，以 sesn- 开头。
state string | 当前状态
Work 当前状态： queued 为已入队， starting 为启动中， active 为执行中， stopping 为停止中，stopped 为已停止。
type string | 对象类型
类型标识，固定为 work 。
updated_at string | 更新时间
Work 最近一次状态迁移的时间，格式为 RFC 3339。
acknowledged_at string | 认领时间
Work 被 Worker 成功认领的时间，格式为 RFC 3339；尚未认领时不返回该字段。
latest_heartbeat_at string | 最近心跳时间
服务端最近一次接受 Work 心跳的时间，格式为 RFC 3339；尚未收到心跳时不返回该字段。started_at string | 开始时间
Work 开始执行的时间，格式为 RFC 3339；尚未开始执行时不返回该字段。
stop_requested_at string | 停止请求时间
服务端收到 Work 停止请求的时间，格式为 RFC 3339；尚未收到停止请求时不返回该字段。stopped_at string | 停止时间
Work 进入 stopped 状态的时间，格式为 RFC 3339；尚未停止时不返回该字段。
tags object[] | 资源标签
与当前 Work 关联的资源标签列表。
key string | 标签键
tags.key
value string | 标签值
tags.value
