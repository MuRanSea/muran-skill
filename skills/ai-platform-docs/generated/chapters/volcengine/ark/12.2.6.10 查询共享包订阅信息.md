12.2.6.10 查询共享包订阅信息
POST https://ark.cn-beijing.volcengineapi.com/?Action=GetSharedPackageInfo&Version=2024-01-01通过共享包 ID 或绑定的席位 ID 查询 Agent Plan 企业版共享包的订阅状态、购买数量，以及订阅起始和到期时间。
使用说明
SharedPackageID 和 SeatID 至少填写一个。同时填写时，按 SharedPackageID 查询。
CurrentQuota 和 NextPeriodQuota 表示共享包购买数量，不表示 AFP 消耗量或剩余额度。本接口不返回 AFP 用量明细。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
SeatID string | 席位 ID
已绑定共享包的席位 ID，用于查询该共享包的订阅信息。
SharedPackageID string | 共享包 ID
待查询订阅信息的共享包 ID。
响应参数
ArrivalTime integer | 查询时间
查询响应生成时间，采用 Unix 时间戳，单位为秒。
Data object | 共享包订阅信息
共享包订阅信息，包括订阅状态、当前和下一计费周期的购买数量，以及订阅起始和到期时间。AccountID string | 所属账号 ID
Data.AccountID
共享包所属账号的 ID，以十进制字符串形式返回。
CurrentQuota number | 当前周期购买数量
Data.CurrentQuota
当前计费周期生效的共享包购买数量。
ExpiredTime integer | 订阅到期时间
Data.ExpiredTime
共享包订阅到期时间，采用 Unix 时间戳，单位为秒。尚未初始化时返回 0 。
NextPeriodQuota number | 下一周期购买数量
Data.NextPeriodQuota
下一计费周期的共享包购买数量。
OrderTime integer | 订阅起始时间
Data.OrderTime
共享包订阅起始时间，采用 Unix 时间戳，单位为秒。尚未初始化时返回 0 。
SharedPackageID string | 共享包 ID
Data.SharedPackageID
订阅信息所属的共享包 ID。
Status integer | 订阅状态
Data.Status
共享包的订阅状态。
1 ：待生效。
2 ：生效中。
3 ：已到期。
4 ：已回收。
InstanceID string | 订阅实例 ID
Data.InstanceID
共享包关联的订阅实例 ID，用于续费共享包。
说明
未关联交易订阅实例时，可能不返回该字段。
