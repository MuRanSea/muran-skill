13.8.5 查询精调效果指标
POST https://ark.cn-beijing.volcengineapi.com/?Action=GetModelCustomizationJobMetrics&Version=2024-01-01查询精调任务的效果指标名称列表，返回的指标名称可用于 GetModelCustomizationJobMetricData 接口获取详细指标数据。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
ModelCustomizationJobId string 必选 | 模型精调任务 ID
模型精调任务 ID，格式如 mcj-20241128104838-g9vqg 。可通过 ListModelCustomizationJobs 接口获取响应参数
Metrics string[] | 指标名称列表
指标名称列表。返回的指标名称可作为 GetModelCustomizationJobMetricData 接口的 Metrics 入参，用于查询指标的详细打点数据。常见取值包括 train/loss 、 eval/loss 、 train/total_tokens 、 eval/total_tokens等。
