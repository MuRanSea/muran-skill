10.3 Sessions
10.3.1 创建会话
POST https://ark.cn-beijing.volces.com/api/v3/sessions
创建一个新的会话，用于与托管智能体进行多轮交互。创建时可指定智能体、环境、标题、标签、保管库及初始资源。
说明
resources 中可挂载 type=file 的资源，通过 file_id 引用 Files API 已上传的文件；智能体在沙箱内按 mount_path 或 /mnt/session/uploads/{file} 访问这些文件。已支持 purpose=agent 与 purpose=user_data 两类文件，会话侧统一按沙箱资源使用；文件是否能直接进入模型上下文由后续 user.message 内容块决定。
说明
传入 environment 覆写对象可在本次会话中临时调整所引用 Environment 的 config （例如 tos产物存储配置），将本次会话产物存储到指定的用户 TOS Bucket；覆写不会修改原
Environment，也不影响后续新建的其他会话。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。

Body 参数
agent string / object 必选 | 智能体标识
指定会话使用的智能体。支持两种形态：字符串 agent_id （使用最新版本）、 AgentRef 引用对象（通过 version 锁定指定版本）
智能体 ID string
智能体 ID；会话启动时使用该智能体的最新版本
智能体引用 object
智能体引用对象，可通过 version 锁定指定版本
id string 必选 | 智能体 ID
agent.id
type string 必选 | 引用类型
agent.type
引用类型，固定为 agent
version integer | 版本号
agent.version
智能体版本号；省略时使用最新版本
智能体覆写对象 object
以 id 指定的智能体版本为基础，省略字段时沿用原配置；传入 system 、 multiagent 或 model 时替换对应配置； tools 、 mcp_servers 或 skills 传 [] 时清空对应列表，传非空数组时整体替换。覆写仅影响本次会话，不会创建新版本或修改基础智能体。
id string 必选 | 智能体 ID
agent.id
基础智能体 ID。缺失或为空时返回 HTTP 400 MissingParameter 。
type string 必选 | 覆写类型
agent.type
覆写类型，固定为 agent_with_overrides
model object | 模型运行参数覆写
agent.model
仅对本次会话生效的模型配置。支持设置 id 、 speed 、 service_tier 、 thinking 和 reasoning_effort ；省略子字段时沿用基础智能体的对应配置。
id string | 模型 ID 覆写
agent.model.id
本次会话使用的模型 ID。省略时沿用基础智能体的模型；指定时仅影响本次会话，不修改基础智能体。模型 ID 无效时返回 HTTP 400；模型未开通时返回 HTTP 403 ModelNotOpen 。
reasoning_effort string | 推理投入档位
agent.model.reasoning_effort
可选值为 none 、 minimal 、 low 、 medium 、 high 、 xhigh 、 max 。省略时沿用基础智能体的配置；传空字符串时使用当前模型的默认配置。传入不支持的取值时返回 HTTP 400 InvalidParameter 。各模型支持的取值和默认值，请参见 模型支持的参数列表 。
service_tier string | 推理服务档位，可选值为 auto 、 default 、 fast
agent.model.service_tier
省略时沿用基础智能体的配置；传空字符串时使用当前模型的默认配置。传入不支持的取值时返回 HTTP400 InvalidParameter 。各模型支持的取值和默认值，请参见 模型支持的参数列表 。
speed string | 模型推理速度档位，可选值为 standard 、 fast
agent.model.speed
省略时沿用基础智能体的配置；传空字符串时使用模型服务的默认配置。并非所有模型都支持 fast ，传入不支持的取值时返回 HTTP 400 InvalidParameter 。
thinking string | 思考模式，可选值为 enabled 、 disabled 、 auto
agent.model.thinking
auto 表示由模型判断是否启用思考；省略时沿用基础智能体的配置；传空字符串时使用当前模型的默认配置。传入不支持的取值时返回 HTTP 400 InvalidParameter 。各模型支持的取值和默认值，请参见 模型支持的参数列表 。
system string | 系统提示词覆写
agent.system
本次会话使用的系统提示词。省略时沿用基础智能体的配置。
version integer | 版本号
agent.version
基础智能体版本号。省略时使用最新版本；指定版本时，以该版本保存的配置为基础应用本次覆写。Agent 引用（对象形态） object
type: "agent" + id + optional version。
与 CreateSessionRequest.agent 联合使用。
id string 必选 | Agent ID
agent.id
type string 必选 | 固定 "agent"
agent.type
取值固定为 agent 。
version integer | Agent 版本号；不传走最新
agent.version
environment object | 环境覆写
环境覆写对象。以 id 指定的 Environment 为基础，按子字段覆写 config （含 tos 产物存储配置）。仅需要临时调整本次会话的运行时配置（例如把产物存储到不同的用户 Bucket 或 Prefix）时使用；与 environment_id 二选一。
id string 必选 | 环境 ID
environment.id
基础 Environment ID
type string 必选 | 对象类型
environment.type
对象类型，固定为 environment_with_overrides
config object | 覆写后的运行配置
environment.config
本次会话使用的环境配置。省略子字段时沿用基础 Environment 的对应配置； tos 传非空对象时整体替换，传 {} 时清空并使用默认存储。
type string 必选 | 环境类型
environment.config.type
运行环境类型： cloud 表示平台托管的云端运行环境， self_hosted 表示用户自托管环境。覆写时必须与基础 Environment 保持一致。
tos object | 产物存储覆写
environment.config.tos
会话级产物存储覆写。整块 tos 是原子配置：省略保留 base、 {} 清空并回落到默认存储、非空时 bucket 和 prefix 必须同时提供
bucket string | TOS 桶
environment.config.tos.bucket
用户 TOS 存储桶名称。Bucket 必须与当前方舟 API 接入地域一致，否则请求会被拒绝。
prefix string | 对象前缀
environment.config.tos.prefix
智能体产物存放在用户 Bucket 内的对象前缀。运行时最终对象 key 形如 {prefix}outputs/{env-id}/{session-id}/
{file}
environment_id string | 环境 ID
会话运行的环境 ID。关联到已创建的 Environment（含 config / packages / networking / 产物存储 tos 等运行时配置）。 environment_id 与 environment 二选一互斥：都不传或都传返回 400；两者引用同一个Environment ID（ environment_id == environment.id ）时也拒绝
