15.2.5 管理 Coding Plan
15.2.5.1 查询 Coding Plan 支持的模型列表
POST https://ark.cn-beijing.volcengineapi.com/?Action=ListArkCodingPlanModel&Version=2024-01-01查询 Coding Plan 支持的模型列表。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
响应参数
Datas object[] | 模型列表
Coding Plan 套餐当前可选的模型列表。
ModelID string | 模型 ID
Datas.ModelID
模型 ID，例如 doubao-seed-1.6 ，调用模型时填入 model 参数。
