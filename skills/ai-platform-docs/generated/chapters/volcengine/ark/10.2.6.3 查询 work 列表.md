10.2.6.3 查询 work 列表
GET https://ark.cn-beijing.volces.com/api/v3/environments/{environmentId}/work
按 environment 分页查询 work 项。
本接口用于分页查询自托管环境中的 work。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
environmentId string 必选 | 环境 ID
Query 参数
在 URL Query String 中传入。
limit integer | 每页数量
page string | 翻页游标
翻页游标；首次请求可省略，后续请求传上一次响应的 next_page 值。
响应参数
data object[] | work 列表
当前分页的 work 项列表。
created_at string | 创建时间
data.created_at
服务端落库产生 work 项时的时间戳（RFC 3339 格式）。
data object | 工作载荷
data.data
该 work 要执行的具体工作载荷；当前仅 session 一种。
id string | 业务对象 ID
data.data.id
业务对象 ID，例如 session ID。
type string | 载荷类型
data.data.type
业务载荷类型，当前固定为 session 。
environment_id string | 环境 ID
data.environment_id
归属的 environment 标识符（形如 env-... ）。
id string | Work 标识符
data.id
Work 标识符；值等同 session_id（形如 sesn-... ）。
state string | 当前状态
data.state
当前状态。取值：
queued ：已入队；
starting ：已认领启动中；
active ：执行中；
stopping ：请求停止中；
stopped ：已停止
type string | 对象类型
data.type
类型标识，固定为 work 。
acknowledged_at string | 认领时间
data.acknowledged_at
被某个 worker 认领时的时间戳；未认领时为空。
latest_heartbeat_at string | 最近心跳时间
data.latest_heartbeat_at
最近一次 heartbeat 时间；未曾收到任何 heartbeat 时为空。
started_at string | 开始时间
data.started_at
work 实际开始执行的时间戳；未开始执行时为空。
stop_requested_at string | 停止请求时间
data.stop_requested_at
收到 Stop 请求的时间戳；未收到时为空。
stopped_at string | 停止时间
data.stopped_at
最终停止时间戳；state 变为 stopped 之后落值。
tags object[] | 资源标签
data.tags
与本 work item 关联的火山资源标签列表。
key string | 标签 key
data.tags.key
value string | 标签 value
data.tags.value
updated_at string | 更新时间
data.updated_at
最近一次状态迁移的时间戳（RFC 3339 格式）。
next_page string | 下一页游标
下一页游标；作为下次请求的 page 参数传入。若已是最后一页则为空。
