8.1.4 取消或删除 3D 生成任务
DELETE https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks/{id}
取消排队中的 3D 生成任务，或者删除 3D 生成任务记录。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。

Path 参数
id string 必选 | 任务 ID
需要取消或者删除的 3D 生成任务 ID。
