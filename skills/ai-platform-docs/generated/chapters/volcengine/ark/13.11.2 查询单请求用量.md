13.11.2 查询单请求用量
POST https://ark.cn-beijing.volcengineapi.com/?Action=GetInferenceRequestUsage&Version=2024-01-01根据 RequestID 查询指定小时内当前账号下某个同步推理请求的用量明细。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
QueryHour string 必选 | 查询小时
请求记录所在小时的起始时间，格式为 YYYY-MM-DD HH:00:00 。分钟和秒必须为 00 。默认使用北京时间（Asia/Shanghai）；其他环境以其查询时区配置为准。
RequestID string 必选 | 请求 ID
待查询的同步推理请求 ID。
说明
RequestID 为同步推理请求在响应体中返回的 id 。
响应参数
Records object[] | 用量明细
同步请求用量明细数组。一个 RequestID 可能对应多条用量记录，接口会在该数组中返回全部明细。AccountantEndTime integer | 账期结束时间
Records.AccountantEndTime
账期结束时间，Unix 时间戳，单位为秒，不包含该时间点。仅当 BillingStatus 严格等于 normal 时返回。
AccountantStartTime integer | 账期开始时间
Records.AccountantStartTime
账期开始时间，Unix 时间戳，单位为秒，包含该时间点。仅当 BillingStatus 严格等于 normal 时返回。AccountID integer | 账号 ID
Records.AccountID
记录所属的账号 ID。有记录时返回。
APIKeyID string | API Key 标识
Records.APIKeyID
请求使用的 API Key 标识，不是 API Key 密钥内容。有记录时返回。
AudioCachedTokens integer | 音频缓存 Token 数
Records.AudioCachedTokens
音频缓存 Token 数。返回 Token 用量组时返回。

Records.AudioOriginalDurationMs
