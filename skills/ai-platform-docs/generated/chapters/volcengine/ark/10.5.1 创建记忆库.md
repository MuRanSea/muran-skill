10.5 Memory Stores
10.5.1 创建记忆库
POST https://ark.cn-beijing.volces.com/api/v3/memory_stores
创建一个新的记忆库，用于存储和检索智能体的长期记忆数据。记忆库以 path 为唯一键管理其下记忆条目，供智能体在会话中按需读写。每账号最多创建 100 个记忆库，超出报错拒绝。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Body 参数
name string 必选 | 记忆库名称
记忆库名称，长度 1~64 个字符
description string | 记忆库描述
记忆库描述，说明记忆库的用途和存储内容，长度不超过 2048 字符
metadata object | 自定义元数据
用户自定义元数据，键值均为字符串，用于标记和分类记忆库；最多 64 个 key，序列化后 ≤8KB响应参数
created_at string | 创建时间
记忆库创建时间，RFC 3339 格式
created_by object | 创建者
记忆库创建者信息
type string | 操作者类型
created_by.type
操作者类型，固定为 user_actor
user_id string | 用户 ID
created_by.user_id
操作者用户 ID，取自鉴权上下文
id string | 记忆库 ID
记忆库唯一标识符，格式为 memstore- 开头的小写 ULID
memory_count integer | 记忆条目数量
当前记忆库内的记忆条目数量
metadata object | 自定义元数据
用户自定义元数据，键值均为字符串；恒返回，缺省为空对象
name string | 记忆库名称
记忆库名称，用于用户识别和管理
session_count integer | 关联会话数
当前挂载该记忆库的活跃会话去重数
storage_bytes integer | 存储字节数
当前记忆库占用的存储字节数
type string | 对象类型
对象类型，固定为 memory_store
updated_at string | 更新时间
记忆库最后更新时间，RFC 3339 格式
description string | 记忆库描述
记忆库描述，说明记忆库的用途和适用场景；空串时省略
