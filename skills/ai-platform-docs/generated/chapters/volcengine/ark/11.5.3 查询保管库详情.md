11.5.3 查询保管库详情
GET https://ark.cn-beijing.volces.com/api/v3/vaults/{vault_id}
查询指定保管库的详细信息。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
vault_id string 必选 | 保管库 ID
保管库 ID，以 vlt- 开头。
响应参数
created_at string | 创建时间
保管库的创建时间，采用 RFC 3339 格式。
display_name string | 保管库展示名
保管库的展示名称，用于识别该保管库。
id string | 保管库 ID
保管库 ID，以 vlt- 开头。
type string | 对象类型
表示当前对象是一个保管库。
取值固定为 vault 。
updated_at string | 更新时间
保管库最后一次更新的时间，采用 RFC 3339 格式。
metadata object | 自定义元数据
为保管库设置的字符串键值对，可用于分类或关联业务信息。未设置时返回 null 。
