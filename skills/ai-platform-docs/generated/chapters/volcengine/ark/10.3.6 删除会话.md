10.3.6 删除会话
DELETE https://ark.cn-beijing.volces.com/api/v3/sessions/{sessionId}
删除指定的会话，删除后会话及其相关数据不可恢复。删除操作为异步执行。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
sessionId string 必选 | 会话 ID
要删除的会话 ID。通过创建会话接口 (POST /sessions) 返回, 或通过查询会话列表接口 (GET /sessions) 获取。
响应参数
id string | 会话 ID
被删除的会话 ID
type string | 对象类型
对象类型，固定为 session_deleted
