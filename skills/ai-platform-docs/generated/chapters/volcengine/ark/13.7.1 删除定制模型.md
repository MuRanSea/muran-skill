13.7 管理定制模型
13.7.1 删除定制模型
POST https://ark.cn-beijing.volcengineapi.com/?Action=DeleteCustomModel&Version=2024-01-01调用本接口删除指定的定制模型。删除后该定制模型不可恢复，请谨慎操作。建议在删除前确认该定制模型未被任何在线推理接入点（Endpoint）使用。
注意
删除操作不可逆，定制模型一旦删除，关联的训练产物、版本信息将一并被清理，无法通过 API或控制台恢复。如该定制模型已被在线推理接入点（Endpoint）引用，请先解除关联或删除接入点后再执行删除。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 定制模型 ID
待删除的定制模型 ID。可通过 ListCustomModels 接口查询当前账号下的定制模型列表。
DryRun boolean 默认值 false | 是否预检请求
是否仅对此请求进行预检（DryRun），不实际执行删除。
true ：发送检查请求，仅校验参数与权限，不执行实际删除操作。
false （默认）：发送正常请求，执行实际的删除操作。
响应参数
本接口无特有的返回参数，成功时 HTTP 状态码为 200 ，返回结构中 Result 为空对象 {} 。
