10.5.6.3 查询记忆列表
GET https://ark.cn-beijing.volces.com/api/v3/memory_stores/{memoryStoreId}/memories目录浏览：分页查询指定记忆库下的记忆条目。支持按 path_prefix 过滤，可通过 depth 折叠子目录返回目录项。列表元素仅包含精简元信息，不含 content 。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
memoryStoreId string 必选 | 记忆库 ID
目标记忆库 ID。通过创建记忆库接口 (POST /memory_stores) 返回, 或通过查询记忆库列表接口 (GET /memory_stores) 获取。
Query 参数
在 URL Query String 中传入。
depth integer | 折叠层数
折叠层数：不传则平铺返回前缀下全部 path；传则必须 >= 1，超出层数的子目录会以 memory_prefix 类型折叠返回
最小值： 1
limit integer 默认值 20 | 每页数量
每页返回的数量。上限 2000 与单库 Memory 上限保持一致。
取值范围： [1, 100]
order_by string | 排序字段
排序字段。不传或空串等价 path （按字典序）； updated_at / created_at 按对应时间倒序page string | 分页游标
分页 opaque cursor，传入上一次响应返回的 next_page 以获取下一页
path_prefix string | 路径前缀
路径前缀过滤，仅返回 path 以此为前缀的记忆
响应参数
data object[] | 记忆列表
记忆列表项； type=memory 为文件项， type=memory_prefix 为折叠目录项（仅含 type + path ，path 以 / 结尾）
path string | 记忆路径
data.path
记忆路径； memory_prefix 类型时以 / 结尾
type string | 列表项类型
data.type
列表项类型： memory 表示文件项， memory_prefix 表示折叠目录项
content_sha256 string | 内容摘要
data.content_sha256
内容 SHA-256 摘要，仅 type=memory 时返回
content_size_bytes integer | 内容字节数
data.content_size_bytes
内容字节数，仅 type=memory 时返回
created_at string | 创建时间
data.created_at
创建时间，仅 type=memory 时返回，RFC 3339 UTC 毫秒格式
id string | 记忆 ID
data.id
记忆条目 ID，仅 type=memory 时返回
memory_store_id string | 记忆库 ID
data.memory_store_id
所属记忆库 ID，仅 type=memory 时返回
memory_version_id string | 版本 ID
data.memory_version_id
当前 head 版本 ID，仅 type=memory 时返回
updated_at string | 更新时间
data.updated_at
更新时间，仅 type=memory 时返回，RFC 3339 UTC 毫秒格式
prefixes string[] | 折叠前缀列表
当前查询下所有被折叠的目录前缀列表；即使无折叠也返回空数组
next_page string | 下一页游标
下一页 opaque cursor，格式为 page_<token> ；作为 page 参数传入以获取下一页；无更多数据时为空
