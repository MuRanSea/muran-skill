11.6 Skills
11.6.1 创建技能
POST https://ark.cn-beijing.volces.com/api/v3/skills
通过 multipart/form-data 上传一个 Skill 目录中的多个文件或一个 ZIP 包，创建自定义技能。系统会解析并验证技能内容，创建成功后自动生成第一个版本。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Body 参数
files file 必选 | 技能文件
待上传的 Skill 内容。支持以下上传方式：
按文件上传：重复传入 files[] 。每个文件通过 filename 指定上传后在 Skill 中的路径，例如 basic_math/SKILL.md 。所有路径必须使用同一个顶层目录。
ZIP 上传：通过 files 上传包含一个完整 Skill 目录的 ZIP 文件。
上传限制：
ZIP 文件最大 50 MiB。
解压后单个文件最大 25 MiB。
解压后文件总大小最大 200 MiB，文件数最多 500 个。
display_title string | 展示名称
技能展示名称。省略时从 SKILL.md 元数据或顶层目录名解析
响应参数
created_at integer | 创建时间
技能创建时间，Unix 秒时间戳
display_title string | 展示名称
技能展示名称。优先取 latest 版本对应的 display_title ，否则回落到 SKILL.md 里解析出的 nameid string | 技能 ID
技能唯一标识符，格式为 skill- 开头的字符串
latest_version string | 最新版本
最新版本号
object string | 对象类型
对象类型，固定为 skill
source string | 技能来源
技能来源。 custom 表示用户上传的自定义技能， skill_hub 表示平台内置技能
updated_at integer | 更新时间
技能最后更新时间，Unix 秒时间戳
description string | 技能描述
技能描述，说明技能的功能、用途和使用场景
name string | 技能名称
技能名称（ SKILL.md 中解析出的 name ），供仍依赖 name 字段的前端 / BP 侧使用。展示名建议优先取 display_title
