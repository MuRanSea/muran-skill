10.3.7 会话事件
10.3.7.1 发送会话事件
POST https://ark.cn-beijing.volces.com/api/v3/sessions/{sessionId}/events
向指定会话发送用户侧事件。请求体格式为 {"events": [<事件对象>, ...]} ，一次最多 10 条；每个事件对象至少包含 type 字段，业务字段结构详见 会话事件结构参考 。发送后智能体异步处理，结果通过事件流返回。
说明
user.message 事件的 content 数组支持文本、图片、文档、视频等多种内容块，其中图片 / 文档 / 视频块均可通过 source.type=file + source.file_id 引用 Files API 已上传的文件，实现 File ID →模型输入的复用。file_id 支持 purpose=user_data 与 purpose=agent 两类；实际能否被当前模型直接消费由模型能力和内容类型共同决定，不满足时可改走会话 resources 挂载让智能体在沙箱内处理。字段结构详见 会话事件结构参考 。
说明
视频内容块（ type=video ）通过 source 传入，支持三种方式： url （公网可访问 URL，文件大小 ≤ 50 MB）、 base64 （本地文件转 Base64，MIME 类型仅支持 video/mp4 / video/xmsvideo / video/quicktime ，解码后 ≤ 50 MB、请求体 ≤ 64 MB）、 file （通过 Files API 上传后的视频文件 ID）。可通过 source.fps 字段（取值 0.2-5，默认 1）控制抽帧频率：画面变化剧烈或需关注动作细节时调高，画面变化少时调低以节省 Token。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
sessionId string 必选 | 会话 ID
会话 ID，格式为 sesn- 开头的字符串
Body 参数
events object[] 必选 | 事件列表
要发送的用户侧事件列表。每个事件对象至少包含 type 字段，其余业务字段随事件类型不同而不同。所有可发送事件类型（ user.message / system.message / user.interrupt / user.tool_confirmation / user.tool_result / user.custom_tool_result / user.define_outcome ）的完整字段结构见 会话事件结构参考。 system.message 必须与一条 user.message 放在同一个 events 数组中，并紧跟在该 user.message后发送。
type string 必选 | 事件类型
events.type
事件类型标识符。可选值及字段结构详见 会话事件结构参考 。
响应参数
data object[] | 已接收事件列表
服务端已接收的事件回执，与请求中的 events 一一对应。每个元素包含请求中的 type 和对应业务字段； id 可能为服务端生成的事件 ID，也可能暂为空字符串。回执不包含 processed_at 、 session_id 或 sequence 。事件处理后的完整结构请通过 查询会话事件列表 或流式接口获取；业务字段结构详见 会话事件结构参考 。
type string | 事件类型
data.type
事件类型，与请求中传入的 type 一致，如 user.message
id string | 事件 ID
data.id
回执中的事件 ID。部分事件会立即返回 sevt- 开头的 ID； system.message 等事件可能返回空字符串，最终事件 ID 以历史列表或流式事件为准
