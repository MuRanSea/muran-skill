11.3.10.3 查询线程事件列表
GET https://ark.cn-beijing.volces.com/api/v3/sessions/{session_id}/threads/{thread_id}/events分页查询指定线程中已经产生的消息、工具调用和状态事件。查询会话主线程中的事件时，请使用 获取会话事件列表 ；实时接收指定线程的事件时，请使用 流式获取线程事件 。返回字段随事件类型变化，详情请参见 会话事件结构参考 。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
session_id string 必选 | 会话 ID
会话 ID，格式为 sesn- 开头的字符串
thread_id string 必选 | 线程 ID
线程 ID，形如 sthr-xxxxx 。
Query 参数
在 URL Query String 中传入。
created_at[gt] string | 起始时间（不含）
事件处理时间的起始边界（不含），采用 RFC 3339 格式。 created_at 四个边界至多使用两个组成区间created_at[gte] string | 起始时间（含）
事件处理时间的起始边界（含），采用 RFC 3339 格式。 created_at 四个边界至多使用两个组成区间created_at[lt] string | 结束时间（不含）
事件处理时间的结束边界（不含），采用 RFC 3339 格式。 created_at 四个边界至多使用两个组成区间created_at[lte] string | 结束时间（含）
事件处理时间的结束边界（含），采用 RFC 3339 格式。 created_at 四个边界至多使用两个组成区间limit integer 默认值 50 | 每页事件数
每页返回的事件数量。
说明
limit 为 0 时按默认值 50 处理；大于 200 时按 200 处理。负数或无法解析为整数的值会返回参数错误。
取值范围： [0, 200]
order string 默认值 asc | 排序方向
事件排序方向。
说明
desc 表示倒序；省略、传入 asc 或其他值时均按正序返回。
page string | 下一页标识
下一页标识。请将上一页返回的 next_page 原样传入；不传则从第一页开始
types string[] | 事件类型筛选
按事件类型筛选，可重复传入，例如 types=user.message&types=agent.message 。支持的取值请参见 会话事件结构参考 。
响应参数
data object[] | 事件列表
指定线程的事件列表，用于查询子智能体线程内部的消息和工具调用。
每个事件对象包含 id 、 type 、 processed_at 以及随 type 变化的业务字段。
• 查询主线程事件：请使用 获取会话事件列表 。
查看完整字段结构：请参见 会话事件结构参考 。
id string | 事件 ID
data.id
事件唯一标识符，形如 sevt-...
processed_at string | 处理时间
data.processed_at
事件处理时间，采用 RFC 3339 格式
type string | 事件类型
data.type
事件类型（如 user.message 、 agent.message 、 session.status_idle 等）
next_page string | 下一页标识
下一页标识，请原样传入下一次请求的 page 参数；无更多数据时不返回该字段
