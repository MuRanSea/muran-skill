13.2 管理 Agent / Coding Plan
13.2.1 创建个人版套餐
POST https://ark.cn-beijing.volcengineapi.com/?Action=CreatePersonalPlan&Version=2024-01-01个人版用户购买 Agent Plan / Coding Plan 套餐（ AgentPlan / CodingPlan ）。
您通过 API 接口发起部署请求或调用本服务的，即表示您已充分阅读、理解并同意 《火山引擎数据授权协议》 、《方舟平台专用条款》 、《免责声明》 、《豆包模型服务协议》 、《开源模型许可证》 、《语音服务协议》 、《Harness能力说明和产品专用条款》 及其他适用的平台规则。如您不同意上述协议，请立即停止调用。
注意
自 2026 年 8 月 26 日起， CreatePersonalPlan 接口新增必填请求参数 AgreementAccepted ，用于确认调用方已阅读并同意当前 Plan 所适用的协议及条款。该参数仅支持传入 true 。未传入该参数时，将无法下单并返回参数缺失错误。 请您尽快完成接口适配，以避免影响套餐购买。
说明
单次请求仅支持订购单一套餐类型（单次仅购买一个 PlanType ）。
支持传入 DryRun=true 参数，仅执行订购合法性校验，不实际创建订阅订单。
个人版同一账号同档位同一时间仅允许持有一个有效订阅，重复提交同档位订购请求，将返回 OperationDenied 类错误。
接口为异步下单，自动扣费模式，下单前请确保云账户内余额充足。
调用 CreatePersonalPlan 提交套餐创建请求后，订单存在异步处理或状态延迟情况。建议在调用 CreatePersonalPlan 接口后，通过 GetPersonalPlan 接口进行反查，以确认最终的套餐创建结果。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
AgreementAccepted boolean 必选 | 协议确认
是否已阅读并同意当前 Plan 适用的协议及条款。该参数仅支持传入 true ；未传入时，将无法下单并返回参数缺失错误。
Duration number 必选 | 订购时长
订购时长，单位以 PricingCycle 为准。
取值范围： [1, 12]
Plan string 必选 | 商品名称
待购买的商品名称。可选值： AgentPlan （Agent Plan 个人版）、 CodingPlan （Coding Plan 个人版）。PlanType string 必选 | 套餐档位
套餐档位。支持以下套餐类型及档位取值：
AgentPlan ： Small 、 Medium 、 Large 、 Max
CodingPlan ： Lite 、 Pro
PricingCycle string 必选 | 计费周期
计费周期。当前仅支持 Month （包月）。
AutoRenew boolean 默认值 false | 自动续费
是否在套餐到期时开启自动续费。设为 true 时套餐到期前会从云账户余额自动续费，仅支持单次自动续费。
DryRun boolean 默认值 false | 预检模式
是否仅校验不下单。设为 true 时，仅完成参数、额度全链路校验，不会实际扣款，适用于上线前预校验场景。
响应参数
PlanType string | 已购买的套餐档位
