10.3.3 查询会话详情
GET https://ark.cn-beijing.volces.com/api/v3/sessions/{session_id}
查询指定会话的详细信息，包括智能体、会话运行环境、资源、状态和标签等。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
