10.1.5 删除智能体
DELETE https://ark.cn-beijing.volces.com/api/v3/agents/{agentId}
删除指定的智能体。删除后，无法再通过 API 查询或恢复该智能体及其历史版本。存在 running 状态的会话时，删除请求返回 400 InvalidAction ；其他状态的会话不阻止删除。重复删除、智能体不存在或调用方无权访问时返回 404 InvalidAgent 。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
agentId string 必选 | 智能体 ID
要删除的智能体 ID，以 agent- 开头。该 ID 可通过创建智能体接口返回，或在控制台智能体列表页面获取。
响应参数
id string | 智能体 ID
被删除的智能体 ID，以 agent- 开头，与请求中的 agentId 相同。
