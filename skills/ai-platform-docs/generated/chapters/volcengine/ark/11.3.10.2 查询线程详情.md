11.3.10.2 查询线程详情
GET https://ark.cn-beijing.volces.com/api/v3/sessions/{session_id}/threads/{thread_id}查询指定线程的当前状态、关联智能体、主子关系、时长统计和累计用量。已知 thread_id 时使用本接口。
查看全部线程请使用 查询线程列表 ；排查执行过程请使用 获取线程事件列表 。
说明
线程信息是根据会话执行事件形成的当前视图：
created_at 表示首次观察到该线程的时间。
updated_at 表示最近一次状态变化时间。
stats 表示当前线程的累计运行时长、生命周期总时长和启动准备时长。
usage 表示当前线程运行期间累计的运行时长、模型 token 和服务端搜索请求统计。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
session_id string 必选 | 会话 ID
会话 ID，形如 sesn-...
thread_id string 必选 | 线程 ID
线程 ID，形如 sthr-...
响应参数
agent_name string | 智能体名称
线程关联的智能体名称
created_at string | 创建时间
首次观察到该线程的时间，采用 RFC 3339 格式。
id string | 线程 ID
线程唯一标识符，形如 sthr-...
parent_thread_id string / null | 父线程 ID
子线程的父线程 ID；主线程返回 null 。
session_id string | 会话 ID
所属会话 ID，形如 sesn-...
stats object | 时长统计
当前线程的累计运行时长、生命周期总时长和启动准备时长。
active_seconds number | 累计运行时长
stats.active_seconds
当前线程处于 running 状态的累计时长，单位为秒。该值与 usage.active_seconds 相同。duration_seconds number | 线程总时长
stats.duration_seconds
当前线程从创建到查询时刻的总时长，单位为秒。线程终止后，该值固定为从创建到终止的时长。startup_seconds number | 启动准备时长
stats.startup_seconds
主线程从创建到首次进入 running 状态的准备时长，单位为秒，包括沙箱启动和初始化；子线程返回 0 。
status string | 线程状态
线程状态：
running 智能体正在处理
idle 空闲（等待用户输入或工具结果）
rescheduling 调度中
terminated 已终止
type string | 对象类型
对象类型，固定为 session_thread
updated_at string | 更新时间
最近一次线程状态变化的时间，采用 RFC 3339 格式。
usage object | 用量统计
当前线程运行期间累计的运行时长、模型 token 和服务端搜索请求统计。用量统计暂不可用时，服务端不返回该字段。
active_seconds number | 累计运行时长
usage.active_seconds
当前线程处于 running 状态的累计时长，单位为秒。
cache_creation object | 缓存创建统计
usage.cache_creation
当前线程的提示词缓存创建 token 统计。当前服务端不区分缓存有效期，两个字段均返回 0 。ephemeral_1h_input_tokens integer | 1 小时缓存输入 token 数
usage.cache_creation.ephemeral_1h_input_tokens
1 小时有效期提示词缓存的输入 token 数。当前固定返回 0 。
ephemeral_5m_input_tokens integer | 5 分钟缓存输入 token 数
usage.cache_creation.ephemeral_5m_input_tokens
5 分钟有效期提示词缓存的输入 token 数。当前固定返回 0 。
cache_read_input_tokens integer | 缓存读取 token 数
usage.cache_read_input_tokens
当前线程累计从提示词缓存读取的输入 token 数。
input_tokens integer | 输入 token 数
usage.input_tokens
当前线程内所有模型请求累计消耗的未缓存输入 token 数。
output_tokens integer | 输出 token 数
usage.output_tokens
当前线程内所有模型请求累计生成的输出 token 数。
server_tool_use object | 服务端工具用量
usage.server_tool_use
当前线程内服务端托管搜索工具累计发起的请求次数。
general_search_requests integer | 通用搜索请求次数
usage.server_tool_use.general_search_requests
服务端执行通用搜索的累计请求次数。
visual_search_requests integer | 视觉搜索请求次数
usage.server_tool_use.visual_search_requests
服务端执行视觉搜索的累计请求次数。
web_fetch_requests integer | 网页抓取请求次数
usage.server_tool_use.web_fetch_requests
服务端执行网页抓取的累计请求次数。
web_search_requests integer | 联网搜索请求次数
usage.server_tool_use.web_search_requests
服务端执行联网搜索的累计请求次数。
