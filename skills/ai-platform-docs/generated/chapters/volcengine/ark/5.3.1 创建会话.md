5.3 Sessions
5.3.1 创建会话
POST https://ark.cn-beijing.volces.com/api/v3/sessions
创建会话并绑定指定的智能体与环境。创建时可引用已有资源、为本次会话覆写部分配置，或内联创建新的 Agent 和 Environment。创建成功后，可使用返回的会话 ID 发送事件、查询状态、升级配置、归档或删除会话。已归档的智能体和 Environment 不能用于创建新会话。
可引用已创建的智能体和 Environment，也可在请求中内联创建新的 Agent 和 Environment。挂载文件、记忆库或凭证时，仍需先创建对应资源并取得其 ID。如需在创建会话的同时提交首批任务，传入 initial_events ；服务端会在会话创建后按顺序投递事件并启动智能体循环。
根据目标选择接口：
需要新会话或更换绑定的智能体、环境时，使用本接口。
只修改标题或标签：使用 更新会话标题和标签 。
保留同一会话并刷新配置：使用 升级会话 。
单个智能体默认最多可同时拥有 10000 个活跃会话（活跃状态指非 archived 、 terminated 状态）；达到配额时，创建会话接口返回 HTTP 429 SessionQuotaExceeded 。实际配额可能因账号配置而不同。说明
resources 中可通过 file_id 挂载 Files API 已上传的文件， purpose 为 agent 或 user_data的文件均可使用；文件能否直接进入模型上下文，由后续 user.message 内容块和模型能力决定。
传入 agent_with_overrides 对象可在本次会话中临时调整所引用 Agent 的模型、系统提示词、工具、MCP 服务、技能或多智能体协作配置。覆写不会创建新的 Agent 版本。
传入 environment 覆写对象可在本次会话中临时调整所引用 Environment 的部分运行配置。覆写不会修改原 Environment，也不影响其他会话。
直接在 agent 中填写 name 和 model ，并在 environment 中填写 name 和 config 时，
服务端会先创建新的 Agent 和 Environment，再使用这些资源创建会话。响应通过 
created_resources 返回新资源 ID。
传入非空 initial_events 时，会话创建后立即投递事件并启动智能体循环，创建响应可能为 running ；省略或传入空数组时以 idle 创建。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。

**传 ** [] ：清除自定义策略并改用运行时默认行为，不表示关闭自动压缩。

生成压缩摘要时使用的自定义指令。省略、传 null 或空字符串时不保存自定义指令；非空值不能仅包含空白字符。
mcp_servers object[] | MCP 服务列表

agent.mcp_servers.type

MCP 服务名称，最长 255 个字符，用于在当前 Agent 中识别该服务；配置 MCP 工具集时，tools[].mcp_server_name 必须填写此名称。

agent.model

推理投入档位。省略时沿用基础智能体的配置；传空字符串时使用当前模型的默认配置。
传入不支持的取值时返回 HTTP 400 InvalidParameter 。各模型支持的取值和默认值，请参见 模型支持的参数列表 。取值： none / minimal / low / medium / high / xhigh / max 。

agent.model.service_tier
推理服务档位。省略时沿用基础智能体的配置；传空字符串时使用当前模型的默认配置。
传入不支持的取值时返回 HTTP 400 InvalidParameter 。各模型支持的取值和默认值，请参见 模型支持的参数列表 。取值： auto / default / fast 。

agent.model.speed
模型推理速度档位。省略时沿用基础智能体的配置；传空字符串时使用模型服务的默认配置。并非所有模型都支持 fast ，传入不支持的取值时返回 HTTP 400 InvalidParameter 。取值： standard / fast 。

agent.model.thinking
思考模式。 auto 表示由模型判断是否启用思考；省略时沿用基础智能体的配置；传空字符串时使用当前模型的默认配置。
传入不支持的取值时返回 HTTP 400 InvalidParameter 。各模型支持的取值和默认值，请参见 模型支持的参数列表 。取值： enabled / disabled / auto 。
