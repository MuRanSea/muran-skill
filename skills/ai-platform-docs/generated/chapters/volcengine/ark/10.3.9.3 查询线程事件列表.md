10.3.9.3 查询线程事件列表
GET https://ark.cn-beijing.volces.com/api/v3/sessions/{sessionId}/threads/{threadId}/events分页查询指定线程的历史事件列表，仅返回该线程相关的事件，支持按时间范围、事件类型等条件过滤。返回的事件结构与流式接口一致，具体字段定义请参考 会话事件结构参考 。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
sessionId string 必选 | 会话 ID
会话 ID，格式为 sesn- 开头的字符串
threadId string 必选 | 线程 ID
线程 ID，格式为 sthr- 开头的字符串
Query 参数
在 URL Query String 中传入。
created_at[gt] string | 起始时间（不含）
起始时间（不含），ISO 8601 / RFC3339 格式，仅返回该时间之后产生的事件。created_at 四个边界至多用两个组成区间
created_at[gte] string | 起始时间（含）
起始时间（含），ISO 8601 / RFC3339 格式，仅返回该时间起（含）产生的事件。created_at 四个边界至多用两个组成区间
created_at[lt] string | 结束时间（不含）
结束时间（不含），ISO 8601 / RFC3339 格式，仅返回该时间之前产生的事件。created_at 四个边界至多用两个组成区间
created_at[lte] string | 结束时间（含）
结束时间（含），ISO 8601 / RFC3339 格式，仅返回该时间前（含）产生的事件。created_at 四个边界至多用两个组成区间
limit integer 默认值 50 | 每页事件数
每页返回的事件数量。
说明
当 limit 大于 200 时，服务端会按 200 处理，不会返回参数错误。
取值范围： [1, 200]
order string 默认值 asc | 排序方向
排序方向， asc 按事件产生时间正序（从旧到新）， desc 倒序。
page string | 分页游标
分页游标（opaque cursor），传入上一页返回的 next_page 获取下一页
types string[] | 事件类型白名单
事件类型白名单，多个类型请使用数组传入，例如 types=user.message&types=agent.message响应参数
data object[] | 事件列表
事件列表，每个元素为一个 SessionEvent 对象，仅包含指定线程相关事件。包含公共字段（ id / type /processed_at / session_id / session_thread_id （本接口中始终等于路径参数 thread_id ）/ sequence ）与业务字段（随 type 不同）。完整字段结构详见 会话事件结构参考 。
id string | 事件 ID
data.id
事件唯一标识符
processed_at string | 处理时间
data.processed_at
事件处理时间，ISO 8601 格式
sequence integer | 序列号
data.sequence
事件在会话内的单调递增序列号
session_id string | 会话 ID
data.session_id
事件所属会话 ID
type string | 事件类型
data.type
事件类型（如 user.message 、 agent.message 、 session.status_idle 等）
session_thread_id string | 线程 ID
data.session_thread_id
事件所属线程 ID，本接口返回值中始终等于路径参数 thread_id ，不会为 null
next_page string | 下一页游标
下一页游标（opaque），传入下一次请求的 page 参数即可获取下一页；若无更多数据则不返回该字段
