11.5.6.2 批量创建记忆
POST https://ark.cn-beijing.volces.com/api/v3/memory_stores/{memoryStoreId}/memories/batch_create在指定记忆库中批量创建多条记忆。相比单条创建接口，批量接口一次请求可提交最多 100 条记忆、总内容不超过 50 MB；服务端逐条处理并返回每条的成功或失败结果，单条失败不影响其他条目。说明
单批最多 100 条，总内容大小上限 50 MB，超限请分批调用。
每条记忆按 path 唯一定位，批内 path 重复整批拒绝（400）。
on_conflict 决定同 path 已存在时的行为，取值 overwrite （覆盖生成新版本）或 fail （该条目返回冲突错误）。
响应中的 results 与请求 items 按顺序一一对应；单条通过 memory / error 二选一返回。鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
memoryStoreId string 必选 | 记忆库 ID
目标记忆库 ID。通过创建记忆库接口 (POST /memory_stores) 返回, 或通过查询记忆库列表接口 (GET /memory_stores) 获取。
Body 参数
items object[] 必选 | 记忆列表
待创建的记忆条目列表，最多 100 条；批内 path 重复整批拒绝
content string 必选 | 记忆内容
items.content
记忆内容正文，单条大小上限 ≤100KB
path string 必选 | 记忆路径
items.path
记忆在记忆库中的层次化路径，长度 1-1024 字符
on_conflict string | 冲突策略
当目标 path 已存在同名记忆时的处理策略：
overwrite ：用新内容覆盖已有记忆，生成新版本
fail ：该条目返回冲突错误，其他条目继续处理
响应参数
results object[] | 处理结果列表
批量处理结果列表，与请求 items 顺序一一对应；每个元素或返回 memory （成功），或返回 error（失败）
path string | 记忆路径
results.path
对应请求 items[].path ，用于关联请求条目与结果
error object | 错误信息
results.error
条目失败时的错误信息；成功时该字段为空
message string | 错误描述
results.error.message
面向开发者的错误描述
type string | 错误类型
results.error.type
错误类型标识，用于分类和排查失败原因
memory object | 记忆详情
results.memory
成功创建（或覆盖）的记忆详情；条目失败时该字段为空
content_sha256 string | 内容摘要
results.memory.content_sha256
内容的 SHA-256 摘要（十六进制小写）
content_size_bytes integer | 内容字节数
results.memory.content_size_bytes
记忆内容的字节大小
created_at string | 创建时间
results.memory.created_at
创建时间，RFC 3339 UTC 毫秒格式
created_by object | 创建者
results.memory.created_by
记忆的创建者信息
type string | 操作者类型
results.memory.created_by.type
操作者类型，固定为 user_actor
user_id string | 用户 ID
results.memory.created_by.user_id
操作者用户 ID
id string | 记忆 ID
results.memory.id
记忆条目唯一标识符，格式为 mem- 开头的小写 ULID
memory_store_id string | 记忆库 ID
results.memory.memory_store_id
所属记忆库 ID
memory_version_id string | 版本 ID
results.memory.memory_version_id
当前 head 版本 ID
path string | 记忆路径
results.memory.path
记忆在记忆库中的层次化路径
type string | 对象类型
results.memory.type
对象类型，固定为 memory
updated_at string | 更新时间
results.memory.updated_at
最后更新时间，RFC 3339 UTC 毫秒格式
content string | 记忆内容
results.memory.content
记忆内容正文；仅单点读取（Get）时返回
