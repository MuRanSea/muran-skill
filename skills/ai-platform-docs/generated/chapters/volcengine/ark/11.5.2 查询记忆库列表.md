11.5.2 查询记忆库列表
GET https://ark.cn-beijing.volces.com/api/v3/memory_stores
分页查询当前账号下的记忆库列表，默认按创建时间倒序返回。支持按创建人和库名模糊过滤，采用opaque cursor 分页。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Query 参数
在 URL Query String 中传入。
created_by string[] | 创建人过滤
按创建人过滤，可传入多个用户 ID 取并集；空或不传时忽略
limit integer 默认值 20 | 每页数量
每页返回的数量,。
取值范围： [1, 100]
name string | 库名模糊过滤
按库名模糊过滤（LIKE %name%）
page string | 分页游标
分页 opaque cursor，传入上一次响应返回的 next_page 以获取下一页
响应参数
data object[] | 记忆库列表
created_at string | 创建时间
data.created_at
创建时间，RFC 3339 UTC 毫秒格式
created_by object | 创建者
data.created_by
记忆库创建者信息
type string | 操作者类型
data.created_by.type
操作者类型，固定为 user_actor
user_id string | 用户 ID
data.created_by.user_id
操作者用户 ID
id string | 记忆库 ID
data.id
记忆库唯一标识符，格式为 memstore- 开头的小写 ULID
memory_count integer | 记忆条目数量
data.memory_count
当前记忆库内的记忆条目数量
metadata object | 自定义元数据
data.metadata
用户自定义元数据，键值均为字符串；恒返回，缺省为空对象
name string | 记忆库名称
data.name
记忆库名称，用于用户识别和管理
session_count integer | 关联会话数
data.session_count
当前挂载该记忆库的活跃会话去重数
storage_bytes integer | 存储字节数
data.storage_bytes
当前记忆库占用的存储字节数
type string | 对象类型
data.type
对象类型，固定为 memory_store
updated_at string | 更新时间
data.updated_at
更新时间，RFC 3339 UTC 毫秒格式
description string | 记忆库描述
data.description
记忆库描述，空串时省略
next_page string | 下一页游标
下一页 opaque cursor，格式为 page_<token> ；作为 page 参数传入以获取下一页；无更多数据时为空
