10.2.6 自建 Worker
10.2.6.1 长轮询拉取 work
GET https://ark.cn-beijing.volces.com/api/v3/environments/{environmentId}/work/poll长轮询拉取待执行 work；命中时返回待执行 work，供 worker 拉起执行。如需凭据，响应中可包含凭据payload。
本接口用于自托管环境的 Worker 调用。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
environmentId string 必选 | 环境 ID
Query 参数
在 URL Query String 中传入。
block_ms integer | 长轮询等待时间
长轮询等待时间，取值 1-999 毫秒；缺省则非阻塞立即返回。
reclaim_older_than_ms integer | 认领超时阈值
认领超时时间阈值（毫秒）；超过该时间未 heartbeat 的 work 可被其它 worker 重新认领。Header 参数
在 HTTP 请求头中传入。
Ark-Worker-ID string | Worker 实例 ID
Worker 实例 ID。服务端会使用该 Header 统计最近 30 秒内曾 Poll 过的 worker 数，用于队列水位观测。响应参数
created_at string | 创建时间
服务端落库产生 work 项时的时间戳（RFC 3339 格式）。
data object | 工作载荷
该 work 要执行的具体工作载荷；当前仅 session 一种。
id string | 业务对象 ID
data.id
业务对象 ID，例如 session ID。
type string | 载荷类型
data.type
业务载荷类型，当前固定为 session 。
environment_id string | 环境 ID
归属的 environment 标识符（形如 env-... ）。
id string | Work 标识符
Work 标识符；值等同 session_id（形如 sesn-... ）。
state string | 当前状态
当前状态。取值：
queued ：已入队；
starting ：已认领启动中；
active ：执行中；
stopping ：请求停止中；
stopped ：已停止
type string | 对象类型
类型标识，固定为 work 。
acknowledged_at string | 认领时间
被某个 worker 认领时的时间戳；未认领时为空。
latest_heartbeat_at string | 最近心跳时间
最近一次 heartbeat 时间；未曾收到任何 heartbeat 时为空。
secret string | 凭据 payload
本次 work 执行所需的凭据 payload。如需凭据，仅在 poll 响应返回；其它 Work 查询路径不会返回。started_at string | 开始时间
work 实际开始执行的时间戳；未开始执行时为空。
stop_requested_at string | 停止请求时间
收到 Stop 请求的时间戳；未收到时为空。
stopped_at string | 停止时间
最终停止时间戳；state 变为 stopped 之后落值。
tags object[] | 资源标签
与本 work item 关联的火山资源标签列表。
key string | 标签 key
tags.key
value string | 标签 value
tags.value
updated_at string | 更新时间
最近一次状态迁移的时间戳（RFC 3339 格式）。
