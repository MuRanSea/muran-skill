10.5.6.4 查询记忆详情
GET https://ark.cn-beijing.volces.com/api/v3/memory_stores/{memoryStoreId}/memories/{memoryId}按 ID 查询单条记忆的完整信息，包括 content 正文。
浏览路径和精简元信息时，使用查询记忆列表接口。
获取某条记忆的完整正文时，使用本接口，并传入同一记忆库下的完整记忆 ID。
调用前需已创建记忆库和记忆条目。
说明
记忆库不存在或不可访问时返回 404 InvalidMemoryStore.NotFound ；记忆不存在时返回 404 ResourceNotFound 。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
memoryId string 必选 | 记忆 ID
用于定位要查询的记忆，以 mem- 开头。传入创建、列表或更新接口返回的完整 ID，不要自行拼接。memoryStoreId string 必选 | 记忆库 ID
用于指定记忆所属的记忆库，以 memstore- 开头。传入创建或列表接口返回的完整 ID，不要自行拼接。响应参数
content string | 记忆内容
记忆正文，为 UTF-8 文本。本接口返回 content ；可结合 content_sha256 和 content_size_bytes 校验完整性。
content_sha256 string | 内容摘要
记忆正文的 SHA-256 摘要，以小写十六进制字符串表示，可用于校验内容完整性。
content_size_bytes integer | 内容字节数
记忆正文采用 UTF-8 编码后的字节数。
created_at string | 创建时间
记忆创建时间，采用 RFC 3339 UTC 格式。
created_by object | 创建者
创建该记忆的操作者信息。
type string | 操作者类型
created_by.type
操作者类型。 user_actor 表示通过用户身份写入， session_actor 表示会话中的智能体写入。session_id string | 会话 ID
created_by.session_id
写入该记忆的会话 ID，仅 type 为 session_actor 时返回。
user_id string | 用户 ID
created_by.user_id
写入该记忆的用户 ID，仅 type 为 user_actor 时返回。
id string | 记忆 ID
服务端生成的记忆 ID，以 mem- 开头。后续查询、更新或删除记忆时，作为 memoryId 路径参数传入。
memory_store_id string | 记忆库 ID
该记忆所属的记忆库 ID。
memory_version_id string | 版本 ID
记忆条目的当前版本标识。内容或路径成功更新后，该值会变化。
path string | 记忆路径
记忆在记忆库中的文件路径。
type string | 对象类型
对象类型，固定为 memory 。
updated_at string | 更新时间
记忆最后更新时间，采用 RFC 3339 UTC 格式。
