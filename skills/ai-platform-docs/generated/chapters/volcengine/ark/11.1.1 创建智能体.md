11. Managed Agents API
11.1 Agents
11.1.1 创建智能体
POST https://ark.cn-beijing.volces.com/api/v3/agents
创建一个新的托管智能体，可以配置模型、工具、MCP 服务、技能等参数。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Body 参数
model object 必选 | 模型配置
智能体使用的模型配置
id string 必选 | 模型 ID 或推理接入点 ID
model.id
例如模型 ID doubao-seed-2-1-pro-260628 ，或推理接入点 ID ep-20260907123456-abcd1 。reasoning_effort string | 推理投入档位，对应底层模型调用的 reasoning_effort 字段model.reasoning_effort
可填 none 、 minimal 、 low 、 medium 、 high 、 xhigh 、 max ；实际支持值与默认值以模型元数据为准。不设置或传空字符串时，Managed Agents 使用模型元数据中的默认值；如模型元数据未配置默认值，则不会向底层模型调用传递该字段，由底层模型服务按默认策略处理。各模型支持的取值和默认值，请参见 模型支持的参数列表 。
service_tier string | 推理服务档位，对应底层模型调用的 service_tier 字段
model.service_tier
可填 auto 、 default 、 fast ；实际支持值与默认值以模型元数据为准。不设置或传空字符串时，Managed Agents 使用模型元数据中的默认值；如模型元数据未配置默认值，则不会向底层模型调用传递该字段，由底层模型服务按默认策略处理。传入不支持的取值时返回 400 InvalidParameter 。各模型支持的取值和默认值，请参见 模型支持的参数列表 。
speed string | 模型速度档位
model.speed
空字符串走默认。
thinking string | 思考开关，对应底层模型调用的 thinking.type 字段
model.thinking
可填 enabled 、 disabled 、 auto ； auto 表示由模型判断是否思考，不表示继承。实际支持值与默认值以模型元数据为准。不设置或传空字符串时，Managed Agents 使用模型元数据中的默认值；如模型元数据未配置默认值，则不会向底层模型调用传递该字段，由底层模型服务按默认策略处理。传入不支持的取值时返回 400 InvalidParameter 。各模型支持的取值和默认值，请参见 模型支持的参数列表 。name string 必选 | 智能体名称
智能体名称，长度限制 1-100 个字符
description string | 智能体描述
智能体描述，说明智能体的用途和能力，最大 2048 字符
mcp_servers object[] | MCP 服务配置
配置给智能体使用的 MCP 服务列表，最多 20 项
name string 必选 | 在本 Agent 内唯一
mcp_servers.name
被 tools[].mcp_server_name 引用。
type string 必选 | MCP server 类型，当前固定 "url"
mcp_servers.type
取值固定为 url 。
url string 必选 | MCP server URL
mcp_servers.url
metadata object | 自定义元数据
用户自定义元数据，键值对形式，最多支持 16 个键；key 长度不超过 64 字符，value 长度不超过 512 字符
multiagent object | 多智能体配置
多智能体协作配置
agents object[] 必选 | 下属 Agent 数组
multiagent.agents
1–20 项；深度限制为 1（被引用的 Agent 自身不能再有 multiagent ）。
type string 必选 | 引用类型
multiagent.agents.type
id string | 被引用 Agent 的 ID
multiagent.agents.id
version integer | 被引用 Agent 的版本号
multiagent.agents.version
type string 必选 | 拓扑类型
multiagent.type
skills object[] | 技能配置
绑定到智能体的技能列表，最多 20 项
type string 必选 | Skill 来源类型
skills.type
skill_hub ：来自 SkillHub 的公共 Skill。
custom ：当前账号通过 Skills API 创建的自定义 Skill。
skill_id string | Skill ID，形如 skill-...
skills.skill_id
version string | Skill 版本号，可选；不传走最新
skills.version
system string | 系统提示词
系统提示词，定义智能体的角色和行为规则，最大 100000 字符
tags object[] | 标签列表
用户自定义标签列表
key string 必选 | 标签键
tags.key
标签键，用于分类和检索
value string | 标签值
tags.value
tools object[] | 工具配置
配置给智能体使用的工具列表，支持内置工具集、MCP 工具、自演进工具和自定义工具
type string 必选 | 工具类型
tools.type
各取值含义如下：
agent_toolset_20260701 ：使用方舟内置工具，包括文件操作、命令执行和网络访问工具。mcp_toolset ：使用指定 MCP Server 提供的工具。需要同时填写 mcp_server_name 。
evolution ：启用自演进工具。需要在 configs 中配置 advisor 。
custom ：定义由客户端执行的自定义工具。需要同时填写 name 、 description 和 input_schema 。configs object[] | 内置工具集、 mcp_toolset 和 evolution 专用
tools.configs
用于按工具名称配置启用状态和权限策略。
evolution 必须包含一项 name 为 advisor 的配置，且该配置不能设置 permission_policy 。name string 必选 | 工具名称
tools.configs.name
工具名称。可用值取决于工具集：
agent_toolset_20260701 ： bash 、 bash_status 、 edit 、 read 、 write 、 glob 、 grep 、web_fetch 、 web_search
mcp_toolset ：MCP Server 提供的工具名称
evolution ： advisor
enabled boolean | 是否启用
tools.configs.enabled
是否启用该工具： true 启用该工具； false 禁用该工具。省略时沿用默认配置。
permission_policy object | 权限策略
tools.configs.permission_policy
工具权限策略，省略沿用默认配置。 evolution 中的 advisor 不支持设置该字段。
type string 必选 | 策略类型
tools.configs.permission_policy.type
策略类型， always_allow 表示总是允许调用， always_ask 表示每次使用前需要用户确认default_config object | 内置工具集和 mcp_toolset 专用；未在 configs 中显式列出的工具使用此默认配置
tools.default_config
evolution 不支持该字段。
enabled boolean | 是否启用
tools.default_config.enabled
是否默认启用工具： true 默认启用该工具集下所有未在 configs 中单独配置的工具； false 默认禁用。
permission_policy object | 权限策略
tools.default_config.permission_policy
默认工具权限策略
type string 必选 | 策略类型
tools.default_config.permission_policy.type
策略类型， always_allow 表示总是允许调用， always_ask 表示每次使用前需要用户确认description string | custom 专用；1–10,000 字符
tools.description
input_schema object | custom 专用；工具输入参数的 JSON Schema 对象
tools.input_schema
properties object | 属性映射
tools.input_schema.properties
JSON Schema 属性映射，key 为属性名、value 为该属性的 JSON Schema 子对象（值为任意 JSON 对象）required string[] | 必填参数名称列表
tools.input_schema.required
调用自定义工具时必须提供的参数名称列表。每个名称必须对应 properties 中定义的属性。type string 默认值 object | Schema 类型
tools.input_schema.type
JSON Schema 的顶层类型，固定为 object 。
mcp_server_name string | mcp_toolset 专用；须匹配 mcp_servers[].name 。
tools.mcp_server_name
name string | custom 专用；1–128 字符， [A-Za-z0-9_-]
tools.name
响应参数
created_at string | 创建时间
智能体创建时间，ISO 8601 格式
id string | 智能体 ID
智能体唯一标识符，格式为 agent- 开头的字符串
name string | 智能体名称
智能体名称，用于用户识别和管理
type string | 对象类型
对象类型，固定为 agent
updated_at string | 更新时间
智能体最后更新时间，ISO 8601 格式
version integer | 版本号
智能体版本号，每次更新递增
description string | 智能体描述
智能体描述，用于说明智能体的用途、能力范围、适用场景等
