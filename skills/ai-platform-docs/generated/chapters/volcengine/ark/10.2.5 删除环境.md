10.2.5 删除环境
DELETE https://ark.cn-beijing.volces.com/api/v3/environments/{environment_id}
永久删除当前项目中指定的 Environment。
删除条件
当 Environment 仍被 idle 或 running 状态的 Session 使用时，服务端返回 HTTP 400 
InvalidAction 。先结束相关 Session，再删除 Environment。
删除操作不可撤销。重复删除已不存在的 Environment 会返回 HTTP 404 
InvalidEnvironment.NotFound ；超时重试时，可将该结果视为资源已经删除。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
environment_id string 必选 | 环境 ID
要删除的 Environment ID，以 env- 开头。可从创建环境或查询环境列表接口的响应中获取。响应参数
id string | 环境 ID
已删除的 Environment ID，以 env- 开头，与路径参数中的值相同。
type string | 对象类型
对象类型，固定为 environment_deleted 。
