10.3.8.2 查询会话资源列表
GET https://ark.cn-beijing.volces.com/api/v3/sessions/{session_id}/resources
查询指定会话已挂载的资源列表。接口全量返回，最多返回 1000 条，无分页参数。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
session_id string 必选 | 会话 ID
会话 ID，格式为 sesn- 开头的字符串
响应参数
data object[] | 资源列表
指定会话当前挂载的资源列表。
文件资源 object
通过 Files API 上传并挂载到会话的文件。
created_at string | 挂载时间
data.created_at
资源挂载到会话的时间，采用 RFC 3339 格式。
id string | 资源 ID
data.id
会话资源 ID。
type string | 资源类型
data.type
资源类型，固定为 file 。
updated_at string | 更新时间
data.updated_at
会话资源信息最后更新的时间，采用 RFC 3339 格式。
access string | 访问权限
data.access
文件访问权限，固定为 read_only 。
file_id string | 文件 ID
data.file_id
当前可用的文件 ID。
mount_path string | 挂载路径
data.mount_path
文件在会话运行环境中的完整挂载路径。
记忆库资源 object
挂载到会话的记忆库。
created_at string | 挂载时间
data.created_at
资源挂载到会话的时间，采用 RFC 3339 格式。
id string | 资源 ID
data.id
会话资源 ID。
type string | 资源类型
data.type
资源类型，固定为 memory_store 。
updated_at string | 更新时间
data.updated_at
会话资源信息最后更新的时间，采用 RFC 3339 格式。
access string | 访问权限
data.access
会话对记忆库的访问权限。可选值： read_only 、 read_write 。
memory_store_id string | 记忆库 ID
data.memory_store_id
挂载到会话的记忆库 ID。
TOS 资源 object
挂载到会话的 TOS 对象目录。
created_at string | 挂载时间
data.created_at
资源挂载到会话的时间，采用 RFC 3339 格式。
id string | 资源 ID
data.id
会话资源 ID。
type string | 资源类型
data.type
资源类型，固定为 tos 。
updated_at string | 更新时间
data.updated_at
会话资源信息最后更新的时间，采用 RFC 3339 格式。
access string | 访问权限
data.access
会话对 TOS 目录的访问权限。可选值： read_only 、 read_write 。
mount_path string | 挂载路径
data.mount_path
TOS 目录在会话运行环境中的挂载路径。创建会话时未指定挂载路径，则不返回该字段。
tos_bucket string | TOS 存储桶
data.tos_bucket
TOS 挂载源所在的存储桶名称。
tos_key string | TOS 目录前缀
data.tos_key
TOS 中已挂载目录的对象前缀。
tos_region string | TOS 地域
data.tos_region
TOS 挂载源所在地域的 Region ID。
