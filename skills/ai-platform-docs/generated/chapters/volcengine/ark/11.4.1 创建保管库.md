11.4 Vaults
11.4.1 创建保管库
POST https://ark.cn-beijing.volces.com/api/v3/vaults
创建一个新的凭证保管库，用作凭证的逻辑容器。保管库本身不携带敏感数据，敏感数据存储在其下挂的凭证中。
面向多租户产品的用户级凭证场景，建议在 metadata 中使用 external_user_id 键存储客户产品侧的用户唯一标识，用于将保管库与终端用户建立映射。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Body 参数
display_name string 必选 | 保管库展示名
保管库展示名，长度限制 1-255 个字符
metadata object | 自定义元数据
用户自定义元数据，键值均为字符串
用户级凭证场景推荐使用 external_user_id 键存储客户产品侧的用户唯一标识，用于将保管库与终端用户建立映射。例如 {"external_user_id": "usr_abc123"} 。
响应参数
created_at string | 创建时间
保管库创建时间，RFC 3339 格式时间戳
display_name string | 保管库展示名
保管库的展示名称，用于用户识别
id string | 保管库 ID
保管库唯一标识符
type string | 对象类型
对象类型，固定为 vault
updated_at string | 更新时间
保管库最后更新时间，RFC 3339 格式时间戳
metadata object | 自定义元数据
用户自定义键值对元数据；未设置或清空时返回 null
