10.3.7.3 流式获取会话事件
GET https://ark.cn-beijing.volces.com/api/v3/sessions/{sessionId}/events/stream
通过 SSE（Server-Sent Events）协议流式订阅会话内实时产生的事件。智能体处理消息的过程中会不断推送事件，包括用户消息、智能体回复、工具调用、状态变更等。所有事件的结构定义请参考 会话事件结构参考 。
说明
不支持历史回放：订阅建立成功后只会收到此后产生的事件。断线重连后想补漏需要走 获取会话事件列表 接口，通过时间窗口拉取历史事件。
连接建立后，服务端会保持长连接，持续推送事件，直到会话结束或连接断开。
服务端会周期性发送 SSE 心跳注释行（ : heartbeat ）避免连接被中间代理超时切断；客户端按SSE 协议忽略以 : 开头的注释行即可。
流结束时服务端会发送 data: [DONE] 帧。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
sessionId string 必选 | 会话 ID
会话 ID，格式为 sesn- 开头的字符串
Query 参数
在 URL Query String 中传入。
event_deltas array | 流式预览事件类型的 opt-in 白名单
指定希望以增量帧（ event_start / event_delta ）流式预览的事件类型白名单。未提供该参数时本连接不下发任何 event_start / event_delta 帧，只推送 buffered 的最终事件；提供后对白名单内的事件类型（当前支持 agent.message 、 agent.thinking ）额外下发对应的 event_start 与 event_delta （besteffort，不进入 event history）。多值可重复参数（ ?event_deltas=agent.message&event_deltas=agent.thinking ）或逗号分隔（ ?event_deltas=agent.message,agent.thinking ）。未识别的值会被忽略。
响应参数
流式响应（SSE）
data string | 事件 JSON 数据
事件数据，JSON 格式字符串。反序列化后为一个会话事件对象。当前 buffered 事件以及 event_start 、event_delta 预览帧均包含 id 、 type 、 processed_at ； session_thread_id 仅由特定事件携带，其他事件会省略该字段。其余业务字段随 type 不同，完整结构详见 会话事件结构参考 。
event string | SSE 事件类型
SSE 事件类型标识符，固定为 message
