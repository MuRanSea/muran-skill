11.6 Memory Stores
11.6.1 创建记忆库
POST https://ark.cn-beijing.volces.com/api/v3/memory_stores
创建一个记忆库，用于集中存放智能体的长期记忆。创建后可向库内写入带路径的记忆条目，并将记忆库挂载到会话。
说明
新建记忆库的 memory_count 、 storage_bytes 和 session_count 均为 0。
常见失败原因：名称为空或超过 64 个字符、描述采用 UTF-8 编码后超过 2048 字节、元数据不符合限制，或当前账号和项目已达到 300 个记忆库。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Body 参数
name string 必选 | 记忆库名称
用于识别和管理记忆库的名称。同一账号和项目下允许存在同名记忆库，可通过各自的记忆库 ID 区分。注意
长度为 1–64 个字符。
description string | 记忆库描述
用于说明记忆库的用途和存储内容。
注意
UTF-8 编码后不得超过 2048 字节。
metadata object | 自定义元数据
用于标记和分类记忆库的自定义键值对。
注意
最多包含 64 个非空键；键和值均为字符串，UTF-8 序列化后不得超过 8192 字节。
响应参数
created_at string | 创建时间
记忆库创建时间，采用 RFC 3339 UTC 格式。
created_by object | 创建者
创建该记忆库的操作者信息。
type string | 操作者类型
created_by.type
创建者类型，固定为 user_actor 。
user_id string | 用户 ID
created_by.user_id
创建该记忆库的用户 ID，由服务端根据当前请求的身份自动记录，可用于按创建者筛选记忆库。id string | 记忆库 ID
服务端生成的记忆库 ID，以 memstore- 开头。后续查询、更新或删除记忆库时，作为 memory_store_id路径参数传入。
memory_count integer | 记忆条目数量
记忆库当前包含的记忆条目数量。
metadata object | 自定义元数据
创建或更新记忆库时设置的自定义元数据。
name string | 记忆库名称
记忆库名称，用于识别和管理该记忆库。
session_count integer | 活跃会话数
当前挂载该记忆库的活跃会话数量。
storage_bytes integer | 内容总字节数
记忆库当前所有记忆正文的总字节数。
type string | 对象类型
对象类型，固定为 memory_store 。
updated_at string | 更新时间
记忆库更新时间，采用 RFC 3339 UTC 格式。
description string | 记忆库描述
记忆库的用途和存储内容说明。
dream_id string | Dream 任务 ID
仅 Dream 输出记忆库返回，表示创建该输出 Memory Store 的 Dream ID；普通 Memory Store 不返回该字段。
dream_status string | Dream 任务状态
仅 Dream 输出记忆库返回，表示创建该输出 Memory Store 的 Dream 当前状态；普通 Memory Store 不返回该字段。可选值： pending 、 running 、 completed 、 failed 、 canceled 。
mountable boolean | 是否可挂载
表示当前是否可以挂载、读取或修改该 Memory Store。普通 Memory Store 返回 true ；Dream 输出记忆库在 pending 或 running 状态时返回 false ，在 completed 、 failed 或 canceled 状态时返回 true 。
project_name string | 项目名称
记忆库实际所属的项目名称。
usage_ready boolean | 用量是否就绪
表示 memory_count 和 storage_bytes 是否已可作为准确统计值。普通 Memory Store 返回 true ；Dream 输出记忆库在 pending 或 running 状态时返回 false ，在 completed 、 failed 或 canceled 状态时返回 true 。
