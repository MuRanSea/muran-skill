Java SDK
适用范围
本 SDK 仅适用于 Java 服务端开发，暂不支持 Android 平台。若需在 Android 平台使用相关功能，需由客户自行开发适配方案。
前提条件
检查并安装 Java 版本，Java 版本需 1.8 或以上。
如未安装 Java 或者版本不满足要求，可访问 Oracle 官方网站 下载并安装适合操作系统的 Java 版本。请确保选择 1.8 或以上版本。
