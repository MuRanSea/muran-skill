11.5.6.5 删除凭证
DELETE https://ark.cn-beijing.volces.com/api/v3/vaults/{vault_id}/credentials/{credential_id}删除指定凭证。
警告
删除后无法恢复或读取该凭证。后续运行也无法再使用该凭证访问 MCP 服务或注入环境变量。删除前请确认业务不再使用该凭证。
如果首次删除请求超时，可以使用相同的凭证 ID 重试。
在鉴权信息和项目均未改变的情况下，重试返回 404 InvalidCredential.NotFound 表示该凭证已不存在，此时停止重试。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
credential_id string 必选 | 凭证 ID
凭证 ID，以 vcrd- 开头。
vault_id string 必选 | 保管库 ID
保管库 ID，以 vlt- 开头。
响应参数
id string | 凭证 ID
已删除的凭证 ID，以 vcrd- 开头，与路径参数中的值相同。
type string | 对象类型
表示当前对象是一条已删除的凭证记录。
取值固定为 vault_credential_deleted 。
