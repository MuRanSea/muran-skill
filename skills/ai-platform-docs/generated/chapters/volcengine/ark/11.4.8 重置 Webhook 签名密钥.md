11.4.8 重置 Webhook 签名密钥
POST https://ark.cn-beijing.volces.com/api/v3/webhook_endpoints/{endpoint_id}/reset_secret为指定 Webhook 接入点生成新的签名密钥，并立即使旧密钥失效。启用和停用状态下均可调用。重置只更新 updated_at ，不改变接入点状态、停用原因、连续失败数或最近成功投递时间。接口不提供新旧密钥并行生效窗口。新密钥仅在本次成功响应中返回，响应丢失时需要再次重置并同步接收端配置。
旧密钥立即失效
重置成功后，平台不再使用旧密钥生成新签名。已经签名并发出的在途请求仍可能使用旧密钥到达。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
endpoint_id string 必选 | 接入点 ID
Webhook 接入点 ID，以 wep- 开头。该 ID 可从创建或列表接口的响应中获取。
响应参数
signing_secret string | 签名密钥
新生成的 Webhook 签名密钥，以 whsec_ 开头。关闭响应后无法再次获取。
updated_at string | 更新时间
签名密钥完成替换的时间，采用 RFC 3339 格式。
