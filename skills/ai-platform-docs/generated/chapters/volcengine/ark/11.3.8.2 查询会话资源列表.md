11.3.8.2 查询会话资源列表
GET https://ark.cn-beijing.volces.com/api/v3/sessions/{sessionId}/resources
查询指定会话已挂载的资源列表。接口全量返回，最多返回 1000 条，无分页参数。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
sessionId string 必选 | 会话 ID
会话 ID，格式为 sesn- 开头的字符串
响应参数
data object[] | 资源列表
type string | 资源类型
data.type
资源类型，枚举值： file 文件、 memory_store 记忆库、 tos TOS 对象存储
access string | 访问权限
data.access
访问模式： read_only 只读、 read_write 读写。 type=file 恒为 read_only ； type=tos 未传默认 read_only ； type=memory_store 时按入参回显。
created_at string | 创建时间
data.created_at
创建时间，ISO 8601 格式
file_id string | 文件 ID
data.file_id
文件 ID，当 type 为 file 时返回，其他 type 时该字段为空
id string | 资源 ID
data.id
资源唯一标识符
memory_store_id string | 记忆库 ID
data.memory_store_id
记忆库 ID，type 为 memory_store 时返回
mount_path string | 挂载路径
data.mount_path
沙箱内的挂载路径，type 为 file 时有效。不传时使用文件名作为路径，挂载于 /mnt/session/uploads/
{filename}。不可含 "../" 等越权路径片段。
tos_bucket string | TOS 存储桶
data.tos_bucket
TOS 挂载源所在的存储桶名称；仅当 type=tos 时返回
tos_key string | TOS 目录前缀
data.tos_key
TOS 中待挂载目录的路径前缀；仅当 type=tos 时返回。该值必须以 / 结尾，不能指向单个文件tos_region string | TOS 地域
data.tos_region
TOS 挂载源所在地域的 Region ID；仅当 type=tos 时可能返回
updated_at string | 更新时间
data.updated_at
更新时间，ISO 8601 格式
