13.11.3 查询用量明细导出任务状态
POST https://ark.cn-beijing.volcengineapi.com/?Action=GetRecordExportTask&Version=2024-01-01查询用量明细导出任务状态，并获取文件下载链接。
注意
GetRecordExportTask 接口返回的 CSV 文件中，计费字段展示方式已按用户调用情况和导出任务查询窗口的结束时间 EndTime 完成分阶段切换，变更点如下：
2026 年 9 月 2 日前已产生调用的用户：切换时刻为 2026 年 9 月 15 日。
2026 年 9 月 2 日及以后新增调用的用户：切换时刻为 2026 年 9 月 2 日。
对上述两类用户：
EndTime 晚于对应切换时刻时，CSV 不再单独返回 input_token_charge_item 、
output_token_charge_item 、 cache_hit_token_charge_item 三列，相关计费信息统一整合至 charge_value_list 字段。
EndTime 早于或等于对应切换时刻时，CSV 继续单独返回上述三列。
任务提交后，该任务对应的 CSV 字段展示方式保持不变。请按实际返回结果完成适配。
说明
需传入通过 CreateRecordExportTask 接口获取的任务 ID 作为入参。
CreateRecordExportTask 任务提交后，建议等待 5 秒再发起 GetRecordExportTask 轮询： 轮询间隔：不小于 5 秒。
单任务轮询总时长：不超过 5 分钟。
当接口返回 Succeeded 状态且包含 DownloadUrl 字段时，请立即下载 CSV 文件，避免链接过期失效，链接有效期为 12 小时。

响应参数
Task object | 任务完整状态
任务完整状态，包含任务进度、命中/导出行数及结果文件下载链接（仅在任务成功时返回）。CreateTime number | 创建时间
Task.CreateTime
任务创建时间（UTC Unix 时间戳，单位:秒），即任务被提交并创建的时刻。
Id string | 任务 ID
Task.Id
任务 ID，与请求参数 Id 一致，方便并发查询时区分结果。
Status string | 任务状态
Task.Status
任务状态机。可取值：
Pending ：任务已提交，等待调度
Running ：任务正在执行
Succeeded ：任务执行成功，可通过 DownloadUrl 下载结果
Failed ：任务执行失败，原因见 ErrorMessage
DownloadUrl string | 下载链接
Task.DownloadUrl
TOS 一次性签发的下载链接，仅当 Status 为 Succeeded 时存在有效值。
注意
下载链接有效期为 12 小时。链接过期后，FileExpired 字段值为 true ，需重新提交任务以获取新链接。
通过 DownloadUrl 下载的 CSV 文件中，计费字段展示方式已发生变更。具体的变更说明、切换时刻、兼容建议和示例代码，请参见 用量明细 CSV 解析最佳实践 。
DownloadUrlExpireTime number | 链接过期时间
Task.DownloadUrlExpireTime
下载链接的过期时间（UTC Unix 时间戳，单位：秒），有效期 12 小时，过期后对应 TOS 文件将被清理。EndTime number | 结束时间
Task.EndTime
任务结束时间（UTC Unix 时间戳，单位：秒）。代表任务进入 Succeeded 、 Failed 终态的时间；任务处理中时该字段不返回。
ErrorMessage string | 失败原因
Task.ErrorMessage
任务失败时的指引文案，仅当 Status 为 Failed 时存在有效值。
ExportCount number | 实际导出行数
Task.ExportCount
实际写入 CSV 文件的行数，最大不超过 100000 。当 TotalCount 大于 ExportCount 时，表示导出结果因达到单任务行数上限而被截断。
最大值： 100000
FileExpired number | 文件过期标识
Task.FileExpired
文件是否已过期的标识。当当前时间大于等于 DownloadUrlExpireTime 时为 true 。
QueryParams string | 原始请求参数
Task.QueryParams
原始请求参数的 JSON 字符串，用于任务回放或审计。
StartTime number | 开始时间
Task.StartTime
任务开始时间（UTC Unix 时间戳，单位：秒），对应任务状态切换为 Running 的时刻。任务未调度时该字段不返回；若任务触发系统重试，此字段始终保留首次启动时间。
TotalCount number | 命中总行数
Task.TotalCount
查询命中的总行数，用于判断 ExportCount 是否因单任务 100000 行上限被截断。
