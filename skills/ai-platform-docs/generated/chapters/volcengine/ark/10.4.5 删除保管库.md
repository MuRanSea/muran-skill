10.4.5 删除保管库
DELETE https://ark.cn-beijing.volces.com/api/v3/vaults/{vaultId}
删除指定保管库及其中的全部凭证。
警告
删除保管库会同时删除其中的全部凭证。
删除后无法恢复保管库或凭证，后续运行也无法再使用这些凭证。
删除前，确认业务不再使用该保管库。
保管库仍被 running 状态的 Session 引用时，返回 HTTP 409 Conflict 。请先中断相关 Session 并等待其不再处于 running 状态，或等待本轮对话运行结束后重试。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
vaultId string 必选 | 保管库 ID
保管库 ID，以 vlt- 开头。
响应参数
id string | 保管库 ID
已删除的保管库 ID，以 vlt- 开头，与路径参数中的值相同。
type string | 对象类型
表示当前对象是一个已删除的保管库记录。
取值固定为 vault_deleted 。
