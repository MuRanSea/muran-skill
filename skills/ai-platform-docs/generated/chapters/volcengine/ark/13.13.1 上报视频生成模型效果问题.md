13.13 效果上报
13.13.1 上报视频生成模型效果问题
POST https://prompt-pilot.cn-beijing.volces.com/case-platform?
Action=CasePlatformV1BadcaseReport&Version=2024-01-01
本接口用于上报 Doubao Seedance 2.x 系列模型的视频生成效果问题。系统根据指定的 task_id 创建Badcase 记录，并保存问题描述等反馈信息。本接口同时支持通过 Access Key 和方舟 API Key 两种方式鉴权。
注意
本接口及文档仅支持中国大陆火山方舟服务，不支持非中国大陆地区（如 BytePlus 等）。通过本接口提交 Badcase，视为您同意使用方舟排障服务，我们将严格按照《方舟平台专用条款》第 3.7.7 条第（2）项进行数据处理。详细条款请查阅：https://ark.volcengine.com/region:cn-beijing/docs/ark/volcengine-ark-platform-terms
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
【推荐】API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
【可选】Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。
请求参数
Body 参数
Feedback string 必选 | 问题描述
Badcase 的问题描述。内容不能仅包含空白字符。
Id string 必选 | 任务 ID 列表
待标记为 Badcase 的 task_id 。可提交单个 ID，也可传入多 ID 字符串。
多 ID 场景 • 系统会按半角逗号、全角逗号、换行、空格或制表符自动拆分，并移除每个 ID 首尾的空白字符和空项。
超过 max_length 限制时，接口返回 422 。
AccountId string | 火山引擎账号 ID
Id 中任务所属的火山引擎账号 ID。
使用 Access Key 调用时必填。
使用方舟 API Key 调用时可省略，系统根据 API Key 解析账号 ID。
BadcaseType string | Badcase 类型
效果问题的类型。可选值：
character_id_drift ：角色 ID 漂移
subtitle_generation_error ：字幕生成错误
logo_watermark_generated ：生成 logo 水印
style_drift ：风格漂移
regular_flickering ：规律性闪烁
extended_video_joint_jump ：续写视频拼接跳变
duplicate_character_appearance ：角色重复出现
audio_end_noise ：音频结尾噪声
chinese_pronunciation_error ：中文发音错误
voice_tone_reference_error ：音色参考错误
other ：其他
支持传入单个枚举值或枚举值数组。如果设置为其他值，接口返回 422 参数校验错误。
注意
仅当 Id 对应任务的真实模型属于 Doubao Seedance 2.x 系列时，才接受本字段。若 Id 对应模型不在支持范围内，接口返回业务错误码 60002 或 60003 。
模型支持：
doubao-seedance-2-5-260628
doubao-seedance-2-0-260128
doubao-seedance-2-0-fast-260128
doubao-seedance-2-0-mini-260615
ContactInfo string | 联系方式
提交人的联系方式，支持电子邮箱地址或电话号码。
ProjectName string 默认值 default | 项目名称
用于在 Case 平台中归类本次 Badcase 上报的项目名称。
Source string 默认值 customer | 反馈来源
效果问题的反馈来源。可选值：
huosu ：火速助手
huoshan ：火山助手
qianzhi ：钳知
customer ：客户提交
未设置或设置为 null 时，使用默认值 customer 。
响应参数
Accepted object[] | 已接受任务列表
通过校验并已创建 Case 记录的 task_id 列表。
CaseId string | Case ID
Accepted.CaseId
系统预分配的 Case ID，格式为 instance-<uuid> 。
接口返回时，Case 状态为 processing ；后台异步转存视频和输入帧，并写入会话及消息数据。处理成功后状态更新为 completed ，处理失败后更新为 failed 。
Code integer | 返回码
Accepted.Code
该任务的处理结果码，固定为 0 。
Message string | 返回消息
Accepted.Message
该任务的处理结果信息，固定为 Success 。
TaskId string | 任务 ID
Accepted.TaskId
已接受并创建 Case 记录的 task_id 。
Rejected object[] | 未接受任务列表
未通过校验且未创建 Case 记录的 task_id 列表。
Code integer | 错误码
Rejected.Code
未接受该任务的业务错误码。含义参见「错误码」章节。
Message string | 拒绝原因
Rejected.Message
未接受该任务的原因。
TaskId string | 未接受的任务 ID
Rejected.TaskId
未通过校验的 task_id 。
SubmissionId string | 提交 ID
本次提交的唯一标识，格式为 badcase-sub-<uuid> 。可使用该标识检索相关日志。
Total integer | 提交总数
本次提交的 task_id 总数，按 Id 参数拆分后的原始列表统计，包含重复项。
