10.6.7 查询技能的版本列表
GET https://ark.cn-beijing.volces.com/api/v3/skills/{skill_id}/versions
查询指定技能的版本。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
skill_id string 必选 | 技能 ID
用于指定要查询版本的技能。
Query 参数
在 URL Query String 中传入。
limit integer 默认值 20 | 每页数量
用于设置单页最多返回的记录数。
取值范围： [1, 100]
page string | 下一页标识
用于告诉服务端从上一页结束的位置继续返回数据。该值由服务端生成，不是页码。
例如，首次请求 GET /api/v3/skills/{skill_id}/versions?limit=20 时不传 page 。如果响应返回 "has_more": true和 "next_page": "<NEXT_PAGE>" ，下一次请求时，将响应中的 <NEXT_PAGE> 传入 GET /api/v3/skills/{skill_id}/versions?limit=20&page=<NEXT_PAGE> ，即可获取下一页版本列表。不要自行生成或修改该值。响应参数
data object[] | 技能的版本列表
包含当前页返回的不同版本的技能。
created_at string | 创建时间
data.created_at
表示该版本的创建时间。
display_title string | 展示名称
data.display_title
表示该版本的展示名称。
id string | 版本 ID
data.id
用于唯一标识该版本，值以 skillver- 开头。
skill_id string | 技能 ID
data.skill_id
表示该版本所属技能的 ID。
type string | 资源类型
data.type
用于标识响应对象的资源类型，固定为 skill_version 。
version string | 版本号
data.version
表示技能的版本号。
description string | 技能描述
data.description
表示方舟平台从该版本的 SKILL.md 中解析出的技能描述。
has_more boolean | 是否有下一页
表示是否还有下一页数据。 true 表示仍有数据，可以继续分页查询。 false 表示已返回最后一页。next_page string | 下一页标识
服务端生成的下一页标识，用于记录本页结束的位置。 has_more 为 true 时，将该值原样传入下一次请求的 page 参数。没有下一页时，服务端不返回该字段。
