12.2.6.3 批量绑定企业版席位
POST https://ark.cn-beijing.volcengineapi.com/?Action=AssignTeamSeats&Version=2024-01-01将企业版席位批量绑定到指定子用户。支持在单次调用中为多个席位指派对应的用户，采用部分成功语义：返回结果中分别列出绑定成功与失败的席位，调用方可据此重试失败项。已绑定其他用户的席位不会被覆盖，会作为失败项返回。
注意
本接口为部分成功语义：返回结果中 SuccessIds 与 FailedResult 分别列出绑定成功与失败的席位，调用方需根据 FailedResult 自行重试或修复。已绑定其他用户的席位不会被覆盖，会进入FailedResult。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Data object[] 必选 | 席位绑定列表
待分配的席位绑定关系列表，每一项指定一个席位 ID 及其对应的目标子用户。
SeatId string 必选 | 席位 ID
Data.SeatId
待绑定的席位 ID。
UserId string 必选 | 子用户 ID
Data.UserId
待绑定的目标子用户 ID。
UserName string 必选 | 子用户名
Data.UserName
子用户的显示名称。
ProjectName string 默认值 default | 项目名称
席位所属的项目空间名称。未传值时使用默认项目；指定不存在的项目时会返回 NotFound.ProjectName错误。
响应参数
FailedResult object[] | 失败席位列表
绑定失败的席位明细列表，包含失败的 SeatId 与失败原因。
Message string | 失败原因
FailedResult.Message
绑定失败的具体原因说明。
SeatId string | 失败席位 ID
FailedResult.SeatId
绑定失败的席位 ID。
SuccessIds string[] | 成功席位 ID
绑定成功的席位 ID 列表。
