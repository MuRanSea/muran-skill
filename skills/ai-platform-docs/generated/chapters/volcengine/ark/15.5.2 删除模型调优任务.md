15.5.2 删除模型调优任务
POST https://ark.cn-beijing.volcengineapi.com/?Action=DeleteModelCustomizationJob&Version=2024-01-01调用本接口删除指定的模型调优任务（精调任务）。删除后任务记录不可恢复，请谨慎操作。仅支持删除处于已结束状态（如已完成、已失败、已取消）的任务；运行中或排队中的任务请先调用 停止模型调优任务 终止后再删除。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 模型调优任务 ID
待删除的模型调优任务的 ID。可通过 获取模型调优任务列表 接口查询
响应参数
本接口无特有的返回参数，成功时 HTTP 状态码为 200 ，返回结构中 Result 为空对象 {} 。
