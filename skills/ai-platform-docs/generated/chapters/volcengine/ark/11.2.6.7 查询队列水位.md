11.2.6.7 查询队列水位
GET https://ark.cn-beijing.volces.com/api/v3/environments/{environmentId}/work/stats查询 work 队列水位；O(1) 读操作。
本接口用于查询自托管环境的 work 队列水位。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
environmentId string 必选 | 环境 ID
响应参数
depth integer | 待认领条数
未认领的 work 条数（consumer group lag）。
pending integer | 处理中条数
已被 Poll 但尚未 Ack 的 work 条数。
type string | 对象类型
类型标识，固定为 work_queue_stats 。
workers_polling integer | 活跃 Worker 数
最近 30 秒内曾 Poll 过的 worker 数；依赖 Ark-Worker-ID header 上报。
oldest_queued_at string | 最早入队时间
stream 中最早一条 work 的时间戳（含 queued 与 pending）；队列空时为空。
