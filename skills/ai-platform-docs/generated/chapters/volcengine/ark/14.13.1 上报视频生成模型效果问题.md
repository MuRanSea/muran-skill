14.13 效果上报
14.13.1 上报视频生成模型效果问题
POST https://prompt-pilot.cn-beijing.volces.com/case-platform?
Action=CasePlatformV1BadcaseReport&Version=2024-01-01
本接口用于上报 Doubao Seedance 2.x 系列模型的视频生成效果问题。系统根据指定的 task_id 创建Badcase 记录，保存问题描述、可选截图和时间轴反馈。本接口同时支持通过 Access Key 和方舟 API Key两种方式鉴权。3D 任务的参数要求参见 上报 3D 生成效果问题 。
注意
本接口及文档仅支持中国大陆火山方舟服务，不支持非中国大陆地区（如 BytePlus 等）。通过本接口提交 Badcase，视为您同意使用方舟排障服务，我们将严格按照《方舟平台专用条款》第 3.7.7 条第（2）项进行数据处理。详细条款请查阅：https://ark.volcengine.com/region:cn-beijing/docs/volcengine-ark-platform-terms
上报时效
本接口需要根据 task_id 向上游查询原始任务数据，因此火山方舟的视频任务须在 7 天内上报。请在任务生成完成后尽早提交；超过上报窗口后，平台可能无法读取原始任务数据。
上报问题截图时，截图源链接须在提交后至少 24 小时内保持可访问，以便平台异步下载。该要求与视频任务的上报窗口分别计算。
请求头
使用方舟 API Key 时，请设置 Authorization: Bearer <API_KEY> 和 Content-Type: application/json ，请求体可省略 AccountId 。
使用 AK/SK 时，请设置 V4 签名所需的 Authorization 、 X-Date 和 X-Content-Sha256 。签名的 Service为 ark ， Region 为 cn-beijing ，请求体须包含 AccountId 。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
【推荐】API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
【可选】Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。
请求参数
Query 参数
在 URL Query String 中传入。
Action string 必选 | 接口名称，固定为 CasePlatformV1BadcaseReport
Version string 必选 | 接口版本，固定为 2024-01-01
Body 参数
Feedback string 必选 | 问题描述
Badcase 的问题描述，长度为 1 至 2000 个字符，不能仅包含空白字符。同一请求中的所有任务共用此描述。
Id string / string[] 必选 | 任务 ID 列表
待上报的任务 ID，支持单个字符串或字符串数组。服务端按半角逗号、全角逗号、换行、空格或制表符拆分，并移除首尾空白和空项。
拆分后的任务数量须为 1 至 50，否则返回 HTTP 422 、错误码 40011 。同一请求中的任务共用 Feedback 和 FeedbackImages 。
AccountId string | 火山引擎账号 ID
Id 中任务所属的火山引擎账号 ID。
使用 Access Key 调用时必填。
使用方舟 API Key 调用时可省略，系统根据 API Key 解析账号 ID。
BadcaseType string / string[] | Badcase 类型
效果问题的类型。可选值：
character_id_drift ：角色 ID 漂移
subtitle_generation_error ：字幕生成错误
logo_watermark_generated ：生成 logo 水印
style_drift ：风格漂移
regular_flickering ：规律性闪烁
extended_video_joint_jump ：续写视频拼接跳变
duplicate_character_appearance ：角色重复出现
audio_end_noise ：音频结尾噪声
chinese_pronunciation_error ：中文发音错误
voice_tone_reference_error ：音色参考错误
other ：其他
支持传入单个枚举值或枚举值数组。如果设置为其他值，接口返回 422 参数校验错误。
注意
仅当 Id 对应任务的真实模型属于 Doubao Seedance 2.x 系列时，才接受本字段。若 Id 对应模型不在支持范围内，接口返回业务错误码 60002 或 60003 。
模型支持：
doubao-seedance-2-5-260628
doubao-seedance-2-0-260128
doubao-seedance-2-0-fast-260128
doubao-seedance-2-0-mini-260615
ContactInfo string | 联系方式
提交人的联系方式，支持电子邮箱地址或电话号码，最多 255 个字符。建议填写，便于处理人员联系您补充信息。
FeedbackImages object[] | 问题截图
可选的问题截图，最多 5 张，同一请求中的所有任务共用。视频和 3D 任务均可使用。
平台受理后异步下载截图。下载失败不影响 Case 建立，也不会自动重试；可通过 查询视频生成模型效果问题结果 查看每张截图的下载状态和失败原因。
Url string 必选 | 截图地址
FeedbackImages.Url
须使用公网可直接访问的 HTTPS 图片直链，不需要登录，不指向内网或私有地址，重定向不超过 3 次。不要提交网页、3D 模型文件、 tos:// 路径或 data: 内联图片。
支持 PNG、JPEG、WebP，以实际文件内容判断，每张不超过 10 MB。上报后至少 24 小时内保持可访问；单张下载时限为 60 秒。
Source string 默认值 customer | 反馈来源
效果问题的反馈来源。可选值：
huosu ：火速助手
huoshan ：火山助手
qianzhi ：钳知
customer ：客户提交
未设置或设置为 null 时，使用默认值 customer 。
TimelineFeedbacks object[] | 视频时间轴反馈
视频任务专用的时间轴反馈。每条通过 TaskId 指定所属任务，单个任务最多保留 20 条。超出的条目及校验失败的条目通过 RejectedTimelineFeedbacks 返回，不影响 Case 主记录的建立。
3D 模型没有时间轴，请省略本字段。顶层 Feedback 按请求结构要求填写。
EndTime number 必选 | 时间段终点，单位为秒，须大于等于 StartTime ；相等表示单个时间点TimelineFeedbacks.EndTime
不校验是否超过视频时长。
Feedback string 必选 | 该时间段的效果问题描述，长度为 1 至 2000 个字符，不能仅包含空白字符TimelineFeedbacks.Feedback
StartTime number 必选 | 时间段起点，单位为秒，非负，精度为 0.01 秒
TimelineFeedbacks.StartTime
TaskId string 必选 | 所属的视频任务 ID，必须出现在本次请求的 Id 列表中
TimelineFeedbacks.TaskId
BadcaseType string / string[] | 该时间段的视频效果问题类型，可选，取值参见顶层 BadcaseTypeTimelineFeedbacks.BadcaseType

AccountId 。
