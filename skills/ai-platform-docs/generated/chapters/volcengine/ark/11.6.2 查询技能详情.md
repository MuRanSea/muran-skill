11.6.2 查询技能详情
GET https://ark.cn-beijing.volces.com/api/v3/skills/{skillId}
查询指定技能的详细信息，包括基本信息和版本列表。
说明
技能版本管理能力将在 2026-07-16 之后完整开放，一期返回的版本列表用于占位；如需按版本调用，请以后续版本管理接口发布公告为准。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
skillId string 必选 | 技能 ID
要查询的技能 ID，格式为 skill- 开头的字符串
响应参数
created_at integer | 创建时间
技能创建时间，Unix 秒时间戳
description string | 技能描述
技能描述，说明技能的功能、用途和使用场景
display_title string | 展示名称
技能展示名称。优先取 latest 版本对应的 display_title ，否则回落到 SKILL.md 里解析出的 nameid string | 技能 ID
技能唯一标识符
latest_version string | 最新版本
最新版本号
name string | 技能名称
技能名称，用于用户识别和管理
object string | 对象类型
对象类型，固定为 skill
source string | 技能来源
技能来源。 custom 为用户创建的自定义技能， skill_hub 为来自 SkillHub 的公共技能
updated_at integer | 更新时间
技能最后更新时间，Unix 秒时间戳
versions object[] | 版本列表
技能所有版本的简要信息列表
created_at string | 创建时间
versions.created_at
版本创建时间，ISO 8601 格式
status string | 版本状态
versions.status
版本状态， uploading 上传中、 processing 处理中、 ready 就绪可用、 failed 处理失败version string | 版本号
versions.version
changelog string | 更新说明
versions.changelog
版本更新说明
metadata object | 自定义元数据
用户自定义元数据
