3.3 查询 Response 输入项列表
GET https://ark.cn-beijing.volces.com/api/v3/responses/{responseId}/input_items
分页查询某次 Response 的所有输入项列表，返回创建 Response 时传入的 input 内容，以及通过previous_response_id 关联的历史输入项。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
responseId string 必选 | Response ID
要查询输入项的 Response ID。
Query 参数
在 URL Query String 中传入。
after string | 起始游标
返回该 ID 之后的输入项，用于分页向后翻页。
before string | 结束游标
返回该 ID 之前的输入项，用于分页向前翻页。
include string[] | 附加返回字段
用于指定在响应中要额外包含的字段。部分接口默认返回基础字段，通过 include 可让服务端补充返回更多信息。
取值固定为 message.input_image.image_url 。
注意
可选值：
message.input_image.image_url ：包含输入消息中的图像 URL。图像为 url 时返回 url；图像为base64 编码时返回 base64 编码信息。
limit integer 默认值 20 | 单页数量
控制单次返回的最大项目数。
取值范围： [1, 100]
order string 默认值 desc | 排序方式
控制输入项的排序方式。
asc ：按照正序排列。
desc ：按照倒序排列。
