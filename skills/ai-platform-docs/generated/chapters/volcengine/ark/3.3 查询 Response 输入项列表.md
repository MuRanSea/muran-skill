3.3 查询 Response 输入项列表
GET https://ark.cn-beijing.volces.com/api/v3/responses/{responseId}/input_items
分页查询某次 Response 的所有输入项列表，返回创建 Response 时传入的 input 内容，以及通过previous_response_id 关联的历史输入项。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
responseId string 必选 | Response ID
要查询输入项的 Response ID。
Query 参数
在 URL Query String 中传入。
after string | 起始游标
返回该 ID 之后的输入项，用于分页向后翻页。
before string | 结束游标
返回该 ID 之前的输入项，用于分页向前翻页。
include string[] | 附加返回字段
用于指定在响应中要额外包含的字段。部分接口默认返回基础字段，通过 include 可让服务端补充返回更多信息。
取值固定为 message.input_image.image_url 。
注意
可选值：
message.input_image.image_url ：包含输入消息中的图像 URL。图像为 url 时返回 url；图像为base64 编码时返回 base64 编码信息。
limit integer 默认值 20 | 单页数量
控制单次返回的最大项目数。
取值范围： [1, 100]
order string 默认值 desc | 排序方式
控制输入项的排序方式。
asc ：按照正序排列。
desc ：按照倒序排列。

status string | 状态
data.status
推理内容的状态。可选值： in_progress 、 completed 、 incomplete 。
summary object[] | 推理摘要
data.summary
推理内容摘要列表。
type string | 类型
data.summary.type
摘要片段类型，固定为 summary_text
text string | 摘要文本
data.summary.text
思维链摘要文本内容。
type string | 类型
data.type
输入元素类型，此处固定为 reasoning
content object[] | 推理内容
data.content
推理过程的内容元素列表。
模型回答文本 object
模型生成的最终回答文本。
type string | 类型
data.content.type
内容类型，此处固定为 output_text
annotations object[] | 标注列表
data.content.annotations
文本附带的标注信息列表（如引用来源等）

MCP 审批请求 object
历史 MCP 工具审批请求记录，用于多轮对话上下文回传。
arguments string | 调用参数
data.arguments
工具调用参数的 JSON 字符串。
name string | 工具名
data.name

data.server_label

type string | 类型
data.type

id string | 请求 ID
data.id

MCP 审批响应 object

approval_request_id string | 请求 ID
data.approval_request_id

approve boolean | 是否批准
data.approve

type string | 类型
data.type
输入元素类型，此处固定为 mcp_approval_response
id string | 响应 ID
data.id
审批响应的唯一 ID。
reason string | 决策理由
data.reason
决策理由（可选）
MCP 工具清单 object
历史 MCP 工具清单记录，用于多轮对话上下文回传。
server_label string | 服务标签
data.server_label
MCP Server 标签。
type string | 类型
data.type
输入元素类型，此处固定为 mcp_list_tools
error string | 错误信息
data.error
MCP Server 无法返回工具列表时的错误信息。
id string | 列表 ID
data.id
工具列表的唯一 ID。
tools object[] | 工具列表
data.tools
该 MCP Server 上可用的工具列表。
name string | 工具名
data.tools.name
工具名称。
annotations object | 注解信息
data.tools.annotations
工具的附加注解信息。
description string | 工具描述
data.tools.description
工具的功能描述。
input_schema object | 入参 Schema
data.tools.input_schema
描述工具入参的 JSON Schema。
MCP 工具调用 object
历史 MCP 工具调用记录，用于多轮对话上下文回传。
name string | 工具名
data.name
实际运行的工具名称。
server_label string | 服务标签
data.server_label
运行工具的 MCP Server 标签。
type string | 类型
data.type
输入元素类型，此处固定为 mcp_call
arguments string | 调用参数
data.arguments
传递给工具的调用参数 JSON 字符串。通过 response.mcp_call_arguments.delta 流式追加，初始 output_item.added 事件可能不携带该字段。
error string | 错误信息
data.error
工具调用失败时的错误信息。
id string | 调用 ID
data.id
工具调用的唯一 ID。
output string | 返回结果
data.output
工具调用的返回结果。
上下文元素 object
表示模型生成回复时需参考的上下文内容。该项可以包含文本、图片和视频输入，以及先前助手的回复和工具调用的输出。
id string | 条目 ID
data.id
引用的上下文条目 ID。
type string | 类型
data.type
输入元素类型，此处固定为 item_reference
first_id string | 首条 ID
列表中第一条数据的 ID。
last_id string | 末条 ID
列表中最后一条数据的 ID。
object string | 对象类型
固定为 list
has_more boolean | 是否有更多
标识是否还有更多数据未返回。
true ：存在未返回的数据。
false ：已返回全部数据。
