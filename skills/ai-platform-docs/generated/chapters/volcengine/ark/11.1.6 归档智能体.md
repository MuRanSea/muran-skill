11.1.6 归档智能体
POST https://ark.cn-beijing.volces.com/api/v3/agents/{agent_id}/archive
当某个智能体不再用于创建新 Session，但仍需保留配置和历史版本供查询时，调用本接口将其归档。归档后，该智能体不能再更新或用于创建新 Session，但详情和历史版本仍可查询。已有 Session 不受影响，继续使用创建时保存的配置快照。
本接口支持幂等调用；重复归档不会改变首次 archived_at 。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
agent_id string 必选 | 智能体 ID
要归档的智能体 ID，以 agent- 开头。可从创建智能体响应或智能体列表中获取。
响应参数
created_at string | 创建时间
智能体创建时间，采用 RFC 3339 格式的 UTC 时间。
id string | 智能体 ID
智能体唯一标识，以 agent- 开头。更新或删除智能体，以及创建会话时，需要使用该值。name string | 智能体名称
用于识别和管理智能体的名称。
type string | 对象类型
返回对象的类型，表示该对象为智能体。
取值固定为 agent 。
updated_at string | 更新时间
智能体最后更新时间，采用 RFC 3339 格式的 UTC 时间。
version integer | 版本号
当前智能体配置的版本号。
archived_at string | 归档时间
智能体首次归档的时间，采用 RFC 3339 格式的 UTC 时间。归档接口成功后返回该字段；重复归档时保持不变。
base_agent string | 基础 Agent 类型
智能体创建时确定的基础 Agent 类型。
ark_agent_preview ：通用 Agent。
ultra_vision_agent_preview ：Seedance Managed Agent。
context_management object[] | 上下文管理
智能体版本的上下文管理策略。
未保存自定义策略，或已保存策略未包含 compact_threshold 时，响应展示平台当前默认压缩策略或默认阈值；当前默认阈值为 192000 token。
响应中的默认展示值不会写回 Agent 版本。显式保存的 compact_threshold 优先返回。
type string | 策略类型
context_management.type
策略类型，固定为 compaction 。
compact_threshold integer | 压缩阈值
context_management.compact_threshold
查询响应展示的自动压缩触发阈值，单位为 token。未显式保存时，对外接口响应会填充平台当前默认值，当前默认值为 192000 ；该展示值不会写回 Agent 版本或 Session 快照。
instructions string | 摘要指令
context_management.instructions
用户配置的压缩摘要指令。
description string | 智能体描述
智能体的用途、能力范围和适用场景。
display_name string | 展示名称
智能体的展示名称。
mcp_servers object[] | MCP 服务列表
智能体已配置的 MCP 服务列表。
name string | MCP 服务名称
mcp_servers.name
用于标识 MCP 服务的名称。
type string | 接入方式
mcp_servers.type
MCP 服务的接入方式。
取值固定为 url 。
url string | 服务地址
mcp_servers.url
MCP 服务的访问地址。
metadata object | 自定义元数据
智能体的自定义键值对元数据。
model object | 模型配置
智能体使用的模型配置。
id string | 模型或接入点 ID
model.id
智能体调用的模型 ID 或推理接入点 ID。例如模型 ID doubao-seed-2-1-pro-260628 ，或推理接入点 ID ep-20260907123456-abcd1 。
reasoning_effort string | 推理投入档位
model.reasoning_effort
模型在深度思考时使用的推理投入档位。可选值： none 、 minimal 、 low 、 medium 、 high 、xhigh 、 max 。
service_tier string | 推理服务档位
model.service_tier
模型调用使用的推理服务档位。可选值： auto 、 default 、 fast 。
speed string | 推理速度档位
model.speed
模型使用的推理速度档位。可选值： standard 、 fast 。
thinking string | 深度思考
model.thinking
模型的深度思考模式。 auto 表示由模型决定是否启用深度思考。取值： enabled / disabled / auto 。multiagent object | 多智能体配置
智能体与子智能体之间的协作配置。
agents object[] | 子智能体列表
multiagent.agents
参与协作的子智能体列表。

multiagent.agents.type

id string | 智能体 ID
multiagent.agents.id
被引用智能体的 ID。
version integer | 智能体版本
multiagent.agents.version
被引用智能体的版本号。
type string | 协作模式

多智能体协作模式，取值固定为 coordinator 。当前智能体负责分配任务并汇总子智能体的结果。scene string | Agent 场景
Agent 场景标记。

智能体已绑定的技能列表。

skills.type
技能来源。
ark ：方舟预置技能。

custom ：当前账号通过 Skills API 创建的自定义技能。

skills.skill_id
绑定到智能体的技能 ID。
version string | 技能版本
skills.version
绑定到智能体的技能版本号。

工具类型。
服务端可能返回兼容之前基础工具集的历史值。

mcp_toolset ：使用指定 MCP 服务提供的工具。

tools.configs.enabled
是否启用此工具。

该工具使用的权限策略。

enabled boolean | 默认是否启用

permission_policy object | 默认权限策略

未在 configs 中单独配置的工具所使用的默认权限策略。
