15.5.9 更新模型调优任务
POST https://ark.cn-beijing.volcengineapi.com/?Action=UpdateModelCustomizationJob&Version=2024-01-01调用本接口更新已创建的模型调优任务（精调任务）的可变属性，包括任务名称、描述以及调度优先级。仅 Name 、 Description 、 Priority 三类元数据支持在任务创建后修改；训练数据集、超参数、基础模型等核心训练配置一经创建即不可变更，如需调整请通过 创建模型调优任务 重新创建任务。鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 模型调优任务 ID
待更新的模型调优任务的 ID。可通过 获取模型调优任务列表 接口查询
Description string | 任务描述
待更新的模型调优任务描述，可用于补充任务用途、训练目标等业务备注信息
Name string | 任务名称
待更新的模型调优任务名称，用于在控制台和接口返回中标识该任务，建议使用具备业务可读性的命名Priority string | 调度优先级模式
待更新的模型调优任务调度优先级模式。 Allocated 表示使用预留资源调度，优先级较高； Spot 表示使用抢占式资源调度，成本更低但可能被高优任务抢占
响应参数
本接口无特有的返回参数，成功时 HTTP 状态码为 200 ，返回结构中 Result 为空对象 {} 。
