11.4.6.2 查询凭证列表
GET https://ark.cn-beijing.volces.com/api/v3/vaults/{vault_id}/credentials
分页查询指定保管库下的所有凭证。接口仅返回凭证元信息，不返回任何密文字段（access_token /token / secret_value / refresh_token / client_secret）。
列表结果包含 mcp_oauth 、 static_bearer 、 mcp_static 、 environment_variable 四类凭证。响应 auth.type 字段忠实回显 DB 原值， static_bearer 与 mcp_static 作为两个独立类型并存，服务端不做归一化转换。对于 environment_variable 类型，响应仅包含 secret_name 与 networking 网络范围配置。鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
