4.2 统计 Messages 请求 token 数
POST https://ark.cn-beijing.volces.com/api/compatible/v1/messages/count_tokens
统计 Messages 请求的输入 token 数，可用于请求预估、配额控制和成本测算。实际用量以真实请求结果为准。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。

output_config.effort

none ：关闭思考。

low ：轻量思考，侧重快速响应。
medium ：均衡模式，兼顾速度与深度。
high ：深度分析，处理复杂问题。
xhigh ：更高程度思考。
max ：最高程度思考，适配高难度推理任务。
说明
支持该字段的模型、默认取值、参数兼容映射规则，以及与 thinking.type 字段的关系，详见 文档。
