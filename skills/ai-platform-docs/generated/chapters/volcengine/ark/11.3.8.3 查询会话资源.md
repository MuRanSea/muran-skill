11.3.8.3 查询会话资源
GET https://ark.cn-beijing.volces.com/api/v3/sessions/{sessionId}/resources/{resourceId}查询指定会话中某个资源的详细信息。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
resourceId string 必选 | 资源 ID
资源 ID。通过添加会话资源接口 (POST /sessions/{sessionId}/resources) 返回。
sessionId string 必选 | 会话 ID
会话 ID，格式为 sesn- 开头的字符串
响应参数
id string | 资源 ID
资源唯一标识符
type string | 资源类型
资源类型： file 文件、 memory_store 记忆库、 tos 对象存储
access string | 访问模式
访问模式： read_only 只读、 read_write 读写；当 type=memory_store 时返回
created_at string | 创建时间
创建时间，ISO 8601 格式
file_id string | 文件 ID
文件 ID；当 type=file 时返回
memory_store_id string | 记忆库 ID
记忆库 ID；当 type=memory_store 时返回
mount_path string | 挂载路径
tos_bucket string | TOS 存储桶
TOS 挂载源所在的存储桶名称；仅当 type=tos 时返回
tos_key string | TOS 目录前缀
TOS 中待挂载目录的路径前缀；仅当 type=tos 时返回。该值必须以 / 结尾，不能指向单个文件tos_region string | TOS 地域
TOS 挂载源所在地域的 Region ID；仅当 type=tos 时可能返回
updated_at string | 更新时间
更新时间，ISO 8601 格式
