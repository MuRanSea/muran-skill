14.8.8 停止模型调优任务
POST https://ark.cn-beijing.volcengineapi.com/?Action=TerminateModelCustomizationJob&Version=2024-01-01调用本接口停止正在执行的模型调优任务（精调任务）。仅支持停止处于运行中或排队中的任务；任务停止后将进入已取消状态，已产生的训练资源费用不退还。如需删除已终止的任务记录，可继续调用 删除模型调优任务。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 模型调优任务 ID
待停止的模型调优任务的 ID。可通过 获取模型调优任务列表 接口查询
