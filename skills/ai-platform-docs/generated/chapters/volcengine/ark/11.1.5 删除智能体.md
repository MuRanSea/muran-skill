11.1.5 删除智能体
DELETE https://ark.cn-beijing.volces.com/api/v3/agents/{agentId}
删除指定的智能体，删除后智能体及其历史版本不可恢复。若智能体正被现有会话引用，删除将失败。鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
agentId string 必选 | 智能体 ID
要删除的智能体 ID。通过创建智能体接口 (POST /agents) 返回, 或在控制台智能体列表页面获取。响应参数
id string | 智能体 ID
被删除的智能体 ID
type string | 对象类型
对象类型，固定为 agent_deleted
