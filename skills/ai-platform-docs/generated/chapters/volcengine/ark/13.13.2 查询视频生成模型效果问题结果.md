13.13.2 查询视频生成模型效果问题结果
POST https://prompt-pilot.cn-beijing.volces.com/case-platform?
Action=CasePlatformV1BadcaseQuery&Version=2024-01-01
本接口用于根据 task_id 查询 Doubao Seedance 2.x 系列模型视频生成效果问题的 Badcase 标记状态和鉴定结果。本接口同时支持通过 Access Key 和方舟 API Key 两种方式鉴权。
注意
本接口及文档仅支持中国大陆火山方舟服务，不支持非中国大陆地区（如 BytePlus 等）。通过本接口查询 Badcase 结果，视为您同意使用方舟排障服务，我们将严格按照《方舟平台专用条款》第 3.7.7 条第（2）项进行数据处理。详细条款请查阅：https://ark.volcengine.com/region:cn-beijing/docs/ark/volcengine-ark-platform-terms
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 {target="_self"}。
【推荐】API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
【可选】Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。
请求参数
Body 参数
Id string 必选 | 任务 ID 列表
待查询的 task_id 。支持提交单个 ID，也可传入多 ID 字符串。
多 ID 场景 • 系统会按半角逗号、全角逗号、换行、空格或制表符自动拆分，并移除每个 ID 首尾的空白字符和空项。
拆分后数量必须在 1 至 50 之间；为空或超过 50 时，接口返回 422 参数校验错误。
ProjectName string 默认值 default | 项目名称
用于在 Case 平台中定位所查 task_id 的项目名称。若资源不在默认项目中，需填写实际项目名称。响应参数
Accepted object[] | 已接受任务列表
