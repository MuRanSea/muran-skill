12.2.6.4 批量更新企业版席位 API Key
POST https://ark.cn-beijing.volcengineapi.com/?Action=RegenerateTeamSeatApiKeys&Version=2024-01-01企业版管理员对指定席位批量轮换（重新生成）API Key。轮换后原 API Key 立即失效，系统为每个席位生成新的密钥，需及时同步更新业务侧调用配置。采用部分成功语义：返回结果中分别列出轮换成功与失败的席位。
注意
轮换操作不可逆，被轮换席位的旧 API Key 在操作完成后立即失效。请在调用前确认已做好密钥更替的业务联动准备，并妥善保管新生成的 API Key，避免泄露。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Plan string 必选 | 商品名称
目标套餐商品名称。可选值： AgentPlanTeam （Agent Plan 企业版）、 CodingPlanTeam （Coding Plan 企业版）。
SeatIds string[] 必选 | 席位 ID 列表
待轮换的席位 ID 列表，支持批量操作。
ProjectName string | 项目名称
席位所属的项目空间名称。
响应参数
FailedResults object[] | 失败席位明细
本次操作中轮换失败的席位明细列表，每项包含失败的 SeatId 与具体原因。
Message string | 失败原因
FailedResults.Message
轮换失败的具体原因说明。
SeatId string | 失败席位 ID
FailedResults.SeatId
轮换失败的席位 ID。
SuccessIds string[] | 成功席位 ID
本次操作中轮换成功的席位 ID 列表。
