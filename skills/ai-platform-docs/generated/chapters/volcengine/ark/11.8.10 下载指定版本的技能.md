11.8.10 下载指定版本的技能
GET https://ark.cn-beijing.volces.com/api/v3/skills/{skill_id}/versions/{version}/content获取指定版本的技能 ZIP 包下载地址。服务端返回 HTTP 302 响应，并在 Location 响应头中提供有效期为 1 小时的下载地址。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
skill_id string 必选 | 技能 ID
用于指定要下载版本内容的技能。
version string 必选 | 版本号
用于指定要下载的版本号。
响应参数
Location string | 下载地址
表示指定版本的技能 ZIP 包下载地址，有效期为 1 小时。
