10.5.6.5 更新记忆
POST https://ark.cn-beijing.volces.com/api/v3/memory_stores/{memoryStoreId}/memories/{memoryId}更新一条记忆的内容和/或重命名其 path ； content 与 path 至少给一个。并发更新采用 last-writewins，本期不提供乐观锁。鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
memoryId string 必选 | 记忆 ID
要更新的记忆条目 ID。通过创建记忆接口 (POST /memory_stores/{memoryStoreId}/memories) 返回, 或通过查询记忆列表接口获取。
memoryStoreId string 必选 | 记忆库 ID
所属记忆库 ID。通过创建记忆库接口 (POST /memory_stores) 返回, 或通过查询记忆库列表接口 (GET /memory_stores) 获取。
Body 参数
content string | 记忆内容
新的记忆内容正文，大小上限 ≤100KB； content 与 path 至少提供其一
path string | 记忆路径
新的记忆路径，用于重命名；同库内 path 唯一； content 与 path 至少提供其一
响应参数
content_sha256 string | 内容摘要
内容的 SHA-256 摘要（十六进制小写）
content_size_bytes integer | 内容字节数
记忆内容的字节大小
created_at string | 创建时间
创建时间，RFC 3339 UTC 毫秒格式
created_by object | 创建者
记忆的创建者信息
type string | 操作者类型
created_by.type
操作者类型，固定为 user_actor
user_id string | 用户 ID
created_by.user_id
操作者用户 ID
id string | 记忆 ID
记忆条目唯一标识符，格式为 mem- 开头的小写 ULID
memory_store_id string | 记忆库 ID
所属记忆库 ID。通过创建记忆库接口 (POST /memory_stores) 返回, 或通过查询记忆库列表接口 (GET /memory_stores) 获取。
memory_version_id string | 版本 ID
当前 head 版本 ID（版本接口本期不暴露）
path string | 记忆路径
记忆在记忆库中的层次化路径
type string | 对象类型
对象类型，固定为 memory
updated_at string | 更新时间
最后更新时间，RFC 3339 UTC 毫秒格式
content string | 记忆内容
记忆内容正文；仅单点读取（Get）时返回
