10.5.6.5 更新记忆
POST https://ark.cn-beijing.volces.com/api/v3/memory_stores/{memoryStoreId}/memories/{memoryId}按字段更新记忆的正文、路径或两者；未传字段保持不变。更新 path 后，响应会返回新的记忆 ID，旧ID 立即失效，继续使用旧 ID 查询、更新或删除会返回 404 ResourceNotFound ；后续请求必须改用响应中的新 ID。
说明
并发修改导致冲突时，重新查询最新记忆后再重试。
仅传入与当前值相同的 path 且不传 content 时，不会产生实际更新，ID、版本标识和更新时间保持不变。
说明
常见失败包括：记忆库或记忆不存在、路径或内容不合法、目标路径已存在、正文超过 100 KiB，以及并发修改冲突。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
memoryId string 必选 | 记忆 ID
用于定位要更新的记忆，以 mem- 开头。传入创建、列表或更新接口返回的完整 ID，不要自行拼接。memoryStoreId string 必选 | 记忆库 ID
用于指定记忆所属的记忆库，以 memstore- 开头。传入创建或查询记忆库接口返回的完整 ID，不要自行拼接。
Body 参数
content string | 记忆内容
用于替换现有正文的记忆内容。省略时保持现有正文不变。
注意
记忆正文必须是有效的 UTF-8 文本，且不得超过 102400 字节（100 KiB）。 content 与 path 至少提供一个。
path string | 记忆路径
用于重命名记忆的文件路径。省略时保持现有路径不变。
注意
路径必须以 / 开头，以 .md 或 .txt 结尾，UTF-8 编码后不得超过 1024 字节，且不得包含控制字符、 % 、 ; 或 ? ；路径段不得为空、 . 或 .. 。 content 与 path 至少提供一个。响应参数
content_sha256 string | 内容摘要
记忆正文的 SHA-256 摘要，以小写十六进制字符串表示，可用于校验内容完整性。
content_size_bytes integer | 内容字节数
记忆正文采用 UTF-8 编码后的字节数。
created_at string | 创建时间
记忆创建时间，采用 RFC 3339 UTC 格式。
created_by object | 创建者
创建该记忆的操作者信息。
type string | 操作者类型
created_by.type
操作者类型。 user_actor 表示通过用户身份写入， session_actor 表示会话中的智能体写入。session_id string | 会话 ID
created_by.session_id
写入该记忆的会话 ID，仅 type 为 session_actor 时返回。
user_id string | 用户 ID
created_by.user_id
写入该记忆的用户 ID，仅 type 为 user_actor 时返回。
id string | 记忆 ID
服务端生成的记忆 ID，以 mem- 开头。后续查询、更新或删除记忆时，作为 memoryId 路径参数传入。
memory_store_id string | 记忆库 ID
该记忆所属的记忆库 ID。
memory_version_id string | 版本 ID
记忆条目的当前版本标识。内容或路径成功更新后，该值会变化。
path string | 记忆路径
记忆在记忆库中的文件路径。
type string | 对象类型
对象类型，固定为 memory 。
updated_at string | 更新时间
记忆最后更新时间，采用 RFC 3339 UTC 格式。
