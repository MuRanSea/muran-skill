12.2.6 管理 Agent Plan（企业版）
12.2.6.1 创建企业版席位
POST https://ark.cn-beijing.volcengineapi.com/?Action=CreateTeamSeats&Version=2024-01-01企业版管理员批量购买 Agent Plan / Coding Plan 席位（ AgentPlanTeam / CodingPlanTeam ）。您通过 API 接口发起部署请求或调用本服务的，即表示您已充分阅读、理解并同意 《火山方舟大模型订阅套餐服务专用条款》 、《豆包模型服务协议》 、《开源模型许可证》 、《Harness 能力说明和产品专用条款》 及其他适用的平台规则。如您不同意上述协议，请立即停止调用。说明
单次请求可同时下单多个套餐档位（ Seats 数组），席位数组内同档位仅允许单次提交。
支持传入 DryRun=true 参数，仅执行订阅合法性校验，不实际创建席位订单。
接口幂等性由调用方自行保障，请勿使用相同参数并发请求，防止席位重复创建。
接口为异步执行，自动扣费，下单前请确保云账户内余额充足。
调用 CreateTeamSeats 提交席位订购请求后，订单存在异步处理或状态延迟情况。建议在调用 CreateTeamSeats 接口创建企业版席位后，通过 ListSeatInfos 接口进行反查，以确认最终的席位购买结果。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Plan string 必选 | 商品名称
待购买的企业版商品名称。可选值： AgentPlanTeam （Agent Plan 企业版）、 CodingPlanTeam （CodingPlan 企业版）。
Seats object[] 必选 | 席位配置列表
席位配置明细列表。Plan 为 AgentPlanTeam 时最多支持 4 项配置（ Small 、 Medium 、 Large 、 Max各一项）；Plan 为 CodingPlanTeam 时最多支持 2 项（ Lite 、 Pro ）。单次请求内不允许出现重复的 PlanType。
Duration number 必选 | 订购时长
Seats.Duration
订购时长，单位以 PricingCycle 为准。
取值范围： [1, 12]
PlanType string 必选 | 套餐档位
Seats.PlanType
套餐档位。Plan 为 AgentPlanTeam 时取值 Small 、 Medium 、 Large 、 Max ；Plan 为 CodingPlanTeam 时取值 Lite 、 Pro 。单次请求内不允许重复，重复时返回 Duplicated.PlanType 错误。PricingCycle string 必选 | 计费周期
Seats.PricingCycle
计费周期。当前仅支持 Month （包月）。
SeatNumber number 必选 | 席位数量
Seats.SeatNumber
该档位创建的席位数量，需大于 0。企业版首次购买需满足：账号下处于 Active 状态的席位数加本次新购总数不少于 5 个。
最小值： 1
AutoRenew boolean 默认值 false | 自动续费
Seats.AutoRenew
是否在套餐到期时开启自动续费。设为 true 时套餐到期前会从云账户余额自动续费，仅支持单次自动续费。
DryRun boolean | 预检模式
是否仅做参数预检而不实际下单。设为 true 时仅完成参数、额度全链路校验，不占用席位且不执行扣款，适用于上线前的预校验场景。
ProjectName string 默认值 default | 项目名称
席位所属的项目空间名称。未传值时使用默认项目；指定不存在的项目时返回 NotFound.ProjectName 错误。
响应参数
Seats object[] | 席位结果列表
已分配的席位结果列表，按 PlanType 聚合返回；同档位下生成的所有席位 ID 通过 SeatIds 数组返回。PlanType string | 套餐档位
Seats.PlanType
该结果项对应的套餐档位。
SeatIds string[] | 席位 ID 列表
Seats.SeatIds
该档位下已生成的席位 ID 列表，列表长度等于该档位的 SeatNumber，可作为后续席位绑定、续费、终止接口的入参。
