11.4.6 删除 Webhook 接入点
DELETE https://ark.cn-beijing.volces.com/api/v3/webhook_endpoints/{endpoint_id}
删除指定 Webhook 接入点。删除成功返回 204，不返回响应体。
删除会取消尚未开始和等待重试的投递，并立即清除签名密钥。已经发出的请求仍可能到达。删除后的接入点不能恢复。
删除后保留 7 天墓碑。墓碑保留期内重复删除仍返回 204，仍可查询尚未过期的关联事件；墓碑到期后再次删除返回 404。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
endpoint_id string 必选 | 接入点 ID
Webhook 接入点 ID，以 wep- 开头。该 ID 可从创建或列表接口的响应中获取。
响应参数
成功时 HTTP 状态码为 204 No Content 。
本接口不返回响应正文。
