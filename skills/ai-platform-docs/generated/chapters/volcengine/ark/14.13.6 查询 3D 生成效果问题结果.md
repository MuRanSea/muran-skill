14.13.6 查询 3D 生成效果问题结果
POST https://prompt-pilot.cn-beijing.volces.com/case-platform?
Action=CasePlatformV1BadcaseQuery&Version=2024-01-01
本接口用于查询 Seed3D 2.0 生成效果问题的处理状态、问题标签、解决方案说明，以及上报时附带截图的保存结果。先通过 上报 3D 生成效果问题 提交反馈，再使用生成任务的 task_id 查询。只能查询当前账号已上报的任务，支持通过 Access Key 或方舟 API Key 鉴权。
Status 为 processing 时表示排查中，为 done 时表示处理完成。截图的下载状态与排查状态相互独立。视频任务参见 查询视频生成模型效果问题结果 。
注意
本接口及文档仅支持中国大陆火山方舟服务，不支持非中国大陆地区（如 BytePlus 等）。上报窗口与查询时机
请先在 7 天内通过 上报 3D 生成效果问题 提交火山方舟的 3D 任务反馈。上报接口需要根据 task_id查询上游原始任务数据，因此有上报窗口。
7 天是上报窗口。本接口查询已上报 Case 的处理状态和结果。 Status 为 processing 时，排查尚未完成， ProblemLabel 和 SolutionNote 尚未产出，请稍后再次查询；为 done 时，可读取处理结论。截图下载状态与排查状态相互独立。
链接有效期
FeedbackImages[].Url 为截图的预签名链接，有效期约 10 分钟，具体过期时间见 ExpiresAt 。每次查询会重新生成链接，过期后请重新调用本接口。
SolutionNote.Attachments[].Url 为解决方案附件链接，每次查询会重新签名。请使用最新响应中的链接，过期后重新查询。
以上是返回链接的有效期，不代表 Case 记录的保留期。
请求头
使用方舟 API Key 时，设置 Authorization: Bearer <API_KEY> 和 Content-Type: application/json ，账号身份从API Key 解析。
使用 AK/SK 时，设置 V4 签名所需的 Authorization 、 X-Date 和 X-Content-Sha256 ，签名的 Service 为 ark 、 Region 为 cn-beijing 。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
【推荐】API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
【可选】Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。
请求参数
Query 参数
在 URL Query String 中传入。
Action string 必选 | 接口名称，固定为 CasePlatformV1BadcaseQuery
Version string 必选 | 接口版本，固定为 2024-01-01
Body 参数
Id string / string[] 必选 | 任务 ID 列表
待查询的任务 ID，支持单个字符串或字符串数组。字符串按半角逗号、全角逗号、换行、空格或制表符拆分，移除首尾空白和空项，并对重复任务 ID 去重。
标准化后的任务数量须为 1 至 50，否则返回 HTTP 422 、错误码 40011 。只能查询当前账号已上报过的任务。
3D 响应中的视频兼容字段
视频和 3D 使用相同的 Action、Version、鉴权方式及公共响应结构。 Accepted 条目中的 BadcaseType 和TimelineFeedbacks 仅供视频任务使用；3D 任务返回空数组，可忽略。

错误码
HTTP 4xx 或 5xx 时，错误在 ResponseMetadata.Error 中；HTTP 200 时仍需检查 Result.Accepted 与 Result.Rejected ，逐个确认查询结果。
查询接口的 40012 表示「尚未上报过」，与上报接口的 40012 （任务 ID 格式不合法）含义不同。错误信息可能返回中文或英文，程序应按错误码判断。
