14.9 管理推理接入点（Endpoint）
14.9.1 开启推理接入点
POST https://ark.cn-beijing.volcengineapi.com/?Action=StartEndpoint&Version=2024-01-01启动指定的推理接入点，使其从已停止状态恢复为可用状态。
注意
仅处于关闭状态（ Stopped ）的接入点支持开启操作；已处于运行状态（ Running ）的接入点重复开启会返回错误。开启操作为异步执行，调用成功后接入点将进入启动中（ Starting ）状态，并在就绪后转为运行中（ Running ）状态。后付费模式下，接入点进入 Running 状态后开始计费。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 推理接入点 ID
待开启的推理接入点（Endpoint）ID，以 ep- 开头。可在火山方舟控制台的「推理接入点」页面查看，或通过 ListEndpoints 接口获取。
