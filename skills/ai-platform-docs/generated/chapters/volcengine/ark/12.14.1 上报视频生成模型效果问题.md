12.14 效果上报
12.14.1 上报视频生成模型效果问题
POST https://prompt-pilot.cn-beijing.volces.com/case-platform?
Action=CasePlatformV1BadcaseReport&Version=2024-01-01
本接口用于上报 Doubao Seedance 2.x 系列模型的视频效果反馈，保存反馈描述、截图和时间轴反馈，并创建 Case 记录。支持以下上报方式：
按任务上报：每个任务分别创建一个 Case。
按 Session 上报：将同一次连续创作的多个任务保存为一个多轮 Case。
Badcase 用于效果问题排查。Seedance 2.5 及以上模型还支持上报 Goodcase 和参与 Case 激励计划。本接口支持 Access Key 和方舟 API Key 鉴权。3D 任务的参数要求参见 上报 3D 生成效果问题 。注意
本接口及文档仅支持中国大陆火山方舟服务，不支持非中国大陆地区（如 BytePlus 等）。通过本接口提交 Badcase，视为您同意使用方舟排障服务，我们将严格按照《方舟平台专用条款》第 3.7.7 条第（2）项进行数据处理。详细条款请查阅：https://ark.volcengine.com/region:cn-beijing/docs/volcengine-ark-platform-terms
上报时效
本接口需要根据 task_id 向上游查询原始任务数据，因此火山方舟的视频任务须在 7 天内上报。请在任务生成完成后尽早提交；超过上报窗口后，平台可能无法读取原始任务数据。
上报问题截图时，截图源链接须在提交后至少 24 小时内保持可访问，以便平台异步下载。该要求与视频任务的上报窗口分别计算。

同一次连续创作产生多个任务时，可将其合并上报为一个 Session Case，每个任务对应一轮。每个请求只能上报一个 Session，包含 1 至 50 个任务。
上报前检查
所有任务属于同一账号，并使用同一个模型。
每个任务均已成功生成视频，不包含样片或成片任务。
任务 ID 不重复，且此前未单独上报或作为其他 Session 的一轮上报。
所有任务满足上报时效、账号及其他校验要求。
构造请求
将 IdType 设置为 session 。
按生成轮次的顺序填写 Id ，第一个任务对应第 1 轮。
填写反馈信息。同一 Session 共用 Feedback 、 FeedbackImages 、 BadcaseType 、 ContactInfo 、Source 、 AccountId 、 CaseType 和 JoinIncentive 。如需提交时间轴反馈，通过 
TimelineFeedbacks[].TaskId 关联对应轮次，时间相对于该轮视频计算。
检查受理结果
系统在所有任务通过校验后创建一个 Case。请根据响应检查结果：
成功上报后，任务不能再单独上报或加入其他 Session，重复上报返回 40003 。
请求头
使用方舟 API Key 时，请设置 Authorization: Bearer <API_KEY> 和 Content-Type: application/json ，请求体可省略 AccountId 。
使用 AK/SK 时，请设置 V4 签名所需的 Authorization 、 X-Date 和 X-Content-Sha256 。签名的 Service为 ark ， Region 为 cn-beijing ，请求体须包含 AccountId 。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
【推荐】API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
【可选】Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。

Body 参数
Feedback string | 反馈描述
效果反馈描述，长度为 1 至 2000 个字符，不能仅包含空白字符。同一请求中的所有任务共用此描述。视频任务： Feedback 与 TimelineFeedbacks 至少填写一个，否则返回错误码 40014 。上报 Goodcase或参与激励计划时，必须填写 Feedback ，不能仅提供时间轴反馈。
3D 任务：必须填写 Feedback ，不能用 TimelineFeedbacks 替代。
Id string / string[] 必选 | 任务 ID 列表
待上报的任务 ID，支持单个字符串或字符串数组。服务端按半角逗号、全角逗号、换行、空格或制表符拆分，并移除首尾空白和空项。
拆分后的任务数量须为 1 至 50，否则返回 HTTP 422 、错误码 40011 。同一请求中的任务共用 Feedback 和 FeedbackImages 。
IdType 为 session 时，按轮次顺序传入同一个 Session 的任务 ID，第一个任务为第 1 轮。一个请求只能上报一个 Session，同样支持 1 至 50 个任务。
AccountId string | 火山引擎账号 ID
Id 中任务所属的火山引擎账号 ID。
使用 Access Key 调用时必填。
使用方舟 API Key 调用时可省略，系统根据 API Key 解析账号 ID。

效果问题的类型。可选值：

voice_tone_reference_error ：音色参考错误
other ：其他
支持传入单个枚举值或枚举值数组。如果设置为其他值，接口返回 422 参数校验错误。
本字段可省略。
注意
仅当 Id 对应任务的真实模型属于 Doubao Seedance 2.x 系列时，才接受本字段。若 Id 对应模型不在支持范围内，接口返回业务错误码 60002 或 60003 。

Case 的类型。可选值：

可选的效果截图，最多 5 张，同一请求中的所有任务共用。条目格式、数量或图片引用不合法时，整个请求被拒绝，返回错误码 40015 。

错误码

按 Session 上报时，整个 Session 同时受理或同时拒绝。时间轴反馈条目的校验结果单独在 RejectedTimelineFeedbacks 中返回，不影响 Case 主记录的创建。
