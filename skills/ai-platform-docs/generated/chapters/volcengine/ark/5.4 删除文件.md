5.4 删除文件
DELETE https://ark.cn-beijing.volces.com/api/v3/files/{file_id}
根据文件 ID 删除已上传的文件，并将文件从存储空间中移除。删除后该文件无法再用于模型推理输入，且无法恢复。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
file_id string 必选 | 文件 ID
要删除的文件 ID，可通过 上传文件 接口返回的 id 字段获取
注意
文件删除后不可恢复，请确认该文件不再被推理任务引用后再执行删除。
响应参数
deleted boolean | 删除结果
文件是否删除成功。取值 true 表示已成功从存储空间中移除
id string | 文件 ID
被删除文件的唯一标识符（ID），与请求中传入的 file_id 一致
object string | 对象类型
对象类型，固定为 file ，用于标识返回结果对应的资源类型
