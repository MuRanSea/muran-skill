11.3.9.2 查询线程详情
GET https://ark.cn-beijing.volces.com/api/v3/sessions/{sessionId}/threads/{threadId}查询指定会话中某个线程的详细信息。线程是会话下的独立对话分支，一个会话可以包含多个线程（例如子智能体、多线程 topology 场景）。
说明
线程视图由服务端从会话事件流派生生成（ session.thread_created 及 session.thread_status_* 事件），不是独立持久化的资源。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
sessionId string 必选 | 会话 ID
会话 ID，格式为 sesn- 开头的字符串
threadId string 必选 | 线程 ID
线程 ID，格式为 sthr- 开头的字符串
响应参数
agent_name string | 智能体名称
线程关联的智能体名称。若创建事件缺失（如老数据），可能为空字符串。
created_at string | 创建时间
创建时间，ISO 8601 / RFC3339 格式
id string | 线程 ID
线程唯一标识符
session_id string | 会话 ID
所属会话 ID
status string | 线程状态
线程状态：
running 智能体正在处理
idle 空闲（等待用户输入或工具结果）
rescheduling 调度中
terminated 已终止
type string | 对象类型
对象类型，固定为 session_thread
updated_at string | 更新时间
最近一次事件更新时间，ISO 8601 / RFC3339 格式
parent_thread_id string | 父线程 ID
父线程 ID。顶级线程（primary thread）该字段为 null 。
