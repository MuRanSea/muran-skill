14.11.6 查询模型推理限额
POST https://ark.cn-beijing.volcengineapi.com/?Action=ListModelInferenceLimits&Version=2024-01-01查询指定基础模型的累计推理用量限额及当前用量。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
FoundationModelNames string[] 必选 | 基础模型名称列表
指定需要查询推理限额的基础模型名称列表，一次最多可传入 100 个模型名称。已下线模型不返回查询结果。
响应参数
Items object[] | 模型推理限额列表
模型推理限额信息列表。
CurrentUsage integer | 当前累计推理用量
Items.CurrentUsage
模型当前已累计的推理用量。
FoundationModelName string | 基础模型名称
Items.FoundationModelName
Limit integer | 累计推理用量上限
Items.Limit
模型的累计推理用量上限，推理限额关闭时不返回。
StartTime string | 限额生效时间
Items.StartTime
推理限额的生效时间，RFC3339 格式。
