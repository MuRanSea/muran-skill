11.4.6.5 删除凭证
DELETE https://ark.cn-beijing.volces.com/api/v3/vaults/{vault_id}/credentials/{credential_id}删除指定的凭证，删除后凭证永久无法恢复，使用该凭证的 MCP 服务或智能体将无法正常调用。鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
credential_id string 必选 | 凭证 ID
要删除的凭证 ID。通过创建凭证接口 (POST /vaults/{vault_id}/credentials) 返回, 或通过查询凭证列表接口获取。
注意
凭证删除后不可恢复，关联使用该凭证的服务将无法正常鉴权，请确认后再操作。
vault_id string 必选 | 保管库 ID
凭证所属的保管库 ID
响应参数
id string | 凭证 ID
被删除的凭证 ID
type string | 对象类型
对象类型，固定为 vault_credential_deleted
