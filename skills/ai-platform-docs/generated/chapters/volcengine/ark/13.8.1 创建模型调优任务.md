13.8 管理模型精调
13.8.1 创建模型调优任务
POST https://ark.cn-beijing.volcengineapi.com/?Action=CreateModelCustomizationJob&Version=2024-01-01创建一个模型调优任务，支持全量 SFT、SFT-LoRA、继续预训练、DPO-LoRA、DPO、GRPO、
GRPOLoRA、PPO、OPD、OPDLoRA 等训练类型。
说明
训练类型 CustomizationType 一经创建即不可修改；如需更换类型请新建任务。
任务创建后会进入排队（ Queue ）→ 运行中（ Running ）→ 完成（ Completed ）/ 失败
（ Failed ）/ 取消（ Cancelled ）的阶段流转，可通过 GetModelCustomizationJob 接口查询当前 Status.Phase。
Hyperparameters 数组中每一项的 Name 不能重复；具体可用超参数因训练类型不同而异，请参考训练类型文档。
强化学习类训练（ GRPO 、 GRPOLoRA 、 PPO 等）需配合 RewardConfigs 或 
CustomRLPipelineConfig 使用。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
