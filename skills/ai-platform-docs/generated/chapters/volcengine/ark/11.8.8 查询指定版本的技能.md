11.8.8 查询指定版本的技能
GET https://ark.cn-beijing.volces.com/api/v3/skills/{skill_id}/versions/{version}查询指定技能在某一版本下的详细信息，不返回技能文件内容。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
skill_id string 必选 | 技能 ID
用于指定要查询版本的技能。
version string 必选 | 版本号
用于指定要查询的版本号。
响应参数
created_at string | 创建时间
该版本的创建时间，采用 RFC 3339 格式。
display_title string | 展示名称
表示该版本的展示名称。
id string | 版本 ID
用于唯一标识该版本，值以 skillver- 开头。
skill_id string | 技能 ID
表示该版本所属技能的 ID。
type string | 资源类型
用于标识响应对象的资源类型，固定为 skill_version 。
version string | 版本号
表示技能的版本号。
description string | 技能描述
表示方舟平台从该版本的 SKILL.md 中解析出的技能描述。
