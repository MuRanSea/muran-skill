12.1.5 删除批量推理任务
POST https://ark.cn-beijing.volcengineapi.com/?Action=DeleteBatchInferenceJob&Version=2024-01-01删除指定的批量推理任务。删除后任务及其状态信息无法恢复，请谨慎操作。
注意
删除操作不可逆，任务及其状态信息将无法恢复，请确认后再执行。建议先通过 DryRun 预检请求合法性。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 任务 ID
待删除的批量推理任务 ID。
DryRun boolean 默认值 false | 预检请求
是否仅对此请求进行预检。 true 表示发送检查请求； false 表示发送正常请求，执行删除操作。响应参数
