11.4.2 查询保管库列表
GET https://ark.cn-beijing.volces.com/api/v3/vaults
分页查询当前租户下的所有保管库。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Query 参数
在 URL Query String 中传入。
limit integer | 每页数量
每页返回的数量
page string | 分页游标
分页游标，传入上一次响应里的 next_page，首次请求留空
响应参数
data object[] | 保管库列表
created_at string | 创建时间
data.created_at
保管库创建时间，RFC 3339 格式时间戳
display_name string | 保管库展示名
data.display_name
id string | 保管库 ID
data.id
保管库唯一标识符
type string | 对象类型
data.type
对象类型，固定为 vault
updated_at string | 更新时间
data.updated_at
保管库最后更新时间，RFC 3339 格式时间戳
metadata object | 自定义元数据
data.metadata
用户自定义键值对元数据；未设置或清空时返回 null
next_page string | 下一页游标
下一页游标，无更多数据时为空
total integer | 总数
符合条件的保管库总数
