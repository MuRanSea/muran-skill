13.10.8 更新评测任务
POST https://ark.cn-beijing.volcengineapi.com/?Action=UpdateEvaluationJob&Version=2024-01-01更新指定模型评测任务的名称或描述等可变属性。仅模型评测任务的名称（Name）和描述
（Description）可在创建后被更新；其他配置（如模型、评测集等）创建后不可修改。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 评测任务 ID
待更新的模型评测任务 ID。可在控制台评测任务列表页获取，或通过 ListEvaluationJobs 接口查询。Description string | 任务描述
更新后的模型评测任务描述。
DryRun boolean 默认值 false | 是否仅做预检
是否仅对此请求进行预检：
true ：仅做参数与权限校验，不会真正执行更新。
false ：发送正常请求，更新评测任务。
Name string | 任务名称
更新后的模型评测任务名称。
响应参数
本接口无特有的返回参数，成功时 HTTP 状态码为 200 ，返回结构中 Result 为空对象 {} 。
