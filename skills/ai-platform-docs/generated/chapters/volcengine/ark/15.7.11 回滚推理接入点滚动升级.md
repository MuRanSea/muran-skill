15.7.11 回滚推理接入点滚动升级
POST https://ark.cn-beijing.volcengineapi.com/?Action=RollbackEndpointRolling&Version=2024-01-01回滚指定的滚动更新任务，将推理接入点恢复到滚动更新开始前的状态。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 滚动更新任务 ID
要回滚的滚动更新任务 ID
Message string | 回滚原因
回滚操作的原因说明
响应参数
Id string | 滚动更新任务 ID
已回滚的滚动更新任务 ID
