12.2.6.6 查询席位 AFP 额度用量列表
POST https://ark.cn-beijing.volcengineapi.com/?Action=ListSeatAFPUsage&Version=2024-01-01分页查询企业版 AgentPlanTeam 模式下席位的 AFP 额度用量。支持按席位 ID、绑定用户、套餐档位过滤，按指定窗口用量或创建时间排序。
注意
仅适用于企业版 Agent Plan 套餐；个人版套餐用量请改用 GetAFPUsage。Filter 内 SeatIDs /UserNames / PlanType 单次最多各传入 1000 项，多个筛选条件之间为 AND 关系。返回的 Quota /Used 单位为 AFP，时间戳为 epoch 毫秒。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
ProjectName string 必选 | 项目名称
资源所属的项目名称。资源不在默认项目中时，填写实际项目名称。
Filter object | 过滤条件
席位过滤条件。多个筛选条件之间为 AND 关系。
PlanType string[] | 套餐档位
Filter.PlanType
按套餐档位过滤，可同时指定多个。取值： Small 、 Medium 、 Large 、 Max 。
SeatIDs string[] | 席位 ID 列表
Filter.SeatIDs
按席位 ID 过滤，单次请求最多传入 1000 个。
UserNames string[] | 绑定用户名
Filter.UserNames
按席位绑定的用户名过滤，单次请求最多传入 1000 个。
PageNumber integer 默认值 1 | 起始页码
分页查询的起始页码，从 1 开始。
最小值： 1
PageSize integer 默认值 10 | 每页大小
分页查询时每页返回的席位数量。
取值范围： [10, 100]
SortBy string 默认值 CreateTime | 排序字段
排序字段。取值：
AFPFiveHour ：按 5 小时 AFP 用量排序；
AFPWeekly ：按周 AFP 用量排序；
AFPMonthly ：按月 AFP 用量排序；
CreateTime ：按创建时间排序。
SortOrder string 默认值 Desc | 排序方向
排序方向。取值：
Asc ：升序排列；
Desc ：降序排列。
