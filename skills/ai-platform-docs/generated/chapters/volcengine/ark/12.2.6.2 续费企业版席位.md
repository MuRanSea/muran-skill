12.2.6.2 续费企业版席位
POST https://ark.cn-beijing.volcengineapi.com/?Action=RenewTeamSeats&Version=2024-01-01续费企业版席位，支持一次为不同席位设置不同续费时长。
您通过 API 接口发起部署请求或调用本服务的，即表示您已充分阅读、理解并同意 《火山方舟大模型订阅套餐服务专用条款》 、《豆包模型服务协议》 、《开源模型许可证》 、《Harness 能力说明和产品专用条款》 及其他适用的平台规则。如您不同意上述协议，请立即停止调用。说明
接口为异步执行，自动扣费，下单前请确保云账户内余额充足。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Plan string 必选 | 商品名称
待续费的企业版商品名称。可选值： AgentPlanTeam 、 CodingPlanTeam 。
Seats object[] 必选 | 续费明细
续费明细列表，非空。支持一次为不同席位组设置不同的续费时长。
Duration number 必选 | 续费时长
Seats.Duration
本组的续费时长，单位以 PricingCycle 为准。
取值范围： [1, 12]
PricingCycle string 必选 | 计费周期
Seats.PricingCycle
计费周期。当前仅支持 Month （包月）。
SeatIds string[] 必选 | 席位 ID 列表
Seats.SeatIds
本组待续费的席位 ID 列表，不可为空。
DryRun boolean 默认值 false | 预检模式
是否仅做参数预检而不实际下单。设为 true 时仅校验请求，不执行扣款。
ProjectName string 默认值 default | 项目名称
资源所属的项目名称。资源不在默认项目中时，填写实际项目名称。
响应参数
SeatIds string[] | 成功席位 ID
本次所有已续费的席位 ID 汇总列表。
