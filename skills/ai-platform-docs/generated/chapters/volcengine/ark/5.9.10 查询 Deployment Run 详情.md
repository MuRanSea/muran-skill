5.9.10 查询 Deployment Run 详情
GET https://ark.cn-beijing.volces.com/api/v3/deployment_runs/{deployment_run_id}查询某次 Deployment Run 的触发来源（手动/定时）和 Session 启动结果，用于确认定时任务是否按计划启动。
接口不返回 Session 中模型、工具或 Agent 任务的最终执行状态。Run 成功后，通过 session_id 查询Session 和事件。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
deployment_run_id string 必选 | Run ID
要查询的 Deployment Run ID。
响应参数
agent object | Agent 引用
本次 Run 受理时固定的 Agent 和版本。
id string | Agent ID
agent.id
Deployment 使用的 Agent ID。
type string | 对象类型
agent.type
Agent 引用类型，固定为 agent 。
version integer | Agent 版本
agent.version
Deployment 固定使用的 Agent 版本号。
created_at string | 创建时间
Run 记录创建时间，采用 RFC 3339 格式。
deployment_id string | Deployment ID
触发本次 Run 的 Deployment ID。
id string | Run ID
Deployment Run 的唯一标识符，以 drun- 开头，形如 drun-<14位时间戳>-<10位随机字符> 。trigger_context object | 触发信息
本次 Run 的触发方式和计划执行时间。
type string | 触发方式
trigger_context.type
Run 的触发方式： manual 表示通过立即运行接口手动触发； schedule 表示由定时计划自动触发。scheduled_at string | 计划执行时间
trigger_context.scheduled_at
定时 Run 按计划应开始执行的时间，采用 RFC 3339 格式，不包含实际调度产生的延迟。手动触发的 Run不返回该字段。
type string | 对象类型
对象类型，固定为 deployment_run 。
error object | 失败信息
Run 启动失败时返回的错误信息。Run 成功或尚未结束时不返回该字段。
message string | 错误信息
error.message
用于定位失败原因的可读信息。
type string | 错误类型
error.type
错误分类。
session_id string | Session ID
Session 和初始事件均受理成功时返回的 Session ID。Run 失败或尚未结束时不返回该字段。
