15.6.2 删除评测任务
POST https://ark.cn-beijing.volcengineapi.com/?Action=DeleteEvaluationJob&Version=2024-01-01删除指定的模型评测任务。任务删除后不可恢复，请确认任务已停止运行且评测结果已确认后再执行删除。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Id string 必选 | 评测任务 ID
待删除的模型评测任务 ID。可在控制台评测任务列表页获取，或通过 ListEvaluationJobs 接口查询。DryRun boolean 默认值 false | 是否仅做预检
是否仅对此请求进行预检：
true ：仅做参数与权限校验，不会真正删除任务。
false ：发送正常请求，删除评测任务。
响应参数
本接口无特有的返回参数，成功时 HTTP 状态码为 200 ，返回结构中 Result 为空对象 {} 。
