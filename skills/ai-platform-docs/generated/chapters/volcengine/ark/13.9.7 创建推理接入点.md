13.9.7 创建推理接入点
POST https://ark.cn-beijing.volcengineapi.com/?Action=CreateEndpoint&Version=2024-01-01创建一个推理接入点（Endpoint），用于调用模型服务。接入点是调用模型的入口资源，绑定模型后即可通过接入点 ID 发起推理请求。
注意
创建接入点为异步操作，返回 Id 后接入点进入调度（ Scheduling ）状态，运行就绪后转为 Running 。计费随接入点进入 Running 状态开始；如需先校验参数而不实际创建，可设置 DryRun 为 true 。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
