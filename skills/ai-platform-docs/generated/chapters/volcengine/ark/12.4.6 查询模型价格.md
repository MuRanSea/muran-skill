12.4.6 查询模型价格
POST https://ark.cn-beijing.volcengineapi.com/?Action=ListModelPrices&Version=2024-01-01查询当前账号可见基础模型的价格信息，可按服务类型、窗口、区域、时段、分辨率和输出尺寸筛选价格分组。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
FoundationModelNames string[] 必选 | 基础模型列表
待查询价格的基础模型名称列表。重复名称仅查询一次，并按去重后的请求顺序返回结果。注意
传入空列表时返回空的 ModelPrices 。
Dimensions object[] | 价格维度筛选
按服务类型、窗口、区域、时段、分辨率和输出尺寸筛选价格分组。未指定 service_type 时，返回空的模型价格列表。
说明
同一维度的多个取值按“或”匹配，不同维度按“且”匹配。未匹配到价格时返回空结果。
Name string 必选 | 维度名称
Dimensions.Name
价格筛选维度名称。可选值： service_type （服务类型）、 window （窗口）、 region （区域）、time_period_type （时段类型）、 resolution （分辨率）、 output_size_level （输出尺寸级别）。Values string[] 必选 | 维度取值
Dimensions.Values

响应参数
ModelPrices object[] | 模型价格列表
当前账号可见模型的价格列表。
说明
无匹配结果、模型不可见或请求的模型列表为空时返回空数组。
FoundationModelName string | 基础模型名称
ModelPrices.FoundationModelName

ModelPrices.PriceGroups
基础模型在不同计费条件下对应的价格分组。
Dimensions object[] | 价格维度
ModelPrices.PriceGroups.Dimensions
价格分组中显式配置的维度组合。默认档位对应的维度不包含在此数组中。
Name string | 维度名称
ModelPrices.PriceGroups.Dimensions.Name
价格分组中显式配置的维度名称。可选值： service_type 、 window 、 region 、 time_period_type 、resolution 、 output_size_level 。
Value string | 维度取值
ModelPrices.PriceGroups.Dimensions.Value
价格分组中该维度的实际取值。

ModelPrices.PriceGroups.PriceItems
价格分组中的计费项价格信息。
Label string | 计费项名称
ModelPrices.PriceGroups.PriceItems.Label
维度名称 取值 查询规则
4k ：4K 分辨率档位。 |
"" ：默认分辨率档位。
output_size_level
large ：大尺寸档位。 |未

计费项名称。仅返回当前模型适用的计费项。

ModelPrices.PriceGroups.PriceItems.DiscountPriceEndTime

促销价格的生效时间，格式为 RFC3339。
OriginalPrice number | 原价
ModelPrices.PriceGroups.PriceItems.OriginalPrice
折扣前价格。
说明
缺少该字段表示未提供原始价格，不得按 0 处理。
Price number | 当前价格

当前账号对应的价格。
说明
缺少该字段不表示免费，缺失时不得按 0 处理。
UsageUnit string | 用量单位

Name string | 维度名称

Value string | 维度取值
ModelPrices.DimensionAttributes.Value
维度附属信息的取值。
Ranges string[] | 维度范围
ModelPrices.DimensionAttributes.Ranges
与维度取值关联的范围信息。闲时时段的取值可能为包含星期、起始时间、结束时间和时区等信息的JSON 字符串，具体内容以实际返回值为准。
