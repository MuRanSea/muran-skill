11.1.2 查询智能体列表
GET https://ark.cn-beijing.volces.com/api/v3/agents
分页查询当前账号下的所有智能体，支持按创建时间范围筛选。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Query 参数
在 URL Query String 中传入。
created_at_gte string | 创建时间下界
按创建时间筛选，返回创建时间大于等于该值的智能体，ISO 8601 格式
created_at_lte string | 创建时间上界
按创建时间筛选，返回创建时间小于等于该值的智能体，ISO 8601 格式
limit integer 默认值 20 | 每页数量
每页返回的数量。
取值范围： [1, 100]
page string | 分页游标
分页 cursor（opaque），传入上一页返回的 next_page 获取下一页数据；首次请求可省略响应参数
data object[] | 智能体列表
当前页返回的智能体列表；无命中时返回空数组 []
created_at string | RFC 3339 时间
data.created_at
id string | Agent ID，格式为 agent- 开头的字符串
data.id
对外暴露给 session 引用。
name string | 人类可读名称，1–256 字符
data.name
type string | 固定 "agent"
data.type
取值固定为 agent 。
updated_at string | RFC 3339 时间
data.updated_at
version integer | 版本号；每次 update 递增
data.version
description string | 描述信息，最大 2048 字符
data.description
mcp_servers object[] | MCP 服务器列表，最多 20 项
data.mcp_servers
name string | 在本 Agent 内唯一
data.mcp_servers.name
被 tools[].mcp_server_name 引用。
type string | MCP server 类型，当前固定 "url"
data.mcp_servers.type
url string | MCP server URL
data.mcp_servers.url
metadata object | 用户自定义键值对元数据
data.metadata
最多 16 对，key ≤ 64 字符，value ≤ 512 字符。
model object | 模型配置
data.model
id string | 模型 ID 或推理接入点 ID
data.model.id
例如模型 ID doubao-seed-2-1-pro-260628 ，或推理接入点 ID ep-20260907123456-abcd1 。reasoning_effort string | 推理投入档位，对应底层模型调用的 reasoning_effort 字段data.model.reasoning_effort
可填 none 、 minimal 、 low 、 medium 、 high 、 xhigh 、 max ；实际支持值与默认值以模型元数据为准。不设置或传空字符串时，Managed Agents 使用模型元数据中的默认值；如模型元数据未配置默认值，则不会向底层模型调用传递该字段，由底层模型服务按默认策略处理。各模型支持的取值和默认值，请参见 模型支持的参数列表 。
service_tier string | 推理服务档位，对应底层模型调用的 service_tier 字段
data.model.service_tier
可填 auto 、 default 、 fast ；实际支持值与默认值以模型元数据为准。不设置或传空字符串时，Managed Agents 使用模型元数据中的默认值；如模型元数据未配置默认值，则不会向底层模型调用传递该字段，由底层模型服务按默认策略处理。传入不支持的取值时返回 400 InvalidParameter 。各模型支持的取值和默认值，请参见 模型支持的参数列表 。
speed string | 模型推理速度档位，可填 standard 、 fast
data.model.speed
standard 为标准模式， fast 为快速模式；并非所有模型都支持 fast ，实际支持范围以模型元数据为准。不设置或传空字符串时，Managed Agents 不会向底层模型调用传递该字段，由底层模型服务按默认策略处理。
thinking string | 思考开关，对应底层模型调用的 thinking.type 字段
data.model.thinking
可填 enabled 、 disabled 、 auto ； auto 表示由模型判断是否思考，不表示继承。实际支持值与默认值以模型元数据为准。不设置或传空字符串时，Managed Agents 使用模型元数据中的默认值；如模型元数据未配置默认值，则不会向底层模型调用传递该字段，由底层模型服务按默认策略处理。传入不支持的取值时返回 400 InvalidParameter 。各模型支持的取值和默认值，请参见 模型支持的参数列表 。multiagent object | 多 Agent 编排拓扑（可选）
data.multiagent
agents object[] | 下属 Agent 数组
data.multiagent.agents
1–20 项；深度限制为 1（被引用的 Agent 自身不能再有 multiagent ）。
type string | 引用类型
data.multiagent.agents.type
id string | 被引用 Agent 的 ID
data.multiagent.agents.id
version integer | 被引用 Agent 的版本号
data.multiagent.agents.version
type string | 拓扑类型
data.multiagent.type
skills object[] | Skill 列表，最多 20 项
data.skills
type string | Skill 来源类型
data.skills.type
skill_hub ：来自 SkillHub 的公共 Skill。
custom ：当前账号通过 Skills API 创建的自定义 Skill。
skill_id string | Skill ID，形如 skill-...
data.skills.skill_id
version string | Skill 版本号，可选；不传走最新
data.skills.version
system string | System prompt，最大 100,000 字符
data.system
tags object[] | 资源标签
data.tags
key string | 标签键
data.tags.key
标签键，用于分类和检索
value string | 标签值
data.tags.value
tools object[] | 工具配置数组
data.tools
type string | 工具 type
data.tools.type
configs object[] | toolset 类专用
data.tools.configs
name string | 工具名称
data.tools.configs.name
工具名称，例如 bash 、 read_file 等
enabled boolean | 是否启用
data.tools.configs.enabled
是否启用该工具，默认 true
permission_policy object | 权限策略
data.tools.configs.permission_policy
工具权限策略
type string | 策略类型
data.tools.configs.permission_policy.type
策略类型， always_allow 为总是允许， always_ask 为使用前询问
default_config object | toolset 类专用；未在 configs 里显式列出的工具走此默认
data.tools.default_config
enabled boolean | 默认是否启用
data.tools.default_config.enabled
未显式配置的工具默认是否启用
permission_policy object | 默认权限策略
data.tools.default_config.permission_policy
未显式配置的工具默认权限策略
type string | 策略类型
data.tools.default_config.permission_policy.type
策略类型， always_allow 为总是允许， always_ask 为使用前询问
description string | custom 专用；1–1024 字符
data.tools.description
input_schema string | custom 专用；承载 JSON Schema 的字符串形态 （wire 上是 JSON-encodedstring，非 nested object）
data.tools.input_schema
mcp_server_name string | mcp_toolset 专用；须匹配 mcp_servers[].name 。
data.tools.mcp_server_name
name string | custom 专用；1–128 字符， [A-Za-z0-9_-]
data.tools.name
next_page string | 下一页游标
下一页 cursor（opaque），将该值原样作为下一次请求的 page 参数拉取下一页；已到末页时不返回该字段
total integer | 智能体总数
命中的智能体总数；是否返回由服务端决定
