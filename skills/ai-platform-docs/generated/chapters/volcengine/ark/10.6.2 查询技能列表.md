10.6.2 查询技能列表
GET https://ark.cn-beijing.volces.com/api/v3/skills
查询方舟平台预置技能或自定义技能列表。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Query 参数
在 URL Query String 中传入。
limit integer 默认值 20 | 每页数量
用于设置单页最多返回的记录数。
取值范围： [1, 100]
name string | 技能名称
用于按 SKILL.md 中的技能名称筛选技能。
page string | 下一页标识
用于告诉服务端从上一页结束的位置继续返回数据。该值由服务端生成，不是页码。
例如，首次请求 GET /api/v3/skills?limit=20 时不传 page 。如果响应返回 "has_more": true 和 "next_page":
"<NEXT_PAGE>" ，下一次请求时，将响应中的 <NEXT_PAGE> 传入 GET /api/v3/skills?
limit=20&page=<NEXT_PAGE> ，即可获取下一页技能列表。不要自行生成或修改该值。
source string | 技能来源
用于按技能来源筛选技能。设置为 custom 时，服务端返回当前账号的自定义技能。设置为 ark 时，服务端返回方舟平台预置技能。省略时，服务端返回这两类技能。该接口不支持查询 Skill Hub 技能。传入 skill_hub 时，服务端返回参数错误。
响应参数
data object[] | 技能列表
包含当前页返回的技能列表。
created_at integer | 创建时间
data.created_at
表示技能的创建时间。
display_title string | 展示名称
data.display_title
表示技能的展示名称。服务端优先返回最新版本的展示名称。未配置时，服务端返回 SKILL.md 中的 name 。
id string | 技能 ID
data.id
用于唯一标识技能。服务端返回的自定义技能和方舟平台预置技能 ID 均以 skill- 开头。latest_version string | 最新版本
data.latest_version
表示技能的最新版本号。
object string | 资源类型
data.object
用于标识响应对象的资源类型，固定为 skill 。
source string | 技能来源
data.source
该字段表示技能来源：
custom 表示当前账号上传或导入的自定义技能。
ark 表示方舟平台预置技能。
updated_at integer | 更新时间
data.updated_at
表示技能最后一次更新的时间。
description string | 技能描述
data.description
表示方舟平台从 SKILL.md 中解析出的技能描述。
name string | 技能名称
data.name
表示 SKILL.md 中定义的技能名称。
protection_enabled boolean | 内容保护开关
data.protection_enabled
表示技能是否已启用内容保护。 true 表示运行技能时，方舟平台会注入保护指令，降低技能内容被直接输出的风险。 false 表示方舟平台未启用该保护。
has_more boolean | 是否有下一页
表示是否还有下一页数据。 true 表示仍有数据，可以继续分页查询。 false 表示已返回最后一页。next_page string | 下一页标识
服务端生成的下一页标识，用于记录本页结束的位置。 has_more 为 true 时，将该值原样传入下一次请求的 page 参数。没有下一页时，服务端不返回该字段。
