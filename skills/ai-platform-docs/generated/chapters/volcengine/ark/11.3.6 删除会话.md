11.3.6 删除会话
DELETE https://ark.cn-beijing.volces.com/api/v3/sessions/{session_id}
永久删除不再需要的会话并释放其活跃会话占用。删除成功后，该会话将无法再通过 查询会话详情 或 查询会话列表 访问。相关运行资源可能继续在后台回收，无需轮询删除状态。
删除会话前，请根据会话状态处理：
**状态为 ** idle ** 或 ** terminated ：可以直接删除。
**状态为 ** running ：先发送 user.interrupt ，等待状态恢复为 idle 后再删除。
其他状态：等待当前操作完成并恢复为 idle 后再删除。
如需中断当前任务但保留会话，请发送 user.interrupt ，不要删除会话。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权 。
API Key 鉴权，请在 API Key 管理 页面，获取长效 API Key。
请求参数
Path 参数
session_id string 必选 | 会话 ID
要删除的会话 ID，格式为 sesn- 开头的字符串。
响应参数
id string | 会话 ID
被删除的会话 ID。
type string | 对象类型
对象类型，固定为 session_deleted 。
