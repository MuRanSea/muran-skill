13.7.4 获取定制模型列表
POST https://ark.cn-beijing.volcengineapi.com/?Action=ListCustomModels&Version=2024-01-01查询当前账号下的定制模型列表，支持按模型 ID、名称、标签和项目等条件筛选，并可分页与排序返回结果。
注意
本接口仅返回当前账号下可见的定制模型，跨项目查询需指定正确的 ProjectName。
鉴权
本接口支持鉴权方式如下，详情请参见 Base URL 及鉴权。
Access Key 鉴权，请在 Access Key 管理 页面，获取 Access Key。本接口仅支持 Access Key 鉴权。请求参数
Body 参数
Filter object | 定制模型筛选条件
待查询定制模型的筛选条件。
Ids string[] | 定制模型 ID 列表
Filter.Ids
定制模型 ID 数组，精确匹配。
Name string | 定制模型名称
Filter.Name
定制模型名称，模糊匹配。
PageNumber integer 默认值 1 | 起始页码
分页查询时的起始页码，从 1 开始。
最小值： 1
PageSize integer 默认值 10 | 每页记录数
分页查询时每页显示的记录数。
取值范围： [1, 100]
ProjectName string 默认值 default | 项目名称
资源所属的项目名称。若资源不在默认项目中，需填写正确的项目名称。
SortBy string 默认值 CreateTime | 排序指标
指定排序指标。可选值： CreateTime 、 UpdateTime 。
SortOrder string 默认值 Desc | 排序顺序
指定排序顺序。可选值： Asc 、 Desc 。
TagFilters object[] | 标签筛选条件
基于绑定标签的筛选条件。
Key string 必选 | 标签键
TagFilters.Key
Values string[] | 标签值列表
TagFilters.Values

Items.CreateTime
定制模型创建时间，RFC 3339 格式。
CustomizationType string | 定制类型
Items.CustomizationType
定制类型。

FinetuneLoRA ：LoRA 精调。
Pretrain ：预训练。
FoundationModel object | 基础模型引用
Items.FoundationModel
定制模型所基于的基础模型引用。

Items.FoundationModel.ModelVersion
Name string | 基础模型名称
Items.FoundationModel.Name

定制模型的超参列表。

超参数的参数名
Value string | 超参数值
Items.HyperParameters.Value

Id string | 定制模型 ID
Items.Id
Name string | 定制模型名称
Items.Name
ProjectName string | 项目名称
Items.ProjectName
定制模型所属的项目名称。
SourceType string | 来源类型
Items.SourceType

Status string | 定制模型状态
Items.Status

Items.Tags
定制模型绑定的标签列表。
Key string | 标签键
Items.Tags.Key
Value string | 标签值
Items.Tags.Value

Description string | 定制模型描述

Items.ModelCustomizationJobId
模型调优任务 ID。
SourceModelAvailable boolean | 源模型是否可用
Items.SourceModelAvailable
如果当前定制模型是基于全量 SFT 模型增量精调得到的，该字段表示全量 SFT 模型是否仍然有效。PageNumber integer | 起始页码
分页查询时的起始页码。
PageSize integer | 每页记录数

TotalCount integer | 定制模型总数
